# Hip Dislocation

*Trauma · 30 / 67*

## 1 Basics

### Epidemiology

**Who** — young, **high-energy** trauma (MVA **dashboard**); rare but **high rate of associated injuries** (**95%**)

**Direction** — **posterior 90%** · anterior **\~10%** (Orthobullets) · **10–15%** (TO)

**Stability** — bony geometry + **labrum, capsule, ligamentum teres**, muscles

### Associated injuries (knee, aorta)

| Dislocation | Associated injury |
|---|---|
| **Posterior** | **Posterior wall fracture (commonest; up to 70%, TO)**, femoral head fracture (**5–15%**, TO · 10–15%, OB) — anterior head fragment, **sciatic nerve (peroneal division)**, **ipsilateral knee (up to 25%)**, AVN |
| **Anterior** | **Femoral head impaction / chondral fracture — commonest (TO)** (superolateral, **Hill-Sachs-like**); acetabulum, neck, GT, shaft; **AIIS avulsion** (superior type); femoral vessels + **femoral nerve** (less common) |

**Ipsilateral knee on MRI** — **93% abnormal**: **effusion 37%**, **bone bruise 33%**, **meniscal tear 30%** → most likely concomitant = **ipsilateral meniscus tear**\
✗ Wrong options: contralateral ACL · SDH · ankle · lumbar burst

**Thoracic aortic rupture** — associated with **posterior hip dislocation** (deceleration); **bilateral pulse deficit → proximal large-vessel injury** → CXR mediastinum, thoracic surgery

## 2 Mechanism

| Hip position | Result |
|---|---|
| **Flexed + adducted (+ IR)**, axial load via knee (**dashboard**) | **Posterior — pure** (more flexion / adduction → simple) |
| Flexed + **abducted** | **Posterior fracture-dislocation** |
| **Abduction + ER + extension** | **Anterior superior (pubic)** |
| **Abduction + ER + flexion** | **Anterior inferior (obturator)** |

## 3 Presentation

| Type | Limb attitude |
|---|---|
| **Posterior** | **Flexion, adduction, internal rotation**, shortened |
| **Anterior pubic (superior)** | **Extension + external rotation** |
| **Anterior obturator (inferior)** | **Flexion, abduction, external rotation** |
| **Irreducible variant** | **Neutral, mildly shortened** — not overtly flexed / IR, limb locked |

**Exam** — ATLS; **sciatic nerve (10–20%)**; knee stability; **CXR for aortic injury**

**FNB attitude question (TO)** — answer key not provided by the source; map: **FADIR → posterior**, **FABER → anterior obturator**, **extension + abduction (ER) → anterior pubic**

## 4 Diagnosis & Classification

### Classification

**Simple** — pure dislocation · **Complex** — + acetabulum or proximal femur fracture

| Thompson-Epstein (posterior) (TO) | Description |
|---|---|
| 1 | ± Minor fracture |
| 2 | **Large single posterior rim** fragment |
| 3 | **Comminuted rim** ± major fragment |
| 4 | **Acetabular floor** fracture |
| 5 | **Femoral head** fracture |

| Epstein (anterior) (TO) | Description |
|---|---|
| **Type 1 — superior** | **Pubic, subspinous** |
| **Type 2 — inferior** | **Obturator, thyroid, perineal** |
| Subtypes | **A** simple · **B** head fracture · **C** acetabular fracture |

### Key radiology findings

| Finding | Meaning |
|---|---|
| AP + **cross-table lateral** | **Anterior vs posterior**; **check femoral neck before reduction** |
| **Shenton's line broken** | **All dislocations** (inferior neck ↔ superior obturator foramen) |
| **Head smaller** than other side, over roof, **lesser trochanter hidden (IR)** | **Posterior** |
| **Head larger**, **medial / inferior** to acetabulum | **Anterior** |
| **Cranial head close to ilium + ER (prominent LT)** + IA fragments | **Irreducible variant** (✗ Wrong options: absent fragments · hidden LT · Shenton's (all dislocations)) |
| **Post-reduction CT — mandatory in ALL** | Head fractures, **loose bodies / incarcerated fragments** (even if concentric on X-ray), acetabular fractures |
| Post-reduction AP, inlet / outlet, **Judet** | — |
| MRI | Controversial, not routine (labrum, cartilage, vascularity) |

**Advanced imaging before reduction** — **no** → reduce first

## 5 Management

```
Hip dislocation
├─ Femoral neck fracture → NO closed reduction; fix neck first (ORIF)
├─ Otherwise → emergent closed reduction (GA / deep sedation) → post-reduction CT
│      ├─ concentric, stable, no fragments → protected WB 4–6 wk
│      └─ incarcerated fragment / non-concentric → open reduction ± removal
└─ Irreducible → urgent open reduction (posterior → KL · anterior → Smith-Petersen)
```

### Reduction — urgency & technique (including children)

**Timing** — **within 6 h** (OB, TO) · **within 12 h** (Orthobullets, OB) — read the options; **> 12 h → 5.6× AVN odds (TO)**; ↑ adverse events

**Hip before wrist** — reduce hip first; **CT after reduction**\
✗ Wrong options: CT / MRI first

**Technique** — supine, **traction in line with deformity**, adequate sedation + relaxation, assess stability

| Manoeuvre (TO) | Dislocation | Key steps |
|---|---|---|
| **Allis** | Posterior | Inline traction, **knee 90°**, assistant stabilises pelvis, extend + ER |
| **Bigelow** | Posterior | Traction, knee 90°, **extension, abduction, ER** |
| **East Baltimore lift** | Posterior | Hip + knee 90°, physician + assistant lift under popliteal fossa |
| **Allis leg extension** | Anterior | Inline traction; **pubic → hyperextension** |
| **Reverse Bigelow** | Anterior | Traction in line → **adduct, IR, extend** |

**Child (10-yr, posterior)** — **closed reduction under GA with fluoroscopy** → avoids **physeal separation (epiphyseal displacement)**, confirms concentricity\
✗ Wrong options: ED sedation · no fluoroscopy · open first

**After reduction (TO)** — **WBAT**, ROM / strengthening, **jog 6–8 wk**, **running / sport 3–4 months**; follow **18 months–2 yr** for AVN

**Simple dislocation (Orthobullets)** — **protected WB 4–6 wk**

### Post-reduction CT

**Next step after closed reduction (any)** — **CT hip + pelvis**\
✗ Wrong options: skeletal traction · EUA fluoroscopy · spica · TDWB · observation

**Skeletal traction** — if acetabular fracture / loose body / unstable

### Operative criteria

| Indication | Treatment |
|---|---|
| **Irreducible** dislocation | **Urgent open reduction** |
| **Incarcerated fragment** on CT, **non-concentric** reduction | Open reduction / fragment removal |
| **Delayed presentation** | Open reduction |
| **Associated femoral neck fracture** | **Stabilise neck before reduction** |
| Acetabular / femoral head fractures | ORIF |
| Arthroscopy | No established indication (loose bodies, labrum) |

### Anterior / obturator & irreducible dislocations — recognition & open approach

**Approach** — **posterior → Kocher-Langenbeck** · **anterior → Smith-Petersen** (or Watson-Jones)

**Irreducible femoral head fracture-dislocation** — head **buttonholes through labrum-bone interval**; **Smith-Petersen**: ↓ op time, ↓ blood loss, better view, **spares head supply** (anterior capsule contributes little)

**Smith-Petersen interval** — **sartorius (femoral) ↔ TFL (superior gluteal)**; deep: rectus femoris ↔ gluteus medius

**Other intervals** — Watson-Jones: TFL ↔ gluteus medius (both **superior gluteal**) · Hardinge: splits gluteus medius + vastus lateralis (no internervous plane) · **posterior (Moore / Southern)**: splits gluteus maximus

**Posterior approach risk** — **lateral epiphyseal artery within 15 mm of external rotator insertions**

**Irreducible without PW fracture (Mehta)** — **urgent ORIF without closed attempts** → avoid iatrogenic neck fracture

### Associated femoral head fracture — management

**Infrafoveal head fracture, stable hip, 8 mm displacement (TO)** — **ORIF via anterior approach**\
✗ Wrong options: traction · excision · posterior ORIF

**Approach rule (TO)** — **Pipkin I / II → anterior** · **Pipkin IV → posterior**

**Nonop Pipkin I / II (TO)** — **< 2 mm displacement**, stable hip, **no interposed fragment**

## 6 Complications

| Complication | Rate / fact |
|---|---|
| **Post-traumatic arthritis** | **Up to 20% simple** (commonest long-term, TO); markedly ↑ complex; **anterior 17%** (TO) |
| **AVN** | **5–40%** (Orthobullets) · **2–10% if reduced < 6 h** (TO); ↑ with time to reduction; **anterior 4%** (TO) |
| **Sciatic nerve** (peroneal division) | **8–20%** (Orthobullets) · **10–15%** (TO); ↑ with delayed reduction |
| HO | **2.8–9%** (TO); repeated reduction attempts |
| **Recurrent dislocation** | **< 2%** |

## X vs Y

| | **Posterior** | **Anterior** |
|---|---|---|
| Frequency | **90%** | \~10% |
| Attitude | **Flexion, adduction, IR** | **ER** + abduction (obturator: flexion · pubic: extension) |
| X-ray head size | **Smaller** | **Larger** |
| Associated | **PW fracture**, sciatic nerve, knee | **Head impaction**, femoral NV |
| AVN | Higher | **4%** |
| Open approach | **Kocher-Langenbeck** | **Smith-Petersen** |

| | **Anterior pubic (superior)** | **Anterior obturator (inferior)** |
|---|---|---|
| Hip at injury | **Extension** | **Flexion** |
| Attitude | **Extension + ER** | **Flexion, abduction, ER** |
| X-ray | Head superior | **Head inferior** |
