# Terrible Triad Injury of Elbow

*Trauma · 62 / 67*

## 1 Basics

### Components of the triad

**Triad (Hotchkiss 1996)** — **elbow dislocation (posterolateral)** + **radial head / neck fracture** + **coronoid fracture** · LCL injury almost always

**NOT part of it (TO)** — **olecranon fracture** · **biceps tendon tear**\
✗ Wrong options: LCL injury · coronoid · radial head (all part)

**Mason-Johnston type IV** (radial head fracture + dislocation) = terrible triad pattern (TO)

**Coronoid fracture types in the triad (TO)** — mostly **tip**, less often **anteromedial facet** (O'Driscoll)

![Terrible triad — lateral radiograph](../../Orthobullets/attachments/ob1021-xray-elbow-lat-terrible-triad.jpg)

### Anatomy — elbow stabilisers

| Primary (TO) | Secondary (TO) |
|---|---|
| **Ulnohumeral joint (coronoid)** — buttress vs varus + posterior dislocation | **Radial head** — valgus + PLRI |
| **Anterior bundle of MCL** | Flexor-pronator + extensor origins |
| **LCL complex** | Joint capsule |

**Radial head** — **secondary restraint to PLRI + valgus** (Orthobullets) · "**primary restraint to PLRI**" (OB) — read the options · neutral rotation: lateral non-articular margin between **radial styloid + Lister's tubercle**

**Coronoid** — **anterior + varus buttress**; \~60% of anterior articulation (TO); **resists posterior subluxation beyond 30° flexion** · fragment often has **anterior capsule** attached

**Anterior capsule insertion** — **5.9 mm from tip** (TO) · inserts more distally — small tip fractures often lack capsule (OB) · coronoid tip fracture is a **shear**, not an avulsion (OB)

| MCL bundle | Fact |
|---|---|
| **Anterior** | **Most important — valgus + PMRI restraint** · inserts **sublime tubercle (anteromedial facet of coronoid)**, **18.4 mm dorsal to tip** (✗ Wrong options: 3 mm distal to tip · radial tuberosity) |
| Posterior | Valgus instability in flexion |
| Transverse | — |

| LCL component (insert: **supinator crest**) | Fact |
|---|---|
| **LUCL** | **Most important; primary restraint to PLRI** · pushing up from chair |
| Radial collateral | Varus instability |
| Annular | Little stability |
| Accessory collateral | — |

**LCL injury** — usually **avulsed from the lateral epicondyle (humeral origin)** ± extensor origin rupture

## 2 Mechanism

### Mechanism & sequence of soft-tissue failure

**Mechanism** — fall on **extended arm, forearm supinated** → **valgus + axial + posterolateral rotatory** forces → **posterolateral dislocation** · \~60% of complex dislocations from **standing-height fall** (TO)

**Sequence (Horii circle)** — **LCL → anterior capsule (coronoid) → MCL** · **MCL torn last** (TO)\
✗ Wrong options: MCL first

**EXCEPT (TO)** — "**LCL tear is uncommon due to valgus force**" — false; LCL fails first

**Supination + axial + posterolateral + valgus** — **coronoid + radial head fracture + dislocation**\
✗ Wrong options: supracondylar · anterior olecranon fracture-dislocation (direct blow at 90°) · coronoid + olecranon + LCL (**varus**)

| Pattern | Force | Fracture |
|---|---|---|
| **PLRI (terrible triad)** | **Valgus**, supination, axial | Radial head + coronoid **tip** |
| **PMRI** | **Varus** | **Anteromedial coronoid facet**, LCL; often no radial head fracture |

**PLRI far commoner** than PMRI

## 3 Presentation

**Symptoms** — pain, **clicking + locking in extension** · varus / valgus instability · **check DRUJ (Essex-Lopresti)**

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| Pre- + post-reduction X-rays | **Concentric ulnohumeral + radiocapitellar joints** · **radial neck line through capitellum centre** on every view |
| Lateral | **Coronoid fracture** |
| Wrist / forearm | When indicated (Essex-Lopresti) |
| **CT ± 3D** | Coronoid detail, fracture lines |

### Coronoid anatomy & biomechanics (MCL insertion, Regan-Morrey, approach)

| Regan-Morrey | Coronoid height | Fixation |
|---|---|---|
| **I** | **Tip** (< 10%) | **Not needed** — no stability conferred (cadaver) |
| **II** | **≤ 50%** | Usually not — fix MCL first if unstable |
| **III** | **> 50%** | **Fix** |

**Biomechanics** — **> 50% fractured → ↑ posterior axial displacement at all flexion angles incl. 30°** · **< 50% (I + II) → no significant change** · **anteromedial facet → PMRI**\
✗ Wrong options: 25% → displacement

**Fix the coronoid** — when > 10% (OB) · > 30–50% base (OB) · **type III** (OB) · decided by **fragment size + stability after radial head** — read the options\
✗ Wrong options: displacement > 5 mm · comminution · age

**Repair even type I (TO)** — **restores anterior bony buttress + anterior capsule insertion → prevents posterior subluxation** · OB: type I / II repair adds little\
✗ Wrong options: brachialis attachment · HO prevention · LUCL isometric point

**Isolated large coronoid fracture** — **medial FCU-splitting approach + buttress plate** → FCU = **ulnar nerve** · triad → through lateral radial head defect

## 5 Management

```
Terrible triad (after reduction)
├─ Rare: concentric, small coronoid, radial head non-surgical, stable → splint 90° 7–10 d, early ROM
└─ Most → sequential repair, deep to superficial, then retest
       ├─ 1 coronoid (fix / capsular suture) → 2 radial head ORIF or replace
       ├─ 3 LCL repair to humerus → 4 MCL repair if still unstable
       └─ 5 hinged ex-fix if still unstable
```

### Operative criteria

| Structure | Fix / replace when |
|---|---|
| **Radial head ORIF** | **Non-comminuted, < 40% articular** · 2-part > 30% → ORIF |
| **Radial head arthroplasty** | **Comminuted > 3 fragments** (≥ 3 involving > 25%, OB) · > 40% articular · not age > 40, sagittal fracture, PIN palsy |
| **Radial head excision** | **Never** with instability / Essex-Lopresti · fragment excision only if < 25%, non-articulating, stable |
| **Coronoid** | Type III / large base (see above) |
| **MCL** | **Instability after LCL + fractures**, esp. **extension beyond 30°** · PMRI with type I / II coronoid |

### Standard fixation — radial head fixation / replacement, coronoid ORIF & LCL repair

**Standard (comminuted head + coronoid)** — **radial head arthroplasty + coronoid ORIF + LCL / LUCL repair** (McKee: 34 / 36 stable)\
✗ Wrong options: closed + early ROM · radial head resection · hinged brace · static ex-fix 6 wk · MCL routinely · ulnar nerve transposition

**LUCL** — **repair to the humerus** (avulsed from origin)\
✗ Wrong options: reconstruction acutely · repair to ulna · TEA

**Radial head ORIF** — 1.5 / 2.0 / 2.4 mm countersunk screws · plate **posterolateral, safe zone 90–110°** (styloid → Lister's) · 2.0 plate on neck → little motion loss

**Radial head implant** — articulate **2 mm distal to coronoid tip** · **avoid overstuffing** · undersizing → valgus instability

**Coronoid fixation** — through radial head defect · sutures via 2 drill holes ("lasso"), anchors · **posterior-to-anterior lag screws** if large (anterior-to-posterior, TO) · basal → medial plate

**LCL repair** — anchors / transosseous at **centre of capitellar curvature**, elbow 90° · **MCL intact → forearm pronated** · **MCL injured → supinated** (avoid medial gapping)

**Posterior skin incision** — reaches medial + lateral, fewer cutaneous nerve injuries, cosmetic

**Elbow stable after triad — single most important for rotatory stability** — **LCL complex repair / reconstruction**\
✗ Wrong options: radial head replacement / ORIF · capsular plication · MCL

### Persistent instability after lateral repair — MCL repair

**Still unstable after coronoid + radial head + LCL** — **repair MCL**\
✗ Wrong options: larger radial head (overstuffing) · resect head · cast 6–8 wk · reinforce LCL · Steinmann pin · ex-fix before MCL

**Residual posterolateral instability after fracture fixation alone** — **repair LCL complex**\
✗ Wrong options: MCL first · cast / brace · ex-fix

**Type I coronoid, unstable with valgus after head ORIF + LCL** — **MCL repair**\
✗ Wrong options: coronoid ORIF · convert to arthroplasty · splint

**Posteromedial subluxation after head + LCL, tip fracture** — **MCL via medial approach, protect MABCN (medial antebrachial cutaneous nerve)**\
✗ Wrong options: coronoid through lateral · medial brachial cutaneous · musculocutaneous

**Hinged ex-fix** — **last step**, after MCL

### Postoperative splinting position

| Repaired | Splint / passive motion |
|---|---|
| **LCL only (MCL intact)** | **Flexion + pronation** — pronation tightens MCL sling |
| MCL | Supination |
| **Both** | **Flexion + neutral** |

**Rehab** — **active ROM at 48 h** (dynamic stabilisers) · may block last 30° of extension early · prolonged immobilisation → poor results

## 6 Complications

### Complications — stiffness

| Complication | Fact |
|---|---|
| **Post-traumatic stiffness** | **Most common** complication · **commonest needing reoperation** · prevent with early ROM |
| **Instability** | Commoner after **type I / II coronoid** not fixed · "most commonly persistent instability" (OB) — read the options |
| Fixation failure | **Radial neck** ORIF (poor vascularity → AVN, nonunion) |
| **HO** | Common; doesn't always need surgery · prophylaxis with **head injury / revision** |
| PTOA | Chondral damage, residual instability |
| PIN injury | Lateral approach — stay proximal to annular ligament, pronate, release supinator posteriorly |

**Prognosis** — historically poor: **persistent instability, stiffness, arthrosis**; good with stable fixation + early motion

## X vs Y

| | **PLRI (terrible triad)** | **PMRI** |
|---|---|---|
| Force | **Valgus**, supination | **Varus** |
| Coronoid | **Tip** | **Anteromedial facet** |
| Radial head | **Fractured** | Usually intact |
| Key repair | **LCL** | Coronoid buttress (medial) + LCL |

| | **LCL repair, MCL intact** | **MCL also injured** |
|---|---|---|
| Forearm during LCL repair | **Pronation** | **Supination** |
| Splint | **Flexion + pronation** | Neutral (both repaired) |

## How it's asked

**"Not part of terrible triad (TO)?"** → **olecranon fracture**

**"Not part of terrible triad, biceps option (TO)?"** → **biceps tendon tear**

**"Valgus + axial + posterolateral force (supinated)?"** → **coronoid + radial head fracture + dislocation**

**"Sequence of injury?"** → **LCL → anterior capsule → MCL**

**"Terrible triad EXCEPT (TO)?"** → **LCL tear uncommon due to valgus**

**"PLRI radiograph?"** → **terrible triad (radial head + coronoid tip)**

**"Coronoid > 50%, comminuted head?"** → **arthroplasty + coronoid ORIF + LCL repair**

**"Comminuted head + basal coronoid, 62-yr?"** → **head replacement + coronoid ORIF + LUCL ± MCL**

**"What decides ulna (coronoid) fixation?"** → **fragment size + stability after head replacement**

**"Restore stability in most cases?"** → **head fixation / replacement + coronoid fixation + LUCL repair**

**"Type II coronoid, nonreconstructable head?"** → **arthroplasty + coronoid ORIF + LCL repair**

**"Arthroplasty indication?"** → **> 3 fragments**

**"Unstable in valgus at 40° (comminuted head)?"** → **replacement + coronoid ORIF + LUCL repair**

**"Comminuted head in triad?"** → **radial head arthroplasty**

**"Where to repair LUCL?"** → **to the humerus**

**"Still unstable after full lateral repair?"** → **repair MCL**

**"Residual posterolateral instability < 35°?"** → **repair LCL complex**

**"Type I coronoid, valgus instability after head + LCL?"** → **MCL repair**

**"Unstable 0–20° after full repair?"** → **repair medial UCL**

**"Posteromedial subluxation — next step + nerve?"** → **MCL via medial approach, protect MABCN**

**"Most rotatory stability?"** → **LCL complex repair**

**"Late instability pushing from chair?"** → **LUCL**

**"Repair type I coronoid — rationale (TO)?"** → **anterior buttress + capsule insertion vs posterior subluxation**

**"Anterior MCL bundle inserts?"** → **anteromedial (sublime tubercle) coronoid**

**"Isolated coronoid — approach muscle nerve?"** → **ulnar (FCU split)**

**"Cadaver — > 50% coronoid?"** → **↑ posterior axial displacement at 30°**

**"Coronoid needing fixation?"** → **Regan-Morrey type III**

**"Splint if MCL intact?"** → **flexion + pronation**

**"Commonest complication requiring reoperation?"** → **loss of motion**

**"Most common complication?"** → **post-traumatic stiffness**
