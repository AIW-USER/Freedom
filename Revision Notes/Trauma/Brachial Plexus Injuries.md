# Brachial Plexus Injuries

*Trauma · 5 / 67*

## 1 Basics

### Epidemiology

| Traumatic BPI pattern | Share |
|---|---|
| **Complete (all roots, supraclavicular)** | **75–80%** — commonest |
| **C5–C6 upper trunk (Erb)** | **20–25%** |
| **C8–T1 (Klumpke)** | **0.6–3%** |

**Cause** — **high-speed vehicle, mostly motorcycle (83%)**

**Spectrum** — traumatic · obstetric (Erb, Klumpke) · burners / stingers · Parsonage-Turner

### Plexus anatomy – cord / trunk innervation & lesion localisation

![Brachial plexus motor and sensory innervation](../../Orthobullets/attachments/ob1008-brachial-plexus-fixed.jpg)

| Level | Branches |
|---|---|
| **Roots** | **Dorsal scapular (rhomboids, C5)** · **long thoracic (serratus anterior, C5–7)** · phrenic contribution (C3–5) |
| **Upper trunk (C5–6)** | **Suprascapular (SS, IS)** · nerve to subclavius |
| **Lateral cord** | **Musculocutaneous** · **lateral root of median** (FCR, PT) · lateral pectoral (clavicular pec major) |
| **Medial cord** | Medial pectoral · medial brachial + antebrachial cutaneous · **ulnar** · medial root of median |
| **Posterior cord** | **Upper + lower subscapular** (subscapularis, teres major) · **thoracodorsal (latissimus)** · **axillary (deltoid, teres minor)** · **radial** (triceps, BR, wrist + finger extensors) |

**Erb's point (TO)** — **C5 + C6 roots + suprascapular nerve + nerve to subclavius** converge\
✗ Wrong options: **long thoracic** (does not meet there)

**Upper trunk lesion (tackle / stinger)** — **axillary + musculocutaneous + suprascapular** deficits: lateral shoulder + radial forearm numbness, weak abduction, ER, elbow flexion, ↓ biceps reflex → **normal 2nd + 5th finger abduction** (ulnar, inferior trunk)\
✗ Wrong options: C4 · middle trunk · lateral cord · axillary nerve

**Posterior cord lesion** — spares **supraspinatus** (suprascapular, upper trunk) (EXCEPT answer) · clavicle fragment on posterior cord → radial numbness + weak abduction, IR, wrist extension

**Subscapularis** — upper subscapular nerve consistently from **posterior cord** (lower subscapular variably from axillary)\
✗ Wrong options: biceps = lateral cord · pec major = medial + lateral · rhomboid = C5 root · supraspinatus = upper trunk

**Axillary nerve path (quadrilateral space syndrome)** — **C5–6 → upper trunk → posterior division → posterior cord**\
✗ Wrong options: C5–7 / lateral cord = musculocutaneous · C5–6 / upper trunk = suprascapular · C5–7 roots = long thoracic · C8–T1 / medial cord = ulnar

**Cord-level lesion (TO)** — **Tinel in infraclavicular fossa**; long thoracic, suprascapular, pectoral spared

| Cord lesion (TO) | Deficit |
|---|---|
| **Lateral** | Musculocutaneous (biceps), lateral median (FCR, PT), lateral pectoral; **small anterolateral forearm sensory zone**; **GH subluxation** |
| **Posterior** | Subscapular, thoracodorsal, axillary, radial → can't IR, elevate, extend; sensory loss over deltoid |
| **Medial** | Combined ulnar + median (except FCR, PT) + medial arm / hand sensory loss |

**Can't flex fingers + no ulnar-side sensation (TO)** — **C8**

### Root values (TO)

| Root (TO) | Key motor | Key sensory |
|---|---|---|
| **C5** | Shoulder abduction, ER | Skin over deltoid |
| **C5–C6** | Shoulder abduction, **elbow flexion**, supination | — |
| **C6** | — | **Thumb + index** |
| **C7** | **Elbow + wrist extension** (not specific to one muscle) | **Middle finger** |
| **C8–T1** | **Finger flexion, hand intrinsics** | C8 ring + little; T1 medial forearm |
| T2 | — | Medial arm |
| **C5–T1** | **Flail limb** | — |

## 2 Mechanism

**Caudally forced shoulder / head to opposite side** — **upper plexus** (high energy → all roots)

**Forced abduction (clutching while falling)** — **lower roots (C8–T1)**

## 3 Presentation

**Horner syndrome** — **ptosis, miosis, anhidrosis**; appears **\~3 days** after injury → **C8 / T1 root avulsion** (sympathetic chain)

**Severe pain in anaesthetic limb** — **root avulsion**

**Serratus anterior + rhomboids working** — C5 injury more likely **postganglionic**

**Pulses** — check; arterial injury common with complete BPI

### Upper vs lower vs total palsy

| | **Erb (C5–6)** | **Klumpke (C8–T1)** | **Total (C5–T1)** |
|---|---|---|---|
| Cause | Head to opposite side + shoulder depression; difficult delivery; fall on shoulder | **Excess abduction** (falling, clutching); cervical rib, lung mets | High energy |
| Posture | **"Waiter's tip"**: **adducted + IR shoulder, extended elbow, pronated forearm**, flexed wrist | **Claw hand**: wrist extended, MCP hyperextended, IP flexed | **Flaccid arm** |
| Nerves | C5 → axillary, suprascapular, musculocutaneous · C6 → radial (BR, supinator) | Ulnar + median (all intrinsics) | All |
| Extras | C7 also in **50%** (TO) | **Preganglionic + Horner** | — |
| Prognosis | **Best** | **Poor** | **Worst** |

**Erb (TO)** — weak deltoid, biceps, brachialis, SS, IS, serratus, rhomboids, levator scapulae, supinator; sensory loss lateral arm / forearm / radial hand

## 4 Diagnosis & Classification

### Pre- vs post-ganglionic lesions

| | **Preganglionic (avulsion, proximal to DRG)** | **Postganglionic** |
|---|---|---|
| Regeneration | **CNS — none** → **worst prognosis** | PNS — can regenerate |
| **Horner** | **Yes** | No |
| **Scapular winging** | **Medial winging** (serratus) · rhomboid palsy → lateral winging | No |
| Hemidiaphragm | **Elevated** (phrenic) | Normal |
| Tinel in neck | **Absent** | Present; **advancing Tinel** = regeneration |
| **SNAP** | **Normal / intact** (DRG cell body intact) despite anaesthesia | **Absent** |
| Motor NCV | Absent | Absent |
| **EMG paraspinals** | **Denervated** | **Normal** |
| **Histamine test** | **Normal triple response** (red, wheal, **flare**) | **Abnormal — no flare** |
| CT myelogram | **Pseudomeningocele** (> 95% predictive) | Roots intact |
| Wallerian degeneration of sensory fibres | **No** | Yes |
| Flail arm | **Yes** | **Yes** (both) |

**SNAP normal + insensate ulnar zone** → **preganglionic C8–T1** · **SNAP normal + insensate median zone** → **preganglionic C5–C6**

**TO NOT-seen trap (TO)** — preganglionic shows **absent motor but intact sensory conduction** → **"absent sensory conduction" is NOT seen** · if both absent → postganglionic

**C8–T1 avulsion vs plexus injury** — **ptosis (Horner)**\
✗ Wrong options: weak radial pulse · SSSC double break · elevated hemidiaphragm = C5 · musculocutaneous deficit

**Child, fall clutching ladder, Horner + hand weakness** — **root level (preganglionic)**

**Paraspinals normal on EMG** — **postganglionic**\
✗ Wrong options: avulsion · Horner · normal histamine

**Postganglionic injury spares** — **rhomboid major** (dorsal scapular from root)\
✗ Wrong options: ECRL, biceps, deltoid, BR

**Most suggestive of postganglionic** — **advancing Tinel in supraclavicular region**\
✗ Wrong options: rhomboid / serratus involved · pseudomeningocele · diaphragm palsy · Horner

### Key radiology findings

| Study | Finding / use |
|---|---|
| **CXR (PA + lat)** | **1st / 2nd rib fracture** → plexus injury · old rib fractures matter for **intercostal transfer** · inspiration / expiration → **paralysed diaphragm** (upper root) |
| **C-spine AP + lateral** | **Transverse process fracture** → root avulsion |
| Scapula / shoulder (AP + axillary) | **Scapulothoracic dissociation** → root avulsion + major vascular injury |
| Clavicle | Fracture may signal BPI |
| **CT myelography** | **Gold standard for root level**; avulsion → **meningocele**; do at **3–4 wk** (clot dissipates, meningocele forms) |
| **MRI** | Lesions **distal to roots**; **pseudomeningocele (T2)**, **empty root sleeves (T1)**, **cord shift away from midline (T1)**, neuromas |

### Electrodiagnostics

| Test | Fact |
|---|---|
| **EMG** | Fibrillations **10–14 d** proximal muscles, **3–6 wk** distal; test **rhomboids, serratus, cervical paraspinals** for pre vs post |
| **NCV / SNAP** | SNAP **preserved proximal to DRG** → preganglionic |
| **NAP (intra-op)** | Across lesion; detects reinnervation **months before EMG**; NAP negative = **neurapraxic** · NAP positive = **axonotmetic** (Orthobullets wording) |
| **SSEP / MEP** | More sensitive than EMG / NCV for root–cord continuity; at **4–6 wk** (Wallerian); stimulate **Erb's point**, record scalp |

## 5 Management

```
Traumatic brachial plexus injury
├─ Sharp / open / iatrogenic / vascular / expanding haematoma → explore < 1 wk
├─ Near-total, high energy (avulsion likely) → early surgery 3–6 wk
└─ Partial upper plexus, low energy / GSW → observe
       └─ plateau at 3–6 mo → delayed surgery (not > 6 mo)
```

### Operative criteria (timing)

| Timing | Indication |
|---|---|
| **Immediate (< 1 wk)** | **Sharp penetrating** (not GSW), iatrogenic, open, progressive deficit, **vascular injury / expanding haematoma** |
| **Early (3–6 wk)** | **Near-total plexus, high energy** · preganglionic → explore + reconstruct **within 6 wk** (OB) |
| **Delayed (3–6 mo)** | **Partial upper plexus, low energy**, plateaued recovery · postganglionic: wait 6 wk–6 mo |
| **Observe** | Most; **GSW** without vascular injury → **3 months** |

**Motor end-plate deadline** — irreversible loss **\~1 yr** (OB) · **20–24 months** (another OB explanation) → nerve transfer > 20–24 mo relatively contraindicated → **free functioning muscle transfer** — read the options

**Best clinical sign of regeneration** — **advancing Tinel**

### Techniques

| Technique | Fact |
|---|---|
| **Direct repair** | Rare — acute sharp injuries only |
| **Nerve graft** | Common for **postganglionic traction**; upper + middle trunk best; donors **sural**, medial brachial cutaneous, MABC; **vascularised ulnar** (superior ulnar collateral a.) if C8–T1 avulsed |
| **Neurotisation (nerve transfer)** | Expendable motor nerve → important denervated muscle; **reduces high injury to low injury**, faster reinnervation |
| Extraplexal donors | **Spinal accessory (CN XI)**, **intercostals**, **contralateral C7**, hypoglossal (CN XII) |
| Intraplexal donors | Phrenic, median / ulnar fascicles, pectoral |
| **Muscle / tendon transfer** | **Isolated adult C8–T1** (too far to reinnervate intrinsics) · late presentation · **gracilis** = commonest free muscle |

### Nerve transfers (Oberlin, intercostal)

**Oberlin / double fascicular transfer** — **ulnar fascicle → biceps branch** + **median fascicle → brachialis branch** → elbow flexion

**Indication** — **acute (< 3–6 mo) C5–C6 avulsion / upper trunk** · restores **musculocutaneous (lateral cord)** function\
✗ Wrong options: C8–T1 avulsion (ulnar dead) · 22 mo old palsy · medial + posterior cord GSW · C6 ASIA A

**Other C5–6 options** — **SA → suprascapular** · SA or intercostal → musculocutaneous

**Pan-plexus avulsion (C5–T1, pseudomeningoceles)** — ulnar / median useless → **intercostal → musculocutaneous**: donor is **expendable + functional**\
✗ Wrong options: near end plate · synergistic · near sensory target · pure motor (intercostals carry sensation)

**Contralateral C7 (TO)** — harvested in total palsy with minimal donor deficit

### Reconstruction priorities

| Priority | Nerve |
|---|---|
| **1 Elbow flexion** | **Musculocutaneous** |
| **2 Shoulder stability / abduction** | **Suprascapular** |
| 3 Brachial–thoracic pinch | Pectoral |
| 4 C6–C7 sensation | Lateral cord |
| 5 Wrist extension / finger flexion | Lateral + posterior cords |
| 6 Wrist flexion / finger extension | — |
| 7 Intrinsics | — |

**Least important (TO)** — **elbow extension**\
✗ Wrong options: shoulder abduction · elbow flexion · medial-hand sensation

**Medial-hand sensation (TO)** — restore to prevent ulcers, burns, self-mutilation → median fascicles → ulnar sensory / dorsal ulnar branch; LABC → dorsal ulnar via 15 cm sural graft

### Obstetric brachial plexus palsy

**Erb** — **commonest obstetric palsy** (1:1000) + **best prognosis** → **shoulder IR + forearm pronation** (adducted, elbow extended, wrist flexed)

**Good prognosis** — **biceps return before 3 months** + **full passive shoulder ROM**\
✗ Wrong options: breech (preganglionic) · no clavicle fracture · Horner · absent Moro

**Poor signs** — **breech** (preganglionic), **Horner**, **absent Moro**

### Deafferentation pain after plexus injury (TO)

**Stem (TO)** — severe chronic whole-limb pain weeks after BPI → options: baclofen pump, duroplasty, dorsal nerve ablation, **DREZ (dorsal root entry zone) procedure** — **answer key not provided by the source**

## 6 Complications

**Prognosis** — recovery up to **3 yr**; regeneration **1 mm/day**

**Better** — **infraclavicular > supraclavicular** · **upper plexus** (hand preserved) · postganglionic

**Worst** — **root avulsion (preganglionic)**: not repairable → arthrodesis, tendon transfer

## X vs Y

| | **Oberlin transfer** | **Intercostal → MC** |
|---|---|---|
| Use | **Upper trunk (C5–6)**, ulnar + median working | **Pan-plexus avulsion** |
| Donor | Intraplexal, synergistic, near target | Extraplexal, expendable, distant |

| | **NAP negative** | **NAP positive** |
|---|---|---|
| Lesion | Neurapraxic (Orthobullets) | Axonotmetic / regenerating |

## How it's asked

**"Nerve that does NOT meet at Erb's point?"** → **long thoracic** (TO)

**"Can't flex fingers, ulnar-side numbness — root?"** → **C8** (TO)

**"Infraclavicular Tinel, anterolateral forearm numbness, GH subluxation?"** → **lateral cord** (TO)

**"Posterior cord transection spares?"** → **supraspinatus**

**"Superior trunk injury — what stays normal?"** → **2nd + 5th finger abduction**

**"Tackle: lateral shoulder + radial forearm numbness, weak abduction / ER / elbow flexion?"** → **upper trunk**

**"Muscle innervated by posterior cord?"** → **subscapularis**

**"Quadrilateral space nerve pathway?"** → **C5–6, upper trunk, posterior division, posterior cord**

**"Clavicle fragment, radial numbness, weak abduction + IR + wrist extension?"** → **posterior cord**

**"NOT seen in preganglionic palsy?"** → **absent sensory conduction** (TO)

**"Supports preganglionic injury?"** → **intact SNAPs**\
✗ Wrong options: abnormal histamine · flail arm · intact roots on myelogram · normal paraspinals

**"Normal paraspinal EMG means?"** → **postganglionic**

**"Postganglionic — muscle NOT paralysed?"** → **rhomboid major**

**"Suggests C8–T1 root avulsion?"** → **eyelid droop (Horner)**

**"Most suggestive of postganglionic?"** → **advancing Tinel**

**"Gold standard for root level?"** → **CT myelography at 3–4 wk**

**"Ulnar → biceps + median → brachialis transfer indication?"** → **C5–6 avulsion 2 months ago**

**"Ulnar / median fascicle transfers treat injury to?"** → **lateral cord**

**"Intercostal → MC in pan-plexus avulsion — principle?"** → **expendable, functional donor**

**"Least important to reconstruct?"** → **elbow extension** (TO)

**"Top reconstruction priority?"** → **elbow flexion (musculocutaneous)**

**"Commonest obstetric palsy — posture?"** → **shoulder IR + forearm pronation**

**"Obstetric palsy — good prognosis?"** → **biceps return before 3 mo + full passive shoulder ROM**

**"GSW plexus injury without vascular injury?"** → **observe 3 months**

**"Sharp penetrating plexus injury?"** → **explore < 1 week**

**"Isolated adult C8–T1?"** → **tendon / muscle transfer**
