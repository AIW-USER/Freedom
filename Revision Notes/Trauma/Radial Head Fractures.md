# Radial Head Fractures

*Trauma · 50 / 67*

## 1 Basics

### Epidemiology

**Incidence** — 1–4% of adult fractures · **20–30% of elbow fractures (commonest)** · mean age \~45 (85% 30–60) · **F:M 3:2**

**Mechanism** — **FOOSH with elbow extended + forearm pronated**

**Associated (30%)** — **LCL injury (commonest, up to 80% on MRI)**, MCL, **Essex-Lopresti**, coronoid, olecranon, **Monteggia**, **terrible triad**, **scaphoid**

### Anatomy

**Head** — **15° offset** from neck · **anterolateral third lacks subchondral bone** (fractures here) · 40° concave dish

**Safe zone (non-articular)** — **90–110° arc between radial styloid + Lister's tubercle** (straight lateral in neutral) · \~25% of head doesn't articulate with ulna

**Radiocapitellar joint** — **60% of elbow load**

| Ligament | Role |
|---|---|
| **LUCL** (supinator crest) | **Varus + ER (hypersupination)**; deficiency → **PLRI** |
| RCL | Into annular ligament |
| **Annular** | Holds head to lesser sigmoid notch; interposition → irreducible |
| **MCL anterior bundle** | **Primary valgus stabiliser** (radial head 2nd) |

**Radial head roles** — **secondary valgus restraint** (key if MCL deficient) · **longitudinal stability** (with IOM + DRUJ)

### Longitudinal instability (Essex-Lopresti) — radial head as buttress, excision contraindicated

**Essex-Lopresti** — **radial head fracture + IOM disruption + DRUJ injury** → proximal radial migration, ulnocarpal impaction\
✗ Wrong options: distal radius fracture

**Single best answer (TO)** — **interosseous membrane injury**; IOM gives **> 70% axial stability** (TO)

**Primary buttress against proximal migration** — **radial head** (then IOM) (OB) — read the options · TFCC (triangular fibrocartilage complex) also maintains length

**Excision in Essex-Lopresti (TO)** — if ever, delay **3 weeks** (IOM heals)

**Clues** — **wrist / DRUJ tenderness**, ballottement +, ulnar styloid base fracture, **radius pull test > 3 mm** (intra-op), DRUJ translation > 50% vs other side

**Late presentation** — only **20% satisfactory** vs 80% if acute

![Essex-Lopresti lesion](../../Orthobullets/attachments/ob1019-essex-lopresti-lesion.jpg)

**Load share (TO)** — **\~75–80%** of wrist axial load crosses the radiocarpal joint → IOM transfers it to the ulna · secondary stabilisers = **IOM central band** + TFCC / DRUJ

**IOM (TO)** — **5 bands**; **central band** most important, runs at **\~20–25°** (angle used for reconstruction, PL or gracilis graft — rarely done)

**Recognise early (TO)** — radial head + forearm tenderness, DRUJ tenderness / instability → **X-ray elbow AND wrist**; **ultrasound** can show IOM tear · missed → painful loss of pronation / supination

**Pull test < 3 mm (TO)** — excision alone acceptable · **≥ 3 mm → radial head replacement**

**DRUJ after head fixation / replacement (TO)** — unstable → **above-elbow slab in supination**, **DRUJ pinning**, or **TFCC repair**

**Neglected Essex-Lopresti (TO)** — salvage **single-bone forearm** (proximal ulna to distal radius, DCP) → pain relief, no rotation · position **slightly more pronated than mid-prone**

## 3 Presentation

**Exam** — lateral tenderness; **mechanical block to motion** (normal flexion 0–150°, pronation 75°, supination 85°) → **aspirate haematoma + intra-articular lidocaine** · PIN + ulnar nerve · pivot shift / posterolateral drawer (LUCL), valgus stress (MCL) · **palpate wrist + IOM**

**Pain limits exam at 1 wk** — **intra-articular lidocaine + re-examine**\
✗ Wrong options: CT · MRI · splint 2–3 wk · EUA

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| AP + lateral elbow, **forearm + wrist** | — |
| **Radiocapitellar (Greenspan)** | Oblique lateral, **45° cephalad** → head without coronoid overlap |
| **Fat pads** | Haemarthrosis; **posterior fat pad more sensitive** |
| CT | Comminution, fracture-dislocations (3D planning) |
| MRI | Ligaments; rarely changes management |
| Dynamic CT | Subtle DRUJ instability |

### Mason classification (Hotchkiss / Broberg-Morrey)

| Type | Description |
|---|---|
| **I** | **< 2 mm**, **no block** |
| **II** | **> 2 mm** / angulated, **possible block** |
| **III** | **Comminuted**, displaced, **block** |
| **IV** | **+ elbow dislocation** |

![Mason classification](../../Orthobullets/attachments/ob1019-mason-classification.jpg)

**OTA 2R1** — A extra-articular · B partial articular · C complete articular · high interobserver variability

## 5 Management

```
Radial head fracture
├─ No block (Mason I / II) → sling 2–7 d + early ROM
├─ Block / displaced, ≤ 3 fragments, young → ORIF (headless screws ± plate in safe zone)
├─ > 3 fragments / dislocation / Essex-Lopresti / unstable → radial head arthroplasty (+ LCL repair)
└─ Low-demand, no instability → fragment excision (< 25–30%) or resection (never if unstable)
```

### Nonoperative vs ORIF — mechanical block & lidocaine test

**Mason I (violinist, no block)** — **sling \~2 days → active motion** · good **85–95%** · Mason II without block: early failure up to **12%**\
✗ Wrong options: cast ≥ 1 wk (worse function)

**Displaced partial articular + block (20–30° / 45–65° arcs)** — **ORIF** via **ECU / anconeus (Kocher)** with plate or screws\
✗ Wrong options: excision > 30% · medial approach · arthroplasty (older / ≥ 3 fragments)

**Mason II on CT, young** — **ORIF**\
✗ Wrong options: cast · excision (< 25%) · CRPP (none in adults) · replacement

**Correct pairing** — **38-yr Mason II, 40° arc → ORIF**\
✗ Wrong options: 4-part young → arthroplasty · resection in young Mason III · arthroplasty for minimally comminuted 3-part · excision with ulnar styloid / DRUJ injury

### Operative criteria

| Treatment | Indication |
|---|---|
| **Nonop** | Mason I; Mason II **without block** |
| **ORIF** | **Mason II with block**; Mason III / IV if feasible (**≤ 3 fragments**); open; complex elbow injury |
| **Arthroplasty** | **> 3 fragments** (≥ 3, OB), fracture-dislocation (> 30% articular), **Essex-Lopresti**, terrible triad, plastic deformity, malunion / nonunion |
| **Fragment excision** | Low demand, no instability, fragment **< 25%** (Orthobullets) · **< 30%** (OB) |
| **Resection** | Sedentary, **delayed isolated** fracture, salvage · not with **IOM injury (pull > 3 mm)**, coronoid fracture, MCL deficiency |

**ORIF outcomes** — **> 3 fragments → > 50% unsatisfactory** · isolated vs complex similar at 4 yr · fixation fails more than arthroplasty if elbow unstable

### Surgical approach & safe zone (PIN, forearm rotation, LUCL)

| Approach | Interval | Pros / cons |
|---|---|---|
| **Kocher** | **ECU (PIN) / anconeus (radial)** | **Less PIN risk**, extensile · **LUCL risk** if capsulotomy too posterior (stay anterior to crista supinatoris) |
| **Kaplan** | **EDC (PIN) / ECRB (radial)** | **Protects LUCL**, anterior fragment access · **more PIN risk** |
| EDC split | Through EDC | Anterior half, LCL spared |
| Posterior | Lateral flap | With olecranon / Monteggia |

**TO approach intervals** — written as **Kocher = ECRB–anconeus** and **Kaplan = ECRL–ECRB** (TO elbow-injuries lecture — verify: standard Kocher = **anconeus–ECU**, Kaplan = **ECRB–EDC**, as in the table above) · avoid deep retraction near annular ligament (PIN) · isolated low-energy comminution → excision (TO)

**Approach** — **forearm pronated** (moves **PIN** anterior) · PIN crosses radius in supinator **\~4 cm distal** to head

**Plate application** — **forearm NEUTRAL → plate straight lateral** in safe zone · TO answer: "**just posterior to mid-axial line with forearm in pronation**" — read the options\
✗ Wrong options: pronation / supination

**Limits** — **within 90° arc (styloid–Lister's)** · **not distal to bicipital tuberosity (PIN)** · countersink articular implants

**Fixation** — headless / 2.0–2.4 mm screws (simple partial articular; **better ROM than plates**) · 1.5–2.0 mm plates for head + neck · plate removal common

**Least LUCL risk for arthroplasty** — **Kaplan (EDC / ECRB)**\
✗ Wrong options: Kocher (anconeus / ECU)

**Head-neck fracture past bicipital tuberosity + PIN palsy (GSW)** — **Kaplan + ORIF in safe zone** (neurolysis possible)

### Radial head arthroplasty — indications & sizing (overstuffing)

**4-fragment + dislocation** — **arthroplasty**\
✗ Wrong options: excision · ORIF · splint · hinged ex-fix

**Comminuted + dislocation** — **arthroplasty + LCL repair**\
✗ Wrong options: ORIF + LCL · excision

**Osteoporotic 65-yr comminuted** — **metallic anatomic arthroplasty**\
✗ Wrong options: excision (wrist pain, instability, migration)

**Best indication** — **Mason III + IOM injury**

**Implants** — **loose-stem (spacer)**, press-fit, **bipolar** (may destabilise), **monoblock vs modular**, pyrocarbon (investigational) · **silicone abandoned** (fracture, synovitis)

**Overstuffing** — **> 2.5 mm** alters kinematics → pain, stiffness, **capitellar erosion** · **detect: visual widening of LATERAL ulnohumeral joint** → **remove + downsize**\
✗ Wrong options: medial on AP (only after 6 mm)

**Height** — proximal implant at **proximal lesser sigmoid notch**; **dish at level of lateral coronoid facet** · TO coronoid question: answer key not provided by the source

### Terrible triad & complex instability

**Terrible triad** — **elbow dislocation + radial head + coronoid fractures**

**Treatment** — **coronoid ORIF + radial head ORIF / arthroplasty + LUCL repair** → MCL repair ± hinged ex-fix if still unstable\
✗ Wrong options: **radial head excision — never** · transarticular screw · coronoid excision

**Most common complication** — **restricted motion (stiffness)**\
✗ Wrong options: redislocation · PIN · infection

**Distal humerus partial articular + radial head (23-yr)** — **ORIF both** (headless screws)

## 6 Complications

| Complication | Fact |
|---|---|
| **Stiffness** | 3–20%; **supination loss commonest**; functional arc **30–130° + 50 / 50 rotation** |
| PIN injury | Distal to bicipital tuberosity, retraction → splint, EMG later, transfers |
| Secondary displacement | **< 5%** of nonop |
| Nonunion / malunion | Common, often asymptomatic |
| Radiocapitellar OA | Common radiographically; overstuffing |
| **HO** | CNS injury, burns → indomethacin 6 wk; excise when mature (\~10% recur) |
| Resection sequelae | **Proximal migration, cubitus valgus, wrist pain, OA 73%** |

### Late sequelae — malunion & post-traumatic stiffness

**Malunited comminuted head 4 yr, stable DRUJ + elbow** — **radial head resection**\
✗ Wrong options: ligament reconstruction · ORIF · debridement · TEA

**Stiff 4 months after minimally displaced fracture** — **static / dynamic progressive splinting**\
✗ Wrong options: steroid · MUA (worsens) · home program · CPM

**8 months, arc 50–85°, ulnar paraesthesia, healed** — **anterior + posterior capsular release + ulnar nerve transposition**\
✗ Wrong options: head resection · partial release · injection

**60-yr, 1 yr after fracture, near-normal motion, intermittent pain (TO)** — answer key not provided by the source

### Paediatric radial neck — acceptable angulation

**10-yr-old (TO)** — **< 30° angulation + < 2 mm translation** (2–3 mm) → cast only; more → closed reduction (Israeli / Kaufman, Patterson, Neher-Torch), Metaizeau, joystick
