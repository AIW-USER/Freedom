# Calcaneus Fractures

*Trauma · 6 / 67*

## 1 Basics

### Epidemiology

**Commonest tarsal fracture** — \~65% of tarsal fractures (OB)

**Intra-articular** — **60–75%** (Orthobullets) · **75%** (OB) · tuberosity fractures **1–3%** · avulsion + tongue-type **< 15%**

**Open** — **17%** (15–20%) → no ↑ infection, ↑ wound complications

**Tuberosity fractures** — peak in **women, 7th decade**

### Associated injuries

| Association | Rate |
|---|---|
| **Calcaneocuboid joint extension** | **63%** |
| **Vertebral fracture** | **10%** |
| **Contralateral calcaneus** | **10%** |
| **Peroneal tendon instability (SPR tear)** | **\~20%** — **commonest acute concurrent pathology** |
| **Foot compartment syndrome** | **10%** (Orthobullets) · **3–10%** (TO) |

### Fracture anatomy – constant fragment, sustentaculum & FHL

**Facets** — **posterior = largest, main weight-bearing** · **middle on sustentaculum (anteromedial)** · anterior often confluent with middle · **sinus tarsi** = calcaneal interosseous sulcus + talar sulcus

**Constant (superomedial / sustentacular) fragment** — **sustentaculum tali**; stays attached to talus by **interosseous + medial talocalcaneal ligaments** (+ deltoid); lateral fragments + tuberosity are reduced **to it**\
✗ Wrong options: held by Achilles · by navicular · displaces superolateral

**FHL** — wraps **inferiorly around sustentaculum** in a groove · **medial to posterior facet, inferior to middle facet**; origin **inferior ⅔ posterior fibula + interosseous membrane**

| FHL problem | Cause | Sign |
|---|---|---|
| **Iatrogenic** | **Lateral → medial drill / screws too long** into constant fragment | **Fixed flexed hallux** post-op |
| **Stenosis / tear** | **Sustentaculum tali fracture** | **Pain / popping with great-toe flexion** |
| **Entrapment** | **Marked posterior facet displacement** | **Limited hallux motion** |

**✗ FHL traps** — beak / tuberosity (Achilles) · lateral wall · FDL runs **superior** to sustentaculum (lesser-toe flexion) · plantar paraesthesia = medial plantar nerve · spring ligament

**Bifurcate ligament** — dorsal **anterior process → cuboid + navicular**; resists **plantarflexion–inversion**; EDB also originates there

### Blood supply

**Extensile lateral flap** — **lateral calcaneal branch of peroneal artery** (± lateral malleolar + lateral tarsal)\
✗ Wrong options: branch of ATA · lateral malleolar a.

**Heel pad** — **medial calcaneal branch of posterior tibial artery**\
✗ Wrong options: lateral calcaneal · sinus tarsi a. · tarsal canal a. (those feed talus)

## 2 Mechanism

**Intra-articular** — **axial load** (fall from height, MVC)

**Primary fracture line** — **oblique shear** → **superomedial (constant) + superolateral (posterior facet)** fragments · secondary line decides **tongue vs joint depression**

**Tuberosity (avulsion)** — osteoporosis + violent **triceps surae** contraction with forced dorsiflexion / knee extended · tight gastroc · neuropathy

**Anterior process** — **inversion + plantarflexion** → **bifurcate ligament avulsion**

**Stress** — ↑ activity with relative energy deficiency; runners, **military recruits**, female athlete triad, obesity, **after hip / knee arthroplasty**

## 3 Presentation

**Heel** — swollen, **shortened, widened**, apparent varus

**Posterior heel skin** — **tenting, blanching, ecchymosis** with tuberosity / tongue fractures → **urgent fixation**

**Fracture blisters** — must epithelialise before surgery · **wrinkle sign (Langer lines)** = skin ready

**Check** — compartments, nerves, pulses (severe PVD may preclude surgery), Achilles continuity, plantarflexion strength

## 4 Diagnosis & Classification

### Key radiology findings

| View / study | Use |
|---|---|
| AP, lateral, oblique foot | Standard |
| **Broden** | **Posterior facet**; ankle neutral, **\~45° IR**, beam **40, 30, 20, 10° cephalad**; intra-op reduction check |
| **Harris (axial)** | Tuberosity **widening, shortening, varus**; max dorsiflexion, beam 45° |
| AP ankle | **Lateral wall extrusion → fibular impingement** |
| **CT (2–3 mm)** | **Gold standard** · **30° semicoronal** = posterior + middle facets (Sanders) · **axial** = **CC joint** · **sagittal** = tuberosity · axial CT shows peroneal dislocation |
| MRI | **Only for stress fracture** with normal X-ray: **T2 oedema first**, later **T1 low-signal fracture line** |

| Sign / angle | Normal | Fracture |
|---|---|---|
| **Böhler angle** | **20–40°** | **↓** (posterior facet collapse) |
| **Crucial angle of Gissane** | **120–145°** | **↑** |
| **Double-density sign** | — | **Lateral portion of posterior facet** depressed / rotated \~90° into body, separated from sustentaculum → subtalar incongruity |
| Calcaneal shortening, varus tuberosity | — | Present |

**Böhler angle** — line anterior process top → posterior facet top **vs** line along superior tuberosity (lateral view)

**Gissane** — line along lateral posterior facet **vs** line anterior to calcaneal beak

![Böhler angle and crucial angle of Gissane](../../Orthobullets/attachments/ob1051-shows-bohler-and-gissane.jpg)

### Essex-Lopresti classification

| Type | Secondary line |
|---|---|
| **Tongue-type** | **Axial plane beneath facet, exiting posteriorly** — posterior facet stays attached to tuberosity → Achilles pulls fragment up |
| **Joint depression** | **Behind posterior facet** |

### Sanders classification (coronal CT, widest posterior facet)

| Type | Posterior facet | Treatment |
|---|---|---|
| **I** | **Non-displaced** (any number of lines) | **Nonop** |
| **II** | **1 line → 2 fragments** | **ORIF** |
| **III** | **2 lines → 3 fragments** | **ORIF** |
| **IV** | **> 3 lines, comminuted (≥ 4 fragments)** | **ORIF + primary subtalar arthrodesis** |

**Sanders III vs II** — **6.5× PTOA**, **4× subtalar fusion**

![Sanders classification](../../Orthobullets/attachments/ob1051-diagram-of-sanders-classification.jpg)

### Beavis classification (tuberosity)

| Type | Fracture |
|---|---|
| **1** | **Sleeve** — small cortical shell avulsed |
| **2** | **Beak** — oblique line from superior posterior facet running posteriorly |
| **3** | **Infrabursal** — from mid-tuberosity |

### Anterior process fracture types

| Type | Description |
|---|---|
| I | Non-displaced avulsion |
| II | Displaced, **no** CC joint |
| III | Displaced, **involves CC joint** |

**Extra-articular (25%)** — anterior process (bifurcate), sustentaculum, tuberosity (Achilles avulsion)

## 5 Management

```
Calcaneus fracture
├─ Tongue-type / tuberosity + skin threatened → splint 30° PF → urgent fixation
├─ Sanders I, small extra-articular, comorbid → NWB cast 10–12 wk
├─ Sanders II–III → ORIF at 10–14 d (wrinkle sign)
└─ Sanders IV → ORIF + primary subtalar fusion
```

### Operative criteria

| Nonoperative (NWB cast 10–12 wk) | Operative |
|---|---|
| **Small extra-articular < 1 cm**, Achilles intact, < 2 mm | **Displaced tongue-type > 1 cm**, **threatened skin**, open |
| **Sanders I** | **Sanders II + III**: facet **> 2–3 mm**, flattened Böhler, varus tuberosity |
| **Near-normal Böhler (20–40°)** | **Large extra-articular, > 10° varus / valgus** |
| **Anterior process < 25% CC joint** | **Anterior process > 25% CC joint** |
| **Smoker, diabetes, PVD** (avoid wound complications) | **Displaced sustentaculum** |
| Elderly low-demand tuberosity < 1 cm, skin OK | **Sanders IV → primary subtalar arthrodesis** |

**Stress fracture** — **NWB short-leg cast 6 wk** (well-padded heel) / CAM boot + NWB

**Cast technique (10–12 wk)** — mild equinus, **posterior heel window**, **weekly cast changes** (skin complications)

**Timing of ORIF** — **10–14 days** (swelling + blisters resolve, wrinkle sign) · no benefit to early surgery · **except displaced tuberosity / tongue with skin compromise → urgent**

**Goals (TO)** — **posterior facet congruity** · restore **height, width, length, Böhler angle** · **correct hindfoot varus** (TO)\
✗ Wrong options: correct **talar declination** (that's talar neck)

### Tongue-type / tuberosity fracture – urgent fixation

**Why urgent** — Achilles pulls fragment **proximal + posterior** → **posterior skin necrosis** (> 20%)\
✗ Wrong options: subtalar arthrosis · nonunion · AVN · compartment syndrome · better reduction

**Splint** — **30° plantarflexion** (max PF) to relax skin

**Fixation** — **immediate**, minimally invasive / percutaneous **lag screws posterosuperior tuberosity → inferior + distal** (perpendicular to fracture) · ORIF bone-to-bone if large · ± **gastrocnemius recession (Strayer)**

**✗ Tuberosity traps** — cast in equinus · **excise fragment + reattach Achilles** (large fragment, tension lost) · **percutaneous K-wires** (too weak vs triceps) · **extensile lateral approach** with swelling · delayed ORIF · primary arthrodesis (beak is extra-articular)

**Posterior approach (tuberosity)** — prone, midline; lag screws / tension band / Krackow through tunnels; restricted WB 6 wk + 6 wk progression

### Approaches & techniques

| Technique | Key facts |
|---|---|
| **Closed reduction + percutaneous pinning** | **Minimally displaced tongue-type**, severe PVD / soft-tissue compromise; Essex-Lopresti manoeuvre; pins out 8–10 wk; ± distracting ex-fix (tuberosity, cuboid, tibia) |
| **Extensile lateral (L-shaped)** | Vertical limb between fibula + Achilles, horizontal toward 5th MT base; full-thickness flap (**lateral calcaneal a.**); **high wound complications**; sural nerve + peroneals in flap; **bone graft adds nothing** |
| **Sinus tarsi** | **Tip of fibula → 4th MT base**, 2–4 cm; EDB up, peroneals back; sees **posterior facet, anterolateral fragment, lateral wall**; **↓ wound complications, ↓ infection, ↓ op time, better Maryland foot scores**; same Böhler restoration; **↑ radiation**; **sural nerve at greatest risk** (identify inferiorly) |
| **Arthroscopic-assisted** | Anterolateral + posterolateral portals; ↓ dissection; ↑ swelling, demanding |
| **Primary subtalar arthrodesis** | **Sanders IV**; restore height + fuse; avoids second surgery |

**Post-op (sinus tarsi)** — NWB 6–8 wk; ankle ROM from 2 wk

### Operative vs nonoperative – prognostic factors

| Better outcome with ORIF | Worse outcome with ORIF |
|---|---|
| **Female** | **Male** (men do worse with surgery) |
| **Age < 29–30** | **Age > 50** (op ≈ nonop) |
| **No workers' compensation** | **Workers' comp**, litigation |
| **Sedentary / light job** | **Heavy manual labour** |
| **Sanders II** (less comminution) | Higher Sanders, **Böhler < 0°** |
| Böhler **0–14°** (moderately flat, OB) · **> 15°** (another OB) | **Smoking**, obesity, open, **bilateral**, polytrauma, vasculopathy |
| — | **Previous calcaneus fracture** (no benefit, EXCEPT answer) |

**Most likely eventual subtalar fusion** — **male + WC + heavy labour + Böhler < 0°**

**Highest PTOA risk** — **Sanders III treated with ORIF** (articular damage drives arthritis, not sex / job)

**Best predictor of PTOA** — **initial energy / fracture severity (Sanders)** > reduction quality

**Positive prognostic factor (Sanders II, 2 fragments)** — **Sanders classification**\
✗ Wrong options: sex · age 40 · labourer job · approach

**Only undisputed op vs nonop difference** — **ORIF ↑ wound complications + reoperation** (nonop → ↓ wound complications) · function, satisfaction, walking, shoe fit **equal at 5 yr**

**Surgery reduces** — **PTOA / subtalar fusion \~6× (5.5–6×)**\
✗ Wrong options: faster RTW · ↑ subtalar ROM · ↓ nonunion (nonunion is rare)

**Sanders II, young healthy non-smoker** — **ORIF**\
✗ Wrong options: cast · fusion · percutaneous (tongue only) · ex-fix

**68-yo healthy, blisters** — **delayed ORIF** (age > 50 no longer absolute contraindication; comorbidities matter more)

### Open calcaneus fractures (TO)

**Medial wound < 4 cm, closeable, stable (TO)** — **serial I&D → standard ORIF** when swelling settles (Sanders III)\
✗ Wrong options: percutaneous · ex-fix

**Lateral wounds / medial > 4 cm / not closeable / unstable after 7–10 d (TO)** — **open reduction through wound + percutaneous fixation**

**Grade 1–2 medial open, clean at 3 wk** — **infection ≈ closed fracture** with extensile ORIF; IV antibiotics 2–3 d\
✗ Wrong options: 3–5× infection · ex-fix only

## 6 Complications

| Complication | Fact |
|---|---|
| **Wound complications** | **10–25%** (Orthobullets) · **10–35%** (OB) · **delayed wound healing / dehiscence = commonest** (up to 25%) · deep infection 1–4% closed |
| **Subtalar arthritis** | ↑ with nonop; **commonest complication of nonop** |
| **Sural neuroma** | Extensile lateral / sinus tarsi |
| **FHL injury** | Long lateral→medial screws at sustentaculum |
| **Compartment syndrome** | **10%** → **claw toes** |
| **Peroneal tendinitis / impingement** | Lateral wall blowout; **typical after nonop** |
| **Malunion** | Loss of height, widening, varus, impingement |
| Overall | **\~40% complication rate** |

### Wound complications, approach & sural nerve

**Risk factors (TO)** — **smoking** · **diabetes**, **open fracture**, single-layer closure, higher Sanders, long op, ↑ EBL, many people in OR, delay to surgery, ↑ BMI, **less surgeon experience**\
✗ Wrong options: RA · steroids · alcohol

**Not wound risk factors (OB)** — workers' comp, allograft, contralateral fracture, male sex

**Prevention (TO)** — tourniquet, no smoking, full-thickness flap, **drain**, **two-layer closure ends → middle**, sutures **2–3 wk**, no ROM during that time, keep hardware away from incision corner

**Superficial dehiscence after sinus tarsi in smoker** — **stop PT, immobilise, local wound care** (± oral antibiotics) · deep / purulent → serial debridement\
✗ Wrong options: I&D · hardware removal

**Sural neuroma (burning lateral pain, 7 cm above heel)** — **excise + bury sural nerve in muscle or vein**\
✗ Wrong options: SPN neuroplasty · subtalar fusion · hardware removal at 6 mo

**Nerve by approach** — sinus tarsi / extensile = **sural** · direct lateral fibula + anterolateral ankle = **SPN** · posteromedial = tibial nerve + PTA

### Associated injuries – peroneal tendon dislocation

**SPR tear + peroneal instability** — **\~20%**, from **lateral wall blowout** (joint depression); ↑ with higher Sanders + fracture-dislocation

**Fleck / cortical avulsion off distal fibula on CT** — **SPR disrupted → anterior peroneal subluxation** confirmed intra-op\
✗ Wrong options: intact SPR · FHL entrapment · skin necrosis

**CT** — limited sensitivity → **test SPR intra-operatively**

**TO stem (TO)** — calcaneum X-ray, "which movement is weak?" (plantarflexion / dorsiflexion / inversion / eversion) — **answer key not provided by the source**

### Compartment syndrome – claw toes

**Strongest association (TO)** — **Sanders IV**\
✗ Wrong options: soft-tissue compromise · delay · crush

**Lesser-toe clawing at 3 mo** — **missed foot compartment syndrome** (intrinsic contracture)\
✗ Wrong options: FHL tethering · sural · medial plantar neuropathy · tib post

### Malunion sequelae & subtalar distraction bone-block arthrodesis

**Malunion triad** — **↓ height (talus dorsiflexed, talar declination < 20°)**, **↑ width (lateral wall exostosis)**, **varus**

| Sequel | Cause |
|---|---|
| **Anterior tibiotalar impingement / ↓ dorsiflexion** | **Loss of posterior facet height** → dorsiflexed talus (**talar declination < 20°**) |
| **Subfibular / peroneal impingement, peroneal tendinitis** | **Lateral wall blowout + widening** (✗ Wrong options: hindfoot valgus (uncommon)) |
| Shoe-wear problems | ↑ width |
| **Subtalar arthritis** | Articular incongruity (most cases; often radiographic only) |
| **Varus** hindfoot | Tuberosity pulled into varus |

**Nonop DIACF frequently** — **peroneal tendinitis**\
✗ Wrong options: return to normal · narrowing · lengthening · plantarflexed talus

![Calcaneal malunion classification](../../Orthobullets/attachments/ob1051-illustration-of-calcaneal-malnunion-classification.jpg)

| Malunion type (Stephens–Sanders) | Features | Treatment |
|---|---|---|
| **I** | Lateral exostosis, **no** subtalar arthritis | **Lateral wall resection (exostectomy)** |
| **II** | Exostosis **+ subtalar arthritis** | **Lateral wall resection + subtalar fusion** |
| **III** | + **varus malunion** | Wall resection + subtalar fusion **± valgus osteotomy** (controversial) |

**Distraction bone-block subtalar arthrodesis** — indicated by **loss of height with anterior ankle impingement / ↓ dorsiflexion** (+ subtalar arthritis); restores height (\~8 mm), talocalcaneal angle (\~9°), **talar declination** (\~11°); corrects varus, TN subluxation

**Bone block not for** — **full dorsiflexion, no tibiotalar impingement** (EXCEPT) · **peroneal impingement alone** (needs **lateral wall exostectomy**) · isolated sinus tarsi pain (→ **in situ** fusion) · + tibiotalar arthritis (→ triple / larger fusion)

**Ankle + lateral pain, subfibular impingement + arthritis** — **distraction subtalar arthrodesis + lateral wall ostectomy**

**Early post-traumatic subtalar arthritis, ankle pain-free** — **Arizona / gauntlet brace** (limits inversion–eversion) before surgery\
✗ Wrong options: ASO lace-up · UCBL · medial wedge

**Subtalar fusion after prior ORIF** — better function + fewer wound problems than after nonop malunion (Radnay)

### Stress & insufficiency fractures

**Clinical** — **heel squeeze (medial–lateral compression) tender**; pain all day, worse with WB; walls of calcaneus

**X-ray** — **sclerotic line at 2–3 wk** (dense condensation in elderly insufficiency, e.g. after TKA)

**MRI** — most sensitive: **marrow oedema (T2 / STIR) + linear low-signal fracture line on T1**\
✗ Wrong options: plantar fascia thickening · Achilles insertion signal · OCD · serpiginous AVN line

**Next step if suspected** — **restricted WB + MRI**\
✗ Wrong options: heel-pad steroid (fat-pad atrophy) · PRP · nerve release · Graston · EMG

**Treatment** — **boot / cast + NWB**; 4–6 months cast excessive\
✗ Wrong options: fascia stretching · eccentric Achilles · CRPP · activity as tolerated

### Anterior process fracture – bifurcate ligament

**Mechanism** — **inversion + plantarflexion → bifurcate (Y) ligament avulsion**\
✗ Wrong options: CFL (inversion + dorsiflexion) · ATFL (talus) · tibiocalcaneal (deltoid)

**Often missed** as "ankle sprain"; best seen on **oblique foot X-ray or CT**; prone to nonunion

**Treatment** — acute non-displaced → immobilise NWB · **> 25% CC joint → ORIF**

## X vs Y

| | **Tongue-type** | **Joint depression** |
|---|---|---|
| Secondary line | Exits **posteriorly** through tuberosity | **Behind** posterior facet |
| Facet | Attached to tuberosity | Depressed separately |
| Urgency | **Skin necrosis → urgent** | Delay 10–14 d |
| Option | **Percutaneous** reduction / screws | ORIF |

| | **Extensile lateral** | **Sinus tarsi** |
|---|---|---|
| Wounds / infection | **Higher** | **Lower** |
| Op time | Longer | **Shorter** |
| Radiation | Less | **More** |
| Böhler restoration | Same | Same |

| | **In situ subtalar fusion** | **Distraction bone-block fusion** |
|---|---|---|
| Indication | Isolated subtalar arthritis | **+ loss of height, anterior ankle impingement** |
