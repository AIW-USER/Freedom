# Scapula Fractures

*Trauma · 53 / 67*

## 1 Basics

### Epidemiology

**Incidence** — **< 1% of fractures**, 3–5% of shoulder girdle · age 25–50, M > F · mortality 2–5%

**Location** — **body / spine 45–50%** · glenoid 35% (neck 25%, fossa / rim 10%) · acromion 8% · coracoid 7%

**Mechanism** — **high energy 80–90%** (**MVC > 70%**) · FOOSH · dislocation: **anterior → anterior rim**, **posterior (seizure, shock) → posterior rim**

### Associated injuries (rib / chest injury, ISS)

**Associated injuries** — **80–95%** · **↑ Injury Severity Score**\
✗ Wrong options: ↑ mortality · LOS · ICU

| Injury | Rate |
|---|---|
| **Chest injury** (commonest) | **80%** — pneumo / haemothorax > 30%, **contusion > 40%** |
| **Rib fractures (commonest fracture)** | **52–53%** |
| Head injury | 35–50% |
| Ipsilateral limb | 50% (**clavicle 25%**) |
| Spine | 26–30% |
| Pelvis / acetabulum | 15% |
| Vascular (subclavian / axillary) | 11% |
| Brachial plexus | 5–13% (**75% resolve**) |

**CT chest** — consider for ribs + lung injury

### Anatomy

**Body** — **18 muscles**; spine separates supra- / infraspinatus; **spinoglenoid notch** → infraspinatus only · scapular notch → supra + infraspinatus

**Glenoid** — pear-shaped, **1–5° retroversion**, **15° superior tilt**; labrum deepens **50%**

**Acromion** — pre- (tip), meso- (mid), meta- (base) acromion · **os acromiale** (unfused meso / meta) ≠ fracture

**Coracoid** — ossification centres open **to \~25 yr** (angle, tip); conjoint tendon, pectoralis minor; CC ligaments **\~25 mm from tip**

**SSSC (superior shoulder suspensory complex)** — **distal clavicle, acromion, coracoid, glenoid + AC + CC ligaments** · **double disruption = unstable ("floating shoulder")**

**Axillary nerve** — inferior to glenoid · motion ⅓ scapulothoracic, ⅔ glenohumeral

## 3 Presentation

**Often missed** with distracting injuries · diffuse pain, dyspnoea, chest pain · passive ROM only · check **axillary, radial, median, ulnar**, pulses

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Measurement |
|---|---|
| True AP, **Grashey**, **scapular Y**, axillary; **CXR** | Pneumothorax; **medial border–spine > 1 cm → scapulothoracic dissociation** |
| **Glenopolar angle (Grashey)** | Normal **30–45°**; **< 20–22° → poor / operative** |
| Lateral border offset | Medialisation |
| Angulation | **Scapular Y** |
| **CT (3D)** | Intra-articular, displacement > 1 cm, thoracic / spine injuries |
| MRI | SSSC ligament injury |

### Classifications

| Ideberg (glenoid, Goss) | Fracture |
|---|---|
| **Ia** | **Anterior rim** |
| **Ib** | **Posterior rim** |
| **II** | Fossa → exits **inferiorly** |
| **III** | Fossa → exits **superiorly** |
| **IV** | Fossa → exits **medially** through body |
| Va / Vb / Vc | II + IV · III + IV · II + III + IV |
| VI | **Severe comminution** |

**AO-OTA glenoid (more reliable)** — 14F0 extra-articular (neck) · 14F1 simple intra-articular (rim, transverse) · 14F2 multifragmentary · 14B body extension

| Kuhn (acromion) | Fracture |
|---|---|
| I | Non / minimally displaced |
| II | Displaced, subacromial space OK |
| **III** | **Displaced → narrows subacromial space** |

| Ogawa (coracoid) | Fracture |
|---|---|
| **I** | **Proximal to CC ligaments** |
| **II** | **Tip** (distal) |

## 5 Management

```
Scapula fracture
├─ Most (90% minimally displaced) → sling 2–3 wk + early motion (weekly X-ray × 3 wk)
├─ Glenoid: step-off > 4 mm or > 20–25% rim with subluxation → ORIF
├─ Body / neck: medialisation > 20 mm, angulation > 40°, GPA < 20–22°, translation > 1 cm → ORIF (Judet)
└─ Floating shoulder (SSSC double disruption) → fix (clavicle ± scapula)
```

### Operative indications — glenoid neck displacement, SSSC double disruption, scapular spine

| Fracture | ORIF if |
|---|---|
| **Body** | **Medialisation > 20 mm**, **GPA < 20–22°**, **angulation > 40°** (> 45°, OB), medialisation > 15 mm + angulation > 35° |
| **Neck** | **Angulation > 40°**, **translation > 1 cm**, GPA < 20–22°, **SSSC double disruption** |
| **Glenoid** | **> 20–25% anterior / posterior rim + subluxation**; **step-off > 4 mm** (> 5 mm OB · > 3–4 mm OB) |
| Acromion | **Kuhn III**, painful nonunion, impingement, double disruption |
| Coracoid | > 1 cm, nonunion, Ogawa I into body, double disruption (✗ Wrong options: Ogawa II tip (nonop even > 1 cm)) |
| Any | Open fracture |

**Neck: medial 3 mm, angulated 20°** — **sling 2 wk + PT**\
✗ Wrong options: ORIF

**Displaced lateral scapular spine, weak abduction** — **ORIF** (poor deltoid lever, impingement)\
✗ Wrong options: stimulator · brace · acromioplasty · excision

**Displaced extra-articular scapula + comminuted clavicle** — **ORIF scapula + clavicle**\
✗ Wrong options: sling · fix one only

**Glenoid neck + strongest operative indication** — **ipsilateral distal clavicle fracture (floating shoulder)**\
✗ Wrong options: plexus injury (75% resolve) · LC1 pelvis · pneumothorax · 2 rib fractures

**Double disruption with neck fracture** — **AC ligament injury**\
✗ Wrong options: labrum, supraspinatus, transverse scapular ligament, coracohumeral ligament

**Nonop outcomes** — union 6–8 wk; near-normal function; **may displace in first 3 wk** (rib fractures, SSSC injury) · poor if GPA < 20°

### Floating shoulder

**Definition (TO)** — **ipsilateral clavicle + scapular neck fracture LATERAL to coracoid (anatomical neck)** · surgical neck (medial to coracoid) + clavicle + **CA + CC ligament disruption** also counts — TO explanation calls both correct

**Surgical neck** — medial to coracoid base (common) · **anatomical neck** — lateral (rare, unstable)

### Posterior (Judet) approach — internervous interval

**Modified Judet** — **infraspinatus (suprascapular n.) ↔ teres minor (axillary n.)**\
✗ Wrong options: supra / infraspinatus · teres minor / major (axillary / lower subscapular) · deltopectoral

**Incision** — along spine + down vertebral border ("L" / boomerang); detach posterior deltoid

**At risk** — **posterior branch axillary nerve** (teres minor retracted inferiorly), **suprascapular nerve + artery** (infraspinatus superiorly), circumflex scapular + posterior humeral circumflex vessels

**Other approaches** — straight posterior (isolated neck / lateral border) · **deltopectoral** (anterior glenoid, Ideberg II; axillary + musculocutaneous risk; subscapularis failure) · lateral mid-axial (inferior glenoid) · posterior over spine (acromion)

**Fixation** — 2.7 / 3.5 mm plates (locking on thin border) · rim: screws / arthroscopic anchors · acromion: lag + recon plate / tension band · coracoid: 2.7 / 3.5 mm screws

![Judet approach](../../Orthobullets/attachments/ob1013-judet-approach.jpg)

### Glenoid rim fracture — instability

**Large anterior-inferior rim fracture after dislocation** — untreated → **recurrent instability** (loss of concavity compression) → ORIF

## 6 Complications

| Complication | Fact |
|---|---|
| PTOA | Residual step-off → arthroplasty |
| Malunion | Nonop, angulation / medialisation; glenoid → RSA |
| Recurrent instability | Young, large bone loss |
| Neurovascular | Scapulothoracic dissociation → **EMG at 3–6 wk** |

### Carpal fracture epidemiology

**Commonest carpal fracture (TO)** — **scaphoid** > triquetrum > trapezium

| + clavicle | Floating shoulder if CA + CC torn | **Floating shoulder** |
