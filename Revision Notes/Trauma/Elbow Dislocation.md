# Elbow Dislocation

*Trauma · 17 / 67*

## 1 Basics

### Epidemiology

**Rank** — **2nd commonest major joint dislocation** (after shoulder); **commonest dislocation in children**

**Share** — **10–25%** of elbow injuries · **posterolateral 80%** · peak **age 10–20**

**Simple vs complex** — **simple (no fracture) 50–60%** · complex 40–50%

**Associated** — shoulder / wrist injuries **10–15%** · radial head fracture up to 10%

### Anatomy – stabilisers

| Type | Structures |
|---|---|
| **Primary static** | **Ulnohumeral joint**, **anterior bundle MCL** (key valgus), **LCL complex incl. LUCL** (primary varus + posterolateral rotatory) |
| **Secondary static** | **Radiocapitellar joint**, **capsule**, **common flexor + extensor origins** |
| **Dynamic** | **Anconeus, brachialis, triceps** (+ biceps) — compression |

**LCL (TO)** — radial collateral, annular, **lateral ulnar collateral** · **MCL (TO)** — **anterior bundle (valgus)**, posterior bundle (secondary valgus + ulnar rotation) · extensors resist varus, flexors resist valgus

## 2 Mechanism

**Posterolateral dislocation** — **axial load + forearm supination / ER + valgus posterolateral force** (O'Driscoll) · varus posteromedial mechanism also reported

**Circle of Horii (lateral → medial)** — **LCL fails first** → capsule → **MCL last** (energy dependent); some recent work suggests failure may start medially (TO)

**LUCL failure mode** — **avulsion from humeral (lateral epicondylar) origin** · McKee: proximal avulsion 32, midsubstance 18, bony humeral 5, ulnar 3 / 62\
✗ Wrong options: ulnar insertion · midsubstance (less common) · bony avulsion

**MRI of torn LCL** — avulsed off lateral epicondyle (MCL + flexor origin intact)

## 3 Presentation

**Exam** — pain, swelling, deformity; **skin (open?)**; **compartments**; **wrist + shoulder**; NV

**Commonest nerve injury (TO)** — **ulnar nerve** (stretch) · median rare (with brachial artery) · brachial artery (rare; open)

## 4 Diagnosis & Classification

### Key radiology findings

**AP + lateral** — congruency esp. post-reduction · **obliques** — periarticular fractures · **CT** — complex patterns, fractures, loose bodies

**"Drop sign" (TO)** — **↑ static ulnohumeral distance** on post-reduction lateral → residual posterolateral subluxation

### Classification

| Basis | Types |
|---|---|
| **Anatomic** (olecranon vs humerus) | **Posterolateral (commonest)** · posteromedial |
| **Simple** | No fracture |
| **Complex** | With fracture: **terrible triad** (dislocation + LUCL + radial head + coronoid tip) · **varus PMRI** (LCL + anteromedial coronoid; radial head spared) |

## 5 Management

```
Elbow dislocation
├─ Simple, stable after reduction → splint 5–10 d → early active ROM
│      └─ residual subluxation (drop sign) → active ROM pronated, avoid varus
├─ Unstable (needs > 50–60° flexion) / irreducible → open, repair LCL ± MCL
├─ Complex → fix coronoid / radial head / olecranon + LCL ± MCL
└─ Chronic → open reduction, release, hinged ex-fix
```

### Simple dislocation – reduction & early motion

**Reduction** — analgesia + relaxation → **in-line traction** (coronal) + **forearm supination** (coronoid under trochlea) + **flex elbow with pressure on olecranon** → "clunk"

**Post-reduction test** — unstable in **extension** + **valgus**; test valgus with **forearm pronated** (locks lateral side)

**Splint** — posterior splint **≥ 90° flexion**, rotation of maximum stability: **LCL torn → pronation** · **MCL torn → supination** (O'Driscoll: reduce in supination, immobilise in pronation) · neutral acceptable

**Duration** — **5–10 days** (5–7 d, OB) → **early active ROM** through stable arc; hinged brace with extension block **3–4 wk**; light duty at 2 wk; full extension by **6–8 wk** · avoid varus / valgus loading until 12 wk (TO)

**Stable after reduction — start motion** — **\~1 week**\
✗ Wrong options: immediately · 3 wk · 6 wk · after LCL repair

**Best outcome predictor** — **mobilisation within 5–10 days** (> 10 days → arthrofibrosis, pain) · immobilisation **> 3 wk → poor final ROM**

**Avoid** — **immobilisation 4 wk**\
✗ Wrong options: vs active motion, 90° neutral splint, extension-limited early rehab, light duty (all OK)

**Simple dislocation, can't move elbow** — **closed reduction, splint, early ACTIVE ROM**\
✗ Wrong options: passive ROM · hinged ex-fix · acute LCL repair · open reduction

**Residual posterolateral subluxation (drop sign) (TO)** — **splint 1 wk → active motion with forearm PRONATED through full range**; elbow at side (no varus / shoulder abduction); supinate only at ≥ 90° flexion\
✗ Wrong options: LCL reconstruction · splint 1 month

**Recurrent instability after simple dislocation** — **rare (< 1–2%)**

### Operative criteria

| Indication | Treatment |
|---|---|
| **Irreducible** (soft tissue / osteochondral fragment) | Open reduction |
| **Persistent instability** — needs **> 50–60° flexion** to stay reduced (Orthobullets, OB) · **redislocates at < 30° flexion** (TO) | **Repair LCL ± MCL** |
| **Complex** (coronoid, radial head, olecranon) | ORIF / arthroplasty + LCL ± MCL |
| Open, vascular injury, recurrent | Surgery |
| Throwers | ± MCL repair |
| **Chronic dislocation** | **Open reduction + capsular release + dynamic hinged ex-fix** |
| Still unstable after all repairs | **Hinged external fixator** |

**Highly unstable after closed reduction** — **open reduction + LCL repair ± MCL repair**\
✗ Wrong options: 6 wk splint · ex-fix alone · internal joint stabiliser alone · reconstruction + 6 wk immobilisation

**Essential lesion in persistent instability** — **LUCL**\
✗ Wrong options: MCL (repaired only if still unstable) · coracohumeral · capsule

**Structure needing repair** — **LUCL**\
✗ Wrong options: radial collateral · MCL bands · accessory collateral

### Approaches

**Kocher (ECU–anconeus)** — LCL, extensor origin, coronoid, capitellum, radial head; incise **anterior to radial head midline** to spare posterior LCL fibres; careful retractors → **PIN**

**Medial** — MCL, flexor-pronator, comminuted coronoid; **protect ulnar nerve**

### Complex dislocation – fixation

**Coronoid** — tip fractures rarely need ORIF (proximal to brachialis); lateral or medial approach

**Radial head ORIF** — **safe zone ≈ 90° non-articulating arc** (between Lister tubercle + radial styloid lines) (Orthobullets, OB) · **\~110°** in original dissections · **69%** of head articulates with ulna

**Radial head arthroplasty** — if unreconstructable; **anatomic size / length** → restores varus + ER stability **only once LCL repaired** · **excision → varus / ER instability** without LCL

**Dislocation + comminuted radial head (55-yo)** — **open reduction, LCL repair, radial head ORIF or metallic replacement**\
✗ Wrong options: cast 4 wk · brace + immediate ROM · silastic implant (contraindicated) · excision

### Complex dislocation – coronoid & PMRI

**Varus PMRI** — **LCL rupture (humeral) + anteromedial coronoid facet fracture + ulnohumeral subluxation / dislocation**; radial head usually spared

**Dislocation + anteromedial coronoid fracture on AP** — highest risk **varus PMRI**\
✗ Wrong options: AIN / PIN palsy · PLRI · chair-rise instability

**Fixation preventing PMRI** — **anteromedial coronoid facet** · failure to fix / malunion → poor function + arthrosis (Doornberg & Ring)\
✗ Wrong options: radial head · coronoid tip · olecranon tip · medial capitellum

**Transolecranon fracture-dislocation (TO)** — **anterior dislocation with intact PRUJ**, mainly **bony**, usually **no ligament injury**, coronoid fracture common → **NOT a Monteggia variant** (EXCEPT) · type I simple / II complex · restore ulnar length, alignment, rotation + **sigmoid notch**; missed coronoid = failure

## 6 Complications

| Complication | Fact |
|---|---|
| **Loss of terminal extension** | **Commonest** (simple + complex) → early active ROM; static progressive splint at 6–8 wk |
| Stiffness / contracture | **Immobilisation > 3 wk** |
| **HO** | May need excision |
| Varus PMRI | LCL + anteromedial facet |
| Nerve | **Ulnar** (stretch) · **AIN palsy** (weak pinch, can't flex thumb IP — misread as FPL rupture) |
| Brachial artery | Rare, open dislocations |
| Compartment syndrome, articular damage, recurrent instability | — |

### Post-traumatic stiffness – release & HO excision

**Functional arc** — **30–130°**

**Arc 30–95° (flexion-limited) + HO** — **excise HO + release posterior bundle of MCL + ulnar nerve decompression** (flexion < 100° → decompress)\
✗ Wrong options: supracondylar osteotomy + anterior MCL release · anterior capsule release (helps extension) · **LCL release → instability**

**MCL release order** — **posterior bundle → transverse → (posterior half of anterior bundle)**

**Extension loss 80° with mature anterolateral HO, no ulnar symptoms** — **open resection + capsulectomy via lateral approach** (access anterior + posterior)\
✗ Wrong options: arthroscopic (risky with tight capsule) · anterior approach (no posterior access) · indomethacin + radiation (too late once visible) · manipulation (contraindicated)

**HO maturation** — fluffy → sharp margins over **3–6 months**; labs + bone scan not prognostic; prophylaxis (NSAID, **700 cGy**) ineffective once visible

## X vs Y

| | **Terrible triad (PLRI)** | **Varus PMRI** |
|---|---|---|
| Force | Valgus, supination, axial | Varus, posteromedial, axial |
| Radial head | **Fractured** | **Spared** |
| Coronoid | **Tip** | **Anteromedial facet** |
| Ligament | LCL (± MCL last) | LCL humeral avulsion |

| | **LCL torn** | **MCL torn** |
|---|---|---|
| Most stable forearm position | **Pronation** | **Supination** |

| | **Transolecranon fracture-dislocation** | **Posterior Monteggia** |
|---|---|---|
| PRUJ | **Intact** | Disrupted |
| Ligaments | Usually intact | LCL injured in up to ⅔ |

**"Best outcome strategy?"** → **mobilise within 5–10 days**
