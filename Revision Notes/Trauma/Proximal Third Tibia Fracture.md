# Proximal Third Tibia Fracture

*Trauma · 49 / 67*

## 1 Basics

### Epidemiology

**Incidence** — **5–11% of tibial shaft fractures** (\~10%)

**Mechanism** — low energy: **torsion → spiral oblique** (indirect) · high energy: direct

**Associated** — **compartment syndrome**, soft-tissue injury (**muscle injury severity → amputation need**)

### Characteristic deformity — valgus & procurvatum and its causes

| Force | Effect |
|---|---|
| **Patellar tendon** | **Proximal fragment extends → apex anterior (procurvatum)** |
| **Gastrocnemius** | **Distal fragment flexes** |
| **Pes anserinus** | Proximal fragment **varus** (per note) |
| **Anterior compartment** | **Valgus** |

**Classic malunion after IMN** — **valgus + procurvatum (apex anterior)** + anterior translation of proximal fragment\
✗ Wrong options: varus · recurvatum · rotation

**Causes** — wide metaphysis (no canal fit), **eccentric / medial start**, deforming muscles, **knee hyperflexion**, nail **Herzog curve** ("wedge effect")

**Malalignment rate** — **20–60%** (Orthobullets) · **58%** proximal ⅓ (Freedman; vs 7% middle, 8% distal) · **up to 84%** (OB)

**Other fractures' typical malunions** — humeral shaft: varus, shortening, IR · distal femur: varus, shortening, recurvatum · distal ⅓ tibia + intact fibula: varus + rotation · subtroch: **flexion, abduction, ER**

## 3 Presentation

**Exam** — contusions, blisters, open wounds, **compartments** (passive toe stretch ± pressures) · DPN, SPN, sural, tibial, saphenous; DP + PT pulses

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP + lateral tibia + **knee + ankle** · findings: **proximal fragment extended, apex anterior, varus**; **distal fragment flexed**

**CT** — **intra-articular extension** (differential: plateau fracture, knee dislocation)

| AO 42 | Pattern |
|---|---|
| A | Simple |
| B | Wedge |
| C | Comminuted |

## 5 Management

```
Proximal ⅓ tibia fracture
├─ Closed low energy, acceptable alignment → long leg cast (10–20° flexion) → brace at 4 wk
├─ Soft-tissue compromise / polytrauma → ex-fix (convert to IMN 7–21 d)
├─ ≥ 5–6 cm proximal bone for 2 locking screws → IMN + anti-deformity tricks
└─ Very proximal / inadequate nail fixation → percutaneous locking plate
```

### Operative criteria

| Acceptable for cast | Limit |
|---|---|
| Varus / valgus | **< 5°** |
| AP angulation | **< 10°** |
| Cortical apposition | **> 50%** |
| Shortening | **< 1 cm** (hardest to control) |
| Rotation | **< 10°** |

| Option | Indication / fact |
|---|---|
| **Ex-fix** | Soft-tissue compromise, polytrauma; circular frame for very proximal; **more malalignment than IMN** |
| **IMN** | **≥ 5–6 cm proximal bone (2 locking screws)**; static locking proximal + distal; ≥ 2 proximal screws, **oblique** screws help |
| **Percutaneous locking plate** | Extreme proximal, transverse / oblique, good soft tissue; **lateral safer**; **lateral plate + medial comminution → varus collapse**; **↑ infection vs IMN in open** |

### Nailing technique — lateral start point, semi-extended / suprapatellar nailing, unicortical plate

**Start point** — **just medial to lateral tibial spine (AP)** + **proximal, anterior to articular margin (lateral)** → **lateral start prevents valgus**\
✗ Wrong options: medial start → valgus · distal + medial → anterior cortex cut-out

**Approach** — **lateral parapatellar** (needs mobile patella) helps lateral start · medial parapatellar → valgus

**Semi-extended / suprapatellar nailing** — neutralises extensor pull → **prevents procurvatum** · **suprapatellar does NOT affect valgus (coronal)**\
✗ Wrong options: hyperflexion (worsens) · radiolucent triangle

**Suprapatellar vs infrapatellar** — infrapatellar → **more anterior knee pain**; ROM, union, PF joint same

**Unicortical plate** — short ⅓-tubular plate anterior / anteromedial / posteromedial, 2 unicortical screws each side → holds reduction (prevents procurvatum + anterior translation)

**Universal / femoral distractor** — Schanz pins medial, parallel to joint (can double as blocking pins)

**Prevent apex anterior — all EXCEPT** — **anterior blocking screw** (posterior blocking screw, posterior starting hole, semi-extended interlocking, anteriorly directed nail all help)

**Preserve reduction — EXCEPT** — **countersinking the nail** (loses aperture fixation)\
✗ Wrong options: oblique proximal screws · blocking screws · lateral eminence start · unicortical plate

**Valgus prevention — NOT shown for** — **suprapatellar portal**

**Nail choice** — **Herzog curve proximal to fracture** (distal curve → anterior translation)

**Locking** — **static**; no acute dynamisation

### Blocking (Poller) screws — position & function

**Rule** — place in the **concavity** of the deformity, in the **proximal (metaphyseal) fragment** → narrows canal, redirects nail

| Screw | Prevents |
|---|---|
| **Posterior to nail, proximal fragment** (coronal screw) | **Procurvatum** (counters patellar tendon + gastrocnemius) |
| **Lateral to nail, proximal fragment** (sagittal screw) | **Valgus** |
| Anterior | **Worsens** procurvatum |
| Medial | **Worsens** valgus |

**Benefits** — obtain + maintain reduction, **↑ construct stiffness** (if left) · Ricci: < 5° valgus with screws vs > 6° without · union \~5.4 months (Krettek)\
✗ Wrong options: ↓ nail breakage · replace interlocks · larger nail

### Minimally invasive plating — superficial peroneal nerve risk

**Long lateral plate, percutaneous distal screws** — **superficial peroneal nerve** (± deep peroneal) → **small open incision for distal holes**\
✗ Wrong options: common peroneal · saphenous (medial) · peroneal artery · tendons

## 6 Complications

| Complication | Fact |
|---|---|
| **Anterior knee pain** | **> 30% after IMN**; **nail removal helps \~50%** |
| **Malunion** | **Valgus + procurvatum (20–60%)** → ↑ arthrosis; revision IMN / osteotomy |
| Nonunion | **Rule out infection**; dynamise if axially stable |

## X vs Y

| | **Posterior blocking screw** | **Lateral blocking screw** |
|---|---|---|
| Prevents | **Procurvatum** | **Valgus** |
| Plane | Coronal screw (sagittal deformity) | Sagittal screw (coronal deformity) |

| | **Lateral start** | **Medial start** |
|---|---|---|
| Effect | **Prevents valgus** | **Causes valgus** |
