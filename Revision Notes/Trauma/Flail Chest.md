# Flail Chest

*Trauma · 23 / 67*

## 1 Basics

### Definition & epidemiology

**Flail chest** — **segmental fractures of ≥ 3 consecutive ribs** → hemothorax / pneumothorax

**Incidence** — \~300,000 / yr; **\~10% of blunt thoracic trauma** (OB); more ribs → ↑ morbidity + mortality

**Who** — bimodal: young trauma · elderly osteopenic

**Commonest ribs** — **7–10**

**Mortality** — **up to 33%** with flail chest · **2.5% with surgical stabilisation**

### Associated injuries

| Ribs | Association |
|---|---|
| **1–3** | **Mediastinal injury (aorta, brachial plexus)**, worse mortality |
| **1–4** (upper) | **Progressive displacement of ipsilateral clavicle fracture** |
| **9–12** | **Intra-abdominal injury — liver + spleen** |
| Any | Hemopneumothorax, pulmonary contusion, scapula + clavicle fractures |

### Anatomy

**Ribs** — 12 pairs; **11–12 = floating** (no costal cartilage to sternum)

**Intercostal neurovascular bundle** — **posteroinferior**, in **costal groove** → avoid when plating

![Intercostal neurovascular bundle](../../Orthobullets/attachments/ob1061-neurovascular-bundle-anatomy.jpg)

## 2 Mechanism

**Mechanism** — direct blunt / penetrating; fracture at impact or **rib angle (posterolateral bend) = weakest point**; pathological / metastatic

**Pathophysiology** — negative-pressure ventilation → **paradoxical motion** → pain → ↓ respiratory effort → **pneumonia, ARDS**, intubation

## 3 Presentation

**Symptoms** — pain, chest-wall bruising, respiratory difficulty

**Paradoxical respiration** — segment **sinks in on inspiration**, **expands on expiration**

**Palpation** — bony / soft-tissue crepitus; visible deformity

![Flail chest and paradoxical respiration](../../Orthobullets/attachments/ob1061-flail-chest-and-paradoxical-respiration.jpg)

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| Standard AP / lateral CXR | **Low sensitivity**; may show hemothorax |
| **Dedicated rib series** | **More sensitive** (oblique views, higher energy) |
| **CT** | **Best** for displacement, segmental injury, **need for surgery** + thoracic / abdominal injuries |

## 5 Management

```
Rib fractures
├─ No respiratory compromise, no flail → O2, incentive spirometry, multimodal analgesia
└─ Flail (≥ 3 consecutive segmental) / failure to wean / open / intractable pain → ORIF
       └─ haemodynamically unstable / spine or pelvis first → delay
```

### Operative criteria

| Indication (ORIF) | Contraindication |
|---|---|
| **Flail segment (≥ 3 consecutive segmental ribs)** | **Haemodynamic instability** |
| **Failure to wean from ventilator** | **Spinal / pelvic fractures needing fixation first** |
| **Open rib fractures** | — |
| Displaced fractures with **intractable pain** | — |
| **Symptomatic nonunion** | — |

**Guidelines** — Chest Wall Injury Society SSRF algorithm

![SSRF rib fracture algorithm](../../Orthobullets/attachments/ob1061-ssrf-rib-fractures-algorithm.jpg)

### Technique

| Approach | Fractures |
|---|---|
| **Lateral thoracotomy** (lateral decubitus) | Anterolateral + posterolateral |
| **Posterior paramedian** | Very posterior, near **costovertebral junction** |
| **Inframammary** (supine) | Anterior + **costochondral dislocations** |

**Implants** — plate + screw constructs · intramedullary splints

### Operative rib fixation — outcomes

**Surgery vs nonop** — **↓ ICU stay** · **↓ total hospital stay** · **↓ pneumonia** · ↓ ventilation days, ↓ tracheostomy, ↓ deformity, ↓ mortality, ↓ cost

**Long-term respiratory function** — **equivalent**\
✗ Wrong options: superior

## 6 Complications

| Complication | Fact |
|---|---|
| **Nonunion** | Chest pain **> 3 months** → nonunion work-up before fixation |
| **Intercostal neuralgia** | Bundle **posteroinferior** to rib |
| Periscapular weakness | — |
| **Pneumonia** | — |
| **Restrictive** pulmonary function | — |

## X vs Y

| | **Ribs 1–3** | **Ribs 9–12** |
|---|---|---|
| Associated injury | **Aorta, brachial plexus** (mediastinal) | **Liver, spleen** |

## How it's asked

**"Flail ORIF vs nonop?"** → **shorter ICU stay**\
✗ Wrong options: longer / equal hospital stay · superior long-term lung function · equal pneumonia

**"Definition of flail chest?"** → **≥ 3 consecutive ribs fractured segmentally**

**"Lower rib fractures associated with?"** → **liver + spleen injury**

**"Upper rib fractures + clavicle?"** → **progressive clavicle displacement**

**"Best imaging for surgical decision?"** → **CT**
