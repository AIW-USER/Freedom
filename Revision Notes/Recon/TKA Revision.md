# TKA Revision

*Recon · 58 / 65*

## 1 Basics

### Causes of failure (loosening, wear, osteolysis, metallosis)

| Cause | Note |
|---|---|
| ✓ **Infection** | **Most common overall** (national databases, TO) · ✓ **most common early (<2 yr)** · always exclude first · **neutrophil**-predominant |
| **Aseptic loosening** | **2nd overall** · ✓ **most common late (>2 yr)** (OB5949: late = **>10 yr**) · **tibial > femoral** · femoral lysis hidden (posterior condyles) → oblique views, **serial X-rays** |
| **Instability** | **~8%** · MCL/LCL incompetence · flexion instability (PCL attenuation in CR, unbalanced gap, ↑ slope, small femur, femur in extension) |
| **Periprosthetic fracture** | **~5%** (3–5%) · supracondylar femur commonest |
| **Arthrofibrosis** | **~5%** (0–3% OB) · **fibroblasts** |
| **PF maltracking** | **Component malposition** |
| Joint-line problems · patellar clunk (arthroscopic excision) · metal hypersensitivity (**lymphocytes, plasma cells**) | — |

**TO top four** — **infection → aseptic loosening → periprosthetic fracture → instability** (TO)

**Trends** — ✓ **PE wear no longer the major cause** (HXLPE) · instability/malalignment share ↓ · stiffness common early\
✗ Wrong options: infection commonest late · loosening commonest early

**Osteolysis** — PE, PMMA, metal particles → **macrophages + giant cells** · femur: condyles near collateral attachments · tibia: periphery + cancellous access channels · commonest in **uncemented** + **backside wear** · modern cementless ↓ aseptic revision in morbidly obese

| Scenario | Answer |
|---|---|
| 15 yr, pain + instability, osteolysis + loosening, infection excluded | ✓ **revision TKA** (✗ Wrong options: protected WB · bisphosphonate · observe · liner exchange + graft) |
| 15 yr, cemented PS, HXLPE 13 mm — likely cause of revision | ✓ **aseptic loosening** |
| 16 yr, well-defined femoral metaphyseal lysis, medial narrowing | ✓ **particle-mediated osteolysis** (✗ Wrong options: metastasis · stress shielding · sepsis · sarcoma) |
| 13 yr, metal-backed patella, squeaking/grinding | ✓ **extensive metallosis** (worn-through PE → metal-on-metal, black tattooing) |
| 12 yr, femoral migration into varus, normal labs | ✓ **polyethylene wear** (commonest contributor to late lysis/loosening) |
| 6 yr, tibia 5° varus, medial PE narrowing, lateral laxity | ✓ **revise all components + soft-tissue balancing** (✗ Wrong options: poly exchange · isolated tibial (PCL then incompetent)) |
| Commonest early revision — cell lineage | ✓ **neutrophil** (✗ Wrong options: macrophage (PE lysis) · lymphocyte/plasma (metal allergy) · fibroblast (arthrofibrosis)) |

## 3 Presentation

**History** — original indication · pre-op ROM, ambulation · infection, thrombophlebitis, falls · **THA** · implant records

**Temporal pattern** — pain **since index** vs new pain (acute vs chronic infection) · **weight-bearing pain → mechanical**

**Exam** — gait (stiff-legged, no full extension in stance) · ROM · skin, effusion, warmth (**infection vs CRPS**) · ligaments · patellar tracking

## 4 Diagnosis & Classification

### Key radiology findings

| Test | Use |
|---|---|
| **Serial AP + lateral** | Timeline of migration/loosening |
| **Weight-bearing films** | Asymmetric wear |
| **Skyline** | Patellar tracking |
| **Standing long-leg** | Alignment |
| **AP pelvis** | Exclude hip pathology |
| **CT** | Component rotation (vs femoral neck version) · bone defects |
| **Bone scan** | **Positive up to 2 yr** after TKA · positive = nonspecific (loosening, infection, stress fracture) · ✓ **negative rules out loosening** · diffuse uptake → **CRPS** |

### Genes & lab markers

**CBC, ESR, CRP + aspiration** (cell count, culture) before any revision

**Antibiotics already started** → ✓ **stop antibiotics and repeat aspiration**\
✗ Wrong options: continue 2 wk · add gram-negative cover · revise · PT

**Painful nonunion after periprosthetic ORIF with effusion + loosening screws** → ✓ **inflammatory labs + aspiration first**\
✗ Wrong options: PT · bone stimulator · revision ORIF / DFR before infection excluded

### AORI (Anderson) bone defect classification

| Type | Description | Treatment |
|---|---|---|
| **1** | Minor defects, **intact metaphysis**, stability not compromised | **Cement** or **impaction allograft** (no metaphyseal augmentation) |
| **2A** | Metaphyseal damage, **one** condyle/plateau | Cement, **augments**, small graft |
| **2B** | Metaphyseal damage, **both** condyles/plateaus | Cement, augments, small graft |
| **3** | **Massive** loss of condyle/plateau ± **collateral / patellar tendon** attachments | **Bulk allograft**, custom, megaprosthesis, **tantalum cones**, **sleeves**, **rotating hinge** |

## 5 Management

### Goals & steps

**Goals** — extract with minimal bone loss · restore bone · ✓ **restore joint line** · balance ligaments · stable implants · soft-tissue cover

**Sequence** — extensile exposure → remove implants → **tibia first** (establish tibial joint line **1.5–2 cm above fibular head**, use contralateral X-ray) → femur matched to tibia → **flexion–extension gaps** → **medial–lateral gaps** → PF tracking (patella **>12 mm**)

### Exposure (rectus snip, tibial tubercle osteotomy)

**Rectus (quad) snip** — extension of MPP superolaterally across rectus tendon · ✓ **no difference in outcomes** vs MPP · ✓ **enhances exposure without changing rehab or outcomes** · **most common** extra-exposure method\
✗ Wrong options: lateral arthrotomy (devascularises patella) · full MCL release · patellectomy · mobile bearing

**TTO** — **8–10 cm** medial osteotomy hinged on lateral periosteum · ✓ **patella baja** (contracted tendon; prevents avulsion; allows **proximal transfer**) · well-fixed long stems/sleeves/cones · RA, valgus, anteromedial scarring · ✓ **very low nonunion (~100% union)** · fixed with screws or **16-gauge wires/cerclage** (long stems do not preclude) · OK in infected/staged cases · ROM restricted 4–6 wk · used if snip insufficient (V-Y → lag)\
✗ Wrong options: well-fixed standard baseplate alone · slope · CR · BMD predicts

| Figure | TTO needed? |
|---|---|
| ✓ **Patella baja** | **Yes** |
| Posterior dislocation, PT avulsion (alta), spin-out, recurvatum | No |

**Post-HTO baja, PJI explant, flexion 65°, stiff after release** → ✓ **TTO** (best exposure, preserves patellar supply)\
✗ Wrong options: snip + lateral release (lateral geniculate) · V-Y turndown (blood supply) · snip alone (insufficient) · modified V-Y

### Bone loss (augments, cones, sleeves, stems)

**Stems** — load-share to diaphysis · bypass metaphyseal defects

| | **Press-fit diaphyseal stem** | **Cemented stem** |
|---|---|---|
| Pros | Scratch fit, aids alignment, no cement to remove later | **Bowed femur**, antibiotic delivery, **osteopenic bone** |
| Cons | No ingrowth · **iatrogenic fracture** · not for bowed femur · ✓ **end-of-stem pain** (modulus mismatch) | Harder future revision |

**Shin pain at stem tip after hybrid (press-fit) stem** → ✓ **fully cemented stem would have prevented**\
✗ Wrong options: hinge · spacer · teriparatide · short press-fit

**Medial baseplate overhang with long stem → pain** → ✓ **offset tibial stem**\
✗ Wrong options: ingrowth augment · no stem · allograft · cement

| Defect | Option |
|---|---|
| **Cavitary <1 cm** | **Cement** (structurally better than graft) |
| **Cavitary >1 cm, contained** | **Metaphyseal sleeve** |
| **Large, uncontained / asymmetric** | ✓ **Trabecular (tantalum) cone** + press-fit diaphyseal stem (intact diaphysis) |
| **Small asymmetric uncontained** | Metal augment |
| **Small symmetric contained** | Impaction graft |
| **Large symmetric contained + poor diaphysis** | Sleeve + **cemented** stem |
| **Elderly, massive tibial loss incl. posterior cortex** | ✓ **metal-augmented revision tibia** (structural allograft for younger) (✗ Wrong options: hinge · ICBG · cement) |

| | **Metaphyseal sleeves** | **Trabecular metal cones** | **Structural allograft** |
|---|---|---|---|
| Data | Mid–long term good | Short–mid term good | Mid–long term OK |
| Link to implant | ✓ **Morse taper** (modular, attached to stem/tray) | **Independent**, unitised with cement | Cemented |
| Vendor | **Manufacturer-specific** | ✓ **Any system** | — |
| Defect | **Contained only** (✗ Wrong options: large uncontained) | ✓ **Uncontained** OK | Custom shape |
| Other | Simple, acts as cutting guide · expensive, hard to remove | **Brittle**, can be cemented to bone if scratch fit poor · soft-tissue irritant · expensive | Time, disease transmission, **resorption**, infection |

**Porous cones vs cortical allograft** → ✓ **higher long-term survival**\
✗ Wrong options: implant-specific · ductile Morse taper (sleeves) · cannot be cemented · AORI 1

**Cone purpose** → ✓ **↑ metaphyseal contact for osseointegration**\
✗ Wrong options: antibiotics · diaphyseal fit · no cement · easier future revision

**Stage 2, massive metaphyseal defects, intact collaterals, healed TTO** → ✓ **uncemented porous metaphyseal sleeves + uncemented stems**\
✗ Wrong options: impaction graft · allograft without stem/cement · "diaphyseal" defects

**Sleeve relative contraindication** → ✓ **large uncontained metaphyseal defect**\
✗ Wrong options: hinge · stem · RA · capacious diaphysis (sleeve helps)

### Constraint in revision (VVC, hinge)

| Implant | Indication |
|---|---|
| **CR** | Intact PCL (keep PS available) |
| **PS** | PCL deficiency |
| **Constrained non-hinged** | V/V instability, LCL/MCL attenuation (MCL controversial — post may break), flexion laxity (tall post) |
| **Rotating hinge** | **Global ligament deficiency** · flexion laxity with mismatch · multiply revised / post-traumatic · ✓ **hyperextension (polio)** — absolute · tumour / infection resection · Charcot (relative) · **collateral origin bone loss** |
| **DFR** | Salvage: fracture, massive bone loss |

**Rule** — **least constraint** that gives stability

| Scenario | Answer |
|---|---|
| 1990 TKA, two-component osteolysis + instability | ✓ **revise femur + tibia with stems/augments** (✗ Wrong options: tibia only ± LCL reconstruction · immobiliser · no stems) |
| Irreparable saw MCL transection, valgus laxity >1 cm (RA) | ✓ **unlinked VVC** (least interface stress) (✗ Wrong options: PS fixed/mobile · CR · hinge) |
| 80 yo, MCL deficient + anterior drawer + no SLR (multiplanar) | ✓ **hinged revision** + EM repair (✗ Wrong options: poly upsize · MCL reconstruction · femoral only · high-post) |
| Absolute indication for rotating hinge | ✓ **hyperextension instability** (✗ Wrong options: LCL attenuation (CCK) · EM deficiency · PCL deficiency (PS) · contained condylar defect (AORI 2A)) |
| Stage 2 — strongest hinge indication | ✓ **medial femoral cortical loss involving medial epicondyle** (MCL origin) (✗ Wrong options: cancellous loss (cones/sleeves) · cortical loss sparing collaterals (augments)) |

### Flexion instability

**Revision options** — ✓ **upsize femoral component** · ↓ tibial slope · more distal femur + thicker poly · correct rotation\
✗ Wrong options: ↑ slope · more posterior femur · more tibia (both gaps) · distal augments (extension only)

### Infection-related (cement, host, workup)

**Stage 2 for MRSA** → ✓ **pre-mixed gentamicin cement + hand-mixed vancomycin** · pre-mixed better elution + mechanics · FDA: antibiotic cement approved only for **stage 2 of two-stage**; primary use off-label\
✗ Wrong options: plain cement

**Failure of repeat two-stage** → ✓ **MSIS host grade C** (none cleared) → consider **fusion / amputation** · also MRSA, polymicrobial\
✗ Wrong options: WBC >25k · anaerobic cocci (low virulence) · semi-constrained · static spacer

**Revision infection risk** — **4–7%** (double primary) · ↑ with MSIS C · PJI 1–2% primary, up to 4% revision

### Cementless TKA indications

**Best evidence** → ✓ **younger, obese males** (↓ tibial aseptic loosening, HA-coated; short–mid term)\
✗ Wrong options: osteopenic · RA · elderly ♀ · elderly smokers

### Wound & extensor problems

**Skin** — incorporate prior scars · supply medial → lateral edge hypoxic → **use most lateral incision** · full-thickness defect → **medial gastrocnemius flap**

**iNPWT** — ✓ **revision TKA** clearly benefits (↓ wound complications)\
✗ Wrong options: UKA · primary TKA · primary THA any approach

**EM disruption** — Achilles bone-block allograft (residual lag common) · **mesh** may give better mid-term function + survival

**Other** — pain worse than primary (activity pain ~6 mo) · stiffness · peroneal palsy (valgus + FFD correction)

### Distal femoral replacement outcomes

**DFR for fracture around primary components** → ✓ **lower revision rates** than DFR after prior revision components or failed ORIF
