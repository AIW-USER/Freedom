# TKA Wound Complications

*Recon · 63 / 65*

## 1 Basics

### Risk factors (diabetes, obesity, smoking, nutrition)

| Category | Factors |
|---|---|
| **Systemic** | **Diabetes mellitus** · vascular disease · **inflammatory arthritis (RA)** · immunosuppressives / **steroids** · **tobacco** · renal + liver disease · **poor nutrition** (albumin <3.5 g/dL, TLC <1,500/µL) · perioperative **anaemia** · **morbid obesity (BMI >40)** |
| **Local** | **Previous incisions** · knee deformity · skin adhesions · poor local blood supply · traumatic arthritis |
| **Technique** | **Large subcutaneous flaps** · short incision → vigorous skin traction · not preserving subcutaneous fat layer · long surgical time · long tourniquet time (Orthobullets) |
| **Post-op** | **Haematoma** · infection · **early (first 4 days) flexion >40°** in a high-risk knee |

**Diabetes** — ✓ **most strongly associated** with early wound complication needing surgery (Galat: > inflammatory arthritis, smoking, PVD, steroids, BMI >30, previous open surgery)

**Tourniquet** — Orthobullets lists long tourniquet time · OB: tourniquet use + duration **not correlated** with wound complications — read the options\
✗ Wrong options: "tourniquet 70 min" as strongest factor

**Previous knee surgery** — **open** surgery = risk · esp. if a more **medial** incision used → **lateral wound necrosis** (may need gastrocnemius flap)\
✗ Wrong options: arthroscopy

**DVT prophylaxis** — **aspirin** → **fewer** wound complications than LMWH / NOACs\
✗ Wrong options: aspirin as risk factor

**Early surgical intervention for wound** → ↑ major subsequent surgery (**5.3%**) + deep infection (**7.0%**) → aim for primary healing at index surgery

**Modifiable before surgery** — smoking cessation · nutritional optimisation · stop harmful immunomodulators · glucose control · weight loss

### Genes & lab markers – nutrition

| Marker | Malnutrition cut-off |
|---|---|
| **Albumin** | **<3.5 g/dL** |
| **Total lymphocyte count (TLC)** | **<1,500 /µL** (cells/mm³) |
| **Prealbumin** | **<15 mg/dL** |
| **Transferrin** | **<200 mg/dL** |

**TLC + prealbumin for a chronic wound** → ✓ **assess nutrition**\
✗ Wrong options: rule out infection · detect inflammation (ESR/CRP) · immune status (complement/immunoglobulins) · anaemia (Hb, Hct, RBC)

### Smoking

**Smoker vs non-smoker TKA** → ✓ **higher readmission** · smoking = single greatest predictor of **30-day readmission + reoperation** after outpatient TJA · ↑ deep + superficial SSI · ↑ **MUA** · ↑ wound breakdown, loosening\
✗ Wrong options: better SF-36 · better pain relief · no difference in SSI or MUA

**Cessation** — **4–6 wk before and after** TJA → complications ↓ **50%** (↑ blood O₂-carrying capacity)

**MUA risk factors (Issa)** — diabetes · hypercholesterolaemia · preop ROM **<100°** · TKA for osteonecrosis · smoking

### Obesity

**BMI >40 TKA** → ✓ **more post-op radiolucent lines** · ↑ complications · ↑ revision, inferior survivorship · poorer function\
✗ Wrong options: no difference in function / complications / revision

### AAOS 2016 knee OA surgical guideline

| Strength | Statement |
|---|---|
| **Strong** | Obese patients **less improvement** after TKA · **no difference** in pain/function with **patellar resurfacing** · **no difference CR vs PS** · **periarticular + peripheral nerve** anaesthesia ↓ pain + opiates |
| **Moderate** | **Diabetes** ↑ complications · **neuraxial** anaesthesia improves perioperative outcomes + complications |
| **Limited** | ✓ **Hepatitis C / cirrhosis ↑ complications** |

## 3 Presentation

**History** — multiply operated knee · prior infection

**Symptoms** — persistent knee pain · **persistent drainage beyond 7 days** (early post-op period)

**Exam** — wound breakdown · erythema · warmth · drainage · **peri-incisional eschar**

## 4 Diagnosis & Classification

### Key radiology findings

| Test | Role |
|---|---|
| **Aspiration** | Exclude **deep infection** before wound surgery |
| **Radiographs** | Help rule out deep infection — look for **bone resorption** |
| **Bone scan** (radionuclide) | Infection suspected but **aspiration + serology not confirmatory** |
| **Angiography** | **Sural artery flow** in question **before gastrocnemius flap** |

## 5 Management

```
TKA wound complication
├─ Small superficial wound / not a surgical candidate → local wound care ± antibiotics
├─ Proximal necrosis over patella → local wound care + SKIN GRAFT
└─ Full-thickness necrosis → debridement + rotational flap
       ├─ Anterior / medial (patellar tendon, tubercle) → MEDIAL GASTROCNEMIUS
       └─ Lateral defect → LATERAL GASTROCNEMIUS
```

### Operative criteria – incision planning

| Rule | Value |
|---|---|
| Skin bridge between incisions | **>5–6 cm** |
| Crossing a previous incision | Never at an angle **<60°** |
| Which old incision | ✓ **Most lateral** usable — anterior knee superficial supply mainly from **medial geniculates** |

### Soft tissue coverage - gastrocnemius flap

**Exposed patellar tendon after superficial debridement, aspiration negative** → ✓ **medial gastrocnemius flap + skin graft**\
✗ Wrong options: split-thickness graft alone · wet-to-dry Dakin's · VAC to secondary intention · latissimus free flap

**Ries** — necrosis over **patella** → local care + **skin graft** · over **tibial tubercle / patellar tendon** → ✓ **muscle flap** (prevents extensor mechanism disruption + deep infection) · all TKAs salvaged

**Flap artery** — medial gastrocnemius = ✓ **medial sural artery** · lateral gastrocnemius = **lateral sural artery**\
✗ Wrong options: inferomedial geniculate (medial plateau + patella) · recurrent anterior tibial (patellar anastomosis) · profunda femoris (thigh) · descending branch of circumflex femoral (joins patellar anastomosis, not below knee)

**Reach** — proximally based → rotates up to **15 cm above the joint line** · low failure rate

**Muscle flap types (Markovich)** — **prophylactic** (before reconstruction) · **treating** (infected prosthesis, deficient cover — least successful) · **salvage** (early dehiscence / necrosis)

## 6 Complications

### Haemarthrosis – commonest early complication (TO)

**Commonest post-op complication of knee arthroplasty** → ✓ **haemarthrosis** (TO) · a little over **1%** · esp. after **lateral retinacular release** or **liberal synovectomy**\
✗ Wrong options: infection · compartment syndrome · tourniquet palsy

**Wound complication sequelae** — deep infection · extensor mechanism disruption (exposed tendon) · ↑ reoperation + cost

## X vs Y

| | **Medial gastrocnemius flap** | **Lateral gastrocnemius flap** |
|---|---|---|
| Artery | **Medial sural** | **Lateral sural** |
| Defect covered | **Anterior + medial** (patellar tendon, tubercle) | **Lateral** |

| Test ordered | What it assesses |
|---|---|
| TLC, albumin, prealbumin, transferrin | **Nutrition** |
| ESR, CRP | Inflammation / infection |
| Complement, immunoglobulins | Immune status |
| Hb, Hct, RBC | Anaemia |

## How it's asked

**"Exposed patellar tendon after debridement of TKA skin necrosis — next?"** → **medial gastrocnemius flap + skin graft**\
✗ Wrong options: STSG · VAC · Dakin's · latissimus

**"Artery of the rotational flap for distal medial necrosis?"** → **medial sural artery**

**"Comorbidity most associated with early wound complication needing surgery?"** → **type 2 diabetes**\
✗ Wrong options: arthroscopy · aspirin · BMI 31 · tourniquet 70 min

**"BMI >40 effect on TKA?"** → **more post-op radiolucent lines**

**"Active smoker vs non-smoker after TKA?"** → **higher readmission risk**

**"Purpose of TLC + prealbumin for chronic TKA wound?"** → **assess nutrition status**

**"AAOS 2016 statement WITHOUT strong recommendation?"** → **hepatitis C / cirrhosis ↑ complications** (limited)

**"Commonest post-op complication of knee arthroplasty?"** → **haemarthrosis** (TO)

**"Multiple previous incisions — which to use?"** → **most lateral; bridge >5–6 cm; cross at ≥60°**
