# TKA Instability

*Recon · 45 / 65*

## 1 Basics

**Epidemiology** — common cause of **early** TKA failure · **10–20%** of revisions · causes: ligament dysfunction, component malposition, poly wear

**Types** — **extension (varus-valgus)** · **flexion (AP)** · **mid-flexion** · **genu recurvatum** · **global, multiply operated**

### Valgus TKA instability (TO)

**Most common complication of valgus TKR** — ✓ **tibiofemoral instability** (TO)\
✗ Wrong options: peroneal palsy · maltracking · recurrent valgus (second)

| Valgus TKR complication (TO) | Rate |
|---|---|
| **Tibiofemoral instability** | **2–70%** |
| **Recurrent valgus** | **4–38%** |
| Stiffness needing MUA | 1–20% |
| Wound problems | 4–13% |
| Patellar stress fracture / ON | 1–12% |
| Patellar tracking | 2–10% |
| **Peroneal palsy** | **1–4%** |

## 3 Presentation

**History** — prior operations · original implant · connective tissue / inflammatory disease · DM, **Charcot** · trauma

**Exam** — **varus/valgus thrust** in gait · laxity through ROM · ✓ **flexion instability test = posterior sag at 90°** · strength · extensor competence · patellar tracking

**Flexion instability symptoms** — instability **without frank giving way**, worst **descending stairs** · **recurrent (often bloody) sterile effusions** · diffuse **peripatellar + pes anserinus** tenderness (anterior soft-tissue strain) · quad weakness

## 4 Diagnosis & Classification

### Key radiology findings

| View | Assesses |
|---|---|
| **Weight-bearing AP** | Joint-line symmetry |
| **Full-length AP** | Mechanical alignment |
| **Lateral** | **Tibial slope**, **tibial subluxation**, recurvatum |
| **CT** | **Component rotation** |

| Instability | Radiographic cause |
|---|---|
| **Extension** | **Excess distal femoral resection** · oversized femoral component |
| **Flexion** | **Over-resected posterior condyles** · **undersized femur** · **↑ tibial slope** |
| **Mid-flexion** | **Anterior or proximal femoral component** (joint-line change) |

### Genes & lab markers

**Rule out infection** — CBC, ESR, CRP + **aspiration** (cell count, culture) · bloody aspirate with negative markers fits flexion instability

## 5 Management

### Extension (varus-valgus) instability

| Type | Cause | Treatment |
|---|---|---|
| **Symmetric** | **Excess distal femoral resection** → flexion/extension mismatch | **Distal femoral augments** · **upsizing poly fails** (tightens both gaps) |
| **Asymmetric** (commoner) | Uncorrected coronal deformity / ligament imbalance | Release contracted side · ligament insufficient → **VVC (varus-valgus constrained)** |

### MCL injury & constraint

**MCL injury causes** — medial retractors · subperiosteal elevation (tibial sleeve avulsion) · **saw** during tibial / posterior condylar cut

**Intra-op midsubstance MCL transection** → ✓ **suture repair + CR or PS implant + hinged brace 6 wk** · alternative **unlinked constrained (CCK)** ± repair\
✗ Wrong options: CR/PS without repair · PS + immobilizer · hinge (not for simple collateral rupture)

**Hinge indications** — moderate–severe instability · **absent collateral(s)** · severe bone loss · large deformities

**Charcot knee (diabetic)** — excellent ROM, **ligamentous laxity** + bone loss → ✓ **semiconstrained prosthesis prevents instability** · augments for bone loss\
✗ Wrong options: stiffness (not a problem)

### Flexion instability & gap mismatch

**Definition** — **flexion gap > extension gap** · PS knee can **"jump the post"** → dislocation

**Femoral cam jump (TO)** — **specific to PS knees** · ✓ **loose flexion gap** · varus/valgus stress in flexion opens gap → cam rotates in front of post · **popliteus over-release** may cause · closed reduction: **90° flexion + anterior drawer** (clunk) · definitive: **revision** (TO)\
✗ Wrong options: tight flexion gap

**Loose flexion gap, normal extension gap (PS)** → ✓ **posterior knee dislocation** (cam locked behind/in front of post)\
✗ Wrong options: MUA · hyperextension (loose extension gap) · anterior dislocation · patella fracture (<13 mm patella)

**Recurrent dislocation of PS mobile-bearing revision** → ✓ **loose flexion gap** (undersized / anteriorised femur, excess distal augmentation, collateral + posterior capsule insufficiency)\
✗ Wrong options: loose extension gap (V/V instability) · malrotation (patellar/rotational) · design

**Popliteus injury** — popliteus = **flexion stabiliser** · cut while resecting **posterolateral femoral condyle** → flexion laxity → PS dislocation\
✗ Wrong options: too little slope · posterior femoral translation · over-recessed PCL (PCL usually removed in PS) · joint line

### Femoral cuts & flexion gap

| Cut | Effect |
|---|---|
| **Anterior** | Does not affect flexion gap · under-resect → oversize → **PF stuffing** · over-resect → **notching** · good cut = "grand piano" |
| **Posterior condylar** | ✓ **Sets flexion gap** · over-resection → **flexion instability** (line 2) |
| **Anterior / posterior chamfers** | Fit only |
| **Distal femoral** | **Sets extension gap** · = component thickness · extra for flexion contracture |
| **Tibial slope** | ↑ slope → **↑ flexion gap** (line 5) |

**Flexion instability in PS knee** — **anterior tibial translation at 90°** pathognomonic · no posterior subluxation (cam-post)

**Flexion instability causes (OB)** — ↑ posterior femoral resection · **under-resected distal femur** (joint line distalised) · **excess tibial slope** · PCL incompetence (CR)

| Cause | Fix |
|---|---|
| **Over-resected posterior condyles** | **Posterior femoral augments** |
| **Undersized femur** | **Upsize femoral component** |
| **Excess tibial slope** | **↓ slope** + consider **PS** |
| **PCL insufficiency after CR** | **Convert to PS** |

**Flexion instability revision (to PS)** → ✓ **additional distal femoral resection + posterior femoral augments + upsize poly**\
✗ Wrong options: downsize femur + distal augments + thinner poly · ER tibial tray + thicker poly · isolated thicker poly (over-tightens extension) · IR tray + ↑ slope

**Non-op** — quad strengthening, bracing · revision for flexion instability shows **least improvement** of any revision indication

**CR knee, instability on stairs, effusions, posterior tibial subluxation** → ✓ **PCL insufficiency**\
✗ Wrong options: patellar tendon rupture (no active extension) · joint line · ACL (sacrificed) · loosening

### Mid-flexion instability

**Features** — poorly understood · **joint-line modification** (elevation) · instability/malrotation between **45–90°** · contributors: sagittal femoral design, **anterior MCL attenuation**, tibiofemoral geometry

**Joint-line elevation threshold (TO, FNB 2024)** — options >2 / >4 / >6 / >8 mm · **answer not provided by the source** · Orthobullets: elevation **>8 mm** → motion problems incl. mid-flexion instability (TKA axial alignment)

**Treatment** — usually **full revision** · restore joint line · equalise gaps

### Genu recurvatum

**Associations** — **poliomyelitis** (quad weakness → walks locked in hyperextension, ankle equinus) · **RA** · **Charcot** · fixed valgus + ITB contracture

**Treatment** — **long-stemmed PS or VVC** · **rotating hinge = salvage** (residual hyperextension → early failure)

### Global, multiply-operated instability

**Features** — flexion + extension + V/V laxity · bone loss · recurvatum gait

**Treatment** — **VVC minimum** · usually **hinge** ± augments, sleeves, cones · **endoprosthesis** if severe bone loss

### Component malrotation

**Valgus knee, femur IR 8°, tibia IR 4°, dislocated patella + coronal instability** → ✓ **revise femoral + tibial components** into ER\
✗ Wrong options: PT · brace · thicker liner · lateral release

## X vs Y

| | **Flexion instability** | **Extension (V/V) instability** | **Mid-flexion** |
|---|---|---|---|
| Gap | Flexion > extension | Extension loose | 45–90° |
| Cause | Posterior condyle over-resection, small femur, ↑ slope, PCL loss | Excess distal cut (symmetric) · imbalance (asymmetric) | Joint-line elevation |
| Fix | Posterior augments, upsize femur, ↓ slope, PS | Distal augments · release · VVC | Revision, restore joint line |
| Thicker poly alone | No (over-tightens extension) | No (symmetric) | — |

## How it's asked

**"Femoral cam jump — EXCEPT?"** → **associated with tight flexion gap** (TO)

**"CR TKA, instability on stairs, posterior tibial subluxation?"** → **PCL insufficiency**

**"PS TKA, anterior translation at 90° — over-resection at?"** → **posterior femoral condylar cut (line 2)**

**"PS mobile-bearing revision, recurrent dislocation?"** → **loose flexion gap**

**"Loose flexion gap, normal extension gap (PS) — risk?"** → **posterior knee dislocation**

**"Medial + lateral laxity at 90°, bloody negative aspirate — which cut?"** → **excess posterior tibial slope (line 5)**

**"Flexion instability revision to PS — additional strategy?"** → **more distal femoral resection + posterior augments + thicker poly**

**"Intra-op MCL transection, coronal instability?"** → **suture repair + PS implant + hinged brace**

**"Charcot knee — semiconstrained prosthesis prevents?"** → **instability**

**"PS knee dislocation on lateral X-ray — cause?"** → **popliteus injury cutting posterolateral condyle**

**"IR femur 8°, tibia 4°, dislocated patella?"** → **revise femoral and tibial components**

**"Most common complication of valgus TKR?"** → **tibiofemoral instability** (TO)
