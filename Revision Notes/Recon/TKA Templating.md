# TKA Templating

*Recon · 61 / 65*

## 1 Basics

**Definition** — anticipating implant **size + position** pre-op · predicts sizes needed in OR · reliable starting point

**Accuracy** — **manual 92–100%** within ± one size · **automatic only 51%**

**Steps** — radiographs → analysis → check **scale (20% magnification)** → femur → tibia

## 4 Diagnosis & Classification

### Key radiology findings

| View | Role |
|---|---|
| **AP weight-bearing knee** | Required · bony defects + osteophytes easiest here |
| ✓ **Lateral knee** | **Most important view for templating** · slope, patellar height |
| **Patellofemoral (sunrise)** | Not needed for templating · tilt/shift |
| **Full-length hip-to-ankle WB AP** | Optional · rule out **extra-articular deformity**, coronal laxity, plan cuts vs mechanical axis |

### Radiographic analysis

| Step | Assessment |
|---|---|
| **1** | **Mechanical axis** (hip-to-ankle) — neutral bisects knee centre |
| **2** | Coronal deformity — **tibiofemoral angle** |
| **3** | **Femoral resection (valgus cut) angle** = mechanical vs anatomic femoral axis |
| **4** | **Tibial cut** ⊥ mechanical axis |
| **5** | Bony defects + osteophytes (AP) |
| **6** | **Tibial slope** (lateral) |
| **7** | **Patellar height** (lateral) — **baja** → harder exposure |
| **8** | Patellar shift/tilt (skyline) |

![Valgus cut angle](../../Orthobullets/attachments/ob12303-valgus-cut-angle.jpg)

### Alignment strategies

| | **Mechanical alignment** | **Kinematic alignment** |
|---|---|---|
| Goal | Neutral axis **0 ± 3°** | Restore pre-arthritic joint line + kinematics |
| Femur | ⊥ femoral mechanical axis (**5–7° valgus** to anatomic) | Cylindrical axis of posterior condyles · **0.7–1.8° more valgus** |
| Tibia | ⊥ tibial mechanical axis (0°), avoid accidental varus | Pre-arthritic joint line · **1.2–2.2° more varus** |
| Slope | — | Native · ~**1.2° more** |
| Rotation | **TEA** or **3° ER** to posterior condyles | — |
| Soft tissue | Releases anticipated for rectangular gaps | Few/no releases · equal medial/lateral resections |

## 5 Management

### Template the femur

**Size on lateral** — restore **posterior condylar offset** · avoid **notching**

**AP** — ML position, no overhang (overhang → consider downsizing)

**Pitfall** — ✓ **oversizing the femur** · femur **less accurate** than tibia

### Template the tibia

**Size on lateral** — no overhang · match native slope · confirm on AP

**Pitfall** — **equally likely to over- or undersize** · intra-op tendency to **downsize**

![Tibial template — lateral](../../Orthobullets/attachments/ob12303-tibial-template-lateral.jpg)

### Extra-articular deformity

**Healed femoral fracture with hardware, mechanical axis ~3° valgus, 14° deformity not affecting joint** → ✓ **routine knee prosthesis** · avoid hardware removal with **extramedullary jigs / navigation**\
✗ Wrong options: custom components · special IM jigs · hinge · osteotomy (only for severe deformity)

## X vs Y

| | **Femoral templating** | **Tibial templating** |
|---|---|---|
| Accuracy | Lower | Higher |
| Error | **Oversizing** | Over = under · surgeons downsize |

## How it's asked

**"Prior femoral fracture, axis 3° valgus — restore mechanical axis with?"** → **routine knee prosthesis**

**"Most important view for TKA templating?"** → **lateral knee**

**"Manual vs automatic templating accuracy?"** → **92–100% vs 51% (± one size)**
