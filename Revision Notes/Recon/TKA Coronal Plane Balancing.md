# TKA Coronal Plane Balancing

*Recon · 41 / 65*

## 1 Basics

**Principle** — **concave side = tight → release** · **convex side = stretched → tighten** (fill gap with thicker poly) · always test in **flexion and extension**

**Epidemiology** — **>85%** of TKA patients neutral or varus · valgus = more complex

**Kinematic alignment** — implants in patient's constitutional varus/valgus · outcomes ≈ neutral mechanical alignment

![Coronal balancing — concave vs convex](../../Orthobullets/attachments/ob5015-coronal-balancing.jpg)

### Posterior oblique ligament function

| Structure | Primary role | Secondary |
|---|---|---|
| **POL** | ✓ **Resists internal rotation** | Valgus, external rotation |
| **Superficial MCL** | **Valgus** | Valgus + IR combined |
| **Deep MCL** | Released in standard approach | — |
| **LCL** | **Varus** | — |
| **LCL + posterolateral release** | → **external rotation laxity** | — |

\
✗ Wrong options: POL resists flexion

## 5 Management

### Medial release sequence (varus knee)

| Step | Orthobullets | TO (FNB 2022) |
|---|---|---|
| **1** | **Deep MCL** release to mid-coronal plane of tibia | Deep MCL + posteromedial capsule from tibia + osteophytes |
| **2** | **Medial osteophytes** | **POL** |
| **3** | **Posteromedial corner (POL)** | **Semimembranosus** (+ transect PCL if preserved) |
| **4** | **Medial tibial reduction osteotomy** | **Pie-crust superficial MCL** + release **pes anserinus** |
| **5** | **PCL release / substitution** if imbalance persists | Strip periosteum + sMCL off tibia distally **4–5 cm** |
| **6** | **Semimembranosus** (esp. with flexion contracture) | — |
| **7** | **Pie-crust superficial MCL** (**18-gauge needle**) | — |
| **8** | Complete **sMCL / pes** release — rarely needed · destabilises medial flexion gap → **constrained prosthesis** | — |

**Differential sMCL release** — **posterior (oblique) portion tight in extension** · **anterior portion tight in flexion**

**Extension vs flexion space (TO)** — posterior structures (**POL → posterior capsule → semimembranosus**) affect ✓ **extension** space · **anterior half of sMCL + pes anserinus** affect **flexion** space (TO)

**Tight medial in extension, flexion balanced (FFD 15°)** → ✓ **release POL** (TO)\
✗ Wrong options: sMCL · pes · PCL

**Pie-crusting** — ✓ **soft-tissue balancing in TKR** (TO) · multiple stabs with blade/needle **parallel to joint line** on contracted side · titrated lengthening of varus or valgus sleeve\
✗ Wrong options: syndesmosis · deltoid · bone cuts

**Lateral side (varus knee)** — fill gap to tension stretched lateral ligaments · **poly >15 mm needed → constrained** (avoid joint-line elevation)

**Blount's varus 25° with thrust** → ✓ **constrained implants may be needed** (posteromedial bone loss + extensive posteromedial releases)\
✗ Wrong options: peroneal palsy common (that is valgus) · arthrodesis · lateral reefing (attenuates) · TKA then osteotomy

### Valgus knee (lateral release, popliteus, peroneal nerve)

**Valgus pathology** — ✓ **lateral femoral condyle hypoplasia** · tight lateral retinaculum, LCL, posterolateral corner, ITB · **attenuated MCL** · **lateral patellar tracking** · **tibial external rotation** relative to femur\
✗ Wrong options: tibial IR · medial tracking · tight MCL

| Order | Lateral release (Orthobullets) | Lateral release (TO) |
|---|---|---|
| **1** | **Osteophytes** | Lateral osteophytes + posterolateral capsule |
| **2** | **Posterolateral capsule** | **PCL always released** |
| **3** | **ITB** if **tight in extension** (pie-crust or off Gerdy's) | Pie-crust ITB (extension) at joint line or at Gerdy's |
| **4** | **Popliteus** if **tight in flexion** (anterior part of insertion) | Strip LCL + popliteus (flexion) off LFC |
| **5** | **LCL** (some release first if tight in flexion + extension) | Lateral gastrocnemius + posterolateral capsule off femur |

| Tight | Release |
|---|---|
| **Extension only** | **Iliotibial band** |
| **Flexion only** | ✓ **Popliteus** (anterior portion) → ↑ **lateral flexion space** (tibia max IR in flexion → popliteus tightest) |
| **Flexion + extension** | **LCL** |
| **LCL + popliteus both released** | Flexion gap unstable → **constrained prosthesis** |

**Balanced in extension, lateral tight in flexion** → ✓ **release anterior popliteus**\
✗ Wrong options: pie-crust ITB (extension) · PCL recession (medial flexion) · LCL (instability → constraint) · semimembranosus (medial extension)

**Medial side (valgus)** — fill until MCL taut · poly **>15 mm** (OB: >14 mm) → **constrained** · CCK / CPS for longstanding deformity

**Femoral rotation trap** — hypoplastic LFC + **posterior referencing** → ✓ **femoral component IR** → PF maltracking + asymmetric flexion gap · check against **epicondylar + AP (Whiteside) axes**\
✗ Wrong options: angulation (IM guide controls) · exposure (easier in valgus) · flexion · tibial rotation

**Severe valgus (≈45°) — IM femoral entry point (TO, FNB 2024)** — options more lateral / medial / superior / standard · answer not provided for this item · another TO explanation (FNB 2023): entry point in a valgus knee is usually ✓ **more medial** than standard (TO)

### Femoral component rotation

**Posterior condylar axis** — normally **3° IR** relative to TEA / tibial joint line → cutting block has **3° ER** built in

**Valgus with hypoplastic LFC** — posterior condylar angle **>3°** (e.g. **9°**) → standard 3° guide leaves **6° IR** → ✓ **add 6° more ER**\
✗ Wrong options: 0° guide → 9° IR · upsize · IR 6° vs TEA · rotate tibia

### Peroneal nerve palsy

**Highest risk** — correction of **valgus + flexion contracture**

| Risk factor | Mechanism |
|---|---|
| **Valgus >12°** | Stretch beyond tolerance |
| **Flexion contracture >10°** | Stretch → ischaemia |
| **Lumbar laminectomy** | **Double crush** |
| **Epidural anaesthesia** | ↓ proprioception → unprotected compression |
| ✗ Wrong option: **female gender** | **Not a risk factor** |

**Palsy in recovery** — remove dressing, **flex knee** · observe **3 months** · then NCS / exploration · explore at **posterior border of biceps femoris**

**Severe valgus (>15°) + FFD** → ✓ **prophylactic CPN release** — fascial septum between **peroneus longus + EDL** (anterior/lateral compartments, below knee)\
✗ Wrong options: MCL pie-crust (varus) · less distal femur (resect more for FFD) · medial opening HTO (worsens valgus) · CR implant (needs more constraint)

### Flexion contracture

| Order | Posterior release |
|---|---|
| **1** | **Posterior femoral + tibial osteophytes** |
| **2** | **Posterior capsule** (stripped short distance from condyles) |
| **3** | **Additional distal femoral resection** (raises joint line → mid-flexion instability; try soft tissue first) |
| **4** | **Gastrocnemius origins** (medial + lateral) |

**Releases at 90° flexion** — popliteal artery falls posteriorly · do not remove **more tibia** for contracture → changes joint line → **patella alta**

### Extra-articular deformity & constraint

**>20° coronal deformity** — ✗ Wrong options: correctable with cuts + balancing → ✓ **extra-articular osteotomy** (staged or concomitant)

**Femoral varus 28° after old distal femur fracture** → ✓ **distal femoral lateral closing-wedge osteotomy**\
✗ Wrong options: cuts + balancing · medial closing wedge (worsens varus) · HTO (wrong bone) · hinged TKA

![Femoral extra-articular deformity correction](../../MCQ/attachments/q210157-illa-screen-shot-2018-04-07-at-10-41-50-pm.jpg)

### Kinematic alignment

**Varus knee, kinematic** → ✓ **varus tibial cuts + valgus femoral cuts** · equal aseptic loosening, satisfaction equal/better, ROM equal/greater, same reoperation\
✗ Wrong options: ↑ loosening · ↓ satisfaction · ↓ ROM · ↑ reoperation

## X vs Y

| | **Varus knee** | **Valgus knee** |
|---|---|---|
| Tight side | **Medial** | **Lateral** |
| Bone deficiency | Posteromedial **tibia** (tibia-driven) | **Lateral femoral condyle** (femur-driven) |
| Key error | — | **Femoral IR** with posterior referencing |
| Nerve risk | Low | **Peroneal palsy** |
| Release for flexion tightness | Anterior sMCL, pes | **Popliteus** |
| Release for extension tightness | POL, posterior capsule, semimembranosus | **ITB** |

## How it's asked

**"Peroneal palsy risk factors — EXCEPT?"** → **female gender**

**"Isolated popliteus release appropriate when?"** → **valgus knee tight in flexion**

**"Severe valgus — pathology encountered?"** → **lateral femoral hypoplasia**

**"Valgus knee, IM femoral guide, posterior referencing — watch for?"** → **femoral component rotation**

**"Popliteus release — effect?"** → **increases lateral flexion space**

**"Balanced in extension, lateral tight in flexion?"** → **release anterior popliteus**

**"Valgus + 15° FFD — consider?"** → **release fascial septum between peroneus longus and EDL**

**"3° ER guide off posterior condyles left IR femur — prevention?"** → **add 6° more ER**

**"28° femoral varus deformity?"** → **distal femoral lateral closing-wedge osteotomy**

**"Blount's varus TKA — true?"** → **constrained implants may be needed**

**"Kinematic alignment in varus knee?"** → **varus tibial + valgus femoral cuts**

**"POL primary function?"** → **resists internal rotation**

**"Soft-tissue balancing — true?"** → **tight extension space: release posterior capsule then semimembranosus** (TO)

**"Pie-crusting used for?"** → **soft-tissue balancing in TKR** (TO)

**"FFD 15°, medial tight in extension, flexion balanced — release?"** → **POL** (TO)
