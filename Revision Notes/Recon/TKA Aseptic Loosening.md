# TKA Aseptic Loosening

*Recon · 39 / 65*

## 1 Basics

**Definition** — **macrophage-induced inflammatory** bone loss → implant loosening **without infection**

**Epidemiology** — ✓ **most common mode of long-term (>2 yr) TKA failure** · HXLPE has ↓ wear failures but loosening persists

**Steps** — **particulate debris formation** → **macrophage-activated osteolysis** (RANKL → osteoclasts) → **prosthesis micromotion** → **debris dissemination**

### Osteolysis & prevention

**Factors affecting PE wear rate** — **sterilization method** (gamma in air ↑) · manufacturing (conventional vs cross-linked) · **shelf life** (prolonged ↑) · third-body debris · **backside wear** (modular insert on metal tray) · femoral counterface roughness · **alignment + stability** · **activity level**

**Malalignment** — asymmetric loading → early loosening · ✓ **varus more than valgus**

| ↓ Osteolysis | ↑ Osteolysis |
|---|---|
| ✓ **All-polyethylene tibial component** (no backside wear) | Metal tray + **modular PE insert** (backside wear) |
| **HXLPE** | Avoiding HXLPE |
| Congruent PE | **↓ congruency** → sliding → adhesive wear |
| Less constraint | **↑ constraint** (VVC) → ↑ stress at articulation |

![All-polyethylene tibial component](../../MCQ/attachments/q215497-illa-all-polyethylene-tibial-component.jpg)

### Early cement debonding

**Weak link** — ✓ **implant–cement interface** (more common than bone–cement)

**↑ Risk** — ✓ **ROM + ligament stability testing before cement fully cures** (↓ tibial tray pull-out strength) → tibial tray loosening with **varus collapse**

**Prevention (✗ Wrong options: as risk factors)** — **fresh gloves** before handling implants (lipid) · **suction + dry bone surface** · cement on **both implant undersurface and bone** · **roughened** tray undersurface (✗ Wrong options: smooth polished) · let cement fully cure

## 3 Presentation

**Symptoms** — painless early · later pain localised around loose component · **weight-bearing / activity related**

**Exam** — minimal pain with ROM · ↑ pain with weight bearing · effusion possible

## 4 Diagnosis & Classification

### Key radiology findings

| View | Use |
|---|---|
| **AP** | **Tibial osteolysis** readily seen · **femoral osteolysis hard to see** (posterior condyles hidden by component) |
| **Lateral** | Routine |
| **Oblique** | ✓ **Best for femoral osteolysis** |
| **CT / MRI** | Size large lesions for pre-op planning |

**Findings** — radiolucency with **sclerotic border**, especially **>2 mm** · implant position change (**varus/valgus tibial subsidence**) · **progressive widening** of cement–bone / bone–prosthesis interface · **cement cracking / fragmentation**

![Femoral and tibial osteolysis](../../Orthobullets/attachments/ob12754-latos.jpg)

### Genes & lab markers

**ESR + CRP normal** · always exclude **PJI** first

**Osteolysis vs others** — effusion, near-normal ESR, normal CRP, lytic lesions, no loosening → ✓ **osteolysis**\
✗ Wrong options: infection · aseptic loosening (no loosening signs) · PE dislodgement (locking mechanism intact) · crystal (doesn't explain lysis)

## 5 Management

```
Painful TKA, suspected loosening
├─ Rule out PJI (ESR, CRP, aspirate)
├─ Stable implant, minimal symptoms → observe
└─ Pain + loosening / osteolysis → revise all loose components
       ├─ Defect >10 mm, young → bone graft
       ├─ Defect >10 mm, elderly low demand → metal wedges/augments
       └─ Small defect → cement
```

### Revision indications

**Revise** — pain due to aseptic loosening · pain + osteolysis · **extensive osteolysis that would compromise future revision**

**Observe** — stable implant, minimal symptoms

| Defect | Fill |
|---|---|
| **>10 mm, younger** | **Bone graft** (preserves bone stock) |
| **>10 mm, elderly / low activity** | **Metal wedges / augments** |
| **Small** | **Bone cement** (heat → thermal necrosis → can cause loosening) |

## X vs Y

| | **Osteolysis** | **Aseptic loosening** | **PJI** |
|---|---|---|---|
| Implant | Fixed | **Loose / subsided** | Variable |
| Labs | Normal | Normal | ↑ ESR, CRP |
| Treatment | Observe or liner exchange + graft | **Revise loose parts** | Two-stage / DAIR |

## How it's asked

**"7 yr TKA, effusion, CRP normal, lytic lesions, no loosening?"** → **osteolysis**

**"Reduces osteolysis risk?"** → **all-polyethylene tibial component**

**"Tibial tray varus collapse at 3 yr — technical risk?"** → **ROM/stability testing before cement fully cures**

**"Best view for femoral osteolysis?"** → **oblique** (AP misses posterior condyles)

**"Most common weak link in cemented TKA?"** → **implant–cement interface**
