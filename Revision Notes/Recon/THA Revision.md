# THA Revision

*Recon · 32 / 65*

## 1 Basics

### Epidemiology

**Volume** — US revisions projected **>100% ↑ by 2030** · ~equal sex · age **65–70**

**Causes** — overall + after 2 yr: **mechanical failure** (aseptic loosening) · **early (<2 yr): infection, periprosthetic fracture**

**Indications** — wound problems · periprosthetic/implant fracture · instability · **PJI** · ALTR (MoM) · trunnionosis · osteolysis · aseptic loosening · LLD

**Charnley LFA (1962, 22 mm head, cemented)** — **11.8% revised at 30 yr** · ✓ **acetabular failure most common** reason (> deep infection > fracture; acetabular > femoral) · acetabular exchange = commonest Charnley revision

### Categories

| Category | Examples |
|---|---|
| **No component change** | Wound closure · **psoas release** · **HO excision** · ORIF fracture with stable implants |
| **Modular only** | **Head ± liner exchange** · titanium sleeve |
| **Non-modular** | **Cup** or **stem** exchange · both · spacer · Girdlestone |

### Sciatic nerve risk (TO)

**Nerve palsy rates** — primary OA **0.5%** · DDH **2.3%** · ✓ **revision 3.5% (highest)** · risk factors: DDH, post-traumatic, posterior approach, cementless, **revision**, female, lengthening

## 3 Presentation

| Symptom | Suggests |
|---|---|
| **Groin pain** | Acetabular problem |
| **Thigh pain** | Femoral stem |
| **Start-up pain** | Component loosening |
| **Night pain** | Infection |
| No improvement after surgery | Wrong diagnosis |

**Stem subsidence** — stems subside into **retroversion** → ✓ **limb externally rotated**\
✗ Wrong options: IR · flexion contracture

**Resisted hip flexion pain** — psoas impingement

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP pelvis · orthogonal hip views · **full-length femur** · prior/immediate post-op films · **Judet views** (columns, discontinuity)

**CT** — ✓ **osteolysis extent** (X-rays **underestimate**) · pre-op planning, discontinuity · **CT angiogram for Paprosky IIIB ("up and in")** — iliac vessel relation ✓

**Labs** — ESR, CRP, CBC · Co/Cr (trunnionosis, pseudotumour) · aspirate if labs suggest infection · ✓ **↑ ESR + CRP precludes single-stage revision without further work-up**\
✗ Wrong options: ↑ cobalt · metallosis · high Co:Cr · pseudotumour

**Lysis around stable cup, normal labs** → ✓ **CT** (Judet) to plan · failed cup with bone loss → ✓ **CT** to plan and detect discontinuity\
✗ Wrong options: bone scan · aspiration · ions · dynamic fluoroscopy

### AAOS acetabular bone loss

| Type | Defect |
|---|---|
| **I** | **Segmental** — rim or medial wall |
| **II** | **Cavitary** — volumetric loss |
| **III** | **Combined** |
| **IV** | **Pelvic discontinuity** |
| **V** | ✓ **Arthrodesis** (TO) |

### Paprosky acetabular bone loss

| Type | Description | Typical reconstruction |
|---|---|---|
| **I** | Minimal deformity, **intact rim** | Hemispherical cup + screws |
| **IIA** | Superior (± medial) lysis, **intact superior rim** | Cup + screws |
| **IIB** | **Absent superior rim**, superolateral migration (<3 cm) | Cup + screws ± jumbo/augment |
| **IIC** | **Localized medial wall** destruction | Cup / jumbo + screws + morsellized graft |
| **IIIA** | Rim loss **10 → 2 o'clock**, **"up and out"** (>3 cm superolateral) | **Porous cup + metal augments** + graft |
| **IIIB** | Rim loss **9 → 5 o'clock**, **"up and in"** (superomedial), **Köhler line broken**, discontinuity | **Cup-cage**, **custom triflange**, structural graft |

**Type II vs III (TO)** — hip centre migration **<3 cm vs >3 cm** · II has supportive columns (≥50% host contact), III lacks them

|---|---|

### Paprosky femoral bone loss

| Type | Description | Treatment |
|---|---|---|
| **I** | Minimal metaphyseal loss | **Primary components** |
| **II** | Extensive metaphyseal, **intact diaphysis** | **Extensively porous-coated long stem** |
| **IIIA** | Metadiaphyseal loss, **≥4 cm intact isthmus** | **Extensively porous-coated (cylindrical) stem** · modular tapered |
| **IIIB** | Metadiaphyseal loss, **<4 cm isthmus** | ✓ **Modular fluted tapered stem** · extensively coated (if canal **<19 mm**) · **impaction grafting** · APC |
| **IV** | **Non-supportive diaphysis** (no isthmus) | **Impaction grafting**, **APC**, **EPR / PFR**, long cemented |

**TO (FNB 2014)** — <4 cm diaphysis → ✓ **IIIB: extensively porous-coated tapered stem + impaction grafting**\
✗ Wrong options: IIIA · II · IV/APC

## 5 Management

```
Revision THA planning
├─ Exclude infection (ESR/CRP → aspirate) → if PJI, staged
├─ Well-fixed, well-positioned cup + wear/lysis → head + liner exchange ± graft
├─ Acetabulum: ≥50% host support → porous cup/jumbo + screws ± augments
│      └─ Discontinuity / <50% → cup-cage, triflange, column plating
└─ Femur: Paprosky I → primary · II/IIIA → extensively coated · IIIB → tapered fluted · IV → PFR/APC
```

### Acetabular reconstruction

**Porous hemispherical / jumbo cup + screws** — needs **≥50% host bone** · cup **inferior + medial** (↓ JRF) · cavitary defects → particulate graft · ✓ **most reliable long-term** for Paprosky II · jumbo may compromise posterior column, dislocation\
✗ Wrong options: cemented all-PE (high failure) · cage · bilobed · bipolar in acetabulum (pain, erosion)

**Paprosky IIC (medial wall), ≥50% stock, no discontinuity, normal centre** → ✓ **jumbo cup + screws + morsellized graft** (most stable + cost-effective)\
✗ Wrong options: cage · triflange · spacer · augments

**Paprosky IIB** → ✓ **cementless hemispherical cup + screws**

**Paprosky IIIA (LLD 3.5 cm, Trendelenburg)** → ✓ **porous cup + metal augments + graft + screws** (unitize augment–cup with cement)\
✗ Wrong options: particulate graft alone (IIA/IIB) · triflange (IIIB) · cemented cup (shear failure) · 2-stage

**Augments** — Paprosky **IIB–C, IIIA–B** · survivorship **94–100% (2 yr), 92–100% (5 yr), 92% (10 yr)**

**Reconstruction / antiprotrusio cage + structural graft** — rim **<⅔**, <50% stock · PE cemented into cage · **allograft failure commonest complication** · without cage **40–60% failure** · major bone loss + medial wall penetration → ✓ **reinforcement cage + graft**\
✗ Wrong options: jumbo

**Non-contained bicolumn defects >50% of weight-bearing area** → ✓ **ilioischial reconstruction ring + structural corticocancellous graft** (restores stock)\
✗ Wrong options: morsellized graft + cup · bilobed · roof ring

**Impaction grafting (acetabulum)** — contained cavitary defects + cemented PE · not for discontinuity

**Cemented cup** — cement liner into a well-fixed shell · **revision cemented cups fail** (shear)

### Pelvic discontinuity & triflange

**Definition** — separation of **superior ilium from inferior ischiopubic** segment · AAOS IV / Paprosky IIIB · acute pain, cannot bear weight (e.g. RA) → ✓ **pelvic discontinuity**

**Principles** — reconnect ilium + ischium · bleeding bone contact with ingrowth surfaces · graft defects · stable construct until ingrowth

| Option | Indication |
|---|---|
| **Column plating + hemispherical cup** | **Acute** discontinuity, minimal bone loss, healing potential |
| **Cup-cage** | Chronic discontinuity, **Gross IV/V** segmental defects · ✓ displaced transverse periprosthetic acetabular fracture with medial migration · ✓ Paprosky IIIB + structural graft |
| **Custom triflange (CTAC)** | Massive bone loss + **chronic discontinuity** · **irradiated** bone · iliac → pubic → ischial flanges, screws ± posterior column plate · ✓ **most common complication: dislocation** |
| **Distraction** | Discontinuity with shell ± augments |
| Bulk allograft + cemented cup | **~50% failure** (resorption, infection) |
| Independent cage alone | **50–60% failure** |

**Triflange chosen because of** — ✓ **pelvic discontinuity** (✗ Wrong options: dislocations · IPD · loosening · Paprosky 2B) · triflange needs posterior/extensile exposure (✗ Wrong options: anterior approach for ischial/iliac flanges) · not a bilobed cup

**Paprosky IIIB with discontinuity** → ✓ **custom triflange** or **cup-cage** (✗ Wrong options: cemented cup · multihole cup) · chronic discontinuity after infection cleared (6 months, normal labs) → ✓ **triflange + femoral revision** (✗ Wrong options: new spacer · bulk allograft · cage alone · Girdlestone)

### Osteolysis & isolated liner exchange

**Retain shell + liner exchange + graft lysis** — ✓ **well-designed, well-fixed modular cup** with good locking mechanism and record · lysis via screw holes/dome hole; loosening late\
✗ Wrong options: non-modular · instability · radiolucency · migration

**Indications** — eccentric PE wear with stable components · acute infection · trunnionosis

**Typical answers** — eccentric head + proximal femoral lysis, fixed components → ✓ **synovectomy + liner exchange** (✗ Wrong options: stem/cup revision) · massive cup lysis, ceramic-on-conventional PE, fixed cup → ✓ **liner exchange + grafting + switch head to METAL** (✗ Wrong options: new ceramic head on used taper (fracture; metal sleeve if ceramic wanted)) · lysis around one screw → ✓ **liner exchange + remove screw + debride ± graft** (Beaulé: no lesion recurrence) · retroacetabular lysis with clicking, normal labs → ✓ **head + liner exchange + retroacetabular graft**

**Osteolytic lesions** — may shrink/heal without grafting once wear source removed · grafting optional/controversial

**Complication** — ✓ **dislocation** (11–25%) · use larger head · damaged locking mechanism → cement liner into shell (2–4 mm mantle)

**Ischial lysis with dissociated dome-hole eliminator** → ✓ **wear-induced osteolysis**\
✗ Wrong options: chondrosarcoma · metastasis · corrosion

### Femoral revision

**Primary components** — Paprosky I (no unexpected bone loss)

**Extensively porous-coated long stem** (or porous/grit combo) or **modular tapered** — Paprosky **II, IIIA** (IIIB modular fluted tapered) · **95% survival at 10 yr** · bypass most distal defect by **2 cortical diameters** · cavitary → particulate graft · cortical defects → struts/plates · ✓ superior to cemented revision

**Typical answers** — loose hemi with proximal loss → ✓ **cementless diaphyseal press-fit stem** (✗ Wrong options: bone scan · tumour prosthesis · metaphyseal cement) · IIIA with fracture → ✓ **fully coated cementless + cables + graft** (✗ Wrong options: ORIF · modular · total femur) · start-up pain + subsidence, no defects → ✓ **uncemented long fully porous stem** (✗ Wrong options: cemented · APC · PFR · spacer) · deficient proximal femur with >4 cm isthmus → ✓ **diaphyseal-engaging extensively coated** (✗ Wrong options: standard cemented · proximally coated · PFR · APC) · <4 cm isthmus (IIIB) → ✓ **modular fluted tapered stem** (✗ Wrong options: struts alone · impaction + cementless (impaction needs **cemented** stem) · metaphyseal tapered) · early loosening at 3 months → ✓ **non-modular tapered fluted Ti stem**

**Failed ingrowth signs** — reactive line around porous part · **hypertrophy under collar** · **pedestal** at tip (no stress shielding) → ✓ **revise femoral component**

**Symptomatic loose osteolytic stem** → ✓ **protected WB + urgent (not emergent) revision** when cleared\
✗ Wrong options: reassure · alendronate

**Impaction grafting (femur)** — ectatic canal, thin cortices · **Paprosky IIIB, IV** · morsellized fresh-frozen allograft + **smooth tapered cemented stem** · **subsidence** commonest complication

**APC** — Paprosky **IIIB, IV** · allograft canal slightly larger than host · cement stem into allograft, **press-fit 4–6 cm into host**

**EPR / PFR** — massive loss, **non-supportive diaphysis** · elderly/sedentary · frozen section of osteotomy bone to exclude tumour · distal fixation cemented / compressive osseointegration / press-fit

**Cemented revision stems** — irradiated bone, severe osteopenia, Dorr C · **high failure** · remove old cement, neocortex, sclerotic bone

### Proximal femoral replacement

**Indications** — ✓ **<4 cm diaphyseal cortex** · extensive metadiaphyseal loss with <4 cm isthmus · **Paprosky IV** · **failed multiple osteosyntheses of proximal femoral nonunion** · elderly/sedentary · ✓ **EXCEPT: age <50**

**Pre-op film indicating PFR** — ✓ **Paprosky IV** (no isthmus) (II → extensively coated, IIIA → diaphyseal/modular tapered)

### Extended trochanteric osteotomy

**Use** — remove well-fixed stem / **difficult cement mantle** (✓ ETO when only half the cement can be removed) · **12–14 cm** including vastus ridge · enables diaphyseal-engaging stem\
✗ Wrong options: short metaphyseal stem · impaction on loose mantle · cement-in-cement on loose mantle · spacer

**Biomechanics** — ✓ **reduces torque-to-failure to <50% of intact femur** → guide rehab restrictions

**Proximal migration** — ✓ **plate + cables**\
✗ Wrong options: abduct >10–15° when fixing · <10 cm osteotomy (↑ migration) · distal prophylactic cable (prevents propagation only) · strut (junctional failure)

**Complications** — nonunion, intraop fracture, proximal migration, infection, subsidence

**Fully coated stem fracture after ETO** — ✓ **cantilever bending after distal ingrowth**\
✗ Wrong options: poor distal fixation · anteversion · inadequate bypass · excessive diameter (thin stems fail)

### Abductor deficiency & instability after revision

**Gluteus maximus transfer** (anterior part + TFL to GT) for irreparable abductors ✓ (label A) · Hardinge most associated with post-op Trendelenburg

**Hemi in demented 91-yr-old dislocating** → contributor ✓ **dementia** → convert to THA + constrained liner

**MoM resurfacing with abducted cup, clunking** → ✓ **revise to conventional THA**\
✗ Wrong options: cup-only revision (leaves MoM)

**Loose stem + well-fixed well-positioned cup, 10 dislocations, unknown implant, high-risk host** → ✓ **revise stem + cement constrained liner into existing shell** (shell fixed, positioned, locking broken/unknown, room for 2–4 mm mantle)\
✗ Wrong options: retrovert stem · remove all · Girdlestone

### Conversion of hip arthrodesis

**Indications** — **low back + knee pain** · ✓ **gluteus medius function predicts ambulatory outcome** (pre-op **EMG**)\
✗ Wrong options: >95% survival at 20 yr (97% at 8 yr; others <70% at 10 yr) · time limit (success 30 yr after fusion) · complications = primary (higher) · nerve palsy = primary (higher)

**Technique** — GT osteotomy · neck osteotomy + reaming under fluoroscopy · revision cup/stem ± **dual mobility or constrained** · glut max transfer if abductors deficient · improves knee + back pain

### THA in ankylosing spondylitis (TO)

**Features** — ↑ blood loss, ↑ infection (steroids), intraop fracture, dislocation, **HO** · **stuck-sitting, posterior pelvic tilt, sacral slope change <10°** → **↓ cup anteversion** (and inclination) to prevent posterior impingement + **anterior dislocation** · dual mobility · release tight capsule/soft tissue · cement if Dorr C · ✓ **false: "difficult reaming"** (canal wide, cortex thin — perforation/fracture risk) · hip before knee if equal · spine first if both operative

## 6 Complications

**Revision vs primary** — lower survival · ↑ **dislocation** (even simple), infection, nerve palsy, fracture, abductor deficiency, DVT, LLD

## X vs Y

| | **Paprosky IIIA (acetabulum)** | **Paprosky IIIB (acetabulum)** |
|---|---|---|
| Direction | **Up and out** | **Up and in** |
| Rim loss | 10–2 o'clock | 9–5 o'clock |
| Köhler line | Intact | **Broken** |
| Discontinuity | Uncommon | **Common** — CT angiogram |
| Reconstruction | Cup + **augments** | **Cup-cage / triflange** |

| | **Paprosky IIIA femur** | **Paprosky IIIB femur** |
|---|---|---|
| Isthmus | **≥4 cm** | **<4 cm** |
| Stem | **Extensively porous-coated cylindrical** | **Modular fluted tapered** (or coated if canal <19 mm) |
