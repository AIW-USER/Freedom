# TKA Patellar Maltracking

*Recon · 49 / 65*

## 1 Basics

**Epidemiology** — common cause of dissatisfaction · ✓ **most common reason for secondary surgery after TKA** · historically main cause of revision

**Principle** — anything that **↑ Q angle** → lateral pull → subluxation/dislocation

### Causes of lateral maltracking (TO)

| ✓ Causes (↑ Q angle) | Not a cause |
|---|---|
| **Femoral component IR** (missed **hypoplastic LFC** in valgus knee) | ✓ **Medial placement / translation of patellar button** (TO) — this is the correct position |
| **Medial shift of femoral component** (moves trochlea medially) | Excess femoral ER (helps tracking; may loosen medial flexion gap) |
| **Tibial component IR** | Joint-line elevation (→ mid-flexion instability) |
| **Lateral placement / centralisation of patellar button** | Femoral component in extension (→ notching) |
| **Flexed femoral component** | KA vs MA per se (debated) |
| **Residual valgus** | — |
| **Asymmetric patellar resection / thickness** | — |
| Pre-op: excess femoral anteversion, tibial IR · design · extensor imbalance · anterior femoral component · patellar height | — |

### Rules for tracking

**Femur** — **lateralise** · avoid IR · ER helps

**Tibia** — **lateralise** · avoid IR · centre of tray on **medial ⅓ of tibial tubercle** · slight **ER** → net medialisation of tubercle

**Patella** — ✓ **medialise button** (replicates median eminence) — the only implant placed medially · total thickness ~**21–22 mm** native/composite

## 3 Presentation

**Symptoms** — subluxation sensation · frank dislocation · **peripatellar / anterolateral pain** · **limited flexion** · stiffness

**Sign** — ✓ **J-sign** (subluxed in extension, reduces as it engages trochlea in flexion)

## 4 Diagnosis & Classification

### Key radiology findings

| View | Assesses |
|---|---|
| **AP** | Femoral component placement, Q angle |
| **Lateral** | Femoral size + rotation |
| **Tangential (Merchant)** | **Patellar subluxation**, button placement, resection angle, **tilt** |
| **CT** | ✓ **Best for rotational malalignment** |

**Findings** — lateral subluxation · ↑ Q angle · anterior femoral component · asymmetric resection · lateral button · lateral patellar osteophyte

**Most important test for multifactorial subluxation** → ✓ **axial CT from supracondylar femur to below tibial tubercle**\
✗ Wrong options: long-leg AP · fluoroscopy · bone scan · MRI (artefact)

## 5 Management

**Rule** — address the **cause** · component malalignment first

### Component internal rotation – CT evaluation & revision

**Subluxed patella on Merchant, femoral IR** → ✓ **revision with ER of femoral component + lateral release** (± tibial revision if IR, soft-tissue realignment)\
✗ Wrong options: brace · tantalum patella lateralised · more tibial IR · femoral IR

**CR TKA, anterolateral pain, J-sign, normal X-ray + labs, CT → revision** → ✓ **internal rotation of components**\
✗ Wrong options: joint-line elevation · infection · osteolysis · clunk (PS knees)

**Tray centred medial to medial ⅓ of tubercle** → ✓ **patellar maltracking** (IR tray)\
✗ Wrong options: flexion instability (gaps balanced) · osteolysis (HXLPE) · fracture (22 mm thick) · clunk (PS)

### Intra-op lateral subluxation despite lateral release

✓ **Slight ER of tibial component** (medialises tubercle)\
✗ Wrong options: femoral IR · anterior tibial translation · fixed vs mobile bearing (no difference) · thicker button (overstuffs)

### Hypoplastic lateral condyle

**Valgus knee, patella tracks laterally on trials** → ✓ **failure to recognise hypoplastic LFC** → femoral IR with posterior referencing\
✗ Wrong options: KA · raised joint line · excess ER · femur in extension

### Patellofemoral arthroplasty failure

**Most common early failure** — ✓ **patellar instability / maltracking** (malalignment, soft tissue, malposition) · **late** failure = **tibiofemoral OA progression (~25%)** · loosening **<1%** cemented, higher cementless

## X vs Y

| Error | Effect on Q angle / tracking |
|---|---|
| **Femur IR** / **femur medialised** | ↑ Q → lateral maltracking |
| **Tibia IR** | ↑ Q → lateral maltracking |
| **Button lateral / central** | ↑ Q |
| **Button medial** | ✓ ↓ Q (correct) |
| **Femur ER / lateralised** | ✓ Better tracking |

## How it's asked

**"Subluxed patellar component 3 mo post-op — best course?"** → **revision with lateral release + femoral ER**

**"Intra-op lateral subluxation despite lateral release?"** → **slight ER of tibial component**

**"Multifactorial patellar subluxation — most important test?"** → **axial CT supracondylar femur to below tibial tubercle**

**"CR TKA, J-sign, CT → revision — cause?"** → **internal rotation of components**

**"Tray medial to medial ⅓ of tubercle — complication?"** → **patellar maltracking**

**"Valgus knee, patella tracks laterally on trials — error?"** → **failure to recognise hypoplastic LFC**

**"Most common early failure of PF arthroplasty?"** → **patellar instability/maltracking**

**"Lateral subluxation after TKR — cannot be the reason?"** → **medial placement of patellar component** (TO)

**"Lateral maltracking caused by all EXCEPT?"** → **medial translation of patellar component** (TO)
