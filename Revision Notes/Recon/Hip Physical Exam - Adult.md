# Hip Physical Exam - Adult

*Recon · 11 / 65*

## 3 Presentation

### Inspection

**Skin** — discoloration, wounds, deformity

**Bone** — length vs contralateral · rotation (IR/ER) · flexion contracture

**Gait** — stride, foot rotation, pelvic rotation, stance phase

**Antalgic gait** — **shortened stance phase** on painful side

**Trendelenburg gait** — **abductor weakness** → stance on affected hip → **contralateral hip drops**

## 4 Diagnosis & Classification

### Special tests

| Test | Technique | Positive → |
|---|---|---|
| **FADIR** | Flex 90°, **adduct + IR** | Groin pain → **labral tear / FAI** |
| **FABER (Patrick)** | Flex 90°, **abduct + ER** | Hip/back pain, ↓ ROM → intra-articular, **iliopsoas**, **SI joint** (posterior pain) |
| **Log roll** | Passive max IR/ER supine | Click → **labral tear** · ↑ total ROM → **capsular laxity** |
| **Thomas** | Supine, fully flex one hip | Contralateral thigh lifts → **fixed flexion deformity** |
| **Modified Thomas** (TO) | Same at table edge, leg hangs | Measures peak hip extension angle in all |
| **Ober** | Lateral, affected side up, hip slightly extended, abduct then drop | Cannot adduct → **tight ITB** |
| **Stinchfield** | Supine, knee straight, resist hip flexion at **30–45°** | Pain → **intra-articular** pathology |
| **Staheli** (TO) | **Prone** at table edge, hand on pelvis, extend thigh until pelvis rises | **Hip flexion contracture** · measure thigh–horizontal angle |
| **Ely** (TO) | Prone, flex knee to buttock | Pelvis/hip flexes → **short rectus femoris** |

**Staheli conflict (TO)** — one version: ✓ **psoas contracture** (psoas mainly causes hip flexion contracture) · FNB 2020 version without psoas option: ✓ **rectus femoris contracture** — read the options\
✗ Wrong options: quadriceps · hamstring · gastrocnemius

### Clinical tests – Allis, Trendelenburg (TO)

**Galeazzi / Allis test** — supine, **hips 45°, knees 90°**, malleoli together · normal knees level · affected knee **behind** → **femur short** · affected knee **lower** → **tibia short**

**Allis not done for** — ✓ **polio of lower limb**\
✗ Wrong options: DDH · Perthes · SCFE

**Trendelenburg test — opposite (non-tested) limb** — ✓ **foot neutral off the ground, hip slight extension** (flexion may activate iliopsoas)\
✗ Wrong options: plantigrade/hip neutral · hip 30–45° flexion

**Positive sign** — stance on weak side → **opposite pelvis dips** · patient **lurches to the weak (same) side** · bilateral = **waddling gait**

| Abductor mechanism defect (TO) | Causes |
|---|---|
| **Fulcrum** (hip joint) | Dislocation, advanced **TB/septic** hip, **DDH**, Perthes, advanced AVN |
| **Lever arm** (head/neck) | Head/neck fracture, **coxa vara**, trochanteric fracture |
| **Power** (abductors) | **Polio**, **superior gluteal nerve** injury, TFL/ITB palsy, **L5 radiculopathy** |

### Key radiology findings – MRI for occult fracture

**Occult femoral neck fracture within 24 h** — ✓ **MRI** (NICE 2011) · **CT** second line if MRI contraindicated / not available in 24 h (TO)\
✗ Wrong options: PET-CT · repeat X-ray

**Fracture signal** — ✓ **dark on T1, bright on T2** (free water/haemorrhage)\
✗ Wrong options: bright both · dark both · gadolinium

## How it's asked

**"Investigation of choice for occult femoral neck fracture within 24 h?"** → **MRI** (TO)

**"Limited MRI for occult hip fracture — signal?"** → **dark T1, bright T2**

**"Allis test is not done for?"** → **polio** (TO)

**"Trendelenburg test — position of the limb not being tested?"** → **foot off ground, hip slight extension** (TO)

**"Staheli test is done for?"** → **psoas (hip flexion) contracture**; if psoas absent → **rectus femoris** (TO)

**"Thomas test detects?"** → **fixed flexion deformity**

**"Ober test detects?"** → **tight ITB**

**"Stinchfield positive means?"** → **intra-articular pathology**

**"FADIR positive suggests?"** → **labral tear / FAI**

**"Antalgic gait?"** → **short stance phase** on painful side
