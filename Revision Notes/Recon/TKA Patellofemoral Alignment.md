# TKA Patellofemoral Alignment

*Recon · 51 / 65*

## 1 Basics

**Key fact** — ✓ **abnormal patellar tracking = most common complication of TKA** · PF complications (subluxation, clunk, wear/loosening, fracture) occur in ~**30%**

**Most important variable** — **preserve normal Q angle** (ASIS → patella centre vs patella centre → tibial tuberosity)

**↑ Q angle** — ↑ lateral subluxation force → pain, mechanical symptoms, wear, dislocation · ↑ need for **lateral release**

### Errors that ↑ Q angle

| Component | Bad: ↑ Q angle (maltracking) | Good: ↓ Q angle (good tracking) |
|---|---|---|
| **Femur** | **Internal rotation** · **medialisation** | **External rotation** · **lateralisation** |
| **Tibia** | **Internal rotation** · **medialisation** | **External rotation** · **lateralisation** (with adequate ER) |
| **Patella** | **Lateral placement** | **Medial / central** placement |
| **PF space** | ↑ composite thickness (under-resection), **anterior femoral translation** → tight lateral retinaculum (medial approach) | — |

**Lateral release rates (OB)** — IR femur: **24% varus, 33% valgus** · ER off TEA: **7% varus, 29% valgus**

## 4 Diagnosis & Classification

### Key radiology findings

**Malrotation** — ✓ **CT scan of the knee**\
✗ Wrong options: 3-joint standing film · fluoroscopic EUA · 45° flexed PA · MR arthrogram

**Merchant / tangential** — lateral tilt + subluxation

## 5 Management

### Femoral rotation landmarks (posterior condylar axis, hypoplastic lateral condyle)

| Axis | Definition | Use |
|---|---|---|
| **AP (Whiteside's line / trans-sulcus)** | Deepest trochlear groove → top of intercondylar notch | **Perpendicular** = neutral rotation · fewer maltracking reoperations in valgus knees (Whiteside & Arima) |
| **Transepicondylar (TEA)** | Medial ↔ lateral epicondyle · **⊥ Whiteside's line** · parallel to cut tibia | Posterior cut ∥ TEA → **rectangular flexion gap** · more reliable than PCA |
| **Posterior condylar (PCA)** | Tips of posterior condyles · ✓ **~3° IR to TEA** (range **1–10°**) | Cut in **3° ER** from PCA |

**Posterior condylar axis normal relation** → ✓ **3° internally rotated to TEA**\
✗ Wrong options: parallel · ⊥ Whiteside · 3° or 7° ER

**Hypoplastic LFC + posterior referencing** → ✓ **femoral component IR** → lateral tilt, maltracking, anterior pain in flexion · fix: add ER, posterior lateral augments, check against TEA / Whiteside\
✗ Wrong options: tibial rotation errors

**Femoral IR also** → **tight medial / loose lateral flexion gap** → stiffness \
✗ Wrong options: joint-line change · poly thickness change · ↓ Q

**Gap-balanced flexion (tensioner) — varus (A) vs valgus with hypoplastic LFC (B)** → ✓ **B needs more ER relative to PCA** · posterior **medial** resection thicker than lateral when ER correct · B would need posterior **lateral** augments if any\
✗ Wrong options: more IR to trans-sulcus

**Valgus knee with lateral tilt after TKA** → ✓ **posterior condyles used as rotation reference**\
✗ Wrong options: excess ER · femoral lateralisation · gap balancing (not linked) · TEA matching

### Component internal rotation & maltracking

**Most common intra-op error causing maltracking** → ✓ **femoral component IR**\
✗ Wrong options: gap balancing vs measured resection · tibial ER · femoral lateralisation · over-resected patella (**under**-resection overstuffs)

**Optimise tracking** → ✓ **ER of femoral and tibial components** · medialise patellar button

**↓ Need for lateral release** → ✓ **femoral ER** · ✓ **tibial ER** (medialises tubercle)\
✗ Wrong options: mobile bearing (no benefit) · anterior tray (force not tracking) · CR device

**Lateral subluxation after medial approach** → ✓ **femoral IR** (also tibial IR, ↑ composite patellar thickness, anterior femoral translation)\
✗ Wrong options: tibial ER · posterior femoral translation · ↓ patellar thickness · lateral tibia

**Patellar tilt — all cause EXCEPT** → ✓ **lateralisation of the femoral prosthesis**

### Patellar component & tibial position (medialisation, Q angle)

**Patella** — centred or ✓ **medialised** (replicates median eminence) · ideal **40–45%** (medial edge → central peg ÷ resected width) · uncovered **lateral facet** → excise to avoid lateral facet syndrome · or **oval** button with apex medial

**Most risky for maltracking** → ✓ **lateral placement of patellar component**\
✗ Wrong options: resection thickness · CR · medial placement · pre-op tilt

**Decreases Q angle** → ✓ **medialisation of patellar component**\
✗ Wrong options: medialise femur/tibia · IR femur/tibia

**Tibia** — **neutral rotation**, centred over **medial ⅓ of tibial tubercle** (junction medial–middle third) · may leave posteromedial tibia uncovered, posterolateral overhang · tibial IR = relative tubercle ER → ↑ Q

**Tray at medial/middle ⅓ with 10° ER, still lateral tilt** → ✓ **lateralise the tibial component**\
✗ Wrong options: medialise femur · lateralise button · IR femur/tibia

**Tibial size** — not related to tracking

### Tourniquet effect on tracking

**Lateral subluxation with perfect components** → ✓ **deflate tourniquet and re-evaluate** before lateral release\
✗ Wrong options: lateral release first · revise components

### Patellar resurfacing vs patelloplasty

**Absolute indications to resurface** — **inflammatory arthritis** (✓ consistent benefit) · **patellar maltracking** · **PF OA as main indication** · severe patellar deformity

**Strategies** — always · never (± **patelloplasty**: excise marginal osteophytes, reshape) · **selective**

| Resurfaced vs not | Finding |
|---|---|
| **Anterior knee pain** | **Less with resurfacing** (Orthobullets; OB4743) · **no difference** (OB215498) — read the options |
| **Revision / secondary surgery** | **Unresurfaced → ↑ secondary resurfacing (8.7%)** · secondary resurfacing gives **inferior** results |
| **Tibial/femoral revision** | No difference |
| **Fracture, AVN, tendon injury** | No difference |
| **Infection** | No difference |
| **Satisfaction / function** | Similar · TKA improves function either way |
| **Metal-backed button** | Not lower loosening — **higher** |

**Patelloplasty EXCEPT** → ✓ **"no difference in anterior knee pain"** = false

**"Patella-friendly" trochlea** — **thinner anterior flange** · anatomic groove

### Late instability – realignment

**Instability after fall, components correctly ER on CT, tiny patellar fragment** → ✓ **lateral retinacular release + proximal realignment** (excise fragment)\
✗ Wrong options: ORIF + brace · tibial revision · distal tubercle medialisation (not first line) · patellar revision

**Rule** — malpositioned components → **revise** · well-positioned → **soft-tissue procedures** (lateral release first)

## X vs Y

| | **Posterior condylar axis** | **TEA** | **Whiteside's line** |
|---|---|---|---|
| Relation | 3° IR to TEA | Reference | ⊥ TEA |
| Pitfall | **Hypoplastic LFC → IR** | Epicondyles hard to palpate | Trochlear dysplasia |
