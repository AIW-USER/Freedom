# High Tibial Osteotomy

*Recon · 4 / 65*

## 1 Basics

### Overview

**Purpose** — correct angular deformity → unload one compartment → prevent/slow **unicompartmental OA**

**Commonest indication** — primary/secondary **medial knee arthrosis** with **varus** · isolated lateral OA much less common

**Combined with** — **cartilage restoration** procedures (better mechanical environment) · ligament reconstruction (ACL/PCL/PLC) when malaligned

### Anatomy – mechanical axis

**Mechanical axis** — centre of femoral head → centre of ankle · normally passes **just medial to medial tibial spine**

**Fujisawa point** (TO) — **62% of tibial plateau width measured from the medial edge** · slightly **lateral to lateral tibial spine** · = mechanical axis **3–5° valgus** · correction angle = lines from this point to femoral head + ankle centres · TO technique text also cites **62.5%**\
✗ Wrong options: 62% from lateral · 67%

![Fujisawa point](../../MCQ/attachments/TO17140821-1.png)

### Normal tibial slope (OB)

**Posterior tibial slope** — **9–11° medial**, **6–8° lateral**

## 3 Presentation

**Symptoms** — medial (varus) or lateral (valgus) knee pain · localized

**Exam** — malalignment · **varus thrust** (LCL laxity, lateral opening in stance — predicts medial OA progression)

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — **standing hip-to-ankle alignment films** → mechanical axis · plus knee AP/lateral

**Stress radiographs** — narrow **lateral** compartment cartilage space → contraindicates valgus HTO

**Unloader brace test** — **medial unloader brace** = **therapeutic + diagnostic** · benefit → likely benefit from valgus HTO\
✗ Wrong options: steroid injection · NSAIDs · patellar/strap brace

### Varus types (TO)

| Type | Components | HTO |
|---|---|---|
| **Primary varus** | Bony varus, **no ligament instability** | **Best indication** |
| **Double varus** | Bony varus + **ACL** instability | Combined/staged ligament + HTO |
| **Triple varus** | Varus + **ACL + PCL** insufficiency + **PLC failure** · **varus thrust** | Combined/staged |

## 5 Management

```
Medial compartment OA + varus, young/active
├─ Failed nonop → trial medial unloader brace (predicts success)
├─ Isolated medial OA, ROM ok, BMI ok → valgus HTO
│      └─ overcorrect to 8–10° anatomic valgus (Fujisawa 62%)
├─ Smoker → lateral closing wedge (not opening wedge — nonunion)
└─ Contraindication present → UKA / TKA
```

### Indications & patient selection

**Ideal candidate** — **young, active <50 yr** (arthroplasty would wear out) · **good vascular status** · **non-obese** · pain/disability · **one compartment only** · compliant

**Overcorrection** — ✓ **overcorrect into valgus**: anatomic axis **8–10° valgus** (Orthobullets, OB) · mechanical **3–5°** valgus (TO) · least recurrence

**Return to impact sport** — **HTO allows faster return to sport/impact work** than UKA (activity levels equal) · running discouraged after UKA (PE wear, loosening)

**Typical stems** — 30–48-yr-old labourer/athlete, isolated medial OA, varus 5–9°, failed nonop → ✓ **medial opening wedge HTO**\
✗ Wrong options: UKA · TKA · arthroscopic debridement/microfracture · OCA · meniscal transplant · lateral opening DFO (for valgus) · unispacer

**HTO vs UKA with ACL tear** (TO) — 45-yr-old, ACL torn, lateral meniscus intact, grade 4 medial OA, 10° passively correctable varus → ✓ **HTO** · ACL deficiency **contraindicates UKA**, only relative for HTO (reconstruct simultaneously) · UKA preferred if varus <10°

**HTO vs UKA with thrust + lateral meniscal tear** (TO) — 48-yr-old marathoner, **varus thrust**, 8° varus, functional ACL, stable lateral meniscal tear, no lateral chondral loss → ✓ **medial opening wedge HTO**\
✗ Wrong options: fixed/mobile UKA · TKA

| Finding (TO) | UKA | HTO |
|---|---|---|
| **Varus thrust** | Relative/strong contraindication (loosening) | **Strong indication** — corrects cause |
| **Lateral meniscal tear** | **Absolute contraindication** | Relative (depends on extent + cartilage) |
| Goal | Resurfacing → pain relief | **Axis realignment + stability** |

**Note — varus thrust conflict** — Orthobullets/OB: **varus thrust = contraindication** to HTO · TO (2025 case): thrust **favours HTO over UKA** — read the stem (OB: thrust + lateral laxity → ✓ "contraindication")

### Contraindications

| Contraindication | Orthobullets / OB | TO |
|---|---|---|
| **Inflammatory arthritis** | ✓ (psoriatic — high failure) | ✓ |
| BMI | **>35** | **>30** |
| **Flexion contracture** | **>15°** (10° OK) | **>10°** (extension lag) |
| **Knee flexion** | **<90°** | **<90°** |
| Correction needed | **>20°** | — |
| **Varus deformity** | **>10°** (valgus HTO) | **>15°** · >10° relative only |
| **Lateral tibial subluxation** | **>1 cm** | **>1 cm** (✓ 2 cm subluxation) |
| Medial bone loss | **>2–3 mm** | Medial compartment bone loss |
| Lateral compartment | Narrow on stress films · **loss of lateral meniscus** · lateral OA | Lateral narrowing (bi/tricompartmental) |
| **PF arthritis** | ✓ | ✓ |
| **Ligament instability / varus thrust** | ✓ | **Relative** — (✗ Wrong options: cruciate insufficiency alone)|
| **Smoking** | ✓ (OB) · esp. opening wedge (nonunion) | High smoker |
| Age | Best <50 · **>60** worse | **Age >60 relative** |
| Others (OB) | Nonconcordant pain (PF pain + medial OA) · unwilling to accept cosmetic angular change | — |

**Not contraindications** — **ACL tear** (TO) · **varus 10°** (TO) · **flexion ROM 0–100°** (TO) · chondral lesion size · BMI 22–24 · age 38–42 · 10° flexion contracture · postmenopausal

### Varus-producing tibial osteotomy

**Use** — valgus knee + lateral OA · **less common than DFO** (creates **oblique joint line**) · deformity must be **<12°** · contraindicated: medial OA, loss of medial meniscus · **DFO better if lateral femoral condyle hypoplasia**

### Opening vs closing wedge

| | **Medial opening wedge** | **Lateral closing wedge** |
|---|---|---|
| Approach | Anteromedial · pes + sMCL release | Anterolateral · **fibular osteotomy / PTFJ disruption** |
| **Tibial slope** | **↑ slope** (anterior plate) + anterior tibial translation | **↓ or no change** + posterior translation |
| **Patellar height** | **↓ → patella baja** | **↑ → patella alta** (TO) |
| Stability / WB | Less stable · **longer NWB** · may lose correction | **More stable · earlier WB · faster rehab** |
| Graft | Defect **≥10 mm → graft** | **No graft** |
| Peroneal nerve | **Minimal risk** · avoids PTFJ | **↑ risk** (fibular osteotomy) |
| Nonunion / plate failure | **↑** · avoid in **smokers** | ↓ · choose in smokers, diabetics, steroids |
| Limb length | Lengthens | Shortens |
| Later TKA | Preserves tibial shape | Harder (stem impingement, lateral bone loss) |
| Favoured with (TO) | **PCL injury**, patella alta, MCL laxity, LLD | **Patella baja**, ACL reconstruction, nonunion risk |

**Exclusive to closing wedge** — ✓ **proximal tibiofibular joint disruption**\
✗ Wrong options: compartment syndrome · plate breakage · neurologic injury (seen in both)

**Smoker** → favours **lateral closing wedge**\
✗ Wrong options: age · BMI · meniscectomy history

**Lateral closing vs medial opening** — ✓ **shorter time to weight bearing**\
✗ Wrong options: ↑ baja · ↑ popliteal injury · less stable · ↓ peroneal risk

**Outcomes** — opening vs closing: both appropriate\
✗ Wrong options: "opening superior"

### Other osteotomies (TO)

| Osteotomy | Feature |
|---|---|
| **Focal dome** | Concavity proximal · centre at **CORA** · **least translation**, minimal shortening · for **large corrections (≥20°, 18–20 mm)** e.g. Blount, trauma · cut below tubercle → **no change in slope or patellar height** |
| **Hemicallotasis** | Gradual distraction, ex-fix · below tubercle · minimal change in slope/height |
| **Chevron** | Inverted-V · no bone loss/graft · technically complex |

### Tibial slope & ligament instability

**Rule** — **↑ slope → anterior tibial translation** (stress ACL) · **↓ slope → protects ACL**

| Deficiency | Slope change in HTO |
|---|---|
| **ACL-deficient** | **Decrease** slope |
| **PCL / PLC-deficient** | **Increase** slope ✓ (✗ Wrong options: decrease · neutral) |

**ACL + varus + medial OA, young athlete (pain + instability)** → ✓ **HTO + ACL reconstruction at the same time**\
✗ Wrong options: either alone · vibration rehab

**Recurrent PCL + PLC (dial >10° asymmetry at 30° + 90°) + varus, 1A Lachman** → ✓ **PCL + PLC reconstruction + HTO increasing slope**\
✗ Wrong options: ACL reconstruction · PLC alone

**Native slope 14° ignored during HTO** → ✓ **positive Lachman** (anterior translation persists)\
✗ Wrong options: medial pseudolaxity · quadriceps active test/sag (PCL) · varus thrust

**Decrease slope if** — slope **>13°** + anterior translation **≥10 mm** vs contralateral · **1 mm anterior closure ≈ 2° slope decrease**

## 6 Complications

| Complication | Fact |
|---|---|
| **Recurrence of varus** | ✓ **Most common** (TO) · **60% failure at 3 yr** if undercorrected or overweight · prevented by overcorrection |
| **Patella baja** | **Most patients** after proximal tibial osteotomy · **opening wedge** (raises joint line) · scarring, tendon contracture, immobilization · ✓ **HTO most likely procedure** to cause baja (✗ Wrong options: ACL/PCL/MPFL recon · TKA) |
| **Patella alta** | **Lateral closing wedge** (TO) |
| **Loss of posterior slope** | Closing wedge |
| **Peroneal nerve palsy** | **Lateral** opening/closing wedges · **fibular osteotomy** · minimal in medial opening |
| **Popliteal artery** | Rare, devastating |
| **Nonunion / malunion** | ↑ opening wedge, smokers |
| Compartment syndrome | Any osteotomy |

**Prognosis** — varus-producing HTO **87% success at 10 yr** · valgus-producing **50–85% at 10 yr** (Orthobullets) · good results after later conversion to TKA

### Conversion to TKA

**Risk factors for TKA failure after HTO** — ✓ **BMI >35** · **male** · **young age** at TKA · laxity · preoperative malalignment\
✗ Wrong options: female · stiffness · advanced age

## X vs Y

| | **HTO** | **UKA** |
|---|---|---|
| Patient | **<50, high-impact**, labourer | Older, lower demand |
| ACL deficiency | Relative — reconstruct together | **Contraindication** |
| Varus | Up to ~10–15° (TO) | **<10°**, passively correctable |
| Return to impact sport | **Faster** | Discouraged (running) |

| | **Valgus HTO** | **Varus DFO** |
|---|---|---|
| Deformity | Varus, tibial CORA | Valgus >12°, femoral CORA |
| Compartment | Medial OA | Lateral OA |
