# TKA Sagittal Plane Balancing

*Recon · 59 / 65*

## 1 Basics

### Gap definitions (TO)

**Extension gap** — ✓ **distal femoral cut ↔ proximal tibial cut** (in extension) (TO)

**Flexion gap** — **posterior femoral cut ↔ proximal tibial cut** (at 90°) (TO)

**Goal** — gaps **rectangular and equal** (TO)

### Rules

| Change | Affects |
|---|---|
| **Distal femoral cut / distal augment** | **Extension gap only** |
| **Posterior femoral cut / femoral AP size / posterior augment / AP position** | **Flexion gap only** |
| **Tibial cut / poly thickness** | **Both gaps** |
| **Tibial slope** | **Flexion gap** (↑ slope opens flexion) |
| **Posterior capsule release** | Extension |
| **PCL recession / release** (CR) | Flexion |

**Symmetric problem** (both tight / both loose) → **tibia / poly** · **asymmetric problem** → **femur**

**Femoral AP position** — **anterior** shift → ↑ flexion gap · **posterior** shift → ↓ flexion gap (and tightens posterior tissues) · proximal/distal shift → extension gap

**Downsizing femur** — changes **AP dimension only** (no proximal–distal change) · with anterior referencing → removes more posterior condyle → opens flexion

**Gap-balancing technique (TO)** — remove osteophytes → precise tibial cut → **release ligaments before femoral cuts**

## 5 Management

### Sagittal balancing grid (TO + OB)

| | **Tight in flexion** | **Balanced in flexion** | **Loose in flexion** |
|---|---|---|---|
| **Tight in extension** | ✓ **Cut more proximal tibia** (or thinner poly) | ✓ **Cut more distal femur** · release posterior capsule | ✓ **Cut more distal femur + thicker poly** · or more distal femur + **upsize femur** |
| **Balanced in extension** | ✓ **Downsize femur** (same poly) · ↑ **posterior slope** · CR: **recess / cut PCL** · anteriorise femur | Done | ✓ **Upsize femur ± posterior augments** · move femur posteriorly · more distal femur + thicker poly · less slope + thicker poly |
| **Loose in extension** | ✓ **Downsize femur + thicker poly** | **Distal femoral augment, same poly** (OB) · downsize femur + thicker poly or more slope + thicker poly (TO) — read the options | ✓ **Thicker poly** |

### Tight in extension – resect distal femur

**Flexion contracture, flexion balanced** → ✓ **resect more distal femur** (or release posterior capsule)\
✗ Wrong options: PCL recession · ↑ slope (flexion problems) · smaller femur · more tibia (loosens flexion) · thinner poly (both) · posterior augments (tighten flexion)

**Pre-op 25–95°, after capsule release + osteophytes still 20° short, flexion fine** → ✓ **resect 2 mm more distal femur**\
✗ Wrong options: 2 mm tibia · downsize + thicker poly · ↑ slope · femur 4 mm posterior (tightens flexion + posterior tissues)

**Flexion contracture steps (OB)** — 1: ML balance + osteophytes + distal femur over-resected **2 mm** · 2: **posterior capsule release** · 3: distal femur up to **4 mm** more · 4: **hamstring tenotomy** · <15° → steps 1–2 suffice · steps 3–4 for some >35° · residual contracture >15° less likely to improve

**Flexion contracture treatments EXCEPT** → ✓ **downsize femoral component** (flexion gap only)

**Revision: 2 mm more tibia for 10° contracture** → ✓ **flexion instability** (common pitfall; cut distal femur instead)

### Loose in flexion – upsize femur & posterior augments

**Causes** — **excess posterior femoral resection** (✓ loose flexion gap) · ↑ slope · undersized femur · **PCL resection** · popliteus injury

**Loose flexion, balanced extension — EXCEPT (TO)** → ✓ **downsize femur + thicker spacer** · valid: more distal femur + thicker spacer · upsize femur, same spacer · less slope + thicker spacer (TO)

**Cruciate-sacrificing, flexion instability, extension fine** → ✓ **upsize femur + posterior augments** (or move femur posterior, or thicker poly then fix tight extension)\
✗ Wrong options: downsize femur/tibia · upsize tibia · femur anterior

**Loose flexion, stable extension** → ✓ **move femoral component posterior**\
✗ Wrong options: thicker poly alone · downsize · anterior + distal augment · ER both

**Revision: upsized femur + posterior augments because** → ✓ **balanced in extension, loose in flexion**

**CR TKA, AP instability at 90°, femur anterior, liftoff** → ✓ **revise to larger PS implant**\
✗ Wrong options: NSAID · brace · PT · thicker poly

**Revision with distal augment → dislocated at 1 mo** → ✓ **flexion gap instability** (distal augments treat extension; thin patella / EM weakness aggravates)\
✗ Wrong options: joint line · PT rupture · tibial IR · femoral hyperextension

**Robotic plan 8 mm, 13 mm posterior condyle removed** → ✓ **difficulty rising from a chair** · flexion instability: recurrent effusions, **quad weakness**, stairs, ↑ (not ↓) terminal flexion\
✗ Wrong options: hyperextension · ↓ flexion · coronal instability in extension · hamstring weakness

### Tight in flexion – downsize femur or increase slope

**Downsizing femur helps** → ✓ **tight flexion + normal extension** (TO) · keep anterior cut (avoid notching) → removes more posterior condyle

**PS revision, full extension, tight flexion** → ✓ **downsize femoral component** (TO)\
✗ Wrong options: flex femur (tightens flexion) · thinner tibia (both) · more distal femur (extension)

**CR knee, tight flexion gap (TO)** → ✓ **cut PCL** (convert to PS) · other: ↑ slope (limited), downsize femur (may need anterior referencing) (TO)\
✗ Wrong options: more tibia (opens extension too) · upsize femur · distal femur

**Anterior referencing, 8 mm posterior cut, still tight flexion (TO)** → ✓ **downsize implant** (TO)\
✗ Wrong options: distal femur · ↓ slope · thinner poly

**Full extension, flexion only to 90°** → ✓ **downsize femur**\
✗ Wrong options: more tibia / thinner poly (loosen extension) · distal augment · distal femur

**IM referencing, stable extension, won't flex past 90°** → ✓ **downsize femur** · also **PCL recession**, **↑ slope**\
✗ Wrong options: thinner insert · posterior augments · distal femur · medial tibial reduction osteotomy (valgus laxity)

**CR, recut tibia with ↑ slope because** → ✓ **balanced extension, tight flexion** (slope opens flexion via rollback)

**Tibial tray lift-off in flexion** = tight flexion · easy extraction at 90° = loose flexion

### Femoral referencing (TO)

| | **Posterior referencing** | **Anterior referencing** |
|---|---|---|
| Fixed | **Posterior cut** (~8–9 mm) → flexion gap fixed | **Anterior cut** (no notching) |
| Sequence | Distal cut → size → anterior/posterior cuts → chamfers + notch | Anterior cut first (Whiteside rotation) → size |
| Size change alters | **Anterior** resection | **Posterior** resection (flexion gap) |
| Between sizes | **Choose larger** (smaller → notching) | **Choose smaller** (wider flexion gap, better flexion; rare mid-flexion instability) |

![Posterior vs anterior referencing](../../MCQ/attachments/TO19356211-1.jpg)

### Tight in both – resect tibia

**Cannot extend + tray lifts off past 90°** → ✓ **resect more proximal tibia** (or thinner poly)\
✗ Wrong options: distal augment · distal femur only · downsize femur only · thicker poly

### Loose in extension – distal femoral augment

**Balanced flexion, loose extension** → ✓ **distal femoral augment, same poly**\
✗ Wrong options: distal resection · downsize + thinner poly · tibial resection · augment + thicker poly

### Combined gap mismatch

**Tight extension + loose flexion (TO)** → ✓ **distal femoral cut + thicker poly**\
✗ Wrong options: downsize + slope · downsize + thicker poly · tibia + thicker poly

**Post-op flexion contracture + loose flexion (revision)** → ✓ **resect more distal femur + upsize femur**\
✗ Wrong options: thicker poly (worsens extension) · more tibia · anterior femur + thinner poly · distal femur + tibia

**CR TKA, recurvatum + flexion only 80° (loose extension, tight flexion)** → ✓ **downsize femur + thicker insert**\
✗ Wrong options: semi-constrained · more tibia · anteriorise femur alone · ↑ slope alone

**Extension gap > flexion gap — release? (TO, FNB 2024)** — options anterior sMCL, posterior capsule, POL, deep MCL · **answer not provided by the source** · TO rule (chapter 41): **anterior half of sMCL + pes → flexion space**; POL, posterior capsule, semimembranosus → extension space

**Revision joint-line elevation** — 23 mm spacer, full extension, stable flexion, **patella impinging on poly** → ✓ **upsize femur + distal and posterior augments** (lower joint line, shrink flexion gap) · error: femoral component seated on residual bone → too small + too proximal\
✗ Wrong options: proceed · tendon Z-lengthening · posterior augments only · distal augments only

### PCL deficiency in CR knee – anterior femoral subluxation (TO)

**CR TKR, anterior femoral subluxation on X-ray** → ✓ **PCL deficiency** (TO)\
✗ Wrong options: ACL deficiency · PCL impingement · PLC instability

**CR contraindications (TO)** — PCL insufficiency · posterolateral instability · **flexion >20°**, **coronal >15°** deformity · inflammatory arthritis + EM deficiency (now relative) · prior ORIF/HTO/UKA (poor ligaments → PS easier) · bone defects needing augments/stems · **excessive native slope** (flexion tight → convert to PS) (TO)

**CR technique (TO)** — avoid over-resecting distal femur (CR tends to flexion tightness) · choose **smaller** femur between sizes (PS: **larger**) · PCL inserts **5–10 mm** below tibial surface → protect (osteotome / bone block) · tight PCL → release / convert to PS (TO)

**Kinematics (TO)** — CR: anterior femoral translation **30–60°** WB · PS: constant contact, rollback 60–90° NWB · both show early paradoxical translation · clinical scores, ROM, mid-term survival, quad recovery **no different** · **bicruciate-retaining** preserves screw-home partially (TO)

### Genu recurvatum correction (TO)

**Steps (TO)** — **minimal distal femoral resection** · **move joint line distally** · ✓ **smaller femoral component** (anterior referencing → bigger flexion gap) · thicker poly fills both gaps · **appropriate constraint**

**EXCEPT (TO)** → ✓ **one size bigger femoral component**

## X vs Y

| | **Downsizing femur** | **More distal femur** | **More proximal tibia** |
|---|---|---|---|
| Flexion gap | **↑** | — | ↑ |
| Extension gap | — | **↑** | ↑ |
| Fixes | Tight flexion | Tight extension / FFD | Both tight |
