# Ulnar nerve

*Basic Science · 108 / 108*

## 1 Basics

### Anatomy

**Course** — **medial cord** → anteromedial arm → **pierces medial intermuscular septum** (upper arm) → posteromedial → **cubital tunnel** → motor branches **distal** to tunnel (FCU, FDP ring + small) → hand

**No elbow function** — ✓ transection above elbow → **no elbow limitation** (elbow movers = radial, musculocutaneous, median)

### Motor innervation (interossei, adductor pollicis, palmaris brevis) (TO)

| Region | Ulnar supply (TO) |
|---|---|
| **Forearm** ("1½ flexors") | **FCU** + **medial half of FDP** (ring, small) |
| **Hand — thenar** ("1½ muscles") | ✓ **Adductor pollicis** + **deep (medial) head of FPB** |
| Hand — other | ✓ **All interossei (palmar + dorsal)** · **medial 2 lumbricals** · hypothenars |
| **Superficial branch** | ✓ **Palmaris brevis** (only intrinsic) |
| **Deep branch** | Hypothenars (FDM brevis, ADM, ODM) · medial lumbricals · adductor pollicis · interossei · FPB deep head |

| Median supply (TO) | Radial supply (TO) |
|---|---|
| Forearm: pronator teres, PL, FCR, FDS · **AIN**: FPL, pronator quadratus, lateral FDP | Before spiral groove: triceps long + medial · in groove: lateral head, anconeus |
| Hand: APB, opponens pollicis, superficial FPB, **lateral 2 lumbricals** | Below groove: BR, ECRL (brachialis sensory only) · **PIN**: supinator + APL, EPB, ECRB, EIP, EDC, EDM, ECU |

## 3 Presentation

**Cubital tunnel syndrome** — hand clumsiness · intrinsic wasting · ✓ **Froment sign** · ↓ sensation ulnar small finger · **Tinel at medial elbow**

![Cubital tunnel — intrinsic wasting](../../MCQ/attachments/q4602-a-cubitaltunnel.jpg)

### Sensory & motor distribution after injury

**Martin-Gruber anastomosis** — median → ulnar **motor** connections in forearm · distal ulnar transection with **intact finger abduction/adduction** · sensation: ✓ **dorsal 1st web + index tip intact, small finger tip lost** (sensory loss still ulnar)

## How it's asked

**"Ulnar nerve transected excising medial intermuscular septum — elbow limitation?"** → **none**

**"Distal ulnar transection, intact abduction/adduction — sensation?"** → **dorsal 1st web + index tip intact, small finger tip lost**

**"Nerve to adductor pollicis?"** → **ulnar** **(TO)**\
✗ Wrong options: median · both

**"Nerve to palmar interossei?"** → **ulnar** **(TO)**

**"Intrinsic supplied by superficial branch of ulnar nerve?"** → **palmaris brevis** **(TO)**\
✗ Wrong options: adductor pollicis, FDM brevis, ADM
