# Renal Osteodystrophy

*Basic Science · 91 / 108*

## 1 Basics

**Definition** — metabolic bone disease of **chronic renal insufficiency** · deficient mineralisation from electrolyte + endocrine abnormalities → osteomalacia, osteonecrosis, pathological fracture

### Labs & pathophysiology (TO)

**Key step** — ✓ **uraemia-related phosphate retention**\
✗ Wrong options: PTH receptor sensitivity · metabolic alkalosis · dialysis electrolyte shifts

```
Chronic renal failure
├─ ↓ PO₄ excretion → hyperphosphataemia → Ca-PO₄ precipitates → ↓ Ca
├─ ↓ 1α-hydroxylase (PO₄ inhibits it) → ↓ 1,25-D → ↓ Ca → OSTEOMALACIA
└─ ↓ Ca + ↑ PO₄ → chief cell hyperplasia → SECONDARY HYPERPARATHYROIDISM
       └─ autonomous gland → hypercalcaemia → TERTIARY HYPERPARATHYROIDISM
```

**Tertiary hyperparathyroidism (TO)** — prolonged stimulation → gland autonomous, insensitive to Ca/PO₄/vit D → **hypercalcaemia** **(TO)**

### Classification

| | **High turnover (high PTH)** | **Low turnover (normal PTH)** |
|---|---|---|
| Cause | Chronic ↑ PO₄ → **secondary hyperparathyroidism** (PO₄ ↓ Ca, ↓ 1α-hydroxylase, directly ↑ PTH) | **Aluminium deposition** in bone |
| Mechanism | Chief cell hyperplasia | ↓ osteoblast differentiation/proliferation · **↓ PTH release** · disrupted mineralisation |
| **Ca** | **↓** | ↑ |
| **PO₄** | **↑** | Normal |
| **ALP** | **↑** | ↑ |
| **PTH** | **↑** | **Normal** |

### Genes & lab markers

**Newly diagnosed** — ✓ **↑ PTH, ↑ PO₄ (hyperphosphataemia), ↓ Ca** · ↓ active vit D · low urinary Ca + PO₄ **(TO)**

**ALP ↑ in (TO)** — ✓ **renal osteodystrophy** · rickets (all) · osteomalacia · Paget's · primary hyperparathyroidism · CRF with 2° HPT · lytic neoplasms **(TO)**

**ALP normal (TO)** — osteoporosis · **osteopetrosis** · fibrous dysplasia · **multiple myeloma** · hypoparathyroidism **(TO)**

**ALP ↓ (TO)** — achondroplasia · **hypophosphatasia** · cretinism **(TO)**

| Lab pattern (Ca / PO₄ / ALP / PTH) | Diagnosis |
|---|---|
| ↓ / ↑ / ↑ / ↑ | ✓ **High-turnover renal osteodystrophy** |
| ↑ / N / ↑ / N | Low-turnover renal osteodystrophy |
| ↓ / ↓ / ↑ / ↑ | Nutritional (vit D deficiency) rickets |
| ↓ / ↑ / N / ↓ | Hypoparathyroidism |
| ↑ / N / N–↑ / ↑ | Primary hyperparathyroidism |

**Histology** — thinned trabeculae · extreme bone turnover · **amyloid** pink on **Congo red**

## 3 Presentation

**Symptoms** — weakness · bone pain · **pathological fracture (commonest complication)** · deformity · growth retardation (children)

**Hypocalcaemia** — abdominal pain · cramps · dyspnoea · seizures · mental status change · **Trousseau** (carpopedal spasm with BP cuff) · **Chvostek** (facial twitch on tapping facial nerve)

| Orthopaedic manifestations |
|---|
| **Osteomalacia** (adults) · growth retardation (children) |
| **AVN** |
| Tendinitis, **tendon rupture** |
| **Carpal tunnel** — **β2-microglobulin amyloid** |
| **Pathological fracture** — **brown tumours** (HPT) or amyloid |
| Osteomyelitis, septic arthritis |

**Deformity in children (TO)** — ✓ **genu valgum** commonest (TO; ROD occurs later than nutritional rickets' physiological-varus age) · Orthobullets lists **femoral varus** — read the options · others: genu varum, **SCFE**, ankle valgus/varus, coxa vara, bowing, scoliosis, osteonecrosis, OCD, brown tumour **(TO)**

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — **Looser zones** · **brown tumour** · **osteosclerosis** (mineralised osteomalacic bone) → **rugger jersey spine** (alternating sclerotic + lytic bands) · soft-tissue / **tumoral calcinosis** · chondrocalcinosis · osteopenia · fracture

![Rugger jersey spine](../../Orthobullets/attachments/ob9030-rugger-jersey-spine.jpg)

**Children** — **widened physis + zone of provisional calcification** · physeal **widening, bowing, cupping** · varus femurs (e.g. 9-yr-old, <5th centile height, femoral bowing → ✓ **renal osteodystrophy**; ✗ Wrong options: XLH less likely at that onset · fibrous dysplasia — no ground glass, OI — no fractures)

**CT** — osseous resorption · may **mimic bone tumour**

![Brown tumour](../../Orthobullets/attachments/ob9030-brown.jpg)

**Osteitis fibrosa cystica** — multiple cysts from PTH resorption **(TO)**

### Metaphyseal bands (TO)

| Dense metaphyseal bands — causes (TO) |
|---|
| **Chronic anaemia** — sickle cell, thalassaemia |
| **Chemotherapy** — methotrexate · treated leukaemia |
| Growth arrest/recovery lines — asthma, DM, CF, JIA, malnutrition |
| **Heavy metals** — **lead (commonest)**, bismuth, arsenic, phosphorus, fluoride, mercury |
| Healing **renal osteodystrophy** · healing rickets · **bisphosphonates** · neonatal normal variant |
| ✓ **Hypervitaminosis D** — rarest → "not seen" answer |

## 5 Management

**Treatment** — treat underlying renal disease / relieve urological obstruction

## How it's asked

**"Metaphyseal bands NOT seen in?"** → **hypervitaminosis D** **(TO)**\
✗ Wrong options: lead, methotrexate, sickle cell

**"Serum ALP increases in?"** → **renal osteodystrophy** **(TO)**\
✗ Wrong options: osteopetrosis, myeloma, hypophosphatasia

**"Labs in new renal osteodystrophy?"** → **↑ PTH, hyperphosphataemia, hypocalcaemia**

**"Key step causing osteomalacia in renal osteodystrophy?"** → **uraemia-related phosphate retention**

**"High-turnover renal osteodystrophy labs?"** → **↓ Ca, ↑ PO₄, ↑ ALP, ↑ PTH**

**"Commonest deformity in renal osteodystrophy?"** → **genu valgum** **(TO)**

**"Dialysis patient, bilateral hip fractures, ↑ ALP + PTH, thin trabeculae?"** → **renal osteodystrophy**\
✗ Wrong options: metastasis, myeloma

**"9-yr-old, short, bilateral femoral bowing, cupped wide physes?"** → **renal osteodystrophy**\
✗ Wrong options: diastrophic dysplasia, OI, fibrous dysplasia
