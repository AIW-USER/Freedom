# Tendons

*Basic Science · 105 / 108*

## 1 Basics

**Function** — transfer muscle force to bone · orient along stress

| | **Paratenon-covered** | **Sheathed** |
|---|---|---|
| Examples | **Patellar, Achilles** | **Hand flexors** |
| Blood supply | **Rich** → heal better | Avascular areas · **nutrition by diffusion** |
| Injury | Trauma · fail at **musculotendinous** or **tendon–bone junction** | **Laceration** · risk of **adhesions** |

### Composition (collagen, decorin, aggrecan, enthesis)

**Structure** — fascicles separated by **endotenon**, surrounded by **epitenon** · hierarchical (microfibrils → fibrils → fascicles) · mostly **water**

| Component | % dry weight / role |
|---|---|
| **Type I collagen** | **85%** (Orthobullets, OB213905) · **95%** (OB8280) — read the options |
| Type III collagen | **0–5%** (<5%) · also V, VI small |
| Proteoglycans | 0–5% · attract water |
| ✓ **Decorin** | **Most abundant tendon proteoglycan** (small leucine-rich PG) · ✓ **regulates collagen fibril diameter / size** · cross-links fibres, transfers load |
| ✓ **Aggrecan** | Proteoglycan in **areas of compression** |
| Tenascin-C | Glycoprotein ↑ in tendinopathy |
| Elastin | Tissue recoil after stretch |
| Fibronectin | Cell adhesion, migration, differentiation |
| Fibrillin | Elastic fibre formation |

![Hierarchical tendon structure](../../Orthobullets/attachments/ob9015-hierarchical-structure.jpg)

**Cells** — **fibroblasts (tenocytes)**: spindle-shaped, parallel rows along load · make type I (85%) + type III (5%) collagen · drive healing

**Blood supply** — musculotendinous junction · osseotendinous junction · surrounding tissue (paratenon, mesotenon, **vincula**)

### Enthesis

| Insertion zones (↑ modulus) | Contents |
|---|---|
| **Tendon** | Type I + III collagen, elastin, PGs, fibroblasts |
| **Uncalcified fibrocartilage** | Aggrecan, types I, II, III, fibrochondrocytes |
| — **Tidemark** — | Straight basophilic line = soft–hard mechanical boundary |
| **Calcified fibrocartilage** | **Type II**, aggrecan, types I + **X**, fibrochondrocytes · interlocks with bone |
| **Bone** | Osteocytes, osteoblasts, osteoclasts, type I, apatite |

![Four zones of the direct insertion](../../Orthobullets/attachments/ob9015-4-layers-at-insertion-site.jpg)

| | **Fibrous (indirect)** | **Fibrocartilaginous (direct)** |
|---|---|---|
| Site | Metaphysis / diaphysis | Epiphysis / apophysis |
| Structure | Perforating mineralised (Sharpey) fibres | **4 zones** |
| Insertion angle | Changes little | **Changes greatly → overuse injury** |
| Examples | **Deltoid**, adductor magnus–linea aspera, pronator teres | **Rotator cuff, Achilles** |

**Nerve endings** — ✓ **enthesis = free nerve endings (nociception)** · myotendinous junction = **Golgi organs** (steady state), **Ruffini** (prolonged, sensitive), **Pacini** (fast) · **Meissner** = skin light touch

### Vascular supply — vincula

**Sheathed tendons** — vincula = **main blood supply** to bulk of FDS/FDP · FDS + FDP each have **vincula brevia + longa** (2 each, Orthobullets) · "5 vincula: 2 short, 3 long" (OB5552)

| Vinculum | Origin → attachment |
|---|---|
| **VBS** (brevia superficialis) | PIPJ / adjacent proximal phalanx |
| **VLS** (longa superficialis) | Proximal P1 / MCPJ → 2 slips |
| ✓ **VBP** (brevia profundus) | **DIPJ / distal middle phalanx → FDP at A5** |
| **VLP** (longa profundus) | Distal P1 / PIP volar plate → through VBS → FDP |

**Jersey finger (Leddy–Packer II, fragment at A2)** — ✓ **VBP disrupted** · VLP intact · FDS vincula unaffected\
✗ Wrong options: volar plate

## 2 Mechanism

### Mechanical behaviour (toe region, elastin)

**Properties** — **more collagen, less viscoelastic than ligament** · viscoelastic, non-linear · **strain-rate dependent** · ✓ **strong in tension (5–10% strain vs bone 1–4%)** · buckle in compression · **creep + stress relaxation**

**Modifiers** — exercise ↑ · **immobilisation ↓** · ↑ to maturity then ↓ · laser/heat → shrinkage · hydration, temperature, pH → **test under physiological conditions**

| Load–elongation region | Explanation |
|---|---|
| ✓ **Toe** (low load, non-linear) | **Crimped fibres straighten** · crimped elastin fibrils (OB5510) · tendon toe smaller than ligament (more parallel) |
| **Linear (elastic)** | Intermediate load · slope = **Young's modulus** |
| Yield point | Elastic → plastic |
| **Failure** | High load |

![Load–elongation curve](../../Orthobullets/attachments/ob9015-loadelongationcurve2.jpg)

**Soft tissue vs metal** — ✓ **toe region unique to soft tissue**\
✗ Wrong options: modulus, plastic region, strain energy density, yield point (shared)

**Mechanotransduction** — ✓ **deflection of primary cilium**\
✗ Wrong options: apoptosis · cell elongation · pressurisation (older theories)

**Training (8 wk half-marathon)** — ✓ **net ↑ type I collagen** (↑ turnover; ↓ cross-links with endurance)\
✗ Wrong options: known effect on fibril diameter / CSA

## 5 Management

### Healing & adaptation

| Stage | Events | Time |
|---|---|---|
| **Haemostasis** | **Platelets** → coagulation · fibrin clot + fibronectin → chemotaxis | 5–15 min |
| **Inflammation** | ✓ **Neutrophils + M1 macrophages** · chemotaxis of fibroblasts · fibroblasts make **type III collagen** | **1–7 days** |
| **Proliferation** | Disorganised collagen + angiogenesis · GFs: PDGF, IGF, **BMP-12/13**, TGF-β · M2 shift · ↑ type I + neovascularisation | 7–21 days |
| **Remodelling** | **Type III → type I** · fibrosis, ↓ cellularity | Up to **18 months** |

**Repair strength** — ✓ **weakest in inflammatory phase** · **7–10 days** (Orthobullets) · **5–21 days** (OB8271) · most strength by **21–28 days** · max at **6 months** · ✓ **final only ~2/3 normal**

**Early mobilisation** — earlier ROM but ↓ repair strength · ✓ **flexor tendons: prevents adhesions**

## Tendon vs Ligament

| | **Tendon** | **Ligament** |
|---|---|---|
| Collagen | More, more parallel | Less, less organised |
| Viscoelasticity | Less | More |
| Toe region | Smaller | Larger |

## How it's asked

**"Decorin controls?"** → **tendon collagen fibre size**\
✗ Wrong options: myelin · axon branching

**"Tendon matrix ratio?"** → **95% type I, <5% type III**

**"Found in areas of tendon compression?"** → **aggrecan**\
✗ Wrong options: decorin

**"Enthesis contains?"** → **free nerve endings**\
✗ Wrong options: Golgi, Pacini, Ruffini (myotendinous) · Meissner (skin)

**"Function of most abundant tendon proteoglycan?"** → **regulates collagen fibril diameter**\
✗ Wrong options: compression (aggrecan)

**"Region X on load-elongation curve?"** → **toe region with crimped fibres**

**"Stress–strain portion due to elastin structure?"** → **A — toe region**\
✗ Wrong options: B elastic · E modulus

**"Unique to ligament vs titanium curve?"** → **toe region**

**"Tendon repair weakest in which phase?"** → **inflammatory**

**"8 wk marathon training — Achilles change?"** → **net increase type I collagen**\
✗ Wrong options: ↑ fibril diameter · ↑ CSA

**"How fibroblasts sense strain?"** → **primary cilium deflection**

**"Inflammatory phase hallmark (week 1)?"** → **neutrophils + M1 macrophages**\
✗ Wrong options: M2 (remodelling) · type I deposition

**"Jersey finger with fragment at A2 — vascular structure injured?"** → **vincula brevia to FDP**
