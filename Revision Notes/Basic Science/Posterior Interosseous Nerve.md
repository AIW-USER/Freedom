# Posterior Interosseous Nerve

*Basic Science · 82 / 108*

## 1 Basics

### Anatomy & injury

**Course** — middle + lower trunks → **posterior cord** → radial nerve → divides at elbow into **superficial radial nerve (SBRN, sensory)** + **PIN (motor)**

| PIN motor supply | Muscles |
|---|---|
| **Superficial extensors (4)** | **EDM · ECU · EDC · ECRB** |
| **Deep extensors (5)** | **Extensor indicis · EPB · EPL · APL · supinator** |
| ✗ Wrong option: PIN (radial nerve proper) | **ECRL** |

**Sensory** — **dorsal wrist capsule** only (no skin)

![PIN innervation — superficial and deep extensors](../../Orthobullets/attachments/ob10104-pin.jpg)

### Wrist — 4th dorsal compartment

| Dorsal compartment | Contents |
|---|---|
| 1 | APL, EPB |
| 2 | ECRL, ECRB |
| 3 | EPL |
| **4** | **EDC, EIP, terminal PIN** |
| 5 | EDM |
| 6 | ECU |

## 3 Presentation

**PIN palsy pattern** — (✗ Wrong options: MCP extension of thumb + fingers) · ✓ **wrist extension with radial deviation** (ECRL intact, ECRB/ECU out) · ✓ sensation radial forearm + dorsal thumb (SBRN intact) → lesion **distal to SBRN/PIN split**

**Tenodesis intact** — passive wrist flexion → digits extend → ✓ **tendons in continuity** → nerve lesion, not tendon

## 5 Management

**Proximal forearm stab, can't extend fingers/thumb, tenodesis intact** — ✓ **explore + repair PIN**\
✗ Wrong options: NCS/EMG first · splint · tendon repair · observation

**Dorsal Thompson approach** — identify / protect PIN · **pronation** moves PIN away · radial nerve splits proximal to the approach · median / AIN / musculocutaneous not encountered

## Radial nerve vs PIN palsy

| | **Radial nerve (proximal)** | **PIN** |
|---|---|---|
| Wrist extension | No (wrist drop) | ✓ **with radial deviation** |
| Finger/thumb MCP extension | No | No |
| Dorsal radial sensation | No | ✓ intact |

## How it's asked

**"Tendon in same dorsal compartment as PIN?"** → **extensor indicis proprius**\
✗ Wrong options: EDM 5th, ECRB 2nd, EPL 3rd, APL 1st

**"Stab to proximal forearm, can't extend digits, tenodesis intact — management?"** → **explore and repair PIN**

**"After dorsal Thompson approach — no thumb/index MCP extension, wrist extends radially, sensation intact?"** → **posterior interosseous nerve**\
✗ Wrong options: radial · AIN
