# Brachialis

*Basic Science · 22 / 108*

## 1 Basics

### Anatomy

| | Brachialis |
|---|---|
| **Origin** | Distal half of anterior humerus |
| **Insertion** | **Coronoid process + ulnar tuberosity** |
| **Action** | **Major forearm flexor** — flexes in all positions |
| **Innervation** | **Medial (major) part: musculocutaneous (C5, C6)** · **inferolateral part: radial** |
| **Arterial supply** | Muscular branches of brachial artery, recurrent radial artery |

![Brachialis](../../Orthobullets/attachments/ob10018-brachialis.jpg)

**Anterior approach to humerus** — **split brachialis** using its dual innervation (internervous plane)

### Dual innervation (composite / hybrid muscles)

| Muscle | Nerves |
|---|---|
| **Brachialis** | **Musculocutaneous + radial** |
| **FDP** | Median (AIN) + ulnar |
| **Adductor magnus** | Obturator + sciatic (tibial) |
| **Pectineus** | Femoral + obturator |
| **FPB** | Median + ulnar |

**Single nerve** — **gracilis** (obturator) **(TO)** · pronator teres · FDS · coracobrachialis · latissimus dorsi\
✗ Wrong options: dual

## How it's asked

**"All have dual nerve supply EXCEPT (TO)?"** → **gracilis**\
✗ Wrong options: FDP, adductor magnus, brachialis

**"Muscle with dual innervation?"** → **brachialis**\
✗ Wrong options: pronator teres, FDS, coracobrachialis, latissimus
