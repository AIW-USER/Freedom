# Rehab & Prosthetics

*Basic Science · 90 / 108*

## 1 Basics

### Principles

**Goal** — restore function close to original · multidisciplinary team

**Upper limb** — **limb salvage ideal** (prosthesis lacks sensation) · residual length matters for socket suspension

**Lower limb goals** — comfortable · easy on/off · light · durable · cosmetic · functional

**Most important factor choosing LL prosthesis** — ✓ **patient functional status** (current + potential)\
✗ Wrong options: cost, comorbidities, age, gender

### Metabolic cost of amputation

| Amputation | ↑ Metabolic cost of walking |
|---|---|
| **Syme's** | **15%** |
| **Traumatic transtibial** | ✓ **25%** — least of the options |
| Vascular transtibial | 40% |
| Traumatic transfemoral | 68% |
| Vascular transfemoral | 100% |

**Rule** — traumatic < vascular (ongoing vascular disease above level) · more proximal → higher cost

**Other costs** — **wheelchair propulsion +9%** vs normal walking · **crutch walking > walking with prosthesis**

### Gait aids & crutch gait (TO)

**Antalgic gait** — any pain-related gait · **shortened stance** on affected limb

| Gait | Pattern |
|---|---|
| **3-point** | Crutches + injured limb advance together (weight on crutches) → weight onto uninjured limb |
| **4-point** | One crutch → opposite leg → other crutch → other leg |
| **Swing-to** | Crutches advanced, legs swung **to** crutches · slower, ↓ fall risk |
| **Swing-through** | Crutches advanced, legs swung **past** them · faster, ↑ energy, ↑ fall risk · ✓ **paraplegia / SCI with paraparesis** **(TO)** |

![Gait patterns with assistive devices](../../Orthobullets/attachments/ob9072-gait-patterns.jpg)

**Crutch-walking muscles** — latissimus dorsi · triceps + biceps · quads · hip extensors · hip abductors

**Cane** — held **contralateral** → shifts centre of gravity toward affected side

**Gait aid sizing (TO)** — cane in **opposite hand** · crutch tip **15 cm ahead**, axillary pad **5 cm below axillary fold** · walker: elbows at **30° flexion**

**TTWB / NWB one leg** — ✓ **2 axillary crutches**\
✗ Wrong options: single forearm crutch · double cane · single platform crutch

## 5 Management

### Upper limb prostheses (myoelectric vs body-powered)

**Timing** — fit **ASAP**, even before full wound healing · better if **within 30 days**

| | **Myoelectric** | **Body-powered** |
|---|---|---|
| Best candidate | ✓ **Midlength transradial** (only terminal device to drive) | **Heavy labour** |
| Mechanism | Surface electrodes on residual muscles → motor | Harness: **shoulder flexion + abduction** · ring just off **C7 midline toward non-amputated side** |
| Pros | **Cosmesis** · **more proximal function/coverage** · any position incl. **overhead** · **less gross limb movement** · sedentary use | **Most durable** · moderate cost · **lighter** · **more sensory feedback** · less maintenance · less training |
| Cons | **Heavier, expensive, more maintenance**, **less sensory feedback** · clean environment only | Poor cosmesis · **more harnessing** · more gross movement |
| Rejection (Silcox) | 50% rejected myoelectric | 32% rejected conventional (of those with both) |

**Elbow disarticulation / transhumeral** — two joints → heavy · best = **hybrid** myoelectric + body-powered + switch components

**Proximal transhumeral / shoulder disarticulation** — no lever arm → **universal shoulder joint** positioned with contralateral arm + lightweight hybrids · many choose **cosmetic only**

| Component | Detail |
|---|---|
| Passive terminal device | More cosmetic, less functional |
| Active terminal device | More functional · hooks / hands with cables or myoelectric |
| **Hand-like device** | Thumb, index, long finger · gloved · **office worker** |
| **Non-hand (hook, pincer)** | Task tools, quick release · **physical labour** |
| **Voluntary opening** | Closed at rest, opens with proximal contraction · **more common** |
| Voluntary closing | Open at rest · **heavier, less durable** |
| Quick-disconnect wrist | Swap specialised devices |
| Locking wrist | Prevents rotation during lift |
| **Wrist flexion unit** | **Bilateral amputees**, on **longer** limb → midline tasks (shaving, buttoning) |
| **Rigid elbow hinge** | **Short transradial**, no pronation/supination, elbow flexion kept |
| **Flexible elbow hinge** | Wrist disarticulation / long transradial with pronation/supination |

**Grips** — precision (pincer) · tripod (3-jaw chuck) · lateral (key) · hook power · spherical

### Prosthetic foot selection

| Foot | Features |
|---|---|
| **Single axis** | Ankle hinge → **DF + PF only** · poor durability, cosmesis |
| **SACH** (solid ankle cushioned heel) | Rigid wood keel, foam · **low activity / transfers** · being phased out · **overloads contralateral foot** |
| **Dynamic response (energy storing)** | Keel = spring → DF, ↓ contralateral load, push-off · standard for most |
| **Articulating dynamic response** | ✓ **Inversion, eversion, rotation** · absorbs shear · **uneven terrain** (multi-axis — BK amputee walking uneven ground) |
| Non-articulating dynamic response | Spring but no inversion/eversion |
| **Short keel** | Less responsive · **moderate activity, hiking** |
| **Long keel** | **High-demand athletes** |
| Shank | Structural support · endo/exoskeletal · **lever arm after transmetatarsal amputation** |

**SACH vs dynamic response** — SACH: **less dorsiflexion** · ↑ **contralateral GRF** · ↓ **max gait velocity** · **less frequent replacement** · not longer midstance (dynamic foot has **longer midstance**)

![SACH foot](../../Orthobullets/attachments/ob9072-sach.jpg)

**Hiker on SACH** — ✓ **short-keel articulated dynamic-response foot**\
✗ Wrong options: single axis · non-articulated · long keel

**Partial foot / toe amputation, short stance, poor toe-off** — ✓ **full-length steel shank + rocker sole** (shank restores lever arm, rocker → heel–toe transfer) · (✗ Wrong options: solid AFO, HKAFO, UCBL) · rocker may destabilise knee

**Jaipur foot (TO)** — **flexible keel** → **squatting, cross-leg sitting, barefoot walking**

**SAFE foot (TO)** — **Stationary Attachment Flexible Endoskeletal**

**SACH (TO)** — rigid keel + **cushioned heel → pseudo-plantarflexion**

**Canadian prosthesis (TO)** — for **Syme** amputation

### Prosthetic knees

| Knee | Indication | Features |
|---|---|---|
| **Polycentric (4-bar)** | Transfemoral, **knee disarticulation**, **bilateral** | **Variable centre of rotation** · controlled flexion · moderately fast pace · supports more weight · shortens limb at step initiation (↓ stumble) · **heavier, costly, more maintenance** |
| **Stance-phase control (weight-activated)** | **Older patients**, proximal amputation, uneven terrain | Constant friction in swing · locks with weight-bearing |
| **Fluid (hydraulic / pneumatic)** | **Active** patients accepting weight | **Variable cadence** (piston) · ↓ excess flexion · extends earlier |
| **Constant friction (single axis)** | General · uneven terrain · **commonest paediatric** · not old/weak | Hinge + friction · **light, durable, cheap** · **single speed** · stance stability from alignment |
| Variable friction (cadence control) | — | Multiple pads · variable speed · not durable |
| Manual locking | — | Constant friction + extension lock |

**Polycentric centre of rotation** — posterior to weight line → stance control, harder flexion · anterior → easier flexion, less control \
✗ Wrong options: **"fixed anterior to weight-bearing line"**

### Transfemoral sockets & osseointegration (OPRA) (TO)

**Socket** — stump–prosthesis interface · preparatory socket re-adjusted as oedema resolves · **PTB socket commonest for BKA** · transfemoral/quadrilateral → **hard to keep femur adducted** (allows 10° adduction, 5° flexion)

| Transfemoral socket (TO) | Weight bearing | Suspension |
|---|---|---|
| **Quadrilateral** | **Ischial tuberosity** on posterior shelf | Suction ± belts |
| **Ischial containment** | Whole stump surface · medial wall contains **ischial ramus** · more comfort/control | Suction |

**Quadrilateral socket used in** — ✓ **transfemoral amputation** **(TO)**\
✗ Wrong options: Syme's, BKA, transhumeral

**Suspension** — belts, wedges, straps, suction · **silicone liner = airtight seal**

**Pylon** — tube linking socket and terminal device · exoskeleton (hard shell) / endoskeleton (metal frame, soft cover)

**Osseointegration (OPRA)** — stem in residual bone + percutaneous post → direct skeletal attachment **(TO)**

**OI advantages (TO)** — no socket problems (skin breakdown, fit, pain) · may ↓ disuse **osteoporosis** + contralateral arthritis · **short residual limb**, HO, scar, multiple amputations · **osseoperception** (terrain sensing) · ↑ wear time · **easier** donning/doffing **(TO)**\
✗ Wrong options: "no donning/doffing needed"

| OPRA contraindications (FDA) (TO) |
|---|
| **Incomplete skeletal growth** · atypical anatomy · <2 mm cortex around implant |
| **Osteoporosis** |
| **Age >65 or <22** · **weight >220 lb** (with prosthesis) · pregnancy |
| Non-compliance · severe PVD · complicated DM · residual-limb skin disease |
| Neuropathy, severe phantom pain · active infection / dormant bacteria |
| ✓ **NOT a contraindication: malignancy as cause of amputation** |

### Orthoses & splints (TO)

**GRAFO** — ✓ **all**: **Newton's third law** · **accelerates knee extension in midstance** (weak quadriceps) · **compensates weak gastrocnemius–soleus** **(TO)**

**Turnbuckle splint** — gradual stretch of contracted joint · **Volkmann's ischaemic contracture, stiff elbow** · ↓ rehab time, good compliance **(TO)**

**Orthosis naming (TO)** — joints spanned, **proximal → distal + "O"** (foot-drop splint = **AFO**) · static (no motion, finger splint) vs dynamic (controlled motion, wrist-drop splint)

| Nerve palsy / lesion (TO) | Orthosis |
|---|---|
| **Ulnar (claw hand)** | **Knuckle bender** |
| **Median** | **Opponens splint** |
| **Radial (wrist drop)** | **Cock-up / wrist-drop splint** |
| **Mallet finger** | Finger splint |
| **Brachial plexus (no avulsion, Toronto > 3.5)** | **Aeroplane splint** up to 3 mo |
| **Tennis elbow** | **Counter-force strap 5 cm distal to lateral epicondyle** |

**Closed nerve injury (TO)** — observe **3–6 wk** with splint · transected nerve → repair, not splint

| Spinal orthosis (TO) | Use |
|---|---|
| Soft collar | Muscle strain |
| **Philadelphia collar** | **Suspected** C-spine injury |
| **SOMI** | **Confirmed** fracture |
| **Halo vest** | **Maximal** stabilisation |
| Lumbosacral belt | Hydraulic (intra-abdominal pressure) principle |
| **Taylor brace** | Dorsolumbar **T10–L3** |
| **ASH brace** | Compression fracture, kyphosis control |
| **Milwaukee** | High profile; lateral pad on **apical** vertebra |
| **Boston** | Low profile, commonest; **20 h/day**; brace if **Cobb < 45° + Risser 3–5** (TO — verify: bracing is usually for **Risser 0–2**, skeletally immature) |

**Floor reaction orthosis (TO)** — polio, CP, spina bifida · heel moves down → shell **pushes knee into extension** → assists weak quadriceps + plantarflexors

**Foot orthoses (TO)** — flat foot → **Thomas heel** · metatarsalgia → **metatarsal / rocker bar** · plantar fasciitis → silicone heel pad · hallux valgus → bunion splint

**Paediatric orthoses (TO)** — **Pavlik 23 h/day** (DDH) · **Denis Browne splint** (CTEV, pre-walking) · CTEV shoes at walking age

### Physical modalities — TENS (TO)

**TENS frequencies** — **<10 Hz, high intensity → muscle contraction** · **>50 Hz, low intensity → paraesthesia** without contraction **(TO)**

**Indications** — ✓ **generalised muscle pain**, LBP, spasm, myofascial, arthritic, neurogenic, post-surgical, diabetic neuropathy, dysmenorrhoea · not acute **fracture pain** (no proven benefit) **(TO)**

**Contraindications** — **pregnancy, epilepsy, pacemaker** · pads not over eyes, trans-cerebral, anterior neck, ant + post chest together, broken skin, tumour, spine · ✓ **metal implants are NOT a contraindication** (insufficient heating) **(TO)**\
✗ Wrong options: "relative"

## 6 Complications

**Choke syndrome** — socket too tight → venous obstruction · acute: red, indurated, **orange-peel** skin · chronic: **haemosiderin**, venous stasis ulcers

**Skin** — **contact dermatitis** (liner, socks, suspension → remove item) · cysts + sweating = **excess shear / poor fit** · scar massage

**Painful residual limb** — HO · bony prominence · poor fit · **neuroma** · thin soft tissue

### Transtibial prosthesis alignment & gait problems

| Problem | Cause / effect |
|---|---|
| **Swing-phase pistoning** | **Ineffective suspension** |
| **Stance-phase pistoning** | **Poor socket fit** / volume change (change stump sock) |
| **Inset (medialised) foot** | **Varus strain** · **circumduction** · pain **medial-proximal + lateral-distal** |
| **Outset (lateralised) foot** | **Valgus strain** · **broad-based gait** · pain **lateral-proximal + medial-distal** (e.g. lateral knee + medial distal stump → ✓ **reduce lateral offset**) |
| **Anterior foot** | Stable ↑ **knee extension** + patellar pain |
| **Posterior foot** | Unstable ↑ knee flexion · **drop-off / buckling** |
| Dorsiflexed foot | ↑ patellar pressure · drop-off |
| Plantar-flexed foot | Drop-off + ↑ patellar pressure (per Orthobullets) |
| **Heel too soft** | ↑ **knee extension** |
| **Heel too hard** | ↑ **knee flexion** + toe external rotation |

![Inset vs outset foot](../../MCQ/attachments/q23-illa-prosthesis-inset-outset-1.jpg)

**Drop-off (knee buckling in terminal stance)** — body weight over MTPs too early · caused by ↓ anterior support: DF foot, **posterior foot**, soft keel, **posterior toe break** → ✓ **move foot anterior**

## How it's asked

**"Inset BKA foot — EXCEPT?"** → **increased knee extension in stance**\
✗ Wrong options: varus strain · circumduction · medial-proximal pain

**"Drop-off in terminal stance — fix?"** → **move foot more anterior**\
✗ Wrong options: dorsiflex · move posterior · softer keel

**"Toe amputation, short stance, irregular toe-off?"** → **full-length steel shank + rocker sole**

**"Lateral knee + medial distal stump pain after BKA?"** → **reduce lateral offset of foot**

**"Hiking BKA amputee struggling on SACH?"** → **short-keel articulated dynamic-response foot**

**"SACH vs dynamic response — EXCEPT?"** → **longer midstance**\
✗ Wrong options: less replacement · less DF · ↑ contralateral GRF

**"Multi-axis articulated foot recommended for?"** → **BKA walking on uneven ground**

**"Most important factor choosing LL prosthesis?"** → **functional status**

**"Polycentric fluid knee vs constant friction — EXCEPT?"** → **lighter weight**

**"Polycentric hydraulic knee — EXCEPT?"** → **centre of rotation fixed anterior to weight line**

**"Body-powered vs myoelectric — EXCEPT?"** → **decreased harnessing**\
✗ Wrong options: heavy labour, lighter, less therapy, less maintenance

**"Myoelectric advantage — EXCEPT?"** → **more sensory feedback**

**"Least ↑ metabolic demand?"** → **traumatic transtibial**
