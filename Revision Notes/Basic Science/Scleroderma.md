# Scleroderma

*Basic Science · 96 / 108*

## 1 Basics

**Definition** — autoimmune disease of **collagen deposition + fibrosis** → hardening of skin, subcutis, muscle, internal organs

**Demographics** — **F > M (3–14:1)** · African American > Caucasian · **30–50 yr** · ✓ **rapidly progressive in children**

**Triggers** — genetic predisposition · **silica**, solvents (benzene), radiation

**Pathophysiology triad** — **collagen deposition + fibrosis** · **non-inflammatory vasculopathy** (microvascular fibroproliferation) · **autoimmunity**

### Genes & lab markers

**Genetics** — usually sporadic · HLA · **STAT4 → limited** · **IRF5 → diffuse**

| Antibody / lab | Association |
|---|---|
| **ANA** | **90–95%** · speckled / centromere · **nucleolar = specific** for systemic sclerosis |
| **Anti-centromere** | **Limited (CREST)** · ~50% |
| **Anti-Scl-70 (anti-topoisomerase I)** | **Systemic (diffuse)** · ~30% |
| Anti-histone | Also drug-induced lupus, SLE, RA |
| ESR, CRP | ↑ |
| Creatinine | Renal monitoring |
| **CXCL4** | ↑ → pulmonary fibrosis |
| **NT-proBNP** | ↑ → early pulmonary hypertension |

### Classification

| | **Limited** | **Diffuse (systemic)** |
|---|---|---|
| Skin | **Face + hands** | Widespread |
| Organs | — | **Kidney, lung, heart** |
| Course | — | **Rapidly progressive**, high mortality |
| Antibody | **Anti-centromere** | **Anti-Scl-70** |
| Subtype | **CREST** — **C**alcinosis · **R**aynaud · **E**sophageal dysmotility · **S**clerodactyly · **T**elangiectasia | — |

**Linear scleroderma (en coup de sabre)** — child with linear skin lesions + **limb atrophy** + **Achilles contracture / toe-walking** → ✓ **scleroderma** · early surgery + immunosuppression\
✗ Wrong options: arthrogryposis (non-progressive, no skin lesions) · JIA · eczema · abuse

## 3 Presentation

**Skin** — **diffuse pruritus** · **Raynaud** (white → blue → red; cold/stress) · tightness, induration, shiny loss of wrinkles · **sclerodactyly** · digital ulcers · diuretic-resistant oedema · **hyper- + hypopigmentation** · telangiectasia · calcinosis

**Hand contractures** — **PIP flexion + compensatory MCP hyperextension** · **1st web adduction contracture**

![Sclerodactyly](../../Orthobullets/attachments/ob322121-scleroderma2.jpg)

**MSK** — myalgia · arthralgia · **osteolysis (calcaneus)** · contractures, atrophy, LLD, angular malalignment (children)

**Systemic** — **acid reflux** (smooth muscle atrophy → ↓ LES pressure) · dry cough, dyspnoea (**restrictive lung disease**), dry rales · palpitations · cor pulmonale · **renal hypertension**

## 4 Diagnosis & Classification

### Key radiology findings

**CT chest** — **ground glass = early fibrosis** · honeycombing + bronchiolectasis = established interstitial fibrosis

![Honeycomb + ground glass — lung fibrosis](../../Orthobullets/attachments/ob322121-honeycomb-and-ground-glass-appearance-indicative-of-early-lu.jpg)

**Angiography** — loss of digital flow

**Manometry** — **distal oesophageal aperistalsis + ↓ LES tone** · PFTs for early fibrosis · routine ECG

**Differential** — nephrogenic systemic fibrosis · eosinophilic fasciitis · GVHD

## 5 Management

| Problem | Treatment |
|---|---|
| Progression (esp. lung) | **Methotrexate · mycophenolate** · **cyclophosphamide** if refractory |
| **Renal involvement** | **ACE inhibitor** |
| Pruritus | Antihistamines |
| **Raynaud** | **Calcium-channel blockers** |
| Pulmonary hypertension | **Ambrisentan + tadalafil** |

### Operative criteria

| Deformity | Surgery |
|---|---|
| Symptomatic calcinosis | I&D |
| **Fixed PIP flexion** | **PIP arthrodesis** |
| **Fixed MCP hyperextension** | **MCP resection arthroplasty** |
| **1st web contracture** | **Adductor pollicis release ± trapeziectomy** |
| Digital gangrene | Amputation |

## 6 Complications

**Complications** — digital infarct/gangrene · **pulmonary hypertension** · **pulmonary fibrosis** · renal failure · pulmonary/renal/cardiac involvement = worse prognosis

## How it's asked

**"7-yr-old rapidly progressive toe-walking, limb atrophy, linear skin lesions?"** → **scleroderma**\
✗ Wrong options: arthrogryposis · JIA · abuse

**"Anti-topoisomerase I antibodies?"** → **scleroderma (diffuse)**
