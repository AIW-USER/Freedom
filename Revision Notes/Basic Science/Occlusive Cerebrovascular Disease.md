# Occlusive Cerebrovascular Disease

*Basic Science · TO notes*

## 1 Basics

### Definition & categories

**OCVD** — stenosis / occlusion of brain-supplying arteries → transient or permanent ischaemia from ↓ cerebral blood flow (TO)

**Extracranial** — carotid + vertebral arteries in the neck · **intracranial** — circle of Willis + branches (TO)

### Epidemiology

| Parameter | Data (TO) |
|---|---|
| Age | **> 45 years** |
| Sex | **Male > female** |
| Commonest vessel | **Internal carotid artery** |
| Commonest site | **Carotid bifurcation** |
| Commonest cause | **Atherosclerosis** |

**Stroke burden** — \~13 million / year · **80–85% ischaemic** · 15–20% haemorrhagic (TO)

### Cerebral blood flow thresholds

| CBF (mL/100 g/min) | State (TO) |
|---|---|
| **50–60** | Normal |
| **20** | **Ischaemia** threshold |
| **10** | **Infarction** threshold |

**Penumbra** — ischaemic but **salvageable** tissue → window for reperfusion (TO)

### Circulation & watershed

**Anterior** — ICA → ACA + MCA → frontal, parietal, temporal · **posterior** — vertebral → basilar → PCA → occipital, brainstem, cerebellum (TO)

**Watershed zones** — **ACA–MCA** and **MCA–PCA** borders → vulnerable to **hypoperfusion** (TO)

## 2 Mechanism

### Etiopathogenesis

| Mechanism | Description (TO) |
|---|---|
| **Atherosclerosis** | Plaque → narrowing → thromboembolism (**commonest**) |
| Thrombosis | Plaque rupture → local clot |
| **Embolism** | Cardiac (**AF**, MI, endocarditis) or atheromatous |
| Dissection | Intimal tear → false lumen → occlusion |
| Vasculitis | Takayasu, PAN, SLE, **Moyamoya** |
| Hypercoagulable | Malignancy, protein C/S deficiency, pregnancy |

**Other secondary causes** — radiation arteritis · **fibromuscular dysplasia** (TO)

## 3 Presentation

### Stroke syndromes

| Syndrome | Territory | Features (TO) |
|---|---|---|
| **ACA** | Medial frontal + parietal | Contralateral **leg > arm** · **urinary incontinence** |
| **MCA** | Lateral hemisphere | **Face / arm > leg** · aphasia (dominant) · **neglect (non-dominant)** |
| **PCA** | Occipital | **Contralateral homonymous hemianopia** |
| **Vertebrobasilar** | Brainstem + cerebellum | Vertigo, ataxia, diplopia, dysarthria, **drop attacks** |
| **Lacunar** | Small perforators | **Pure motor / pure sensory** · ataxic hemiparesis |

**TIA** — deficit **< 24 h** (usually < 1 h), complete recovery · **\~10% stroke risk within 3 months** (TO)

## 4 Diagnosis & Classification

### Key radiology findings

| Modality | Finding / use (TO) |
|---|---|
| **NCCT** | Rule out haemorrhage · early signs: loss of grey–white differentiation, **insular ribbon sign** |
| **MRI DWI / FLAIR** | ✓ **Earliest infarct detection** (minutes) · **DWI bright, ADC dark** |
| CTA / MRA | Stenosis, occlusion, dissection |
| **Carotid Doppler** | Flow velocity · **> 50% stenosis significant** |
| **DSA** | **Gold standard** vascular mapping · reserved for intervention planning |
| CT / MR perfusion | **Core vs penumbra** → thrombolysis selection |

### NASCET stenosis grading

**Formula** — **% stenosis = [1 − (residual lumen ÷ distal normal lumen)] × 100** (TO)

| Grade | Narrowing (TO) |
|---|---|
| Mild | **< 50%** |
| Moderate | **50–69%** |
| Severe | **≥ 70%** → highest stroke risk |
| Occlusion | 100% |

## 5 Management

### Acute ischaemic stroke

| Modality | Agent / dose | Window (TO) |
|---|---|---|
| **IV thrombolysis** | **Alteplase 0.9 mg/kg (max 90 mg)** | **≤ 4.5 h** |
| Tenecteplase | **Single bolus** | Similar efficacy, easier |
| **Mechanical thrombectomy** | Stent retriever | **6–24 h** (large-vessel occlusion, viable penumbra) |

**Supportive** — SpO₂ **> 94%** · MAP **> 80** · glucose **< 180 mg/dL** · avoid fever (TO)

### Secondary prevention

| Strategy | Intervention (TO) |
|---|---|
| Antiplatelet | **Aspirin 75–150 mg** or **clopidogrel 75 mg** |
| **Dual antiplatelet** | **21–90 days** in high-risk TIA / minor stroke |
| **Anticoagulation** | **Cardioembolic** (AF, LV thrombus) · DOAC or warfarin |
| Statin | Atorvastatin 40–80 mg |
| Targets | BP **< 140/90** · HbA1c **< 7%** · stop smoking |

### Carotid revascularisation (operative criteria)

| Stenosis (NASCET) | Action (TO) |
|---|---|
| **Symptomatic ≥ 70%** | **CEA recommended** |
| Symptomatic 50–69% | **Selective** CEA |
| **Asymptomatic > 80%** | Consider intervention |
| Complete occlusion / near-total collapse | **CEA contraindicated** |

```
Carotid stenosis
├─ Symptomatic ≥ 70% → CEA
├─ Symptomatic 50–69% → SELECTIVE CEA
├─ Asymptomatic > 80% → CONSIDER INTERVENTION
└─ Complete occlusion → NO CEA
```

**CEA** — **gold standard** for accessible lesions · **carotid stenting (CAS)** — high surgical risk or **irradiated neck** (TO)

**Peri-operative** — continue antiplatelet · normotension (avoid **hyperperfusion syndrome**) (TO)

### Special variants

| Variant | Key facts (TO) |
|---|---|
| **Moyamoya** | Progressive **terminal ICA** stenosis + collaterals → **"puff of smoke"** on angiography · children / young adults · TIA, stroke, seizures · **EDAS** (indirect) or **STA–MCA bypass** (direct) |
| **Takayasu arteritis** | Granulomatous large-vessel vasculitis (aorta, subclavian, carotid) · **young females** · limb claudication, weak pulses, **BP discrepancy** · steroids + immunosuppressants ± angioplasty / stent |
| **Radiation arteriopathy** | Late intimal fibrosis after neck irradiation · often **stenting** |

## 6 Complications

**List** — recurrent stroke / TIA · **haemorrhagic transformation** after thrombolysis · **hyperperfusion syndrome** after CEA / CAS (headache, seizure, haemorrhage) · contrast nephropathy · restenosis (TO)

## X vs Y

| | CEA | CAS |
|---|---|---|
| Type | Surgical plaque removal | Endovascular stent |
| Use | **Gold standard**, accessible lesions | High surgical risk · **irradiated neck** (TO) |

| | IV thrombolysis | Mechanical thrombectomy |
|---|---|---|
| Window | **4.5 h** | **Up to 24 h** (viable penumbra) |
| Target | Any eligible ischaemic stroke | **Large-vessel occlusion** (TO) |

## How it's asked

**"Earliest imaging to detect infarct?"** → **MRI DWI** (TO)

**"tPA window?"** → **4.5 hours** (TO)

**"Symptomatic carotid stenosis — CEA threshold?"** → **≥ 70% (NASCET)** (TO)

**"'Puff of smoke' on angiogram?"** → **Moyamoya disease** (TO)

**"Infarct between ACA–MCA territories?"** → **watershed infarct** (TO)

**"Commonest artery / site in OCVD?"** → **ICA at the carotid bifurcation** (TO)
