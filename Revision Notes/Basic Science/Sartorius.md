# Sartorius

*Basic Science · 94 / 108*

## 1 Basics

### Anatomy

| | Sartorius |
|---|---|
| **Origin** | **ASIS** |
| **Insertion** | Superior medial tibial shaft near tuberosity — **pes anserinus** (with gracilis + semitendinosus) |
| **Action** | **Flexes + laterally rotates hip** · flexes knee |
| **Innervation** | **Femoral nerve (L2, L3, L4)** |
| **Arterial supply** | Muscular branches of femoral artery |

### Femoral nerve innervation

**Femoral nerve supplies** — **sartorius** · **rectus femoris** (quadriceps) \
✗ Wrong options: obturator · tibial · peroneal · "sartorial nerve" (doesn't exist)
