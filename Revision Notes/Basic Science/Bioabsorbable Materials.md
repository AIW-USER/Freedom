# Bioabsorbable Materials

*Basic Science · 12 / 108*

## 1 Basics

### Why bioabsorbable

**Problems solved** — migration · growth disturbance · rigidity · radio-opacity · infection · **need for removal**

**Indications** — paediatrics (transphyseal **SR PLGA 80/20** screws → only temporary growth arrest in rabbits) · osteomyelitis (antibiotic-eluting PLA) · **carriers for rhBMP-2/-7** · iliac-crest harvest site

### Types

| Material | Properties |
|---|---|
| **PGA** | **Hydrophilic**, crystalline · Tg **36 °C** · **early degradation + strength loss** · must be heated/cooled intraop |
| **PLA** | More **hydrophobic** than PGA |
| **PLLA** (L-isomer) | Hydrophobic, crystalline · Tg **57 °C** · **degrades over years** → **late reactions** |
| D-isomer PLA | Amorphous, less stable · for copolymers |
| **P(L/D)LA** | Adding D → less tightly packed → **less crystalline, faster** than PLLA · e.g. 70/30 (maxillofacial) |
| **PLGA** (PLA + PGA) | Low crystallinity |
| **Self-reinforced (SR)** | Oriented fibres in matrix (composite) · ↑ **rigidity + strength** · **malleable at room temp** · withstands 4× bending · minimal memory · **gamma sterilisation OK** (✗ Wrong options: non-reinforced (↓ molecular weight)) |

### Absorption time

| Material | Time |
|---|---|
| **SR PLLA** | **>5–6 yr** |
| PLLA | >5 yr |
| P(D/L)LA 70/30 | 2–3 yr |
| P(D/L)LA 96/4 | 2 yr |
| PLGA 80/20 | 1–2 yr |
| SR PGA | 0.5–1 yr |
| PDS | 2 months |
| **PGA** | **1–2 months** |

## 2 Mechanism

### Biodegradation & excretion

**Main mechanism** — **random hydrolysis of ester bonds** → ↓ molecular weight → loss of strength → **CO₂ + H₂O + Krebs (TCA) cycle** products

![Poly-hydroxy-acid degradation](../../Orthobullets/attachments/ob9071-biodegradation.jpg)

**PLA excretion** — lactic acid → Krebs cycle → ✓ **CO₂ via lungs (respiratory)**\
✗ Wrong options: hepatic · renal · GI

**Kidney** — **PGA and PDS** (poly-p-dioxanone) products may be renally excreted

**Enzymes** — involved in PLA + PGA degradation

**↓ pH** — breakdown products lower pH → **accelerate** breakdown

**Crystallinity** — **amorphous / hydrophilic → faster** · crystalline / hydrophobic → slower

**Other variables** — composition, MW · fibre orientation (SR vs simple) · monomer concentration · stereoisomerism · porosity, surface area/volume · sterilisation · enzymatic vs hydrolytic

## 4 Diagnosis & Classification

### Histopathology

**Granulomatous inflammation** — T lymphocytes (**CD4 > CD8**) · plasma cells · endothelial cells · **birefringent polymer debris** · thin macrophage layer · **multinucleated giant cells**

**Capsule** — **inner** 2–3-cell layer (**type III collagen**) · **outer** fibrous layer (**type I collagen**)

**Sequence** — neutrophils → CD4 T cells → **macrophages last**

## 6 Complications

### Adverse tissue reactions

**Incidence** — **3% children** · **up to 60% adults**

**Cause** — degradation outpaces debris clearance → **sterile fluid** accumulation · fluctuant papules · synovitis · sinus

**Timing** — late with slow materials (**PLLA ~5 yr**)

**Labs** — cultures **sterile** unless secondary infection

**X-ray** — **osteolysis** in up to **60%**

```
Bioabsorbable implant reaction
├─ Mild, sterile → OBSERVE
├─ Fluid / sinus → ASPIRATE ± DEBRIDE
│      └─ Sterile implant failure or 2° infection → REMOVE IMPLANT
└─ Severe OA → ARTHRODESIS
```

## X vs Y

| | PGA | PLLA |
|---|---|---|
| Water affinity | Hydrophilic | Hydrophobic |
| Tg | 36 °C | 57 °C |
| Absorption | **1–2 months** | **>5 yr** |
| Problem | Early strength loss | Late reactions |
| Excretion | Kidney possible | Lungs (CO₂) |

## How it's asked

**"PLA implants excreted after absorption by?"** → **respiratory system (CO₂)**\
✗ Wrong options: hepatic · renal (PGA/PDS) · GI

**"Bioabsorbable that degrades fastest?"** → **PGA** (1–2 months) · slowest **SR PLLA**

**"Degrade faster — amorphous or crystalline?"** → **amorphous / hydrophilic**
