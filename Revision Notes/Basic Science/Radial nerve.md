# Radial nerve

*Basic Science · 89 / 108*

## 1 Basics

### Anatomy

**Course** — **posterior cord** → exits **triangular interval** (long head triceps ↔ humerus) with **profunda brachii artery** → **spiral groove** → pierces lateral intermuscular septum **7.5 cm proximal to elbow** → at lateral humeral condyle gives cutaneous branches (superficial radial, posterior cutaneous) → **PIN** through **supinator**, winds around **radial neck**

**Accompanying artery** — ✓ **profunda brachii**\
✗ Wrong options: posterior humeral circumflex (axillary nerve/quadrangular space) · scapular circumflex (triangular space) · brachial (medial with median/ulnar) · lateral thoracic (serratus anterior)

## 3 Presentation

### Injury level

| Deficit | Level |
|---|---|
| ✗ Wrong option: wrist, thumb, finger extension (wrist drop) | **Radial nerve** — spiral groove / distal-third humeral shaft |
| ✗ Wrong option: digit + thumb extension · ✓ **wrist extension with radial deviation** | **PIN at radial neck** (✗ Wrong options: spiral groove · midshaft radius · humeral necks) |

**Holstein-Lewis fracture** — **distal-third humeral shaft** fracture + **radial nerve neuropraxia** · **80–90% recover** with observation → not an indication for surgery

![Holstein-Lewis fracture](../../MCQ/attachments/q212964-a-ap-holstein-lewis.jpg)

## 5 Management

### Reinnervation order (TO)

**Recovery direction** — **proximal → distal** **(TO)**

| Recovery (TO) | Muscle / function |
|---|---|
| **First muscle** | **Brachioradialis** |
| **First function (wrist/finger drop after humeral shaft fracture)** | ✓ **Wrist extension (radial deviation)** (✗ Wrong options: supination · elbow extension · MCP extension) |
| **Last function** | **MCP joint extension** |
| **Last muscle** | ✓ **Extensor indicis proprius** (✗ Wrong options: brachioradialis, ECRB, APL, EPL) |

### Critical period of delay (TO)

**Critical period** — time beyond which motor return isn't expected if repair delayed **(TO)**

| Nerve (TO) | Critical period |
|---|---|
| **Radial** | ✓ **15 months** |
| PIN | 9 months |
| Ulnar — high | 9 months |
| Ulnar — low | 15 months |
| Median — high | 9 months |
| Median — low | 12 months |
| Sciatic | 12–15 months |
| CPN | 12 months |

## How it's asked

**"Radial palsy after humeral shaft ORIF, nerve intact — first function to recover?"** → **wrist extension** **(TO)**

**"Critical period of delay in radial nerve palsy?"** → **15 months** **(TO)**\
✗ Wrong options: 9, 10, 12

**"Last muscle reinnervated in radial palsy?"** → **extensor indicis proprius**

**"GSW — can't extend digits/thumb, wrist extends with radial deviation — level?"** → **radial neck** (PIN)

**"Holstein-Lewis fracture, wrist drop — artery with injured nerve?"** → **profunda brachii**
