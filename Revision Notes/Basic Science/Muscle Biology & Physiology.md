### Sarcomere

**Units** — fibre (cell, from myoblasts) → myofibril (chain of sarcomeres) · **thick = myosin**, **thin = actin**

| Band | Content | In contraction |
|---|---|---|
| **A band** | Actin + myosin | **Unchanged** |
| **I band** | Actin only | Shortens |
| **H zone** | Myosin only | Shortens |
| **Z line** | Actin attachment, sarcomere border | Move closer |

### Action potential & excitation–contraction coupling

**Nerve action potential** — ✓ **Na⁺ through voltage-gated channels** (positive-feedback depolarisation)

**Motor end plate** — ACh released → binds ACh receptor · **myasthenia gravis** = ↓ ACh receptors · **botox** = blocks ACh release

**Coupling** — depolarisation → sarcoplasmic reticulum **releases Ca²⁺** → **Ca²⁺ binds troponin** → tropomyosin shifts → myosin sites on actin exposed → cross-bridges + ATP hydrolysis → sliding · **low Ca²⁺: tropomyosin blocks** binding sites

## 2 Mechanism

### Contraction types (concentric, eccentric, isotonic)

| Type | Definition | Example |
|---|---|---|
| **Isometric** | Constant **length** | **Push against wall** |
| **Isotonic** | Constant **tension** — ✓ **concentric and eccentric** | **Biceps curl up AND down** |
| **Concentric** | Shortens while contracting | ✓ **Upward biceps curl** |
| **Eccentric** | Lengthens while contracting · **highest forces** | Lowering phase · ✓ **distal biceps rupture (eccentric phase of isotonic exercise)** |
| **Isokinetic** | Constant **speed** (Cybex machine) | — |
| **Plyometric** | Rapid lengthening → contraction | Box jumps |

### Force generation & fibre types (cross-sectional area, recruitment)

**Force / maximal tension** — ✓ **most dependent on cross-sectional area** (number of contracting myofibrils)\
✗ Wrong options: fibre type · length (Blix curve) · morphology (pennation angle)

**Speed + duration of contraction** — ✓ **fibre type**

**Progressive overload (strength training)** — ✓ **muscle fibre hypertrophy** (↑ fibre size), ↑ coordination

| | **Type I (slow twitch)** — "slow red ox" | **Type II (fast twitch)** |
|---|---|---|
| Metabolism | **Aerobic, oxidative** | **Anaerobic, glycolytic** (IIa oxidative-glycolytic, IIb glycolytic) |
| Energy | Krebs / oxidative phosphorylation | ATP-CP |
| Use | **Endurance** · low strength, low speed | **Sprinting** · high strength + speed |
| Features | ↑ mitochondria, vascular | ↑ ATPase, low triglyceride · **fatigue rapidly** (IIb) |
| Atrophy | **First to atrophy with deconditioning** | — |

**Recruitment order (size principle)** — ✓ **Type I (slow, fatigue-resistant) → Type IIa (fast, fatigue-resistant) → Type IIb (fast, fatigable)** · no "slow fatigable" units

### Metabolic systems

| System | Duration | Example | Notes |
|---|---|---|---|
| **ATP-CP (phosphagen)** | **<20 s** | 100 m sprint | Anaerobic, **no lactate** · creatine supplement (cramps) |
| **Lactic anaerobic** | **20–120 s** | 400 m | Glucose → lactic acid |
| **Aerobic** | Long, low intensity | Distance running | Krebs cycle, glucose + fatty acids |

## 6 Complications

### Muscle injury & healing

**Soreness (DOMS)** — **oedema + inflammation** of connective tissue · worse with **unaccustomed eccentric** exercise · **peaks 24–48 h** · ↑ CK

**First cells after injury (contusion)** — ✓ **neutrophils** (free radicals may ↑ damage)

**Strain** — ✓ **myotendinous junction** (eccentric) · inflammation → fibrosis · contraction bands seal membrane defects · basal lamina scaffolds preserved

**Healing phases** — necrosis → inflammation → repair → fibrosis · regeneration needs macrophage clearance (NSAIDs may impair)

**Fibrosis** — ✓ **TGF-β1** · regeneration trophic factors **IGF-1, bFGF** · **angiotensin-II receptor blockade ↓ fibrosis**

**Atrophy** — disuse/denervation → fatty infiltration, ↑ fatigability · **single-joint muscles atrophy faster** · ↓ CSA → ↓ force

## How it's asked

**"Upward biceps curl — contraction?"** → **concentric**

**"Distal biceps rupture during dumbbell curl — phase?"** → **eccentric phase of isotonic exercise**

**"Isotonic contraction?"** → **both upward and downward biceps curl**

**"True of skeletal muscle?"** → **duration + speed depend on fibre type**\
✗ Wrong options: force depends on length/fibre type

**"Progressive overload in adults →?"** → **fibre hypertrophy**

**"Cross-sectional area determines?"** → **maximal tension**

**"Force most dependent on?"** → **cross-sectional area**

**"Motor-unit recruitment order?"** → **slow fatigue-resistant → fast fatigue-resistant → fast fatigable**

**"First cells after thigh contusion?"** → **neutrophils**

**"Promotes fibrosis after muscle injury?"** → **TGF-β1**\
✗ Wrong options: IGF-1, bFGF (regeneration)

**"Na⁺ through voltage-gated channel →?"** → **nerve action potential**
