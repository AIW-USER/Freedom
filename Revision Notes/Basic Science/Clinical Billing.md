# Clinical Billing

*Basic Science · 24 / 108*

## 1 Basics

### Definitions

| Term | Meaning |
|---|---|
| **CPT** | 5-digit code for the **procedure/service** → reimbursement · Category I (00100–99499) · Category III = provisional/emerging |
| **RVU** | Unit value per CPT code (4 factors) |
| **ICD-10** | WHO **diagnosis** classification · **3–7 alphanumeric characters** (1st alpha, 2nd numeric) · >68,000 codes (vs ~13,000 ICD-9) |
| **E&M** | Evaluation and management (office/hospital visits) |
| **Modifier** | 2-digit code for a special situation |

### ICD-10 & modifiers

**ICD-10 describes** — chronicity · **phase of care** · effects (routine, complication) · **laterality**

**7th character** — ✓ **phase of treatment / encounter**\
✗ Wrong options: site · laterality · aetiology · category

| 7th char | Meaning |
|---|---|
| **A** | Initial, closed fracture |
| B | Initial, open type I/II |
| C | Initial, open IIIA–C |
| **D** | Subsequent, routine healing |
| G | Subsequent, delayed healing |
| **K** | Subsequent, **nonunion** |
| **P** | Subsequent, **malunion** |
| **S** | **Sequela** |
| E/F, H/J, M/N, Q/R | Open-fracture equivalents (I/II vs IIIA–C) |

| Modifier | Use |
|---|---|
| **-22** | Unusually complicated (difficulty, time, effort) |
| **-24** | **Unrelated E&M** in the postoperative period |
| **-25** | **Significant, separate E&M on the day of a (minor) procedure** |
| **-58** | ✓ **Staged / planned / more extensive procedure in global period** · **restarts global** · 100% paid (e.g. spacer removal + graft, 2nd-stage PJI) |
| **-59** | Distinct procedural service, same encounter (different site, incision, lesion) |
| -76 | Repeat procedure |
| **-78** | **Unplanned return to OR** for related condition/complication in global period |
| **-79** | **Unrelated** procedure in global period · overlapping globals · 100% paid |

## 5 Management

### New vs established patient

**New patient** — no professional services from the physician **or anyone in the same group and same specialty within 3 years**

**Established** — seen by physician or same-group same-specialty partner **within 3 years**

**Exception** — hand + sports surgeons with a **CAQ** may bill patients seen by other group orthopaedists as new

**Consultation** — requested by another physician for **advice** · request documented · level documented · **written response** to requester · no 3-yr rule · **Medicare no longer recognises consult codes**\
✗ Wrong options: transfer of care

**Coding error rate** — 32.4% of Medicare claims (Shalowitz) · consult errors common

### E&M coding & global period

**Component-based level** — history + examination + MDM · **billed at the lowest of the three**

**Time-based** — visit mostly counselling/coordination · time documented

**Global period** — 0, 10 or **90 days** · single payment

| In the 90-day global | Not in the global |
|---|---|
| Preop visits/work, marking, positioning, prep | Diagnostic tests (e.g. POD1 CBC) |
| Skin-to-skin work | **Immobilisation applied outside OR** |
| **Immobilisation/bracing applied in OR** | Visits for separate problems |
| Inpatient + postop visits (physician **or extender**) | Evaluation by a different group |
| **Closed fracture "restorative treatment" follow-up** (code 99024, $0) | **Reoperation for complications** (infection) · **staged procedures** |

**Fraud** — services not provided · not provided by billing physician · not supported by documentation · **intentional or not** · responsibility = **billing physician**

## How it's asked

**"Which scenario is a new patient (2009 guidelines)?"** → **arthroscopy by partner 4 years ago**\
✗ Wrong options: seen <3 yr by you or partner

**"Time to revert to new patient?"** → **3 years**

**"Referred with consult request, partner saw 4 yr ago, history L3/exam L4/MDM L3, letter sent?"** → **level 3 consultation**

**"Cast removal 4 wk after closed reduction of phalanx fracture?"** → **not billed** (90-day global)

**"ICD-10 seventh character?"** → **phase of treatment**

**"Planned second-stage spacer removal + graft at 6 wk — modifier?"** → **58**\
✗ Wrong options: 78 (unplanned) · 79 (unrelated) · 59 · 25
