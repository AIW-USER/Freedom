# Flexor Hallucis Longus

*Basic Science · 36 / 108*

## 1 Basics

### Anatomy

| | Flexor hallucis longus |
|---|---|
| **Origin** | **Inferior ⅔ of posterior fibula** + lower interosseous membrane |
| **Insertion** | Plantar base of **distal phalanx of great toe** |
| **Action** | Flexes great toe · helps supinate · very weak ankle plantarflexor |
| **Innervation** | **Tibial nerve (S2, S3)** |
| **Arterial supply** | Muscular branches of peroneal + posterior tibial arteries |

### Origin — leg compartments (TO)

| Compartment | Origin rule (TO) |
|---|---|
| **Anterior** | All from **fibula** except **tibialis anterior** (tibia) |
| **Lateral** | All from fibula (peroneus longus, brevis) |
| **Posterior** | ✓ **Only FHL from fibula alone** · soleus + tibialis posterior from **both** tibia and fibula · FDL from tibia |

| Posterior muscle (TO) | Origin | Insertion |
|---|---|---|
| Gastrocnemius | Femoral condyles | Calcaneus (Achilles) |
| Plantaris | Lateral supracondylar ridge | Calcaneus |
| Soleus | Tibia + fibula | Calcaneus (Achilles) |
| Popliteus | Lateral femoral condyle | Tibial shaft |
| FDL | **Tibia** | Distal phalanges, lateral 4 toes |
| **FHL** | **Fibula** | Distal phalanx, great toe |
| Tibialis posterior | Tibia + fibula + IOM | Navicular tuberosity |

### MRI anatomy

**Axial ankle MRI** — FHL tendon runs on **posterior tibia, just anterior to Achilles** · peroneals behind fibula · tibialis posterior + FDL behind medial malleolus

## How it's asked

**"Axial ankle MRI, tendon on posterior tibia just anterior to Achilles?"** → **FHL**\
✗ Wrong options: tibialis posterior, FDL (behind medial malleolus) · peroneals (behind fibula)

**"Posterior-compartment muscle arising from fibula only (TO)?"** → **FHL**\
✗ Wrong options: tibialis posterior, soleus (both bones) · FDL (tibia)
