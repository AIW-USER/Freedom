# Lumbrical Muscles

*Basic Science · 59 / 108*

## 1 Basics

### Anatomy & function

| | Lumbricals (4) |
|---|---|
| **Origin** | **FDP tendons** (radial side) |
| **Insertion** | **Radial lateral band** of extensor expansion |
| **Action** | **Flex MCP** (force palmar to MCP axis) + **extend PIP/DIP** |
| **Innervation** | **1st + 2nd: median** · **3rd + 4th: ulnar** |
| **Arterial supply** | Palmar metacarpal arteries |

![Lumbricals arising from FDP](../../Orthobullets/attachments/ob10051-lumbricals-moved.jpg)

| Muscle | Pennation / origin |
|---|---|
| **1st, 2nd lumbricals** | ✓ **Unipennate** · radial side of own FDP |
| 3rd, 4th lumbricals | **Bipennate** · adjacent FDP tendons |
| Dorsal interossei (4) | Bipennate · adjacent metacarpals · **ABduct** |
| Palmar interossei (3) | Ulnar side index, radial side ring + small MC · **ADduct** |

**Intrinsic-plus hand** — tight lumbricals + interossei → MCP flexion with **↓ supple PIP/DIP flexion**

## How it's asked

**"Unipennate, radial side of FDP, inserts radial lateral band, palmar to MCP axis?"** → **1st lumbrical**\
✗ Wrong options: 4th lumbrical (bipennate) · dorsal interosseous
