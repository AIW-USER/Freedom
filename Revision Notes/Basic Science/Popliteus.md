# Popliteus

*Basic Science · 81 / 108*

## 1 Basics

### Popliteus anatomy

| | Popliteus |
|---|---|
| **Origin** | **Lateral femoral condyle** — anterior popliteal groove (main) |
| **Insertion** | **Posterior (posteromedial) tibia**, fan-like, just above popliteal (soleal) line |
| **Action** | **Internally rotates tibia on femur** → **unlocks knee** at start of flexion |
| **Innervation** | **Tibial nerve (L4, L5, S1)** |
| **Arterial supply** | Medial inferior genicular (popliteal) + muscular branch of posterior tibial artery |

![Popliteus](../../Orthobullets/attachments/ob10088-popliteus.jpg)

**Tripartite proximal tendon (TO)** — ✓ **tripartite** · main attachment **lateral femoral condyle** · + **head of fibula** · + **posterior lateral meniscus** **(TO)**\
✗ Wrong options: bipartite · medial femoral condyle

| Popliteus action (TO) | Foot position |
|---|---|
| **External rotation of femur** | Foot plantigrade (weight-bearing) |
| **Internal rotation of tibia** | Foot free |
| **"Unlocking of the knee"** | Both |

## 5 Management

### Posteromedial exposure

**Extended posteromedial knee approach** — interval **medial gastrocnemius ↔ posterior semimembranosus** → posteromedial capsule (inside-out meniscal repair)

**Deeper exposure** — posteromedial tibia / **PCL fossa** → ✓ **subperiosteal elevation of popliteus** off posterior tibia\
✗ Wrong options: plantaris, semitendinosus, gracilis (superficial) · soleus (distal)

**Uses** — meniscal repair · tibial plateau ORIF · **PCL tibial avulsion** fixation · PCL tibial inlay · Baker's cyst · posterior capsular release

**At risk** — superficial **saphenous nerve + vein** · popliteal artery branches (inferior medial genicular often spared)

## How it's asked

**"True about popliteus?"** → **tripartite, main proximal attachment lateral femoral condyle** **(TO)**

**"Extended posteromedial approach — dissect what for PCL fossa / posterior tibia?"** → **popliteus**\
✗ Wrong options: plantaris, soleus
