# Extensor digitorum longus

*Basic Science · 32 / 108*

## 1 Basics

### Anatomy

| | Extensor digitorum longus |
|---|---|
| **Origin** | Lateral tibial condyle, proximal ¾ anterior fibula, upper interosseous membrane, fascia cruris, anterior intermuscular septum |
| **Insertion** | 4 slips after inferior extensor retinaculum → dorsal middle + distal phalanges (extensor expansion) |
| **Action** | Extends toes 2–5 · dorsiflexes ankle |
| **Innervation** | **Deep peroneal nerve (L4, L5, S1)** |
| **Arterial supply** | Anterior tibial artery |

![Extensor digitorum longus](../../Orthobullets/attachments/ob10080-extensor-digitorum-longus.jpg)

### Deep peroneal nerve function

**Supplies** — tibialis anterior · **EHL** · EDL · peroneus tertius · EDB · EHB

**Course** — posterior half of tibial shaft proximally · crosses distal tibia **40–110 mm above the ankle joint**

**Anterolateral ankle approach** — always exposes **superficial peroneal nerve** (subcutaneous)

## X vs Y

| Deficit | Nerve |
|---|---|
| **Great-toe extension** | ✓ **Deep peroneal** |
| Hindfoot eversion (peronei) | Superficial peroneal |
| Hindfoot inversion (tibialis posterior) | Tibial |
| Great-toe flexion (FHL) | Tibial |
| Ankle plantarflexion (gastrosoleus) | Tibial |
| Posterior distal leg + lateral foot skin | Sural |

## How it's asked

**"Deep peroneal nerve injury causes?"** → **weak great-toe extension**\
✗ Wrong options: eversion (SPN) · inversion/toe flexion/plantarflexion (tibial)
