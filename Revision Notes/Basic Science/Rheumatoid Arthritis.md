# Rheumatoid Arthritis

*Basic Science · 92 / 108*

## 1 Basics

### Epidemiology

**Commonest inflammatory arthritis** — **3% women, 1% men**

**Genetics** — **HLA-DR4**, HLA-DW4 · ~**15%** monozygotic twin concordance · trigger: infection or HLA locus

**Twin concordance** — \~**15%** (Orthobullets) · **15–30%** (TO) — read the options

**Sex** — **F:M 3:1** · peak 30s–50s (TO)

**Genes (TO)** — **HLA-DRB1 shared epitope (DR4)** · PTPN22 · CTLA4 · STAT4 · TNFAIP3 · CCL21 · **PADI4** (Japanese)

**Triggers (TO)** — **smoking** · **gingivitis (Porphyromonas gingivalis)**, Aggregatibacter, EBV · gut microbiota · triggering sites lung, mouth, gut

### Pathophysiology & serology (RF, anti-CCP, synovium)

**Immunology** — **IgM cell-mediated (T cell–MHC class II)** response → soft tissue (early) → cartilage, bone (later) \
✗ Wrong options: IgA/IgD/IgE/IgG-mediated

**Primary destructive cell** — **mononuclear cells** · cytokines **IL-1, TNF-α** (+ IL-6)

**Cascade** — Ag–Ab reactions → microvascular proliferation/obstruction → **pannus** (prominent **intimal hyperplasia**) → subluxation, chondrocyte death → **tenosynovitis + tendon rupture**

| RA synovium | |
|---|---|
| ✓ **Intimal hyperplasia** | 2 → **10–20 cell layers** |
| ✓ **↓ Apoptosis** of lining | |
| ✓ **↑ Angiogenesis** | |
| ✓ **Abundant lymphocytes** | Perivascular lymphoid follicles |
| ✗ Wrong option: **basement membrane disruption** | Synovium **has no true basement membrane** |

**Pannus** — invasive granulation tissue · fibroblast-like synoviocytes, few inflammatory cells · anchorage-independent growth → directly destroys cartilage

**Bone erosion** — ✓ **TNF + IL-6 (+ IL-1) blockade slows erosion** · TNF mobilises osteoclast precursors · **M-CSF + RANKL** drive **osteoclast** differentiation · **denosumab** slows erosion, not inflammation · TNF ↑ **Dkk-1** → blocks **Wnt** → ↓ repair (Wnt interference ↑ erosion) · erosion ∝ synovitis · steroids, MTX, leflunomide bone-sparing via ↓ synovitis\
✗ Wrong options: "synovial fibroblasts resorb"

**Citrullination (TO)** — **PAD enzyme** converts **arginine → citrulline** (filaggrin, fibrinogen) → neoantigens → MHC II T cells → B cells → **ACPA** · epitope spreading in maturation stage

**Stages (TO)** — triggering → maturation (lymphoid tissue, marrow) → targeting (synovium) → fulminant (fibroblast-like synoviocytes lose contact inhibition, resist apoptosis)

**Synovial lining (TO)** — **type A (macrophage-like)** + **type B (fibroblast-like)** synoviocytes · CD4/CD8 lymphoid follicles with germinal centres

**Enzymes (TO)** — **MMP-3 most linked to cartilage destruction** (also MMP-1, 8, 9, ADAMTS) · **cathepsin B → subchondral bone destruction** (cathepsin K too) · IL-1, IL-17 → chondrocyte apoptosis

**Bare-area erosions (TO)** — where synovium inserts into periosteum → characteristic of RA

### Genes & lab markers

**Rheumatoid factor** — ✓ **IgM antibody against Fc of native IgG** · immune complexes deposit (kidney)\
✗ Wrong options: IgG vs IgM · IgA vs IgG

**RF positivity** — **75–80%** (Orthobullets) · **80–90%** (OB6543) — read the options · sensitive, not specific · also non-RA autoimmunity

**Anti-CCP** — ✓ **most sensitive + specific** · sensitivity **50–75%**, specificity **90–95%** · as sensitive as, more specific than RF · **high levels → erosive disease** · may precede arthritis · anti-CCP ⊂ **ACPA** · ACPA bind citrullinated vimentin on osteoclasts → TNF → osteoclastogenesis · **independently predicts erosion**\
✗ Wrong options: "synovitis but not erosion"

**RF / anti-CCP figures (TO)** — RF **75–85%** · may turn positive within 2 yr · high titre → extra-articular disease, poor prognosis · false + in Sjögren, SLE, vasculitis, chronic infection, liver disease, malignancy · anti-CCP **sensitivity 65%, specificity 95%** (TO) — read the options

**Seropositive vs seronegative (TO)** — seropositive (RF / anti-CCP +) → more severe, more erosive · seronegative → usually milder

**Other** — **anti-MCV** · ↑ ESR · ↑ CRP · **ANA in 30–40%** · joint fluid: **↓ complement**, ± RF

| Autoantibody | Disease |
|---|---|
| ✓ **Anti-IgG (RF)** | **RA** |
| Anti-dsDNA | SLE |
| Anti-ACh receptor | Myasthenia gravis |
| **Anti-topoisomerase I** | **Scleroderma** |
| Anti-GAD | Type 1 DM |

## 3 Presentation

**Symptoms** — insidious **morning stiffness** · symmetric **polyarthropathy** of hands + feet · **DIP spared** · also knees, C-spine, elbows, ankles, shoulders

**Rheumatoid nodules** — **commonest extra-articular manifestation** · **20%** (Orthobullets presentation) / **25%** (finger section) · **strongly RF+**, **aggressive disease** · over IP joints, **olecranon**, ulnar forearm · may form sinus · treat steroid injection / excision (cosmesis, pain, biopsy)

**Systemic** — rheumatoid vasculitis · pericarditis · pulmonary disease

| Syndrome | Features |
|---|---|
| **Felty** | RA + **splenomegaly + leukopenia** |
| **Still's** | Acute RA + **fever, rash, splenomegaly** |
| **Sjögren** | Exocrine glands → ↓ saliva + tears · lymphoid proliferation |

| Joint involvement (TO) | Frequency |
|---|---|
| MCP / PIP / MTP | **90%** |
| Knee, ankle, wrist | 80% |
| Shoulder | 60% |
| Elbow | 50% |
| TMJ, AC, SC | 30% |

**Spared (TO)** — **DIP**, **thoracolumbar spine**, **SI joints** · **MCP = commonest joint** · morning stiffness **> 1 h**

**Extra-articular (TO)** — **30–40%** · markers: high RF / anti-CCP, HLA-DR4, **male**, smoking · eyes: sicca, episcleritis, scleritis · lung: ILD, effusion, nodules · heart: pericarditis · blood: anaemia, thrombocytosis, Felty · nerve: mononeuritis multiplex, myelopathy · vasculitis, digital gangrene

**Nodule sites (TO)** — olecranon, extensor tendons, occiput, heels, ischial tuberosity

**Palindromic rheumatism (TO)** — episodic arthritis hours–days · normal between attacks · **no erosions** · equal sex · Guerne–Weismann 1992: 6-mo history, ≥1 attack seen by physician, ≥3 joints in separate attacks, no erosions, exclude RA/SLE/gout

| ACR 1991 functional class (TO) | Limitation |
|---|---|
| I | None |
| II | Leisure only |
| III | Work + leisure |
| IV | Self-care |

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — **periarticular erosions** + **osteopenia** · symmetric joint-space narrowing · **central glenoid erosion** · **protrusio acetabuli**

**Protrusio acetabuli** — femoral head medial to **teardrop** · RA (bilateral + multijoint on bone scan → ✓ RA) · Marfan · Paget · Otto pelvis (**arthrokatadysis** = primary protrusio, with osteomalacia, no other joints)\
✗ Wrong options: DDH

### Diagnostic criteria — 2010 ACR/EULAR (TO)

**Target** — ≥1 joint with definite synovitis not better explained · ✓ **score ≥6/10 = RA** · <6 → reassess, may accumulate **(TO)**\
✗ Wrong options: ">8"

| Domain (TO) | Points |
|---|---|
| **Joints** — 1 large | 0 |
| 2–10 large | 1 |
| 1–3 small | 2 |
| 4–10 small | 3 |
| **>10 joints (≥1 small)** | **5** — greatest weight |
| **Serology** — RF− and anti-CCP− | 0 |
| Low +ve RF or anti-CCP (1–3× ULN) | 2 |
| High +ve (≥3× ULN) | 3 |
| **Acute phase** — abnormal CRP or ESR | 1 |
| **Duration ≥6 wk** | 1 |

**Excluded joints (TO)** — **hand DIP**, **1st CMC**, **1st MTP** **(TO)**

**1987 ARA criteria** — ≥4 of 7 for **6 wk**: morning stiffness **≥1 h** · swelling **≥3 joints** · nodules · hand X-ray erosions/decalcification · **symmetric** arthritis · serum RF · hand (MCP, PIP) + wrist arthritis

### Post-viral (chikungunya) arthritis (TO)

**Phases (TO)** — acute <3 mo (viraemic 5–10 d, sub-acute 6–21 d) · **chronic >3 mo** — RA-like, SpA, fibromyalgia patterns · chronic in **14–25%** (age >45, viral load >10⁹/mL) · neuropathic pain ~20% **(TO)**

**Tests (TO)** — RT-PCR days 0–7 · IgM from 5–10 d (peak 3 wk, lasts 2–3 mo) · IgG after 1 wk, lasts years · chronic → check **RF, anti-CCP, HLA-B27** **(TO)**

| Phase (TO) | Treatment |
|---|---|
| Acute | Rest, fluids, **paracetamol** · avoid NSAIDs until **dengue excluded**, aspirin, steroids <3 wk |
| Sub-acute | Low-dose prednisolone (10 mg × 5 d, taper) for synovitis · HCQ for persistent symptoms |
| ✓ **Chronic (>3 mo, e.g. 18 mo)** | ✓ **MTX + sulfasalazine + HCQ** (combination > HCQ alone) · TNFi if resistant |

## 5 Management

### DMARDs & biologics (TNF, IL-1, CTLA4, CD20)

**Approach** — aggressive early DMARDs > pyramid · advances → ↓ surgery

| Drug | Mechanism |
|---|---|
| **Methotrexate** | **Folate analogue — inhibits DHFR** · ↓ neovascularisation · adenosine release · ✓ **+ tetracycline (doxycycline) more effective** (anti-collagenase) |
| **Leflunomide** | **Pyrimidine synthesis inhibitor** |
| Sulfasalazine | Unknown · ↓ ESR/CRP · ↓ prostaglandins, leukotrienes |
| Hydroxychloroquine | Blocks **toll-like receptors** → ↓ dendritic cells |
| Gold | Inhibits monocytes |
| D-penicillamine | — |
| **Etanercept** | **TNF receptor (p75/type II)–IgG1 Fc fusion protein** binding TNF-α · SC · RA, JRA, PsA, psoriasis, AS |
| **Infliximab** | **Human–mouse chimeric anti-TNF-α mAb** · opportunistic infection, malignancy |
| Adalimumab · golimumab | Human anti-TNF-α mAb |
| Certolizumab | Pegylated anti-TNF-α |
| **Anakinra** | **Recombinant IL-1 receptor antagonist** (IL-1RI) · refractory / 2nd–4th line |
| **Rituximab** | **Anti-CD20 → B cells** · not TNF · with MTX after TNF failure |
| **Abatacept** | **Binds CD80/CD86 (co-stimulation) → T cells** |
| Ustekinumab | Anti-**IL-12/IL-23** |
| **Tocilizumab** | **IL-6 receptor inhibitor** · 2nd line after TNF failure |
| Cyclosporine | Calcineurin inhibitor |

**TNF blockers** — revolutionised RA (also JRA, SpA, CRMO, histiocytosis X) · ↓ pannus, cartilage loss, osteoclastic resorption · risks: **latent TB reactivation**, infection, **lymphoma**

| Drug (TO) | Dose / fact |
|---|---|
| **Methotrexate** | **7.5–25 mg weekly** · hepatotoxicity, marrow suppression, pulmonary fibrosis · first-choice anchor DMARD · ineffective in axial SpA |
| **Leflunomide** | Load **100 mg × 3 d** → 10–20 mg/d · diarrhoea, alopecia, neuropathy, HTN · avoid in pregnancy |
| Sulfasalazine | 2 g/d · GI upset, rash, marrow suppression, (male) infertility |
| Hydroxychloroquine | 200 mg bd × 3 mo → daily · **retinopathy** → eye exam baseline, at 5 yr, then yearly |
| **Infliximab** | **3 mg/kg IV wk 0, 2, 6 → q8 wk** · **must combine with MTX** · infusion reaction, TB reactivation |
| Etanercept | 25 mg SC twice weekly |
| Adalimumab | 40 mg SC every 2 wk · fully human |
| **Tofacitinib** | **JAK1/JAK3** · 5 mg bd oral · **herpes zoster** (vaccinate first) |
| Baricitinib · filgotinib | JAK1/2 · selective JAK1 |
| Tocilizumab | IL-6R · 4–8 mg/kg IV monthly · monitor lipids |
| Secukinumab · belimumab · mavrilimumab | IL-17 · BLyS · GM-CSF |

**Steroids (TO)** — flares + extra-articular disease · bridge **6–8 wk** · maintenance **≤ 10 mg prednisolone** · usable in pregnancy

**Pregnancy (TO)** — safe: **HCQ, sulfasalazine** (+ steroids) · avoid: **MTX, leflunomide, biologics, JAK inhibitors** · RA often improves in pregnancy

**Screening / monitoring (TO)** — **TB, HBV, HCV (± HIV)** before DMARD/biologic · CBC + LFT monthly × 3 mo then q2–3 mo · annual renal function

**Treat-to-target (TO)** — DAS28: low → monotherapy · moderate-high → combination + short steroid · active > 3 mo → biologic (TNF or non-TNF) or JAK inhibitor · relapse common if stopped

**Synovectomy (TO)** — rarely · persistent **wrist synovitis with tendon-rupture risk**

**Perioperative (TO)** — hold biologics until their half-life has passed before surgery

### Perioperative medication management & infection risk

| Medication | Perioperative rule |
|---|---|
| NSAIDs | Stop **5 half-lives** before (aspirin 7–10 d; naproxen 3 d) |
| Steroids | Stress dose by surgical stress |
| **Methotrexate · sulfasalazine · HCQ · penicillamine** | ✓ **Continue** |
| Leflunomide | Continue (minor) · stop 1–2 d before major, restart 1–2 wk |
| **Etanercept** | Hold **1 wk** (OB3092 key) · **2 wk** before THA (2017 ACR/AAHKS, OB212995; Orthobullets complications) · 4 wk (Keith) · plan at end of dosing interval +1 wk — read the options |
| Adalimumab | Stop **10 days** before |
| Infliximab | Lowest level **2 wk before next infusion** |
| **Rituximab** | Stop **7 months** before major surgery |
| **Ustekinumab** | Skip next dose + 1 wk (~**13 wk** from last) · restart **>14 d** → ↓ **wound complications** |
| Anakinra | Continue minor · stop 1–2 d major · restart 10 d |

**Infection** — ✓ **prior SSI = most significant risk factor** (✗ Wrong options: age, hardware, sulfasalazine, infliximab) · ✓ **etanercept** shown to ↑ post-op infection (✗ Wrong options: naproxen, leflunomide, sulfasalazine, aspirin) · immunosuppression effect overall controversial

### Hand & wrist (extensor tendon rupture, tendon transfers, wrist fusion) (TO)

**Upper-limb reconstruction order (TO)** — ✓ **hand/wrist > shoulder > elbow** · lower limb before upper · LL order **forefoot > hip > knee > hindfoot > ankle** **(TO)**

**Ulnar drift (wind-swept) (TO)** — ✓ **ulnar displacement of extensors + radial collateral ligament attenuation** · radial sagittal band fails → EDC into ulnar valleys · wrist radial deviation → ulnar bowstring (zigzag) · ECU subluxes volar-ulnar **(TO)**

```
Ulnar drift at MCP
├─ Early, flexible → SYNOVECTOMY + EXTENSOR CENTRALISATION + INTRINSIC RELEASE (cross-intrinsic)
├─ Late / fixed → SILICONE (SWANSON) MCP ARTHROPLASTY
│      (correct radially deviated wrist at same time · satisfaction ~70%)
└─ Thumb MCP without IP disease → MCP FUSION
```

| Finger deformity | Pathoanatomy | Treatment |
|---|---|---|
| **Boutonnière** | PIP synovitis → **central slip** attenuation · lateral bands **volar** · **oblique** retinacular contracture → DIP hyperextension | Splint (flexible) · central slip imbrication / **Fowler distal tenotomy** (moderate) · PIP fusion / arthroplasty (rigid) |
| **Swan neck** | **Terminal tendon** rupture (DIP) · **FDS, volar plate, collaterals** attenuate · lateral bands **dorsal** · **transverse** retinacular attenuation, triangular ligament contracture | Splint · **FDS tenodesis** / proximal Fowler (flexible) · releases (rigid) |
| **Arthritis mutilans** | RA or PsA · pencil-in-cup, wind-chime fingers | Interposition graft + fusion |

| Nalebuff thumb | Deformity | Treatment |
|---|---|---|
| **I — Boutonnière** | ✓ **Most common** · **MCP flexion + IP (hyper)extension** · EPB attenuation, EPL subluxes volar **(TO)** | ✓ **Restore MCP extension + stabilise IP** **(TO)** · synovectomy + EPL rerouting (early) · **MCP fusion 10–15°** (late, most reliable) · IP fusion if fixed |
| II — Boutonnière + CMC | Uncommon / very rare | As I and III |
| **III — Swan neck** | **CMC adduction/subluxation + MCP hyperextension + IP flexion** | **Address CMC first** — trapeziectomy/LRTI · MCP >30° → volar capsulodesis or fusion · first web release |
| **IV — Gamekeeper** | Adductor contracture + **UCL laxity** · P1 radial deviation | Flexible: synovectomy, UCL reconstruction, adductor release · fixed: MCP arthroplasty / fusion |
| V | MCP hyperextension — **volar plate laxity** (swan neck with MCP disease) | Volar capsulodesis (MCP in flexion) |

|---|---|
| Triggering | Synovectomy + **FDS resection** |

| FDP rupture | Synovectomy + DIP fusion |
| FDS rupture | Observe |

**Extensor rupture frequency** — **EDM > EDC ring > EDC small > EPL** · ✓ **extensor digiti quinti most at risk** (silent — EDC still extends small finger)

**Vaughan-Jackson** — ✓ **rupture of digital extensors ulnar → radial** · **DRUJ instability + volar carpal subluxation → dorsal ulnar head** → attrition · **EDM first** · **painless**, no warning · treat **EIP → EDC transfer + distal ulna resection**

| Ruptured | Transfer |
|---|---|
| EPL | **EIP → EPL** |

| EDQM + EDC5 | **EIP → EDC5** or EDC piggyback |

**EIP transfer** — ✓ **no index extension deficit** (cut proximal to sagittal band)

**FDS (middle/ring) → EDC (Nalebuff–Patel)** — ✓ **radially around radius, dorsally** (easy, avoids dorsal synovitis, corrects ulnar deviation)\

**Radial sagittal band failure** — extensor slips ulnar + volar to MCP axis\

### Elbow (synovectomy, total elbow arthroplasty)

| Elbow procedure | Indication |
|---|---|

**Synovectomy indications** — preserved joint space · young on DMARD · early disease · heavy work (rules out TEA) · **female gender** is not an indication

### Shoulder · hip · knee

**Shoulder** — **>90%** develop symptoms · **rotator cuff tears** (large, irreparable → poorer arthroplasty, glenoid loosening) · central glenoid wear, osteopenia, cysts

**Hip** — **protrusio acetabuli**

**Knee synovectomy** — ↓ pain + swelling · does not halt radiographic progression, prevent TKA or ↑ ROM · synovium re-forms then becomes rheumatoid

**TKA** — ✓ **resurface patella** in RA · unresurfaced → ↑ **anterior knee pain** · resurfaced → ↑ extensor rupture, patellar clunk

### Forefoot & midfoot reconstruction

**Rheumatoid foot** — bilateral, symmetric · **forefoot first** · HLA-DR4 · ~90% develop forefoot deformity (hallux valgus, hammer toes, lesser MTP dislocation)

**Earliest forefoot sign** — **MTP synovitis** → MTP hyperextension · distal fat-pad migration · plantar callosities · ulcers

**Gold standard** — ✓ **1st MTP arthrodesis + lesser metatarsal head resections** (+ hammertoe correction — **Hoffman-Clayton**) · Coughlin & Mann **90%** good/excellent

| ✗ Wrong option | Why |
|---|---|
| **Keller** arthroplasty | Unstable platform, recurrence, poorer function |
| 1st MTP replacement | Unreliable long-term |
| Bunionectomy / chevron / realignment | Doesn't stabilise ray or address arthritis · osteotomies only if no erosions |
| **Lapidus** | TMT fusion — does not address MTP |
| Weil osteotomies | do not address erosive lesser MTPs |
| **Lesser MTP fusion** | Lateral foot needs motion |
| Lesser MTP arthroplasty | Resection preferred |
