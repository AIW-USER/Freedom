# Cranial Nerves

*Basic Science · TO notes*

## 1 Basics

### Functional groups

**Definition** — **12 pairs** arising directly from the brain (not the cord) → head, neck, special senses (TO)

| Group (TO) | Nerves | Supply |
|---|---|---|
| **Somatic (cranial myotomes)** | **III, IV, VI, XII** | Eyeball muscles + tongue |
| **Branchial arch derivatives** | **V, VII, IX, X, XI** | Face, pharynx, larynx |
| **Special sense** | **I, II, VIII** | Smell, vision, hearing / balance |

### Functional columns in brainstem

| Column (TO) | Carries | Nerves |
|---|---|---|
| **GSE** | Motor to somatic skeletal muscle | III, IV, VI, XII |
| **SVE** | Branchial-arch muscle | V, VII, IX, X, XI |
| **GVE** | **Parasympathetic** | **III, VII, IX, X** |
| GVA | Visceral sensation | IX, X |
| **SVA** | **Taste, smell** | I, VII, IX, X |
| GSA | Skin / mucosa sensation | V, VII, IX, X |
| **SSA** | Vision, hearing, balance | **II, VIII** |

### Summary table

| Nerve (TO) | Type | Main function | Key lesion |
|---|---|---|---|
| **I Olfactory** | Sensory | Smell | Anosmia |
| **II Optic** | Sensory | Vision | Visual field defects |
| **III Oculomotor** | Motor + PS | Eye movement, pupil constriction | **Ptosis, down-and-out eye, mydriasis** |

| **V Trigeminal** | Mixed | Face sensation, mastication | Corneal reflex loss (afferent) |

| **XII Hypoglossal** | Motor (GSE) | Tongue | LMN: deviates **toward** lesion |

## 2 Sensory nerves (I, II, VIII)

### CN I – Olfactory

**Epithelium (TO)** — upper nasal cavity under **cribriform plate** · **olfactory receptor cells = 1st-order bipolar neurons** · supporting cells · **basal cells = regenerative progenitors** · axons → **12–16 filaments** through cribriform plate

**Pathway (TO)** — bipolar receptor (1st) → **olfactory bulb mitral cells (2nd)** → tract → **lateral stria → primary cortex (uncus)** · medial stria → opposite side via anterior commissure · intermediate stria → olfactory tubercle

**Secondary cortex (TO)** — **entorhinal area / parahippocampal gyrus** → emotion + memory link

**Unique (TO)** — **only two-order neuron system** · **does not relay through thalamus** ("smell skips the thalamus") · limbic links

### CN II – Optic

**Pathway (TO)** — retina → optic nerve → chiasma → tract → **lateral geniculate body** (3rd order, thalamus) → optic radiations → **visual cortex area 17** (calcarine fissure)

**Retina (TO)** — rods (brightness), cones (colour) · **bipolar cells = 1st order** · **ganglion cells = 2nd order** (axons form nerve) · **optic disc = blind spot**

**Field projection (TO)** — temporal field → nasal retina · superior field → inferior retina (and vice versa)

| Term (TO) | Fact |
|---|---|
| **Chiasma** | **Nasal fibres cross**; temporal stay ipsilateral → lesion = **bitemporal hemianopia** |
| Optic nerve lesion | **Monocular blindness** |
| Optic tract | Contralateral visual field |
| **Meyer's loop** | Inferior fibres loop round temporal horn → **"pie in the sky"** defect |
| **Von Willebrand's knee** | Inferior nasal fibres loop into opposite optic nerve → **junctional scotoma** |
| Macula | Sharpest vision; **occipital pole** |

**Light reflex (TO)** — retina → optic nerve → tract → superior colliculus (TO — verify: relay is the pretectal nucleus) → **Edinger-Westphal** → CN III → **ciliary ganglion** → sphincter pupillae · **consensual** response both pupils

**Accommodation reflex (TO)** — retina → visual cortex → frontal eye field → Edinger-Westphal → ciliary muscle → lens thickens + pupil constricts

**Not a true peripheral nerve (TO)** — forebrain outgrowth · covered by meninges · **no neurilemma** · myelinated by **oligodendrocytes**

### CN VIII – Vestibulocochlear

**Type (TO)** — purely sensory (SSA) · cochlear (hearing) + vestibular (balance)

**Organ of Corti (TO)** — hair cells (**inner 2 rows**, outer 3–4 rows) = transducers · supporting **Deiters', Claudius', Hensen's** cells · rods of Corti · tectorial membrane · **spiral ganglion = 1st-order neuron**

**Hearing (TO)** — tympanic membrane → ossicles → **oval window** → perilymph of scala vestibuli → endolymph → basilar membrane → hair cells bend

| Auditory relay (TO) | Site |
|---|---|
| 1 Spiral ganglion | Cochlea |
| 2 Cochlear nuclei (dorsal + ventral) | Upper medulla |
| 3 **Superior olivary nucleus** | Pons — **sound localisation** |
| 4 Trapezoid body | Crossed fibres |
| 5 **Lateral lemniscus** | Ascending auditory tract |
| 6 **Inferior colliculus** | Midbrain reflex relay |
| 7 **Medial geniculate body** | Thalamus |
| 8 **Primary auditory cortex — areas 41, 42 (Heschl's gyrus)** | Temporal lobe |

**Mnemonic (TO)** — "Some Cats Sleep Till Late In Midday"

| Vestibular organ (TO) | Receptor | Detects |
|---|---|---|
| **Utricle + saccule** (static labyrinth) | **Macula** (otolith CaCO₃ crystals) | **Linear acceleration**, head position |
| **Semicircular canals** (kinetic labyrinth) | **Crista ampullaris** | **Angular acceleration** |

**Vestibular pathway (TO)** — **Scarpa's (vestibular) ganglion** → **4 vestibular nuclei** (superior, medial, lateral, inferior) → vestibulo-ocular (III, IV, VI via **MLF**) · vestibulospinal (posture) · vestibulocerebellar (**flocculonodular lobe**) · vestibulothalamic

**Imbalance signs (TO)** — truncal ataxia · staggering gait · vertigo · nystagmus

## 3 Eye movement nerves (III, IV, VI)

### CN III – Oculomotor

**Nuclei (TO)** — **oculomotor** (extraocular muscles) + **Edinger-Westphal** (parasympathetic)

**Course (TO)** — midbrain at **superior colliculus** level → **interpeduncular fossa** → **between PCA and SCA** → cavernous sinus → superior orbital fissure → superior division (**SR, LPS**) + inferior division (**MR, IR, IO**) · PS → ciliary ganglion → short ciliary nn. → sphincter pupillae + ciliary muscle

**LR6 SO4 (TO)** — lateral rectus = VI · superior oblique = IV · all others = III

| III palsy finding (TO) | Cause |
|---|---|
| **Eye down and out** | Unopposed LR + SO |
| **Ptosis** | LPS paralysis |
| **Mydriasis** | Loss of PS to sphincter pupillae |
| Loss of accommodation | Ciliary muscle paralysis |

**Pupil-involving III palsy (TO)** — **surgical emergency** · compression between **PCA and SCA** (aneurysm / herniation)

### CN IV – Trochlear

**Unique (TO)** — **only nerve emerging dorsally** from brainstem · nucleus in midbrain at **inferior colliculus** · fibres **cross before emerging** · enters orbit via SOF **outside annulus of Zinn**

**Action / lesion (TO)** — superior oblique: **intorsion + depression in adduction** · lesion → eye elevated + extorted → **vertical diplopia, worse going down stairs**

### CN VI – Abducens

**Course (TO)** — nucleus in **pons beneath facial colliculus** → **petroclival ligament of Gruber** → cavernous sinus → SOF

**Lesion (TO)** — cannot abduct → **medial squint**

**MLF (TO)** — connects **III and VI nuclei** → conjugate gaze (look right = right LR + left MR)

## 4 Trigeminal (V) and Facial (VII)

### CN V – Trigeminal

| Nucleus (TO) | Location | Function |
|---|---|---|
| **Chief sensory** | Pons | Touch, pressure |
| **Spinal** | Medulla → **C2** | **Pain, temperature** |
| **Mesencephalic** | Midbrain | **Proprioception**, jaw reflex · acts like a **DRG (1st-order neurons)** |
| Motor | Pons | 1st pharyngeal arch muscles |

**Mnemonic (TO)** — touch = chief · pain/temp = spinal · position = mesencephalic

**Ganglion (TO)** — **trigeminal (Gasserian) ganglion in Meckel's cave** (petrous apex) · lies **over foramen lacerum** (does not pass through) · cavernous sinus medial

| Division (TO) | Fibres | Exit | Supply |
|---|---|---|---|
| **V1 ophthalmic** | Sensory | SOF | Upper face, scalp, **cornea** · frontal (supraorbital, supratrochlear), lacrimal, **nasociliary** |
| **V2 maxillary** | Sensory | **Foramen rotundum** → pterygopalatine fossa → infraorbital canal | Midface, lower eyelid, upper lip, upper teeth, palate |
| **V3 mandibular** | **Mixed** (GSA + SVE) | **Foramen ovale** | Mastication muscles, mylohyoid, ant. digastric, **tensor tympani, tensor veli palatini** · lower face, auricle, lower teeth, **general sensation ant. 2/3 tongue** |

**V3 branches (TO)** — meningeal (**nervus spinosus** → meningeal headache) · **auriculotemporal** (auricle; carries fibres to parotid) · **lingual** · inferior alveolar → **mental** (chin, lower lip) · buccal

**Corneal reflex (TO)** — **afferent V1 (nasociliary)** → **efferent VII** (orbicularis oculi)

| PS ganglion (TO) | Preganglionic source | Via CN V | Target |
|---|---|---|---|
| **Ciliary** | Edinger-Westphal (III) | V1 | Sphincter pupillae, ciliary muscle |
| **Otic** | **Inferior salivatory (IX)** | V3 – auriculotemporal | **Parotid** |
| **Submandibular** | Superior salivatory (VII) | V3 – lingual | Submandibular + sublingual glands |
| **Pterygopalatine** | Superior salivatory (VII) | V2 – zygomatic | **Lacrimal gland** |

### CN VII – Facial

| Nucleus (TO) | Type | Function |
|---|---|---|
| Motor | SVE | Facial expression |
| Superior salivatory + lacrimatory | GVE | Submandibular, sublingual, lacrimal glands |
| **Nucleus tractus solitarius** | SVA | **Taste ant. 2/3 tongue** |
| Spinal nucleus of V | GSA | External ear |

**Course (TO)** — **pontomedullary junction** → internal acoustic meatus → **internal genu round abducens nucleus (→ facial colliculus)** → **geniculate ganglion (external genu)** → **stylomastoid foramen** → parotid (**pes anserinus**)

| Branch (TO) | Function |
|---|---|
| **Greater petrosal** | PS → pterygopalatine ganglion → lacrimal gland |
| **Nerve to stapedius** | Damps stapes → loss = **hyperacusis** |
| **Chorda tympani** | Taste ant. 2/3 + PS to submandibular ganglion · via **petrotympanic fissure → joins lingual** |
| Posterior auricular, digastric (post.), stylohyoid | Motor |
| **Terminal: temporal, zygomatic, buccal, marginal mandibular, cervical** | Facial expression ("To Zanzibar By Motor Car") |

| Lesion site (TO) | Features |
|---|---|
| **UMN (supranuclear)** | **Contralateral lower face only** |
| **LMN** (nuclear / infranuclear) | **Ipsilateral whole face** (**Bell's palsy**) |
| **Geniculate ganglion** | Loss of taste, **dry eye**, **hyperacusis** |
| **Stylomastoid foramen** | **Pure facial palsy** |

## 5 Lower cranial nerves (IX, X, XI, XII)

### CN IX – Glossopharyngeal

| Component (TO) | Nucleus | Function |
|---|---|---|
| SVE | **Nucleus ambiguus** | **Stylopharyngeus** (only muscle; 3rd arch) |
| GVE | **Inferior salivatory** | **Parotid** via otic ganglion |
| GVA | Dorsal nucleus of vagus (TO — verify: visceral afferents usually to nucleus tractus solitarius) | Pharynx, carotid body / sinus |
| SVA | Nucleus tractus solitarius | **Taste post. 1/3 tongue** |

**Course (TO)** — medulla between olive and pyramid (TO — verify: IX emerges from the post-olivary sulcus; XII emerges between pyramid and olive) → **jugular foramen** (superior + inferior ganglia)

**Branches (TO)** — **tympanic (Jacobson's)** → lesser petrosal → otic ganglion → parotid · carotid (body + sinus) · pharyngeal · stylopharyngeal · tonsillar + lingual

**Lesion (TO)** — **loss of gag reflex (afferent limb)** · loss of taste + sensation post. 1/3 tongue · pharynx, tonsil, fauces numb

### CN X – Vagus

| Component (TO) | Nucleus | Function |
|---|---|---|
| SVE | **Nucleus ambiguus** | Pharynx, larynx, palate |
| GVE | **Dorsal nucleus of vagus** | Heart, lungs, GIT |
| GVA | Dorsal nucleus of vagus | Thoracic / abdominal viscera |
| SVA | NTS | Taste epiglottis, pharynx |
| GSA | Spinal nucleus of V | External ear |

**Course (TO)** — jugular foramen (2 ganglia) → **carotid sheath between carotid artery and IJV**

**Branches (TO)** — **auricular (Arnold's)** + meningeal · pharyngeal (motor) · **superior laryngeal**: external → **cricothyroid**; internal → sensation **above** cords · **recurrent laryngeal** → sensation **below** cords; motor to **all intrinsic laryngeal muscles except cricothyroid**

| Vagus lesion (TO) | Finding |
|---|---|
| **Unilateral** | Palatal droop → **uvula deviates to opposite side** |
| Gag reflex | **Efferent lost (X)**, afferent intact (IX) |
| Voice | **Hoarseness** (cord paralysis) |
| Cough reflex | Lost |

### CN XI – Accessory

| Root (TO) | Nucleus | Supply |
|---|---|---|
| Cranial | Nucleus ambiguus | Joins vagus → pharynx, larynx, palate |
| **Spinal** | **C1–C5** spinal nucleus | **SCM + trapezius** |

**Course (TO)** — spinal root ascends via **foramen magnum** → joins cranial root → exits **jugular foramen** · spinal rootlets **posterior to denticulate ligament**, between dorsal + ventral roots up to C5

**Lesion (TO)** — cranial part → dysphonia, dysphagia · spinal part → **weak head rotation (SCM) + shoulder shrug / droop (trapezius)**

### CN XII – Hypoglossal

**Origin (TO)** — pure motor (GSE) · nucleus in medulla · **between pyramid and olive** · 10–12 rootlets → **hypoglossal canal**

**Course (TO)** — crosses **lingual artery loop** · joined by **C1 fibres → geniohyoid + thyrohyoid** (ansa cervicalis) · supplies all intrinsic + extrinsic tongue muscles **except palatoglossus** (pharyngeal plexus via X)

| Lesion (TO) | Tongue |
|---|---|
| **LMN** | Deviates **toward** lesion, atrophy, fasciculations |
| **UMN** | Deviates **away** from lesion, no atrophy |

## X vs Y

| | **UMN facial palsy** | **LMN facial palsy (Bell's)** |
|---|---|---|
| Side | Contralateral | Ipsilateral |
| Face | **Lower face only** (forehead spared) | **Whole face** |

| | **Gag reflex — IX lesion** | **Gag reflex — X lesion** |
|---|---|---|
| Limb lost | **Afferent** | **Efferent** |

| Taste (TO) | Nerve |
|---|---|
| **Ant. 2/3 tongue** | **VII (chorda tympani)** |
| **Post. 1/3 tongue** | **IX** |
| Epiglottis, pharynx | X |
| General sensation ant. 2/3 | V3 (lingual) |

## How it's asked

**"Only sensory pathway not relaying in the thalamus?"** → **olfactory (CN I)** (TO)

**"Lesion of Meyer's loop?"** → **'pie in the sky' superior quadrantanopia** (TO)

**"Chiasmal lesion?"** → **bitemporal hemianopia** (TO)

**"Only cranial nerve emerging dorsally from the brainstem?"** → **trochlear (CN IV)** (TO)

**"Eye down and out, ptosis, dilated pupil?"** → **CN III palsy** (TO)

**"Corneal reflex — afferent and efferent?"** → **V1 (nasociliary) / VII** (TO)

**"Trigeminal ganglion lies in?"** → **Meckel's cave** (TO)

**"Facial lesion at geniculate ganglion?"** → **loss of taste, dry eye, hyperacusis** (TO)

**"Only muscle supplied by CN IX?"** → **stylopharyngeus** (TO)

**"Unilateral vagus lesion — uvula?"** → **deviates to the opposite side** (TO)

**"LMN hypoglossal lesion — tongue?"** → **deviates toward the lesion** (TO)

**"Tongue muscle not supplied by XII?"** → **palatoglossus** (TO)
