# Semimembranosus

*Basic Science · 98 / 108*

## 1 Basics

### Anatomy

| | Semimembranosus |
|---|---|
| **Origin** | **Superolateral quadrant of ischial tuberosity** |
| **Insertion** | **Posterior medial tibial condyle** |
| **Action** | Extends hip · flexes knee · medially rotates tibia (esp. knee flexed) |
| **Innervation** | **Tibial nerve (L5, S1, S2)** |
| **Arterial supply** | Perforators of profunda femoris · inferior gluteal · superior muscular branches of popliteal |

| Structure | Position |
|---|---|
| **Gracilis** | **Most medial**, superficial to adductor magnus |

| ✓ **Semimembranosus** | **Medial** to semitendinosus |
| Semitendinosus | Lateral to semimembranosus |
