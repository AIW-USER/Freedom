# Inheritance Patterns of Orthopaedic Syndromes

*Basic Science · 51 / 108*

## 1 Basics

### Mendelian patterns & pedigrees

**Mendelian (monogenic)** — AD · AR · X-linked dominant · X-linked recessive · ~1% of humans

**Rule of thumb** — ✓ **AD → structural protein defects** (e.g. FGFR3 in achondroplasia) · **AR → enzymatic/biochemical defects**

**Pedigree key** — circle = female · square = male · filled = affected · horizontal line = mating · vertical = offspring

| Pattern | Pedigree clue |
|---|---|
| **AD** | Every generation, both sexes, ~50% of offspring (no skipping if complete penetrance) |
| **AR** | Both sexes equally, **skips generations**, affected children of unaffected (carrier) parents, ¼ of offspring |
| **X-linked recessive** | Males; affected mother → **all sons affected** |
| X-linked dominant | Affected father → all daughters |

**No inheritance** — fibular hemimelia · **McCune-Albright / fibrous dysplasia** (GNAS — sporadic **mosaicism**, non-Mendelian)

### Non-Mendelian inheritance (imprinting, anticipation, mosaicism)

| Phenomenon | Definition | Example |
|---|---|---|
| **Genomic imprinting** | Expression depends on **parent of origin** | **Prader-Willi** (paternal defect — hypotonia, obesity, hypogonadism; chr 15) · **Angelman** (maternal — epilepsy, tremor, smiling) |
| **Anticipation** | **Earlier onset + more severe** in each generation · **trinucleotide repeats** | **Huntington's** (CAG, chr 4, AD), myotonic dystrophy, Friedreich ataxia, fragile X |
| **Mosaicism** | Post-zygotic mutation → mixed cell lines | Fibrous dysplasia, McCune-Albright |
| Variable penetrance/expressivity | Same gene, varying degree | — |
| Genetic drift | Chance change in genotype frequency | — |
| Trisomy | Extra chromosome | Down (21) |

### Lesch-Nyhan syndrome

**Defect** — **X-linked recessive** · deficient **HGPRT** (purine metabolism) → ✓ **↑ serum uric acid**

**Features** — cognitive impairment · **choreoathetosis** · **self-mutilation** (biting fingertips), aggression · fractures, hip dysplasia, progressive scoliosis · surgery outcomes ≈ CP · ↑ HO, femur fixation failure

| Lab | Condition |
|---|---|
| **↑ Serum uric acid** | **Lesch-Nyhan** |
| ↑ Urine keratan sulfate | Morquio |
| ↑ Ca, ↓ PO₄ | Hyperparathyroidism |
| ↑ Glucocerebrosides | Gaucher |
| Chromosome 15 deletion | Prader-Willi |

## How it's asked

**"Prader-Willi / Angelman — parent-of-origin expression?"** → **genomic imprinting**

**"Symptoms earlier each generation?"** → **anticipation**

**"Genetic defect NOT following Mendelian inheritance?"** → **Gs-α defect (McCune-Albright)**\
✗ Wrong options: FGFR3, sulfate transporter, fibrillin, glucocerebrosidase

**"Chorea at 46, father at 55?"** → **autosomal dominant with anticipation (Huntington's)**

**"Example of anticipation?"** → **more severe and earlier in subsequent generations**

**"AR pedigree — which condition?"** → **diastrophic dysplasia**\
✗ Wrong options: DMD, Hunter, haemophilia B, SED tarda (XR)

**"X-linked recessive disorder?"** → **haemophilia A**\
✗ Wrong options: Gaucher, diastrophic (AR) · Prader-Willi (imprinting) · hypophosphataemic rickets (XD)

**"AD genes typically cause which defect?"** → **structural**

**"Pedigree for MHE?"** → **autosomal dominant**

**"Spotted juxta-articular sclerotic lesions in pregnant woman — inheritance?"** → **AD (osteopoikilosis)**

**"Radiograph suggesting X-linked dominant disease?"** → **hypophosphataemic rickets**

**"Lesch-Nyhan — lab finding?"** → **↑ serum uric acid**

**"Self-mutilating, cognitively impaired, X-linked recessive boy?"** → **Lesch-Nyhan**\
✗ Wrong options: Léri-Weill (XD) · Apert (AD)

**"Bit off his fingertip, purine metabolism disorder?"** → **Lesch-Nyhan**
