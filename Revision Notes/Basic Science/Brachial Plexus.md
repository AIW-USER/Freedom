# Brachial Plexus

*Basic Science · 21 / 108*

## 1 Basics

### Variants

| Type | Roots | Frequency |
|---|---|---|
| **Standard** | C5–T1 | **77%** |
| Prefixed | + C3, C4 | 22% |
| Postfixed | Below T1 | 1% |

### Anatomy — "Robert Turner Drinks Cold Beer"

**Roots (5)** — ventral rami **C5–T1** · superior + posterior to subclavian artery

**Interscalene course** — ✓ exits between **scalenus anterior and scalenus medius** (+ first rib) **(TO)**\
✗ Wrong options: medius/posterior · medius/levator scapulae

**Trunks (3)** — superior (C5, 6) · middle (C7) · inferior (C8, T1)

**Divisions (6)** — 3 anterior + 3 posterior

**Cords (3)** — posterior (all 3 posterior divisions) · lateral (anterior superior + middle, C5–7) · medial (anterior inferior, C8, T1)

### Branches by level

| Level | Branch | Supplies |
|---|---|---|
| Root | **Dorsal scapular (C5)** | Levator scapulae, rhomboids |
| Root | **Long thoracic (C5–7)** | Serratus anterior |
| Superior trunk | **Suprascapular (C5, 6)** | Supra- + infraspinatus, AC + GH joints (via suprascapular notch) |
| Superior trunk | Nerve to subclavius (C5, 6) | Subclavius |
| Lateral cord | Lateral pectoral (C5–7) | Pectoralis major |
| Medial cord | Medial pectoral (C8, T1) | Pierces pec minor → pec minor + major |
| Medial cord | Medial brachial + antebrachial cutaneous | Skin |
| Posterior cord | Upper subscapular (C5, 6) | Subscapularis |
| Posterior cord | **Lower subscapular (C5, 6)** | Subscapularis + **teres major** |
| Posterior cord | **Thoracodorsal (C6–8)** | Latissimus dorsi |

### Lateral cord branches — terminal branches

| Cord | Terminal branches |
|---|---|
| **Lateral** | ✓ **Musculocutaneous + median (lateral root)** |
| **Medial** | **Ulnar + median (medial root)** |
| **Posterior** | **Axillary + radial** |

**Musculocutaneous (C5–7)** — most superficial · pierces **coracobrachialis 1.5–9 cm** from origin → biceps, coracobrachialis, brachialis → **lateral antebrachial cutaneous**

**Median** — lateral + medial roots join **anterior to axillary artery**

## How it's asked

**"Terminal branches of the lateral cord?"** → **musculocutaneous + median**\
✗ Wrong options: axillary (posterior cord) · ulnar (medial cord)

**"Brachial plexus exits between (TO)?"** → **scalenus anterior and scalenus medius**
