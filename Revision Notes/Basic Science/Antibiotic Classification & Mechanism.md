# Antibiotic Classification & Mechanism

*Basic Science · 6 / 108*

## 1 Basics

### Mechanism of action by class

**Five basic mechanisms** — cell-wall synthesis · membrane permeability · ribosomal (protein) inhibition · DNA metabolism · antimetabolite (folate)

![Antibiotic mechanisms of action](../../Orthobullets/attachments/ob9059-antibiotics-mechanisms-of-action.jpg)

| Target | Drugs | Cidal / static |
|---|---|---|
| **Cell wall** (transpeptidase / PBP) | **Penicillins, cephalosporins**, carbapenems (imipenem), aztreonam, β-lactamase inhibitors | Bactericidal |
| **Cell wall — D-Ala-D-Ala** | **Vancomycin** (binds D-Ala-D-Ala terminal → blocks transpeptidation, peptidoglycan cross-linking) | Bactericidal |
| Membrane permeability | Bacitracin · polymyxin | — |
| Membrane depolarisation | **Daptomycin** | Bactericidal |
| Fungal membrane sterols | **Amphotericin, nystatin** — bind sterols → disrupt membrane | — |
| **30S ribosome** | **Aminoglycosides** (gentamicin, tobramycin — **irreversible**) · **tetracyclines** (doxycycline — block tRNA binding) | AG cidal · tetracycline static |
| **50S ribosome** | **Macrolides** (erythromycin — reversible, blocks aminoacyl translocation) · **clindamycin** · chloramphenicol (peptidyl transferase) · streptogramins | Static |
| **50S 23S rRNA — initiation complex** | **Linezolid** (oxazolidinone) — prevents 30S–50S (70S) initiation complex | Static vs staph/enterococci · cidal vs strep |
| **DNA gyrase** (type II topoisomerase) | **Fluoroquinolones** (cipro, levo, moxi) | Bactericidal |
| DNA (metabolic by-products) | Metronidazole | Bactericidal |
| **RNA polymerase** (DNA-dependent) | **Rifampin** | Bactericidal |
| Mycolic acid | Isoniazid | — |
| **Folic acid** (PABA mimic) | **TMP/SMX**, sulfonamides | Static |

**Required** — pneumococcal · **Hib** · meningococcal C · influenza vaccines · **lifelong oral penicillin V or erythromycin**

## 2 Mechanism

### Resistance (mecA, biofilm, efflux, D-zone test)

**Three basic mechanisms (OB)** — **avoidance** · decreased susceptibility · inactivation

| Mechanism | Confers resistance to | Example |
|---|---|---|
| **β-lactamase** (hydrolysis) | Penicillin | E. coli, S. epidermidis, Pseudomonas, Klebsiella → add clavulanate (Augmentin) |
| **Genetic mutation — mecA** (on SCCmec) → **PBP2a** (low β-lactam affinity) | **Methicillin, oxacillin, nafcillin**, cephalosporins | **MRSA** · SCCmec type IV = **CA-MRSA** (less multidrug-resistant) |
| Altered cell-wall permeability | Tetracyclines, quinolones, trimethoprim, β-lactams | — |
| **Biofilm** (glycocalyx) = **avoidance** | Adherence to implants, resists phagocytosis | **S. epidermidis**, Salmonella |
| **Active efflux pumps** | **Erythromycin, tetracycline** | msrA gene (Staph) |
| Altered peptidoglycan (D-Ala-D-Ala) | **Vancomycin** | **VRE** |
| **Ribosome alteration** — erm gene methylates 23S rRNA | Inducible **MLS** (macrolide–lincosamide–streptogramin) | **D-zone test** |
| Altered DNA gyrase | Quinolones | — |
| Altered RNA polymerase | Rifampin | — |
| Altered membrane-binding protein | β-lactams | — |

**Tetracycline resistance (3)** — **increased drug efflux** · ribosome protection · tetracycline modification

**Biofilm biology** — forms when bacterial mass sufficient → **quorum sensing** → stationary/reduced growth phase · **high-shear** environments stimulate it

**MRSA options** (don't bind PBPs) — **vancomycin, TMP/SMX, clindamycin, linezolid**

## 4 Diagnosis & Classification

### D-zone test

**Indication** — **erythromycin-resistant MRSA** (or β-haemolytic strep) **before starting clindamycin**

**Basis** — plasmid alters **50S** binding site for both clindamycin + erythromycin → **inducible clindamycin resistance**

**Method** — erythromycin disc next to clindamycin disc → **D-shaped zone of inhibition = positive** → **don't use clindamycin**

![D-zone test — flattening next to the erythromycin disc](../../Orthobullets/attachments/ob9059-d-zone-test.jpg)

| Test | Use |
|---|---|
| **D-zone** | ✓ **Inducible clindamycin resistance** |
| Etest | MIC |
| CAMP | Group B strep |
| Ziehl–Neelsen | Acid-fast (mycobacteria) |
| Oxidase | Cytochrome c oxidase +/− |
| Phenylalanine deaminase | Proteus |
| Citrate / decarboxylase | Enterobacteriaceae |
| β-lactamase | Penicillin resistance |

## 5 Management

### Clinical use (rifampin, antibiotic cement, dental prophylaxis)

**Rifampin** — **lipophilic → high cell penetration** → effective vs **intracellular phagocytised S. aureus** (in macrophages) · always combined (synergy)

**Vancomycin indications** — serious β-lactam allergy · MRSA/MRSE infection · prosthesis prophylaxis where **MRSA/MRSE rate is high**

**Vancomycin coverage** — G+ only · no GN bacilli (too large) · time-dependent killing

**Antibiotic cement (PMMA)** — max **5% of cement weight** without ↓ mechanical strength → **2 g per 40 g** · commercial = **1 g / 40 g** · add as **powder, never liquid**

**Antibiotic nail for septic tibial nonunion** — PMMA + **vancomycin (G+) + tobramycin (GN)**

**Dental prophylaxis after TJA** — only **high-risk**: immunocompromised (transplant, AIDS, inflammatory arthritis, chemo) · **prior PJI** · **uncontrolled diabetes**

**Regimen** — **cephalexin / amoxicillin / cephradine 2 g PO within 1 h** \
✗ Wrong options: routine IV

## 6 Complications

### Adverse effects & contraindications

**Quinolones** — **inhibit early fracture healing** (toxic to **chondrocytes** → immature callus, more cartilage) · **Achilles tendinitis/rupture (RR 3.7)**

**Tetracycline** — ✓ **contraindicated in children** (stains teeth + bone)\
✗ Wrong options: penicillin, cephalexin, erythromycin, ampicillin

**Linezolid** — reversible non-selective **MAOI** → **serotonin syndrome** (esp. with SSRIs): headache, diaphoresis, tachycardia, hypertension, tremor, **clonus**, unreactive pupils → stop drug + **IV benzodiazepines** · severe → serotonin antagonist

**Vancomycin** — flushing = **red man syndrome**

## How it's asked

**"Mechanism of vancomycin?"** → **inhibition of cell-wall synthesis**\
✗ Wrong options: permeability · ribosome · DNA · antimetabolite

**"All inhibit ribosomes EXCEPT?"** → **vancomycin**\
✗ Wrong options: gentamicin, tobramycin, erythromycin, linezolid

**"All interfere with cell-wall synthesis EXCEPT?"** → **gentamicin**\
✗ Wrong options: cefazolin, penicillin G, vancomycin, imipenem

**"Family that inhibits DNA gyrase?"** → **quinolones**\
✗ Wrong options: penicillins, aminoglycosides, macrolides, sulfonamides

**"Binds the 30S subunit?"** → **aminoglycosides**\
✗ Wrong options: macrolides (50S) · rifampin (RNA polymerase)

**"Linezolid (oxazolidinone) targets?"** → **ribosomal activity**\
✗ Wrong options: DNA-dependent RNA polymerase (rifampin) · membrane (daptomycin)

**"Cephalosporins block transpeptidase → effect?"** → **inhibit cell-wall synthesis**

**"Fluoroquinolones inhibit?"** → **DNA gyrase**\
✗ Wrong options: RNA gyrase · DNA polymerase · telomerase

**"Amphotericin acts by?"** → **binding sterols, disrupting the cell membrane**

**"Tobramycin in an antibiotic nail — mechanism?"** → **irreversibly binds 30S**\
✗ Wrong options: reversible · 50S · D-Ala-D-Ala = vancomycin

**"Correct class–mechanism pairing?"** → **fluoroquinolones – DNA gyrase**

**"Prevents 30S–50S initiation complex?"** → **linezolid**\
✗ Wrong options: gentamicin · doxycycline · chloramphenicol · erythromycin

**"Binds the 50S subunit?"** → **clindamycin**\
✗ Wrong options: cefazolin, cipro, doxycycline, vancomycin

**"Binds D-Ala-D-Ala to block transpeptidation?"** → **vancomycin**\
✗ Wrong options: daptomycin (membrane depolarisation)

**"Species producing mecA?"** → **MRSA**

**"How does S. epidermidis adhere and resist phagocytosis?"** → **biofilm**

**"MRSA resistance to penicillinase-stable antibiotics via?"** → **genetic mutation (mecA → PBP2a)**\
✗ Wrong options: efflux · biofilm · permeability · peptidoglycan

**"Tetracycline resistance: ribosome protection, modification and?"** → **increased drug efflux**

**"Biofilm resistance is an example of?"** → **avoidance**

**"Erythromycin-resistant MRSA, want clindamycin — test?"** → **D-zone test**\
✗ Wrong options: oxidase, CAMP, Ziehl–Neelsen, Etest

**"MSSA abscess → recurrence now methicillin-resistant — mechanism?"** → **mecA gene mutation**

**"Antibiotic toxic to chondrocytes, inhibits early fracture healing?"** → **quinolones**

**"Contraindicated in children?"** → **tetracycline**

**"Linezolid → clonus, tachycardia, hypertension — next step?"** → **IV benzodiazepines (serotonin syndrome)**
