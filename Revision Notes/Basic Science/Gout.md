# Gout

*Basic Science · 42 / 108*

## 1 Basics

### Epidemiology

**Demographics** — recurrent attacks in **men 40–60 yr**

**Site** — lower limb · **podagra (1st MTP)** · knee, ankle · hand/wrist possible · **tophi**: ear helix, eyelid, olecranon, Achilles

**Risk factors** — chemotherapy · alcohol

### Pathophysiology

**Primary gout** — idiopathic disorder of **nucleic acid (purine) metabolism** → **hyperuricaemia** → MSU crystal deposition

**Secondary gout** — high cell turnover: **psoriasis, haemolytic anaemia, leukaemia, chemotherapy**

**Inflammation** — crystals → proteases, prostaglandins, **leukotriene B4**, free radicals · tophi/pannus release IL-6, IL-8, TNF-α

**Associations** — **renal stones**, urate nephropathy · **septic arthritis can coexist** (~1.5%) — crystals don't exclude infection

## 3 Presentation

**Symptoms** — acute severe joint pain, swelling, erythema · mimics septic arthritis · remits in 1–2 wk, recurs

**Tophus aspirate** — **white, toothpaste-like** · tophi often confused with infection

## 4 Diagnosis & Classification

### Diagnostic criteria

**Definitive** — ✓ **joint aspiration + polarised microscopy** (or tophaceous deposits)

| Gout (MSU) | Pseudogout (CPPD) |
|---|---|
| **Needle-shaped**, thin, tapered, **intracellular** | **Rhomboid** |
| **Strongly negatively birefringent** | **Positively** birefringent |
| **Yellow parallel** to red compensator · blue perpendicular | Blue parallel |
| 1st MTP | Knee (large joints) |

**Serum uric acid** — not diagnostic · **80%** with hyperuricaemia never get gout · may be **normal during an attack**

### Key radiology findings

**X-ray** — **punched-out periarticular erosions with sclerotic overhanging edges** · **soft-tissue tophi** · joint space preserved until late

![Gout — punched-out erosions and tophi](../../Orthobullets/attachments/ob9041-22a-moved.jpg)

| Foot X-ray | Diagnosis |
|---|---|
| Periarticular erosions + tophi, 1st MTP | **Gout** |
| Pencil-in-cup, bilateral | Psoriatic arthritis |
| Flattened 2nd MT head | Freiberg's |
| Hindfoot fragmentation | Charcot |
| MTP dislocations, aspherical 1st MT head | RA |

**Biopsy** — acute + chronic inflammation, **prominent clefts** (crystals dissolved), no atypia

## 5 Management

### Treatment & distinguishing from septic arthritis

| Phase | Treatment |
|---|---|
| **Acute** | **NSAID — indomethacin** 50 mg tid (inhibits phagocytosis) · **colchicine** (if **peptic ulcer history**; can be IV) · steroids (oral, IA, IV) if NSAID/colchicine contraindicated (IA only if no sepsis) |
| **Chronic** | ✓ **Allopurinol** (xanthine oxidase inhibitor) — not in acute attack |
| Prophylaxis after recurrent attacks | **Colchicine** (up to 85% effective) |

```
Hot swollen joint, aspirate
├─ MSU crystals, synovial WBC <50k, well → NSAIDs (± ALLOPURINOL LATER)
├─ Crystals + WBC >50k / fever / infection risk → EMPIRIC IV ANTIBIOTICS → I&D
│      (crystals do not exclude sepsis)
└─ CPPD crystals → NSAIDs ± IA STEROID (not allopurinol)
```

**Fever 38.3, tachycardia, recent abdominal abscess, crystals on aspirate** — ✓ **empiric IV antibiotics** (cultures taken) → likely I&D

**WBC 20k, normal serum markers, MSU crystals** — ✓ **oral NSAIDs**\
✗ Wrong options: antibiotics · allopurinol · I&D · uric acid level

**Isolated gout flare suitable for discharge** — ✓ **SFA 35k WBC + MSU**\
✗ Wrong options: 75k + MSU (superimposed sepsis) · CPPD · 200k RBC (haemarthrosis)

**Hand lytic lesions, uric acid 10.4, clefts on biopsy** — ✓ **colchicine + indomethacin**\
✗ Wrong options: radiation, chemo, amputation, antibiotics

## X vs Y

| Aspirate image | Diagnosis |
|---|---|
| Negatively birefringent needles | **Gout** |
| Positively birefringent rhomboids | Pseudogout |
| Haemosiderin-laden giant cells | PVNS |
| Gram-positive cocci | Septic arthritis |
| Histiocytes, inflammatory cells | RA |

## How it's asked

**"60-yr-old, 2 yr intermittent great-toe pain, erosions + soft-tissue densities?"** → **MSU crystal deposition**\
✗ Wrong options: CPPD, renal osteodystrophy, TB, sarcoid

**"Foot radiograph most consistent with gout?"** → **periarticular erosions + tophi** (B)

**"Clinical + radiographic tophaceous lesion caused by?"** → **uric acid deposition**

**"Swollen hot 1st MTP — definitive diagnosis?"** → **aspiration of 1st MTP**\
✗ Wrong options: serum uric acid/CRP/ESR · MRI · RF

**"Gout diagnosed by tophi or?"** → **MSU crystals in synovial fluid**\
✗ Wrong options: ↑ serum uric acid

**"Hand lesion, negatively birefringent intracellular rods?"** → **gout**\
✗ Wrong options: CPPD, infection, GCT

**"Alcoholic, recurrent knee swelling, colchicine — aspirate image?"** → **negatively birefringent needles**

**"Crystal analysis consistent with gout?"** → **negatively birefringent needle-shaped**

**"Line cook, tophi on fingers, acute wrist pain — SFA?"** → **negatively birefringent needles**

**"Recurrent medial forefoot pain responsive to NSAIDs, normal WBC?"** → **needle-shaped negatively birefringent crystals**

**"Febrile, recent diverticular abscess, crystals in knee aspirate — next?"** → **empiric IV antibiotics**

**"Elderly woman, finger lytic lesions, uric acid 10.4 — treatment?"** → **colchicine + indomethacin**

**"Knee aspirate WBC 20k, MSU, normal labs — next?"** → **oral NSAIDs**

**"Isolated gout flare suitable for discharge?"** → **35k WBC + MSU**
