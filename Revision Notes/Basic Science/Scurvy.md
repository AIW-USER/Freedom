# Scurvy

*Basic Science · 97 / 108*

## 1 Basics

**Definition** — severe **vitamin C** deficiency

**Epidemiology** — deficiency in 8% men, 6% women (US) · M:F 4:3 · bimodal: **infants 5–10 mo** (rare <7 mo if breastfed — breast milk has vit C) + **men >60**

**Risk factors** — elderly men living alone ("tea and toast") · overcooking · alcoholism · smokers · malabsorption (Whipple's, IBD, chemotherapy) · infants on **evaporated/condensed milk**

### Pathophysiology

**Biochemistry** — humans lack functional **L-gluconolactone oxidase** → can't make ascorbic acid · ✓ **↓ chondroitin sulfate + collagen synthesis** · impaired **hydroxylation** of collagen peptides · ↓ carnitine → myalgia

**Site** — greatest effect on **metaphysis** (physeal region) · defective **primary + secondary spongiosa** · type I collagen defect → ↓ **osteoblast** function · fragile capillaries → bleeding\
✗ Wrong options: osteoclast (osteopetrosis)

**Histology** — primary trabeculae replaced by **granulation tissue** · haemorrhage · ✓ **widened zone of provisional calcification**

## 3 Presentation

**Symptoms** — malaise · bone pain · myalgia · **bleeding gums, loose teeth** (bluish-purple gums) · haematuria · haematemesis · iron deficiency

**Signs** — petechiae, ecchymoses · **joint effusions** · **swelling over long bones (subperiosteal haemorrhage)** · massive thigh swelling in infant

**Scorbutic rosary** — costochondral separation with **angular step-off** · not rachitic rosary (**rounded, nodular**)

![Scorbutic rosary](../../Orthobullets/attachments/ob9034-scorbutic-rosary.jpg)

**Sites** — wrists · knees · sternal rib ends (rapid growth)

## 4 Diagnosis & Classification

### Key radiology findings

| Sign | Description |
|---|---|
| ✓ **White line of Frankel** | Dense band = **widened zone of provisional calcification** between epiphysis + metaphysis |
| **Trümmerfeld zone (scurvy line)** | Transverse **lucent** metaphyseal band next to Frankel line |
| **Wimberger ring** | Dense ring around **epiphysis** |
| **Pelkin spur** | Metaphyseal spurs + fractures |
| **Corner sign of Park** | Metaphyseal clefts |
| Pencil-point cortex | Thin cortices |
| Ground-glass osteopenia | ↓ trabeculae |
| Others | Subperiosteal elevation · **epiphyseal separation** · fractures, dislocations |

![White line of Frankel and Wimberger ring](../../Orthobullets/attachments/ob9034-wimberger.jpg)

**Views** — wrists · knees · sternal rib ends

### Diagnostic criteria

**Diagnosis** — history + clinical + radiological picture + **response to vitamin C** · labs usually unhelpful · low fasting serum ascorbic acid

## 5 Management

**Treatment** — prompt **vitamin C** · adults **250 mg qid × 1 wk** · excellent prognosis if early

**Unanswered TO item (TO24050610)** — infant, swollen bleeding gums + massive thigh swelling, no trauma/fever · options Ewing / osteosarcoma / **scurvy** / haemophilia · **answer key not provided by source** · bleeding gums + subperiosteal long-bone swelling are scurvy features (Orthobullets)

## Scurvy vs Rickets

| | **Scurvy** | **Rickets** |
|---|---|---|
| Deficiency | Vitamin C | Vitamin D / Ca / PO₄ |
| Rosary | **Angular step-off** | **Rounded, nodular** |
| ZPC | **Widened, dense (Frankel line)** | Poorly calcified, wide physis, cupping |
| Bleeding | Gums, subperiosteal, joints | No |

## How it's asked

**"Somali 7-yr-old, purple bleeding gums, distal femur pain — true?"** → **widening of zone of provisional calcification**\
✗ Wrong options: ↓ osteoclast · vit D · ↑ chondroitin/collagen · epiphysis primarily

**"Infant with bleeding gums + massive thigh swelling, no trauma/fever?"** → **answer key not provided by source** (TO) · options Ewing / osteosarcoma / scurvy / haemophilia
