# Extensor Indicis Proprius

*Basic Science · 33 / 108*

## 1 Basics

### Anatomy

| | Extensor indicis proprius |
|---|---|
| **Origin** | Posterior ulna + interosseous membrane |
| **Insertion** | Extensor expansion of index finger |
| **Action** | Extends index finger, assists wrist extension |
| **Innervation** | **Posterior interosseous nerve (C7, C8)** |
| **Arterial supply** | Posterior interosseous artery |

![Extensor indicis proprius](../../Orthobullets/attachments/ob10040-extensor-indicis.jpg)

### Identification in the 4th compartment

**Position** — **deep and ulnar** to the EDC tendons · same (4th) compartment · single tendon, no subcompartment

**Distinguishing feature** — ✓ **most distal muscle belly**

**Traps** — ✗ Wrong options: separate compartment · circular cross-section (both flat) · most radial/superficial · two slips

## How it's asked

**"Dorsal wrist laceration — which 4th-compartment stump is EIP?"** → **the one with the most distal muscle belly**
