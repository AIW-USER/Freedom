# Subscapularis

*Basic Science · 102 / 108*

## 1 Basics

### Anatomy

| | Subscapularis |
|---|---|
| **Origin** | **Subscapular fossa** |
| **Insertion** | **Lesser tuberosity** |
| **Action** | **Internal (medial) rotation** + adduction · holds humeral head in glenoid |
| **Innervation** | **Upper + lower subscapular nerves (C5–C7)** — from ✓ **posterior cord** |
| **Arterial supply** | Subscapular artery |

![Subscapularis](../../Orthobullets/attachments/ob10016-subscapularis.jpg)

| Brachial plexus level | Branches |
|---|---|
| **Posterior cord** | ✓ **Upper + lower subscapular** · thoracodorsal |
| Lateral cord | Lateral pectoral |
| **Superior (upper) trunk** | **Suprascapular** · nerve to subclavius |
| Middle / inferior trunks | No branches |

## 3 Presentation

**Mechanism** — **forced external rotation** injury → subscapularis tear

**Tests** — **lift-off** (hand behind back, IR) → ✓ **subscapularis highest % maximal contraction** · **belly-press**\
✗ Wrong options: pec major, lat dorsi, supraspinatus

## 4 Diagnosis & Classification

### Key radiology findings

**Sagittal oblique MRI (coracoid level)** — ✓ **subscapularis = anterior** · supraspinatus superior · infraspinatus, teres minor, teres major posterior · assess **atrophy + fatty infiltration** (repair prognosis)

![Sagittal oblique MRI — subscapularis anterior](../../MCQ/attachments/q7394-a-6.jpg)

**Arthroscopy (posterosuperior portal)** — subscapularis tendon anteriorly · axial MRI fatty atrophy = chronic tear

## How it's asked

**"Muscle with highest activity in lift-off test?"** → **subscapularis**

**"Sagittal oblique MRI — anterior muscle (asterisk)?"** → **subscapularis**\
✗ Wrong options: supraspinatus · teres minor

**"Forced ER injury — tendon's nerve branches from?"** → **posterior cord**\
✗ Wrong options: lateral cord · superior trunk
