# Teres Major

*Basic Science · 106 / 108*

## 1 Basics

### Anatomy

| | Teres major |
|---|---|
| **Origin** | Dorsal **inferior angle of scapula** |
| **Insertion** | ✓ **Medial lip of intertubercular groove** |
| **Action** | **Adducts + internally rotates** arm |
| **Innervation** | ✓ **Lower subscapular nerve** — **C6, C7** (Orthobullets) · **C5, C6** (OB) · **thoracodorsal in 20%** |
| **Arterial supply** | Subscapular + circumflex scapular arteries |

![Teres major](../../Orthobullets/attachments/ob10009-teres-major.jpg)

### Innervation

**Lower subscapular nerve** — **posterior cord** (with upper subscapular + thoracodorsal) · also supplies **lower subscapularis** · relevant to tendon transfers for massive cuff tears

| Brachial plexus label (OB210271) | Nerve |
|---|---|
| A | Nerve to subclavius |
| B | Long thoracic |
| C | Upper subscapular |
| ✓ **D** | **Lower subscapular** |
| E | Medial cutaneous nerve of arm |

## How it's asked

**"IR muscle inserting on medial lip of bicipital groove — nerve?"** → **lower subscapular nerve**\
✗ Wrong options: upper subscapular · long thoracic
