## 1 Basics

### Nucleic acids & cell cycle

**Chromosomes** — **46** (22 autosome pairs + 1 sex pair) · **haploid** = DNA content of egg/sperm (half)

| | DNA | RNA |
|---|---|---|
| Bases | **A, T, G, C** (A–T, G–C) | **A, U, G, C** — no thymine |
| Strands | Double | Usually single (double in some viruses/interactions) |
| 2' position | **Hydrogen** (deoxyribose) | **Hydroxyl** (ribose) → less stable |
| Helix | **B-form** | **A-form** |
| Location | Nucleus | Nucleus + cytoplasm |

| RNA | Role |
|---|---|
| mRNA | Carries DNA code for protein |
| rRNA | Ribosome |
| tRNA | Brings amino acids to mRNA |

| Term | Definition |
|---|---|
| **Gene** | DNA segment encoding a protein |
| **Exon** | Coding — **ex**pressed |
| **Intron** | Non-coding |
| **Codon** | 3 nucleotides → 1 of 20 amino acids |
| **Promoter** | Controls transcription initiation |
| Enhancer | Transcription-factor binding site, regulates transcription |
| **Transcription** | ✓ **RNA polymerase reads DNA → complementary mRNA** |
| **Translation** | mRNA codons → polypeptide |
| Replication | DNA synthesis in S phase |
| Recombination | Meiotic haploid product with new allele combination |
| Translocation | Exchange between non-homologous chromosomes (Ewing, rhabdo, synovial sarcoma) |

| Cell-cycle phase | Event | Ploidy |
|---|---|---|
| G0 | Stable, not cycling | 2N |
| G1 | Growth | 2N |
| **S** | ✓ **DNA replication** | → 4N |
| G2 | Gap | 4N |
| M | Mitosis | → 2N daughters |

**No "R phase"**

**Apoptosis** — programmed cell death via intracellular signalling · (✗ Wrong options: lysis (contents spilled)) · loss = hallmark of cancer · **TNF receptor 1** → ✓ **apoptosis**

### Laboratory techniques (RT-PCR, GWAS)

| Technique | Use |
|---|---|
| Agarose gel electrophoresis | Separates **DNA by size** (negative charge, small runs faster) |
| **Southern blot** | **DNA** sequence |
| **Northern blot** | **RNA** |
| **Western blot** (SDS-PAGE) | **Protein** |
| DNA ligation | **Recombinant DNA** |
| **Plasmid** | ✓ **Extrachromosomal circular DNA replicating independently** · antibiotic resistance · vector (transformation) |
| **PCR** | DNA → many DNA copies · primers + heat-stable DNA polymerase |
| **RT-PCR** | RNA → cDNA → amplified · product = ✓ **DNA** · ✓ **measures mRNA level** of a gene |
| ELISA | Antigen / antibody detection |
| Immunocytochemistry | Localise protein in cells |
| DNA microarray | Expression profiling |
| DNA profiling | Forensic identity |

| Sequencing | Scope |
|---|---|
| **Whole-genome (WGS)** | Entire genome, coding + non-coding |
| **Whole-exome (WES)** | **Protein-coding exons only** (1% of genome, 85% of disease variants, 1/6 cost) |
| **GWAS** | ✓ **SNPs across many patients with a phenotype** → mutational variability |

## How it's asked

**"DNA replication phase?"** → **S**

**"RNA statements EXCEPT?"** → **"RNA uses thymine, DNA uracil"**

**"Plasmid?"** → **extrachromosomal circular DNA replicating independently**

**"Transcription?"** → **RNA polymerase reads DNA → mRNA**

**"RT-PCR product?"** → **DNA**

**"Assay for mRNA level?"** → **RT-PCR**\
✗ Wrong options: Western, Southern, ELISA

**"GWAS true?"** → **uses SNPs to evaluate variability among patients**

**"TNF receptor 1 involved in?"** → **apoptosis**

**"Inflammatory modulator of disc herniation pain?"** → **TNF-α**
