# Acetabular Fractures

*Trauma · 1 / 67*

## 1 Basics

### Epidemiology

**Incidence** — **\~4 / 100,000 / yr**

**Bimodal** — **young + high energy** (MVC) · **elderly + low energy** (fall from standing)

**Elderly volume** — \~4,000/yr in USA → may become the commonest age group

| Age group | Commonest patterns |
|---|---|
| **Young** | **Posterior wall** · transverse "family" (transverse, T-type, transverse + PW) · associated both column |
| **Elderly** | **Anterior wall** · **anterior column (quadrilateral plate)** · **anterior column posterior hemitransverse (ACPHT)** · associated both column |

**Elderly low-energy fall onto greater trochanter** — **anterior column + "medial wall"** (quadrilateral plate) ± intrapelvic head dislocation (✗ PC + PW, ✗ transverse, ✗ T-type, ✗ T + PW → young, high energy)

### Associated injuries

| Associated injury | Rate |
|---|---|
| **Lower extremity injury** | **36%** (commonest) |
| Head injury | 19% |
| Chest injury | 18% |
| **Nerve palsy** | **13%** (3–33% in OB) |
| Abdominal | 8% |
| Genitourinary | 6% |
| Spine | 4% |

**Nerve palsy pattern** — **sciatic, peroneal division** → **foot drop**; highest with **transverse + posterior wall**

**Nerve-injury share by pattern (OB)** — PW 9.5–23% · ABC 15.6% · PC + PW 12.5–23% · isolated PC rarely

**Root most often involved** — **L5** (→ tibialis anterior, EHL, EDB) (✗ L4, S1, S2, S3)

**Isolated peroneal-division injury** — commoner than complete sciatic injury

**Posterior hip dislocation + deceleration** — think **traumatic thoracic aortic rupture**; CXR may be normal → chest pain + hypotension + new leg weakness (cord ischaemia) → **CT angiography of chest** (✗ CT head, ✗ CT pelvis, ✗ CT L-spine, ✗ leg angiogram)

### Anatomy – column theory

**Columns** — **inverted Y**, linked to sacrum through the **sciatic buttress**

| | Anterior column | Posterior column |
|---|---|---|
| Parts | Anterior ilium (gluteus medius tubercle), **anterior wall + dome**, iliopectineal eminence, lateral superior pubic ramus | **Quadrilateral surface**, **posterior wall + dome**, **ischial tuberosity**, greater/lesser sciatic notches |
| Radiographic line | **Iliopectineal line** | **Ilioischial line** |
| Best Judet | **Obturator oblique** | **Iliac oblique** |

**TO anatomy (TO)** — anterior column = anterior ½ iliac crest, iliac spines, anterior ½ acetabulum, pubis · posterior column = ischium, ischial spine, posterior ½ acetabulum, dense sciatic-notch bone

**Acetabular orientation** — lateral inclination **40–48°** · anteversion **18–21°**

### Corona mortis & vascular anatomy

**Corona mortis ("crown of death")** — anastomosis **external iliac (inferior epigastric) ↔ obturator** (internal iliac system) behind **superior pubic ramus**

**Prevalence (Tornetta)** — **84%** have an anastomosis · **arterial 34%**, **venous 70%**, both 20%

**Distance from symphysis** — **mean 6.2 cm (range 3–9 cm)** → "brisk bleeding \~5 cm from midline along superior ramus"

**At risk** — **ilioinguinal** (laceration **10–15%**) + **modified Stoppa** (must be **exposed + ligated**); retracts into pelvis → hard to control

**✗ Vessel traps** — superior gluteal + pudendal · internal iliac + MFCA · external iliac + deep femoral · femoral branch

## 2 Mechanism

**Pattern determined by** — **force vector** + **femoral head position** at impact + **bone quality** (age)

**Dashboard / posteriorly directed force** — posterior wall ± posterior dislocation

**Crescent fracture (posterior iliac wing on CT)** — **lateral compression** (laterally directed force on anterior iliac wing) (✗ APC, ✗ VS, ✗ combined)

## 3 Presentation

**Foot drop / ↓ dorsiflexion after acetabular fracture** — **peroneal division of sciatic** → most likely pattern **transverse + posterior wall**

**Hip flexed, adducted, IR** — posterior dislocation ± posterior wall

**Os acetabuli marginalis superior** — accessory ossification centre at superior acetabular rim in adolescents; **mimics fracture / AVN**; usually **fuses by age 20** (✗ fovea capitis, ✗ myositis ossificans, ✗ AVN, ✗ fracture)

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Shows / use |
|---|---|
| **AP pelvis** | Screening; 6 landmarks: **iliopectineal line (AC)**, **ilioischial line (PC)**, anterior wall, posterior wall, **teardrop**, **weight-bearing roof** (+ Shenton's line) |
| **Obturator oblique (Judet)** | Obturator foramen in profile → **anterior column + posterior wall** (**"OOPWAC"**, TO) |
| **Iliac oblique (Judet)** | Iliac wing in profile, obturator foramen perpendicular → **posterior column + anterior wall** |
| Inlet / outlet | Only if pelvic ring involvement suspected |
| **CT** | **Gold standard**: pattern orientation, fragment size + position, **marginal impaction**, **loose bodies** (post-reduction), gap / step-off, surgical planning; 3D recon for planning |
| ✗ CT for | **Pre-existing degenerative change** (EXCEPT answer) |
| **Post-op CT** | **Most accurate for PW reduction** → **best correlation with outcome** |
| **EUA (dynamic fluoroscopy)** | **Best test of posterior wall stability** |
| Duplex US | Delayed presentation → rule out **DVT** |

**Judet = 45° obliques** — ipsilateral **iliac oblique = contralateral obturator oblique** (same image)

**"Best view of LEFT posterior column?"** — **left iliac oblique** (= right obturator oblique) (✗ left obturator oblique, ✗ right iliac oblique)

**Judet traps** — PW on **obturator oblique** (✗ iliac oblique, ✗ inlet, ✗ outlet, ✗ AP) · OO does **not** show SI joint well

**Interobserver reliability (Beaulé)** — Letournel substantial (κ > 0.70) **with or without CT** → CT not essential for classification, but adds **impaction + loose bodies**

![Obturator oblique Judet view: anterior column + posterior wall](../Orthobullets/attachments/ob1034-obturator-oblique-labeled.jpg)

| Sign / measure | Meaning | View |
|---|---|---|
| **Spur sign** | **Intact ilium** (most caudal part of intact ilium / posteroinferior ilium) exposed as acetabulum medialises → **pathognomonic for associated both column** | **Obturator oblique** (also AP) |
| **Gull (seagull) sign** | **Superomedial dome impaction** → **poor prognosis** (Orthobullets) | **Iliac oblique** (Orthobullets) |
| **Gull sign – TO wording (TO)** | **Anteromedial dome impaction**; "pathognomonic for **posterior column** fractures" → needs surgery | **Obturator oblique** (TO) |
| **Roof arc angle (Matta)** | Vertical line through head centre vs line to fracture; **stable if > 45° on AP + both Judets** (fracture exits outside weight-bearing dome) | AP + Judets |
| **CT subchondral arc (Olson & Matta)** | **Superior 10 mm** of acetabulum intact = equivalent to **45° roof arc** (TO) | CT |
| **Articular incongruity** | **> 2 mm** = unstable | CT |
| **Medial clear space widening on EUA** | **Posterior wall instability** | Obturator oblique under stress |

**Gull sign view** — **iliac oblique** (Orthobullets) · **obturator oblique** (TO) — read the options

**Roof arc NOT applicable** — **posterior wall** + **associated both column** (no intact acetabulum to measure)

**Spur sign absent** — **nondisplaced** ABC → use CT to confirm acetabulum–axial skeleton continuity

### Letournel & Judet classification

**Structure** — **5 elementary + 5 associated** = 10 types

![Letournel elementary patterns](../Orthobullets/attachments/ob1034-elementary-types.jpg)

| Elementary | Lines / views | Key fact |
|---|---|---|
| **Posterior wall** | PW outline broken on **OO** | **Commonest overall**; check **superior gluteal NV bundle**; only \~30% single large fragment |
| **Posterior column** | **Ilioischial line only** broken on AP; IO shows break, **anterior wall intact**; OO iliopectineal intact | Superior gluteal NV bundle; isolated PC rarely injures nerve |
| **Anterior wall** | — | **Very rare**; **geriatric** |
| **Anterior column** | **Iliopectineal line broken on OO** with **undisturbed posterior acetabulum** | 3–5% of fractures; may extend to quadrilateral plate without exiting PC |
| **Transverse** | **Iliopectineal + ilioischial** both broken; single line crossing acetabulum | **Only elementary to involve both columns**; axial CT: **vertical (sagittal) A→P line**; articular surface still attached to intact ilium |

![Letournel associated patterns](../Orthobullets/attachments/ob1034-associated-types.jpg)

| Associated | Key fact |
|---|---|
| **Associated both column (ABC)** | **All articular segments detached from intact ilium** (which stays on sacrum via SI joint) → **no articular surface attached to axial skeleton** · **spur sign** · may show **secondary congruence** |
| **Transverse + posterior wall** | **Commonest associated** · **highest nerve injury** · high DJD risk |
| **T-type** | Transverse + vertical split into **obturator ring** · high DJD risk |
| **ACPHT** | **Commonest in elderly** |
| **PC + PW** | **Only associated type NOT involving both columns** |

**Column vs transverse on axial CT** — **transverse = vertical (sagittal) line** · **column = horizontal (coronal) line**

**"Only one column involved?"** — **PC + PW** (✗ ABC, ✗ transverse, ✗ T + PW)

**Line-pattern traps** — both lines + **iliac wing + obturator ring** = ABC or ACPHT · both lines + **obturator ring** = T-type · iliopectineal only = AC · ilioischial only = PC

**Distinguishing ABC from ACPHT / T / T + PW** — those keep **part of articular surface on intact ilium**

### Posterior wall size & stability

| PW involvement | Stability | Action |
|---|---|---|
| **< 20%** | Generally stable | Protected WB — but **EUA if fracture exits superiorly (cranial exit near dome)** |
| **20–40%** | **Indeterminate** | **EUA** |
| **> 40–50%** | **Unstable** | **ORIF** |

**Fragment-size methods (less accurate than EUA)** — **Keith** (depth vs contralateral **at fovea**) · **Moed** (depth vs contralateral **at greatest involvement**) · **Calkins** (posterior **arc length** at greatest involvement)

**EUA technique** — hip **flexion + adduction + axial load**, **obturator oblique** view → **↑ medial clear space** = unstable

**History of dislocation** — **not** predictive of instability (Grimshaw & Moed: stable on stress exam → nonop fine)

**✗ Instability predictors** — fragment size alone, dislocation history, PW comminution, roof arc, MRI labral tear, iliac oblique

## 5 Management

```
Acetabular fracture
├─ Associated hip dislocation → urgent closed reduction (< 12 h) → CT
│      └─ incarcerated fragment → traction pin → ORIF ASAP
├─ Stable / minimally displaced / high-risk patient → protected WB 6–8 wk
└─ Displaced roof > 2 mm, unstable, impaction, loose body → ORIF < 3 wk
       └─ elderly + impaction / comminution / head injury → ORIF + acute THA
```

```
Posterior wall fracture (post-reduction CT)
├─ < 20%, exits low → protected WB
├─ < 20% exiting near dome, or 20–40% → EUA (obturator oblique)
│      └─ unstable → ORIF
└─ > 40–50% or intra-articular fragment → ORIF
```

### Nonoperative criteria

| Patient factors | Fracture factors |
|---|---|
| High operative risk (elderly, **DVT**) | **Minimally displaced < 2 mm** |
| **Morbid obesity** | **< 20% posterior wall** (EUA best test) |
| **Open contaminated wound** | **Head congruent with roof out of traction** |
| **Late presentation > 3 wk** | **ABC with secondary congruence** |
| | **Roof arcs > 45°** on AP + Judets |

**Nonop regimen** — protected WB **6–8 wk**; **skeletal traction NOT needed** if stable outside dome; **DVT prophylaxis**; serial X-rays

**Elderly ABC with secondary congruence** — **nonop** (✗ ORIF + THA)

### Operative criteria

| Patient factors | Fracture factors |
|---|---|
| **< 3 wk from injury** | **Roof displacement > 2 mm** |
| Physiologically stable | **Unstable pattern (PW > 40–50%)** |
| Adequate soft tissue | **Marginal impaction** |
| No local infection | **Intra-articular loose bodies** |
| **Pregnancy is NOT a contraindication** | **Irreducible fracture-dislocation** |

**Absolute surgical indication after dislocation** — **osseous loose body in weight-bearing joint** (✗ sciatic palsy, ✗ labral tear, ✗ PW fracture per se, ✗ chondral defect)

### Fracture-dislocation – reduction, traction & ORIF

**Posterior dislocation + small PW fracture** — **reduce hip now, test stability** (✗ CT first, ✗ MRI, ✗ open reduction, ✗ transfer before reduction)

**After reduction** — **CT mandatory** even if no fracture on X-ray → incarcerated osteochondral fragments (✗ exploration of nerve, ✗ EMG, ✗ traction) · sciatic palsy \~10%

**Reduction timing** — **< 12 h** (Orthobullets; > 12 h delay = poor result, OB) · **< 6 h** to minimise AVN (one OB explanation) — read the options

**Incarcerated fragment after reduction** — **distal femoral traction pin + ORIF ASAP** (offloads cartilage) (✗ knee immobiliser + delayed ORIF, ✗ nonop)

**Incarcerated fragment + shock / unresuscitated + knee laxity** — **distal femoral** pin (✗ proximal tibial pin with knee ligament injury, ✗ emergent ORIF, ✗ binder, ✗ EUA with intra-articular fragment)

**Marginal impaction on CT** — must be **elevated + bone grafted + buttress plated**; otherwise incongruent joint → poor result

**Loose fragments** — remove, but **incorporate** large articular fragments into fixation

**Pregnancy (12 wk, normal fetal HR, unstable hip)** — **acute ORIF** (✗ wait till 15 wk, ✗ traction 6–8 wk)

**Fetal mortality ↑ with** — **injury severity, mechanism of injury, maternal haemorrhage** (✗ trimester, ✗ approach, ✗ classification, ✗ fetal position)

### Timing of surgery

**Worse outcome if fixed** — **> 3 wk** from injury (✗ 48 h, ✗ 5 d, ✗ 1 wk, ✗ 2 wk)

**Delay > 11 days** — ↓ rate of anatomic reduction (OB)

**↑ Time to surgery** — **↓ chance of anatomic reduction** · infection trend ↑ · **no** effect on HO or neuro injury

**Early fixation → ↓** LOS, **↓ organ dysfunction**, ↑ function, ↑ discharge home, ↑ reduction quality (EXCEPT trap: "greater organ dysfunction")

### Surgical approach selection

| Approach | Indications | Risks |
|---|---|---|
| **Kocher-Langenbeck** (posterior) | **PW, PC, PC + PW, most transverse + T** | **Sciatic nerve (2–10%)**, **MFCA** (head blood supply), **↑ HO vs anterior** |
| **Ilioinguinal** (anterior) | **AW, AC, ABC (standard), ACPHT** | **Femoral nerve**, **LFCN**, femoral vessel thrombosis, **corona mortis 10–15%** · **lowest HO** |
| **Modified Stoppa (anterior intrapelvic, AIP)** | **Quadrilateral plate** buttress (medial wall comminution, ABC); ± lateral window ≈ ilioinguinal access | Corona mortis **must be ligated** |
| **Extended iliofemoral** | **Only single approach to see both columns directly**; T-type / transverse with **posterior comminution**, **transtectal T**, ABC with **posterior column comminution**, **SI joint involvement**, **> 3 wk** delay | **Massive HO (highest)**, **gluteal muscle necrosis** |
| **Iliofemoral** | **High anterior column** only | ✗ ABC |
| **Modified Gibson** | Gluteus max–TFL interval ± **trochanteric flip**; PW/PC, selected T + transverse | — |
| **Trochanteric flip osteotomy + surgical dislocation** | **PW + femoral head fracture (Pipkin IV)** | — |

**Stöckle (extended iliofemoral)** — 80% anatomic (< 1 mm) · loss of reduction 8% · **HO grade 3 13%** · AVN 4%

**ABC with spur sign, intact SI + PW, acute** — **ilioinguinal** (✗ extended iliofemoral, ✗ iliofemoral, ✗ KL, ✗ Gibson)

**74-yo, anterior column** — **ilioinguinal** (✗ Watson-Jones = hip, ✗ Hardinge = lateral THA)

**Transverse + PW** — **KL** (✗ trochanteric flip, ✗ extended iliofemoral) · **LC2 crescent** — anterior or posterior (✗ extended)

**Approach does not affect outcome** (Matta)

### Sciatic nerve – positioning & injury

**Least sciatic tension during KL** — **hip extended + knee flexed (90°)** (✗ hip flexed, ✗ knee extended; ✗ ilioinguinal — that risks femoral + LFCN)

**Highest intraneural pressure** — **hip flexed 90° + knee extended** (excursion from sciatic notch to leg)

### Percutaneous column screws – fluoroscopic views

| View | Shows |
|---|---|
| **Obturator outlet ("teepee" / teardrop)** | **Joint penetration** · **cranial–caudal** position · **supra-acetabular start point** (AIIS pin) |
| **Iliac inlet (inlet iliac oblique)** | **Anterior–posterior position in pubic ramus** → screw not exiting **posterior ramus** / not intrapelvic |
| **Obturator inlet** | Supra-acetabular screw **between inner + outer iliac tables** |
| **Iliac oblique** | Trajectory **above sciatic notch** · posterior column screw |
| **Inlet** | **SI joint penetration** |
| IO / OO with **hip + knee flexed** | **Posterior column screw** |

**Teardrop on obturator outlet** — column of bone **AIIS → PSIS** (ex-fix pins / screws) (✗ ASIS, ✗ sciatic buttress, ✗ roof)

**Antegrade AC screw** — start **gluteal pillar** → toward pubic tubercle · retrograde = ramus → iliac wing

### Elderly – acute THA with / without ORIF

**Acute THA indications** — elderly + **osteopenia / comminution**, **pre-existing arthritis**, **marginal impaction (gull sign)**, **PW comminution**, **femoral head fracture / damage**, **superomedial dome impaction**, **dislocation**, **delayed presentation**

**Elderly PW + dislocation + impaction / comminution / head damage** — **acute ORIF + immediate THA** (single stage) → **superior function** vs ORIF + delayed THA

**THA construct** — wall fractures → **buttress plate + multi-hole cup** · column fractures → **cage + cup** · columns must be stable first

**78-yo, posterior column + femoral head fracture** — **PC ORIF + THA same sitting** (✗ cup screws alone → cup migration, LaFlamme; ✗ staged; ✗ cup-cage — only for protrusio / discontinuity)

**74-yo neglected insufficiency fracture, 4 mo, head damage** — **hip reconstruction (THA, flanged / custom cup)** (✗ ORIF, ✗ traction)

**Fracture-dislocation + articular injury + head impaction + loose bodies, ORIF alone** — **\~50% convert to THA**; THA → **better function, fewer complications**

**Kreder** — **> 50 yr + marginal impaction + PW comminution** → **54%** early THA; residual displacement **> 2 mm** → arthritis

**THA after acetabular fracture** — **> 60 yr: \~30% late conversion** · 10-yr implant survival **75–80%**

**Acute ORIF + THA ✗ for** — young patients · isolated AC · small (10–20%) PW · transverse with good bone · ABC with secondary congruence

### Postoperative weight bearing & hip contact pressures

| Activity | Hip contact force |
|---|---|
| **Rising from chair on affected leg** | **Highest** (> walking); **posterosuperior acetabulum** |
| Full WB gait | High |
| Isometrics, bed pan | Approach walking, not exceed |
| Cane | \~60% of walking |
| **Toe-touch WB + passive abduction** | **Lowest** (< NWB — muscles contract in NWB) |

**Touch WB** — **10–15 kg** (< 20% BW) · partial WB = 20–25 kg (30–50% BW) → after **transtectal transverse PW ORIF**

## 6 Complications

| Complication | Fact |
|---|---|
| **Post-traumatic DJD** | **Commonest**; **80% native-hip survival at 20 yr** after ORIF; \~**20% need THA by 20 yr**; risk: **age > 40**, **T + PW and T-type**, **femoral head injury**, marginal impaction, malreduction → **THA or fusion** |
| **Heterotopic ossification** | **Highest extended iliofemoral** · KL intermediate · **lowest ilioinguinal / Stoppa**; \~25% incidence |
| **Osteonecrosis** | **6–7%** overall · **18% posterior patterns** |
| **Nerve injury** | Highest **T + PW**; sciatic (KL 2–10%), femoral / LFCN (ilioinguinal) |
| DVT / PE, infection, bleeding | — |
| Intra-articular hardware | Check obturator outlet |
| Abductor weakness | — |

### Prognostic factors

**Poor outcome** — multi-system trauma · **↑ age** · **poor articular congruency / malreduction** · **marginal impaction** · **femoral head injury** · post-traumatic arthritis · intra-op complications · delay > 3 wk

**Strongest risk for THA** — **articular malreduction** (linear relationship) (✗ > 50% THA at 20 yr, ✗ op time ↓ infection, ✗ delay ↓ malreduction, ✗ anterior column highest arthritis — PW is)

**Protective vs early THA** — **age < 40**, **simple pattern**, **initial displacement < 20 mm**, anatomic reduction, **no head injury** (✗ gender, ✗ approach)

**PW + age > 50 + non-anatomic reduction** — **highest THA conversion** (✗ AC, ✗ PC, ✗ AW, ✗ ABC)

**NOT a negative factor** — **involvement of both columns** (EXCEPT answer) · surgical approach

**Matta results** — excellent 40% · good 36% · fair 8% · poor 16%; clinical result tracks radiographic reduction

**Young, simple transverse, anatomic, no head injury — 20-yr native hip survival** — **> 75%**

**PROs after PW ORIF** — correlate with **hip muscle strength** + gait restoration (✗ age, ✗ arc of motion, ✗ immediate WB)

### Heterotopic ossification

**Brooker classification** — used to grade HO

![Brooker classification of heterotopic ossification](../MCQ/attachments/q219166-illa-illustration-a.jpg)

**Prophylaxis** — **indomethacin ×1 wk**, **low-dose radiation**, **debride gluteus minimus** (Orthobullets)

**OB update** — only **radiation 700–800 cGy within 72 h** clearly effective · **indomethacin unproven** in acetabulum + **prolonged use → ↑ nonunion** · gluteus minimus debridement now questioned

**Natural history** — \~85% asymptomatic; \~15% disabling stiffness → **excision** (even early if sciatic compression); **low symptomatic recurrence** (technical \~30%); expect ↑ blood loss

**✗ HO traps** — generous gluteus **medius** debridement (→ Trendelenburg) · "most need excision" · "high symptomatic recurrence" · ISS / fracture pattern as cause · radiation causing HO

**T-type via extended iliofemoral, HO at 3 mo despite radiation** — cause = **surgical approach**

## How it's asked

**"Elementary fracture involving both columns?"** → **transverse** (✗ ABC, ✗ T-type, ✗ T + PW)

**"All articular segments detached from intact ilium attached to sacrum?"** → **associated both column**

**"Associated fracture NOT involving both columns?"** → **posterior column + posterior wall**

**"Commonest associated pattern?"** → **transverse + posterior wall**

**"Commonest pattern in elderly?"** → **anterior column posterior hemitransverse** (low-energy: anterior column + medial wall)

**"Spur sign — what and where?"** → **intact ilium; obturator oblique** → **ABC** (TO)

**"Spur sign indicates?"** → **associated both column** (✗ transtectal transverse, ✗ vertical shear, ✗ H-type sacral, ✗ APC III)

**"Obturator oblique shows?"** → **posterior wall + anterior column** (TO)

**"Disruption of which line = posterior column?"** → **ilioischial** (TO) (✗ iliopectineal = anterior column, ✗ Shenton, ✗ sacral arcuate)

**"Anterior column fracture — expected finding?"** → **iliopectineal line broken on obturator oblique, posterior acetabulum intact**

**"Only ilioischial line broken, anterior wall intact on IO?"** → **posterior column**

**"CT indicated for all EXCEPT?"** → **pre-existing degenerative change**

**"Most accurate test of PW stability?"** → **dynamic fluoroscopic EUA, obturator oblique** (✗ Keith, ✗ Moed, ✗ Calkins, ✗ dislocation history)

**"PW < 20% but exits superiorly?"** → **fluoroscopic EUA** (✗ bedside exam, ✗ consent ORIF, ✗ angiography, ✗ protected WB)

**"Post-reduction CT, PW fracture with intra-articular fragment?"** → **traction pin + ORIF** (✗ EUA, ✗ protected WB)

**"Hip dislocation reduced, still foot drop?"** → **CT hip** (✗ explore nerve, ✗ EMG)

**"Delay most linked to poor result after dislocation?"** → **closed reduction > 12 h** (✗ > 3 attempts, ✗ traction, ✗ ORIF > 5 d)

**"Delay of fixation associated with poor outcome?"** → **> 3 weeks**

**"Single approach for ABC with segmental posterior column comminution?"** → **extended iliofemoral**

**"Approach for posterior column / PC + PW?"** → **Kocher-Langenbeck**

**"Modified Stoppa for?"** → **quadrilateral plate (ABC with medial wall)**

**"Trochanteric flip osteotomy indicated?"** → **PW + femoral head fracture**

**"Least sciatic tension?"** → **hip extended, knee flexed 90°**

**"Foot drop after acetabular fracture — which pattern?"** → **transverse + posterior wall**

**"Nerve root most affected?"** → **L5**

**"Corona mortis joins external iliac with?"** → **obturator**

**"Retrograde ramus screw — view to avoid posterior exit?"** → **inlet iliac oblique**

**"Obturator oblique-inlet view checks?"** → **screw between inner + outer iliac tables**

**"Obturator oblique-outlet view checks?"** → **cranial–caudal position / joint penetration**

**"Antegrade AC screw — avoid intrapelvic penetration?"** → **iliac oblique inlet**

**"Activity with greatest hip contact force?"** → **rising from chair on affected leg** (posterosuperior acetabulum)
