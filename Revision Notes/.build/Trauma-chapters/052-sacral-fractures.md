# Sacral Fractures

*Trauma · 52 / 67*

## 1 Basics

### Epidemiology

**Incidence** — **30–45% of pelvic ring injuries**; bimodal (young high energy · elderly low-energy / insufficiency)

**Neurological injury** — **25%**; **missed in 75% of intact** and 50% with deficits

### Anatomy

**Sacrum** — 5 fused vertebrae; **4 foramina**; load from S1 → iliac wings → acetabulum

**Nerves** — **L5 root on top of sacral ala** · S1–S4 through foramina (**S1 + S2 most injured**) · **S2–S5: sphincter tone, bulbocavernosus reflex, perianal sensation**; **unilateral preservation enough for bowel + bladder**

**Perianal numbness** — **S2 root** (✗ L3–S1)

## 2 Mechanism

**MVA / fall from height** (landing on feet → U-type) · repetitive stress / osteoporosis → insufficiency

## 3 Presentation

**Exam** — peripelvic pain; rotate iliac wings; **Morel-Lavallée** (lumbosacral degloving); **vaginal exam** (open); **rectal exam**, S2–S5 sensation, **anal wink, bulbocavernosus, cremasteric**; pulses ± ABI

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| **Radiographs** | **Show only 30%** |
| Lateral | Screening; poor quality |
| **Inlet** | Sacral canal, superior S1 |
| **Outlet** | **True AP of sacrum** |
| Signs | **L4 / L5 TP fractures**, asymmetric foramina, anterior ring injury, **stepladder sign** (AP; overriding transverse fragments) |
| **CT** | **Study of choice** (coronal + sagittal) · **sagittal → lumbopelvic instability** |
| MRI | **Neural compromise** suspected |

### Denis zones & neurological injury

| Denis | Location | Neuro deficit |
|---|---|---|
| **1** | **Lateral to foramina (ala)** | **5.9%** — lowest |
| **2** | **Through foramina** | **28.4%** |
| **3** | **Medial → spinal canal** | **\~60% — highest** (bowel / bladder) |

**Classified by most medial extent**

### Transverse, U-type & Roy-Camille

**Transverse sacral fracture** — ↑ nerve dysfunction (Tile A3 / Denis zone III)

**U-type (H / λ)** — **bilateral vertical (zone II) + transverse (S2)** → **spinopelvic dissociation**; axial load (fall onto feet); high neuro deficit, **cauda equina**

![U-type sacral fracture](../Orthobullets/attachments/ob1032-u-type-illustration.jpg)

| Roy-Camille (zone 3 transverse, sagittal) (TO) | Description |
|---|---|
| **1** | **Angulated, no translation** |
| **2** | **Angulated + incomplete translation** |
| **3** | **Complete translation + displacement** |
| 4 (Strange-Vognsen) | **Comminuted (axial load)** |

**Isler (TO)** — L5–S1 facet: 1 lateral (stable) · 2 through facet · 3 medial (2 + 3 unstable)

**AO (TO)** — A sacrococcygeal (stable) · B unilateral longitudinal · C spinopelvic instability

## 5 Management

```
Sacral fracture
├─ < 1 cm displacement, no neuro deficit / insufficiency → progressive WB ± orthosis
├─ > 1 cm / soft-tissue compromise / failed nonop / displacement → fixation
│      ├─ sagittal plane (zone I–II) → IS / transsacral screws (S2 if dysmorphic)
│      └─ U-type / vertical zone II / spinopelvic → triangular osteosynthesis
└─ Neurological deficit → fixation + decompression
```

### Operative criteria

| Nonoperative | Operative |
|---|---|
| **< 1 cm displacement**, no deficit | **Displacement > 1 cm** |
| Insufficiency fractures | Soft-tissue compromise, open |
| — | **Persistent pain / displacement after nonop** |
| — | **Neurological deficit → + decompression** (indirect traction or laminectomy / foraminotomy) |
| — | Posterior cortical displacement **> 4 mm**, + EUA, lumbopelvic dissociation (TO) |

### Spinopelvic dissociation (U-type) & triangular osteosynthesis

**Most stable for unstable transforaminal / U-type** — **triangular osteosynthesis = lumbopelvic (L4 / L5 pedicle → iliac screws) + iliosacral screw** (✗ ex-fix, ✗ IS alone, ✗ anterior plate + IS, ✗ transiliac bars, ✗ tension band)

**U-type + bladder loss (TO)** — **triangular osteosynthesis** (allows laminectomy + early WB) (✗ bilateral S1 screws, ✗ laminectomy + plating, ✗ transsacral screws alone)

**Vertical zone II + dysmorphic sacrum (TO)** — **triangular osteosynthesis with S2 transsacral screw** (✗ horizontal S1 screw — L5 injury, ✗ posterior tension band — wounds, weak vs shear, ✗ S1 TITS)

**Neuro prognosis predictor** — **initial fracture displacement** (✗ time to surgery, ✗ smoking, ✗ BMI, ✗ steroids)

**Elderly bilateral ala fractures** — **U-type / lumbopelvic instability → fixation** (✗ rami fractures alone, ✗ unilateral ala) · frail: 6 wk NWB then progressive (TO)

### Iliosacral / transsacral screws — fluoroscopy & dysmorphism

| View | Shows |
|---|---|
| **Lateral sacral** | **Iliac cortical density (ICD)** — start **posterior to ICD** (normal sacrum) → protects **L5** |
| **Inlet** | Anterior limit; **anterior alar indentation** in dysmorphism (in-out-in → L5) (OB) |
| **Outlet** | Trajectory vs **S1 foramen**; **cephalad alar border** (TO: critical to avoid superior breach → L5) |

**L5 breach view** — **outlet (TO)** · **inlet (OB)** — read the options

**Start point (S1 transsacral)** — **posterior to ICD, anterior to neural tunnels** (narrow safe zone); SI screws slightly more posterior

**Trajectory** — **sacral fracture → horizontal transverse screw** · **SI joint disruption → caudal-to-cranial, posterior-to-anterior** · avoid **over-compression** (nerve injury) → positional screw

**Vessel at risk** — **deep superior branch of superior gluteal artery** (✗ inferior gluteal)

**Dysmorphism** — **ICD not colinear with alar slope** → misleading · **S1 corridor narrow + oblique**, **S2 corridor larger → S2 transsacral screw ("safe harbour")** (TO)

**Dysmorphic signs (TO)** — non-colinear SI joints (sacrum high), **acute alar slope**, **mamillary processes**, **tongue-in-groove SI**, residual S1–S2 disc / accessory foramina, crescent void

**Screws** — ✗ osteoporotic bone; can't remove fragments; malreduction possible

**Posterior tension band plating** — two posterior incisions; ± IS screws; **wound complications**

### Sacral fragility fractures

**Nondisplaced zone 1 insufficiency (79-yr)** — **WBAT + gait PT** (✗ EUA, ✗ NWB, ✗ lumbar MRI, ✗ fixation) · fixation if > 1 cm, neuro deficit, or failed nonop

## 6 Complications

| Complication | Fact |
|---|---|
| VTE | Immobility |
| **Iatrogenic nerve injury** | Over-compression, malpositioned screws |
| Malreduction | **Vertical displacement** |
| Late | LE deficits, **urinary, rectal, sexual dysfunction** |

**Prognosis** — **neurological deficit = most important outcome factor**; **displacement ↑ neuro risk**

| Site | Ala | Foramina | Canal |

| | **SI joint screw** | **Sacral fracture screw** |

## How it's asked

**"Perianal numbness root?"** → **S2**

**"Highest nerve injury pattern?"** → **Denis zone 3**

**"Most neuro deficit?"** → **zone 3 (central canal)**

**"Predicts neuro dysfunction (U-type)?"** → **fracture displacement**

**"Bowel / bladder dysfunction — pattern?"** → **zone III (medial to foramen)**

**"Vertical zone II + dysmorphism (TO)?"** → **triangular osteosynthesis with S2 transsacral screw**

**"U-type + bladder loss (TO)?"** → **triangular osteosynthesis**

**"Most stable for transforaminal fracture?"** → **triangular osteosynthesis**

**"Fall onto feet, perineal numbness?"** → **U-type spinopelvic dissociation**

**"Most stable for U-type?"** → **triangular osteosynthesis**

**"View preventing cephalad breach (TO)?"** → **outlet view**

**"Constricted S1 corridor — alternative (TO)?"** → **S2 transsacral screw**

**"View showing anterior indentation (dysmorphic)?"** → **inlet view**

**"SI screw — true?"** → **guide wire posterior to ICD is safe in normal sacra**

**"S1 transsacral start point?"** → **posterior to ICD, anterior to neural tunnels**

**"79-yr nondisplaced zone 1 insufficiency?"** → **WBAT + PT**

**"Lumbopelvic instability in elderly?"** → **bilateral sacral ala fractures**

**"Roy-Camille type (TO)?"** → **type 2 (angulated + incomplete translation)**
