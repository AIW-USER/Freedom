# Distal Humerus Fractures

*Trauma · 12 / 67*

## 1 Basics

### Epidemiology

**Frequency** — **2% of all fractures** · **30% of elbow fractures** · rising

**Who** — young males (high energy) · older females (low-energy falls)

**Commonest pattern** — **distal intercondylar (bicolumnar)**

**Associated** — elbow dislocation, terrible triad, floating elbow, **Volkmann contracture** (missed forearm compartment syndrome)

### Anatomy

**Articular orientation** — **6° valgus, 5° ER, 30° flexion** (anterior)

**Trochlea** ↔ sigmoid notch (flex / ext) · **capitellum** ↔ radial head (rotation)

**Origins** — **medial epicondyle = flexor-pronators** (PT, FCR, PL, FDS, FCU) · **lateral = extensors** (anconeus, ECRL, ECRB, EDC, EDM, ECU)

**MCL anterior bundle** — medial epicondyle → **sublime tubercle**; primary valgus restraint **30–120°**; tight in pronation

**LCL** — lateral epicondyle → **crista supinatoris**; vs PLRI; tight in supination

**Ulnar nerve** — subcutaneous in cubital tunnel behind medial condyle

### Radial nerve landmarks (posterior approach)

| Landmark | Distance |
|---|---|
| Spiral groove | **15 cm** proximal to distal articular surface |
| From medial olecranon edge | **10 cm** |
| From lateral olecranon edge | **7.5 cm** |
| **Proximal to triceps aponeurosis** | **3.9 cm (≈ 2 finger-breadths)** |
| Pierces lateral intermuscular septum | **\~14 cm** above lateral epicondyle (OB) |

**Course** — between **BR + brachialis** above elbow → divides into **PIN + superficial radial** at radial head

**PABCN** — radial sensory branch **superficial to lateral intermuscular septum** → **posterior distal arm + forearm sensation**; trace it proximally to find radial nerve (✗ LABCN = musculocutaneous, ✗ MABCN = medial cord, ✗ SBRN = dorsoradial hand)

## 2 Mechanism

**Elbow flexed < 90° + axial load** — transcolumnar fracture · direct posterior blow → olecranon ± distal humerus

**Elbow flexed > 90°** — **intercondylar** fracture

## 3 Presentation

**Exam** — open wounds (**posterior**), gross instability (**avoid ROM**), radial / ulnar / median function, **brachial artery** (↓ pulse → non-invasive studies → vascular surgery), **forearm compartment syndrome**

## 4 Diagnosis & Classification

### Key radiology findings

| View | Use |
|---|---|
| **AP (≈ 40° flexion)** + lateral | Standard |
| Humerus, forearm, **wrist** | Associated injuries |
| Oblique | Trochlea continuity with medial epicondyle → implant choice |
| **Traction radiographs** | Comminuted, telescoped / flexed fragments → approach, **ORIF vs TEA**, 3rd plate, tricortical graft (✗ oblique, ✗ flexion / extension films) |
| **CT** | Planning; shear fractures of capitellum + trochlea |
| MRI | Not indicated acutely |

### OTA classification

| Type | Definition |
|---|---|
| **A** | **Extra-articular** — supracondylar (80% extension type), epicondyle |
| **B** | **Partial articular** — single column, coronal shear, epicondyle with articular extension |
| **C** | **Complete articular** — both columns, no joint contiguous with shaft |

![OTA classification of distal humerus fractures](../Orthobullets/attachments/ob1017-ota-distal-humerus.jpg)

### Milch classification (single column — 5%, lateral > medial)

| Type | Lateral trochlear ridge | Treatment |
|---|---|---|
| **I** | **Intact** (stable) | Non-displaced → **cast** · displaced → **CRPP** |
| **II** | **Fractured** through ridge (unstable) | **ORIF** |

**Casting** — **supination for lateral condyle**, **pronation for medial condyle**

### Jupiter classification (bicolumnar)

| Pattern | Feature |
|---|---|
| **High-T** | Transverse at / above olecranon fossa |
| **Low-T** | Just above trochlea (**common**) |
| **Y** | Oblique through both columns + vertical distal line |
| **H** | **Trochlea free fragment → AVN risk** |
| Medial / lateral lambda | Proximal line medial / lateral |
| Multiplane T | + coronal fracture |

**5 articular fragments** — capitellum / lateral trochlea, lateral epicondyle, posterolateral epicondyle, posterior trochlea, medial trochlea / epicondyle

## 5 Management

```
Distal humerus fracture
├─ Non-displaced Milch I → cast · displaced Milch I → CRPP
├─ Supracondylar / bicolumnar / Milch II, adult → ORIF, dual plates
│      └─ complex articular / coronal split → olecranon osteotomy
├─ Elderly, comminuted, osteoporotic / RA, low demand → semiconstrained TEA
└─ Unfit / can't comply → "bag of bones"
```

### Exposure – approaches

| Approach | Use / facts |
|---|---|
| **Triceps-splitting (Campbell)** | Midline split to olecranon; open fractures → use the wound; exposes **35%** of joint |
| **Triceps-sparing (paratricipital, Alonso-Llames)** | **Extra-articular + simple articular split**; medial + lateral windows; convertible to osteotomy |
| **Olecranon osteotomy** | **Complex intra-articular, coronal split**; **most exposure (57%)** |
| **Triceps-reflecting (Bryan-Morrey)** | Medial → lateral sleeve; transosseous repair, protect 4–6 wk; **46%** exposure; good medial, poor lateral view |
| **TRAP (O'Driscoll)** | Triceps + anconeus V-flap; repair via drill holes; no early mobilisation |
| Lateral muscle interval | Lift ECRB + part ECRL off supracondylar ridge |

**Young, complex articular (motorcycle)** — **olecranon osteotomy + parallel plating** (✗ Bryan-Morrey, ✗ TRAP) · or posterior extensile + **chevron** osteotomy (✗ Henry, ✗ Kocher, ✗ medial column, ✗ CRPP)

### Olecranon osteotomy

**Technique** — **chevron, apex distal**, \~**2 cm from tip**, through **bare area**; fix with **TBW, screws, plate**, or **intramedullary cancellous screw angled slightly medially** (proximal ulna varus bow)

**TEA after osteotomy** — **not contraindicated**; triceps-sparing preferred if TEA possible, but **all posterior approaches** (paratricipital, split, tongue, osteotomy) allow TEA

| Complication | Rate |
|---|---|
| **Symptomatic hardware** — **most common** | **6–30%** (Orthobullets) · **8–33%** (OB) · removal up to **70%** in 90/90 + osteotomy series |
| Osteotomy nonunion | **0–9%** (Orthobullets) · **0–2%** (OB); healing 95–100% |
| Fixation failure | \~5% |
| **AIN injury** (K-wires through anterior ulnar cortex) | **Can't flex thumb IP** — check in recovery (✗ wrist flexion, ✗ thumb sensation — AIN has none, ✗ dorsal web, ✗ index abduction) |

**Osteotomy + TBW vs other fixation** — **↑ AIN injury**; **not** ↑ ulnar neuritis

### Fixation constructs – parallel vs orthogonal plating

**O'Driscoll principles** — **every distal screw through a plate**; **screws as long as possible**, engaging many articular fragments; **interdigitate** screws from both plates; **compress both columns** at supracondylar level

**Sequence** — provisional K-wires → articular fragments with **countersunk / headless screws** (use **positional, not lag, screws across trochlea** to avoid narrowing) → plates to shaft

| Construct | Fact |
|---|---|
| **Parallel (medial + lateral, 180°)** | **Greatest rigidity** — **medial + lateral LC-DCP** stiffest |
| **Orthogonal (90-90)** | **Posterolateral + medial**; clinical outcomes **= parallel** |
| **1/3 tubular plates** | **Too weak** → failure + nonunion |
| Single plate (Y, medial) | Weaker than any dual construct |
| **Locking plates** | Poor bone, comminution |

**50-yo displaced intra-articular** — **dual column plates** (✗ TEA, ✗ brace, ✗ cast, ✗ K-wires)

**Adult bicolumnar (any age except frail)** — dual plating (90° or 180°)

**Post-op** — splint **70° flexion** → ROM by 7–10 d · osteotomy: active / active-assisted, **no active extension against gravity / resistance for 6 wk** · strengthening 6 wk, full 3 mo

### Ulnar nerve dysfunction

**Transposition at ORIF** — **no benefit**; **↑ ulnar neuritis** (33% vs 9%) **(TO: no effect or increased)** (✗ decreased)

**In situ release vs transposition** — **in situ → less ulnar neuritis**; PROMs equal

**Transpose only if** — nerve **on stretch or touching implants**, subluxing, recurrent

**Pre-existing cubital tunnel symptoms + H-type fracture** — **parallel plating (all screws through plate) + in situ cubital tunnel release** (✗ orthogonal + submuscular, ✗ observe neuropathy, ✗ lag screws outside plate + subcutaneous)

**Persistent ulnar symptoms after in situ release, no stretch / contact** — **observe + anti-claw splint** (✗ EMG acutely, ✗ revision transposition, ✗ Guyon release)

**Post-op ulnar palsy** — mostly **traction** during ORIF

### Elderly / osteoporotic – TEA vs ORIF

**TEA indication** — **elderly (> 65–70), low demand, osteoporotic, comminuted bicolumnar / distal articular fractures not amenable to stable fixation**; **RA**, **chronic steroids**; must accept **lifting limits**

**Implant** — **semiconstrained (linked)** — collaterals need not heal (✗ unconstrained in RA); radial head not needed

**Lifting limit** — **10 lb** (Orthobullets) · **5 lb** (OB) · **5–10 lb lifelong** (OB) — read the options

| ORIF vs TEA (elderly) | Finding |
|---|---|
| **Reoperation** | **ORIF higher (27% vs 12%)** (OB) · similar frequency (OB) · some studies higher with TEA (OB) — read the options |
| **Early PROMs / short-term function** | **TEA better** |
| ROM | TEA greater (Orthobullets, OB) · similar (OB) |
| Complications | TEA fewer (OB) · TEA more frequent (OB) |
| Operative time | **TEA shorter** |
| **Nonunion** | **Not a TEA complication** |
| Ulnar nerve dysfunction | Both |

**TEA facts** — **> 75% survival at 10 yr**; ROM **26–125°**; commonest complication **loosening / bushing wear (10–15%)**; **men** revised more; **salvage TEA after failed ORIF ≈ primary TEA**; complications: loosening, poly wear, periprosthetic fracture

**Failed ORIF in 83-yo (screws cut out at 5 wk)** — **elbow arthroplasty** (✗ revision ORIF, ✗ bag of bones, ✗ arthrodesis)

**TEA candidates ✗** — young labourer open T · transolecranon fracture-dislocation · coronal shear · nonunion in 50-yo

**"Bag of bones"** — brief immobilisation then ROM for unfit / non-compliant elderly → painless pseudarthrosis, fair function, high nonunion (✗ **immediate** ROM)

### Extra-articular distal-third shaft – functional bracing

**Brace vs surgery** — **similar small loss of elbow motion** (6° vs 3°, NS); 100% union; malalignment without functional limits; shoulder motion within 10°

## 6 Complications

| Complication | Fact |
|---|---|
| **Stiffness** | **Most common** (3–42%); mean arc 90–106°; static-progressive splint |
| **HO** | **8%** (Orthobullets) · \~4% (OB); no routine indomethacin (↑ nonunion); risk: **head injury**, floating elbow, type A + B, delayed fixation |
| **Nonunion** | **0–11%** (2–10%, OB); stripping, open, comminution, **low transcondylar**; → revision ORIF + graft |
| Malunion | Cubitus valgus (lateral column) / varus (medial column) |
| **AIN injury** | Olecranon osteotomy |
| **Ulnar nerve** | **10–38%** (Orthobullets) · **0–12%** (OB) |
| Wound | Up to 16% |
| Infection | 0–14% |
| PTOA | — |

### Stiffness, contracture release & HO

**Most common complication after ORIF** — **↓ ROM / stiffness** → subsequent **open release of capsule + posterior bundle of MUCL** (✗ revision for malunion / nonunion, ✗ hardware removal, ✗ HO removal alone)

**Limited flexion (30–90° or 10–80°)** — **open release of posterior bundle of MCL + posterior capsule + excise osteophytes / HO** (✗ release **anterior** bundle → valgus instability, ✗ complete MCL + LCL release, ✗ anterior arthroscopic release — that limits extension, ✗ dome osteotomy, ✗ indomethacin / radiation — prophylaxis only) · consider ulnar transposition if flexion < 90°

**Expected after ORIF** — **\~25% loss of flexion strength**; full ROM rare; most regain \~75% motion + strength; goal **30–130°**

**Unsatisfactory** — up to 25% (low fracture lines, metaphyseal fragmentation, articular comminution, poor bone)

### Radial nerve & branches

**Neurapraxia on NCV / EMG at 6 wk** — **normal amplitude + velocity in superficial radial sensory nerve** (no Wallerian degeneration) (✗ LABCN, ✗ FCU, ✗ EDC fibrillations = worse injury, ✗ triceps MUPs)

**Recovery order** — **proximal → distal**: **BR first … EIP last**

**Laceration 2 finger-breadths above triceps aponeurosis** — radial nerve → **can't extend index finger** (✗ thumb adduction = ulnar, ✗ small DIP = ulnar, ✗ thumb IP = AIN, ✗ pronation = median)

## X vs Y

| | **Parallel plating** | **Orthogonal (90-90)** |
|---|---|---|
| Plates | Medial + lateral | Medial + posterolateral |
| Rigidity | **Higher** | Lower |
| Clinical outcome | Same | Same |

| | **ORIF** | **TEA (elderly)** |
|---|---|---|
| Who | Adults, good bone | Elderly, osteoporotic, comminuted, RA |
| Nonunion risk | Yes | **None** |
| Early function | Lower | **Better** |
| Restriction | — | **5–10 lb lifelong** |

| | **In situ ulnar release** | **Anterior transposition** |
|---|---|---|
| Post-op ulnar neuritis | **Lower** | **Higher / no benefit** (TO) |
