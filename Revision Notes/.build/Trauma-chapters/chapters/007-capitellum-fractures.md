# Capitellum Fractures

*Trauma · 7 / 67*

## 1 Basics

### Epidemiology

**Frequency** — **1% of elbow fractures** · **6% of distal humerus fractures**

**Associated** — **radial head and / or LUCL injury in up to 60%**

### Anatomy

**Radiocapitellar joint** — key static stabiliser: **longitudinal + valgus stability**; capitellar excision → coronal instability if medial structures are torn

**LUCL relationship** — integral to posterolateral complex → **don't destabilise LUCL** during fixation

**Blood supply** — enters **posterolateral** → preserve during exposure

## 2 Mechanism

**Mechanism** — low-energy **FOOSH**; **axial compression through radial head with elbow semi-flexed** → **shear** of anterior capitellum

## 3 Presentation

**Symptoms** — elbow pain, swelling, ± wrist pain

**Exam** — **mechanical block to flexion / extension and / or rotation**; instability; NV exam

## 4 Diagnosis & Classification

### Key radiology findings

**Best view** — **lateral elbow** (+ AP, radiocapitellar view)

**Double-arc sign** — **pathognomonic** on lateral: **subchondral bone of displaced capitellum + lateral trochlear ridge** → **coronal shear fracture extending into trochlea** (✗ sagittal lateral epicondyle, ✗ coronal medial condyle, ✗ olecranon, ✗ trans-olecranon dislocation) · also called "double bubble"

**CT** — low threshold; delineates anatomy, trochlear involvement, posterior comminution

### Bryan & Morrey classification (McKee modification)

| Type | Description | Treatment |
|---|---|---|
| **I — Hahn-Steinthal** | **Large osseous capitellar fragment**, may involve trochlea | Displaced > 2 mm → **ORIF** |
| **II — Kocher-Lorenz** | **Articular cartilage shear** with **little subchondral bone** | Displaced → **excision** |
| **III — Broberg-Morrey** | **Comminuted / multifragmentary** | Displaced → **excision** (or TEA elderly) |
| **IV — McKee** | **Coronal shear including capitellum + trochlea** | **ORIF** |

## 5 Management

```
Capitellum fracture
├─ Non-displaced (< 2 mm) type I / II → posterior splint < 3 wk
├─ Displaced type I or IV → ORIF, headless screws
│      └─ posterior comminution / medial injury → posterior ± olecranon osteotomy
├─ Displaced type II / III → fragment excision
└─ Elderly, unreconstructable + medial column instability → TEA
```

### Treatment choice – ORIF vs arthroplasty

| Indication | Treatment |
|---|---|
| **Non-displaced I + II (< 2 mm)** | **Posterior splint < 3 wk** |
| **Displaced type I (> 2 mm)**, **type IV** | **ORIF** |
| Isolated type I with good bone (experienced arthroscopist) | **Arthroscopic-assisted ORIF** (70° scope; proximal anterolateral portal trocar reduces; flex past 90° to lock; screws P→A) |
| **Displaced type II, III** | **Fragment excision** |
| **Elderly, unreconstructable + medial column instability** | **TEA** |

**Healthy 33-yo coronal shear (double bubble)** — **ORIF** (✗ excision — large fragment excision → arthritis / instability with MCL tear, ✗ sling, ✗ capitellar replacement)

**Displaced capitellum, no dislocation (diabetic 41-yo)** — **ORIF** (✗ MRI for ligaments — unlikely injured without dislocation, ✗ cast, ✗ splint + motion, ✗ radial head replacement)

**88-yo comminuted low distal humerus (capitellum + trochlea), poor bone** — **TEA** (✗ ORIF, ✗ nonop, ✗ excise capitellum + fix trochlea) · TEA = choice for comminuted DHF > 70 yr; lifting limit **10–15 lb**; interposition arthroplasty for young who can't comply

### Surgical approach & fixation

| Approach | Use | Detail |
|---|---|---|
| **Lateral column / lateral extensile (Kaplan or Kocher)** | **Isolated capitellum + capitellum into lateral trochlear ridge (type I, IV)** | **Supine**; incision over lateral epicondyle → 2 cm past radial head; strip **ECRL + distal BR** off lateral column (wrist-extensor origin), elevate brachialis off anterior capsule; triceps posterior / BR + ECRL anterior; distal ECU–anconeus (Kocher) |
| **Kaplan interval** | — | **EDC ↔ ECRB** → **PIN at risk** → **keep forearm pronated** |
| **Posterior ± olecranon osteotomy** | **Capitellum + trochlea with posterior comminution, medial injuries, distal humerus / olecranon fractures** | **Lateral decubitus**; radial + ulnar flaps |

**Isolated capitellar shear, no trochlear / posterior comminution** — **supine + Kaplan (lateral column)** (✗ prone / lateral + osteotomy, ✗ triceps elevation, ✗ medial epicondylectomy)

**Capitellum + small piece of lateral trochlea** — **lateral column approach** (✗ Bryan-Morrey, ✗ Hotchkiss — medial, ✗ posterior ± osteotomy — too morbid)

**PIN injury from Kaplan approach** — **can't extend thumb** (✗ ulnar = medial approach, ✗ AIN = can't flex thumb / index IP, ✗ brachial artery = anterior, ✗ EIP)

**Fixation** — **headless compression screws** (buried beneath cartilage — avoid radial-head damage) **A→P** or **P→A**; mini-fragment screws P→A; capitellar / mini plates for proximal extension

**Headless screw most indicated** — **capitellar coronal shear (double arc)** (✗ lateral condyle — pins / headed screw, ✗ medial epicondyle — headed ± washer, ✗ olecranon — plate / TBW, ✗ supracondylar — plate / pins)

**Lateral approach best for** — **complete coronal shear capitellum** (✗ extra-articular DHF — posterior, ✗ proximal radial shaft — Henry / Thompson, ✗ undisplaced radial head — nonop, ✗ trans-olecranon — posterior)

## 6 Complications

| Complication | Fact |
|---|---|
| **Elbow contracture / stiffness** | **Most common**; **commonest reason for reoperation** (reoperation up to **48%**) |
| **Nonunion** | **1–11%** after ORIF |
| **Heterotopic ossification** | **4%** after ORIF |
| AVN of capitellum | Less common |
| Ulnar nerve injury, tardy ulnar palsy | — |
| Olecranon osteotomy nonunion | — |
| Instability, PTOA, cubital valgus, infection | — |

**Prognosis** — functional ROM but **residual stiffness** common; ORIF results generally favourable

**Worst outcome predictor** — **posterior comminution** (needs osteotomy / TEA) (✗ single fragment > 2 cm, ✗ coronal shear 1 cm, ✗ 5 mm post-reduction displacement, ✗ lateral trochlear extension)

## X vs Y

| | **Type I Hahn-Steinthal** | **Type II Kocher-Lorenz** | **Type IV McKee** |
|---|---|---|---|
| Fragment | Large bony capitellum | Cartilage shell | Capitellum + trochlea |
| Sign | — | — | **Double arc** |
| Displaced → | ORIF | Excision | ORIF |

| | **Lateral column (Kaplan)** | **Posterior + olecranon osteotomy** |
|---|---|---|
| Pattern | Isolated / lateral trochlear ridge | Posterior comminution, both columns, medial injury |
| Position | **Supine** | **Lateral decubitus** |
| Risk | **PIN** (pronate forearm) | Osteotomy nonunion, ulnar nerve |

## How it's asked

**"Double-arc sign means?"** → **coronal shear fracture of capitellum (into trochlea)**

**"Bicycle fall, double arc on lateral — describe?"** → **capitellum fracture extending into trochlea**

**"Young adult with displaced capitellar shear?"** → **ORIF**

**"Elderly, comminuted distal articular fracture, poor bone?"** → **TEA**

**"Lateral approach elevating extensors off lateral column best for?"** → **complete coronal shear capitellum fracture**

**"Ideal position + approach for isolated capitellar shear?"** → **supine, Kaplan**

**"Capitellum + small lateral trochlea, headless screws — exposure?"** → **lateral column approach**

**"Complication of the approach?"** → **can't extend thumb (PIN)**

**"Headless screw most indicated for?"** → **capitellar coronal shear**

**"Most common complication after fixation?"** → **elbow flexion contracture / stiffness**

**"Most common complication requiring reoperation?"** → **elbow contracture**

**"Finding predicting worst outcome?"** → **posterior comminution**

**"Non-displaced type I or II?"** → **posterior splint < 3 wk**

**"Displaced type II (cartilage shell)?"** → **fragment excision**
