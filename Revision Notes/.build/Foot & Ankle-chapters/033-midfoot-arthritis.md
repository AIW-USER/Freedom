# Midfoot Arthritis

*Foot & Ankle · 33 / 48*

## 1 Basics

### Definition & etiology

**Joints** — **naviculocuneiform**, **intercuneiform**, **tarsometatarsal (metatarsal–cuneiform)** · 2nd + 3rd TMT commonly narrowed

**Commonest cause** — **idiopathic / primary OA** (Orthobullets, OB) · **post-traumatic** articular damage (another OB) — read the options

**Post-traumatic** — missed / untreated **Lisfranc injury** (plantar bruising, "ankle sprain") → progressive flatfoot + midfoot arthrosis

**Inflammatory** — RA, lupus · **rule out inflammatory + neuropathic causes** before treating

**Pathoanatomy** — large forces through joints with **limited motion** · supporting soft tissues overloaded → **midfoot collapse** · over time Achilles shortens → **equinus**

**RA foot** — **forefoot commonest** (dislocations, hallux valgus) · midfoot: symmetric degeneration across **talonavicular + intertarsal** joints

## 3 Presentation

### Post-traumatic vs inflammatory, abduction & gait

**Symptom** — **midfoot / arch pain with toe-off (push-off)** · dull, achy, worse with weight-bearing · walking distance limited

**Gait phase** — **toe-off** (load passes hindfoot → midfoot → forefoot) (✗ heel strike, ✗ midstance, ✗ swing)

![Gait cycle: midfoot arthritis pain peaks at toe-off (E)](../MCQ/attachments/q218894-a-gait-cycle.jpg)

| Deformity on WB | Present? |
|---|---|
| **Longitudinal arch collapse** | **Yes** (✗ arch maintained) |
| **Midfoot collapse** — looks like **PTTI** | **Yes** |
| **Forefoot abduction** | **Yes** |
| **Hindfoot valgus** | **Yes** (✗ hindfoot varus) |
| **Equinus (Achilles) contracture** | **Yes** (✗ peroneus brevis contracture) |
| **Hallux valgus** | Yes |
| Dorsal midfoot prominence | Large **dorsal osteophyte** |

**Palpation** — arch / midfoot tender

**Midfoot vs PTTI** — **single-limb heel rise possible**, **inversion strength 5+**, supple hindfoot → PTT working → deformity **isolated to midfoot**

**Differential** — **PTTI** · post-traumatic **Lisfranc** · lateral ankle instability

## 4 Diagnosis & Classification

### Key radiology findings

| View | Finding |
|---|---|
| **Lateral (WB)** | **Break in Meary's line (talus–1st MT)** with **apex at midfoot** · longitudinal arch collapse · **dorsal osteophytes** · normal calcaneal pitch (vs PTTI) |
| **AP (WB)** | Midfoot arthritic change · **forefoot abduction** · normal talar head coverage (vs PTTI) |
| Inflammatory | **Symmetric joint degeneration**, minimal extra bone |
| Primary OA | **Subchondral cysts, osteophytes**, asymmetric narrowing |
| Image-guided steroid injection | **Diagnostic + therapeutic** |

## 5 Management

```
Midfoot arthritis
├─ First line → NSAIDs, activity change, stiff rocker-bottom shoe, arch support, image-guided steroid
└─ Failed nonop → midfoot (medial column) arthrodesis
       ├─ Equinus → + Achilles lengthening
       └─ Hindfoot valgus → + hindfoot realignment
```

### Nonoperative care – orthoses & bracing

**Best orthosis** — **stiff-soled rocker-bottom shoe** → transfers load **hindfoot → forefoot** with minimal midfoot stress

**Others** — **cushioned heel**, **longitudinal arch supports**

![Rocker-bottom shoe for midfoot arthritis](../MCQ/attachments/q218571-e-rocker-bottom-shoe.jpg)

| Orthosis | Use |
|---|---|
| **Rocker-bottom shoe** | **Midfoot (1st–2nd TMT) arthritis** |
| **Arizona brace** | **Flexible hindfoot planovalgus**; ankle + hindfoot stability |
| **Lateral heel wedge** | **Cavovarus with fixed forefoot pronation** |
| Lateral wedge + **1st ray cutout** | Flexible **cavovarus** |
| **Morton's carbon-fibre extension** | **1st MTP arthritis / hallux rigidus** |
| **Posterior leaf-spring AFO** | **Foot drop** |
| Medial wedge insole, **UCBL** | Flexible **planovalgus** |
| **Metatarsal pad** | **Freiberg disease** (2nd MT head AVN) |

### Midfoot / medial column arthrodesis

**Indication** — **failed nonoperative management** · midfoot joints are **non-essential** → fusion gives **near-normal foot function**, esp. push-off

**Isolated midfoot flatfoot (heel rise OK, flexible hindfoot, mild heel cord contracture)** — **medial column arthrodesis + heel cord lengthening** (✗ PTT debridement, ✗ tendon transfer + spring ligament / LCL, ✗ triple arthrodesis — PTTI / hindfoot procedures)

**TMT collapse, inversion 5+, supple hindfoot, normal heel cord** — **medial Lisfranc arthrodesis** (✗ LCL + FDL, ✗ TN, ✗ subtalar, ✗ triple — hindfoot procedures)

**Atraumatic midfoot OA, push-off pain, failed nonop** — **midfoot arthrodesis** (✗ PRP — not studied, ✗ 1st MT opening wedge — hallux valgus, ✗ **dorsal exostectomy — limited relief in advanced OA**, ✗ double calcaneal osteotomy — planovalgus abduction)

**Iliac crest autograft** — **improved fusion rate / ↓ nonunion** (✗ cost, ✗ fewer implants, ✗ long-term alignment — depends on technique + fixation, ✗ donor morbidity — significant donor pain)

**Realignment arthrodesis** — **1st ray → 1st TMT** · **2nd / 3rd rays → NC + intercuneiform joints** · **do NOT fuse 4th / 5th TMT** (lateral ray mobility accommodates stance) · select cases: **interposition arthroplasty of 4th / 5th TMT** (keeps lateral column length)

**Technique** — TMT joints **2–3 cm deep** → prepare fully · screws, staples, midfoot plates · ± **Achilles lengthening**, ± **hindfoot realignment**

**Outcome** — union linked to satisfactory outcome in **up to 90%** (Kurup) · **union 92%**, few complications at 4.5 yr (Nemec) · inflammatory midfoot: **primary fusion** most reliable

## 6 Complications

### Triple arthrodesis – talonavicular nonunion (TO)

| Complication of triple arthrodesis | Fact (TO) |
|---|---|
| **Nonunion** | **Commonest complication overall** + **commonest early / midterm** (TO) |
| Site of nonunion | **Talonavicular** (most difficult joint to fuse) **> calcaneocuboid** (TO) |
| **Ankle arthritis** | **40–100%** with long follow-up = **commonest long-term** complication (TO) |
| **Midfoot arthritis** | **\~50%** (TO) |
| Hardware irritation, infection, osteonecrosis, malunion, DVT, nerve injury | **Rare** (TO) |

## X vs Y

| | **Midfoot arthritis** | **PTTI flatfoot** |
|---|---|---|
| Single-limb heel rise | **Possible** | Unable |
| Apex of collapse | **Midfoot** (Meary break at TMT / NC) | Talonavicular / hindfoot |
| Calcaneal pitch, talar coverage | **Normal** | Abnormal |
| Surgery | **Medial column / Lisfranc arthrodesis** | Tendon transfer, osteotomies, triple |

| | **Inflammatory** | **Primary OA** |
|---|---|---|
| X-ray | **Symmetric degeneration**, little bone formation | **Cysts, osteophytes**, asymmetric |

## How it's asked

**"Lupus, midfoot pain — X-ray finding?"** → **symmetric joint degeneration**

**"Clinical finding with post-traumatic midfoot arthritis?"** → **forefoot abduction**

**"Gait phase that worsens midfoot arthritis?"** → **E — toe-off**

**"1st–3rd TMT OA, arch collapse — initial orthosis?"** → **Figure E — rocker-bottom shoe**

**"Rocker-bottom shoe prescribed — diagnosis?"** → **first and second tarsometatarsal arthritis**

**"Active 70-yo, push-off pain, failed nonop?"** → **midfoot arthrodesis**

**"Flat foot, heel rise OK, flexible hindfoot, tight heel cord?"** → **medial column arthrodesis and heel cord lengthening**

**"TMT collapse, inversion 5+, supple hindfoot?"** → **medial Lisfranc arthrodesis**

**"Why iliac crest autograft in midfoot fusion?"** → **improved fusion rate**

**"Commonest complication of triple arthrodesis?"** → **talo-navicular nonunion** (TO)

**"Commonest pseudoarthrosis after triple arthrodesis?"** → **talonavicular** (TO)

**"Commonest long-term complication of triple arthrodesis?"** → **ankle arthritis** (TO)
