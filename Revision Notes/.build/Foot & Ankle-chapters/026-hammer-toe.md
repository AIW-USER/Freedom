# Hammer Toe

*Foot & Ankle · 26 / 48*

## 1 Basics

### Epidemiology

**Commonest lesser-toe deformity** — hammer toe · **older / middle-aged women** · **2nd toe** usually

**Associated** — **painful corn on dorsal PIP** · secondary to **hallux valgus** or curly toe · neurogenic, degenerative, metabolic causes

### Plantar plate attenuation – MTP deformity

**Pathoanatomy** — **plantar plate injury** · **overpull of EDL** · **intrinsic imbalance / weakness**

**Plantar plate rupture → hammer toe** — MT head no longer suspended → **translates plantarly** → **MTP extension** → **EDL overpull** → **PIP flexion** to keep toe plantigrade (✗ mallet toe, ✗ TMT arthritis, ✗ Freiberg, ✗ hallux valgus — not the direct result)

**Plantar plate attenuation causes** — **MTP joint extension** (✗ DIP flexion, ✗ PIP extension, ✗ MTP / DIP malrotation)

**Plantar 2nd MTP pain** — "**stepping on a pebble**" · worse in high heels · MRI = degenerative plantar plate tear

## 3 Presentation

**Symptoms** — **dorsal PIP pain with shoe wear** · deformity · plantar 2nd MTP pain

**Exam** — **PIP flexion + DIP extension** (+ slight MTP extension)

**Ankle plantarflexion test** — **flexible deformity corrects** · **fixed / rigid does not correct**

**Push-up test** — dorsal pressure under the MT head → **flexible deformity reduces** (removes extrinsic overpull)

## 4 Diagnosis & Classification

**Diagnosis** — **clinical**: rigid or flexible lesser toe with PIP flexion, DIP extension, slight MTP extension

### Key radiology findings

**Imaging** — **not required** for diagnosis or treatment

### Claw toe vs hammer toe vs mallet toe

| Joint | **Claw toe** ![Claw toe](../Orthobullets/attachments/ob7014-clawe-toe-moved.jpg) | **Hammer toe** ![Hammer toe](../Orthobullets/attachments/ob7014-illustration-moved.jpg) | **Mallet toe** ![Mallet toe](../Orthobullets/attachments/ob7014-mallet-toe-illustration-moved.jpg) |
|---|---|---|---|
| **DIP** | Flexion | **Extension** | **Flexion** |
| **PIP** | Flexion | **Flexion** | Normal |
| **MTP** | **Hyperextension** | **Slight extension** | Normal |
| Cause | — | **EDL overpull** + intrinsic weakness | **FDL overpull / contracture** or EDL rupture |
| Callus | — | **Dorsal PIP** | **Toe pulp** (ulcers / calluses) |

## 5 Management

```
Hammer toe
├─ Pain / dorsal PIP corn → high toe box, foam / silicone sleeves, dorsal PIP padding
├─ Flexible, failed nonop → FDL → EDL transfer
├─ Rigid, failed nonop → PIP resection arthroplasty (± arthrodesis)
└─ MTP involved → Girdlestone (FDL → EDL)
       ├─ Mild MTP hyperextension → EDL Z-lengthening / tenotomy
       └─ Moderate–severe → EDL Z-lengthening + dorsal capsular release
```

### Operative criteria

| Situation | Procedure |
|---|---|
| **Flexible**, failed nonop | **FDL → EDL tendon transfer** |
| **Rigid / fixed**, failed nonop | **PIP resection arthroplasty** ± tenotomy / transfers · or **PIP arthrodesis** |
| **MTP involvement** | **Girdlestone** (FDL → EDL) — as for claw toe |
| Mild MTP hyperextension | **EDL Z-lengthening or tenotomy** |
| Moderate–severe MTP hyperextension | **EDL Z-lengthening + dorsal capsular release** |
| 2nd hammer toe + hallux valgus | **Correct hallux valgus** (arthrodesis if severe) · **amputation** if HV touches 3rd toe in elderly / poor health / declines reconstruction |

**Surgery indicated for** — progressive deformity · **fixed contractures** · **dorsal toe ulceration**

### Flexible vs rigid deformity – padding & PIP resection arthroplasty

**Fixed deformity** — **precludes success with soft-tissue procedures alone** → indication for **PIP resection arthroplasty** (✗ pain with shoes, ✗ all lesser toes involved, ✗ no MTP deformity, ✗ no hallux valgus)

**Rigid 2nd hammer toe sequence** — **dorsal PIP padding → shoe modification → PIP resection arthroplasty** (✗ **plantar** padding — pain is dorsal, ✗ MTP capsular release, ✗ MT head excision)

**Extensor tenotomy / lengthening** — **with** (not before) resection arthroplasty in severe cases → for **MTP dorsiflexion contracture** (✗ tenotomy preceding arthroplasty)

**Rigid hammer toe, failed nonop** — **PIP resection arthroplasty with K-wire fixation** (✗ **Weil osteotomy** — irreducible MTP subluxation / transfer metatarsalgia, ✗ **FDL transfer** — flexible, ✗ **EDL lengthening** — claw toe, ✗ **DIP fusion** — rigid mallet toe)

**Resection arthroplasty technique** — resect **head + neck (distal condyle) of proximal phalanx** (± middle phalanx articular surface) → **fibrous joint** or arthrodesis (**true fusion not necessary**) · **K-wire 2–3 wk** · then **tape PIP in extension 3 wk**

**PIP arthrodesis** — option for rigid deformity · **high nonunion rate** · **K-wire = most cost-effective implant**

**Girdlestone** — **EDL Z-plasty lengthening** · **MTP capsule release** · ± oblique **MT shortening osteotomy** · **FDL → EDL transfer**

## X vs Y

| | **Flexible hammer toe** | **Rigid hammer toe** |
|---|---|---|
| Ankle PF / push-up test | **Corrects** | **Does not correct** |
| Surgery | **FDL → EDL transfer** | **PIP resection arthroplasty** / arthrodesis |

| Procedure | Treats |
|---|---|
| **FDL transfer** | Flexible hammer toe |
| **PIP resection arthroplasty** | Rigid hammer toe |
| **EDL lengthening** | Claw toe / MTP hyperextension |
| **DIP fusion** | Rigid mallet toe |
| **Weil osteotomy** | Irreducible MTP subluxation · transfer metatarsalgia |

## How it's asked

**"Indication for PIP resection arthroplasty over soft-tissue balancing?"** → **fixed deformity**

**"Rigid 2nd hammer toe — sequence?"** → **dorsal PIP padding, shoe modification, PIP resection arthroplasty**

**"Rigid hammer toe, failed high toe box and sleeves?"** → **PIP resection arthroplasty with K-wire fixation**

**"Hammer toe — plantar plate attenuation causes?"** → **MTP joint extension**

**"Degenerative plantar plate tear — likely to develop?"** → **hammer toe**

**"Commonest lesser-toe deformity?"** → **hammer toe** (2nd toe)

**"Flexible hammer toe, failed nonop?"** → **FDL → EDL transfer**

**"PIP arthrodesis — cheapest implant?"** → **K-wire** (high nonunion rate)
