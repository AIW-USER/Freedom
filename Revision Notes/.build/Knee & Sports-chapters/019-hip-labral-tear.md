# Hip Labral Tear

*Knee & Sports · 19 / 61*

## 1 Basics

### Epidemiology & etiology

**Commonest association** — **acetabular dysplasia = highest incidence** (Orthobullets, OB) · **FAI = most common cause** of labral pathology (another OB) — read the options

**Who** — all ages · commonly **active females**

**Site** — **anterosuperior** (chondrolabral junction) — low collagen content + fibres parallel to chondrolabral junction · FAI tears 10–2 o'clock

**Asymptomatic** — **69%** of asymptomatic adults have a labral tear on MRI · 73% some hip pathology (Register) → a tear alone ≠ indication for surgery

**Causes** — **FAI**, **dysplasia** (floppy / redundant / **enlarged** labrum), **trauma** (dislocation / subluxation), **capsular laxity** (↑ translation), **degeneration** (edge loading)

**Effect** — tear ↓ resistance to motion → **initially relative hip instability** ✓ · commonest associated lesion: **chondral injury**

**Traps** — tears **are** related to DJD (✗ unrelated) · occur **with or without** abnormal morphology (✗ only with) · ✗ caused by ligamentum teres lesions · ✗ posteroinferior quadrant

**Dysplasia vs FAI labrum (Leunig)** — both tear **anterosuperior** · labrum **enlarged** in 12 dysplastic hips, none with FAI → anterosuperior rim = initial fatigue site

**Consequence** — ↑ friction, cartilage consolidation + strain → accelerated degeneration (Safran)

### Anatomy

**Shape** — horseshoe, **continuous with transverse acetabular ligament**

**Two parts** — articular = **fibrocartilage** · capsular = dense connective tissue

**Vascularity** — from capsule + synovium at acetabular margin → **only peripheral ⅓ vascularised**

**Innervation** — **highly innervated** (mechanoreceptors + nociceptors) · **nerve to quadratus femoris** + **obturator nerve**

**Function** — adds **22% surface area** + **33% volume** · **negative-pressure suction seal** → retains synovial fluid, frictionless motion

## 3 Presentation

**Symptoms** — mechanical **pain + snapping** (internal snapping), **locking**, vague groin pain · pain with sitting (anterior pathology)

| Provocative test | Manoeuvre |
|---|---|
| **Anterior labral tear** | **Flexed + ER + abducted → extension + IR + adduction** (painful catch) |
| **Posterior labral tear** | **Flexed + adducted + IR → abduction + ER + extension** |
| FADIR | Positive in **AS chondrolabral tear** and cam FAI |

**Intra-articular steroid relief** — diagnostic + therapeutic · confirms intra-articular source (✗ sacroiliitis)

**Distractors** — FNSF: no mechanical symptoms, axial-load pain, not linked to dysplasia · trochanteric bursitis: lateral GT tenderness · AVN: risk factors

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Finding / use |
|---|---|
| Radiographs | Exclude other pathology · **dysplasia**, arthritis, acetabular cysts |
| ANCHOR views (Clohisy) | AP pelvis, cross-table lateral, **45° + 90° Dunn**, frog-leg, false profile |
| **MR arthrogram** | **Study of choice / gold standard** · **92% sensitive** (Orthobullets) · **> 90%** (OB) |
| MRA finding | **Dye extravasation into labrum** · fluid deep to anterior chondrolabral junction |
| MRA + injection | Intra-articular **lidocaine + steroid** → diagnostic + therapeutic |

**FAI triad on MRA** — ↓ head-neck concavity → **↑ alpha angle + chondrolabral tear** · impingement + no crossover → **abnormal alpha angle + chondrolabral tear** (✗ acetabular retroversion, ✗ HO, ✗ AS, ✗ coxa vara)

**Normal values in stems** — **alpha 40° normal** (> 42° cam) · **head-neck offset ratio 0.20 normal** (< 0.17 cam)

| Element | Grading |
|---|---|
| Cartilage grade | **0** normal → **4** full-thickness defect, exposed bone |
| Site A | **< ⅓** of rim-to-cotyloid-fossa distance |
| Site B | **⅓–⅔** |
| Site C | **> ⅔** |
| Reliability | Intra-observer **0.81** · inter-observer **0.88** |

## 5 Management

```
Hip labral tear
├─ All patients first → rest, NSAIDs, PT, steroid injection
└─ Failed nonop → hip arthroscopy (+ treat FAI)
       ├─ full-thickness tear at labral-chondral junction → labral repair
       ├─ tear not amenable to repair → labral debridement
       └─ irreparable labrum → labral reconstruction
```

### Operative criteria

| Procedure | Indication | Outcome |
|---|---|---|
| **Nonoperative** | **Initial treatment for all** | No long-term data |
| **Arthroscopic repair** | Failed nonop + **full-thickness tear at labral-chondral junction** | Better healing + function than partial labrectomy |
| Arthroscopic debridement | Failed nonop + tear **not amenable to repair** | **70–85%** short-term relief |
| Labral reconstruction | Failed nonop + **irreparable** labrum | **Allograft ≈ autograft** PROMs |

### Treatment – arthroscopic repair

**Failed rest, PT, NSAIDs + 1-day injection relief** — **arthroscopic treatment of labral tear ± FAI** (✗ repeat injection, ✗ pinning — no fracture, ✗ loose body removal, ✗ PAO — no dysplasia)

**Address cause** — both labrum and FAI bone must be treated for symptomatic gain · AP pelvis may show retroversion

**Repair technique** — **knotless suture anchors** preserve labral anatomy

**Debridement** — remove unstable labrum + synovitis · **limited WB × 4 wk** · **flexion + abduction limited 4–6 wk**

**Approach (Matsuda)** — open dislocation, mini-open and arthroscopy all improve pain + function · open → **highest complication rate** · mini-open → **LFCN injury** · all-arthroscopic ≥ others, fewest major complications

## X vs Y

| | **Dysplasia labrum** | **FAI labrum** |
|---|---|---|
| Labrum | **Hypertrophic / floppy / enlarged** | Normal size, crushed / separated |
| Site | Anterosuperior | Anterosuperior |
| Bony fix | **PAO** | Osteoplasty |

## How it's asked

**"Avid runner, MRA dye in labrum?"** → **labral tear**

**"Impingement test +, no crossover — MRI shows?"** → **abnormal alpha angle + chondrolabral tear**

**"True statement about hip labral tears?"** → **initially lead to relative hip instability**

**"Dysplasia, snapping, pain flexed-ER-abducted → extended-IR-adducted?"** → **labral tear**

**"FADIR pain, no axial-load pain — which image?"** → **MRA with anterior labral tear (fluid deep to chondrolabral junction)**

**"Failed PT, NSAIDs, rest, brief injection relief?"** → **arthroscopic treatment of labral tear and possible FAI**
