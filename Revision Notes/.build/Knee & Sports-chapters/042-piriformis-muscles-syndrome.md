# Piriformis Muscles Syndrome

*Knee & Sports · 42 / 61*

## 1 Basics

### Sciatic nerve anatomy relative to piriformis

**Normal exit** — **inferior to (deep / anterior to) piriformis**, superior to superior gemellus · via greater sciatic foramen

**Commonest pattern** — **single nerve anterior to piriformis** · **79%** (OB, Pokorny) · **96%** (TO) — read the options

**Atypical anatomy** — **~21%** (Pokorny, 91 cadavers)

**Commonest variant** — **14%**: nerve splits above piriformis → **one branch anterior + one through** the muscle (OB) · usually **peroneal part pierces**, tibial part runs below / above (TO) · whole nerve may pass through the belly (TO)

**Short external rotators (superior → inferior)** — piriformis, superior gemellus, obturator internus, inferior gemellus, obturator externus, quadratus femoris

![Sciatic nerve exiting deep to piriformis](../MCQ/attachments/q2850-illa-piriformis.jpg)

### Pathophysiology

**Definition** — sciatica-like pain from **extrapelvic sciatic nerve compression** at the hip · aka **back pocket / wallet sciatica** (TO)

**Site** — **anterior to piriformis** or posterior to obturator internus / gemelli at **ischial tuberosity level** (Orthobullets) · in piriformis at **greater sciatic notch** (TO)

**Primary (TO)** — anatomic: **split piriformis**, **split sciatic nerve**, anomalous nerve path · Orthobullets adds **bipartite piriformis**, tumours, **inferior gluteal artery aneurysm**

**Secondary (TO)** — trauma, **LLD**, cerebral palsy, narrowed sciatic foramen · macrotrauma to buttock (spasm) · microtrauma / overuse (long-distance walking, running, **dancing**) · **wallet in back pocket**

**FAI link** — ↓ IR → short external rotator contracture → sciatic compression

## 3 Presentation

**Pain** — **posterior gluteal pain radiating down back of leg**, burning / aching

**Pattern (TO)** — worse **rising after sitting / squatting > 15–20 min** · pain on IR (cross-legged sitting) · **improves with ambulation, worse with rest**

**Referred (TO)** — spasm stresses **sacrotuberous ligament** → **pudendal** compression → groin / pelvic pain · **fibular (peroneal) branch** compression → paraesthesia sacrum → buttock → posterior thigh

| Test (TO) | Positive when |
|---|---|
| **FAIR** (Orthobullets) | **Flexion, adduction, IR** stretches piriformis → reproduces symptoms |
| **Pace sign** | FAIR recreates **sciatic symptoms** |
| **Piriformis sign** | Supine, foot lies **externally rotated** · active return to midline → pain |
| **Freiberg sign** | Pain on **passive hip IR** |
| **Beatty test** | Side-lying on unaffected side, lifts top knee ~4 inches → sciatic pain |
| Lasègue | Hip + knee 90°, extend knee → posterior thigh pain |

## 4 Diagnosis & Classification

**Imaging** — X-ray unremarkable · hip MRI usually unremarkable · **lumbar MRI** to exclude spinal cause · **EDS** document sciatic impairment

### Differential – ischiofemoral impingement

**Dancer, buttock pain → at rest, pain on hip extension + ER, quadratus femoris oedema (TO)** — **ischiofemoral impingement** (✗ FAI, ✗ piriformis syndrome, ✗ quadriceps tendinopathy)

**IFI definition (TO)** — chronic groin / buttock / hip pain + **narrowed space between lesser trochanter and ischial tuberosity**

**Ischiofemoral distance on axial MRI (TO)** — **normal > 2 cm** · **< 1.3 cm critical**

**MRI (TO)** — **quadratus femoris ↑ T2 signal**, fibres intact · QF oedema can compress / displace **sciatic nerve** → radicular pain

**Causes (TO)** — **iatrogenic after hip surgery**, hip trauma, **ischial exostosis**, primary in young athletes

**IFI test (TO)** — pain on **extension + adduction + ER** (one TO explanation) · **extension + abduction + ER** (other TO explanation) · tenderness over ischiofemoral space

**IFI treatment (TO)** — NSAIDs, guided steroid injection, PT → failure: **endoscopic resection of lesser trochanter**

| Condition (TO) | Key features | Treatment |
|---|---|---|
| **Ischiofemoral impingement** | Buttock pain, extension + ER, **QF oedema**, distance < 1.3 cm | NSAIDs, injection → LT resection |
| **Piriformis syndrome** | Buttock → posterior leg, worse with sitting, **FAIR / Pace** | Stretch, NSAIDs → release + neurolysis |
| **Snapping hip — internal** | Anterior click · **iliopsoas over iliopectineal eminence** | Stretch → iliopsoas release / lengthening |
| **Snapping hip — external** | **More common** · lateral · **ITB over greater trochanter** | Stretch → ITB release / lengthening |
| **Snapping hip — intra-articular** | **Labral tear, loose body** · dynamic USG / MRI | **Arthroscopic loose body removal + labral repair** |
| **Iliopsoas tendinopathy** | Musculotendinous junction · pain on active flexion, stairs, getting out of car | Rest, stretch, NSAIDs, PT → release at LT / lengthening |
| **Iliopsoas tendonitis after THR** | Groin pain on active flexion · painful SLR, passive SLR pain-free | CT-guided steroid + stretch → **iliopsoas tenotomy** |

**Snapping hip (TO)** — coxa saltans / **dancer's hip** · ballet dancers, extreme flexion + abduction · **extra-articular more common** than intra-articular · resistant extra-articular → local steroid into sheath

**Iliopsoas bursa (TO)** — **largest bursa in the body** · 3 causes of bursitis: **RA, acute trauma, overuse**

**Snapping hip sign / extension test (TO)** — palpate inguinal crease, flex → abduct + ER → back to neutral → palpable click

**Iliopsoas after THR — diagnosis (TO)** — **cross-table lateral** shows **cup prominent beyond anterior rim** (snapping over anterior lip) · relief after **USG / CT-guided local anaesthetic** into iliopsoas sheath confirms

## 5 Management

```
Piriformis syndrome
├─ First line → rest, NSAIDs, muscle relaxants, ice, PT stretching, steroid injection
└─ Refractory → piriformis release + external sciatic neurolysis
```

**Nonoperative** — **stretch piriformis + short external rotators** · strengthen abductors + adductors (TO) · **corticosteroid injection near piriformis** · early conservative Rx most effective (TO)

**Surgery** — only after failed conservative care · release piriformis tension + **explore sciatic notch** for fibrous bands / constrictions

## How it's asked

**"Most common sciatic nerve pattern at exit?"** → **single nerve anterior to piriformis**

**"Dancer, extension + ER pain, quadratus femoris oedema (TO)?"** → **ischiofemoral impingement**

**"MRI finding separating IFI from piriformis syndrome (TO)?"** → **quadratus femoris oedema, ischiofemoral distance < 1.3 cm** (✗ piriformis syndrome — MRI usually normal)
