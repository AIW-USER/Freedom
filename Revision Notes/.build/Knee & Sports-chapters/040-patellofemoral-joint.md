# Patellofemoral Joint

*Knee & Sports · 40 / 61*

## 1 Basics

### Anatomy & stabilisers

**Articulation** — **patella ↔ trochlear (intercondylar) groove** · **LFC diameter > MFC**

**Bony constraint** — **trochlear groove = primary restraint to lateral translation at > 30° flexion**

**MPFL (this note)** — **adductor tubercle → superomedial border of patella** · **primary restraint 0–20°** · instability note: between **medial epicondyle and adductor tubercle**, **0–30°** — read the options

| Passive restraint to lateral subluxation | Share of restraining force |
|---|---|
| **MPFL** (primary, at 20°) | **60%** |
| Medial patellomeniscal ligament | **13%** |
| Medial retinaculum | **10%** |

**Dynamic** — **vastus medialis** resists **lateral** translation · vastus lateralis resists **medial** translation · quadriceps

**Blood supply** — superior medial + lateral geniculate · inferior medial + lateral geniculate · anterior geniculate · descending geniculate

### Q-angle & patellofemoral contact pressures

**Q-angle** — **ASIS → centre of patella → tibial tuberosity** · **13° M / 18° F** (Orthobullets) · 14° M / 17° F (TO) · 14° M / 18° F (OB) — read the options

![Q-angle](../Orthobullets/attachments/ob3002-qangle-moved.jpg)

**Effect of Q-angle** — valgus axis → **laterally directed force** → **↑ lateral facet pressure between 40–90° flexion** · 10° ↑ Q → ↑ peak pressure, lateral facet

**Pressure vs flexion** — ↑ from extension to **\~90°** (maximum) · falls to **1/3 by 130°** · normally even medial / lateral

**Maximum contact** — **45°** (Orthobullets; OB: max bony contact \~45°) · **90°** (TO, instability topic) — read the options

**Location** — deeper flexion → **higher pressure in proximal patella** (patella slides **caudally**) (✗ distal)

**Osteotomy** — medialisation and AMZ both **partially correct** high-Q lateral pressures, similarly

**OB traps** — ✗ patella-trochlea articulation primary at 0–30° (MPFL is) · ✗ vastus medialis = primary restraint near extension · ✗ forces highest in extension

### Biomechanics

**Function** — transmits quads force to patellar tendon · **↑ extensor lever arm** · **patellectomy ↓ extension force 30%**

| Activity (TO) | PFJRF (× body weight) |
|---|---|
| Level walking | **0.5–1** |
| Vertical jumping | **2.4–4.6** |
| Stair ascent / descent | **3.5–6** (descent > ascent) · 2–3 descending (Orthobullets) |
| Running | **4.5–7** |
| Squat | **Up to 7** |
| **Deep squat** | **Up to 20** |

**PFJRF order (TO, this topic)** — **walking < jumping < stair ascent < stair descent < running < squat < deep squat** (✗ jump after stair descent, ✗ ascent > descent, ✗ less force with more flexion)

**PFJRF order (TO, instability topic)** — walking < ascent < descent < running < squat < deep squat < **jumping** — read the options

**Flexion** — **↑ flexion → ↑ PFJRF**

## 4 Diagnosis & Classification

### Key radiology findings

| View | Shows |
|---|---|
| **AP** | Alignment, fracture, arthritis |
| **Lateral** | **Patella alta / baja**, condylar dysplasia, arthritis, **transverse** patella fracture |
| **Axial** | **Malalignment**, trochlear depth, arthritis, **vertical** patella fracture |
| CT | Alignment, fracture, trochlear geometry, **TT-TG** |
| **MRI** | **Best for articular cartilage** · **T2** best sequence |

**Measurements** — patellar height (Insall-Salvati) · **lateral PF angle opens laterally** (normal) · **congruence angle −6°** (normal)

## How it's asked

**"PFJRF true statement (TO)?"** → **walking < jumping < stair ascent < stair descent < running < deep squat**

**"PF biomechanics — true?"** → **higher Q-angle → ↑ lateral contact pressure 40–90°**
