# Scapular Winging

*Shoulder & Elbow · 42 / 60*

## 1 Basics

### Definition & types

**Definition** — dysfunction of **scapular stabilising muscles** → imbalance + abnormal scapular motion; rare, debilitating

**Named by** — direction of the **superomedial corner** of the scapula

| | **Medial winging** | **Lateral winging** |
|---|---|---|
| Muscle | **Serratus anterior** | **Trapezius** (rarely rhomboids) |
| Nerve | **Long thoracic (C5, C6, C7)** | **Spinal accessory (CN XI)** |
| Unopposed pull | **Medialising retraction (rhomboids)** + **elevation (trapezius)** | **Lateralising protraction** (serratus, pec major + minor) |
| Who | **Young athletes**; **more common** | **Iatrogenic** (neck surgery) |
| Commonest cause | **Repetitive stretch/traction** (>50%) | **Iatrogenic** (**up to 70%**) |

![Lateral (trapezius/CN XI) vs medial (serratus/LTN) winging](../../Orthobullets/attachments/ob3062-winging.jpg)

### Anatomy – scapulothoracic stabilisers

**Scapulothoracic articulation** — **not a true joint**; attached via **AC joint** ligaments; **suction** by serratus anterior + subscapularis holds scapula to thorax

**Scapula** — attachment for **17 muscles**

| Muscle | Origin → insertion | Action | Nerve |
|---|---|---|---|
| **Serratus anterior** | **Ribs 1–8** (Orthobullets) · top **8–9 ribs** (OB); 7–10 slips → anteromedial (vertebral) border | **Protraction** (+ upward rotation, stabilises vertebral border) | **Long thoracic (C5–7)** |
| **Trapezius** | Superior nuchal line, EOP, nuchal ligament, **C7–T12** spinous → lateral ⅓ clavicle, acromion, spine | **Upward rotation + elevation** | **Spinal accessory (CN XI)** |
| **Rhomboid major** | **T2–T5** spinous → medial border below minor | **Retraction** (+ elevation, OB) | **Dorsal scapular** |
| **Rhomboid minor** | **C7–T1** spinous → medial border at base of spine | Retraction | **Dorsal scapular** |
| **Levator scapulae** | **C1–C4 transverse processes** → medial border at spine level | Elevation + downward rotation | **C3–C4 cervical plexus** + dorsal scapular |

**Serratus parts** — upper: downward rotation (glenoid down), stabilises superior scapula · middle: protraction · lower: **upward rotation + abduction**

**Serratus blood supply** — long thoracic artery (superior) · **thoracodorsal artery** branches (inferior)

**Trapezius parts** — upper: upward rotation + elevation · middle: **retraction + adduction** · lower: downward rotation + depression

### Long thoracic nerve

**Roots** — **ventral rami C5, C6, C7** · **C4 contribution 13%** · **no C7 in 8%**\
✗ Wrong options: C8–T1 · C4–6 · C6–8

**Course** — **first nerve to branch** off brachial plexus · posterior to axillary vessels + plexus · **superficial to serratus**, branch to each slip

**Vulnerability** — **long course, small diameter, little connective tissue** · easily injured in **axillary dissection**

**Crow's foot** — where LTN crosses the dominant inferior **serratus branch of thoracodorsal artery**

### Spinal accessory nerve

**CN XI** — spinal + cranial parts → accessory trunk → **jugular foramen** → crosses **lateral to IJV** → **SCM** → **posterior triangle** → trapezius · also ventral rami **C2–C4** (OB)

**Vulnerability** — **superficial course in posterior triangle**

### Dorsal scapular nerve – rhomboid & levator

**Medial scapular muscles** — innervated by **dorsal scapular nerve** (TO)\
✗ Wrong options: median · ulnar · musculocutaneous · superior/inferior subscapular · thoracodorsal

**Dorsal scapular nerve (TO)** — **anterior ramus of C5** → **levator scapulae + rhomboids** · OB: **C4 + C5 (mostly C5)**; less commonly causes winging

**Medial-border origins (TO)** — posterior surface: **levator scapulae, rhomboid major + minor** (deep extrinsic) · anterior surface: **teres major** (TO) · **teres minor = lateral border** (TO)

**Attachments (TO)** — levator → **transverse processes of upper cervical** · rhomboids → **spinous processes of upper thoracic**

**Fossa muscles (TO)** — supraspinatus, infraspinatus, subscapularis from their fossae

| Nerve (TO, OB) | Origin | Muscles | Winging? |
|---|---|---|---|
| **Dorsal scapular** | **C5 anterior ramus** | **Levator, rhomboids** | Less common |
| **Suprascapular** | **Superior trunk** (C5–6) | Supraspinatus, infraspinatus | No |
| **Upper (superior) + lower (inferior) subscapular** | **Posterior cord** (C5–6) | Subscapularis, **teres major** | No |
| **Thoracodorsal** | **Posterior cord** (C6–8) | **Latissimus dorsi** | No |
| **Axillary** | **Posterior cord** | Deltoid, teres minor | No |
| Long thoracic | C5–7 | Serratus | **Medial** |
| Spinal accessory | CN XI | Trapezius | **Lateral** |

## 2 Mechanism

### Medial winging – causes

| Cause | Detail |
|---|---|
| **Traction (>50%)** | **Repetitive stretch = most common** (gradual) — head tilted away during overhead activity, **throwing, swimmers, weightlifters, volleyball**, prolonged abduction · acute high-energy (motorcycle) |
| **Compression – acute** | Blunt chest/head/neck trauma (contact sports, **MMA blows**), sudden shoulder depression (fall) |
| **Compression – chronic** | **Scalenes** · **subcoracoid** (coracoid–1st/2nd rib; carrying loads) · inflamed bursae · anteroinferior scapular border |
| **Iatrogenic (10%)** | **Radical mastectomy / axillary node dissection**, thoracic surgery (**flail chest fixation**), **chest tube** |
| Penetrating | Chest wall |
| **Neuralgic amyotrophy (Parsonage-Turner)** | **Isolated LTN palsy in 22%**; no trauma, antecedent immune/inflammatory insult |
| **Mechanical** | **Serratus avulsion** · displaced **inferior pole scapula fracture** |
| Muscle inhibition | Underlying GH pathology (cuff, labrum — Kibler dyskinesia), fatigue from repetitive tensile use |

**Most common cause conflict** — **repetitive traction** (Orthobullets, OB) · **Parsonage-Turner = most often associated** (OB6211) · Parsonage-Turner **"very rarely"** (OB7315) — read the options; nerve = **long thoracic** either way

**Vastamäki (OB)** — 92 isolated serratus palsies: **exertion 40%**, trauma 24%, surgery/anaesthesia 11% · **infection → better recovery**, **surgery/anaesthesia → poorer**

### Lateral winging – causes

**Iatrogenic (most common)** — **cervical lymph node biopsy**, **radical neck dissection**, posterior cervical surgery, carotid endarterectomy

**Traumatic** — traction (**sudden lateral neck flexion**, MVA), blunt (**deep tissue massage**), penetrating neck, fall in elderly

## 3 Presentation

### Medial winging – long thoracic nerve/serratus anterior

**Symptoms** — **vague, nonspecific shoulder girdle pain + fatigue** (base of neck, scapula, deltoid) · spasms · weak **lifting away from body/overhead** · discomfort sitting against chair · subjective instability (no stable platform) · ± traction plexus symptoms

**Deformity** — **inferomedial scapula elevates, protrudes posteriorly + medially**; scapula superior + medial with **inferior pole rotated medially** · **worse with forward flexion / wall push-up**

**Mechanism of deformity** — **compensatory overpull of rhomboids (major + minor) + levator scapulae** (✓ OB) · unopposed **trapezius** pulls medially (antagonist)

**Exam** — abduction often **≤90°** · weak **forward flexion + abduction** · wasting of anterior scalene triangle (SCM atrophy)

**Scapular compression test** — examiner pushes scapula anteriorly + stabilises chest during flexion → **positive = ↑ motion** with support

**Scapular assistance test (OB)** — upward pressure on **inferomedial angle** during elevation → **↓ pain + ↑ arc** = positive

**✗ Exam distractors** — ER lag/hornblower (teres minor) · **belly press** (subscapularis) · **apprehension** (anterior instability) · **Wright's** (TOS)

### Lateral winging – spinal accessory nerve/trapezius & Eden-Lange transfer

**Symptoms** — **similar to medial** + **impingement** (CA arch translates inferiorly as scapula depresses)

**Deformity** — **superomedial scapula drops + protrudes posterior and lateral**; **inferior angle rotates laterally** · **worse with abduction + resisted ER**

**Exam** — **drooping/depressed shoulder girdle** · **trapezius atrophy** (flattened superior trapezius) · weak flexion + abduction · **manual scapular stabilisation ↓ pain**

## 4 Diagnosis & Classification

### Key radiology findings

**EMG medial** — LTN palsy vs **mechanical** (serratus avulsion); **serial every 3 mo** to follow recovery

**EMG lateral** — isolated CN XI vs wider neurological injury; **repeat every 3–6 mo**

**EMG → which nerve** — medial winging + abnormal EMG = **long thoracic (C5–7)**; trapezius denervation = **spinal accessory**

## 5 Management

```
Medial winging (serratus / LTN)
├─ Serratus avulsion / inferior pole fracture → early repair
├─ Neurapraxia → PT, observe ≥6 mo (ideally 18–24 mo)
│      └─ no recovery + EMG compression → supraclavicular neurolysis
└─ Fails 1–2 y, better with manual stabilisation → split pec major transfer
       └─ failed transfer / neuromuscular → scapulothoracic fusion
```

```
Lateral winging (trapezius / CN XI)
├─ Elderly, sedentary, no identifiable injury → nonop
├─ Identifiable injury, early (<20 mo) → explore, neurolysis, repair
└─ Late (>20 mo) / permanent → Eden-Lange transfer
       └─ salvage → scapulothoracic fusion
```

### Nonoperative – medial

**Regimen** — observation, PT (**serratus anterior strengthening**, stretching), avoid heavy lifting · modified thoracolumbar brace (**poor compliance, little benefit**)

**Duration** — **≥6 months**, ideally **18 mo–2 y**

**Recovery** — majority resolve **by 2 y** (Orthobullets; **within 24 mo**, Martin, OB) · **within 1 y** (OB) · **~25% need surgery** (OB)

### Operative criteria

| Procedure | Indication |
|---|---|
| **Early serratus repair** | **Mechanical avulsion** / inferior pole fracture + symptomatic winging |
| **LTN neurolysis** | Failed nonop **≥6 mo** + EMG **compression** (distal latency, denervation) |
| **Split pec major transfer** | Failed nonop **1–2 y** + **relief with manual scapular stabilisation** |
| Surgery (OB) | Symptomatic serratus winging **>1 y + EMG denervation** → fusion, fascial sling, muscle transfer |
| **Eden-Lange** | CN XI injury **diagnosed late (>20 mo)** |
| **CN XI exploration/repair** | **Identifiable injury diagnosed early** (<20 mo) |
| **Scapulothoracic fusion** | **Diffuse neuromuscular disorders**, **failed muscle transfer**; not first choice; goal **pain relief** |

### LTN neurolysis

**Technique** — **supraclavicular decompression** where nerve traverses scalenes

**Outcome** — **98%** pain relief + winging resolution after failed nonop · **better strength (flexion, abduction) than muscle transfer**

### Split pectoralis major transfer

**Technique** — **sternal head** of pec major → **inferior (inferomedial) border/pole of scapula**; direct (± bone block) or with **hamstring/allograft** extension · **most effective** for medial winging · dynamic stabiliser

**Predictor of success** — **symptom relief with preop manual scapular stabilisation**

**Outcome** — persistent **abduction weakness** common

**Complications** — transfer failure at scapula · **breast asymmetry** · infection · adhesive capsulitis

![Split pectoralis major transfer](../../Orthobullets/attachments/ob3062-pec-transfer.jpg)

### Nerve transfer – medial

**Donors** — **lateral branch of thoracodorsal nerve → LTN** · **medial pectoral + sural graft → LTN**; preserves muscle biomechanics · nerve/muscle transfers **mixed results** (OB)

### Lateral – nonoperative

**Role** — **controversial** (most injuries = iatrogenic direct → surgery) · nonop for **elderly, sedentary, no identifiable injury** · **less effective than for serratus palsy**

**Poor prognosis with nonop** — **can't raise arm above shoulder** at presentation · **dominant arm**

**Delay** — marked delay in recognition common

### Eden-Lange transfer

**Classic** — **levator scapulae → lateral scapular spine** + **rhomboid minor + major → infraspinatus fossa** (lateralises: medial border → lateral)

**Triple tendon transfer** — all three to **scapular spine** (Rm medial → RM → LS lateral) to reconstruct trapezius

**Results** — **reliably restores ROM + function** · **better than scapulothoracic fusion** (OB)

(✗ Wrong options: **Distractors** — split pec major (= serratus/medial)) · long head triceps / infraspinatus transfers (rarely used) · latissimus transfer · levator only

![Eden-Lange: levator, rhomboid minor and major transferred laterally](../../Orthobullets/attachments/ob3062-eden-lange.jpg)

### Scapulothoracic fusion

**Technique** — anterior scapula to posterior ribs (wire cables, plates/screws)

**Outcome** — **~20° gain in abduction** · **82% satisfied at 5 y**

**Complications** — nonunion · **pleural effusion** · adhesive capsulitis · symptomatic hardware

## X vs Y

| | **Medial winging** | **Lateral winging** |
|---|---|---|
| Scapula | Inferior pole **medial**, scapula elevated | **Drooping**, inferior angle **lateral**, depressed |
| Worse with | **Forward flexion / wall push-up** | **Abduction + resisted ER** |
| Atrophy | — | **Trapezius** |
| Nonop | **Effective** (most recover) | **Less effective** |
| Muscle transfer | **Split pec major (sternal head)** | **Eden-Lange (levator + rhomboids)** |
| Nerve transfer | Thoracodorsal lateral branch → LTN | |

| Nerve injury | Result |
|---|---|
| Long thoracic | **Medial winging** |
| Spinal accessory | **Lateral winging** |
| Thoracodorsal | Latissimus weakness, no winging |
| Suprascapular | Supra/infraspinatus wasting, no winging |
| Upper/lower subscapular | Subscapularis/teres major, no winging |
| Axillary | Deltoid/teres minor, no winging |
| C8–T1 | No winging |
