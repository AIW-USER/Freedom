# Shoulder Imaging

*Shoulder & Elbow · 48 / 60*

## 1 Basics

### MRI physics – field strength

**Field strength** — stronger magnet → ↑ intrinsic **signal-to-noise ratio**

**3 T vs 1.5 T** — **3 T = 9× proton energy** of 1.5 T → **1.5 T ≈ 11% of 3 T**\
✗ Wrong options: 33% · 66%

| Sequence | TR / TE | Bright | Dark | Shoulder use |
|---|---|---|---|---|
| **T1** | **Short TR, short TE** | **Fat** | Fluid, bone, ligament, marrow, fibrocartilage | **MR arthrogram**; **Hill-Sachs** |
| **T2** | **Long TR, long TE** | **Fluid** (inflammation), marrow | Bone, ligament, muscle, fibrocartilage | **Cuff pathology** — full-thickness tear |
| **STIR** | Fat saturation (suppression) | Fluid + oedema ↑ | Fat ↓ | **Oedema vs fatty infiltration** of cuff muscles |

### CT vs MRI

| | **CT** | **MRI** |
|---|---|---|
| Best for | **Cortical + trabecular bone**, **bony defects** | **Soft tissue**, **bone contusion / trabecular microfracture** |
| Cost | **↑ Radiation** | — |
| Artefact | **No magnification artefact** (unlike X-ray) | — |

## 4 Diagnosis & Classification

### Radiographic views (Zanca, West Point)

| Complete trauma series | Focus |
|---|---|
| Shoulder AP | GH joint space, DJD |
| **Grashey (true AP)** | GH joint space, DJD, **proximal migration of humerus** |
| **AP in ER / AP in IR** | **Hill-Sachs** |
| **Axillary lateral** | **Anterior + posterior dislocation**, acromion |
| **Velpeau** | Axillary modification **if can't abduct arm** |
| **Scapular Y lateral** | **Anterior + posterior dislocation** |

| Additional view | Focus |
|---|---|
| **Supraspinatus outlet** | **Acromion morphology** — type I flat, II curved, **III hooked** (→ impingement + cuff pathology) |
| **Zanca** | **AC joint** — AC disease, **distal clavicle osteolysis**, distally projecting osteophytes |
| **Stryker notch** | **Hill-Sachs** |
| **West Point axillary** | **Anteroinferior glenoid — bony Bankart**, proximal humerus fracture |
| **Garth** | Anteroinferior glenoid — **bony Bankart** |
| **Hobbs** | **Anterior + posterior SC dislocation** |
| **Serendipity** | **Anterior + posterior SC dislocation** |

**Bony Bankart (TO)** — **West Point axillary** = popular view for **glenoid bone defect**\

### Key radiology findings – CT

| CT plane | Best for |
|---|---|
| **Axial** | **Reverse Hill-Sachs** |
| Coronal | **Fractures** |
| **Sagittal** | **Anteroinferior glenoid insufficiency** (bone loss) |
| **3D reconstruction** | **Glenoid version** for TSA |

### Key radiology findings – MRI & MR arthrogram

**ABER position** — sequence beyond coronal/sagittal/axial · hand **behind head** · **tensions anteroinferior GHL + labrum, relaxes capsule** → **Bankart**, **partial/full-thickness cuff tears**, **internal impingement**\
✗ Wrong options: true 90–90

**MR arthrogram** — percutaneous **dilute gadolinium** into joint → **labral + ligament** pathology: **Bankart**, **SLAP**, **GLAD**, **ALPSA**, **HAGL**

## X vs Y

| Lesion | Best X-ray view | Best cross-sectional |
|---|---|---|
| **Hill-Sachs** | **AP in IR / ER**, **Stryker notch** | T1 MRI |
| **Reverse Hill-Sachs** | — | **Axial CT** |
| **Bony Bankart** | **West Point**, **Garth** | **Sagittal CT** (glenoid insufficiency) |
| **Soft-tissue Bankart / SLAP / HAGL** | — | **MR arthrogram**, ABER |
| **AC joint / DCO** | **Zanca** | — |
| **SC dislocation** | **Serendipity**, **Hobbs** | — |
| Cuff tear | Grashey (proximal migration) | **T2 MRI**; STIR (fatty vs oedema) |

## How it's asked

**"1.5 T proton energy as % of 3.0 T?"** → **11%** (3 T = 9×)

**"Best view for AC joint?"** → **Zanca view** (TO)\
✗ Wrong options: serendipity · Greenspan · Brewerton

**"Best view for bony Bankart lesion?"** → **West Point axillary view** (TO)\
✗ Wrong options: IR + Stryker notch · serendipity · Greenspan

**"Hill-Sachs best seen on?"** → **IR view / Stryker notch** (TO)

**"SC joint dislocation view?"** → **serendipity** (or Hobbs)

**"Can't abduct arm for axillary view?"** → **Velpeau**

**"Glenoid version before TSA?"** → **3D CT**

**"Reverse Hill-Sachs?"** → **axial CT**

**"MRI position for internal impingement / anteroinferior labrum?"** → **ABER**

**"Distinguish cuff muscle oedema vs fatty infiltration?"** → **STIR**
