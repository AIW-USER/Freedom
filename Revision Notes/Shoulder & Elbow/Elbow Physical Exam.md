# Elbow Physical Exam

*Shoulder & Elbow · 15 / 60*

## 1 Basics

### Exam sequence & normal values

**Sequence** — inspection → palpation → ROM → stability → motor → sensory → vascular → provocative tests

| Parameter | Normal | Functional |
|---|---|---|
| **Carrying angle** (full extension) | **~11° ♂ · ~13° ♀** (exam note) · ♂ 5–10° / ♀ 10–15° (anatomy note); ↑ in throwers | — |
| **Flexion–extension** | 0–140° | **30–130°** |
| **Pronation** | 75° | **50°** |
| **Supination** | 85° | **50°** |

**Pronation–supination** — test with shoulders fully adducted + elbow at 90°; compare both sides, active + passive

**End point** — **soft = effusion / capsular tightness** · **firm = mechanical block** (loose body, fracture, osteophyte)

**Throwers** — loss of full extension even **without pathology**

### Motor – muscle & root

| Movement | Muscle | Root |
|---|---|---|
| Elbow flexion, **full supination** | Brachialis + biceps | C5–C6 |
| Elbow flexion, **neutral** (thumb to ceiling) | **Brachioradialis** | C6 |
| Elbow extension | Triceps | C7 |
| Pronation | Flexor-pronator mass | C7–C8 |
| Supination | Biceps (primarily) | C6 |
| Wrist extension | ECRL, ECRB, ECU | C6–C8 |
| Wrist flexion | FCR, FCU | C6–C8 |
| Finger/thumb extension | EDC, EPL | C7–C8 |
| Finger/thumb flexion | FDS, FDP, FPL | C7–C8 |
| Intrinsics | Lumbricals, interossei | T1 |

**Brachial artery** — anterior elbow, **medial to biceps tendon**; also check radial + ulnar pulses

## 3 Presentation

### Inspection

**Effusion** — elbow held at **70–80° flexion** (= max capsular distension) · fullness of **soft spot** (radial head + lateral epicondyle + olecranon)

**Cubital tunnel** — **1st dorsal interosseous / 1st web atrophy** · ring/small clawing (more with **Guyon's** — unopposed FDP)

**Distal biceps rupture** — **medial ecchymosis** + swelling · proximal retraction of belly = **reverse Popeye sign**

### Palpation – point of maximal tenderness

| Condition | Tender point |
|---|---|
| **MCL injury** | **MCL origin, just inferior to medial epicondyle**; palpate at **50–70° flexion** (flexor-pronator mass moves anterior) |
| **Valgus extension overload** | **Posteromedial olecranon** |
| **Lateral epicondylitis** | ECRB insertion, **few mm distal to tip of lateral epicondyle** |
| **Radial tunnel syndrome** | **3–5 cm distal to lateral epicondyle** (more distal than tennis elbow) |
| **Medial epicondylitis** | **5–10 mm distal + anterior** to medial epicondyle; swelling/warmth if inflamed |

**Radial head** — best palpated while rotating forearm pronation → supination

**Ulnar nerve subluxation** — over medial epicondyle, extension → flexion · hypermobility in **33% of adults**\
✗ Wrong options: necessarily CuTS

**Snapping medial triceps** — snaps over medial epicondyle on **resisted extension from full flexion** (differentiate from ulnar nerve)

## 4 Diagnosis & Classification

### Stability – MCL (valgus)

**Valgus stress test** — flex **20–30°** (**unlocks olecranon**) + **externally rotate humerus** + valgus → tests **MCL**

| Test | Technique | Positive | Accuracy |
|---|---|---|---|
| **Milking maneuver** | **Pull patient's thumb**, forearm **supinated**, elbow **90°**; supine or seated/standing | Apprehension, instability or **pain at MCL origin** | Sens **87.5%**, **NPV 100%** |
| **Moving valgus stress** | Same position + valgus while ranging full arc; shoulder **fully ER** | Pain at MCL origin **between 70° and 120°** (early acceleration 70° · late cocking 120°) | **Sens 100%, spec 75%** |

![Milking maneuver](../../Orthobullets/attachments/ob322131-milking-maneuver.jpg)

**Valgus extension overload** — **pain with forced elbow extension** · valgus in terminal extension reproduces pain · **varus loading ↓ pain**

### Stability – LCL / posterolateral rotatory instability

| Test | Technique | Positive / accuracy |
|---|---|---|
| **Lateral pivot-shift** | Supine, arm overhead, shoulder fully ER, **forearm supinated + valgus**, extension → flexion | Pain/apprehension or **clunk at 40°** (radiocapitellar dislocated); 2nd clunk with ↑ flexion (triceps reduces radial head); **more reliable under anaesthesia** |
| **PLR drawer** | Supine, elbow **40°**, forearm supinated, AP force over lateral proximal forearm | Apprehension or **skin dimple** (radial head posterior subluxation) |
| **Chair push-up** | Push up from chair, forearm **supinated** | Unable / apprehension; sens **87.5%** (**100% with prone push-up**) |
| **Prone push-up** | Push-up, forearm supinated | Unable; sens 87.5% (100% with chair test) |
| **Table-top relocation** | Press-up on table edge, elbow lateral, forearm supinated; 3 parts | Pain in parts 1 + 3, **relief with thumb on radial head (part 2)** = PLRI |

**Table-top (wrong option)** — pain in **all 3 parts** = intra-articular **radial head fracture**

### Provocative tests – nerve

| Condition | Test / sign | Finding |
|---|---|---|
| Cubital tunnel | **Froment** | Thumb **IP flexion by FPL (AIN)** on key pinch → compensates adductor pollicis (ulnar) |
| Cubital tunnel | **Jeanne** | Thumb **MCP hyperextension** + adduction by **EPL (radial)** on key pinch |
| Cubital tunnel | **Wartenberg** | Persistent **small finger abduction** + extension; weak intrinsics + **unopposed EDM** |
| Cubital tunnel | **Masse** | Flat palmar arch, lost ulnar hand elevation (weak **ODQ**, ↓ small MCP flexion) |
| Cubital tunnel | **Tinel** | Over cubital tunnel, **elbow extended** |
| Cubital tunnel | **Elbow flexion test** | Symptoms with flexion **>60 s** |
| Radial tunnel | **Resisted long finger extension** · **resisted supination** (elbow + wrist extended) · **passive pronation + wrist flexion** | Pain at radial tunnel (weakness from pain); supinator stretch → **250 mmHg** (normal 50) |
| PIN syndrome | Resisted supination ↑ pain · **normal tenodesis** (vs extensor tendon rupture) | Weak finger MCP extension; **wrist extends in radial deviation** (ECRL intact, ECU absent) |
| AIN syndrome | **OK sign** (FDP index + FPL) | **Can't make OK**; weak **PQ** = weak resisted pronation with **elbow maximally flexed** |
| AIN vs FPL rupture (RA) | **Tenodesis** | Intact tendons: passive wrist extension flexes thumb IP + index DIP |

**Cubital tunnel motor** — **weak pinch** (up to **70%** lost; adductor pollicis)

### Pronator syndrome – site-specific tests

**Pronator syndrome** — **Tinel proximal anterior forearm**, not at wrist · wrist-flexion provocation as in CTS

| Resisted test | Compression site |
|---|---|
| **Elbow flexion + forearm supination** | **Bicipital aponeurosis (lacertus)** |
| **Forearm pronation, elbow extended** | **Two heads of pronator teres** |
| **FDS contraction to middle finger** | **FDS fibrous arch** |

### Sensory

**Cutaneous nerves** — medial, lateral, posterior antebrachial cutaneous · ulnar · median · superficial radial

**Cubital tunnel** — ↓ 2PD **small + ulnar ring** · **↓ dorsal ulnar hand** = proximal to wrist (dorsal branch arises **5 cm proximal** to wrist)

**Pronator syndrome** — ↓ sensation in **palmar cutaneous branch** territory (arises **4–5 cm proximal** to carpal tunnel) · not in CTS

### Provocative tests – tendon

| Condition | Test | Key fact |
|---|---|---|
| **Triceps rupture** | **Modified Thompson squeeze** | Prone, forearm hanging; squeeze triceps → **no elbow extension** = complete tear (triceps + lateral expansion) |
| **Distal biceps** | **Hook test** | Elbow 90°, **full supination**, hook **lateral** edge; intact = finger **1 cm beneath tendon**; **sens + spec 100%** |
| Distal biceps | **Ruland biceps squeeze** | Elbow **60–80°**, slight pronation; squeeze belly → **no supination** = positive; **sens 96%** |
| Distal biceps | **Biceps crease interval (BCI)** | Crease → cusp distance **>6 cm or 1.2× contralateral**; sens 92%, spec 100% |
| Distal biceps | **Passive forearm pronation** | Belly moves proximal on supination, distal on pronation (intact) |
| Distal biceps | Strength | **Loss of supination > flexion** |

**Hook test false positives** — **partial tear** · **intact lacertus fibrosus** · **underlying brachialis**

**Biceps triad** — hook + passive pronation + BCI in sequence → **100% sens + 100% spec** for complete rupture

![Hook test](../../Orthobullets/attachments/ob322131-hook-test.jpg)

![Biceps crease interval](../../Orthobullets/attachments/ob322131-biceps-crease-test.jpg)

**Lateral epicondylitis** — pain on resisted wrist extension (elbow extended, pronated) · **Maudsley = resisted middle finger extension** (ECRB) · maximal wrist flexion · passive wrist flexion in pronation

**Chair test** — elbow extended, forearm pronated, shoulder flexed, lift chair → lateral elbow pain = **lateral epicondylitis**

**Medial epicondylitis** — pain on **resisted pronation + wrist flexion** · **no instability/apprehension** on valgus stress or milking (vs MCL)

## 5 Management

### Olecranon bursitis – aspiration & compression

**Cause** — **repeated minor trauma** (leaning on elbow, desk work) > single injury → inflamed lining secretes fluid

![Olecranon bursitis](../../MCQ/attachments/q217371-a-bursa.jpg)

```
Aseptic olecranon bursitis
├─ First line → nonoperative (more effective + safer than surgery)
└─ Aspiration chosen → posterolateral needle, aspirate alone
       └─ then → compressive wrap (bursal walls adhere)
```

**Aspiration ✓** — **alone** (no steroid) + **compressive dressing** → walls adhere, prevents reaccumulation

**Approach** — **posterolateral**\
✗ Wrong options: posteromedial → ulnar nerve

**Avoid steroid** — **↑ septic bursitis** (local immunosuppression); no outcome benefit · **recurrence occurs with or without steroid**\
✗ Wrong options: "steroid ↑ recurrence"

**LUCL rupture** — from repeated steroid injections for **lateral epicondylitis**, not bursa aspiration

| Finding | Septic | Aseptic |
|---|---|---|
| Tenderness | 88% | 36% |
| Erythema/cellulitis | 83% | 27% |
| Warmth | 84% | 56% |
| Trauma / skin lesion | 50% | 25% |
| Fever | 38% | **0%** |

**Septic vs aseptic** — clinical + lab data **overlap** → hard to distinguish

## X vs Y

| | **Lateral epicondylitis** | **Radial tunnel syndrome** |
|---|---|---|
| Tender point | **Few mm distal** to lateral epicondyle (ECRB) | **3–5 cm distal** |
| Provocation | Maudsley, chair test, resisted wrist extension | Resisted long finger extension, resisted supination |

| | **MCL injury** | **Medial epicondylitis** |
|---|---|---|
| Tender point | **Just inferior** to medial epicondyle | **5–10 mm distal + anterior** |
| Milking / valgus stress | **Pain, apprehension, instability** | **No** instability or apprehension |
| Provocation | Moving valgus stress 70–120° | Resisted pronation + wrist flexion |

| | **Pronator syndrome** | **Carpal tunnel syndrome** |
|---|---|---|
| Tinel | **Proximal forearm** | Wrist |
| Palmar cutaneous branch sensation | **↓** | **Spared** |

| | **Cubital tunnel** | **Guyon's canal** |
|---|---|---|
| Clawing | Less | **More** (unopposed FDP) |
| Dorsal ulnar hand | **↓** | Spared |

## How it's asked

**"Olecranon bursa aspiration — true statement?"** → **compressive wrap after aspiration alone promotes bursal wall adherence**\
✗ Wrong options: steroid ↑ recurrence · posteromedial · similar infection risk with steroid · LUCL rupture

**"Steroid injected into olecranon bursa — risk?"** → **↑ septic bursitis**

**"Needle approach for olecranon bursa?"** → **posterolateral** (avoid ulnar nerve)

**"Position to palpate MCL origin?"** → **50–70° flexion**, just inferior to medial epicondyle

**"Elbow position to test valgus stability?"** → **20–30° flexion** (unlocks olecranon), humerus ER

**"Moving valgus stress test positive arc?"** → **70–120°**

**"Clunk at 40° on pivot-shift?"** → **dislocated radiocapitellar joint** (PLRI)

**"Table-top test, pain in all 3 parts?"** → **radial head fracture**\
✗ Wrong options: PLRI

**"Hook test false positive?"** → **partial tear / intact lacertus / brachialis**

**"Tenderness 3–5 cm distal to lateral epicondyle?"** → **radial tunnel syndrome**

**"Elbow held at 70–80° flexion?"** → **effusion** (max capsular volume)

**"Wrist extends into radial deviation?"** → **PIN palsy** (ECRL intact, ECU lost)

**"Weak resisted pronation with elbow fully flexed?"** → **pronator quadratus (AIN)**

**"Resisted pronation, elbow extended reproduces median symptoms?"** → **pronator teres heads**

**"Numbness thenar eminence + forearm Tinel?"** → **pronator syndrome**\
✗ Wrong options: CTS (palmar cutaneous spared)

**"Firm end point to flexion?"** → **mechanical block**\
✗ Wrong options: effusion = soft
