# Basic Arthroscopic Instrumentation

*Shoulder & Elbow · TO notes*

## 1 Basics

### History

| Milestone (TO) | Name |
|---|---|
| Father of sports medicine | **Galen** |
| **First successful arthroscopy (1918)** | **Kenji Takagi** — TB knee, using a **cystoscope** |
| Therapeutic arthroscopy, **triangulation** | **Masaki Watanabe** |
| Brought to the West (1965 Tokyo Olympics) | **Robert Jackson** (Canada) |
| International Arthroscopy Association (**1974**) | Watanabe president · Jackson founding member |
| Arthroscopic camera | **McGinty and Johnson** |

### Operating room set-up

**Tower (TO)** — monitor · camera control unit · light source · shaver control · pump

**Monitor (TO)** — **≥20-inch** (usually 26-inch HD), at surgeon's eye level

**Distension pressure (TO)** — **knee 30 mmHg** · **shoulder 40–50 mmHg** · 3–5 L bags hung high · **raising bag 1 ft → ~20 mmHg ↑**

| Fluid (TO) | Pro | Con |
|---|---|---|
| **Normal saline** | Easily available; **routine use** | **Conductive** → not ideal with cautery |
| **1.5% glycine** | **Non-conductive** → **use with cautery**; less tissue toxicity | Slightly less clear view |
| Ringer lactate | Common in Western practice | Conductive |
| Distilled water | Occasional | **Hypotonic → tissue oedema** |

## 4 Diagnosis & Classification

### Arthroscope (telescope)

**Parts (TO)** — eyepiece (to camera coupler) · light post (fibre-optic entry) · barrel · **objective lens system at distal tip** (thin lenses + spacers) → impact/pressure misaligns lenses → **blurred image**

| Joint (TO) | Diameter | Length |
|---|---|---|
| **Knee / shoulder** | **4 mm** | 13.5 cm |
| **Hip** | 4 mm | **18 cm** |
| **Elbow / wrist / ankle** | **2.7 mm** | 6.7 cm |
| Small joints (hand / foot) | **1.9 mm** | 6.7 cm |

| Movement (TO) | Description | Note |
|---|---|---|
| Pistoning | In–out | Depth |
| Angulation | Up / down / side | Orientation |
| **Rotation** | Twist along axis | **Most important** — changes field of view |

| Angle of inclination (TO) | Use |
|---|---|
| **0°** | Straight view (spine, endoscopy) |
| **30°** | **Standard: knee + shoulder** |
| **70°** | **Hip / periphery**; wider peripheral view but **central blind spot** |

**Field of view (TO)** — **apparent FOV depends on diameter** · **actual FOV = diameter + angle of inclination**

### Sheath, light source & camera

**Sheath (TO)** — scope through **sheath (cannula) + obturator (trocar)** · sheath larger than scope to allow saline flow (stated ~2 mm) · 4 mm scope → **6 mm** sheath · 2.7 → 2.9 mm · 1.9 → 2.2 mm

**Sheath types (TO)** — **universal** = more lens exposed → ↑ damage · **hooded** = protective, **preferred**

**Light source (TO)** — **300–350 W** · tungsten < halogen < xenon < **LED (best)** → **cooler, prevents chondral damage**

**Fibre-optic cable (TO)** — **300 cm**, **4.8 mm** · core (fibres) → cladding → coating

**Camera (TO)** — now **3-chip HD**

## 5 Management

### Hand instruments

| Instrument (TO) | Use / fact |
|---|---|
| **Probe** | "**Extension of surgeon's finger**" — palpate, pull, **measure** (tip **4 mm**, shaft 12 cm) |
| **Punch (basket forceps)** | Cuts tissue: straight / side-cutting / up-biting |
| Grasper | Tissue or foreign body |
| Retriever | Pulls sutures |
| **Switching stick (Singer rod)** | Portal exchange; **4 mm** |
| Cannula | Wash (rigid) · **passport (flexible)** → allows jig passage |

| Suture passer (TO) | Example | Mechanism |
|---|---|---|
| **Direct** | Champion (Stryker), Scorpion (Arthrex) | **Needle fires suture**, trap catches it — no assistant |
| **Indirect – retrograde** | **Lasso** | Loop **pulls suture back** through tissue |
| **Indirect – antegrade** | **Bird Beak** | Sharp jaws carry thread through tissue |

**Knot pusher (TO)** — single-hole · double-hole · **end-splitting = best** (max knot + loop security)

### Powered & energy devices

**Shaver / burr (TO)** — diameters **3.5, 4.5, 5.5 mm** · length 120 mm (knee), 180 mm (hip) · **shaver 1,000–3,000 rpm** · **burr 8,000–9,000 rpm** · blades: standard (smooth) vs **aggressive (toothed)** · **full-radius resector = most used**

| Device (TO) | Use | Note |
|---|---|---|
| Cautery | Haemostasis | Conductive in saline |
| **Laser (Nd:YAG)** | Precision | Smooths frayed cartilage (chondroplasty) |
| **Radiofrequency probe** | Coagulation + **thermal shrinkage** | Tightening effect |

### Sutures & anchors

| Suture (TO) | Composition | Feature |
|---|---|---|
| **Ethibond** | Braided **polyester** | Non-absorbable, moderate strength |
| **FiberWire** | **UHMWPE + polyester** | **4–5× strength of Ethibond** |
| OrthoCord | UHMWPE + **PDS core** | Profile ↓ as core degrades |
| FiberTape / TigerTape | Broad flat UHMWPE | ↑ compression, may abrade tissue |

| Anchor material (TO) | Pro | Con |
|---|---|---|
| **Metal** (SS / titanium) | High pull-out, **visible on X-ray** | **Abrades cartilage**, permanent |
| **PEEK** | **Radiolucent, drillable** | Non-degradable, may migrate |
| **Biocomposite** (PLA + β-TCP) | Absorbable, **bone ingrowth** | Slow degradation |
| **All-suture** (JuggerKnot) | Minimal hardware, high pull-out | Technically demanding |

| Anchor technique (TO) | Use |
|---|---|
| **Knotted** | **Medial row** cuff repair |
| **Knotless** | **Lateral row** · **Bankart** |

| Anchor size (TO) | |
|---|---|
| **Glenoid (Bankart)** | **2.8 mm** |
| **Cuff medial row** | **4.5 mm** |
| **Cuff lateral row** | **5.5 mm** |

### Arthroscopic knots

**Non-sliding (TO)** — **square knot + 5 half-hitches** → **best security** but cannot pass through cannula

**Sliding knots (TO)** — advanced down cannula by pulling one limb · back every sliding knot with **3 reverse half-hitches on alternating posts**

| Sliding knot (TO) | Example | Property |
|---|---|---|
| **Non-locking** | **Duncan loop** | Easy; loosens under back pressure |
| Locking – proximal | **Nicky's knot** | Secure, complex |
| Locking – middle | **SMC (Samsung Medical Center)** | **Most popular**, balanced security |

| Term (TO) | Definition |
|---|---|
| **Knot security** | Resistance to **slippage** under tension |
| **Loop security** | Resistance to **tissue back pressure** |
| Knot failure | Displacement **>3 mm** |

### Sterilisation

| Item (TO) | Method |
|---|---|
| **Camera, light cable, scope** | **ETO or plasma** — **never autoclave** (lens + electronics) |
| Mechanical instruments, handpiece | **Autoclave** or **Cidex** (glutaraldehyde, **30 min**; TO states 4%) · Cidex + Steris common |
| Last resort | **Formalin chamber 24 h** |

## 6 Complications

**Most common complication of arthroscopy (TO)** — **haemarthrosis** (esp. after **synovectomy** or **lateral release**)

**Lens damage (TO)** — universal sheath, impact on objective lens → blurred image

**Chondral thermal damage (TO)** — hot light sources → **LED** preferred

## X vs Y

| | **Saline** | **Glycine 1.5%** |
|---|---|---|
| Conductive | **Yes** | **No** |
| Use | Routine | **With electrocautery** |

| | **Direct passer** | **Indirect passer** |
|---|---|---|
| Mechanism | **Needle fires suture** | **Instrument passes through tissue** (lasso retrograde, bird beak antegrade) |

| | **Knot security** | **Loop security** |
|---|---|---|
| Resists | **Slippage** of knot | **Tissue back pressure** (loop enlarging) |
