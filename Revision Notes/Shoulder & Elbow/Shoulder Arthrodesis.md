# Shoulder Arthrodesis

*Shoulder & Elbow · 44 / 60*

## 1 Basics

### Goal

**Aim** — **stable base** for the upper limb → optimise **hand + elbow** function

**Ideal patient** — **flail shoulder** (deltoid + cuff paralysis) with **functional hand, wrist + elbow**; young, esp. **labourer**

### Anatomy

**GH fusion surface** — small → decorticate **GH articular surfaces + humeral head–acromion undersurface** to ↑ fusion area

**Fixation strength** — only **glenoid fossa + base of coracoid** strong enough for screws

## 3 Presentation

**Symptoms** — **specific to underlying condition**; symptomatic GH dysfunction

## 4 Diagnosis & Classification

### Key radiology findings

| Test | Purpose |
|---|---|
| **X-ray AP, lateral, axillary** | Bone stock for fusion, deformity |
| **CT** | **Glenoid bone loss** (esp. failed arthroplasty) |
| **EMG** | When **neurological status of scapular muscles** is ill-defined |

## 5 Management

### Indications – deltoid and rotator cuff paralysis

| Indication | Note |
|---|---|
| **Paralytic disorders** | **Deltoid + cuff paralysis** (post-traumatic), **brachial plexus palsy**, paralysis in infancy |
| Irreparable deltoid + cuff deficiency with arthropathy | |
| **Failed TSA / failed revision arthroplasty** | Salvage |
| **Tumour resection** | Bone deficiency |
| **Chronic infection** | Painful ankylosis |
| **Recurrent instability** | Failed previous repairs (severe, refractory) |

**Rühmann (OB)** — 43 cases: paralysis **74%**, OA/humeral head necrosis 35%, infection 16%, instability

### Contraindications

**List** — **ipsilateral elbow arthrodesis** · **contralateral shoulder arthrodesis** · **no functional scapulothoracic motion** · **trapezius, levator scapulae or serratus anterior paralysis** · **Charcot** in acute inflammatory stage (**Eichenholtz 0–2**) · **elderly** · **progressive neurological disease**

### Operative criteria – who benefits vs alternatives

| Patient | Best option |
|---|---|
| **Flail shoulder (deltoid + cuff paralysis), hand works** | **Arthrodesis** ✓ |
| No cuff function | No **TSA** (contraindicated) |
| No deltoid function | No **reverse TSA** (contraindicated) |
| Chronic lateral winging | Eden-Lange (levator + rhomboids) |
| Irreparable cuff tear, overhead motion | Latissimus dorsi transfer |
| Young AVN | Hemiarthroplasty |
| Recurrent MDI after arthroscopy | Therapy, revision arthroscopic/open stabilisation |
| Infected TSA removed (70-y) | Treat infection → **2nd-stage TSA / HA / reverse** |
| **Cleidocranial dysostosis** | **Scapulothoracic** (✗ Wrong options: glenohumeral) arthrodesis |

### Fusion position

**Goal** — **hand to mouth** (feeding) + **groin** (hygiene)

| Source | Abduction | Forward flexion | Internal rotation |
|---|---|---|---|
| **Orthobullets "30-30-30"** | **20–30°** | **20–30°** | **20–30°** |
| OB typical | **~40°** | **~35°** | **~20°** |
| Rühmann range (OB) | 20–60° | 20–40° (anteversion) | 0–50°; **no ER** |
| Orthobullets GH anatomy note | 15–20° | 20–25° | 40–50° |

**Positions conflict** — 30-30-30 (Orthobullets) · 40-35-20 (OB) — read the options

### Technique

**Approach** — **S-shaped incision**: scapular spine → over acromion → anterolateral arm

**Steps** — resect cuff from proximal humerus · **tenodese biceps** · decorticate glenoid, humeral head + acromial undersurface · position 30-30-30

**Fixation** — **10-hole 4.5 mm pelvic reconstruction plate** along **scapular spine → acromion → humeral shaft** · **compression screws across GH into glenoid fossa** · screw into **base of coracoid**

![Plate fixation of shoulder arthrodesis](../../Orthobullets/attachments/ob3128-image.jpg)

### Postoperative care

**0–6 wk** — **thermoplastic orthosis** from day 1

**6 wk** — **sling** if no radiographic loosening

**3 mo** — **mobilisation + thoracoscapular strengthening** if no loosening

**Recovery** — **6–12 months**; marked ↑ pain + function in selected patients

## 6 Complications

**List** — **infection** · **nonunion** · **malposition** · **prominent hardware** (pain) · **humeral shaft / periarticular fracture**

## How it's asked

**"45-y, deltoid + cuff paralysis 5 y after motorcycle injury, hand/wrist work?"** → **shoulder arthrodesis**\
✗ Wrong options: Eden-Lange · TSA · reverse TSA · latissimus transfer

**"Who benefits most from GH arthrodesis?"** → **30-y labourer with deltoid + cuff paralysis**\
✗ Wrong options: AVN · MDI · infected TSA removed · cleidocranial dysostosis

**"Position of shoulder fusion?"** → **30° abduction, 30° flexion, 30° IR** — hand to mouth (OB: ~40/35/20)
