# Swan Neck Deformity

*Hand · 86 / 103*

## 1 Basics

**Definition** — **PIP hyperextension + DIP flexion** ("double curve") from PIP force imbalance

**Incidence** — up to **50% of RA** patients

### Pathomechanics – triangular ligament & lateral band tenotomy

**Primary lesion** — **lax volar plate** → PIP hyperextension; causes: trauma, generalised laxity, RA (chronic PIP synovitis)

**Secondary lesion** — **PIP extension force > flexion force**

| Cause | Mechanism |
|---|---|
| **Mallet finger** | DIP extension force transferred to PIP |
| **FDS rupture / laceration** | Lost dynamic check-rein → unopposed PIP extension + volar plate failure |
| **Intrinsic contracture** | Lateral bands tethered (transverse retinacular lig.) → extension force goes to PIP, not terminal tendon |
| **MCP volar subluxation** | RA |
| **Cerebral palsy** | Extrinsic extensor overpull ± intrinsic spasticity |

**Cascade (TO)** — PIP hyperextends → **lateral bands sublux dorsally** (above axis) → ↑ extensor lever arm → self-perpetuating; extensor "used up" at PIP → slack at DIP + FDP pull → **DIP flexion**

**Triangular ligament** — dorsal, base of middle phalanx just distal to central slip; **keeps lateral bands dorsal** → **contracture/tightness → swan neck**\
✗ Wrong options: boutonniere: lateral bands volar

**Not swan neck causes** — volar plate **contracture**, sagittal band insufficiency (extensor subluxation at MCP)

## 3 Presentation

**Symptoms** — **snapping and locking** of fingers

**Exam** — resting PIP hyperextension + DIP flexion

**Bunnell-Littler (intrinsic tightness) test (TO)** — PIP flexion **more restricted with MCP extended** than flexed → **intrinsic tightness**\
✗ Wrong options: capsule contracture · volar plate laxity · extrinsic adhesions

## 4 Diagnosis & Classification

### Key radiology findings

**Radiographs** — AP + lateral hand; PIP joint destruction defines Nalebuff IV

### Nalebuff classification (TO)

| Type | Finding | Treatment principle |
|---|---|---|
| **I** | PIP flexible in all positions | Restore check-rein: **FDS tenodesis** (most widely used), dermodesis, **SORL / ORL reconstruction** (Brooks-Graner), volar plate repair, lateral band translocation |
| **II** | PIP flexion limited with **MCP extended** (+ Bunnell-Littler) | **Intrinsic release + type I procedure** (e.g. **FDS tenodesis + intrinsic release**) |
| **III** | PIP flexion limited in all MCP positions; **joint space preserved** | **MUA** (aim 80–90° flexion) → dorsal skin release / Z-plasty → **lateral band mobilisation**; check flexor gliding; then type I procedure ± intrinsic release |
| **IV** | Stiff PIP + **radiographic destruction** | **Arthrodesis** or **arthroplasty** (+ soft-tissue balancing) |

## 5 Management

```
Swan neck
├─ Flexible, early → double ring splint (block PIP hyperextension)
└─ Progressive → volar plate advancement + PIP balancing
       ├─ FDS rupture → FDS tenodesis
       ├─ extrinsic overpull (CP) → central slip tenotomy (Fowler)
       └─ intrinsic tightness → intrinsic release
```

### Operative procedures

**Nonop** — **double ring splint** prevents PIP hyperextension

**Volar plate advancement** — addresses laxity

**FDS tenodesis / sling (TO)** — volar zig-zag; window either side of **A3**; one FDS slip cut **~1.5 cm** from insertion, distal attachment intact; PIP flexed **20–30°**; fixed to proximal phalanx (anchor) or **distal edge of A2** → static tether

**ORL reconstruction (TO)** — ulnar lateral band or tendon graft; **SORL (Brooks-Graner)** → dynamic PIP + DIP stability

**Volar plate repair (TO)** — when volar plate disruption was initial injury; anchors/drill holes base of P2

**Intrinsic release (Littler) (TO)** — dorsoulnar incision; excise **triangular aponeurosis / oblique fibres** + lateral band at distal half of PIP; preserve **central slip, lateral slips, transverse fibres**

**Central slip tenotomy (Fowler)** — CP swan neck from **extrinsic extensor overpull** (structure C)\
✗ Wrong options: terminal tendon A · lateral band B · lateral slip D · lumbrical E

**CP alternatives** — intrinsic lengthening for intrinsic spasticity; lateral band rerouted volar to PIP axis (Van Heest & House)

**Type IV (TO)** — **arthrodesis** most predictable: **40–50° ulnar digits**, less for index; **silastic arthroplasty** preferred ring & small (motion > pinch)

### Thumb swan neck (Nalebuff type III thumb) (TO)

**Sequence (TO)** — **CMC subluxation/adduction** → compensatory **MCP hyperextension** for pinch

**Treatment (TO)** — fix foundation first: **CMC arthroplasty (LRTI)** → then MCP capsulodesis or fusion

## X vs Y

| | **Swan neck** | **Boutonniere** |
|---|---|---|
| PIP | Hyperextension | Flexion |
| DIP | Flexion | Hyperextension |
| Lateral bands | **Dorsal** | **Volar** |
| Key structure | Lax volar plate; tight **triangular ligament** | Central slip rupture; attenuated triangular ligament |
| Trauma origin | Mallet, FDS rupture | Central slip injury |

## How it's asked

**"Best procedure, type II swan neck?"** → **FDS tenodesis + intrinsic release** (TO)

**"PIP flexion worse with MCP extended?"** → **intrinsic tightness** (TO)

**"Triangular ligament tightness causes?"** → **swan neck**\
✗ Wrong options: boutonniere, sagittal band, volar plate contracture

**"CP swan neck, failed splint — tenotomy of?"** → **central slip (C)**

**"Type IV (destroyed PIP)?"** → **arthrodesis / arthroplasty** (TO)

**"Thumb swan neck — address first?"** → **CMC (LRTI)** (TO)

**"Initial treatment?"** → **double ring splint**
