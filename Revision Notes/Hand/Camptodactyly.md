# Camptodactyly

*Hand · 9 / 103*

## 1 Basics

### Definition & epidemiology

**Definition (TO)** — Greek "**bent finger**"; **nontraumatic flexion deformity of the PIP joint**, classically **small finger**

**Prevalence** — **<1%**

**Laterality** — unilateral 33% · **bilateral 66%** (often **asymmetric** (TO))

**Other digits (TO)** — occasionally; incidence & severity ↑ toward **ulnar side** of hand

**Genetics** — mostly **sporadic**; familial = **AD, incomplete penetrance / variable expressivity**

**Isolated case** — usually idiopathic → **no genetic workup**; Type III / multi-digit → syndromes (e.g. arthrogryposis)

### Etiology

**Commonest causes** — **abnormal lumbrical** insertion/origin · **abnormal FDS** insertion (adherent, hypoplastic, tight)

**Less common** — central slip, extensor hood, volar plate, skin/subcutaneous contracture

**Lumbrical theory (TO)** — lumbrical inserts into lumbrical canal/FDS instead of extensor hood → like an **intrinsic-minus digit** (Jones, Marmor, Lankford)

**Other TO theories** — FDS tightness / "slow retraction" of flexors · short FDP · faulty dorsal extensor aponeurosis

**Unifying concept (TO)** — **final common expression of flexion–extension imbalance at PIP** ("virtually every structure implicated", Smith & Kaplan)

## 3 Presentation

**Exam** — **PIP flexion deformity, small finger**; flexible or fixed; **painless**, no swelling/erythema; normal strength, sensation, perfusion

**Neighbouring joints** — DIP & MCP usually normal; untreated → compensatory **MCP hyperextension** (commonest adjacent)

**Course** — progressive; **rapid worsening in growth spurts**

**Function** — rarely compromised; often unnoticed

## 4 Diagnosis & Classification

### Diagnosis

**Diagnosis** — **clinical**

**Onset (TO)** — congenital (♂ = ♀) or **adolescent** (early teens, ♀, gradual)

### Key radiology findings

**X-ray** — often **normal** early (articular congruity maintained)

**Late X-ray** — ↓ **P1 head convexity** · volar subluxation + flattening of **P2 base**

### Benson classification

| Type | Features | Treatment | Image |
|---|---|---|---|
| **I** (infantile) | Isolated small finger, **infancy**, ♂ = ♀; **most common** (Orthobullets) | **Stretching/splinting** | ![Type I](../../Orthobullets/attachments/ob6074-campto-2-copy.jpg) |
| **II** (adolescent) | Same features, **adolescence**; **♀ > ♂** | If **full active PIP extension with MCP flexed** → **FDS transfer to radial lateral band** | ![Type II](../../Orthobullets/attachments/ob6074-camptodactyly-1-copy.jpg) |
| **III** (syndromic) | **Birth**, severe, **multiple digits**, syndrome | Nonop; after maturity if functional deficit → **osteotomy / fusion** | — |
| Kirner's | Small finger **distal phalanx** volar-radial curve (apex dorsal-ulnar); preadolescent ♀; bilateral; no deficit | — | ![Kirner deformity](../../Orthobullets/attachments/ob6074-kirner-1.jpg) |

**Commonest type — conflict** — **Type I/infantile** (Orthobullets) · **adolescent type more common** (TO) — read the options

## 5 Management

```
Camptodactyly
├─ Most cases / PIP contracture <30° → passive stretching + static (night) extension splinting
│      (best results with EARLY treatment)
├─ Progressive, functional impairment, contracture ~60° despite splinting → surgery
│      ├─ passive (correctable) → FDS tenotomy
│      └─ full active PIP ext with MCP flexed → FDS transfer to radial lateral band
└─ Severe FIXED deformity → osteotomy / arthrodesis
```

### Treatment – stretching & extension splinting

**First line** — **night extension splinting + stretching** (intrinsic-plus splint) → always try first, even mild deformity\
✗ Wrong options: observation alone: shorter duration → better result

**Mild (<30°)** — stretching ± splint → expect resolution (Rhee: **20° → 1°** over 5 mo, ≥20 sessions/day, children <3 y)

**Severe (>60°)** — stretching helps but slower (Rhee: **75° → 28°**, up to 2 y) → may need **FDS tenotomy** if bothersome

(✗ Wrong options: **Traps** — complete correction in 1–2 mo) · **serial casting 90% for >50°** · progressive contracture of all joints · routine bilateral tenotomy\
✗ Wrong options: not effective for significant deformity

**Serial casting — conflict** — not effective for significant deformity (OB) · listed among nonop options for **mild** cases (TO)

**TO nonop list** — active exercises, dynamic splints, serial casts, passive stretching (mild cases)

### Surgery

**Indication** — **progressive** deformity → functional impairment; failed splinting

**Principle** — address **all** abnormal anatomy; rebalance PIP flexion–extension

| Deforming factor (TO) | Procedure |
|---|---|
| **FDS contracture** | **FDS tenotomy** |
| **Anomalous lumbrical** | Excise or reinsert into **lateral band** + volar Z-plasties + active post-op splinting |
| **Flexor–extensor imbalance** | Volar release + **FDS transfer through lumbrical canal to extensor aponeurosis** |
| Extreme | **FDP lengthening + PIP capsulotomy** |

**Outcomes** — **inconsistent / variable**; complications: persistent PIP contracture & MCP hyperextension, residual stiffness, **P1 head remodelling** blocking extension

## X vs Y

| Differential (TO) | Distinguishing point |
|---|---|
| **Camptodactyly** | **PIP flexion**, painless, slow, no trauma |
| **Clinodactyly** | Deviation in **radioulnar plane** |
| Boutonnière | Trauma, swelling/pain, **DIP hyperextension** |
| **Dupuytren** | **MCP contracture**, palmar dimpling/fascia |
| Trigger digit | Triggering; affects **MCP** |
| Congenital absent extensor mechanism | Affects **MCP**, not PIP |

## How it's asked

**"3-y-old, bilateral asymmetric fixed little-finger PIP flexion, painless, no trauma, normal DIP/MCP"** → **camptodactyly** ("compatodactyly" in TO)\
✗ Wrong options: clinodactyly, Dupuytren, absent extensor mechanism

**"PIP 25° one side, 60° other — counsel"** → **stretching fixes 25°; 60° slower ± FDS tenotomy**

**"5-y-old, isolated small finger, limited passive extension — next step"** → **night extension splint + stretching**\
✗ Wrong options: observation · genetic workup · FDS transfer first

**"Full active PIP extension with MCP flexed"** → **FDS transfer to radial lateral band**

**"Severe fixed deformity"** → **osteotomy / arthrodesis**

**"Commonest causes"** → **abnormal lumbrical or FDS insertion**
