# Phalanx Dislocations

*Hand · 61 / 103*

## 1 Basics

**PIP joint** — **most commonly injured joint in hand**; **dorsal > volar**

**DIP** — usually dorsal or lateral; volar rare; often **open** (tight envelope)

**Mechanism** — direct blow; fracture-dislocations by **avulsion** or **impaction shear**

### Anatomy

| Stabiliser | PIP | DIP |
|---|---|---|
| Proper collateral | Proximal phalanx condyle → volar base P2 | P2 condyle → volar base P3 |
| Accessory collateral | → volar plate | → volar plate |
| Dorsal | **Central slip** (dorsal base P2) | Terminal extensor (dorsal base P3) |
| Volar tendon | FDS (volar shaft P2) | FDP (volar base P3) |
| **Volar plate** | **Checkrein ligaments** proximally; resists **hyperextension** | no checkreins; resists hyperextension |

**Collaterals** — resist radial/ulnar deviation

**Ligament box (TO)** — proper collateral (**primary stabiliser**, inserts volar ⅓ of P2) + accessory collateral + volar plate → **at least 2 sides must fail for PIP dislocation** · PIP collateral fails **proximally**, volar plate avulses **distally** · volar plate taut in extension resists dorsal displacement

**P1 head asymmetry (TO)** — slight condylar asymmetry → **\~9° supination** during flexion

## 3 Presentation

**Skin puckering** — soft-tissue interposition

**Stability tests** — lateral stress in **full extension** (secondary stabilisers) and **30° flexion** (collaterals); hyperextension (volar plate); **Elson** (central slip); full active ROM = stable

**Collateral grades** — I pain, no laxity · II laxity, firm endpoint · III no endpoint

**Neuro** — traction neurapraxia of adjacent digital nerves

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP, lateral, oblique

**Dorsal PIP types (TO)** — **I** hyperextension, surfaces still touching · **II** bayonet · **III** fracture-dislocation

**Complex dorsal PIP (TO)** — volar plate interposed + soft-tissue **"tendon noose"** round P1 → open reduction

**Dorsal "V sign"** — dorsal joint widening = **incomplete reduction** (TO) · = **subtle dorsal subluxation of P2** → unstable

### PIP dislocation types

| Type | Lesion | Reduction | After reduction |
|---|---|---|---|
| **Dorsal simple** | Hyperextension + axial load; collaterals torn, **volar plate** sheared ± small avulsion; P2 touches condyles | Volar force + flexion (often by patient) | Stable → **buddy tape 3–6 wk** · unstable → **extension block splint** |
| **Dorsal complex** | **Bayonet**; P2 off condyles; **volar plate blocks** traction | Hyperextend then palmar force | Open (dorsal approach between central slip & lateral band) if fails |
| **Volar simple** | **Central slip rupture** | Flexion + dorsal force at P2 base | **PIP full extension splint**, DIP + MCP free |
| **Volar rotatory** | **One collateral torn**, condyle **buttonholes between central slip & lateral band** | **MCP + PIP 90° flexion + traction** (relaxes lateral band) | Open via **dorsolateral** approach if fails |
| **Lateral** | One collateral + partial volar plate | Closed | Buddy tape; block = **lateral band** |

**Blocks to reduction** — closed dorsal PIP: **volar plate** · open dorsal PIP: **FDP** · lateral: **lateral band** · closed dorsal DIP: **volar plate** (open: FDP) · volar DIP: **terminal tendon**

**Volar PIP splint duration** — **6–8 wk** (Orthobullets) · **4–6 wk** (OB) · **6 wk** (OB) — read the options

## 5 Management

### Dorsal PIP dislocation/fracture-dislocation – extension block splinting

**Primary goal** — **maintain joint reduction → congruent gliding arc**\
✗ Wrong options: anatomic articular reconstruction · volar plate reattachment · immobilise to union

**Best predictor of outcome** — **congruent gliding joint** > early motion > anatomic surface

**Avoid hinging** — subluxation → poor outcome

| Operative threshold | Source |
|---|---|
| **<40%** stable → closed + splint; **>40%** unstable → CRPP/ORIF | Orthobullets |
| **<25%** + reduces in flexion → EBS; **>25%** or incomplete reduction → surgery; **>50%** → open/VPA | OB |
| Stable <30% buddy · tenuous 30–50% EBS if reduced in <30° flexion · unstable >50% surgery | OB (Hastings) |

**Stability threshold (TO)** — **< 40% volar articular surface → usually stable** · **> 40% or comminution → unstable** (proper collateral detaches with volar fragment)

**EBS indications (TO)** — no incongruity · **stable in ≤ 30° flexion** · collaterals intact · start 30°, **extend 10°/wk** · avoid in **short swollen fingers** (→ extension block pinning)

**Extension block pinning (TO)** — K-wire **obliquely between central slip and lateral bands** → early motion

**Dynamic traction (Suzuki frame, TO)** — pilon / multifragment **30–50%** surface, reducible joint · **proximal–distal hook distance ≤ 2.5 cm** (avoid over-distraction)

**Cerclage wiring (TO)** — severe pilon with central impaction when ORIF impossible

**Pilon (TO)** — axial compression → dorsal + volar fragments separate, **central cartilage depression**, P2 base widening → dynamic traction or arthroplasty

**Extension block splint (EBS)** — stable reduced dorsal **fracture**-dislocation <40%; block **~40°**, reduce **10°/wk** over 3 wk, active flexion within splint

**Redislocates only in full extension, <25% involvement** — **EBS 3 wk**

**Avoid cast 6 wk** — stiffness

```
Dorsal PIP fracture-dislocation
├─ Stable, small fragment → buddy tape + early motion
├─ Tenuous, reduces in flexion → EXTENSION BLOCK SPLINT
└─ Unstable (>40–50%, V sign despite splint)
       ├─ reconstructable fragment → ORIF / extension block pinning
       ├─ pilon / comminuted → DYNAMIC DISTRACTION EX-FIX
       ├─ young, ~50%, not fixable → HEMI-HAMATE
       └─ chronic → volar plate arthroplasty / arthrodesis
```

### Unstable/chronic fracture-dislocations – volar plate arthroplasty, hemi-hamate & ORIF

**Acute >50% volar rim, V sign at 30° flexion, young athlete** — **ORIF**\
✗ Wrong options: buddy · EBS · VPA in young acute

**Volar plate arthroplasty** — acute unstable or **chronic** dorsal FD (>40% comminuted volar surface, e.g. neglected 5 wk); excise fragments, trough, advance plate, dorsal sutures

**VPA must release** — **collateral ligaments** (else hinging)

**VPA technique (TO)** — transverse trough at P2 base · mobilise volar plate **4–6 mm distally** · release accessory collaterals · **central exit hole mandatory** (avoids tethering lateral bands) · flex DIP during suture passage

**Volar exposure** — resect **proximal C2, entire A3, distal C1** pulleys

**Hemi-hamate** — **non-vascularised osteochondral autograft with hyaline cartilage** from **hamate**; young, ~50% P2 base, chronic/irreducible\
✗ Wrong options: MFC, iliac crest, fibula, distal radius

**Hemi-hamate graft (TO)** — from **dorsal distal hamate centred over 4th/5th CMC joints** · half dorsal-volar thickness + half radial-ulnar width · orientation restores volar buttress

**Older sedentary chronic** — **PIP arthrodesis**

**Intra-articular proximal phalanx condylar fracture with step** — **ORIF**\
✗ Wrong options: buddy, splint, arthrodesis in young

### Volar PIP dislocation – central slip injury & reduction/splinting

**Most often injured (TO)** — **central slip**\
✗ Wrong options: sagittal bands, lumbrical, juncturae

**Dorsal PIP (TO)** — volar plate injured → early ROM after reduction

**Volar PIP Rx** — **closed reduction + full-time PIP extension splint**; DIP + MCP free (lateral band motion)\
✗ Wrong options: EBS = dorsal

**Untreated** — **boutonnière** (3 wk later: can't extend PIP → central slip)

**Open central slip repair** — subacute/chronic developing boutonnière

**Rotatory volar** — no in-line traction (noose tightens) · no hyperextension · not always open

### DIP dislocations & fracture-dislocations

**Reduction** — traction + dorsal pressure on P3 + flexion; I&D if open

**Splint** — dorsal: slight flexion 2–3 wk if unstable · volar: **extension 6 wk**

**Irreducible closed dorsal DIP** — **volar plate** entrapment → open reduction\
✗ Wrong options: central slip, rotatory, collateral, MCP natatory/transverse ligament

**Open reduction** — after 2 failed attempts; FDP repair if attached to volar fragment

**>40% unstable** — VPA · comminuted without soft-tissue loss — arthrodesis · with NV/soft-tissue loss — amputation

**Tuft fracture** — no specific Rx
