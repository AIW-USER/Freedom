# Metacarpal Fractures

*Hand · 57 / 103*

## 1 Basics

### Epidemiology

**Incidence** — **40% of all hand injuries**; most common hand injury

**Who** — **men 10–29 y**

**Site** — **neck = commonest site**; **5th MC = commonest bone**

### Anatomy

**Arch** — palmar concave; **1st, 4th, 5th = mobile borders**; **2nd + 3rd = stiff central pillar** (index most firmly fixed)

**CMC mobility** — 2nd/3rd CMC stiff → **less tolerance of angulation** in index/long

**Transverse (deep) intermetacarpal ligament** — **primary restraint to shortening** of isolated 3rd/4th shaft fractures; stays intact in shaft fracture\
✗ Wrong options: rotation · MCP/CMC stability · fracture prevention

| Tendon | Insertion | Deforming role |
|---|---|---|
| ECRL / ECRB | Base MC II / III | — |
| **ECU** (PIN) | **Base MC V** | **Pulls 5th MC base dorsal + proximal** |
| APL | Base MC I + trapezium | Bennett/Rolando |
| Opponens pollicis / digiti minimi | MC I / MC V | — |

**Interossei** — 3 palmar + 4 dorsal arise from MC shafts

## 2 Mechanism

**Mechanism** — direct blow / punch; rotational + axial load; high energy → **multiple fractures**

**Associations** — open wounds (tendon, NV injury), **compartment syndrome** (crush, multiple fractures)

### Boxer's fracture

**Definition (TO)** — **transverse or short oblique fracture of the 5th MC neck** (less often 4th)\
✗ Wrong options: head · shaft

**Facts (TO)** — **most common MC fracture**; punching with clenched fist; **apex dorsal angulation**; closed reduction + cast or K-wire

## 3 Presentation

**Fight bite over MCP** — **open until proven otherwise**; dorsal wounds over MC fractures almost always open

**Malrotation** — line up fingernails in partial + full flexion, compare sides → **scissoring/overlap**; best assessed after block

![Assessing malrotation in flexion](../../Orthobullets/attachments/ob6037-metacarpal-rotation.jpg)

**Shortening** — compare knuckles with other hand

**Base deformity** — suspect **CMC dislocation**

## 4 Diagnosis & Classification

### Key radiology findings

| View | Best for |
|---|---|
| PA + lateral | All |
| **ER oblique** (supinated) | **4th/5th CMC** fracture-dislocation |
| **IR oblique** (pronated) | **2nd/3rd CMC** |
| **Brewerton** | **MC head** fractures |
| **Roberts** | **Thumb CMC** |
| CT | Inconclusive CMC injury, multiple CMC dislocations, complex head fractures; **after reduction** of 5th CMC injury |

**CMC fracture-dislocation clues** — MC shortening on AP; dorsal base subluxation / dorsal hamate fragments on lateral

### Acceptable angulation & shortening; extensor lag

| Digit | Shaft angulation (Orthobullets/OB) | Shaft angulation (TO) | Neck angulation | Shortening |
|---|---|---|---|---|
| Index & long | **10–20°** | **>10°** → fix | **10–15°** | 2–5 mm |
| Ring | **30°** | **>25°** → fix | **30–40°** | 2–5 mm |
| Little | **40°** | **>45°** → fix | **50–70°** | 2–5 mm |

**Conflict** — ring 30° / little 40° (Orthobullets, OB) · **ring 25° / little 45°** (TO) — read the options

**Shortening** — **2–5 mm acceptable** (Orthobullets, OB) · fix if **>5–6 mm** (TO)

**Shortening effect** — **7° extensor lag per 2 mm** (linear, not digit-dependent) + **8% ↓ power per 2 mm** (↓ interosseous force; intrinsics 40–90% of grip)

**Shortening >2–5 mm** — **MCP extension lag + ↓ grip** (loss of extensor tension)

**Apex dorsal angulation (index/long)** — **pseudoclawing** (MCP hyperextension, PIP extension lag) because stiff 2nd/3rd CMC cannot compensate; reduce if >10°

**Rotation** — overlap, no extensor lag, no pseudoclaw

### Operative criteria

| Indication | Threshold |
|---|---|
| **Malrotation** | **Any scissoring** / >10° (TO) — **absolute**, least tolerated |
| Angulation | Beyond table limits |
| Shortening | >5–6 mm (TO) |
| **Open** fracture | Any |
| **Intra-articular** | Any (head: **no articular step acceptable**) |
| **Multiple** MC fractures | Any — loss of adjacent support |
| Associated CMC dislocation, extensor lag (TO) | Any |

**Not indications** — comminution alone, manual-labour occupation, ring sagittal angulation 15° (TO)

## 5 Management

```
Metacarpal fracture
├─ Stable, no rotation, within limits → NONOP
│      └─ 5th neck → BUDDY TAPE + SOFT WRAP, OPTIONAL FOLLOW-UP
├─ Rotation / open / intra-articular / beyond limits → CRPP or ORIF
└─ Multiple MC fractures → ORIF ALL
```

### Nonoperative care – buddy taping & early return

**Cast** — **MCP 70–90° flexion**, PIP free, **4 wk**

**Jahss reduction** — MCP 90° flexed, dorsal push through proximal phalanx, stabilise shaft

**5th neck, no rotation (<50–70°)** — **buddy taping 4–5 + soft wrap**, **optional follow-up** → better satisfaction, **earliest RTW**\
✗ Wrong options: ulnar gutter splint/cast · CRPP

**Athletes, minimally displaced spiral ring MC** — ORIF: **no faster union, but faster return to play**; no better grip/ROM

### Rotational deformity – scissoring as fixation indication

**Strongest fixation indication** — **scissoring of digits with flexion**\
✗ Wrong options: 20° 4th neck angulation (30° OK) · 4 mm shortening · comminution · occupation

**Untreated multiple MC shaft fractures** — rotational malunion → **digits overlap in fist** → corrective osteotomy

**Not MC fracture sequelae** — sagittal band rupture (can hold passive extension) · loss of key pinch / Wartenberg / ulnar numbness (ulnar neuropathy)

### Operative fixation – multiple fractures, ORIF & intramedullary screws

**Multiple shaft fractures** — **ORIF**; **fix all three**\
✗ Wrong options: casting → stiffness · ex-fix binds extensors · removable splint → shortening

**Techniques**

| Fixation | Fact |
|---|---|
| CRPP | Antegrade from base or retrograde via collateral recess; remove pins **4 wk** |
| **Lag screws** | Long spiral/oblique; ≥2 screws |
| **Dorsal plate** | **Transverse**; cover with periosteum; extensors less adherent at MC level → low adhesion |
| **IM headless screw** | **Only axially stable** (transverse) patterns; corrects angulation/rotation; not for oblique/shortened/comminuted (**least amenable = long oblique axially unstable**); unstable if fracture length >2× shaft diameter |
| Head ORIF | Dorsal approach, split extensor or release/repair sagittal band; screws in collateral recess / headless / K-wires; hardware not proud |
| Severe head comminution | Ex-fix or **MCP arthroplasty**; late arthritis → fusion |

**Post-op** — **early motion critical**; head fracture commonest complication = **stiffness**

**Neck ORIF** — difficult (little distal bone)

### Fifth CMC fracture-dislocation – deforming forces & pinning

**Incidence** — **<1% of hand trauma**; often **missed**; 5th ± 4th; axial load on clenched fist

**Deforming force** — **ECU** (insertion base 5th MC) → **innervated by PIN**\
✗ Wrong options: radial (ECRL only) · ulnar · AIN

**Acute** — **closed reduction + splint first** → **CT after reduction**\
✗ Wrong options: CT first · immediate CRPP/ORIF

**Reduction lost at 1 wk** — **CRPP**\
✗ Wrong options: repeat reduction · discontinue immobilisation · arthrodesis

**Delayed / irreducible** — **open reduction + pinning**; **comminuted intra-articular 5th base + displaced 4th shaft (>30°)** → **fix both**

**Arthrodesis** — chronic / painful post-traumatic arthritis only

**Dorsal ulnar approach** — **dorsal branch of ulnar nerve** (from **medial cord**), arises **~6 cm proximal to ulnar styloid** → retract (neuroma)

## 6 Complications

**List** — **stiffness** (commonest, head) · malunion (rotation → scissoring; angulation → pseudoclaw; shortening → extensor lag) · tendon irritation (plate) · arthritis

## X vs Y

| | Shortening | Apex dorsal angulation | Malrotation |
|---|---|---|---|
| Sign | **MCP extensor lag**, ↓ grip | **Pseudoclawing** (index/long) | **Scissoring / overlap** |
| Tolerance | 2–5 mm | Digit-specific | **None** |

| | Shaft | Neck |
|---|---|---|
| Angulation tolerance | Less | **More** |
| Little finger | 40° (45° TO) | **50–70°** |
| Ring | 30° (25° TO) | **30–40°** |

## How it's asked

**"Fixation indications EXCEPT?"** → **15° sagittal angulation in ring finger** (TO)

**"Extensor lag + ↓ grip after closed treatment — cause?"** → **5 mm shortening**

**"Effect of shortening?"** → **7° extensor lag per 2 mm**

**"Role of transverse intermetacarpal ligament?"** → **limits shortening**

**"Little finger neck — max acceptable angulation?"** → **50–70°**

**"Index/long healed with deformity — pseudoclawing cause?"** → **30° apex dorsal angulation**

**"Strongest indication to fix 4th neck?"** → **scissoring with flexion**

**"Multiple MC shafts untreated — complaint?"** → **digits overlap in fist**

**"Buddy taping + optional follow-up?"** → **angulated 5th MC neck without rotation**

**"ORIF vs nonop in athlete?"** → **same union time, faster return to play**

**"Fastest RTW for 5th neck <50°?"** → **buddy taping 4th–5th**

**"Multiple MC shaft fractures (polytrauma) — definitive?"** → **ORIF**

**"Three MC fractures from airbag?"** → **fix all three**

**"Least amenable to IM headless screw?"** → **oblique, axially unstable, shortened shaft**

**"Comminuted 5th base + angulated 4th, 2 wk old?"** → **fix both**

**"4th/5th CMC redislocated at 1 wk?"** → **CRPP**

**"Deforming muscle — nerve?"** → **ECU — PIN**

**"Dorsal ulnar approach nerve — from?"** → **medial cord** (dorsal branch ulnar n.)

**"Acute 5th base fracture-dislocation — next step?"** → **closed reduction + splint** (then CT)

**"Boxer's fracture is?"** → **5th MC neck fracture** (TO)
