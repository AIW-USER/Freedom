# Phalanx Fractures

*Hand · 62 / 103*

## 1 Basics

### Epidemiology

**Frequency** — commonest skeletal injuries; **10% of all fractures**

**Sex** — **♂:♀ 2:1**

**Location** — **distal > middle > proximal phalanx**; **small finger** commonest (38% of hand fractures)

**Mechanism by age** — 10–29 y sports · 40–69 y machinery · >70 y falls

**Association** — distal phalanx # → **nail bed injury**

### Anatomy

**Parts** — P3: tuft, shaft, base · P1/P2: head, neck, shaft, base

**Insertions** — terminal extensor → dorsal base P3 · **FDP → volar base P3** · central slip → dorsal base P2 · **FDS → volar shaft P2**

**FDP origin** — **anteromedial proximal ulna** (upper ¾ ulna, olecranon/coronoid, IOM)\
✗ Wrong options: epicondyles; lumbricals arise from FDP tendons

**IP joint** — hinge; dynamic stability from pinch/grip compression; passive from **proper + accessory collaterals**

**Digital NV** — dominant artery on side **closer to midline**; nerve **volar** to artery

### Deforming forces – interossei & central slip (apex volar)

| Fracture | Proximal fragment | Distal fragment | Apex |
|---|---|---|---|
| **P1 shaft (transverse)** | **Flexed by interossei** | **Extended by central slip** | **Volar** |
| P2 distal to FDS insertion | Flexed by FDS | — | **Volar** |
| P2 proximal to FDS insertion / P2 base | Extended by central slip | Flexed by FDS | **Dorsal** |
| P2 with long intact FDS | — | — | No angulation |
| P2 neck | — | — | Volar |
| **Seymour (P3 epiphysis)** | Terminal tendon on proximal epiphysis | FDP on distal fragment | Dorsal (**mallet look**) |

**Proximal fragment flexor** — **interossei** (Orthobullets, most OB) · "lumbrical insertions" (OB217355) — read the options

**P1 base** — transverse # in **proximal 6–9 mm** more stable (collaterals, capsule, intrinsics)

**Reduction manoeuvre** — **flex MCP** → extensor mechanism acts as tension band (**intrinsic-plus**)

## 3 Presentation

**Exam** — swelling, deformity (angular, **rotation**, shortening), **open wounds**

**Scissoring** — rotational component; assess via **tenodesis**

**NV** — 2-point discrimination; cap refill <2 s

![Scissoring = malrotation](../../Orthobullets/attachments/ob6114-scissoring.jpg)

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — **PA, lateral, oblique** of digit (orthogonal)

**X-ray** — P1 apex volar; P2 apex volar (distal to FDS) / dorsal (proximal to FDS)

**CT** — articular displacement, comminution

### Shaft & base patterns

| Bone | Patterns |
|---|---|
| P1 | Shaft: short oblique, **long oblique**, **spiral**, transverse · base: extra-articular, intra-articular lateral base |
| P2 shaft | Transverse, short oblique, long oblique, spiral |
| **P2 base – volar** | Hyperextension/axial → **volar plate avulsion**; unstable if **>40%** articular surface (Orthobullets) |
| P2 base – dorsal | Hyperflexion → **central slip avulsion** |
| P2 base – lateral | Collateral avulsion |
| **P2 pilon** | Complete articular (axial load; dorsal + volar cortex) → **unstable in all directions** |
| P3 tuft | **Crush**; stable (nail plate + pulp); **nail matrix/pulp laceration** |
| P3 shaft | Transverse, longitudinal |
| P3 base | **Usually unstable**: shear (axial, **>20%** surface) or avulsion (terminal tendon / FDP) |

### PIP fracture-dislocation stability (OB)

| Volar lip (P2 base) involvement | Stability |
|---|---|
| **<30%** | Stable → closed reduction |
| **30–50%** | Tenuous; depends on post-reduction stability |
| **>50%** | **Unstable** → surgery |
| Needs **>30° PIP flexion** to hold | Unstable regardless of size |

**Conflict** — volar base unstable if **>40%** (Orthobullets) · **>30% / >50%** bands (OB) — read the options

## 5 Management

```
P1 / P2 extra-articular
├─ <10° angulation + <2 mm shortening + no rotation → buddy tape / splint 3 wk → aggressive ROM
├─ >10° · >2 mm · ANY rotation · open → CRPP or ORIF
└─ Unstable pattern (spiral, long oblique, comminuted) → fixation
       └─ needs early ROM (e.g. musician) → ORIF (lag screws ± plate)
```

### Operative criteria

| Bone | Nonoperative | Operative |
|---|---|---|
| **P1 & P2** | Extra-articular **<10° angulation, <2 mm shortening, no rotation**; undisplaced intra-articular | **>10° angulation**, **>2 mm shortening**, **any rotation**, displaced intra-articular, unstable/irreducible, **grossly contaminated open** |
| **P3** | Most: closed reduction ± splint (nail matrix may block reduction) | Displaced/irreducible shaft · **dorsal base >25%** · **displaced volar base with large FDP fragment** · nonunion · nail bed injury → remove nail, repair bed, replace nail (keeps eponychial fold) |

**EXCEPT trap** — **5° apex dorsal** angulation not an indication (atypical, <10°)

### Operative indications & fixation methods

| Pattern | Fixation |
|---|---|
| Transverse / short oblique P1 | **Two 0.045-in K-wires longitudinally through flexed MCP (metacarpal head)** or PIP; single wire risks rotational malunion |
| Very proximal P1 | **Eaton-Belsky** pinning through metacarpal head |
| **Long oblique / spiral P1** | **Open reduction + lag screws (1.3 mm > 1.5 mm), radial approach**; CRPP ≈ lag screws long term |
| Oblique extending to condyles | **Lag screw** fixation |
| **Unicondylar / bicondylar head** | Unstable → **ORIF** |
| Comminuted bicondylar / comminuted shaft | **Plate**, radial approach (↓ adhesions) |
| P2 | Crossed K-wires, extension-block pinning, collateral recess pinning, mini-fragment, volar plate arthroplasty, **hemi-hamate (>50% articular)** |
| P3 | Longitudinal/crossed K-wires, extension-block, lag screw |
| Intramedullary screw | Shaft #s; not too-proximal P1 |

**Plate** — **allows early ROM** (main reason for ORIF) but **higher complications** (52% in Guerrero; hardware removal, tenolysis/capsulotomy 30%) than CRPP/lag screw; one RCT: plate via mid-lateral → ↑ TAM

**Distal phalanx nonunion ORIF** — **high risk of symptomatic implant** → removal

### Nonoperative care – immobilisation & early motion

**Position** — **intrinsic-plus (MCP flexion)** → prevents MCP stiffness\
✗ Wrong options: MCP + IP extension

**Duration** — **3 wk immobilisation → ROM** (Orthobullets, OB) · buddy-tape 4 wk (Meals, OB)\
✗ Wrong options: immediate ROM without immobilisation → displaces

**Nonop P1 in young** — <60% active motion maintained

### Intra-articular fractures & avulsions (pilon, volar lip)

| Injury | Treatment |
|---|---|
| Bony mallet | Extension splint 6–8 wk |
| DIP fracture-dislocation, small articular piece | Closed reduction ± splint |
| Undisplaced P3 # | None / Alumafoam for comfort |
| **Unicondylar P1 head** | **ORIF** |
| Dorsal PIP fracture-dislocation, congruent + stable 30–90° | **Extension-block splint** |
| Dorsal PIP # -dislocation, subluxed | Extension-block pinning / pin volar fragment / ORIF |
| Large volar articular piece | **ORIF** (buttress plate / screws) |
| **Pilon P2 base** | **Dynamic external fixator** (✗ Wrong options: static) |
| **Unstable dorsal PIP subluxation, comminuted volar lip / malunion with arthrosis** | **Hemi-hamate arthroplasty** (needs intact dorsal cortex) |
| Volar fracture-dislocation (dorsal lip #) | Extension splint, CRPP, transfixion, mini/hook plate, screws |

**HHA not for** — pilon or dorsal lip # (dorsal cortex not intact)

![Pilon fracture of P2 base](../../Orthobullets/attachments/ob6114-mp-base-pilon.jpg)

### Paediatric phalangeal neck/condylar fractures

**Malunion blocking subcondylar fossa** (7 y, PIP 40° arc, stable) → **ostectomy** of subcondylar fossa\
✗ Wrong options: observe: P1 physis proximal → no remodelling · osteotomy: AVN of small fragment · stretching/dynamic splint: bony block

## 6 Complications

### Loss of motion

**Most common complication** (incl. after ORIF PIP fracture-dislocation) — risk: prolonged immobilisation, intra-articular #, extensive dissection → aggressive therapy → surgical release

### Malunion & shortening – PIP extensor lag

**Apex volar P1 malunion** — effectively **shortens extensor** → **PIP extensor lag**\
✗ Wrong options: MCP motion · PIP flexion · scissoring without rotation

| Number | Effect |
|---|---|
| **1 mm P1 shortening** | **12° PIP extensor lag** |
| **16° apex volar** | **10° extensor lag** |
| <15° apex volar | Loss of extension only |
| >25° apex volar | Flexion + extension lost |

**Site → lag** — **P1 shortening → PIP lag**; P2 distal to FDS → DIP lag; P2 proximal to FDS no PIP lag; MC neck no lag

**Treatment** — symptomatic → **corrective osteotomy at malunion** (preferred) · metacarpal osteotomy (limited) · soft-tissue release

**Nonunion** — **<2%**, atrophic, bone loss/NV compromise → resection, graft, plate; ray amputation/fusion

## X vs Y

| | P1 shaft | P2 distal to FDS | P2 proximal to FDS / base |
|---|---|---|---|
| Apex | **Volar** | Volar | **Dorsal** |
| Malunion lag | **PIP** | DIP | No PIP lag |

| | CRPP | Lag screws | Plate |
|---|---|---|---|
| Pattern | Transverse/short oblique; long oblique | **Long oblique / spiral** | Comminuted, bicondylar |
| Early ROM | Less | ✓ | ✓ |
| Complications | Low | Low | **Highest** (stiffness, hardware) |

## How it's asked

**"Cause of apex palmar P1 deformity?"** → **central slip on distal fragment + interossei on P1 base**\
✗ Wrong options: swan neck · boutonnière · intrinsic fibrosis

**"Interossei and central slip deform P1 how, respectively?"** → **proximal flexion, distal extension**

**"True of ORIF of distal phalanx nonunion?"** → **high risk of symptomatic implant**

**"Optimal fixation, long oblique P1?"** → **open reduction + 1.3 mm lag screws, radial approach**

**"Oblique P1 into condyles, can't move PIP/DIP?"** → **reduction + lag screw**

**"P1 operative indications EXCEPT?"** → **5° apex dorsal angulation**

**"Long oblique P1 with rotation — best outcome, fewest complications?"** → **CRPP**\
✗ Wrong options: plate: more complications

**"Indication for surgery after reduced P1 fracture?"** → **5° rotational deformity**

**"Why plate instead of cast/CRPP in a violinist?"** → **need for early ROM**

**"Undisplaced transverse phalanx fracture — treatment?"** → **immobilise with MCP flexed**

**"Reduced P1 fracture, no rotation/shortening/angulation?"** → **short immobilisation, ROM at 3 wk**

**"17° volar malunion — which movement lost?"** → **PIP extension**

**"Untreated angulated P1 fracture — sequela?"** → **loss of PIP extension**

**"Shortened healing causing PIP extensor lag — which bone?"** → **proximal phalanx**

**"Child, PIP motion blocked by subcondylar malunion?"** → **ostectomy**

**"Acute pattern best for ORIF?"** → **unicondylar phalangeal head fracture**

**"Dynamic external fixator — which fracture?"** → **pilon fracture of P2 base**

**"Origin of tendon avulsing P3 volar base?"** → **anteromedial proximal ulna (FDP)**

**"Commonest complication of ORIF of PIP fracture-dislocation?"** → **loss of motion**

**"Unstable dorsal PIP subluxation — hemi-hamate for which film?"** → **dorsal fracture-dislocation with large volar lip fragment**\
✗ Wrong options: pilon · dorsal lip · pure dislocation
