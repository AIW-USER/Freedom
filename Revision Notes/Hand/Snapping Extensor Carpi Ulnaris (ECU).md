# Snapping Extensor Carpi Ulnaris (ECU)

*Hand · 85 / 103*

## 1 Basics

### Epidemiology

**Sports** — **tennis** (backhand), **golf** (club strikes ground), rugby; overuse (e.g. suturing)

### Anatomy – 6th compartment & subsheath

| Compartment | Contents | Condition |
|---|---|---|
| 1 | APL, EPB | De Quervain |
| **2** | ECRL, ECRB | **Intersection syndrome** (1st/2nd crossing) |
| 3 | EPL | — |
| 4 | EIP, EDC | — |
| **5** | EDM | **Vaughan-Jackson** |
| **6** | **ECU** | **Snapping ECU** |

**ECU** — inserts **base of 5th MC**; innervated by **PIN**

**ECU subsheath** — fibro-osseous tunnel, **part of TFCC**, most critical to ECU stability

**Kinematics** — pronation: straight course · **supination: exits 6th compartment at ~30°** → max tension on subsheath

**Subluxation position** — **supination + wrist flexion + ulnar deviation**

## 2 Mechanism

**Pathology** — **attenuation or rupture of ECU subsheath** → subluxation → snapping → **ECU tendonitis**

| Lesion | Behaviour |
|---|---|
| **Attenuation** | Sheath intact but stripped ulnar/palmar → **false pouch** |
| **Ulnar-sided tear** | Subluxes in supination, **reduces in pronation** |
| **Radial-sided tear** | Subluxes in supination, lies **on top of torn subsheath** in pronation |

![Ulnar vs radial subsheath tears](../../Orthobullets/attachments/ob6030-ulnar-sided-tears-top-result-in-dislocation-of-the-tendon-in.jpg)

## 3 Presentation

**Symptoms** — dorsoulnar wrist **pain + snapping/popping**

**Exam** — painful snap with **flexion + supination**; **reduces with pronation**

**Negatives** — no foveal pain with ulnar compression (TFCC) · no DRUJ instability

## 4 Diagnosis & Classification

### Diagnosis – snapping with supination/flexion & examination tests

**Diagnosis** — **clinical** (click with pathognomonic motion)

| Test | Positive in |
|---|---|
| **Flexion + supination → painful snap** | **Snapping ECU** |
| **ECU synergy test** (elbow 90°, full supination, wrist neutral, fingers extended → resisted **thumb + middle finger abduction**) | **ECU tendonitis** |
| Ulnar → radial deviation + scaphoid pressure | Watson (SL) |
| Ulnar soft spot tenderness (styloid–FCU) | TFCC |
| Axial load + max ulnar deviation | Ulnar styloid impingement / ulnocarpal abutment |
| Piano key | DRUJ instability |
| Finkelstein / Eichhoff | De Quervain |
| Resisted wrist extension, elbow extended, pronated | Lateral epicondylitis |

### Key radiology findings

| Modality | Fact |
|---|---|
| X-ray | **Unremarkable** |
| **Ultrasound** | **Dynamic** assessment of ECU stability |
| MRI | Tendonitis (**thickening + high T2 intrasubstance signal**), degenerative tears, TFCC pathology |

![ECU position in pronation vs supination](../../Orthobullets/attachments/ob6030-ecu-during-pronation-left-straight-coures-and-supination-rig.jpg)

**Differential** — TFCC tear · hook of hamate fracture · ulnar styloid fracture · ulnar styloid impaction · ulnar tunnel · pisotriquetral arthritis

## 5 Management

```
Snapping ECU
├─ First line → SPLINT / LONG ARM CAST: PRONATION + EXTENSION + RADIAL DEVIATION
└─ Fails nonop → SUBSHEATH SURGERY ± WRIST ARTHROSCOPY
       ├─ Acute → DIRECT SUBSHEATH REPAIR
       └─ Chronic → EXTENSOR RETINACULUM FLAP RECONSTRUCTION
```

### Nonoperative immobilisation position

**Position** — **pronation, slight extension, radial deviation** → minimal ECU angulation vs ulna

**Avoid supination / ulnar deviation** — lower threshold for subluxation

**Arthroscopy** — **concurrent TFCC tears in 50%**

## X vs Y

| | Snapping ECU | TFCC tear | Ulnar styloid impaction | LT tear |
|---|---|---|---|---|
| Key feature | **Snap on supination**, reduces in pronation | **Deep foveal pain**, worse with ulnar compression | Pain with pronation, + UV | VISI, LT shuck pain |
| Snap/pop | **Yes** | No | No | No |

## How it's asked

**"Golfer, ulnar pain + snap pronation → supination, normal X-ray, no foveal pain?"** → **ECU subluxation**\
✗ Wrong options: TFCC · ulnar abutment

**"Tennis backhand pop, dorsoulnar tenderness?"** → **ECU subluxation**\
✗ Wrong options: intersection (radial side)

**"Exam finding in subluxing ECU?"** → **pain with flexion + supination**

**"MRI ECU thickening + T2 signal — positive test?"** → **ECU synergy test**

**"Immobilisation position?"** → **pronation, extension, radial deviation**

**"Chronic reconstruction?"** → **extensor retinaculum flap**
