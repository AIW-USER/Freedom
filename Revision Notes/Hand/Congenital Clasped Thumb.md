# Congenital Clasped Thumb

*Hand · 13 / 103*

## 1 Basics

### Definition & epidemiology

**Definition** — **flexion-adduction deformity of thumb** persisting **beyond 3rd–4th month** of life; often **bilateral**

**Sex** — **♂:♀ ≈ 2.5:1**

**Predisposing** — consanguinity, family history

### Pathoanatomy

**Key lesion** — **attenuation/absence of EPB** (commoner, mild cases) **or EPL, or both**

**Also** — 1st web contracture · adductor pollicis / 1st dorsal interosseous contracture · global MCP instability · abnormal MCP cartilage

### Genes & lab markers

**Inheritance** — **autosomal dominant**, variable expressivity; may be **sporadic**

### Associations

**Syndromes** — **arthrogryposis** · digitotalar dysmorphism · **Freeman-Sheldon** · X-linked **MASA**

**Lower limb** — **congenital vertical talus**, bilateral **CTEV**

**Upper limb** — flexion deformities of the four fingers

## 3 Presentation

**History** — persistent flexion-adduction **beyond 3–4 mo**, usually bilateral; family history

**Examination** — type of clasped thumb (passive extension/abduction possible?) + associated anomalies

## 4 Diagnosis & Classification

**Diagnosis** — **clinical**

### Tsuyuguchi classification

| Type | Features | Image |
|---|---|---|
| **I — Supple** | Thumb **can be passively abducted & extended**; no other digital anomaly | ![Type I supple clasped thumb](../../Orthobullets/attachments/ob6085-tileshop-fcgi-3.jpg) |
| **II — With contracture** | **Cannot passively extend/abduct**; ± other digital anomalies | |
| **III — Rigid** | With **arthrogryposis** + marked soft-tissue deficit | |

## 5 Management

```
Congenital clasped thumb (all types)
├─ First line → SERIAL SPLINTING + STRETCHING 3–6 MO  (start ~6 mo of age)
│      └─ Type I with EPL or EPB present → good definitive result
└─ Fails / residual deficit → SURGERY (delay to 3–5 y)
       ├─ Type I–II, residual active extension deficit → EIP → EPL TRANSFER
       ├─ Type II–III, web deficit / MCP contracture → THUMB RECONSTRUCTION
       └─ Joint deformity not corrected by release + transfer → ARTHRODESIS
```

### First-line treatment – serial splinting

**All types** — **serial splinting of thumb 3–6 mo** = first line\
✗ Wrong options: observation (will not correct)

**Timing** — begin **~6 months** of age

**Good results** — **Type I** when **one of EPL/EPB present**

**Poor results** — Type I with **both EPL & EPB absent**; **Type II & III**

### Operative options

| Procedure | Indication |
|---|---|
| **EIP → EPL transfer** | **Type I or II** with residual deficit of active extension |
| **Thumb reconstruction** | Failed nonop; **1st web soft-tissue deficit (Type III)**; **Type II/III with significant MCP contracture** |
| **MCP arthrodesis** | **Last resort**: severe deformity / MCP instability not overcome by skin release + transfer |

**Reconstruction age** — **3–5 years**

**Web widening** — dorsal rotational advancement flap · **4- or 5-flap Z-plasty**

**Web deepening** — release thenar origins from TCL · release 1st MCP capsule

**Tendons** — **FPL Z-lengthening** in forearm; **EPB + EPL absent → tendon transfer**; **isolated EPB absence → usually no transfer**

## 6 Complications

**List** — cosmetic appearance · **MCP instability** · reduced thumb function

## X vs Y

| | Clasped thumb Type I | Type II | Type III |
|---|---|---|---|
| Passive extension/abduction | Yes | No | No (rigid) |
| Association | None | ± digital anomalies | **Arthrogryposis** |
| Splinting result | **Good** | Poor | Poor |
| Usual surgery | EIP → EPL if residual lag | Web reconstruction ± transfer | Web reconstruction ± arthrodesis |

## How it's asked

**"8-mo-old, restricted passive thumb extension/abduction — first line?"** → **serial splinting**\
✗ Wrong options: observation · web reconstruction · tendon transfer · MCP arthrodesis

**"Commonest deficient tendon?"** → **EPB**

**"Syndrome with rigid Type III?"** → **arthrogryposis**

**"Type I–II with residual active extension deficit?"** → **EIP → EPL transfer**

**"Age for reconstruction?"** → **3–5 y**
