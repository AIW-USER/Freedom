# Physical Exam of the Hand

*Hand · 63 / 103*

## 1 Basics

### Digital nerve anatomy

**Median nerve after TCL** — splits into smaller **lateral** + larger medial portion

**Lateral portion** — **recurrent motor branch** + **3 proper palmar digital nerves**: radial thumb, ulnar thumb, **radial index** → **one common branch off median nerve**\
✗ Wrong options: radial nerve origin for any of them

| Thumb–index pattern (Jolley) | % |
|---|---|
| Type 1: radial digital thumb + common digital to 1st web (→ radial index + ulnar thumb) | **69** |
| Type 2: common digital to thumb (→ radial + ulnar thumb) + proper radial index | 6 |
| Type 3: **trifurcation** of 3 proper digital nerves | 25 |

**Nerve vs artery** — **digits: nerve VOLAR to artery** ("it hurts before it bleeds"); **palm: nerve DORSAL** (superficial arch volar)

**Radial digital n. index (Lourie)** — at intersection of central index line with **proximal palmar crease**

**Dorsal branches** — proper digital n. at base of P1 → dorsal branch → supplies dorsum of distal phalanx (joins superficial radial)

## 3 Presentation

### Inspection & palpation

| Finding | Meaning |
|---|---|
| Erythema / white / blue-purple / black spots | Cellulitis / arterial insufficiency / venous congestion / melanoma |
| Trophic change (hair, sweat) | Sympathetic derangement |
| **Thenar atrophy** | **Median** (CTS) |
| **Interossei atrophy** | **Ulnar** (cubital tunnel, cervical radiculopathy) |
| Subcutaneous atrophy | Post-steroid injection |
| **Cascade sign** | Flexed fingers converge on **scaphoid tubercle**; non-convergence → **malrotation** |
| Warm / cool | Infection / vascular |

### Normal range of motion

| Joint | Arc |
|---|---|
| MCP | 0–85° |
| PIP | 0–110° |
| DIP | 0–65° |
| Wrist | 60° flexion · 60° extension · **50° radioulnar deviation arc** |

### Neurovascular exam

| Nerve | Motor test |
|---|---|
| Radial | **Thumb IP extension** against resistance |
| Median – recurrent motor | **Palmar abduction** of thumb |
| Median – AIN | Thumb IP + index DIP flexion (**OK sign**) |
| Ulnar | **Cross fingers** / abduct against resistance |

**Vascular** — radial + ulnar pulse, **Allen's**, capillary refill; **sensation** — 2-point discrimination

## 4 Diagnosis & Classification

### Special tests – wrist & DRUJ

| Test | Pathology |
|---|---|
| **Watson (scaphoid shift)** | **SL instability** — thumb on distal pole, radial→ulnar deviation; dorsal pain/**clunk** |
| **Reagan (LT ballottement)** | **LT instability** — pisotriquetral unit vs lunate; laxity + pain |
| **Kleinman shear** | LT instability |
| **Lichtman** | **Midcarpal instability** — axial load, radial→ulnar deviation; **clunk in ulnar deviation** |
| TFCC grind / **ulnocarpal abutment** | TFCC tear / ulnar impingement — ulnar deviation + axial load; pain, pop/click |
| **Fovea sign** | TFCC or **ulnotriquetral ligament split tear** |
| **ECU snap** | ECU instability |
| **Piano key** | **DRUJ instability** |

### Special tests – hand

| Test | Pathology / technique |
|---|---|
| **Grind** | **Thumb CMC** arthritis — axial load + rotate 1st MC; pain, crepitus, instability |
| **Finkelstein** | **De Quervain** — fist over thumb + ulnar deviation; pain 1st compartment |
| **FDP test** | Hold MCP + PIP extended → flex DIP |
| **FDS test** | Hold other fingers fully extended (blocks FDP) → tested finger flexes PIP |
| **Gamekeeper's** | **Thumb UCL** — radial stress in flexion + extension; **>30° laxity** or gross vs other side |
| **Tinel** (CTS) | Percuss distal palmar crease midline → median paraesthesia |
| **Phalen** (CTS) | Gravity wrist flexion, **max 2 min** |
| **Froment** (ulnar) | Paper key pinch → **thumb IP flexes** |
| **Wartenberg** (ulnar) | Fingers adducted + extended → **small finger drifts into abduction** |
| **Jeanne** (ulnar) | Key pinch → **thumb MCP hyperextension** |

### Intrinsic tightness test (Bunnell)

**Technique** — passively flex PIP with **MCP extended**, then with **MCP flexed**

**Intrinsic tightness (positive)** — **↓ PIP flexion with MCP extended** (lateral bands tensioned); PIP flexes easily with MCP flexed

**Extrinsic tightness** — ↓ PIP flexion with **MCP flexed**; flexes easily with MCP extended

## 5 Management

### Functional position of the hand (TO)

**Functional position (TO)** — **wrist 20° extension · MCP 70° flexion · fingers 10° flexion**\
✗ Wrong options: wrist neutral / flexed · MCP 20°

| Position of safe immobilisation (POSI) (TO) | Range |
|---|---|
| Wrist | **10–45° extension** |
| MCP | **60–90° flexion** |
| IP joints | Slight flexion → full extension |
| Thumb | **45° abduction** |

## X vs Y

| | **Intrinsic tightness** | **Extrinsic tightness** |
|---|---|---|
| PIP flexion with MCP **extended** | **↓** | Easy |
| PIP flexion with MCP **flexed** | Easy | **↓** |

## How it's asked

**"Positive intrinsic tightness test?"** → **↓ PIP flexion with MCP extended**

**"Numb both sides of thumb + radial index — nerve origin?"** → **one common branch off median nerve**\
✗ Wrong options: radial nerve

**"Digital nerve relation to artery in the finger?"** → **volar** (dorsal in palm)

**"Functional position of wrist and hand?"** → **wrist 20° extension, MCP 70° flexion, fingers 10° flexion** (TO)

**"Clunk in ulnar deviation under axial load?"** → **midcarpal instability (Lichtman)**

**"Piano key sign?"** → **DRUJ instability**

**"Gamekeeper's positive threshold?"** → **>30° laxity**
