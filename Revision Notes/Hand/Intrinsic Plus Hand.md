# Intrinsic Plus Hand

*Hand · 45 / 103*

## 1 Basics

**Definition** — **MCP flexion + PIP & DIP extension** from **spastic/contracted intrinsics** vs weak extrinsics

**Pathoanatomy** — tight interossei + lumbricals → MCP flexion, IP extension; **weak EDC** (no MCP extension balance); **weak FDS/FDP** (no IP flexion balance)

## 2 Mechanism

**Trauma** — crush, vascular injury, **compartment syndrome** (e.g. IVDU overdose); oedema/haematoma trapped by interosseous fascia → fibrosis

**Rheumatoid** — MCP dislocation + ulnar deviation → spastic intrinsics

**Neurologic** — **TBI, CP, CVA, Parkinson's**

**Other** — repetitive grip (carpenter), prolonged immobilisation, ischaemia, iatrogenic

## 3 Presentation

### Intrinsic tightness (Bunnell test) & posture

**Symptom** — difficulty **gripping large objects** (e.g. hammer)

**Posture** — MCP flexion, PIP + DIP extension

![Intrinsic plus posture](../../MCQ/attachments/q217357-illa-plus.jpg)

**Bunnell (intrinsic tightness) test** — **positive = ↓ passive PIP flexion with MCP extended** vs MCP flexed → **intrinsic tightness**

| Finding | Source of stiffness |
|---|---|
| PIP flexion **↓ with MCP extended** | **Intrinsic tightness** |
| PIP flexion **↓ with MCP flexed** (more with MCP extended) | **Extrinsic tightness** (extensor adhesions) |
| PIP motion unchanged by MCP position | **Joint capsule** contracture |

(✗ Wrong options: **Distractors** — **quadriga** (flexion lag adjacent to repaired FDP)) · **lumbrical plus** (paradoxical PIP extension on active flexion) · central slip rupture (boutonnière)

## 4 Diagnosis & Classification

**Diagnosis** — **clinical**; X-ray not required (normal)

## 5 Management

```
Intrinsic plus hand
├─ Mild → passive stretching / OT, orthoses, botulinum toxin
├─ Some intrinsic function (spastic) → proximal muscle slide
└─ Severe MCP + IP, fibrotic intrinsics → distal intrinsic release
```

**Proximal muscle slide** — **subperiosteal elevation of interossei** → lengthens MTU

**Distal intrinsic release** — resect intrinsic tendon **distal to transverse fibres** (spares MCP flexion)

**Release needed (Espiritu)** — extensor hood index 59%, middle 65%, ring 26%, small 33%

## X vs Y

| | **Intrinsic plus** | **Intrinsic minus (claw)** |
|---|---|---|
| MCP | **Flexion** | **Hyperextension** |
| PIP / DIP | **Extension** | **Flexion** |
| Imbalance | Spastic intrinsics, weak extrinsics | Strong extrinsics, deficient intrinsics |

## How it's asked

**"Passive PIP flexion possible with MCP flexed but not extended?"** → **intrinsic tightness (positive Bunnell)**\
✗ Wrong options: extrinsic tightness · quadriga · lumbrical plus

**"Crush injury, same Bunnell finding — stiffness from?"** → **intrinsic musculature**\
✗ Wrong options: PIP/MCP capsule

**"Posture of intrinsic plus hand after compartment syndrome?"** → **MCPJ flexion with PIPJ & DIPJ extension**\
✗ Wrong options: MCP extension + IP flexion = intrinsic minus
