# Apert Syndrome

*Hand · 3 / 103*

## 1 Basics

### FGFR2 mutation & clinical features

**Synonym** — **acrocephalosyndactyly type 1**: cranium + hands + feet

**Incidence** — rare; **1/80,000** live births

**Features** — **bilateral complex syndactyly** hands & feet (**index, middle, ring** most affected) · **symphalangism** · **craniosynostosis** → flat skull, broad forehead (**acrocephaly**) · **hypertelorism** · glenoid hypoplasia · radioulnar synostosis

**Cognition** — normal → moderately disabled

**Feet** — predictable dysmorphism + **progressive fusions** through skeletal maturity

### Genes & lab markers

| Gene | Condition |
|---|---|
| **FGFR2** | **Apert** (AD, most new cases **sporadic**) |
| ✗ Wrong option: FGFR3 | Achondroplasia |
| ✗ Wrong option: COL2A1 (chr 12) | SED congenita |
| ✗ Wrong option: SEDL | X-linked SED tarda |
| ✗ Wrong option: fibrillin | Marfan |
| ✗ Wrong option: SHH | Radial longitudinal deficiency (TAR, Holt-Oram, VACTERL) |
| ✗ Wrong option: PMP22 | Charcot-Marie-Tooth |
| ✗ Wrong option: COL1A1 | Osteogenesis imperfecta |

## 5 Management

```
Apert hand
├─ ~1 y → release BORDER digits
└─ ~1.5 y → digit reconstruction: central 3 → 2 digits
```

## How it's asked

**"Gene in Apert?"** → **FGFR2**\
✗ Wrong options: FGFR3, COL2A1, SEDL, fibrillin

**"Flat face + wide-set eyes + fused fingers"** → **Apert**\
✗ Wrong options: MED, cleidocranial, Noonan, achondroplasia

**"Infant rosebud hands — mutation?"** → **FGFR2**\
✗ Wrong options: SHH, PMP22, COL1A1

**"Digits most affected"** → **index, middle, ring**
