# Dog and Cat Bites

*Hand · 24 / 103*

## 1 Basics

### Epidemiology

**Frequency** — **dog (90%) > cat (10%) > human**; dog known to victim 90%

**Demographics** — ♂; **2–19 y**; **upper > lower extremity**

**Serious / fatal** — large aggressive dogs, small children, head & neck bites

### Mechanism by animal

| | **Dog** | **Cat** |
|---|---|---|
| Teeth | Blunt, powerful (>450 lb/in²) | **Small, sharp** → punctures **seal immediately** |
| Injury | Crush, avulsion, tear → **structural damage** (nerve, vessel, joint) | Penetrate **joints, bone, flexor sheath** → septic arthritis, OM |
| Infection risk | Lower | **Higher** |

### Pasteurella multocida & microbiology

**Polymicrobial** — most, with **>1 anaerobe**; median 5 isolates/culture

**Most common isolate (dog & cat)** — **Pasteurella** (gram-neg facultative anaerobic pleomorphic coccobacillus)

| | Dog | Cat |
|---|---|---|
| Pasteurella share | **50%** | **70–80%** (Orthobullets) · **75%** (OB) |
| Species | ***P. canis*** | ***P. multocida***, *P. septica* |
| Others | S. aureus, α-strep, Corynebacterium, Bacteroides, Moraxella, Neisseria | Similar |

**Pasteurella culture** — tell lab; special media; **~1 wk** to grow

**Cat Pasteurella** — intense pain + swelling within **48 h**

**Capnocytophaga canimorsus (dog)** — rare; fatal in **splenectomy/immunocompromised** (30–60% mortality); sepsis, endocarditis, meningitis, DIC

**Rabies** — rhabdovirus; dogs, raccoons, **bats**, foxes

### Infection risk factors

**Wound** — hand, foot, major joint; puncture or crush

**Host** — **delay >12 h**, **age >50**, steroids, **asplenia**, alcoholism, DM, vascular disease, oedema

## 3 Presentation

**History** — animal type, time since bite, comorbidities

**Exam** — puncture depth, crush, NV status, **joint penetration**; photograph wounds

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray indications** — crush, suspected fracture, **foreign body** (tooth)

**MRI** — not for flexor tenosynovitis (clinical Dx, delays treatment)

**Culture** — only if infected; **deep aerobic + anaerobic**\
✗ Wrong options: wound swab → skin flora

## 5 Management

```
Dog / cat bite
├─ All → irrigation (>150 mL saline, 18-19G) + tetanus ± rabies Ig/vaccine
├─ Cat / hand / deep / >8 h / immunocompromised / DM → AMOXICILLIN-CLAVULANATE
└─ Abscess / tenosynovitis / septic joint / FB / devitalised tissue → FORMAL I&D
```

**Antibiotics** — **amoxicillin/clavulanate** (covers P. multocida); alternatives cefuroxime, ceftriaxone

**Rabies prophylaxis** — any suspicion (unprovoked attack, bizarre behaviour) → **HDCV + human rabies Ig**; povidone-iodine irrigation if high risk

**Immobilise + elevate**

### Operative criteria

| Formal surgical debridement if |
|---|
| Crush / devitalised tissue, foreign body |
| Bites to **pulp, nail bed, flexor sheath, deep palmar spaces, joints** |
| **Tenosynovitis**, **septic arthritis**, abscess |

### Cat bite flexor tenosynovitis – drainage

**Cat bite + FTS (3 days, fever)** — **open I&D of flexor sheath** ± drain + pathogen-directed Abx

**Early / mild FTS** — catheter irrigation: incision **proximal to A1 + distal to A4**, 18G angiocatheter

**Severe / >1 wk / necrosis** — open debridement (mid-axial or Brunner) → amputation

**Nonop (splint, elevation, IV Abx)** — only if **<48 h** → I&D if no improvement in 12–24 h; **cat bites often need surgery**

**Avoid radial bursa irrigation for long finger** — long finger sheath **does not connect** to radial bursa

**Outcome** — stiffness possible despite prompt treatment

### Cat-scratch disease (Bartonella) – epitrochlear lymphadenitis

**Organism** — ***Bartonella henselae***

**Course** — self-limited **6–12 wk** untreated; papule/pustule at inoculation (25–60%) 3–10 d → lymphadenopathy 1–2 wk later

**Nodes** — **epitrochlear**, axillary, cervical, inguinal; tender, may suppurate → **soft-tissue tumour simulator** (medial elbow mass)

**Histology** — **lymphoid tissue + multiple necrotising granulomas** (only other granulomatous option = M. avium)

**Labs/imaging** — ↑ ESR/CRP; MRI mass + oedema in lymphatic drainage area; serum Bartonella test

**Diagnostic criteria (3 of 4)** — cat contact · positive CSD skin test · characteristic node lesions · negative workup for other lymphadenopathy

**Treatment** — **antibiotics** (azithromycin, ciprofloxacin, doxycycline)\
✗ Wrong options: chemo/radiation · observation

## X vs Y

| Organism | Association |
|---|---|
| **Pasteurella canis** | Dog bite |
| **Pasteurella multocida** | Cat bite |
| **Capnocytophaga** | Dog bite, asplenic → sepsis |
| **Bartonella henselae** | Cat scratch, epitrochlear node, granulomas |
| Borrelia burgdorferi | Lyme |
| Mycobacterium avium | Immunocompromised / HIV |

## How it's asked

**"Most common organism, dog & cat bites?"** → **Pasteurella**\
✗ Wrong options: Strep, Staph, Bacteroides, Moraxella

**"Cat bite 3 days ago, Kanavel signs, fever — next?"** → **open I&D of flexor sheath**\
✗ Wrong options: MRI · swab · radial bursa catheter

**"9-y medial elbow mass, biopsy granulomas — next?"** → **antibiotics** (cat-scratch disease)

**"Epitrochlear mass, necrotising granulomas — organism?"** → **Bartonella henselae**

**"Antibiotic of choice for bite?"** → **amoxicillin-clavulanate**
