# Thumb Hypoplasia

*Hand · 92 / 103*

## 1 Basics

**Incidence** — **1/100,000** live births; ♂ = ♀

**Laterality** — **bilateral ~60%**; right > left

**Association** — often partial/complete **absence of radius**

**Embryology** — AER, progress zone, **FGF** signalling abnormalities

### Associated syndromes & lab markers

**Associated anomalies** — **>80%**: **VACTERL**, **Holt-Oram**, **TAR**, **Fanconi anaemia**, Cornelia de Lange, Okihiro; radial aplasia, thrombocytopenia, renal/cardiac/CNS

**Work-up** — cardiac (auscultation, **echo**), renal + abdominal **US**

**Labs** — **FBC + peripheral smear** → Fanconi

**Chromosomal challenge (breakage) test** — **detects Fanconi anaemia before marrow failure**

## 3 Presentation

**Exam** — thenar hypoplasia, absent skin creases (muscle/tendon anomaly), excessive MCP abduction, **UCL laxity**, **web-space tightness**

**Pollex abductus** — **FPL** attaches to normal insertion **and extensor tendon**; frequent in **type IIIA**

**Also** — variable EPL insertion

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — **bilateral hand, wrist and forearm** films → musculotendinous vs osseous deficiency

### Blauth classification

| Type | Description | Treatment | Image |
|---|---|---|---|
| I | **Minor**: all components present, small | None (opponensplasty if ↓ abduction) | ![Type I](../../Orthobullets/attachments/ob6083-type-1.jpg) |
| II | All bones present; **MCP UCL instability**, thenar hypoplasia, **adduction contracture** | MCP stabilisation + 1st web release + opponensplasty | ![Type II](../../Orthobullets/attachments/ob6083-thumb-hypoplasia-2.jpg) |
| **IIIA** | Musculotendinous + osseous deficiency; proximal ⅓ MC aplasia, **CMC intact**; no active MCP/IP motion | **Reconstruct** (as II) | ![Type IIIA](../../Orthobullets/attachments/ob6083-thumb-hypoplasia-3.jpg) |
| **IIIB** | Basal (proximal ⅔) MC aplasia, **deficient CMC**; no active MCP/IP motion | **Amputate + pollicise** | |
| IV | **Floating thumb** (skin + NV pedicle only) | Amputate + pollicise | ![Type IV](../../Orthobullets/attachments/ob6083-thumb-hypoplasia-4.jpg) |
| V | **Absent thumb** | Pollicise | ![Type V](../../Orthobullets/attachments/ob6083-thumb-hypoplasia-5.jpg) |

**IIIA vs IIIB** — **CMC joint stability**\
✗ Wrong options: osseous completeness · musculotendinous integrity · MCP stability · EPL (all deficient in both)

## 5 Management

```
Hypoplastic thumb — CMC joint stable?
├─ Yes (I, II, IIIA) → reconstruct
│      ├─ I, adequate abduction → observe
│      ├─ I, ↓ abduction → opponensplasty
│      └─ II / IIIA → web release + opponensplasty + MCP stabilisation
└─ No (IIIB, IV, V) → thumb amputation + index pollicisation
```

### Reconstruction vs pollicisation – CMC joint stability

**Deciding factor** — **CMC stability** (resists grasp/pinch; full circumduction arc)\
✗ Wrong options: contralateral thumb · thenar function · EPL · MCP stability · web contracture · absent IP joint

**Antiposition** — abducted, slightly extended, pronated

| Procedure | Technique |
|---|---|
| **Opponensplasty** | **FDS** or **ADM** · Blauth II–IIIA: **FDS ring** transfer or **Huber (ADM) opponensplasty** (TO) |
| 1st web deepening | **Z-plasty** |
| MCP stabilisation | **Fusion** · UCL reconstruction with **FDS** · UCL with free graft |
| **Pollicisation** | Index on NV bundles; detach 1st dorsal + palmar interossei; shorten by removing **index MC + physis**; stabilise index MCP; rebalance tendons; plan skin to avoid grafts · **12–18 mo** · **index MP → thumb CMC** · EIP → EPL · EDC → APL · 1st DI → APB · 1st PI → adductor pollicis (TO) |

**9-month-old, basal MC aplasia, deficient CMC, no MCP/IP motion** → **pollicisation**\
✗ Wrong options: observation · opposition transfer alone · web release + transfer + MCP fusion · UCL reconstruction

## How it's asked

**"Most important variable, reconstruct vs ablate?"** → **CMC joint stability**

**"Key difference Blauth IIIA vs IIIB?"** → **CMC joint stability**

**"Adopted 3-year-old with hypoplastic thumb — deciding factor?"** → **CMC stability**

**"Deficient CMC, absent MCP/IP motion — definitive treatment?"** → **pollicisation**

**"Detect Fanconi before marrow failure?"** → **chromosomal breakage (challenge) test**

**"Pollex abductus?"** → **FPL inserts normally + into extensor; type IIIA**
