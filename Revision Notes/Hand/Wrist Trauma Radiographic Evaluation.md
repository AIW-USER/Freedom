# Wrist Trauma Radiographic Evaluation

*Hand · 103 / 103*

## 1 Basics

### Carpal ossification sequence

**Order** — counterclockwise (right hand) from capitate: **capitate → hamate → triquetrum → lunate → scaphoid → trapezium → trapezoid → pisiform**

**First** — **capitate** (largest carpal bone), **1–3 months**, often with hamate

**Last** — **pisiform** (only **sesamoid** carpal bone)

| Bone | Ossifies (Orthobullets table) | OB explanation | Fusion |
|---|---|---|---|
| **Capitate** | **1 y** | **1–3 mo** | 14–16 y |
| Hamate | 2 y | shortly after capitate | 14–16 y |
| Triquetrum | 3 y | — | 14–16 y |
| Lunate (Kienböck) | 4 y | ~5 y | 14–16 y |
| Scaphoid (Preiser) | 5 y | ~6 y | 14–16 y |
| Trapezium (thumb MC base) | 5–6 y | ~6 y | 14–16 y |
| Trapezoid | 6–7 y | — | 14–16 y |
| **Pisiform** | **9–10 y** | ~12 y | 14–16 y |

**Conflict** — ages differ between sources (above) — read the options; order is the same

## 4 Diagnosis & Classification

### Amsterdam wrist rules (X-ray criteria)

| X-ray if any | Suspected distal radius # | Suspected carpal # |
|---|---|---|
| ↑ age, swelling, deformity, TTP distal radius | Pain on **palmarflexion**, **supination**, painful **radioulnar ballottement**; pain on ulnar deviation = ↓ risk | **Male**, **snuffbox swelling**, pain on **radial deviation**; painful thumb axial compression = ↓ risk |

### Key radiology findings – views

| View | Position / beam | Best for |
|---|---|---|
| **AP / PA** | Shoulder abd 90°, elbow 90°; supinated (AP) / pronated (PA) | **Carpal joints: AP > PA**; DRF |
| **Lateral** | **Shoulder adducted**, elbow 90°, forearm neutral; 10° cephalad | Alignment, carpal instability; adequate = pisiform volar cortex within central 1/3 of volar scaphoid |
| **IR oblique** (pronated 45°) | | **Radial carpus**; **best for scaphoid waist + distal pole** |
| **ER oblique** (supinated 45°) | | **Ulnar carpus**; **pisiform, hamate body** |
| Ulnar deviation | Aim at scaphoid | Scaphoid #, lateral wrist; scaphoid/lunate **extend** |
| Radial deviation | | Medial wrist, palmar triquetral #; scaphoid/lunate **flex** |
| **Carpal tunnel** | Wrist extended; 2.5 cm distal to MC3 base, 25–30° cephalad | **Hook of hamate (best)**, pisiform, trapezium |
| Carpal bridge | 4 cm proximal to wrist bend, 45° caudad | Pisiform, trapezium, hamate hook |
| **Clenched fist** | Supinated, ulnar dev, fist (capitate driven proximally); bilateral | **SL injury** |
| **Scaphoid view** | **30° extension + 20° ulnar deviation** | Scaphoid # |
| **Clements-Nakayama** | Pronated 45°, ulnar dev; at snuffbox (20° cephalad if can't deviate) | **Trapezium #** |

**Why adduct shoulder for lateral** — ulna does not rotate with pronation/supination

### Key radiology findings – signs

| Sign | View | Meaning |
|---|---|---|
| **Pronator quadratus fat pad** | Lateral | Wrist effusion (bowed PQ fascia) |
| Scaphoid fat pad | Ulnar deviation | Effusion / scaphoid # |
| **Piece-of-pie** (triangular lunate) | PA | Lunate dislocation |
| **Spilled teacup** | Lateral | **Stage IV**: lunate volar to radius |
| **Pooping duck** | Lateral / IR oblique | **Dorsal triquetral cortical #** |
| **Absent "eye" (cortical ring)** + sclerosis | PA | **Hook of hamate #** |

### Wrist MRI technique & normal variants (TO)

**Positioning (TO)** — prone **"superman"** position, hand overhead at magnet isocentre, **dedicated wrist coil** (head coil substitute; never body coil) · small FOV, high resolution

**Planning (TO)** — axials ⊥ forearm · **coronals along the RADIUS axis** · sagittals ⊥ coronals (most pulsation artefact) · slices **3 mm**, 0.3–0.5 mm gap

| Sequence (TO) | Use |
|---|---|
| **Coronal PDFS** | **Single most useful**: oedema, fluid, **TFCC + SL + LT in one image** |
| Coronal GRE | Trabeculae, cartilage |
| Coronal T1 | Marrow fat (AVN, sclerosis), chip fractures hidden by oedema |
| Axial T1/T2 + FS | Tendons, median + ulnar nn., carpal tunnel |
| Sagittal FS | Axes: radius, lunate, capitate, MC3 collinear |
| T2 mapping (3 T) | Early cartilage dehydration (early lunatomalacia) |

**Normal, not pathology (TO)** — **heterogeneous signal at ligamentum subcruentum** · **multiple APL slips** · thin radial cartilage beside TFCC disc · fovea subosseous cysts · striated SLIL

**Measure ulnar variance on X-ray, not MRI (TO)** — changes slice to slice · SL angle easier on lateral X-ray

**Radial styloid (TO)** — high inclination / elongation (post-Colles) → **radioscaphoid arthritis** · **carpal boss** = bony hypertrophy at 3rd CMC (boxers)

### Scaphoid fracture

| Location | % |
|---|---|
| **Waist** | **65** |
| Proximal 1/3 | 25 |
| Distal 1/3 | 10 (**commonest in children**) |

**PA** — proximal pole; waist/distal pole distorted (scaphoid flexed)

**Negative X-ray + high suspicion** — thumb spica, **repeat X-ray 14–21 d** (re-evaluate 12–21 d)

| ORIF criteria (instability) | Threshold |
|---|---|
| Displacement | **>1 mm** any view |
| **Humpback** | **15°** |
| SL angle | **>60°** |
| Radiolunate angle (DISI) | **>15°** |
| **Intrascaphoid angle** | **>35°** |
| Other | Proximal pole, perilunate, comminuted, vertical/oblique unstable, non-displaced waist (listed) |

### Lunate / perilunate dislocation

**PA** — **break in Gilula's arc**, lunate–capitate overlap, **piece-of-pie**

**Lateral** — **loss of radius–lunate–capitate colinearity**; stage III capitate dorsal to lunate; **stage IV spilled teacup**; SL angle **>70°**

| Timing | Treatment |
|---|---|
| Acute **<8 wk** | Emergent closed reduction/splint → **open reduction, ligament repair, fixation ± CTR** (✗ Wrong options: nonop) |
| Chronic **>8 wk** | **PRC** |
| Chronic + degenerative | **Total wrist arthrodesis** |

### Other carpal fractures

| Fracture | Best view | Nonop | Surgery |
|---|---|---|---|
| Triquetrum | Lateral / IR oblique (dorsal); radial dev (palmar) | Stable dorsal/palmar cortical, undisplaced body | ORIF if unstable / displaced body |
| **Hook of hamate** | **Carpal tunnel** | Most | **Excise chronic nonunion** |
| Hamate body | **ER oblique** | Extra-articular undisplaced (rare) | ORIF displaced / intra-articular |
| Pisiform | **ER oblique or carpal tunnel** | Most | **Pisiformectomy**: displaced symptomatic, painful nonunion |
| Trapezium | Clements-Nakayama, carpal tunnel | | |

### Normal variants (accessory ossicles)

| Ossicle | Location |
|---|---|
| Lunula | In TFCC between ulnar styloid + triquetrum |
| Os triangulare | Ulnar styloid + lunate + triquetrum |
| **Os hamuli proprium** | Unfused hook of hamate ossification centre (mimics #) |
| Os centrale carpi | Dorsal, scaphoid + trapezoid + capitate |
| Os epilunate | Dorsal lunocapitate joint |
| Os styloideum | Between MC2 & MC3 bases |
| Os paratrapezium | Radius side / base of MC1 |
| Os radiostyloideum | Near radial styloid, lateral to mid-scaphoid |

## How it's asked

**"Single most useful wrist MRI sequence?"** → **coronal proton-density fat-suppressed** (TO)

**"Ossification centre appears at 1–3 months?"** → **largest carpal bone = capitate**\
✗ Wrong options: scaphoid/Preiser, lunate/Kienböck, trapezium, pisiform

**"Last carpal bone to ossify?"** → **pisiform**

**"Best view for hook of hamate?"** → **carpal tunnel view**

**"Best view for scaphoid waist + distal pole?"** → **IR (pronated) oblique**

**"Scaphoid view position?"** → **30° extension + 20° ulnar deviation**

**"Suspected scaphoid #, normal X-ray?"** → **thumb spica, repeat X-ray 14–21 d**

**"Stage IV perilunate lateral sign?"** → **spilled teacup**

**"Pooping duck sign?"** → **dorsal triquetral cortical fracture**
