# Intersection Syndrome

*Hand · 43 / 103*

## 1 Basics

### Epidemiology & anatomy

**Definition** — inflammation where **1st compartment (APL, EPB) muscle bellies cross over 2nd compartment (ECRL, ECRB) tendons**; aka crossover tendinitis; = stenosing tenosynovitis of **2nd compartment**

**Site** — dorsoradial forearm **~5 cm (4–6) proximal to wrist**

**Demographics** — rare; ♂ = ♀ (Orthobullets) · **more in men, dominant hand, younger, shorter symptoms vs DQT** (Sato)

**Risk** — **rowing**, canoeing, skiing, horse riding, weight lifting, racket sports

| Compartment | Contents | Eponymous condition |
|---|---|---|
| 1 | APL, EPB | **De Quervain's** |
| **2** | **ECRL, ECRB** | **Intersection syndrome** |
| 3 | EPL | — |
| 4 | EIP, EDC | — |
| 5 | EDM | Vaughan-Jackson |
| 6 | ECU | Snapping ECU |

## 2 Mechanism

**Mechanism** — **repetitive wrist extension** → friction at crossover → tenosynovitis

## 3 Presentation

**Symptoms** — dorsal forearm/radial wrist pain, worse with pronation–supination

**Signs** — tenderness dorsoradial forearm ~5 cm proximal; **crepitus / squeak / popping** with **resisted wrist extension + thumb extension**

## 4 Diagnosis & Classification

**Diagnosis** — **clinical**

### Key radiology findings

**X-ray** — not required (unremarkable)

**MRI** — only if unclear; fluid-sensitive (STIR, FS PD, T2) → **peritendinous oedema around 1st + 2nd compartments** (most characteristic); tendinosis, muscle oedema, loss of comma shape

![MRI: peritendinous fluid at the intersection](../../Orthobullets/attachments/ob6032-intersec.jpg)

**Differentials** — De Quervain's, Wartenberg's

## 5 Management

```
Intersection syndrome
├─ First line → rest + wrist splint + steroid into 2nd compartment
└─ Recalcitrant → surgical release + debridement of 2nd compartment
```

### Second dorsal compartment (ECRL/ECRB) – injection & release

**Injection** — into **2nd dorsal compartment (ECRL + ECRB)**\
✗ Wrong options: 1st = DQT

**Surgery** — rare; release **2nd compartment** ~**6 cm proximal to radial styloid** (Orthobullets) · **5–6 cm proximal to wrist** (OB) → decompresses **ECRL (inserts base 2nd MC)**

## X vs Y

| | **Intersection syndrome** | **De Quervain's** |
|---|---|---|
| Compartment | **2nd (ECRL, ECRB)** | **1st (APL, EPB)** |
| Site | **~5 cm proximal** to wrist, dorsoradial forearm | Radial styloid |
| Patient | Younger, men, dominant hand, rowers | ♀ >40, **pregnant / lactating / peripartum** |
| Sign | Crepitus, resisted wrist + thumb extension | Finkelstein |
| Injection | 2nd compartment | 1st compartment |

## How it's asked

**"Rower, tender 5 cm proximal to wrist, inject which compartment?"** → **ECRL + ECRB**\
✗ Wrong options: APL/EPB · EPL

**"Compartment + structures affected?"** → **compartment 2; ECRB + ECRL tendons**\
✗ Wrong options: muscle bellies · compartment 1

**"Release decompresses tendon inserting on?"** → **base of 2nd MC (ECRL)**\
✗ Wrong options: thumb P1 base = EPB · P2 base = EPL · 1st MC = APL · index hood = EIP

**"Peripartum woman with radial wrist pain?"** → **De Quervain's**\
✗ Wrong options: intersection
