# Kienbock's Disease

*Hand · 47 / 103*

## 1 Basics

### Definition – lunate osteonecrosis

**Definition** — **avascular necrosis of the lunate** → progressive wrist pain, abnormal carpal motion

**Osteochondrosis, crushing type (TO)** — Kienböck = **lunate**\
✗ Wrong options: scaphoid, radial head, capitulum

| Osteochondrosis (TO) | Site |
|---|---|
| Köhler | Navicular |
| **Kienböck** | **Lunate** |
| Panner | Capitulum |
| Scheuermann | Vertebral ring epiphysis |
| Calvé | Vertebral central nucleus |
| Thiemann | Phalangeal epiphyses |
| Freiberg | Metatarsal heads |
| Iselin *(traction)* | 5th MT base |
| Osgood-Schlatter *(traction)* | Tibial tuberosity |
| Sever *(traction)* | Calcaneal apophysis |
| Sinding-Larsen-Johansson *(traction)* | Inferior pole patella |
| OCD *(splitting)* | — |

**Typical patient** — **♂ 20–40 y**, often **manual labourer** (TO); history of trauma; **dominant** hand

**Lunate ossification** — **2–4 y**

### Aetiology & risk factors (ulnar negative variance, vascular pattern)

**Multifactorial** — repetitive microtrauma + altered biomechanics + ↑ intraosseous pressure + ulnar negative variance → **"all of the above"**

**Ulnar negative variance** — ↑ **radiolunate contact stress**; **most predominant risk factor** (TO); up to **78%** of cases (TO)

**↓ Radial inclination** — ↑ radiolunate pressure; risk ↑ as inclination ↓ → **not increased radial inclination** (TO)

**Lunate morphology (TO)** — small lunate · **type I (triangular, no medial facet)** = weaker trabeculae → risk; type II/III square

**Vascular (TO)** — **fewer penetrating arteries** (esp. volar from palmar radiocarpal arch) → ↑ risk; sparse intraosseous collaterals

**Venous congestion** — ↑ **intraosseous pressure (>40 mmHg vs capitate)** · **wrist extension raises intraosseous pressure (\~40 mmHg) → avoid extension** (TO)

**Acute lunate fracture (TO)** — **no correlation** with later Kienböck · MRI: transient **focal** oedema vs Kienböck diffuse, progressive

**Medical conditions** — scleroderma, sickle cell, SLE, corticosteroids

**NOT a cause** — **increased carpal height** (carpal height ↓ in Kienböck)

**Ulnar variance associations** — **negative** → Kienböck + ulnar impingement · **positive** → TFCC tear, ulnar abutment, SL dissociation, triquetral arthrosis

**Ulnar variance axis (TO)** — measure using the **radial shaft**

**Measuring ulnar variance** — PA, **shoulder 90° abduction, elbow 90°**, neutral rotation; **more positive in pronation**, negative in supination

## 3 Presentation

**Symptoms** — **dorsal wrist pain**, **activity-related** / worse with grip loading; insidious, usually no trauma event (TO)

**Exam** — ± swelling, **radiocarpal tenderness**, ↓ flexion–extension arc, **↓ grip strength**

## 4 Diagnosis & Classification

### Key radiology findings

| Modality | Fact |
|---|---|
| X-ray (AP, lat, oblique) | Normal (stage I) → **sclerosis** (II) → **collapse** (III) → carpal OA (IV) |
| **MRI** | **Best for early disease / IOC** (TO); **↓ T1 signal**; rules out ulnar impaction |
| **CT** | **Most sensitive for staging / early collapse**; extent of necrosis, trabecular destruction, geometry |
| ✗ Wrong option: bone scan | Non-specific |
| ✗ Wrong option: US, angiography | Not used |
| ✗ Wrong option: clenched-fist AP | SL interval |

**Stage IIIA → IIIB** — **radioscaphoid angle >60°** (fixed scaphoid flexion) · ↓ **carpal height ratio (CH / MC3 height)** = capitate migration → IIIB (TO)

**Earliest X-ray sign (TO)** — ↑ **lunate density (sclerosis)**

**MRI T1 pattern (TO)** — **uniform ↓ = Kienböck** · **focal ↓ → think ulnar impaction, intraosseous ganglion, enchondroma** · MRI = most sensitive (TO)

![Kienböck MRI](../../Orthobullets/attachments/ob6050-keinbocksmri-figure3.jpg)

| Stage | Findings | Treatment | Image |
|---|---|---|---|

| **II** | **Lunate sclerosis**, normal shape | **Ulnar −ve → joint levelling** · **ulnar neutral/+ → radial wedge osteotomy or STT fusion** · core decompression · revascularisation | ![II](../../Orthobullets/attachments/ob6050-stage-2.jpg) |
| **IIIA** | **Collapse**, no scaphoid rotation, carpal height preserved | **Same as II** | ![IIIA](../../Orthobullets/attachments/ob6050-stage-3a.jpg) |

**History (TO)** — first classification by **Stahl**, modified by Lichtman

**Lichtman** — X-ray + MRI based; low interobserver variability (TO)

### Articular grading for advanced disease (TO, Bain–Begg)

| Grade | Nonfunctional surfaces | Recommendation |
|---|---|---|
| 0 | None | Joint levelling · forage ± graft · VBG |
| 1 | Proximal lunate | RSL fusion · PRC · osteochondral graft |
| 2a | Proximal lunate + lunate facet radius | **RSL fusion** |
| 2b | Proximal + distal lunate | PRC · lunate replacement · capitate lengthening |
| 3 | 3 surfaces (capitate preserved) | Hemiarthroplasty (SC fusion if radial column intact) |
| 4 | All 4 | Total wrist fusion / TWA (SC fusion if radial column intact) |

**Synovectomy** — all patients (TO)

## 5 Management

```
Kienböck – by stage
├─ I → immobilisation + NSAIDs
├─ II / IIIA → lunate unloading or revascularisation
│      ├─ ulnar NEGATIVE → radial shortening (± VBG)
│      └─ ulnar neutral / positive → radial wedge osteotomy · STT fusion · capitate shortening
├─ IIIB → PRC · STT fusion · SC fusion
└─ IV → wrist fusion · PRC · limited intercarpal fusion
```

```
Practical approach (TO)
├─ Age <15 → nonop >12 mo → epiphysiodesis
├─ Age >70 → nonop 6–12 mo → arthroscopic debridement
├─ Lunate only (B) → unloading (−ve UV radial / +ve UV capitate shortening) or reconstruction (VBG / osteochondral graft)
└─ Wrist affected (C) → SC fusion · PRC · RSL fusion · advanced OA → wrist fusion
```

**Conservative care (TO)** — **no role after diagnosis** (TO) · stage I immobilisation + NSAIDs (Orthobullets) — read the options

**Treatment categories (TO)** — core decompression · joint levelling / unloading · revascularisation (distal radius / pronator quadratus VBG) · salvage (carpectomy, partial fusion)

### Early stages – radial shortening, core decompression & vascularised bone graft

**Stage II, ulnar −ve (TO)** — **VBG + radial shortening**\
✗ Wrong options: STT fusion · PRC · VBG + radial wedge

**Radial shortening osteotomy** — **treatment of choice** stage II ulnar minus; **extra-articular**; more evidence than ulnar lengthening

**Radial shortening amount (TO)** — **2–3 mm only** · **first 2 mm → 90% load reduction**; 3 mm no extra benefit · oblique cut → 2 mm wafer, transverse → 3 mm · **diaphyseal** osteotomy compresses better than metaphyseal

**Ulnar lengthening (TO)** — distal ⅓ ulna · complications **ulnocarpal impingement, nonunion**

**Ulnar-positive variance, stage I–IIIA (TO)** — radial **and** ulnar shortening **contraindicated** → **capitate shortening + capitohamate fusion** · do not release 4th extensor compartment · excise hamate tip

**Radial closing wedge osteotomy (TO)** — for abnormal radial inclination · shifts load **radiolunate → radioscaphoid** · osteotomy **proximal to DRUJ**

**Failed immobilisation stage II** — → **radial shortening**\
✗ Wrong options: continue cast · PRC · STT · fusion

**DRUJ (Tolat type II)** — remodelling after shortening **without arthritis** → not a contraindication

**Ulnar shortening** — ✗ wrong option: **worsens** (↑ radiolunate force)

**Distal radius core decompression** — stage I–IIIA; **local vascular healing response**

**Not Kienböck options** — TFCC repair, SL reconstruction, lunate chondroplasty; lunate excision / implant **rarely used**

**Limited intercarpal fusion** — before total wrist arthrodesis

**Partial fusions** — STT, **capitate shortening ± capitohamate**, SC → stage II (neutral/+), IIIA/IIIB; must address **DISI**

**VBG** — stage I–IIIB; best in stage III; long-term data lacking

**VBG options** — pisiform · distal radius on **pronator quadratus** pedicle · dorsal metacarpal artery branches · **4+5 ECA**

**VBG pedicles (TO)** — **1,2-ICSRA short pedicle** · 2,3-ICSRA good arc · **4,5 = best** (large calibre, arc) · sources: 2nd / 3rd MC base, dorsal distal radius

**4+5 ECA advantage** — **largest arc of rotation** · large diameter · **ulnar location** (✗ Wrong options: radial) · **dorsal** approach (✗ Wrong options: volar) · antegrade flow not unique

**After VBG** — **2–3 mo immobilisation / unloading** (STT/SC pinning or ex-fix) required

![4+5 ECA graft](../../Orthobullets/attachments/ob6050-surgical-technique-for-4-5-eca-graft.jpg)

### Radiolunate contact stress

| Procedure | ↓ Radiolunate stress |
|---|---|
| STT fusion | 3% |
| SC fusion | 12% |
| Capitohamate fusion | 0% |
| **Ulnar lengthening 4 mm** | **45%** |
| **Radial shortening 4 mm** | **45%** |
| Capitate shortening + CH fusion | **66%** (but ↑ radioscaphoid 26%) · **60%** (TO) — read the options |

### Advanced disease – STT fusion/pinning

**Temporary STT pinning** — **adolescent** with Kienböck + progressive pain → ↓ radiolunate, ↑ radioscaphoid load\
✗ Wrong options: radial club hand, scaphoid fracture, hypoplastic thumb, gymnast's wrist

**IIIB** — PRC (also lunate excision + STT/SC fusion); STT superior to PRC in some studies

**Salvage IIIB (TO)** — **SC fusion better than STT fusion** (preferred) · PRC · lunate arthroplasty: **pyrocarbon preferred over silastic** · wrist fusion for advanced collapse

**Stage IV (TO)** — interposition arthroplasty or wrist fusion

**IV** — wrist fusion (remove arthritic joint) ; TWA long-term data lacking

![STT pinning](../../Orthobullets/attachments/ob6050-stt-pinning.jpg)

### Paediatric Kienböck – conservative care

**Skeletally immature, stage I** — **short arm cast + NSAIDs (4 wk)**\
✗ Wrong options: core decompression + ulnar shortening · PRC · STT pinning/fusion

**Nonop outcome (adult)** — majority progress → surgery

### Other carpal osteonecrosis (capitate) – salvage

**Carpal AVN frequency** — scaphoid (trauma), lunate (idiopathic) > **capitate** > hamate > trapezium > trapezoid > triquetrum > pisiform

| Eponym | Bone |
|---|---|
| Kienböck | Lunate |
| **Preiser** | **Scaphoid** |
| Köhler | Navicular |

**Capitate AVN causes** — trauma, **retrograde palmar-dominant supply** (like scaphoid), hypermobility / **ligamentous laxity**, steroids, vibration, repetitive extension

**Capitate AVN treatment** — cast first

| Group | Treatment |
|---|---|
| Pre-collapse, no OA (young) | Decompression / **VBG** (4+5 ECA local; **free MFC flap**) → best preserves vascularity & anatomy |
| Collapse, no OA | Proximal pole excision + interposition · **pyrocarbon** resurfacing · graft · fusion |
| Collapse + OA | **Midcarpal fusion** (salvage), SCL / 4-corner fusion |

**Not for capitate AVN** — **PRC** (radius articulates with dysvascular capitate) · TWA · radial wedge osteotomy · curettage + non-vascularised graft · implant arthroplasty in teen

**Carpal coalition** — **LT** commonest (1%, 60% bilateral; West African descent)
