# Nail Bed Injury

*Hand · 58 / 103*

## 1 Basics

### Epidemiology

**Frequency** — fingertip injuries = **most common hand injury in ED**; **♂:♀ 3:1**

**Mechanism** — crush between objects, closing door, saw, snowblower, hammer

**Associated** — **DIP fracture/dislocation**, **distal phalanx fracture**

### Anatomy

| Structure | Definition |
|---|---|
| Perionychium | Nail + nail bed + surrounding skin |
| Paronychium | Lateral nail folds |
| Hyponychium | Skin distal + palmar to nail |
| Eponychium | Dorsal nail fold (proximal) |
| Lunula | White proximal nail |
| **Sterile matrix** | **Distal to lunula**, adheres to nail |
| **Germinal matrix** | **Proximal to sterile**; **most nail production**; extensor insertion **1.2–1.4 mm proximal** |

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — **AP, lateral, oblique** of finger → rule out **distal phalanx fracture**; child: **physeal separation (Seymour)**

### Injury types

| Type | Finding | Treatment |
|---|---|---|
| **Subungual haematoma <50%** | Crush; blood under nail | **Trephination** (sterile needle / electrocautery) |
| **Subungual haematoma >50%** | | **Nail removal, I&D, nail bed repair** |
| **Laceration** | Nail intact + haematoma >50% | Nail removal + repair; tetanus + antibiotics |
| **Avulsion, minimal matrix loss** | Higher energy; ± DP fracture | Repair ± fracture fixation (**reduce fracture**); tetanus + antibiotics |
| **Avulsion/crush, significant matrix loss** | | Repair + **STSG or nail matrix graft** (adjacent injured finger or **2nd toe**) ± fixation |

![Subungual haematoma](../../Orthobullets/attachments/ob6109-subungual-hematoma.jpg)

## 5 Management

```
Nail bed injury
├─ Subungual haematoma <50% → trephination
├─ Haematoma >50% / laceration → nail removal + nail bed repair
└─ Avulsion ± DP fracture → repair + reduction ± fixation
       └─ significant matrix loss → matrix graft (toe / adjacent finger)
```

### Repair technique – tissue adhesive & Seymour fracture

**Nail** — remove → **soak in Betadine** during repair

**Suture** — **6-0 or smaller absorbable**

**Dermabond (2-octylcyanoacrylate)** — RCT (Strauss, level 1): **only advantage = faster procedure**; no better cosmesis, function, pain, infection (all equal)

**Splint eponychial fold** — original nail, aluminium, or non-adherent gauze (prevents fold adhesion)

**Seymour fracture** — child, nail torn **transversely beneath eponychium** + **juxta-epiphyseal distal phalanx physeal separation** (nail bed trapped) → **I&D + physeal reduction + nail bed repair + immobilisation**\
✗ Wrong options: splint alone · home Betadine soaks · I&D + splint without reduction · pinning first

**Early repair** — superior to secondary correction (91% good–excellent in children); outcome depends on **germinal matrix** injury

## 6 Complications

| Complication | Cause | Treatment |
|---|---|---|
| **Hook nail** | Matrix advanced for coverage **without bony support** | **Remove nail + trim matrix to level of bone** |
| **Split nail** | **Matrix scarring** | **Excise scar + replace matrix** (± graft) |

![Hook nail](../../Orthobullets/attachments/ob6109-hook-nail.jpg)

## How it's asked

**"Dermabond vs suture for nail bed — advantage?"** → **faster procedure**\
✗ Wrong options: cosmesis · function · pain · infection

**"Child, nail torn under eponychium + DP physeal fracture — next step?"** → **I&D, reduction, nail bed repair, immobilisation** (Seymour)

**"Subungual haematoma <50%, nail intact?"** → **trephination**

**"Hook nail treatment?"** → **trim matrix to level of bone**

**"Split nail cause?"** → **matrix scar** → excise + matrix graft
