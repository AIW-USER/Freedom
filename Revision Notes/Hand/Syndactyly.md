# Syndactyly

*Hand · 87 / 103*

## 1 Basics

### Epidemiology – most common web

**Definition** — **most common congenital limb malformation**; adjacent digits webbed (Greek *syn* = together, *dactylos* = digit) (TO)

**Incidence** — **1 in 2,000–2,500**; ♂ > ♀; Caucasians > African Americans

| Web | % |
|---|---|
| **Long–ring** | **50** (most common (TO)) |
| Ring–small | 30 |
| Index–long | 15 |
| Thumb–index | 5 |

### Genes & associations

**Pathophysiology** — **failure of apoptosis** to separate digits

**Genetics** — pure syndactyly **AD**, reduced penetrance, variable expression; **family history 10–40%**

**Associations** — **acrosyndactyly** (constriction ring / Streeter dysplasia) · **Poland** · **Apert** · **Carpenter** (acrocephalopolysyndactyly)

**Acrosyndactyly** — digits fused **distally**, proximal **fenestrations**

|---|---|

## 5 Management

```
Syndactyly
├─ Acrosyndactyly → release in NEONATAL period
├─ Border digits (ring–small, thumb–index) / multiple fusions → release ~6 mo
│      (unequal lengths → tethering, angulation, rotation, shortening)
├─ Central (long–ring) → ~1 y / 12–18 mo (Orthobullets: up to 2 y)
└─ Simple toe syndactyly, no functional issue → nonop
```

### Timing & technique

**Timing — conflict** — **~1 y** (Orthobullets) · **12–18 mo**; delay **>18 mo ↓ scar contracture & web creep** (TO)

**Multiple digits** — **two stages, one side of a digit at a time** → protect digital artery

**Sequence** — release **digits of unequal length first** (border); middle–ring **6 mo later**; all **before school age**

**Bilateral** — simultaneous if **<18 mo**; staged if >18 mo

**Goals (TO)** — new **paronychial nail folds** · interdigital commissure skin · **new web space**

**Incisions** — **interdigitating zigzag flaps** (Cronin, dorsal + volar) → avoid longitudinal scar · **dorsal fasciocutaneous flap** for web · modified double reverse Z-plasty (TO)

**Sutures** — **absorbable (5-0 chromic catgut)**

**Grafts** — **FTSG preferred, less contracture** (TO) · FTSG ↑ web creep, hyperpigmentation, hair; STSG ↑ flexion/extension lag & graft breakdown (Deunk, no preference)

**Technique (TO)** — **volar anchor / triangular flap** · **Buck-Gramcko flaps for nail folds** · FTSG for residual defects

**Stage interval** — **6 mo** (Orthobullets) · **3–6 months** (TO) — read the options

| | **Syndactyly (TO)** | **Symphalangism (TO)** |
|---|---|---|
| Involves | Adjacent fingers | Same finger |
| Fusion | Soft tissue / bone | Longitudinal phalangeal (PIP absent) |
| Rx | Surgery | Conservative |

**Metacarpal synostosis (TO)** — commonly **4th–5th** · carpal synostosis — conservative

## 6 Complications

### Complication – web creep

**Web creep** — **most common** (8–60%) = **distal migration of the web commissure**; warn parents pre-op; regular follow-up

**Early creep** — **necrosis of tip of dorsal quadrilateral flap** + loss of FTSG in web

**Late creep** — adolescence; **discrepant growth** of scar/graft vs surrounding tissue

**Treatment** — reconstruct web with **local skin flaps**

| Other complication (TO) | Fact |
|---|---|
| Infection | Rare, **1.6%** |
| Scar contracture | STSG, bone growth |
| Devascularisation / digital nerve injury | Operate **one side at a time** |
| **Nail deformity** | — |

## How it's asked

**"18-mo, middle–ring release — likely complication"** → **web creep** (TO)\
✗ Wrong options: nail deformity, infection, contracture

**"Most common complication involves"** → **web commissure**

**"Most common finger involvement"** → **long–ring** (TO)

**"Release border digits when?"** → **~6 mo**

**"Acrosyndactyly release when?"** → **neonatal period**

**"Bony side-to-side fusion"** → **complex**

**"Early web creep cause"** → **dorsal flap tip necrosis / FTSG loss**
