# Sagittal Band Rupture

*Hand · 77 / 103*

## 1 Basics

### Epidemiology

**Synonym** — **"boxer's knuckle"**; **zone 5** extensor injury

**Who** — **pugilists** (pros: index/middle; amateurs: ring/little); **RA** (chronic, attritional)

**Finger** — **middle most common (48%)** · little 31% · index 14% · ring 7% (Orthobullets) · "middle or ring" (OB203)

**Side** — **radial SB : ulnar SB = 9:1** → tendon subluxes **ulnarly**

**Association** — MCP collateral ligament injury; often dorsal capsule torn too

### Anatomy & biomechanics

**Sagittal band** — part of closed **girdle** around MC head with palmar plate; origin **volar plate + intermetacarpal ligament** at MC neck → inserts on extensor hood

**Primary stabiliser** of extensor tendon at MCP = **sagittal band**; **secondary = juncturae tendinum**

**Function** — resists **ulnar deviation** of tendon (esp. MCP flexion); prevents **bowstringing** in MCP hyperextension

| Sectioning | Result |
|---|---|
| Ulnar SB (partial/complete) | **No** dislocation |
| Radial SB distal part | No instability |
| **50% of proximal radial SB** | **Subluxation** |
| **Complete radial SB** | **Dislocation** |

**Instability greatest** — **wrist flexion** + MCP flexion; central digits > border; **middle least stable**, **little most stable** (junctura)

## 2 Mechanism

**Traumatic** — forceful resisted flexion or extension ("flicking"); **direct blow** to MCP (forced flexion); hood laceration

**Atraumatic** — **RA**; spontaneous

## 3 Presentation

**Symptoms** — MCP pain, focal swelling, **snapping** with extension; palpable dorsal defect on fist, resolves with MCP extension

**Key finding** — **cannot actively extend MCP from flexion, but CAN HOLD extension once passively placed**\
✗ Wrong options: lag of 30°/60° · Bunnell intrinsic test · IP extension

**IP extension** — preserved (intrinsics)

**Pseudo-triggering** — snapping from subluxation/relocation → **avoid unnecessary trigger release**

**Dislocation into intermetacarpal gully** — most unstable MCP flexion + **wrist flexed**; least with wrist extended

**Provocative** — pain on resisted MCP extension with IPs extended

**RA** — ulnar deviation of digits at MCP

## 4 Diagnosis & Classification

### Key radiology findings

| Modality | Use / finding |
|---|---|
| X-ray | PA, lateral, oblique; **Brewerton** (AP, dorsal fingers on cassette, MCP 45° flexed); **stress view → collateral avulsion** |
| **Dynamic US** | When **swelling obscures exam**; EDC subluxation on MCP flexion |
| **MRI** | Axial at long MCP, **MCP flexed**; acute = poor definition, discontinuity, thickening |
| MRI direction | **Ulnar SB defect → tendon radial**; **radial SB defect → tendon into ulnar gully** |

![MRI: radial sagittal band rupture, tendon subluxed ulnarly](../../Orthobullets/attachments/ob6029-mri-radial-sagittal-band-rupture-mf-and-subluxation-of-centr.jpg)

**Differentials** — collateral injury, EDC rupture, trigger finger, junctura disruption, congenital SB deficiency, MCP OA

## 5 Management

```
Sagittal band rupture
├─ Acute (<6 wk Orthobullets / <3 wk OB) → extension / yoke / relative-motion splint 4–6 wk
├─ Professional athlete → open direct repair
└─ Chronic (>6 wk) or failed splint
       ├─ primary repair possible → direct repair (Kettlekamp)
       └─ not possible → extensor centralisation
```

### Treatment – sagittal band splinting vs open repair

**Splint** — **MCP in extension, IPs free** (extension or **yoke** splint)\
✗ Wrong options: volar finger splint · buddy tape · dorsal block · intrinsic-plus

**Relative-motion splint (OB)** — **MCP 30° hyperextension, PIP free**

**Timing conflict** — acute = **within 6 wk** (Orthobullets) · splint if seen **within 3 wk**, surgery if **>2–3 wk** or failed splint (OB203) — read the options

**Pro athlete (NFL)** — **open repair of sagittal band** → earlier rehab, quicker RTS\
✗ Wrong options: junctura repair

### Centralisation techniques

| Technique | Key detail |
|---|---|
| **Trapdoor** | **Ulnar-based partial-thickness capsular flap**, tendon deep to flap |
| **Kilgore** | Distally based **radial** EDC slip around **radial collateral** |
| **Carroll** | Distally based **ulnar** EDC slip, deep to tendon, around **radial collateral** |
| **McCoy** | **Proximally** based EDC slip around **lumbrical insertion** |
| **Watson** | Distally based EDC slip under **deep transverse MC ligament** |
| **Wheeldon** | **Ring junctura** divided, brought over tendon, sutured to torn radial SB (middle finger) |
| Other | Fascial strips / free tendon graft |

**Rehab** — 0–4 wk resting splint MCP + IP 0° · from 2 wk motion splint MCP 0°, IPs free · AROM 4–8 wk · strengthen >8 wk

## 6 Complications

**MCP flexion contracture** — after nonop / delayed presentation → secondary **intrinsic tightness**

## X vs Y

| Test / finding | Diagnosis |
|---|---|
| **Can't extend MCP, holds when placed** | **Sagittal band rupture** |
| Can't hold MCP extension | EDC rupture/laceration, **PIN palsy** |
| Locking in flexion | Trigger finger (A1) |
| PIP laxity to valgus (PIP 30°, MCP 90°) | Collateral ligament injury |
| Rigid DIP with PIP flexed 90° over table | **Elson** — central slip |
| Can't flex DIP | Jersey finger (FDP) |

## How it's asked

**"Key diagnostic finding of SB rupture?"** → **holds MCP extension after passive extension**

**"Finding present in SB injury?"** → **can't actively extend MCP but maintains it after passive extension**

**"Amateur boxer 2–3 wk — initial treatment?"** → **extension / yoke splint (MCP extended, IPs free)**

**"Punched wall 3 days ago, dorsal defect on fist — next step?"** → **MCP extension splinting**\
✗ Wrong options: trigger injection · hood reconstruction

**"NFL player, tendon subluxing on MCP flexion?"** → **open repair of sagittal band**

**"Relative-motion splint position?"** → **MCP 30° hyperextension, PIP free**

**"Which band and which way?"** → **radial SB → tendon subluxes ulnarly**
