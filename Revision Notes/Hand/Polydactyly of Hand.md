# Polydactyly of Hand

*Hand · 67 / 103*

## 1 Basics

**Definition** — extra digit; **most common congenital hand malformation**; diagnosis clinical

| Form | Digit | Ethnicity |
|---|---|---|
| **Preaxial** | Thumb (radial) | **Caucasian** > African American |
| **Postaxial** | Small finger (ulnar) | **10× African American** (1.2% vs 0.09%) |
| Central | Index/long/ring | Often with **syndactyly** |

### Genes & associations

**Preaxial** — usually **unilateral, sporadic**; ✓ M > F; **Type VII (triphalangeal)** → **Holt-Oram, Fanconi anaemia**, Blackfan-Diamond, imperforate anus, cleft palate, tibial defects

**Preaxial spectrum** — triphalangeal thumb, preaxial polysyndactyly, **mirror hand** = AP-axis limb-bud error

**Postaxial** — **autosomal dominant** (African American); sex-linked recessive modifier hypothesised

**Postaxial in Caucasian** — complex genetics → work up for **chondroectodermal dysplasia / Ellis-van Creveld**

**Pollex abductus** — abnormal **EPL–FPL connection**, ~20% hypoplastic/duplicated thumbs; abducted digit + **absent IP crease**

**Look-alikes** — constriction band = pseudosyndactyly (post-formation injury) · syndactyly → **Apert, Poland** · macrodactyly → **NF, Klippel-Trenaunay-Weber**

## 5 Management

### Preaxial (thumb) duplication – Wassel classification & reconstruction

**Goals** — thumb **80% of contralateral size**; resect smaller (usually **radial**) thumb; preserve/reconstruct **UCL (ulnar collateral)** for pinch; one-stage

| Procedure | Wassel type | Technique |
|---|---|---|
| **Bilhaut-Cloquet** (type 1 combination) | **I, II, III** | Remove central bone + nail, join halves; **~20% late deformity** (stiffness, angulation, growth arrest, nail) |
| Type 2 combination | **III, IV** (V–VI need intrinsic/collateral transfer) | Keep one skeleton + nail, augment with soft tissue, **ablate radial** digit |
| Type 3 combination (on-top plasty) | V, VI, VII | Segmental distal transfer |
| Triphalangeal (VII) | VII | Excise vs fuse extra phalanx |

**Equal-size type IV** — excise **radial** thumb → keep ulnar thumb's **MCP UCL**

**Ulnar-side scar after resection** — **ulnar (valgus) MCP instability**, weak pinch\
✗ Wrong options: dorsal/volar/radial instability · EPL loss

**Principles (TO)** — use parts of both digits · repair collateral ligament · reinsert tendons · adequate web · cover articular surfaces

**Triphalangeal thumb (TO)** — five-fingered hand, **delta phalanx**, unstable MCP → web creation, delta excision, **pollicisation**

### Central polydactyly

**Rx** — **early** osteotomy + ligament reconstruction → prevent angular growth deformity

## X vs Y

| | Preaxial | Postaxial |
|---|---|---|
| Ethnicity | Caucasian | **African American** |
| Genetics | Sporadic (VII syndromic) | **AD** |
| Syndrome work-up | Triphalangeal → Holt-Oram, Fanconi | **Caucasian** → **Ellis-van Creveld** |
| Excise | **Radial** thumb | **Ulnar** digit |

## How it's asked

**"Bilhaut-Cloquet indicated for which Wassel type?"** → **Type II** (I–III)\
✗ Wrong options: IV–VII

**"Which image is preaxial?"** → **duplicated thumb**

**"Ulnar-side thumb resection scar, weak pinch — finding?"** → **ulnar instability of thumb MCP** (UCL)

**"Caucasian with this anomaly — work up for Ellis-van Creveld"** → **postaxial polydactyly**

**"More common in African Americans"** → **postaxial polydactyly**

**"Inheritance of postaxial polydactyly"** → **autosomal dominant**

**"Commonest Wassel type"** → **IV**
