# Tendon Transfer Principles

*Hand · 88 / 103*

## 1 Basics

### Principles of transfer

**Strength** — force ∝ **cross-sectional area** (max at resting length); amplitude ∝ **muscle length**; work = force × amplitude

**Grade loss** — **lose 1 MRC grade** after transfer → transfer **grade 5** donor (foot drop: 4/5 acceptable → ≥3/5 antigravity)

**Donor** — **expendable**, similar excursion + power

**One tendon → one function**

**Synergistic** — rehab easier (finger flexion + wrist extension; wrist flexion + finger extension)

**Line of pull** — **straight** (avoids tethering, late failure); pulley or tenodesis adjusts excursion

**In-phase vs out-of-phase** — in-phase best, but **out-of-phase acceptable** (often the only donor) — not a contraindication

| Smith 3-5-7 rule | Excursion |
|---|---|
| Wrist flexors / extensors | **3 cm** |
| **EDC, FPL, EPL** | **5 cm** |
| **FDS, FDP** | **7 cm** |

**Selection** — missing function → available units → options

**Brachial plexus priorities** — elbow flexion (musculocutaneous) → shoulder stabilisation (suprascapular) → brachiothoracic pinch (pectoral) → sensation C6–7 (lateral cord) → wrist extension + finger flexion

### Prerequisites – supple joints

**Precludes transfer** — **target joint cannot be passively corrected to neutral** (static contracture / bony deformity) → release first

**Not contraindications** — full PROM · motion only in direction of correction · out-of-phase donor · no pulley

**Nonop (therapy, splints, antispasticity)** — ↓ PROM, spasticity

## 3 Presentation

### Nerve palsy patterns

| Palsy | Low | High |
|---|---|---|
| **Radial** (vs PIN origin) | PIN syndrome (wrist extension spared via ECRL) | + triceps, BR, **ECRL** lost |
| **Median** (vs AIN origin) | **Loss of opposition (APB)** | + **FPL, FDP index/middle, FDS, PL** lost |
| **Ulnar** | Power pinch ↓, **Wartenberg**, **clawing marked** | + **FDP ring/small lost** (key deficit) → **less clawing** |

**Brachial plexus avulsion signs** — **Horner's (C8–T1)**, appears 2–3 d · severe pain in anaesthetic limb · **loss of rhomboids**

**Studies** — sensory/motor evoked potentials > standard EMG/NCS

## 4 Diagnosis & Classification

### Bouvier test (claw hand)

**Technique** — wrist neutral, **block MCP hyperextension** → can PIP extend?

| Result | Meaning | Transfer insertion |
|---|---|---|
| **Positive** (PIP extends) | **Simple claw**, central slip intact | MCP flexion only → **A1/A2 pulley or proximal phalanx** |
| **Negative** (PIP doesn't extend) | **Complex claw** | MCP flexion + PIP extension → **lateral bands** |

(✗ Wrong options: **Distractors** — PIP 90° + rigid DIP = **Elson** (central slip)) · PIP flexes with MCP extended not flexed = **extrinsic tightness** · wrist tenodesis = tendon injury · thumb IP flexion on paper = **Froment**

## 5 Management

### Timing

| Timing | Indications |
|---|---|
| **Early (3 wk–3 mo)** | Total/near-total plexus injury, high energy |
| **Late (3–6 mo)** | Partial upper plexus, low energy |

**Post-op** — protect **3–4 wk** → ROM; protective splint 3–6 wk

### Specific transfers

| Goal | Donor | Recipient |
|---|---|---|
| **Musculocutaneous** — elbow flexion | Pec major, latissimus | Biceps |
| Elbow flexion | Common flexor mass | Proximal humerus (**Steindler flexorplasty**) |
| **Radial** — elbow extension | Deltoid, latissimus, biceps | Triceps |
| **Wrist extension** | **Pronator teres** | **ECRB** |
| Finger extension | **FDS, FCR or FCU** | EDC |
| Thumb extension | **PL or FDS** | EPL |
| **Low median** — opposition | **FDS ring** (FCU pulley, **Bunnell**) | Base P1 / APB |
| | **EIP** (around ulnar wrist) | APB |
| **High median** — thumb IP flexion | **BR** | FPL |
| Index/middle flexion | FDP ring/small (ulnar) | FDP index/middle (side-to-side) |
| **Ulnar** — thumb adduction | FDS or ECRB | Adductor pollicis |
| Index abduction | APL, ECRL, EIP | 1st DI |
| Anti-claw | FDS, ECRL (**volar to transverse MC ligament**) | Lateral bands ulnar digits |

### Radial nerve/PIN palsy transfers

**Most consistent radial palsy transfer** — **PT → ECRB**\
✗ Wrong options: **BR → ECRB**: BR is radial-innervated

**PL** — not always present; FDS → APL/EPB unnecessary if EPL rerouted

**PIN transected, no recovery at 1 y** — **FCR → EDC + PL → EPL**\
✗ Wrong options: sural graft at 1 y · wrist fusion + FCU · PT → wrist extensors (wrist extension preserved by ECRL)

### Median/ulnar palsy transfers – opponensplasty & claw correction

| Opposition transfer | Note |
|---|---|
| **Ring/long FDS** (Bunnell, FCU pulley) | Low median; not high median (FDS denervated) |
| **EIP → APB** | **High median** (radial-innervated) ✓; also after median laceration |
| Camitz **PL** | not high median (denervated); **no pronation/MC flexion** → not true opposition |
| Huber **ADM** | Ulnar-innervated |

![EIP opponensplasty](../../MCQ/attachments/q4738-illa-illus-a-eip.jpg)

**High median from supracondylar spur + ligament of Struthers** — decompress + FPL/FDP-I + **EIP → APB**\
✗ Wrong options: FDS · Camitz · neurotisation = pre-ganglionic plexus · CMC fusion

**Low median laceration (4 cm above wrist) after repair** — sensation usually returns; thenar motor unpredictable → **EIP opponensplasty at 6 mo**\
✗ Wrong options: FDP tenolysis · CTR · EDM → 1st DI (ulnar intact; neurotisation = distal AIN → median motor) · ulnar

**Burkhalter** — MCP flexor replacement for intrinsic loss → ↑ grip, ↓ clawing

### Tensioning EIP-to-EPL transfer

**EPL rupture after DRF** — EIP → EPL (synergistic)

**Best tensioning** — **wide-awake local anaesthesia, functional testing** (max extension without losing flexion)\
✗ Wrong options: maximum tension · tenodesis estimate

## 6 Complications

**Adhesions** — aggressive therapy ± **tenolysis**

**Prognosis** — **age = leading factor** (worse >30 y); **distal > proximal** lesions

## X vs Y

| | **Low ulnar palsy** | **High ulnar palsy** |
|---|---|---|
| FDP ring/small | Intact | **Lost** |
| Clawing | **More** | **Less** (ulnar paradox) |

| | **Low median** | **High median** |
|---|---|---|
| Deficit | Opposition | Opposition + thumb IP + index/middle flexion |
| Opposition donor | **FDS ring** or EIP | **EIP** (FDS, PL denervated) |

## How it's asked

**"Precludes tendon transfer?"** → **joint not passively correctable to neutral**\
✗ Wrong options: out-of-phase donor · no pulley

**"PIN transected, no function at 1 y?"** → **FCR → EDC + PL → EPL**

**"Most consistent radial palsy transfer?"** → **PT → ECRB**\
✗ Wrong options: BR → ECRB

**"High median palsy (Struthers) — restore opposition?"** → **EIP → APB**\
✗ Wrong options: ring FDS · Camitz

**"Median laceration 4 cm proximal to wrist — secondary op at 6 mo?"** → **EIP opponensplasty**

**"Ulnar claw — test to choose insertion site?"** → **Bouvier: block MCP extension, PIP fails to extend**\
✗ Wrong options: Elson · Froment

**"Tension EIP → EPL?"** → **awake under local, functional testing**

**"Excursion of FDS/FDP?"** → **7 cm**

**"Strength after transfer?"** → **loses one grade**

**"Leading prognostic factor?"** → **age (worse >30)**
