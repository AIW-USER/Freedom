# DIP and PIP Joint Arthritis

*Hand · 23 / 103*

## 1 Basics

### Epidemiology

**Commonest hand OA** — **DIP > thumb CMC > PIP > MCP**

**DIP** — **highest joint forces in hand**; ≥60% of >60-y-olds show DIP OA

**PIP OA prevalence** — ~**17% ♀ · 13% ♂**

### Forms of arthritis

| Form | Key features |
|---|---|
| Primary OA – DIP | **Heberden nodes** (osteophytes), **mucous cysts**, nail ridging/splitting/deformity/loss of gloss |
| Primary OA – PIP | **Bouchard nodes**; contracture from ligament fibrosis |
| **Erosive OA** | DIP > PIP; **middle-aged ♀, 10:1**; intermittent inflammatory episodes; RA-like synovium but **not systemic**; self-limiting yet destructive |

![Heberden (DIP) & Bouchard (PIP) nodes](../../Orthobullets/attachments/ob6055-herberden-nodes-and-bouchard-nodes.jpg)

## 3 Presentation

**Primary OA** — pain, deformity; PIP → **flexion contracture**, ↓ motion, swelling

**Mucous cyst** — dorsal DIP mass, proximal to nail fold; nail ridging/deformity; → draining sinus → **septic arthritis**

![Mucous cyst with nail ridging](../../Orthobullets/attachments/ob6055-mucous-cyst-moved.jpg)

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP, lateral, oblique hand

**OA** — joint space narrowing DIP/PIP, **dorsal osteophytes** (under mucous cyst)

**Erosive OA** — cartilage destruction, osteophytes, subchondral erosion → **"gull wing" deformity**

**Diagnosis** — history + exam + radiographs

## 5 Management

```
DIP / PIP arthritis
├─ Mild symptoms → observation + NSAIDs (erosive: splints)
├─ DIP debilitating pain / deformity → DIP FUSION (headless screw)
└─ PIP end-stage
       ├─ Index / small, young laborer, deformity, instability, poor bone → PIP FUSION
       └─ Long / ring, older, good bone, no deformity → SILICONE ARTHROPLASTY (volar)
```

### Mucous cyst – excision with osteophyte removal

**First line** — observation (**20–60% resolve**) (Orthobullets) · rarely resolve, usually progress → nail deformity (OB)

**Aspiration ± steroid** — **>40% recurrence**; 60% complete resolution (Rizzo)

**Surgery** — **excision of cyst + osteophyte (bone spur) removal** → **0% recurrence**, 100% resolution; key = **osteophytes MUST be debrided**

**Surgery indications** — significant pain, impending rupture, **repeated drainage**

**Not needed** — skin excision/graft (lesion independent of skin; flap controversial), nail plate removal, collateral/extensor resection, steroid injection, infectious workup

**DIP fusion instead** — **pain with forcible joint movement** + advanced arthritis

![Mucous cyst over DIP spur](../../MCQ/attachments/q711-b-spur.jpg)

### DIP arthrodesis

**Indication** — debilitating pain/deformity; **DIP OA of lesser digits** (e.g. ring DIP marked narrowing) → arthrodesis

**Headless compression screw** — **highest fusion rate**; nonunion 10% (Orthobullets) · union 95% (Kocak), 94–97% (Cox, Matsumoto)

| Digit | DIP fusion position |
|---|---|
| Index, long | **Extension** |
| Ring, small | **10–20° flexion** |

### DIP arthrodesis complication – screw length

| Screw error | Result |
|---|---|
| **Too long** | Prominent tip → **fingertip hypersensitivity** |
| Too wide | **Fracture, nailbed deformity** |
| Headless | ↓ prominence ✓ |
| Cannulated vs not | No difference |

### PIP arthroplasty (silicone, pyrocarbon) vs arthrodesis – indications & outcomes

| PIP option | Indication |
|---|---|
| **Collateral excision + volar plate release + osteophyte excision** | **Predominant contracture, minimal/no joint arthritis** |
| **Arthrodesis** | **Border digits (index, small)**; long/ring with **angulation/rotation, ligament instability, poor bone stock**; **young laborer** |
| **Silicone arthroplasty** | **Long & ring**, good bone stock, no deformity, older |
| Pyrocarbon arthroplasty | Needs **intact collaterals + volar plate** (unconstrained) |
| Resection arthroplasty | Recurrent infection, bone loss |
| Ray resection | Salvage only |
| Vascularised toe PIP transfer | Young; not in clotting disorder (factor V Leiden) |

**Index PIP** — relative CI to arthroplasty (**ulnar-deviating forces in key pinch**); arthroplasty → 4.3× complications, no ROM/pain gain vs fusion (Vitale)

**Long finger** — may also be a relative CI (Milone)

**Young + post-traumatic + rotation** — **arthrodesis** (rotation = collateral insufficiency)

**Silicone & collaterals (conflict)** — RCL should be intact for pinch (Orthobullets) · linked silicone **not dependent** on collaterals/volar plate → choice for **collateral-deficient ring PIP** (OB)

**Silicone outcomes** — **reliable pain relief (98%)**; **no significant ↑ ROM, grip, DASH**; arc ~55°; 60% deformation, 40% failure (Bales); **<60 y → ~25% revision**

**Approach + implant** — **silicone via volar approach → best ROM, least extensor lag, lowest revision (6% vs 18%** surface/dorsal; = 33%); **surface (metal-on-plastic) → highest revision**; dorsal = historic gold standard

**Pyrocarbon PIP** — **high complication rate** → rarely used; **↓ arc (57→31°)**; squeaking, loosening, dislocation, contracture; 34% reoperation, 51% subsidence, 36% unstable (Wagner)

**Pyrocarbon MCP** — **low complications**, mild ↑ arc (62→76°), pain relief; squeaking reported in both MCP & PIP

**PIP fusion technique** — headless screw (highest union), tension band, or plate

| PIP fusion angle | Value |
|---|---|
| Orthobullets | **Index 30° · long 35° · ring 40° · small 45°** |
| OB (radial → ulnar) | **40–55°** increasing |
| Arauz (index) | **0–20°** → natural pinch posture |

### Erosive OA

**Treatment** — splints + NSAIDs (tolerable) → **fusion** for intolerable deformity (same angles)

## X vs Y

| | **Silicone PIP** | **Pyrocarbon PIP** | **Surface (metal-plastic)** |
|---|---|---|---|
| Constraint | Linked, single piece | **Unconstrained** | — |
| Needs collaterals | No (OB) | **Yes** | — |
| Complications | Low | **High** | **Highest revision** |
| ROM | No significant gain | **↓** | Worse than volar silicone |

| Thumb / digit scenario (OB218081) | Best surgery |
|---|---|
| **Ring DIP marked narrowing** | **Arthrodesis** |
| Thumb CMC stage II | Trapeziectomy ± LRTI |
| Thumb CMC hypermobile, 14° hyperextension, mild OA | **Metacarpal osteotomy** |
| Index PIP contracture, no OA | Collateral excision / volar plate release |
| Ring PIP OA, stable | Silicone arthroplasty |

## How it's asked

**"Tender dorsal DIP mass + spur — best treatment?"** → **remove bone spur + cyst**\
✗ Wrong options: aspiration >40% recurrence · fusion

**"Advantage of excision + debridement over aspiration?"** → **↓ recurrence**

**"Important component treating mucous cyst?"** → **excise DIP osteophytes**\
✗ Wrong options: skin · nail · collateral

**"Repeated drainage from DIP lesion — surgery?"** → **mass excision + osteophyte removal**

**"Middle finger PIP arthroplasty — approach/implant?"** → **silicone via volar: best ROM + lowest revision**

**"28-y index PIP post-traumatic OA + rotation?"** → **PIP arthrodesis**\
✗ Wrong options: pyrocarbon (collaterals deficient) · toe transfer (factor V Leiden)

**"True about pyrocarbon arthroplasty?"** → **PIPJ: high complication rate**\
✗ Wrong options: ↑ ROM · no squeaking

**"Best treated with arthrodesis?"** → **ring DIP OA with marked narrowing**

**"Best for PIP arthrodesis?"** → **44-y laborer, index PIP OA**

**"True of silicone PIP arthroplasty?"** → **no significant ↑ ROM**\
✗ Wrong options: ↑ grip/DASH · dorsal better

**"Fingertip hypersensitivity after DIP fusion?"** → **excessive screw length**\
✗ Wrong options: diameter → fracture/nailbed
