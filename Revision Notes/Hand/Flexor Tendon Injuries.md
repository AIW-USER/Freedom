# Flexor Tendon Injuries

*Hand · 34 / 103*

## 1 Basics

### Anatomy & tendon nutrition

**FDP** — flexes **DIP**; common belly; **index/long = AIN**, **ring/small = ulnar**

**FDS** — flexes **PIP**; independent bellies; median n.; **absent to small finger in 25%**

**FPL** — AIN; **most radial** structure in carpal tunnel

**FCR** — inserts base 2nd MC; **median nerve lies immediately ulnar to FCR** at DRUJ level (deep FCR laceration → median nerve injury)

**FCU** — pisiform, hook of hamate, base 5th MC; ulnar n.

**Camper chiasm** — level of **proximal phalanx**; FDP passes through split FDS · **distal to the chiasma the FDP is SUPERFICIAL** → landmark in P1-level injuries (TO)

**Lumbricals (TO)** — arise **radial side of each FDP** → dorsal extensor expansion → MCP flexion + IP extension · **intrinsic-plus position = MCP 90° flexion, IPs straight**

**Finger pulleys** — **A2 & A4 (from periosteum) = most important vs bowstringing**; **A1, A3, A5 from volar plate** (MCP, PIP, DIP); C1–C3 collapsible

**Thumb pulleys** — **A1, Av, A2 + oblique**; **oblique (+ A1) most important vs bowstringing**; A2 contributes least

**Pulley venting** — **25% of A2** and **100% of A4** can be incised with little deficit

**Nutrition in zone II (sheathed)** — **synovial diffusion = primary**\
✗ Wrong options: vincula

**Chiasma rotation (TO)** — FDS slips **rotate 180°** round FDP → restore rotation at repair; **never sacrifice both FDS slips** · **FDP vincula longa arises from FDS** · cruciate pulleys collapse in flexion → protect annular pulleys

**Outside sheath** — direct perfusion: vincula, bony insertion, reflected sheath vessels, longitudinal palmar vessels

## 2 Mechanism

**Cause** — volar laceration ± digital NV injury; closed avulsion (jersey finger)

**Healing pathways** — **intrinsic** (tenocytes) · **extrinsic** (sheath/inflammatory cells → **adhesions**)

**Intrinsic healing (TO)** — tenocytes of tendon + sheath · supple, vascular → **preserves gliding** = healing to promote → **repair the sheath too** (TO) · sheath repair no clinical difference (Orthobullets) — read the options

| Phase | Days | Histology | Strength |
|---|---|---|---|
| Inflammatory | 0–5 | Cellular proliferation | None |
| Fibroblastic | 5–28 | Disorganised collagen | Increasing |
| Remodelling | >28 | Linear collagen | Tolerates AROM |

**Weakest repair** — **post-op day 6–12** (OB) · **day 6–20** (TO) — read the options; fails at **knots**; **gap >3 mm** → failure

**Early motion** — ↓ adhesions, ↑ excursion, better healing biology (esp zone II)

## 3 Presentation

### Diagnosis – disrupted tenodesis cascade

**Resting cascade** — involved digit lies **extended** out of cascade

**Tenodesis** — passive **wrist extension → digits flex**; **DIP stays extended = FDP cut**; PIP stays extended = FDS+FDP

**Extensor injury** — loss of digit extension with passive **wrist flexion**

**Isolated tests** — FDP: block PIP, flex DIP · FDS: hold other fingers extended, flex PIP

**Partial tear clue (TO)** — **painful active flexion → partial injury** · full active flexion does **not** exclude partial tear · straight finger alone ≠ complete tear · NV: static 2PD; delayed capillary refill → arterial injury

### Key radiology findings

**X-ray** — associated fracture; **bony FDP avulsion** (Leddy III large fragment caught at **A4**)

**Ultrasound** — suspected (partial) laceration, retracted stump level

## 4 Diagnosis & Classification

### Flexor zones (no man's land)

| Zone | Boundaries | Key fact |
|---|---|---|
| **I** | Distal to FDS insertion | **Jersey finger**; FDP only |
| **II** | FDS insertion → **A1 / distal palmar crease** | **"No man's land" (Bunnell 1918)** (TO); **FDS + FDP in same sheath**; adhesions |
| **III** | A1 → distal edge TCL (palm) | **NV injury** → worse; good results otherwise; ± A1 release · **lumbrical origins → find + repair** (TO) |
| **IV** | **Carpal tunnel** | Adhesions; repair TCL **lengthened** if bowstringing |
| **V** | Proximal to carpal tunnel (forearm) | NV injury · deep cut → all tendons + median + ulnar nn. + both arteries = **"spaghetti wrist"** (TO) |
| **Thumb T I–III** | TI distal to IP · TII IP→MCP · TIII thenar | ↑ re-rupture; early motion does not improve long-term; **avoid TIII incision (recurrent motor br.)** |

### Jersey finger – FDP avulsion

**Mechanism** — forced DIP extension during grip; **ring finger** most common

**Big bony fragment** — **Leddy type III**, caught at **A4** (stays distal)

**Jersey vs mallet (TO)** — tendon **retracts → splinting does not work** → explore + reinsert (**pull-out button 6–8 wk**, K-wire or mini anchors via zig-zag)

**Stem** — can't flex DIP after grabbing jersey/sliding headfirst → **profundus insertion rupture**

## 5 Management

```
Flexor tendon laceration
├─ <60% width, no triggering → trim frayed edges + early protected ROM (no repair)
├─ 60–75% or ≥50% with triggering → EPITENDINOUS repair of cut edge only
└─ Complete → core (4–6 strand) + running epitendinous, within 2–3 wk, early motion
       └─ child / non-compliant → 4-strand + cast 3–4 wk
```

### Operative criteria

| Situation | Criterion → action |
|---|---|
| Partial laceration | **<60%**, no trigger → no repair · **60–75%** or ≥50% + trigger → epitendinous · **>75%** → repair |
| Complete laceration | Core (**4–6 strands** for early active motion) + running epitendinous |
| Timing | **Within 3 wk** (2 wk ideal); FDP avulsion past ~3 wk → retracted; >6 wk pulleys collapse |
| Re-rupture | Scar **<1 cm** → resect + repair · **>1 cm** → graft (1-stage if sheath intact, 2-stage if collapsed) |
| Reconstruction | **Supple skin, sensate digit, vascularity, full passive ROM** |
| Single-stage graft | Pristine sheath + full ROM |
| Tenolysis | **>3 mo**, stable soft tissue, **full passive ROM**, active ≪ passive |
| Immobilise (✗ Wrong options: early motion) | **Children**, non-compliant |

### Partial lacerations – trimming vs epitendinous repair

**<60% (e.g. 40–50%), no trigger** — **no repair**; trim edges + **early protected ROM** (repaired partial tendons can be weaker)

**Up to 75% partial** — **epitendinous suture of cut edge alone** prevents gap >2 mm; no core (adds bulk), no circumferential needed

**Complete laceration** — always **core + epitendinous**

### Repair biomechanics – core strands, suture purchase, FDS slip & rehab protocol strength

**Strength ∝ number of core strands crossing repair** (linear) — strongest single factor\
✗ Wrong options: suture size · sheath repair

**4–6 strands** — needed for **early active motion**

**Purchase** — **10 mm** from cut edge (> 5 mm) (OB) · **5–7 mm** (TO) — read the options

**Repair thresholds (TO, Mittal)** — **> 60% → repair** · < 50% → conservative / epitendinous · **no primary repair after 6 wk** → reconstruction · best < 2 wk, acceptable ≤ 3 wk

**Handling (TO)** — **non-toothed forceps on endotendon**, not epitendon · stabilise with **25G needle** · **6-0 epitendinous** running (+20% strength, gliding) · named: Tajima (2-strand), Strickland, Savage, Becker

**Zone I FDP (TO)** — distal stump **≥ 1 cm → primary repair** · **< 1 cm → advancement / bone pull-out** (avoid > 1 cm advancement → quadriga)

**Zone V repair order (TO)** — **FDP + FPL → FDS → artery → nerve → superficial tendons (FCR, FCU, PL)** · zones III–IV: tendons first, then NV

**Technique (TO)** — cylindrical tendon → **core + peripheral (epitendinous)**, not simple/mattress · freshen ends with **No. 11 blade** · **modified Kessler-Mason** 2- or 4-strand **3-0 nylon/Prolene** core + **5-0 nylon running** · **knots buried between tendon ends** · non-absorbable monofilament (no braided / absorbable) · other named: Bunnell, cruciate, **Savage**, **Tang**, modified Becker

**Other** — larger calibre ↑ strength; **locking loops ↓ gap**; **dorsal core** stronger

**Epitendinous** — **simple running** (↓ gliding resistance; not Silfverskiöld); +20% strength; ↓ gap; ↓ bulk

**Sheath repair** — no clinical difference

**Zone II FDS** — repair it (↑ strength, outcomes); **repairing 1 slip → better gliding** than both

**Timing** — **within 3 wk** (2 wk ideal); retraction later

**Incisions** — cross creases transversely/obliquely (Brunner); **never longitudinal**

**Excursion target (TO)** — **minimum 3–5 mm, optimal 6–9 mm** · splint off at **6–8 wk** · complex repairs passive-only first 4 wk

**Dorsal blocking splint (TO)** — **4–6 wk**, **MCP 80–90° flexion, IPs straight** · supervised early active-assisted motion (esp. zone II)

| Protocol splint (TO) | Position |
|---|---|
| **Duran** | Static dorsal block: wrist slight flexion, **MCP \~45°**, IPs near extension; isolated DIP → PIP → combined passive |
| **Kleinert** | Dorsal splint, **wrist \~30° flexion, MCP 30–40°**, **rubber bands nail → wrist** (palmar pulley); bands off at night, fingers strapped straight |
| **Strickland (place & hold)** | **Hinged** wrist splint, wrist 20° flexion, MCP 50°; tenodesis passive flexion → **hold \~5 s** |
| Mayo synergistic | Hinged; active wrist + finger motion |

| Rehab protocol | Force / excursion | How |
|---|---|---|
| **Duran** | Low / low | **Patient-assisted** passive flexion, active extension |
| **Kleinert** | Low / low | **Rubber-band dynamic** passive flexion, active extension |
| **Synergistic (Mayo)** | Low / **high** | **Active wrist motion** → greatest excursion |
| **Early active** (place & hold) | Moderate / high | Needs **4–6 strands** |
| Immobilisation | — | **Children, non-compliant**: wrist & MCP flexed, IPs extended |

**2-strand repair** — OK for Duran/Kleinert/synergistic; **not for early active motion**

### Paediatric flexor tendon injuries

**Child (e.g. 4 y) zone II** — **4-strand core + cast 3–4 wk** (wrist 35° flex, MCP 60–70°, IP extended; above elbow)

**Differences from adults** — **poor therapy cooperation**; delayed presentation commoner (may need staged); Botox may aid rehab

### Wide-awake (WALANT) repair

**Anaesthesia** — **lidocaine + adrenaline** tumescent; **no tourniquet, no sedation**

**Adrenaline in digit** — **safe** (up to 1:1000); necrosis was **procaine**; antidote **phentolamine** (1 mg in 5 mL)

**Doses** — 7 mg/kg lido; 1% + 1:100,000 if <50 mL; 0.5% + 1:200,000 if 50–100 mL; 0.25% + 1:400,000 if 100–200 mL; P1/P2 2 mL, P3 1 mL, palm 10–15 mL

**Primary goal** — **active testing of repair** by awake patient (gaps, gliding through A2/A4)

**Benefits** — debulk on the spot, **vent A2 / divide A4** → **↓ late tenolysis**; facilitates early active motion

**Post-op** — immobilise 3 days → **half-fist 45/45/45** active midrange

**WALANT mix (TO)** — **lignocaine 2% + adrenaline + sodium bicarbonate** (bupivacaine for longer cases)

| Other hand anaesthesia (TO) | Key points |
|---|---|
| **Bier block** | Esmarch exsanguination · **double cuff at SBP + 100 mmHg (or 2.5 × SBP)** · **0.5% plain lidocaine \~1 mL/kg** (TO — verify: usual max 3 mg/kg ≈ 0.6 mL/kg of 0.5%) via distal IV · wait 6–8 min → release **distal** cuff, keep proximal · **never release early** (hypotension, convulsions, arrhythmia, death) · **bupivacaine contraindicated** |
| **Axillary block** | Arm abducted + ER; inject above + below axillary artery · **does not block intercostobrachial n.** |
| **Supraclavicular block** | Whole upper limb; US-guided |

**✗ EXCEPT traps** — "adrenaline contraindicated" · "brachial block + sedation" · "forearm tourniquet" · "surgeon passively flexes" · "doesn't reduce tenolysis"

### Late reconstruction – two-stage grafting, FDS transfer & failed repair

**Re-rupture (TO)** — **re-repair if < 3 wk**; **graft if > 3 wk** · tenolysis for adhesions at **4–6 months** (TO)

**Reconstruction ladder (TO)** — do nothing → tenolysis → tendon transfer → primary graft → **two-stage graft (scarred bed)**

**Re-rupture** — 15–25%

```
Re-rupture after repair
├─ scar <1 cm → resect scar + primary repair
└─ scar >1 cm → graft
       ├─ sheath intact (paediatric catheter passes) → single-stage graft (palmaris longus)
       └─ sheath collapsed/scarred → staged (Hunter rod)
```

**Advance FDP >1 cm** — avoid → **quadrigia** & contracture

**Reconstruction prerequisites** — **supple skin, sensate digit, adequate vascularity, full passive ROM of joints**

**Two-stage indications (TO)** — delayed presentation · tendon loss · repeated adhesions · **collapsed sheath** · stage 1: rod sutured to **FDP stump** + **reconstruct A2/A4** with graft · stage 2 at **3–4 months** · junction by **Pulvertaft weave** (not Kessler)

**Hunter (two-stage)** — stage 1 silicone rod → pseudosheath; stage 2 at **≥3 mo** graft through **mesothelium-lined pseudosheath** (Pulvertaft proximal)

**Paneva-Holevich** — stage 1 rod + FDS–FDP loop in palm; stage 2 FDS reflected distally; **intrasynovial graft**, one tenorrhaphy healing at a time

**Graft choice** — **palmaris longus** (commonest; absent 15%) · plantaris (absent 19%, longer) · toe extensors · EIP · FDS

**Pulleys** — reconstruct one **proximal & distal to each joint**; do pulleys first

**Tenolysis after reconstruction** — **>50%**

**Chronic FDP avulsion (4 mo), full passive ROM, palm mass** — **two-stage grafting** (pulleys collapse >6 wk; no direct repair after ~3 wk)

**Chronic FPL laceration (4 mo), full passive IP** — **FDS ring transfer to FPL** (single stage) · alternative IP fusion

**Active silicone rod** — fatigues → not permanent

### Attritional ruptures (rheumatoid, prominent plate)

**Mannerfelt (TO)** — **FPL rupture** in carpal tunnel from **scaphoid (STT) spur**; **most common flexor rupture in RA**

**Treatment** — **palmaris longus graft** (✗ Wrong options: primary repair (attritional)) or FDS transfer; debride osteophyte; IP fusion alternative (✗ Wrong options: MCP fusion)

**Vaughan-Jackson (TO)** — extensor ruptures **ulnar → radial** (EDM/EDC small first) from **distal ulna** (caput ulnae)

**After volar DRF plate** — **FPL attrition** (plate **distal to watershed** / prominent) → **remove plate + FPL reconstruction** (graft or FDS4)

## 6 Complications

| Complication | Key fact |
|---|---|
| **Adhesions** | **Most common**; zone II; tenolysis at **3–6 mo** if passive ≫ active ROM |
| Re-rupture | 15–25%; days 6–12 weakest |
| Joint contracture | Up to 17% |
| **Quadrigia** | FDP over-advanced/tethered → adjacent fingers can't fully flex |
| **Lumbrical plus** | FDP lax/long (graft too long, FDP cut distal to lumbrical) → paradoxical PIP extension on flexing |
| Swan-neck, trigger finger | — · **triggering** from over-tight pulley repair or nodular repair (TO) · contracture from prolonged flexed splinting + delayed therapy (TO) |

**Tenolysis requirements** — soft tissues stable (>3 mo), **full passive ROM**; preserve A2/A4

## How it's asked

**"No man's land?"** → **zone II** (TO)

**"Superficial tendon distal to Camper chiasma at P1 level?"** → **FDP** (TO)

**"Bier block — local anaesthetic contraindicated?"** → **bupivacaine** (TO)

**"Zone II, 40–50% laceration, no triggering"** → **trim + early ROM, no repair**

**"75% laceration with triggering, least suture"** → **epitendinous of cut edge only**

**"Managed by epitendinous alone"** → **~70% partial FDP**

**"Greatest effect on strength"** → **number of core strands**

**"Best load to failure + gliding"** → **10 mm purchase + simple running epitendinous**

**"2-strand repair — NOT strong enough for"** → **early active motion**

**"Zone II true statement"** → **repair of 1 FDS slip improves gliding**

**"Zone II nutrition"** → **synovial diffusion**

**"Median nerve immediately ulnar to"** → **FCR**

**"DIP stays extended with passive wrist extension"** → **FDP**

**"4-y-old zone II"** → **4-strand + cast 4 wk**

**"WALANT true"** → **lido + adrenaline safe in digit** · **primary goal** → **active testing of repair**

**"Re-rupture, 1.8 cm scar, sheath intact"** → **excise + palmaris longus graft**

**"Two-stage reconstruction true"** → **supple skin, sensate, vascular digit**; tenolysis >50%

**"Jersey finger 4 mo, palm mass"** → **two-stage graft**

**"Chronic FPL 4 mo"** → **FDS transfer**

**"RA, can't flex thumb IP"** → **Mannerfelt (FPL) → PL graft**

**"Pop 12 mo after volar plate, can't flex thumb IP"** → **remove plate + FPL reconstruction**

**"Baseball slide, big fragment on X-ray"** → **FDP insertion (Leddy III)**
