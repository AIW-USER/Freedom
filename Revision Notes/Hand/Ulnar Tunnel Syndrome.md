# Ulnar Tunnel Syndrome

*Hand · 96 / 103*

## 1 Basics

### Epidemiology

**Incidence** — **less common than cubital tunnel**

**Risk** — **cyclists → "handlebar palsy"**; manual workers

### Anatomy – Guyon's canal

**Length** — **~4 cm**; proximal TCL edge → **aponeurotic arch of hypothenar muscles**

**Contents** — ulnar nerve + artery; nerve **bifurcates** into superficial sensory + deep motor

| Boundary | Structure |
|---|---|
| **Floor** | **Transverse carpal ligament**, hypothenar muscles |
| **Roof** | **Volar carpal ligament** |
| Ulnar (medial) | **Pisiform**, pisohamate ligament, abductor digiti minimi |
| Radial (lateral) | **Hook of hamate** |

**Deep motor branch** — **all interossei**, **lumbricals 3 & 4** (Orthobullets) · "4th & 5th lumbricals" (TO, as printed) · hypothenars · **adductor pollicis** · **deep head FPB**

**Dorsal ulnar cutaneous branch** — arises **~5 cm proximal** to ulnar styloid / Guyon's canal → **dorsal ulnar hand spared** in ulnar tunnel

**Innervated proximal to Guyon (spared)** — **FCU**, **FDP ring/little**; ECU = PIN; FPL = AIN

## 2 Mechanism

### Causes – ganglion & imaging

**Commonest** — **ganglion cyst = 80% of non-traumatic cases** (often from **pisohamate joint**)

**Others** — lipoma · repetitive trauma · **ulnar artery thrombosis/aneurysm (hypothenar hammer)** · **hook of hamate fracture/nonunion** · pisiform dislocation · inflammatory arthritis/RA · anomalous muscle (ADM), fibrous bands · palmaris brevis hypertrophy · idiopathic

**Ulnar artery occlusion (TO)** — may cause **Raynaud in ulnar 3 digits** (sympathetic fibres travel with artery)

## 3 Presentation

**Symptoms** — pain/paraesthesia **volar ulnar 1½ digits**; weak intrinsics, grip, pinch

**Spared** — **dorsal ulnar hand sensation** · **FDP ring/little** strength · median territory

| Sign | Mechanism |
|---|---|
| **Claw ring + little** | Loss of intrinsics (MCP flexion, IP extension) |
| **Froment** (book test) | Weak **adductor pollicis** → compensatory **thumb IP flexion by FPL** (AIN); thumb + index IPJ flexion when pinching paper |
| **Jeanne** | Thumb **MCP hyperextension** (EPL) with IP flexion |
| **Wartenberg sign** | **Abducted little finger** — weak **3rd palmar interosseous** (ulnar) + unopposed **EDQ/EDM** (PIN) |
| Weak pinch | Loss of thumb adduction → **up to 70% pinch lost** |
| Weak grasp | Loss of MCP flexion |
| Allen test | **Ulnar artery thrombosis** |
| Difficulty crossing index/middle | Interossei weakness |

**Wartenberg distractors** — EDQ (unopposed, not weak) · ADM weakness → adducted · dorsal interossei → adducted · **Wartenberg syndrome** = superficial radial nerve (cheiralgia paraesthetica)

## 4 Diagnosis & Classification

### Guyon's canal zones & motor vs sensory findings

| Zone | Location | Typical cause | Deficit |
|---|---|---|---|
| **1** | **Proximal to bifurcation** | **Ganglion, hook of hamate fracture** | **Mixed motor + sensory** |
| **2** | **Deep motor branch** (radial) | **Ganglion, hook of hamate fracture** | **Motor only**; **most commonly affected (TO)** |
| **3** | **Superficial sensory branch** (ulnar) | **Ulnar artery thrombosis / aneurysm** | **Sensory only** |

**No zone 4** — 3 zones only

**Lesion in Guyon's canal (TO)** — can give **both** motor + sensory loss (motor, sensory or mixed by zone)

### Key radiology findings

| Modality | Fact |
|---|---|
| X-ray / carpal tunnel view / CT | **Hook of hamate fracture** |
| **MRI wrist** | **Ganglion** (T2 hyperintense) → **study that identifies causative lesion**; gradient echo shows aneurysm |
| **Doppler US / arteriogram / MR angiography** | **Ulnar artery thrombosis / aneurysm** |
| US | Ganglion (well-circumscribed, homogeneous → no biopsy) |

![MRI: ganglion in Guyon's canal](../../MCQ/attachments/q213015-illb-coronal-t2.jpg)

### Electrodiagnostics

**NCS/EMG** — diagnosis + prognosis; **CV <50 m/s across elbow**; ↓ SNAP & CMAP amplitudes (Orthobullets, TO)

**EMG localisation** — fibrillations in **adductor pollicis**\
✗ Wrong options: FCU · FDP little · ECU · FPL

**Pure motor lesion** — normal sensory conduction, **delayed motor to 1st dorsal interosseous**

**EMG/NCV** — confirms neuropathy but **does not identify cause** (→ MRI)

## 5 Management

```
Ulnar tunnel syndrome
├─ Mild, no lesion → ACTIVITY MODIFICATION, NSAIDs, SPLINT
├─ Compressive lesion (ganglion) with neuro deficit → EXCISION + DECOMPRESSION
│      └─ excise stalk (pisohamate) → ↓ recurrence
└─ Failed nonop / severe → RELEASE ALL 3 ZONES
       └─ Ulnar artery thrombosis → SEGMENTAL RESECTION + VEIN GRAFT
```

**Local decompression** — release hypothenar origin · excise ganglion · **resect hook of hamate** · vascular repair · **explore all three zones**

**Ulnar artery thrombosis (TO)** — **segmental resection + vein graft** preferred when feasible

**With CTS** — add **carpal tunnel release**

### Tendon transfers

| Goal | Transfer |
|---|---|
| **Correct claw** | ECRL / ECRB / PL graft, **volar to transverse MC ligament**, 2- or 4-tailed to **A2 pulley** ring + little |
| **Power pinch** | **Smith transfer**: ECRB or **FDS ring** |
| **Little finger adduction (Wartenberg)** | **Ulnar insertion of EDM** → A1 pulley / RCL little finger |

## 6 Complications

**Recurrence** — main complication (ganglion stalk left)

## X vs Y

| | Ulnar tunnel (Guyon) | Cubital tunnel |
|---|---|---|
| **Dorsal ulnar hand sensation** | **Spared** | **Lost** |
| Clawing | **More** | Less |
| FCU / FDP ring-little | Normal | Weak |
| Tinel | Wrist | Elbow; + elbow flexion test |
| Compression site | **Ganglion** in canal | Osborne's ligament / FCU heads / anconeus epitrochlearis |

| Look-alike | Differentiator |
|---|---|
| **Limburg-Comstock** | FPL–FDP index anomalous connection (~20%); cannot flex thumb IP without index DIP |
| Parsonage-Turner | Viral brachial neuritis; shoulder pain; cannot flex thumb IP + index |
| C8–T1 radiculopathy | Neck; dermatomal |
| AIN (Gantzer muscle) | Loss FPL, FDP index, PQ; no sensory loss |

## How it's asked

**"Lesion in Guyon's canal leads to?"** → **both motor + sensory loss** (TO)

**"Ring/little numbness, no weakness, ulnar artery aneurysm?"** → **zone 3 compression** (TO)\
✗ Wrong options: normal EDS · Jeanne · cervical

**"Intrinsic atrophy, normal sensation, lesion at Guyon — zone?"** → **zone 2**

**"Ganglion in Guyon + weak 1st DI — additional finding?"** → **Froment sign**\
✗ Wrong options: dorsal ulnar numbness

**"Dorsal sensation normal, Froment + — EMG fibrillations in?"** → **adductor pollicis**

**"Abducted little finger — weak muscle?"** → **3rd palmar interosseous**

**"Ganglion between TCL and volar carpal ligament — sensory area?"** → **volar ulnar 1½ digits only**\
✗ Wrong options: dorsal ulnar

**"Weak key pinch, volar ulnar numbness, dorsal normal — cause?"** → **ganglion in Guyon's canal**

**"Pure motor, ganglion on MRI/US — next step?"** → **cyst excision**\
✗ Wrong options: biopsy · hamate excision

**"Which study identifies the causative lesion?"** → **MRI wrist**\
✗ Wrong options: EMG/NCV
