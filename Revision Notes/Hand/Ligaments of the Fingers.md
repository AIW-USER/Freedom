# Ligaments of the Fingers

*Hand · 48 / 103*

## 1 Basics

### Retinacular ligaments

![Oblique retinacular ligament](../../Orthobullets/attachments/ob6003-obretlig.jpg)

**Oblique retinacular ligament (Landsmeer)** — links PIP & DIP; **volar to PIP axis, dorsal to DIP axis**; prox phalanx (lateral volar) → terminal extensor

**ORL biomechanics** — PIP flexion → relaxes → DIP flexes; PIP extension → tightens → DIP extends

**ORL tight** — rest DIP extended + PIP flexed; **can't flex DIP with PIP extended**, can after PIP flexed

**ORL pathology** — contracture → **boutonnière**; **ORL reconstruction → swan neck** treatment

**Transverse retinacular ligament** — flexor sheath at PIP → lateral bands; **attenuation → swan neck** (dorsal bands); contracture + triangular lig. attenuation → **boutonnière**

**Triangular ligament** — dorsal, distal to PIP; prevents lateral band subluxation; contracture → swan neck

| Tightness test | MCP extended | MCP flexed |
|---|---|---|
| **Intrinsic tightness** | ↓ PIP flexion | ↑ PIP flexion |
| **Extrinsic (extensor) tightness** | ↑ PIP flexion | ↓ PIP flexion |
| **ORL tightness** | DIP flexion only after PIP flexed | — |

### Expansion hood & MCP ligaments

**Central slip** — base of middle phalanx → **PIP extension**

**Lateral band** — distal phalanx → **DIP extension**; lumbricals, EI, interossei insert

**Lumbrical** — **volar** to deep transverse MC ligament · **interossei dorsal** to it

**MCP cam** — "snoopy head" MC head → collaterals **loose in extension, tight in flexion**

| MCP collateral part | Shape/position | Tight in | Test |
|---|---|---|---|
| **Proper** | Cord, dorsal; MC posterior tubercle → P1 base | **30° flexion** | Stress in 30° flexion |
| **Accessory** | Fan, volar; MC head → volar plate & DTML | **Extension** | Stress in extension |

**RCL vs UCL** — RCL more horizontal

**Deep transverse MC ligament** — joins 2nd–5th MC heads at volar plates; prevents splaying

**Natatory ligament** — most superficial; resists abduction; web space

**Sagittal bands** — volar plate → extensor; centralise extensor over MCP

**Volar plate** — prevents hyperextension; **checkrein ligaments** attach to P1; loose in flexion, tight in extension; thumb sesamoids

## 5 Management

### PIP contracture release sequence

```
Volar PIP flexion contracture release (test extension after each step)
├─ 1 → retract flexors, release CHECKREIN ligaments
├─ 2 → ACCESSORY COLLATERAL + VOLAR PLATE
├─ 3 → PROPER COLLATERAL off proximal phalanx
└─ no active extension → extensor tenolysis
```

**After checkreins** — **accessory collateral ligament + volar plate**\
✗ Wrong options: proper collateral · dorsal capsule · extensor

## How it's asked

**"Released after checkrein ligaments in PIP contracture?"** → **accessory collateral ligament + volar plate**

**"Ligament dorsal to digital nerve, spared in Dupuytren's?"** → **Cleland's**

**"MCP proper collateral tight in?"** → **30° flexion**

**"Transverse retinacular ligament attenuation?"** → **swan neck**

**"Lumbrical relation to DTML?"** → **volar**
