# MCP Joint Arthritis

*Hand · 56 / 103*

## 1 Basics

### Epidemiology

**Frequency in hand** — **DIP > thumb CMC > PIP > MCP** (MCP least common)

**Cause** — mostly **inflammatory** (RA); primary OA rare (**6.1% ♂, 1.4% ♀**; OB: 1–5%); post-traumatic rare

**Sex** — OA & post-traumatic → **men**, younger · inflammatory → **women**; 4th–5th decade

**Risk** — intra-articular fracture, dislocation, rheumatic disease

**Trend** — ↓ incidence with **biologics**

### Anatomy

**Joint** — diarthrodial; MCP = **77% of total finger flexion arc**; ADLs need ~35° (50%)

**Volar plate** — ↑ congruence, prevents hyperextension

**Deep transverse MC ligament** — links **2nd–5th MC heads** at volar plate

| Collateral component | Tight in |
|---|---|
| **Accessory** | **Extension** |
| **Proper** | **30° flexion** |

**Thumb MCP** — 2 sesamoids; **adductor pollicis → ulnar sesamoid**; **FPB → radial sesamoid**; most thumb motion at **CMC**

### Genes & lab markers

| Disease | Mediator | Lab / aspirate |
|---|---|---|
| **RA** | **Neutrophil** proteases, ROS; synovial hypertrophy | **RF, anti-CCP** |
| **Gout** | MSU → **↑ IL-1β** | **Needle-shaped, strongly negatively birefringent** (yellow parallel) |
| **CPPD** | Ca pyrophosphate in synovium | **Rhomboid, weakly positively birefringent** |
| **SLE** | **Interferon-inducible genes** ↑ | **ANA** |
| **Haemochromatosis** | Iron → ↑ IL-1R | **Transferrin saturation, ferritin** |

## 3 Presentation

**OA** — pain, deformity · **inflammatory** — waxing/waning, other joints · **erythema** → gout/CPPD · **periarticular tophi** → gout

**RA fingers** — **ulnar deviation** (also secondary to **radial wrist deviation**) · synovitis attenuates dorsal capsule → **volar translation of proximal phalanx** · volar capsule laxity → **swan neck**

**RA thumb** — EPL displaced ulnar & volar → no active MCP extension · MCP flexion + IP hyperextension → **boutonnière** · **90/90 deformity** · CMC adduction → secondary MCP hyperextension · **gamekeeper's deformity** (UCL attrition) → **first web contracture**

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP, lateral, oblique hand

| Disease | X-ray sign |
|---|---|
| **OA** | Narrowing, osteophytes, subchondral sclerosis, cysts |
| **RA** | **Bone loss dorsal base of proximal phalanx**; volar subluxation, ulnar drift |
| **Gout** | **Punched-out "rat-bite" erosions, overhanging edges**, sclerotic margins |
| **SLE** | **Jaccoud's** (deforming **non-erosive**) · erosive = **"rhupus"** |
| **Haemochromatosis** | **Hook-like osteophytes radial 2nd & 3rd MC heads**; symmetrical narrowing |
| **CPPD** | **2nd–5th MCP**, radial hook osteophytes |

### Larsen radiographic grading (RA)

| Grade | Finding |
|---|---|
| 0 | No change |
| I | Slight; periarticular swelling |
| II | Erosions + definite narrowing |
| III | Medium destruction; joint space poorly defined |
| IV | Severe destruction, collapse |
| V | Mutilating; articular surfaces gone |

## 5 Management

```
MCP arthritis
├─ Mild → NSAIDs, DMARDs, splint, steroid injection
└─ Failed 3–6 mo nonop
       ├─ Thumb MCP → ARTHRODESIS 20–25° flexion + slight pronation
       └─ Index–small MCP → ARTHROPLASTY (silicone / pyrocarbon)
```

**Nonop** — injections **temporary**; intrinsic-plus MCP blocking splint + dexterity exercises ↑ ROM; topical NSAID if GI/renal compromise

**Perioperative DMARDs** — **continue methotrexate & sulfasalazine**; cyclosporine/tacrolimus if severe; **stop biologics** (operate at end of dosing cycle)

### Thumb MCP arthrodesis position

**Gold standard** — **arthrodesis** (silastic arthroplasty = option); well tolerated as motion at CMC & IP

**Position** — **20–25° flexion + slight pronation** → **key pinch** (OB, Orthobullets) · "15° pronation" (Orthobullets technique)

**Advanced TMC disease** — ↑ flexion to **20–40°** offloads TMC

| Fixation | Key numbers |
|---|---|
| K-wire | **83–100% fusion**; ↓ pinch/dexterity; **16.7% complications** (nonunion, **EPL rupture**) |
| **Tension band** | **95% success**; ↓ infection/nonunion vs K-wire |
| Plate | Union **11.8 wk**; positioned 10–15° |
| IM screw | Mean 18°, union **10 wk**, 96% pain relief; MC head fracture, cut-out |

**Immobilise** — 4–6 wk / until union

### Finger MCP arthrodesis

**Indication** — index in **high-demand / young with instability**; otherwise **arthroplasty preferred** (motion)

| Finger | Fusion flexion |
|---|---|
| Index | **20–25°** |
| Long | **30°** |
| Ring | **35°** |
| Small | **40°** |

**Index union** — 84.6% at 11.6 wk

### Rheumatoid MCP arthroplasty

**Indication** — **severe finger MCP arthritis / fixed deformity** (ulnar drift, volar subluxation) → **MCP arthroplasty** = least extensor lag, best ulnar drift correction\
✗ Wrong options: tenosynovectomy · soft-tissue realignment alone · resection arthroplasty

**Soft tissue** — release ulnar collateral, tension radial; repair sagittal band, **centralise extensor**; intrinsic release/transfer (swan neck)

**Results** — arc **27–60°**; extensor lag **9–22°**; ~12° loss by 63 mo; pinch ↑ (index radialised)

### Implant contraindications (pyrocarbon vs silicone)

| | **Silicone** | **Pyrocarbon** | Metal-plastic SRA |
|---|---|---|---|
| Design | **One-piece linked hinge**, spacer; fibrous capsule; 30° preflexed | **Unlinked, non-constrained** surface replacement; no ingrowth | Porous Ti MC + cemented PE |
| Stability from | **Implant itself** | **Collateral ligaments + volar plate** | Soft tissues |
| Best for | **Erosion / deformity (RA)** | **Milder, no deformity; OA** | — |
| Survival | 63–97% | RA 81% (10 y), 70% (16 y); OA > inflammatory | RA 95% / 85% (10/20 y); non-inflammatory 76% (10 y), satisfaction 72% |

**Pyrocarbon contraindication** — **deficient collateral ligaments**

**Not contraindications** — deficient radial sagittal band, radial lateral band, MC head subchondral bone, intermetacarpal ligaments

**Thumb MCP arthroplasty** — RA with fixed deformity or limited IP/CMC motion; silastic survival **83% at 5.8 y**; bone change 4%, fracture 2%

## 6 Complications

**Nonunion (thumb fusion)** — **9%**; risk **tension band**, smoking, DM → revision + distal radius graft

**Infection** — **0.1–1%**; ***S. aureus***; risk DMARDs, RA, DM → superficial 2 wk Abx · deep I&D + removal

**Instability** — RA: **SRA 31%, pyrocarbon 19%**; **pyrocarbon highest acute dislocation**; revision 71% success → **revise to silicone**

**Pyrocarbon** — ↑ failure & recurrent deformity in **inflammatory** arthritis

## How it's asked

**"RA, fixed MCP ulnar drift — least extensor lag at 1 y?"** → **MCP arthroplasty**\
✗ Wrong options: tenosynovectomy, EIP→EDQ, resection

**"Thumb MCP fusion position"** → **20–25° flexion**

**"Thumb MCP fusion — flexion & rotation"** → **20° flexion + slight pronation**\
✗ Wrong options: supination · 40°

**"Pyrocarbon vs silicone contraindication — true?"** → **deficient collaterals contraindicate pyrocarbon**

**"Thumb vs fingers"** → **thumb = arthrodesis; index–small = arthroplasty**
