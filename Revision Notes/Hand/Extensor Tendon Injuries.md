# Extensor Tendon Injuries

*Hand · 28 / 103*

## 1 Basics

### Epidemiology & anatomy

**Commonest digit** — **long finger**; commonest zone **VI**

**Extensor mechanism** — EDC → **central slip** (PIP extension) + **2 lateral bands** (DIP extension)

**PIP flexion** — central slip tensed, lateral bands sublux volar + slacken → DIP lax

**Lateral band restraints (TO)** — **triangular ligament** prevents volar subluxation; retinacular ligaments limit dorsal

**Juncturae tendinum** — link adjacent EDC → partial/temporary extension despite zone V cut (masks injury)

**Retraction (TO)** — extensor tendons **flat distally** · retract less when juncturae + sagittal bands intact → cut end found at wound

**Extensor hood (TO)** — over P1; receives **interossei + lumbricals** volarly → MCP flexion + IP extension · vincula supply from volar side

| Retinacular ligament (TO) | Function | If damaged |
|---|---|---|
| **ORL (Landsmeer)** — P1 + flexor sheath → lateral bands / terminal tendon | Links PIP + DIP: **PIP extension tightens it → helps DIP extension** | Tight → contributes to **boutonnière** |
| **TRL** — flexor sheath at PIP → lateral band edges | **Stops lateral bands shifting dorsally** | **Lax / torn** (laceration, RA synovitis) → **swan neck** · tight + torn triangular → boutonnière |
| **Triangular** — dorsal, between lateral bands over P2 | Holds bands together; prevents volar subluxation | **Attenuated → boutonnière** · contracture → swan neck |

![Juncturae tendinum](../../Orthobullets/attachments/ob6028-junctura.jpg)

## 2 Mechanism

| Zone | Mechanism |
|---|---|
| I | **Forced flexion of extended DIP** |
| II | Dorsal laceration / crush |
| III | Hyperflexion, blunt/penetrating trauma, **volar PIP dislocation**, rotation of flexed PIP (condyle buttonholes through triangular lig.) (TO) |
| V | **Fight bite**; **sagittal band rupture ("flea flicker")** = forced extension of flexed digit, long finger |

## 3 Presentation

**Zone I** — can't extend DIP (mallet)

**Zone III / boutonnière (TO)** — **PIP flexed, DIP hyperextended, can't flex DIP**; may appear **10–14 d** after injury

**Zone V** — extensor lag; **radial sagittal band** (stronger) rupture → tendon subluxes **ulnar**, MCP held flexed, no active extension

### Central slip tests

| Test | Method | Positive |
|---|---|---|
| **Elson** (most reliable, before deformity) | **PIP flexed 90° over table**, extend PIP against resistance | **DIP rigid** (normal = DIP **supple**) |
| Modified Elson (TO) | Both digits PIP fully flexed, middle phalanges back-to-back | Injured DIP extends better |
| **Boyes** (TO) | Extend PIP, actively flex DIP | **Can't flex DIP** — **late** sign |

### Tightness tests

| | **Intrinsic tightness** | **Extrinsic tightness** |
|---|---|---|
| Cause | **Crush → interossei/lumbrical fibrosis** | **Extensor adhesions** (e.g. MC fracture) |
| PIP passive flexion ↓ when | **MCP extended** (Bunnell) | **MCP flexed** |
| Improves with | MCP flexion | **MCP extension** |
| Treatment | Interosseous tenotomy | **Tenolysis / fractional extensor lengthening** ± MC osteotomy |

### Key radiology findings

**X-ray** — AP + lateral digit → exclude **bony mallet** / avulsion

**MRI axial T1** — sagittal band rupture

## 5 Management

```
Extensor tendon injury
├─ Laceration <50% + can extend against resistance → PROTECTED EARLY MOTION
├─ Laceration >50% (any zone) → TENDON REPAIR
└─ Closed injury → SPLINT the joint of the zone
       ├─ Zone I mallet → DIP extension splint 6 wk
       ├─ Zone III central slip → PIP extension splint, DIP free
       └─ Zone V sagittal band → MCP extension splint 4-6 wk
```

### Operative criteria

| Situation | Treatment |
|---|---|
| **Laceration >50% width** | Repair |
| **Bony mallet + P3 volar subluxation** | CRPP through DIP / extension-block pinning; **ORIF if >50% articular surface** |
| **Fight bite to MCP** | **Immediate I&D**, loose/delayed closure; cover **Eikenella** |
| Chronic / irreparable | Reconstruction (2-stage) |
| **Chronic EPL rupture** | **EIP → EPL transfer** |

### Mallet (zone I) splinting

**DIP extension splint** — acute (<12 wk), nondisplaced bony mallet, chronic (>12 wk) if **supple + congruent**; **full-time 6 wk** + part-time 4–6 wk; avoid hyperextension (skin necrosis); keep PIP free; noncompliance common

### Central slip injury – Elson test & PIP extension splinting

**Acute closed central slip** — **PIP extension splint, DIP free to move (active DIP flexion)**; **6 wk** full-time + 4–6 wk part-time (Orthobullets, OB) · **5 wk** (OB) · **4–6 wk round the clock + nights** (TO)

**Why DIP motion** — prevents **oblique retinacular ligament contracture** / adhesions

✗ Wrong options: **Distractors** — full-time DIP splint (mallet), MCP extension splint (sagittal band), **dorsal blocking splint** (dorsal PIP dislocation), immobilising DIP

**Surgery (TO)** — only complete rupture/transection/bony avulsion after failed conservative trial (Doyle, Snow, Aiche)

**Chronic boutonnière >6 wk (TO)** — stiff/arthritic/RA → **PIP arthrodesis**; supple → lateral band relocation, **terminal tendon tenotomy (Fowler/Dolphin, not central slip)**, modified Littler

**Central slip reconstruction** — graft, extensor turndown, lateral band mobilisation, TRL, FDS slip

**Pseudo-boutonnière (TO)** — PIP flexion contracture **without DIP hyperextension**; after **dorsal PIP dislocation / volar plate injury**; can't passively extend PIP


### EPL rupture – EIP transfer

**Drummer's palsy (TO)** — **EPL tendon**; chronic tendinitis from repetitive palmar flexion + ulnar deviation; rubs on **Lister's (dorsal) tubercle** → attenuation/rupture

**Drummer's treatment (TO)** — conservative / activity modification; rupture → **EI to EPL transfer**

**EPL rupture after DRF** — **nondisplaced/minimally displaced DRF**; ~**3 mo**; **nutritional compromise + attrition** → **EIP → EPL transfer** or graft\
✗ Wrong options: primary repair · EPB · observation

### ECU tendinitis/subluxation

**ECU (extensor carpi ulnaris)** — tennis forehand; **dorsoulnar pain** on **supination + wrist flexion + ulnar deviation**; X-ray normal

**Subluxation** — ECU retinaculum ruptures → tendon leaves sheath **in supination**, returns in pronation

**Treatment** — immobilisation; surgery if refractory

### Rheumatoid extensor ruptures (Vaughan-Jackson, EDM)

**Commonest RA tendon rupture (TO)** — **EDM / EDQ** (extensor); **FPL** (flexor)

**Vaughan-Jackson (TO)** — **EDQ first → EDC small → ring → middle → index**; **ulnar → radial**; final stage of **caput ulnae** (dorsal ulnar head subluxation)

**Mechanism (TO)** — attrition on raw dorsal ulnar head + invasive tenosynovitis + ischaemia

**EPL in RA (TO)** — ruptures at **Lister's tubercle** (tortuous course)

**Mannerfelt (TO)** — **FPL** rupture in carpal tunnel over **scaphoid / radial osteophyte**

**Clinical (TO)** — painless "drop finger"; no active MCP extension; passive extension holds (tenodesis) → distinguish from MCP dislocation, **radial nerve palsy**

**Bone work first (TO)** — **Darrach** (low-demand) · **Sauvé-Kapandji** (younger) + dorsal synovectomy; wrist stabilisation if severe radial deviation

| Ruptured tendons (TO) | Reconstruction |
|---|---|
| 1 (EDQ) | Side-to-side to **ring EDC** |
| 2 (EDQ + EDC small) | Side-to-side to **middle EDC** |
| 3 (small, ring, middle) | **EIP transfer** |
| 4 (small → index) | **FDS ring** or **ECRL** transfer |

**Post-op (TO)** — dynamic extension splint 4–6 wk

### Repair technique & reconstruction

**Technique by level (TO)** — distal (flat) tendons: **horizontal mattress** (most used) or **figure-of-8** · proximal (rounder): **modified Bunnell / modified Kessler** · **4-0 non-absorbable** (nylon / Prolene) · bury knots · check tension by **tenodesis effect**

**Splint zones V–VIII (TO)** — EPL repair: thumb full extension · fingers IP straight, MP neutral, wrist mild extension (counteract stronger flexors)

**Zone V fight bite (TO)** — dirty wound → debride, explore, repair sagittal band, cover

**Strength** — **number of strands crossing repair** > grasping loops; 4–6 strands → early active motion; epitendinous optional

**Weakest** — **post-op day 6–12**; fails at **knots**

**Reconstruction** — 2-stage: **silicone rod → graft at 3–4 mo**; grafts: **palmaris longus** (commonest; absent 15%), plantaris (absent 19%, longer), toe extensor

**Tenolysis** — adhesions with ↓ flexion; wait **>3 mo** + full passive ROM; not with procedures needing immobilisation

### Extensor laceration rehabilitation – relative motion splint

**SAM (short-arc motion)** — after **zone III repair**; ↑ arc, ↑ DIP motion, ↓ therapy time; **4 mm excursion**

**Relative motion (yoke) splint** — injured MCP in **relative hyperextension**; **zones IV–VII**

**Yoke benefits** — early active ROM, ↓ adhesions, ↓ ADL interference, adjacent digits free, **high compliance**, earlier RTW; **NOT "better at limiting motion"**

## 6 Complications

| Complication | Key facts |
|---|---|
| **Adhesions** | ↓ flexion; **zones IV & VII**, older pts → **tenolysis at 3–6 mo** |
| **Rupture** | **5%**; days **7–10**; revision or reconstruction |
| **Swan neck** | Prolonged DIP flexion, dorsal lateral bands, PIP hyperextension → **Fowler central slip tenotomy**, SORL reconstruction |
| **Boutonnière** | Central slip + volar lateral bands → splint/serial cast → **terminal extensor tenotomy**, PIP volar plate release |

## X vs Y

| | Boutonnière | Pseudo-boutonnière | Swan neck |
|---|---|---|---|
| PIP | Flexed | **Flexion contracture** | **Hyperextended** |
| DIP | **Hyperextended** | Normal / passive motion | Flexed |
| Cause | **Central slip** (volar PIP disloc.) | **Volar plate** (dorsal PIP disloc.) | Lateral bands dorsal |
| Tenotomy | **Terminal tendon** | — | **Central slip (Fowler)** |

## How it's asked

**"Drummer's palsy involves?"** → **EPL tendon** (TO)

**"Thumb won't extend 3 mo after nondisplaced DRF — next?"** → **EIP → EPL transfer**

**"Tennis forehand, dorsoulnar pain on supination/flexion/ulnar deviation?"** → **ECU tendon**

**"DIP hyperextended, can't flex DIP, PIP flexed — injury?"** → **EDC central slip** (TO)

**"Exam finding in traumatic boutonnière?"** → **PIP flexed, resisted extension → DIP rigid (Elson)**

**"Central slip nonop — which active motion?"** → **DIP flexion**

**"Positive Elson, initial plan?"** → **PIP splint 6 wk, DIP free**

**"Relative motion splint benefits EXCEPT?"** → **better at limiting digit motion**

**"↓ PIP flexion with MCP flexed, improves with MCP extension — Dx & Rx?"** → **extrinsic tightness → tenolysis / fractional lengthening**

**"Most common tendon rupture in RA hand?"** → **EDM** (TO)

**"Lax / torn transverse retinacular ligament causes?"** → **swan neck (lateral bands sublux dorsally)** (TO)

**"Extensor repair technique for flat distal tendon?"** → **horizontal mattress / figure-of-8, 4-0 non-absorbable** (TO)

**"Vaughan-Jackson first tendon & direction?"** → **EDQ, ulnar → radial** (TO)
