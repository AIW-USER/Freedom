# Cleft Hand

*Hand · 12 / 103*

## 1 Basics

### Definition & epidemiology

**Synonyms** — **lobster-claw deformity**, ectrodactyly, split hand

**Definition** — **central longitudinal deficiency** → absence of ≥1 central digits (index, middle, ring) of hand or foot

**Incidence** — **rare (1:10,000–1:90,000)**

**Sex** — **♂:♀ 5:1** (Orthobullets + TO)

**Site** — hands, **usually bilateral**; often feet too (**cleft foot**)

**Absent metacarpals** — present in cleft hand → separates from **symbrachydactyly**

**Small finger** — **always present** on ulnar side

### Pathogenesis

**AER defect** — wedge-shaped degeneration of **central part of apical ectodermal ridge** → loss of signalling → progress zone stops proliferating → central ray defect

**Swanson** — **type I failure of formation** (longitudinal arrest) of central ray

### Genes & inheritance

| | Typical cleft hand | Atypical cleft hand (TO) |
|---|---|---|
| Shape | **V-shaped** central cleft | **U-shaped** |
| Laterality | Bilateral | Unilateral |
| Feet | Cleft foot common | — |
| Nature | Genetic | Form of **symbrachydactyly** (absent/syndactylous/hypoplastic digits) |
| Inheritance | See below | **Sporadic, not inherited**; few syndromes |

**Inheritance (typical)** — **autosomal dominant**, reduced penetrance (**70%**) (Orthobullets, OB) · **X-linked dominant**, incomplete penetrance (TO) — read the options; OB pedigree answer = **AD**

**Severity** — inherited forms **worsen each generation**; sporadic cases = de novo mutation

**Gene** — deletions/inversions/translocations of **7q** → **split hand–split foot syndrome**

**Counselling** — affected families → **genetic counselling**

**Associations** — **EEC syndrome** (ectrodactyly–ectodermal dysplasia–cleft lip/palate), **sensorineural hearing loss**, syndactyly, polydactyly

## 3 Presentation

**History** — ± family history

**Symptoms** — aesthetic > functional limitation

**Exam** — absent/short **central (3rd) ray** · ± absent radial digits · ± **syndactyly of ulnar digits** · ± feet

**Spot diagnosis (TO)** — missing middle ray + **normal thumb–index web** → **type I**

## 5 Management

### Priorities

**Thumb web** — **greater priority** than central cleft

**Sequence** — thumb reconstruction **should not precede cleft closure** (compromises skin flaps)

**Cleft closure** — local tissue flaps from cleft + **close intermetacarpal space**

**Thumb/web options** — web deepening, tendon transfer, rotational osteotomy, toe-to-hand transfer

### Treatment by Manske type

| Type | Web surgery | Central cleft |
|---|---|---|
| **I** | **None** (normal web, no impairment) (TO) | **Cleft closure + reduce intermetacarpal space** ± excise polydactylous bone (TO) |
| IIA | **4-flap Z-plasty** (TO) | Dorsal/palmar cleft flaps + reduce IM space |
| IIB | Cleft flaps transposed into thumb web | Close with web procedure; IM space reduced by **ligament reconstruction** |
| III | **Priority to web**: cleft flaps + thumb–index syndactyly release + skin graft | Local pedicle flaps; ligament reconstruction |
| IV | Usually none (less impairment); **MCP arthrodesis**, excise excess skin | — |
| V | **None**; consider **free toe-to-hand transfer** → converts to type IV | — |

**Conflict — type I** — **observation** for types I & IV (Orthobullets) · **no web surgery but cleft closure + IM reduction** for type I (TO) — read the options

**Operative indication (Orthobullets)** — types **IIA, IIB, III, V** → web + thumb + cleft reconstruction

### Prognosis

**Function** — depends on **1st web space involvement**

**Classic line** — **aesthetically displeasing, not functionally limiting**

## X vs Y

| | **Cleft hand** | **Symbrachydactyly** |
|---|---|---|
| Metacarpals | **Absent** | Present (rudimentary nubbins) |
| Shape | V | U ("atypical cleft") |
| Laterality | **Bilateral** | Unilateral |
| Feet | Involved | Not |
| Inheritance | Familial | Sporadic |

## How it's asked

**"Pedigree for cleft hand inheritance?"** → **autosomal dominant**\
✗ Wrong options: AR, X-linked recessive, X-linked dominant, mitochondrial

**"Missing middle ray, normal web — type and treatment?"** → **Manske type I: no web surgery; cleft closure + reduce intermetacarpal space** (TO)

**"Type IIA web surgery?"** → **4-flap Z-plasty** (TO)

**"Which comes first, thumb or cleft?"** → **thumb web has priority, but thumb reconstruction must not precede cleft closure**

**"Feature separating cleft hand from symbrachydactyly?"** → **absent metacarpals**, bilateral, feet involved

**"Associated syndrome?"** → **EEC syndrome**
