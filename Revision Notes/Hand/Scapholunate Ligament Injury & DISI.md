# Scapholunate Ligament Injury & DISI

*Hand · 82 / 103*

## 1 Basics

### Epidemiology

**Acute** — **10–30%** of intra-articular DRF / carpal fractures (Orthobullets) · **30%** of DRF (OB)

**Degenerative** — tears in **>50% of >80-y-olds**; incomplete > complete

**Commonest carpal instability (TO)** — **SL instability / DISI** = commonest form of **CID** (carpal instability dissociative)

### Anatomy – dorsal SLIL is strongest

**SLIL** — **C-shaped**; **dorsal, proximal (membranous), volar** components

| SLIL component | Thickness | Role |
|---|---|---|
| **Dorsal** | **3 mm** | **Strongest; greatest constraint to SL translation**; must tear for dissociation |
| Volar | 1 mm | 2nd |
| Proximal (fibrocartilaginous membrane) | — | **Minimal strength** |

**Yield strength** — **dorsal > volar > proximal**

**Intercalated segment (TO)** — scaphoid, lunate, triquetrum: **no tendon insertions**

**Balance** — scaphoid wants to **flex** (oblique, distal row pull, RSC); triquetrum + lunate want to **extend**; SLIL = tether

**Secondary stabilisers (TO)** — DRCL, **DIC**, **scaphotrapezial (STT)**, **RSC**, scaphocapitate

**SLIL alone cut** — no static change; needs ≥1 secondary stabiliser (TO)

## 2 Mechanism

**Injury** — FOOSH with **wrist extension + ulnar deviation + carpal supination**; also repetitive (crutch walking) (TO)

**Pathoanatomy** — **scaphoid flexes + lunate extends** → **DISI** → untreated → **SLAC**

### Secondary stabilisers & progression to static DISI

| Stage (TO) | Ligaments | X-ray |
|---|---|---|
| **Dynamic instability** | SLIL torn/incompetent; secondary stabilisers intact | **Normal static**; abnormal on **stress / clenched fist** |
| **Static (SL dissociation)** | SLIL + secondary stabiliser | Abnormal static → DISI |
| **SLAC** | Attritional changes | Progressive arthritis |

**Primary secondary stabiliser (TO)** — **STT ligament complex** (+ scaphocapitate) → failure = **dynamic → static DISI**\
✗ Wrong options: DIC · space of Poirier · volar radiolunate

**Static DISI = repair window passed (TO)** — reconstruction / capsulodesis / salvage

### Iatrogenic DISI after distal scaphoid excision

**Distal pole scaphoid excision (for STT OA)** — shortens scaphoid → triquetral extension moment dominates → **DISI** (SL angle 80°)

**Do not cause DISI** — STT fusion, trapezoid resection, LRTI, 4-corner fusion

| STT procedure | Complication |
|---|---|
| **Distal scaphoid excision** | **DISI**; **flexor** tendon rupture (sharp remnant) |
| STT fusion | **Radial styloid impingement ~33%**; adjacent OA radiocarpal 42%, TMC 28% |

**STT OA** — 2nd commonest carpal OA; linked to thumb CMC OA; options: distal pole excision, STT fusion, pyrocarbon

## 3 Presentation

**Symptoms** — **dorsoradial wrist pain**, ↑ with loading (**push-ups**), clicking, ↓ grip, giving way

**Tenderness** — snuffbox / **dorsal SL interval just distal (~1 cm) to Lister's tubercle**

**Watson (scaphoid shift) test** — thumb on **volar scaphoid tubercle**, wrist **ulnar → radial deviation** → proximal pole subluxes dorsally → **painful clunk** on release

## 4 Diagnosis & Classification

### Diagnosis – clenched-fist views, scapholunate angle & DISI

**Next step, normal PA after FOOSH with dorsal tenderness** — **(bilateral) PA clenched-fist view** (capitate driven proximally)\
✗ Wrong options: arthroscopy first · CT · EMG

**Not radial deviation PA** — **closes** SL gap

![Clenched-fist view widening SL gap](../../Orthobullets/attachments/ob6041-reivew-clenched-fist.jpg)

### Key radiology findings

| View / sign | Threshold / meaning |
|---|---|
| **Terry Thomas** (PA / clenched fist) | **SL gap >3 mm** |
| **Cortical ring sign** | Flexed scaphoid seen end-on |
| Scaphoid | Shortening; **humpback** = unstable scaphoid fracture / malunion |
| **SL angle (lateral)** | Normal **30–60°** (TO) · **30–70°** (OB); **>70° = DISI / SL dissociation**; static DISI **>60° (often >80°)** (TO module) |
| **Radiolunate angle** (TO) | Normal **15° ext – 15° flex**; **>15° extension → DISI** |
| **Capitolunate angle** | **>20°** (Orthobullets) · **>15°** (TO) |
| Carpal height ratio | ↓ as collapse progresses |
| **VISI** | SL angle **<30°** |

| Modality | Fact |
|---|---|
| Arthrography | Screens; shows tear but **not size**; compare contralateral |
| MRI | Overused; **low sensitivity** |
| **Arthroscopy** | **Gold standard** |

### SLAC stages (TO)

| Stage | Arthritis |
|---|---|
| I | **Radial styloid–scaphoid** |
| II | Whole radioscaphoid |
| III | **Capitolunate (midcarpal)** |
| IV | Pancarpal incl. radiolunate |

**Radiolunate joint (TO)** — **preserved** in SLAC; SL joint itself spared until late (OB)

### Perilunate spectrum (rocking lunate, Mayfield I)

| Mayfield stage (TO) | Injury |
|---|---|
| **I** | **SL dissociation / scaphoid fracture / scaphoid rotation** (scaphoid fracture **not always** present) |
| II | Lunocapitate → perilunate dislocation |
| III | **LT disruption** / triquetral dislocation |
| IV | **Lunate dislocation** (extruded) |

![Mayfield stages](../../MCQ/attachments/TO17141691-2.png)

**Rocking lunate (TO)** — **SL + LT ligament tears**

**SL tear (TO)** → ↑ SL angle (lunate follows triquetrum into extension) · **LT tear** → ↓ SL angle

## 5 Management

```
SLIL injury
├─ Acute undisplaced / chronic asymptomatic → NSAIDs, splint, repeat imaging
├─ Acute, reducible, repairable → OPEN REPAIR + K-wires ± dorsal capsulodesis
├─ Reducible, not repairable or >18 mo → RECONSTRUCTION (FCR / Brunelli)
└─ Fixed unreducible DISI or SLAC → SALVAGE
       ├─ SLAC I-II → PRC or scaphoid excision + 4-corner fusion
       ├─ SLAC III → 4-corner fusion
       └─ SLAC IV → total wrist arthrodesis
```

### Operative criteria

| Indication | Treatment |
|---|---|
| **Acute**, no malalignment, repairable | **SL ligament repair** |
| Chronic **reducible**, **<18 mo** (Orthobullets) · **<6 wk** acute (TO) | Repair |
| Acute non-repairable or reducible **>18 mo** | **Reconstruction** |
| Pathoanatomy = scaphoid fracture | ORIF / CRPP ± arthroscopy |
| **Rigid unreducible DISI** / severe DJD | **STT or SLC fusion** (SL fusion alone → **highest nonunion**) |

### Acute repair

**Acute SL dissociation (5 days)** — **open repair + percutaneous pinning**\
✗ Wrong options: cast · arthroscopic pinning · capsulodesis (for chronic missed)

**Technique** — incision distal to radial styloid (protect **radial sensory n.**); 2 parallel K-wires in scaphoid → **joystick scaphoid into extension/supination/ulnar dev, lunate into flexion/radial dev** → drive into lunate; suture anchors

**Augment** — **Blatt / Berger dorsal capsulodesis** (DIC advancement); alone for chronic when repair not feasible

**Post-op** — K-wires out **8–10 wk**; no heavy labour 4–6 mo

**Casting alone** — insufficient for most; may suit incomplete tears

### Reconstruction

**Options** — **FCR transfer (modified Brunelli, direct reduction)**, ECRB tenodesis (indirect), **3LT**, SLAM, **RASL** (screw, sacrifices motion), bone-ligament-bone graft; **avoid weave** (late failure)

**Salvage (TO)** — **4-corner fusion** (keeps ~50% flex-ext; preserves radiolunate) · **PRC** (needs intact **capitate head + lunate fossa**)

## 6 Complications

**List** — **SLAC progression**, arthritis, post-op pain, stiffness, fatigue, ↓ grip

## X vs Y

| | **DISI** | **VISI** |
|---|---|---|
| Ligament | **SLIL (dorsal)** | **LTIL** + dorsal radiotriquetral ± volar radiolunate |
| Lunate | **Extended** | **Flexed** (triquetrum extends) |
| SL angle | **>70°** | **<30°** |
| Pain | Dorsoradial | **Ulnar**, ↑ pronation + ulnar deviation |
| Tests | **Watson** | **LT shuck / Reagan ballottement, Kleinman shear** |
| Normal variant? | **Always pathological** | Can occur with **ligamentous laxity** |
| Frequency | Commoner | Less common; LT arthrodesis nonunion 20–40% |

| Carpal translation | Ligament |
|---|---|
| **Ulnar translation** of carpus | **RSC** (radiocarpal dislocation, PRC) |
| **Volar translation** | **Short radiolunate** (volar-ulnar critical corner) |
| Lunotriquetral fusion | Commonest **carpal coalition** |

## How it's asked

**"True about SL dissociation EXCEPT"** → **SL angle 45° in advanced cases** (TO)

**"FOOSH, SL gap 3.7 mm, radiolunate 25° extension — Dx?"** → **SL instability with DISI** (TO)

**"SL dissociation, all true EXCEPT"** → **VISI** (TO) (✓ DISI, Terry Thomas, cortical ring)

**"Watson +, PA normal — best view?"** → **PA clenched fist**\
✗ Wrong options: radial deviation · carpal tunnel view

**"6 d after rollerblading, dorsal tenderness, normal X-rays — next?"** → **bilateral PA clenched-fist X-ray**

**"Radiographic finding of DISI?"** → **lunate extended relative to scaphoid**\
✗ Wrong options: SL angle <30°

**"Untreated SL injury — first carpal deformity?"** → **scaphoid flexion**\
✗ Wrong options: lunate flexion · humpback

**"SL angle 80° — which ligament?"** → **dorsal scapholunate**

**"72-y SL gap after MVA — ligament?"** → **dorsal SL interosseous**

**"Acute SL dissociation, footballer, 5 d?"** → **open repair + percutaneous pinning**

**"DISI 2 y after STT surgery — index operation?"** → **distal scaphoid resection**

**"Counsel before distal pole scaphoid excision?"** → **DISI**

**"Secondary stabiliser whose failure → static DISI?"** → **STT ligament complex** (TO)

**"Mayfield stage I true?"** → **scaphoid fracture not always present** (TO)

**"Rocking lunate results from?"** → **SL + LT ligament tear** (TO)
