# Basilar Thumb Arthritis

*Hand · 6 / 103*

## 1 Basics

### Epidemiology

**Frequency in hand** — **DIP > thumb CMC > PIP > MCP** (2nd most common hand OA)

**Who** — **postmenopausal ♀**, Caucasian; 40% ♀ / 25% ♂ >75 y

**Second patient group** — young **manual labourer**, post-traumatic (old intra-articular #) → fusion candidate

**Associated** — **CTS in up to 50%** · **MCP hyperextension** · STT OA (62% at trapeziectomy)

### Anatomy

**Joint** — trapeziometacarpal (TMC) = **biconcave saddle**; CMC joint reactive force = **13× pinch force**

**Anterior oblique (volar beak) lig** — **primary stabiliser vs subluxation**; palmar tubercle trapezium → ulnar MC base; **its attenuation = cause of OA**

**Dorsoradial lig** — **strongest/thickest**; primary restraint to **dorsal dislocation**

**Intermetacarpal lig** — 2nd MC base → 1st MC base; restrains radial translation

**FCR** — runs in palmar groove of trapezium (used in LRTI)

![Ligament anatomy](../../Orthobullets/attachments/ob6054-ligament-anatomy.jpg)

## 2 Mechanism

**Beak lig attenuation** → **dorsoradial subluxation** of MC base → cartilage wear

**Z (zig-zag) deformity** — painful abduction avoided → **MC adduction + palmar flexion** → 1st web contracture → **compensatory MCP hyperextension** (EPB pull) → ± IP flexion

**NOT a sequela** — **CMC extension deformity** (EXCEPT question)

**Why MCP hyperext matters** — left untreated → deforming force → recurrent MC subluxation after CMC surgery

![Z deformity forces: arrowhead = MC base subluxation, arrow = EPB vector](../../MCQ/attachments/q3669-illa-zigzag-deformity-cmc.jpg)

## 3 Presentation

**History** — pain at thumb base, ↓ **pinch/grip**, worse **opening jars**, key pinch

**Exam** — TTP over CMC · **grind test** (axial load + circumduction) · **shear test** (circumduction + translation) · crepitus

**Late signs** — **MC adduction**, 1st web contracture, **fixed MCP hyperextension (Z)**

![Z deformity of thumb](../../MCQ/attachments/q4730-a-fig-a-z-deformity-of-thumb.jpg)

## 4 Diagnosis & Classification

### Key radiology findings

| Finding / view | Fact asked |
|---|---|
| **Roberts view** | True AP of TMC: thumb flat, **hyperpronated**, beam on trapezium |
| Standard series | AP + lateral hand |
| OA signs | Joint space narrowing, sclerosis, osteophytes (**<2 mm = II, >2 mm = III**), dorsoradial subluxation of MC base |
| **STT involvement** | = **Eaton IV (pantrapezial)** → contraindicates CMC fusion |
| **MCP hyperextension** | Seen on lateral / clinical → measure angle (drives MCP treatment) |
| STT OA + **DISI** | Lateral: extended lunate, volar-tilted capitate → STT fusion, not distal pole excision |
| After trapeziectomy | **MC subsidence** (~25%) → no clinical effect |

![MCP hyperextension on radiograph](../../Orthobullets/attachments/ob6054-hyperextnsion.jpg)

### Eaton–Littler classification

**Eaton–Littler** — radiographic; **stage IV = pantrapezial (STT)** → decides fusion vs not; historical value, limited clinical utility

| Stage | Radiograph | Key decider | Image |
|---|---|---|---|
| I | **Joint widening** (pre-arthritis, laxity) | Osteotomy / volar lig recon | ![I](../../Orthobullets/attachments/ob6054-stage1.jpg) |
| II | Narrowing, sclerosis, **osteophytes <2 mm** | Osteotomy if stable; fusion (labourer) | ![II](../../Orthobullets/attachments/ob6054-early-stage-stage-ii.jpg) |
| III | Marked narrowing, **osteophytes >2 mm** | Trapeziectomy; **fusion if young labourer** | ![III](../../Orthobullets/attachments/ob6054-stage3.jpg) |
| IV | **Pantrapezial — STT involved** | Trapeziectomy (± prox ⅓ trapezoid); **no fusion** | ![IV](../../Orthobullets/attachments/ob6054-stage4.jpg) |

**Differentials** — **C6 radiculopathy** (neck → thumb/index paraesthesia) · **de Quervain** (Finkelstein +) · **STT OA** (TTP just proximal to TMC) · SNAC / radioscaphoid OA (on X-ray)

## 5 Management

### Nonoperative care – splinting & injections

**1st line** — NSAIDs + **thumb spica / night splint**

**2nd line** — **steroid injection** (moderate evidence)

**RCT trap** — **saline = steroid = hylan** (all ≈ 3 mo relief; Heyworth) → answer "all equally effective"

**Hyaluronic acid** — not indicated (no better than placebo/steroid)

**Thumb MCPJ OA (post-RCL insufficiency, labourer)** — 1st: **spica 4–6 wk + NSAIDs** → fail → **MCP fusion** (5–20° flex, 15° pronation); no arthroplasty in lig-deficient thumb/labourer

### Operative algorithm by stage

```
Failed nonop
├─ Stage I–II, stable joint, MCP hyperext <10° → 1st MC dorsal closing-wedge EXTENSION osteotomy
│      (unstable/hypermobile Stage I → volar lig recon with FCR)
├─ Stage II–III, young male heavy labourer, NO STT OA → CMC ARTHRODESIS
└─ Stage III–IV (most patients) → TRAPEZIECTOMY ± LRTI / suspension
       (Stage IV → + excise proximal ⅓ trapezoid)
```

### Operative criteria

| Procedure | Indication | Contraindication |
|---|---|---|
| Arthroscopic debridement | Early stage (I–II) | Stage III–IV |
| Volar lig recon (FCR) | **Stage I, hypermobile/unstable** | Established OA |
| **1st MC extension osteotomy** | **Stage I–II**, stable joint | **Hypermobile/fixed subluxed CMC · MCP hyperext >10°** |
| **CMC arthrodesis** | **Stage II–III, young (<50) male heavy labourer**, post-traumatic | **STT (pantrapezial) OA** |
| **Trapeziectomy ± LRTI** | **Stage I–IV** (most patients, older ♀) | Young heavy labourer (relative) |
| + excise proximal ⅓ trapezoid | **Stage IV** / ST-trapezoid OA (62%) | — |
| Prosthetic arthroplasty | not recommended | Lig-deficient thumb, labourer |
| **MCP fusion** | MCP hyperext **>30–40°**, not correctable, MCP OA | — |

**Osteotomy contraindications** — **hypermobile / fixed subluxed CMC** · **MCP hyperext >10°** (volar joint stays overloaded)

**Osteotomy result** — unloads volar joint; 93% improved at 7 y

**Arthroscopic debridement** — early stage only; portals **1R** (radial to APL) & **1U** (ulnar to EPB)

**Prosthetic arthroplasty** — not recommended; silicone → **silicone synovitis**; pyrocarbon → subluxation (shallow cup)

**Denervation** — resect 4 nerves; pain ≈ trapeziectomy/fusion; ROM > fusion

### Trapeziectomy ± LRTI – equivalence, technique & complications

**Key fact** — **trapezial excision is the essential step**; **no technique superior** to trapeziectomy alone

**LRTI vs trapeziectomy alone** — **no difference** in pain, grip, **key pinch**, ROM, DASH, subsidence → answer "**no benefit of LRTI**"

**Complications** — LRTI/Weilby **> complications** than simple trapeziectomy (OR 4.3)

**Tendon for LRTI** — **FCR** most common; alternatives **ECRL** or **APL**\
✗ Wrong options: FPL

**FCR avulsed intra-op (trapezium already out)** — **LRTI with ECRL**\
✗ Wrong options: fusion (no trapezium left) · implant

**Revision after FCR LRTI** — use **APL**

**Subsidence** — ~**25%** (21% rest, +11% pinch) → **no effect on outcome** → **observe**

**Hematoma arthroplasty** — trapeziectomy alone ± pin; simple, cheap, = LRTI

**Wagner approach — radial artery** — **most at risk**: dorsoradial capsule **proximal to trapezium** · **least at risk**: level of **1st MC base / TMC joint**

**Other nerve at risk** — superficial radial nerve

![Subsidence after trapeziectomy → observe](../../MCQ/attachments/q214671-a-subsidence.jpg)

### MP hyperextension – MP fusion/capsulodesis with CMC reconstruction

**Must address at CMC surgery** — else adduction contracture + recurrent subluxation

| MCP hyperextension | Treatment |
|---|---|
| **<10°** | Nothing |
| **10–20°** | **Pin MCP in 25–35° flexion × 3–4 wk** ± EPB transfer |
| **20–40°** | **Volar capsulodesis** or sesamoidesis |
| **>40°** (or >30° in some stems), not passively correctable, MCP OA | **MCP arthrodesis** |

**Mild (<30°) untreated** — 1-y outcome **same** as no hyperextension (key pinch, grip, abduction) → "no significant difference"

**Classic answer** — end-stage CMC + MCP hyperext 40° → **CMC resection arthroplasty + MCP fusion**

**Failed LRTI + MCP 60°** — **CMC revision stabilisation (APL) + MCP fusion**\
✗ Wrong options: pinning alone

### CMC arthrodesis – young labourers & contraindications (pantrapezial arthritis)

**Indication** — **young (<50) male heavy labourer**, stage II–III, post-traumatic → **preserves grip**, stable

**Contraindication** — **STT / pantrapezial OA (stage IV)**\
✗ Wrong options: radiocarpal OA · chronicity · post-traumatic

**Position** — 35° radial abduction · 30° palmar abduction · 15° pronation

**Main complication** — **nonunion 8–21%** (~12–17%); also STT/MCP OA (mostly asymptomatic)

**Downside** — ↓ ROM, **can't lay hand flat**

**Avoid in labourer** — trapeziectomy/LRTI (↓ grip, no salvage), arthroplasty (bone loss)

![CMC fusion](../../Orthobullets/attachments/ob6054-fusion.jpg)

### STT arthritis – STT arthrodesis

**STT OA** — 16% of population, ♀ >50; pain with pinch; tender proximal to TMC; associated **type II lunate**

**STT OA + DISI (extended lunate, volar-tilted capitate)** — **STT arthrodesis** (lowest revision risk)

**Avoid distal pole excision with DISI** — worsens midcarpal instability → revision

**Avoid CMC arthrodesis for STT OA** — STT not addressed, ↑ shear

![STT OA with DISI on lateral](../../MCQ/attachments/q211336-b-stt-disi-lateral.jpg)

## 6 Complications

**After trapeziectomy** — MC subsidence (asymptomatic → observe); radial artery; superficial radial n.

**If subsidence symptomatic & FCR used** — LRTI with **ECRL or APL**

**After fusion** — nonunion; adjacent STT/MCP OA

**After silicone implant** — **silicone synovitis**, implant fracture/loosening

**Prognosis** — OA in one joint of a row predicts OA in other joints of same row

## How it's asked

**"Compared with trapeziectomy alone, which gives superior pain relief / key pinch?"** → **None of the above**

**"Which injection gives greatest improvement?"** → **All equally effective** (saline = steroid = hylan)

**"Radiograph 1 y after trapeziectomy shows subsidence — next?"** → **Observation**

**"FCR avulsed during LRTI — next?"** → **ECRL LRTI**

**"35-y mechanic / rancher, TMC OA, no STT"** → **CMC arthrodesis**; complication asked → **nonunion**

**"Contraindication to CMC arthrodesis?"** → **Pantrapezial (STT) arthritis**

**"Contraindication to osteotomy?"** → **CMC hypermobility / MCP hyperextension >10°**

**"All are sequelae EXCEPT"** → **CMC extension deformity**

**"Patient with STT OA + DISI — surgery that avoids secondary procedure?"** → **STT arthrodesis**

**"MCP hyperextension 9.8°/ <30° untreated — outcome?"** → **No significant difference**

**Stem clue: deformity with web contracture + MCP hyperextension** → **TMC OA**\
✗ Wrong options: hypoplasia · median neuropathy · lupus · tendon rupture
