# Intrinsic Minus Hand (Claw Hand)

*Hand · 44 / 103*

## 1 Basics

### Etiology

**Definition** — **MCP hyperextension + PIP/DIP flexion** from **strong extrinsics vs deficient intrinsics**

**Ulnar nerve palsy** — cubital tunnel, ulnar tunnel

**Median nerve palsy** — Volkmann's ischaemic contracture, **leprosy**, crush hand not splinted intrinsic-plus

**Others** — **Charcot-Marie-Tooth** (HMSN), **compartment syndrome of hand**

## 2 Mechanism

### Mechanism – strong extrinsics & deficient intrinsics

**Loss of intrinsics** — lose MCP flexion + IP extension

**Strong EDC** — unopposed **MCP extension**; not a significant PIP extensor (central slip force mostly from interossei)

**Strong FDP + FDS** — unopposed **PIP & DIP flexion**

**Crush hand splinted in MCP extension** — ↑ extrinsic flexor tension → **PIP flexion** (claw); splint **intrinsic-plus**

**Hand compartment syndrome** — most consistent sign: **tense swollen hand in intrinsic-minus position**; Rx fasciotomy; full function unlikely after ischaemic contracture

![Pathoanatomy](../../Orthobullets/attachments/ob6010-shows-pathoanatomy.jpg)

| Deformity | Pathoanatomy |
|---|---|
| **Claw / intrinsic minus** | **Strong extrinsics + deficient intrinsics** |
| Intrinsic plus | **Spastic intrinsics + weak extrinsics** → MCP flexion, IP extension |
| Swan neck | **Volar plate laxity** + dorsal lateral band tethering → PIP hyperext, DIP flexion |
| **Lumbrical plus** | **FDP laceration distal to lumbrical origin** → paradoxical IP extension on flexing |
| **Quadriga** | **Adhered FDP** (one finger) → flexion lag adjacent digits |

## 3 Presentation

**Exam** — MCP hyperextension + IP flexion; ↓ grasp, grip, pinch

**Ulnar palsy** — worst in **ring & little** (ulnar lumbricals); index/middle less (median lumbricals)

![Claw hand](../../Orthobullets/attachments/ob6010-claw-hand-moved.jpg)

### Ulnar nerve palsy – claw, ulnar paradox & Bouvier test

**Low ulnar (wrist) cut (TO)** — **clawing ring + little** (lumbricals 3–4), **can't abduct/adduct** (interossei; can't abduct middle finger), **can't pinch** (adductor pollicis), thumb hyperextension

**Ulnar supply in hand (TO)** — deep br.: ADM, FDM, ODM, **adductor pollicis**, **deep head FPB**, **all interossei** (PAD/DAB), **medial 2 lumbricals**; superficial br.: palmaris brevis

**Lumbricals (TO)** — arise from FDP → dual supply like FDP

**Ulnar paradox (TO)** — **higher lesion → less clawing**; due to **FDP** (ulnar half) paralysis at/above elbow; distal lesion spares FDP → more claw\
✗ Wrong options: FDS, FCU, FCR

**Sign rule (TO)** — every deformity is produced by the **muscle that still works, overacting** for the paralysed one · claw of **all 4 fingers = combined ulnar + median** (Duchenne sign)

| Other ulnar sign (TO) | Finding | Cause |
|---|---|---|
| **André-Thomas** | Wrist flexes when trying to extend IPs | Tenodesis compensating for lumbricals |
| **Bunnell O sign** | Can't make round "O" thumb–index | Adductor pollicis + deep FPB lost; FPL takes over |
| **Earle-Vlastou** | Can't cross middle over index | Interossei |
| **Egawa (table-top)** | Can't abduct/adduct middle finger with MCP flexed | Interossei |
| **Card test** | Card pulled easily from between index + middle | Interossei |
| **Pitres-Testut** | Hand flat, can't abduct middle; can't make cone | Palmar + dorsal interossei |
| **Mumenthaler** | No hypothenar dimple on little abduction | Hypothenar + palmaris brevis |
| **Sunderland** | Can't oppose little finger to thumb | FDM, ODM, ADM |
| **Inverted pyramid** | Hollow triangle central palm (chronic) | Transverse head adductor pollicis wasting |
| **Confrontation** | Abducted little fingers opposed → palsied one pushed over | Interossei |

**Examine whole nerve length (TO)** — multiple sites possible (cubital tunnel + Guyon's + brachial plexus schwannoma) · recovery after repair: **radial > median > ulnar** (slowest)

**Deformities (TO)** — **intrinsic plus = safe splinting position** (collaterals relaxed) · swan neck + boutonnière can develop in long-standing ulnar / combined palsy

## 4 Diagnosis & Classification

### Bouvier test

**Bouvier (TO)** — guides **claw correction**; block MCP hyperextension (~10° flexion) → watch active PIP extension

| Result | Meaning | Surgery |
|---|---|---|
| **Positive** (PIP extends; assisted angle 0) | **Simple claw**; extensor mechanism intact | Any procedure **preventing MCP hyperextension** → **static** (MCP capsulodesis, pulley advancement) |
| **Negative** (PIP stays flexed) | **Complex claw** | Needs extensor augmentation / flexor or joint correction |

| Negative Bouvier subtype (TO) | Cause | Clue |
|---|---|---|
| Passive positive | **Stretched central slip** (long-standing) | — |
| Passive negative, tenodesis positive | **Long flexor shortening** | PIP extends with **wrist flexed** |
| Passive negative, tenodesis negative | **Stiff PIP** (volar plate / collateral contracture) | No extension even with wrist flexion |

## 5 Management

```
Claw hand (progressive, ↓ QoL)
├─ Bouvier positive (simple) → STATIC: capsulodesis / pulley advancement / tenodesis
└─ Bouvier negative (complex) → active tendon transfer + extensor/flexor/joint correction
```

**Goal** — **prevent MCP hyperextension**

**Static procedures correct MCP hyperextension only (TO)** — no independent intrinsic action

| Static procedure (TO) | Technique |
|---|---|
| **Zancolli capsulodesis** | **A1 cut**, U-flap of MP volar plate advanced proximally → MP \~30° flexion |
| Omer capsulodesis | Volar plate flap advanced to tighten capsule |
| **Parkes tenodesis** | Grafts from TCL, **volar to deep transverse MC ligament** → radial lateral bands |
| Fowler / Riordan tenodesis | Fowler: grafts to extensor retinaculum · Riordan: distally based strips of ECRL + ECU |
| **Zancolli lasso** | Low ulnar: ring + small FDS divided distal to A1, **looped round A1**, sutured to itself |

| Dynamic procedure (TO) | Donor → insertion | Notes |
|---|---|---|
| **Modified Stiles-Bunnell (Littler)** | **Ring FDS** → 2 slips → lumbrical canals → radial lateral bands ring + little | **Isolated LOW ulnar only** (FDP must work) · suture wrist neutral, MP 45–55°, IP extended · splint intrinsic plus 3–4 wk |
| Middle finger FDS | — | **High ulnar palsy** (ring FDS not expendable in high / combined) · risk swan neck, donor PIP contracture |
| **Brand EE4T** | **ECRB** + 4-tailed graft, **extensor route** through intermetacarpal spaces → lateral bands | Median function uncertain |
| **Brand EF4T** | **ECRL** + graft via **carpal tunnel (flexor route)** | Same insertions |
| **Fritschi PF4T** | **Palmaris longus** | Weak donor |
| **Palande** | Ring FDS in **5 slips** (or ECRL ± PL) → interossei + hypothenar | **Direct interossei activation** → abduction/adduction |

**Lateral band insertion (TO)** — **ulnar side of index**, **radial side** of middle, ring, little

| Other ulnar transfer (TO) | Procedure |
|---|---|
| Little finger abduction (Wartenberg) | **Fowler: ulnar half of EDM** volar to DTML → radial collateral ligament P1 base |
| Thumb adduction / key pinch | **Smith: ECRB + graft** via 2nd intermetacarpal space → adductor tubercle · Littler / Brand: ring FDS |
| Index abduction | **Bunnell: EIP + graft → 1st DI** · Bruner: EPB · Hirayama: PL · Riordan: ring FDS · Neviaser: accessory APL |
| High ulnar (FDP ring/little + FCU lost) | **Side-to-side FDP middle → ring + little** or middle FDS → FDP ring/little · FCR → FCU (rare) |

| Combined palsy (TO) | Order |
|---|---|
| **Low** | Prevent 1st web contracture → index abduction (APL) → thumb adduction (Smith ECRB / ring FDS) → opponensplasty (EIP) → claw correction (EF4T) last |
| **High** | **Finger flexion first** (ECRL → FDP) → BR → FPL → EIP opponensplasty → tenodesis / capsulodesis → **FDMA flap** (radial-innervated) for thumb-tip sensation |

**Ulnar nerve transfers (TO)** — **AIN (PQ branch) → deep motor ulnar** at forearm · fascicle topography **sensory–motor–sensory** (motor central) · sensory: median 3rd web fascicle → ulnar sensory; dorsal cutaneous end-to-side to median · release Guyon's / carpal tunnel

## How it's asked

**"Crush hand splinted in MCP extension — deformity?"** → **PIP flexion**

**"Claw after crush/compartment syndrome — pathoanatomy?"** → **strong extrinsics + deficient intrinsics**\
✗ Wrong options: spastic intrinsics = intrinsic plus

**"Ulnar paradox due to"** → **FDP** (TO)

**"Wrist cut: claw ring/little, can't pinch, can't abduct middle — nerve?"** → **ulnar** (TO)

**"Bouvier test helps correction of"** → **claw deformity** (TO)

**"EE4T stands for?"** → **ECRB, Extensor route, 4 Tails (Brand)** (TO)

**"Direct interossei activation transfer?"** → **Palande** (TO)

**"Stiles-Bunnell ring FDS transfer — contraindicated in?"** → **high ulnar palsy** (FDP ring/little lost) (TO)
