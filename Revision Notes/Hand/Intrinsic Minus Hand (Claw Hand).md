# Intrinsic Minus Hand (Claw Hand)

*Hand · 44 / 103*

## 1 Basics

### Etiology

**Definition** — **MCP hyperextension + PIP/DIP flexion** from **strong extrinsics vs deficient intrinsics**

**Ulnar nerve palsy** — cubital tunnel, ulnar tunnel

**Median nerve palsy** — Volkmann's ischaemic contracture, **leprosy**, crush hand not splinted intrinsic-plus

**Others** — **Charcot-Marie-Tooth** (HMSN), **compartment syndrome of hand**

## 2 Mechanism

### Mechanism – strong extrinsics & deficient intrinsics

**Loss of intrinsics** — lose MCP flexion + IP extension

**Strong EDC** — unopposed **MCP extension**; not a significant PIP extensor (central slip force mostly from interossei)

**Strong FDP + FDS** — unopposed **PIP & DIP flexion**

**Crush hand splinted in MCP extension** — ↑ extrinsic flexor tension → **PIP flexion** (claw); splint **intrinsic-plus**

**Hand compartment syndrome** — most consistent sign: **tense swollen hand in intrinsic-minus position**; Rx fasciotomy; full function unlikely after ischaemic contracture

![Pathoanatomy](../../Orthobullets/attachments/ob6010-shows-pathoanatomy.jpg)

| Deformity | Pathoanatomy |
|---|---|
| **Claw / intrinsic minus** | **Strong extrinsics + deficient intrinsics** |
| Intrinsic plus | **Spastic intrinsics + weak extrinsics** → MCP flexion, IP extension |
| Swan neck | **Volar plate laxity** + dorsal lateral band tethering → PIP hyperext, DIP flexion |
| **Lumbrical plus** | **FDP laceration distal to lumbrical origin** → paradoxical IP extension on flexing |
| **Quadriga** | **Adhered FDP** (one finger) → flexion lag adjacent digits |

## 3 Presentation

**Exam** — MCP hyperextension + IP flexion; ↓ grasp, grip, pinch

**Ulnar palsy** — worst in **ring & little** (ulnar lumbricals); index/middle less (median lumbricals)

![Claw hand](../../Orthobullets/attachments/ob6010-claw-hand-moved.jpg)

### Ulnar nerve palsy – claw, ulnar paradox & Bouvier test

**Low ulnar (wrist) cut (TO)** — **clawing ring + little** (lumbricals 3–4), **can't abduct/adduct** (interossei; can't abduct middle finger), **can't pinch** (adductor pollicis), thumb hyperextension

**Ulnar supply in hand (TO)** — deep br.: ADM, FDM, ODM, **adductor pollicis**, **deep head FPB**, **all interossei** (PAD/DAB), **medial 2 lumbricals**; superficial br.: palmaris brevis

**Lumbricals (TO)** — arise from FDP → dual supply like FDP

**Ulnar paradox (TO)** — **higher lesion → less clawing**; due to **FDP** (ulnar half) paralysis at/above elbow; distal lesion spares FDP → more claw\
✗ Wrong options: FDS, FCU, FCR

## 4 Diagnosis & Classification

### Bouvier test

**Bouvier (TO)** — guides **claw correction**; block MCP hyperextension (~10° flexion) → watch active PIP extension

| Result | Meaning | Surgery |
|---|---|---|
| **Positive** (PIP extends; assisted angle 0) | **Simple claw**; extensor mechanism intact | Any procedure **preventing MCP hyperextension** → **static** (MCP capsulodesis, pulley advancement) |
| **Negative** (PIP stays flexed) | **Complex claw** | Needs extensor augmentation / flexor or joint correction |

| Negative Bouvier subtype (TO) | Cause | Clue |
|---|---|---|
| Passive positive | **Stretched central slip** (long-standing) | — |
| Passive negative, tenodesis positive | **Long flexor shortening** | PIP extends with **wrist flexed** |
| Passive negative, tenodesis negative | **Stiff PIP** (volar plate / collateral contracture) | No extension even with wrist flexion |

## 5 Management

```
Claw hand (progressive, ↓ QoL)
├─ Bouvier positive (simple) → STATIC: capsulodesis / pulley advancement / tenodesis
└─ Bouvier negative (complex) → active tendon transfer + extensor/flexor/joint correction
```

**Goal** — **prevent MCP hyperextension**

## How it's asked

**"Crush hand splinted in MCP extension — deformity?"** → **PIP flexion**

**"Claw after crush/compartment syndrome — pathoanatomy?"** → **strong extrinsics + deficient intrinsics**\
✗ Wrong options: spastic intrinsics = intrinsic plus

**"Ulnar paradox due to"** → **FDP** (TO)

**"Wrist cut: claw ring/little, can't pinch, can't abduct middle — nerve?"** → **ulnar** (TO)

**"Bouvier test helps correction of"** → **claw deformity** (TO)
