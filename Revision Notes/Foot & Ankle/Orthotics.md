# Orthotics

*Foot & Ankle · 36 / 48*

## 1 Basics

### Uses & principles

**Uses** — **off-load** high pressure + ↓ shear · **cushion** vulnerable tissue (diabetics) · **correct flexible / accommodate rigid** deformity (planovalgus) · **eliminate painful motion** (hallux rigidus) · **replace lost motion**, improve gait (**ankle fusion**)

**Stabilisation** — **static** = rigid, holds segment fixed · **dynamic** = mobile, permits motion · or combination

**Naming** — by joints controlled (ankle + foot = **AFO**)

**Patient factors** — soft tissue at risk · functional level (orthosis must match) · **pathology**: soft tissue, flexible vs rigid deformity, painful motion, weakness

**Design** — **three-point pressure** system · aligned at anatomic joint · simple, light, durable, acceptable cosmesis

## 4 Diagnosis & Classification

### Foot posture index (TO)

**FPI (TO)** — **static** clinical assessment of **standing** foot posture · quantifies supinated / neutral / pronated foot · **relaxed double-limb stance \~2 min**\
✗ Wrong options: **dynamic biomechanical assessment** = FALSE

**6 items (TO)** — **talar head palpation** · curves above + below malleoli · **calcaneal frontal-plane position (inversion / eversion)** · **talonavicular congruence** · **medial longitudinal arch height + congruence** · forefoot abduction / adduction

| Item (TO) | −2 (highly supinated) | 0 (neutral) | +2 (highly pronated) |
|---|---|---|---|
| **Talar head palpation** | Lateral side only | Equal medial + lateral | Medial side only |
| Curves above / below malleolus | Below straight or convex | Roughly equal | Below markedly more concave |
| **Calcaneal inversion / eversion** | > 5° inverted (varus) | Vertical | > 5° everted (valgus) |
| **TN congruence** | Markedly concave | Flat | Bulging markedly |
| **Medial arch height** | High, acutely angled | Normal | Very low, arch contacts ground |
| Forefoot abd / adduction | No lateral toes visible | Equal | No medial toes visible |

| Total score (TO) | Foot type |
|---|---|
| **−5 to −12** | **Highly supinated** |
| **−1 to −4** | Supinated |
| **0 to +5** | **Neutral** |
| **+6 to +9** | Pronated |
| **≥ +10** | **Highly pronated** |

**Uses (TO)** — diabetic neuropathic ulcer risk · research inclusion / exclusion · sports injury risk · falls in elderly · age-related foot change · **more valid** than goniometric WB / NWB methods

## 5 Management

### Shoes & shoe modifications

| Shoe | Foot |
|---|---|
| **Extra-depth** | Room for orthosis / deformity |
| **Stiff, supportive** | **Flexible** foot (flexible planovalgus) |
| **Soft, shock-absorbing** (running shoe) | **Rigid, bony** foot |
| **Custom** | Severe deformity (**Charcot**) |
| **High-top lace-up** | **Poor distal proprioception** (proximal feedback, balance) |

**Internal vs external modification** — internal = **more mechanically effective**, ↓ shoe space · external = keeps volume, worse cosmesis, **wears faster**

| Modification | Indication |
|---|---|
| **Cushioned heel** | **Heel pad atrophy** |
| **Lateral flare** | Resists **inversion** (ankle instability) |
| **Medial flare** | Resists **eversion** |
| **Lateral sole wedge** | **Cavovarus with fixed forefoot pronation** (forefoot reaches ground without compensatory varus) |
| **Medial wedge** | **Flexible planovalgus (PTTD)** → corrects hindfoot valgus |
| **Lateral heel wedge** | Unloads **medial knee** compartment (fixed knee varus) |
| **Heel lift** | **Equinus**, **LLD** |
| **Extended shank** (carbon / steel) | Splints forefoot / midfoot: **hallux rigidus (Morton's carbon-fibre extension)**, midfoot arthritis |
| Sole excavation, metatarsal pad, toe crest, scaphoid pad | Bony prominences / painful sites |

**Lateral wedge for cavovarus with fixed forefoot pronation** — **lateral sole wedge** (Orthobullets) · **lateral heel wedge** (OB) — read the options

### Rocker soles

**Effect** — transfer body weight forward · **can destabilise the knee** → caution with balance / proprioception problems

| Rocker | Shape | Use |
|---|---|---|
| **Mild** | Mild angle toe + heel — **commonest** | ↓ MT head pressure, forward propulsion |
| **Heel-to-toe (single)** | More angled toe + heel | ↓ heel-strike pressure + **need for ankle motion**: **ankle / subtalar arthritis or fusion**, midfoot amputation, **calcaneal ulcers** |
| **Toe only** | Angled at toe | ↑ WB proximal to MT heads |
| **Severe angle** | Steep toe | **MT head / toe-tip ulcers** |
| **Negative heel** | Heel lower than sole | **Fixed dorsiflexion** deformity |
| **Double** | Two rockers over forefoot + hindfoot | ↓ midfoot pressure: **midfoot prominence, Charcot** |

### Gait orthosis after ankle arthrodesis

**Ankle fusion gait** — **↑ metabolic energy 9–15%** vs normal

**Rocker-bottom sole** — **mimics ankle DF / PF** · redistributes plantar pressure · improves kinematics + function\
✗ Wrong options: **Arizona brace** (immobilises ankle, ankle arthritis) · non-articulating / articulating **AFO** (immobilise, foot drop) · **Morton's extension** (hallux rigidus)

### Foot orthoses (inserts)

| Insert | Key facts |
|---|---|
| **Heel cup** | Rigid plastic; prevents **lateral calcaneal shift** in flexible planovalgus |
| **UCBL** | Rigid plastic over cast in **maximum manual correction**; heel + midfoot, medial / lateral / posterior walls; heel **vertical neutral** · **flexible planovalgus only** — **rigid → painful, skin breakdown** |
| **Longitudinal arch support** | Prevents subtalar depression, corrects pes planus |
| **Metatarsal pad / bar** | **Metatarsalgia** → load moved from MT heads proximally |

### Ankle orthoses & AFO

**Arizona brace** — **UCBL + lace-up ankle support** · **flexible planovalgus** (rigid hindfoot support) (Orthobullets) · **immobilises ankle** → nonop **ankle arthritis** (OB) · **PTTI / AAFD**: limits ankle motion → **articulated AFO** preferred in active walkers (OB)

**AFO construction** — footplate, calf support, calf band · plastic, metal, leather

**Ankle → knee** — **ankle PF = knee extension force** · **ankle DF = knee flexion force**

| | **Non-articulating AFO** | **Articulating AFO** |
|---|---|---|
| Look | More aesthetic | — |
| Knee | **Flexion force at weight acceptance** (neutral ankle) | Adjustable stops / assists |
| Stance | No eccentric PF in early stance · **trim lines set late-stance flexibility** (max / moderate / min DF resistance) | More natural gait; also medial–lateral control |

| AFO design | Key facts | Use |
|---|---|---|
| **Posterior leaf spring** | **Commonest AFO** · narrow trim line **behind malleoli** · resists PF · **no medial–lateral control** | **Foot drop** |
| **Solid** | Trim line **anterior to malleoli** · blocks PF + varus / valgus | Rigid control |
| **Hinged** | Adjustable stops | Multiplanar instability, ankle pain, **spina bifida (mid-lumbar)** |
| **Ground reaction** | Pretibial shell, forefoot trim line · **max PF resistance → knee extension** | **CP with over-lengthened triceps surae + mild crouch** |
| **Patellar tendon bearing** | Load on patellar shelf | **↓ WB force through foot** |
| **CAM walker** | Off-the-shelf immobilisation, WB allowed | Ankle sprain, stable ankle fracture, Achilles rupture |
| **SMO (supramalleolar)** | **Shortest AFO**, ends above malleoli; heel neutral vertical | Flexible pes planus, planovalgus, hyperpronation |

![Posterior leaf spring AFO](../../Orthobullets/attachments/ob12278-plsafo.jpg)

| Ankle joint option | Effect | Use |
|---|---|---|
| **Free motion** | Free DF + PF; **medial–lateral stability only** | **Ligamentous ankle instability** |
| **Plantarflexion stop** | Blocks PF, free DF → **knee flexion moment** at weight acceptance (✗ Wrong options: **quadriceps weakness**) | **Swing-phase foot drop**, flexible equinus |
| **Dorsiflexion stop** | Blocks DF, free PF → **knee extension moment** (prevents buckling) | **Weak plantarflexion in stance** (± weak quads) |
| **Limited motion stop** | Blocks both | **Global ankle weakness** |
| **DF assist spring** | Posterior coil spring aids swing DF | **DF weakness with preserved motion** |
| **T-strap** | Medial strap → lateral upright = **valgus correction** · lateral strap → medial upright = **varus correction** | Varus / valgus |

### Knee orthoses

**KAFO** — AFO + uprights + mechanical knee + 2 thigh bands · **quadriceps weakness / paralysis**, flexible genu varum / valgum · harder to don · not with moderate–severe cognitive dysfunction

**Double-upright metal KAFO** — **commonest** KAFO

**Scott-Craig orthosis** — **paraplegia (SCI)** standing + ambulation · T-shaped footplate, adjustable ankle stops, pawl-lock knee + bail · **hip hyperextension** puts COG behind hip, in front of locked knee + ankle · **10° ankle DF** alignment → swing-to / swing-through with crutches

## X vs Y

| | **Plantarflexion stop** | **Dorsiflexion stop** |
|---|---|---|
| Blocks | PF | DF |
| Knee moment | **Flexion** (avoid if quads weak) | **Extension** (prevents buckling) |
| Use | **Foot drop**, flexible equinus | **Weak plantarflexors** in stance |

| | **UCBL / medial wedge / Arizona** | **Lateral wedge / 1st ray cutout** |
|---|---|---|
| Foot | **Flexible planovalgus** | **Cavovarus** |

## How it's asked

**"Gait problems after ankle arthrodesis — device?"** → **Figure C — rocker-bottom sole**

**"FALSE about foot posture index?"** → **it is a dynamic biomechanical assessment** (TO)

**"Toe-tip / MT head ulcer — rocker?"** → **severe angle rocker**

**"Fixed ankle dorsiflexion deformity — rocker?"** → **negative heel rocker**

**"Charcot midfoot prominence — rocker?"** → **double rocker**

**"Commonest AFO, for foot drop?"** → **posterior leaf spring AFO**

**"UCBL in rigid planovalgus?"** → **painful, skin breakdown**

**"CP, over-lengthened triceps surae, mild crouch?"** → **ground reaction AFO**

**"AFO joint to avoid with quadriceps weakness?"** → **plantarflexion stop**

**"Paraplegic standing + swing-through gait?"** → **Scott-Craig orthosis**
