# Tarsal Navicular Fractures

*Foot & Ankle · 44 / 48*

## 1 Basics

**Rare midfoot fracture** — **traumatic** (avulsion, tuberosity, body) or **stress** (repetitive microstress)

**Articulations** — **talus, calcaneus, cuboid, cuneiforms** · key to **inversion–eversion** motion

**Medial column** — navicular supports **medial longitudinal arch** · only **displaced fracture / navicular dislocation** → arch instability (OB)

**PTT** — inserts on navicular (tuberosity)

### Stress fracture epidemiology

**Who** — **athletes running on hard surfaces** · **baseball players** (predilection; e.g. catcher jumping from crouch) · gymnasts, soccer, marathon runners (OB stems)

**High-risk stress fracture** — **risk of AVN** · commonest complications **delayed union + nonunion**

**At presentation** — **\~83% incomplete** · complete ones usually **nondisplaced** (OB)

## 2 Mechanism

| Type | Mechanism |
|---|---|
| **Avulsion** | **Plantarflexion** or **eversion / inversion** · TN or naviculocuneiform ligaments |
| **Tuberosity** | **Eversion + simultaneous PTT contraction** · may be **acute diastasis of an accessory navicular** |
| **Body** | **Axial loading** |
| **Stress** | **Chronic overuse** · hard surfaces |
| **Mueller-Weiss** | Spontaneous adult **navicular AVN** |

## 3 Presentation

**Symptoms** — **vague midfoot pain** + swelling · **insidious** in stress fracture → high index of suspicion

**Exam** — midfoot (**dorsomedial / medial**) swelling + **tenderness** · **ankle + subtalar ROM usually full** · full DF / PF / inversion strength

**Not** — anterior tibial tendinitis (no evidence → no cortisone injection into tibialis anterior sheath)

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Finding / role |
|---|---|
| **X-ray** | **AP, lateral, oblique 45°** · **often missed / read as normal** · **45° oblique best for tuberosity fractures** |
| **CT** | **More sensitive than X-ray** · shows **nondisplaced fracture line** through navicular · may be **false-negative** without frank cortical disruption |
| **MRI** | **T2 high signal** (oedema / inflammation) · **best test to confirm** when X-ray negative + high suspicion or failed restricted WB (OB) · stress reaction = **oedema, no fracture line** |
| Mueller-Weiss X-ray | **Narrow navicular + lateral sclerosis** · **"double navicular sign"** (split navicular) (OB) |

**Best imaging** — **CT more sensitive than X-ray** (Orthobullets, OB) · **MRI best to confirm** (OB, CT false negatives) — read the options

### Sangeorzan classification (navicular body)

| Type | Fracture | Deformity |
|---|---|---|
| **I** | **Transverse**, **dorsal fragment < 50%** of bone | **None** |
| **II** | **Oblique**, usually **dorsolateral → plantar-medial** | **Forefoot ADduction** |
| **III** | **Central or lateral comminution** | **Forefoot ABduction** |

## 5 Management

```
Navicular stress fracture
├─ Any type, first presentation → NWB short-leg cast 6–8 wk
├─ Stress reaction (oedema, no line) → restricted WB short-leg cast
└─ Failed cast / nonunion / recurrence → ORIF + autologous bone graft
       └─ High-level / pro athlete → ORIF (OB, Orthobullets)
```

```
Traumatic navicular fracture
├─ Avulsion, most tuberosity, undisplaced type I–II → NWB cast
│      └─ Failed avulsion / symptomatic tuberosity nonunion → fragment excision
├─ Displaced / intra-articular type I–II → ORIF (medial approach), lag screws
└─ Type III or AVN → ORIF + ex-fix vs primary fusion
```

### Operative criteria

| Injury | Operate when |
|---|---|
| **Avulsion** | **> 25% of articular surface** → ORIF · failed nonop → **excision** |
| **Tuberosity** | **> 5 mm diastasis** or **large intra-articular fragment** → ORIF · **symptomatic nonunion → excision** |
| **Body type I–II** | **Displaced or intra-articular** → ORIF (**medial approach**) |
| **Body type III** | **ORIF + ex-fix vs primary fusion** · maintain **lateral column length** |
| **Stress fracture** | **Fracture line across 2 cortices**, or **1 cortex + displacement or cystic change** (OB) · **failed NWB cast** · **nonunion** · **high-level athletes** |
| **Navicular AVN** | **TN + naviculocuneiform fusion** |

### Stress fractures – non-weight-bearing cast first-line

**First line (any type)** — **short-leg cast + NWB 6–8 weeks** (± walking boot + crutches) → **high success**

**45-yo runner** — **short leg cast + non-weight bearing**\
✗ Wrong options: hard-sole shoe (insufficient immobilisation) · partial WB boot / cast (risks progression)

**21-yo baseball player, normal X-ray, MRI T2 signal** — **NWB cast for planned 6–8 weeks**\
✗ Wrong options: observation · steroid into anterior tibial sheath · partial WB boot · ORIF first line

**Gymnast, CT nondisplaced fracture** — **NWB + cast** · **NWB cast more effective than surgery**\
✗ Wrong options: WBAT hard-soled shoe or Aircast boot · partial WB cast (inferior outcomes) · ORIF first

**15-yo soccer, 4 mo pain, MRI oedema, no fracture line (stress reaction)** — **restricted weight bearing in short-leg cast** (± boot)\
✗ Wrong options: ORIF · WBAT boot (may **displace + injure TN joint**) · orthotic + bone stimulator · carbon-fibre orthotic

**High-level athletes** — **NWB cast works even in high-level athletes** · operative first line not supported (OB) · vs **ORIF for pro athletes** who can't tolerate long recovery, to prevent painful nonunion (OB, Orthobullets) — read the stem

### Failed or complete stress fractures – ORIF with bone graft

**Marathoner, recurrent chronic stress fracture with diastasis, failed immobilisation, intra-articular** — **ORIF with autologous calcaneus bone graft**\
✗ Wrong options: WBAT hard-soled shoe · repeat NWB cast · fragment excision + PTT advancement (not described) · CRPP (not described)

**18-yo gymnast, 1 yr pain, failed 6 wk NWB cast** — **ORIF with autologous bone grafting**\
✗ Wrong options: ORIF alone · more NWB cast · PWB walking cast · no treatment

### Acute fracture fixation

**Acute displaced body fracture with diastasis (basketball)** — **open reduction + lag screw fixation** → interfragmentary compression, restores **medial column length** + articular congruity

**✗ Acute traps** — **NWB cast 6–8 wk** (nondisplaced body fracture / stress reaction only) · **CRPP** (insufficient for displacement) · **ex-fix** (**highly comminuted** / substantial **medial column shortening**) · **primary TN fusion** (pre-existing **TN arthritis** or non-reconstructable)

**Column length** — Type III: maintain **lateral column length** (Orthobullets) · ex-fix for **medial column shortening** (OB) — read the options

### Navicular arthrosis – talonavicular & naviculocuneiform fusion

**56-yo, longstanding midfoot pain, no trauma, failed semirigid insoles** — Mueller-Weiss → **fuse talonavicular + naviculocuneiform joints**\
✗ Wrong options: TN only (misses NC joint) · any fusion including **subtalar — spared** in this disease

**Pain source** — abnormal motion at **TN + NC joints**

### Mueller-Weiss syndrome (adult navicular osteonecrosis)

**Definition (TO)** — **spontaneous adult-onset tarsal navicular osteonecrosis** · aka **Brailsford disease** (TO) · related to **Köhler's** (Köhler = paediatric) (OB)

**Who (TO)** — **40–60 yr** · **women** · **frequently bilateral** (TO) · 4th–5th decade (OB) · middle-aged (Orthobullets)

**Aetiology (TO)** — uneven load → **compression of lateral half of navicular** · preconditions: **subtalar varus**, **1st ray brachymetatarsia**, **mild clubfoot** → lateral shift of force, **lateral incompetence of acetabulum pedis**

**Clinical (TO)** — chronic **mid + hindfoot pain** · navicular collapse → secondary OA → **pes planovarus** · tibia forced into **external rotation → knee OA**

**Exam (TO)** — dorsomedial midfoot swelling + tenderness · **heel varus** · prominent navicular tuberosity → **pseudo hindfoot valgus** · flattened medial arch

**Paradoxical pes planovarus (TO)** — **pseudo hindfoot valgus + pes planus** · "**pseudo hindfoot varus**" = the **false** option (TO)

**Treatment** — **semirigid insoles first**, fusion if failed (OB) · **mostly surgical** (TO) — read the options · fuse symptomatic joints + restore arches by correcting **Meary-Tomeno line** · **talonavicular-cuneiform arthrodesis with bone grafting** = best results (TO)

## 6 Complications

### Nonunion risk

| Complication | Fact |
|---|---|
| **Nonunion + delayed union** | **Two commonest** after both nonop + surgery |
| **AVN** | Why stress fracture is **high risk** |
| Malunion | **Very rare** (nondisplaced) |
| Infection | Rare unless open |
| Arch instability | Only **displaced fracture / dislocation** |
| Neuroma | Rare (stress fracture, nonunion) |

**Most common complication (stress fracture image)** — **non-union**\
✗ Wrong options: malunion · infection · longitudinal arch instability · neurovascular injury

**Pro baseball catcher, 5 mo dorsomedial pain, failed nonop, MRI stress fracture — most at risk** — **nonunion**\
✗ Wrong options: arch collapse / acquired flatfoot (chronic **PTTI** sequela) · **cavovarus** · PTTI (chronic, not from stress fracture) · transfer metatarsalgia (after 1st ray shortening)

## X vs Y

| | **Navicular stress fracture** | **Mueller-Weiss (adult AVN)** |
|---|---|---|
| Age | Young athletes | **40–60**, women |
| Cause | Overuse, hard surfaces | Spontaneous; lateral compression |
| X-ray | Often **normal** | **Narrow, lateral sclerosis, double navicular** |
| Treatment | **NWB cast 6–8 wk** → ORIF + graft | Insoles → **TN + NC fusion** (subtalar spared) |

| | **Mueller-Weiss** | **Köhler's** |
|---|---|---|
| Age | **Adult (4th–5th decade)** | **Paediatric** |

| Sangeorzan | Deformity |
|---|---|
| II (oblique) | **ADduction** |
| III (comminuted) | **ABduction** |
