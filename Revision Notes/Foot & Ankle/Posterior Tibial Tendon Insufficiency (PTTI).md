# Posterior Tibial Tendon Insufficiency (PTTI)

*Foot & Ankle · 41 / 48*

## 1 Basics

### Epidemiology

**Commonest cause** — **adult-acquired flatfoot deformity (AAFD)** · renamed **progressive collapsing foot deformity (PCFD)** (Myerson consensus) = hindfoot valgus + forefoot abduction + midfoot varus

**Who** — **women**, **6th decade** (50s–60s), obese, middle-aged

**Flatfoot types (TO)** — congenital: inherited, hyperlaxity, **CVT**, physiological · adolescent: inherited, **tarsal coalition (common)** · **adult acquired: PTTD = most common** (TO)

**Risk factors** — **obesity**, **hypertension**, **diabetes**, ↑ age, **corticosteroid use** (incl. repeated injections), **seronegative inflammatory** disorders

**Associated conditions** — **inflammatory arthropathy** · **tarsal coalition** (young, rigid pes planus ± recurrent ankle sprains) · acute onset after **pronation–external rotation** ankle fracture

### Anatomy & biomechanics of the PTT

**Muscle** — origin **posterior fibula, tibia + interosseous membrane** · **tibial nerve (L4–5)**

**Course** — **posterior to medial malleolus** → divides into **3 limbs**

| Limb | Insertion |
|---|---|
| **Anterior** | **Navicular tuberosity + 1st (medial) cuneiform** |
| **Middle** | **2nd + 3rd cuneiforms, cuboid, MT 2–4** |
| **Posterior** | **Sustentaculum tali** (anteriorly) |

**Blood supply** — **posterior tibial artery branches** distally (Orthobullets) · branches of sural, peroneal + posterior tibial arteries (OB)

**Watershed** — **2–6 cm proximal to navicular insertion** (navicular → distal medial malleolus) = main site of **synovitis + rupture**

**Excursion** — **2 cm** (normal)

**Axis** — **posterior to tibiotalar** + **medial to subtalar** joint axis

**Functions** — **primary dynamic arch support** · **hindfoot invertor** · **adducts + supinates forefoot** in stance · **secondary ankle plantarflexor** · with FDL + FHL dynamically restrains arch

**Primary antagonist** — **peroneus brevis** (evertor)\
✗ Wrong options: peroneus longus (antagonist of tibialis anterior) · tibialis anterior (antagonist of PL) · gastroc-soleus (antagonised by ankle dorsiflexors) · EHL (antagonised by FHL)

**Locking mechanism (TO)** — midstance: **TP initiates subtalar inversion → locks the transverse tarsal (TN + CC) joints** → **rigid lever arm for toe-off** · adducts + plantarflexes navicular on talar head → buttresses medial arch (TO)

**Dysfunction (TO)** — **failure of inversion of the hindfoot that locks the transverse tarsal joints** → heel rise difficult, **heel remains in valgus** (TO)\
✗ Wrong options: eversion · "unlocks"

**Calf fatigue** — unlocked transverse tarsal joint → no rigid lever → ↓ triceps surae mechanical advantage → **medial + distal calf pain, fatigue** → tendinopathy primarily affects the **transverse tarsal joint**\
✗ Wrong options: 1st TMT (dorsiflexed, not the cause) · subtalar (altered, no extra triceps work) · Lisfranc (unaffected) · tibiotalar (stage IV only)

### Spring ligament & related anatomy

**Spring ligament complex** — **superomedial calcaneonavicular (CNL)** + **inferior calcaneonavicular** ligaments · **anterior sustentaculum tali → plantar-medial navicular** · supports **plantar-medial talar head** · **primary static stabiliser of the TN joint**

**Torn / attenuated in AAFD** — **superomedial calcaneonavicular** (most often; 18 / 22 PTT ruptures had spring injury)\
✗ Wrong options: dorsal cuneonavicular · dorsal intercuneiform · dorsal calcaneocuboid · anterior tibiofibular

**Deltoid link** — distal (superficial) deltoid **blends with superomedial spring ligament** = **tibiocalcaneonavicular ligament (TCNL)** · also attenuated · deltoid-spring reconstruction for advanced medial peritalar instability

**Static arch stabilisers** — **spring ligament complex**, **plantar fascia**, **plantar ligaments** (long + short) · TO: long + short plantar, spring + bifurcate ligaments kept tight by TP tension → lost tension → plantar ligament failure, esp. **calcaneonavicular** (TO)

**Failure** — **plantar + medial migration of the talar head** → arch flattens → **loss of medial peritalar stability**

**Medial labelled figure** — **A = spring (superomedial CN) ligament** · B = joint capsule · C = plantar ligaments · D = plantar fascia · E = tibialis posterior tendon

**Plantar labelled figure** — **structure D = spring (plantar calcaneonavicular) ligament** · A = peroneus longus · B = long plantar ligament · C = short plantar ligament · E = tibialis anterior

![Spring ligament complex, medial view](../../MCQ/attachments/q212155-illa-sping-labeled.jpg)

**✗ Ligament–condition traps** — Lisfranc injury = **Lisfranc ligament** (plantar-lateral medial cuneiform → plantar-medial 2nd MT base) · peroneal dislocation = **SPR** · pes cavus = muscle imbalance · 2nd toe crossover = **plantar plate + collateral ligament**

## 2 Mechanism

**Aetiology** — exact cause **unknown** · acute injury vs **long-standing tendon degeneration**

**Sequence** — **tenosynovitis → tendinosis / elongation → loss of dynamic arch stabilisation → attritional failure of static stabilisers** (spring ligament, plantar fascia, plantar ligaments) → fixed degenerative joint changes

**Structure order** — **PTT → spring + talocalcaneal ligaments → deltoid** (last = stage IV)

**Deformity** — **pes planus** · **hindfoot valgus** · **forefoot abduction** · **forefoot varus / supination** (compensatory → keeps foot plantigrade)

**Equinus cycle** — hindfoot valgus → **Achilles lateral to subtalar axis → acts as evertor** · valgus shortens gastrocnemius → **fixed equinus, Achilles / gastroc contracture** → worse arch collapse → worse equinus

**Stage IV** — **deltoid incompetence → valgus talar tilt in mortise** → tibiotalar arthritis

## 3 Presentation

### Diagnosis & examination (too-many-toes, single-limb heel rise, equinus)

**Early** — **medial ankle / foot pain + weakness** · tenderness + swelling **just posterior to tip of medial malleolus** / along PTT · ↓ endurance

**Progressive** — **loss of arch** ("lost her arch", needs shoe inserts), foot "looks wider"

**Late** — **lateral (sinus tarsi) pain from subfibular impingement** (calcaneus / talus against fibula tip)

| Present in AAFD | Not a feature |
|---|---|
| **Hindfoot valgus** | Hindfoot varus |
| **Forefoot abduction** ("too many toes") | Forefoot adduction |
| **Forefoot varus / supination** (compensatory) | Forefoot valgus / pronation (cavovarus) |
| **Pes planus** | Cavus, plantarflexed 1st ray (cavovarus compensation) |
| **Equinus / Achilles / gastrocnemius contracture** | Claw toes, hallux varus, plantar fasciitis |
| — | **Hallux valgus** (no ↑ rate in PTTI) |

**Single-limb heel rise** — **hallmark** · patient **unable to raise the heel off the ground and stand on the toes while supported on one leg** · **stages II–IV can't** · stage I can (TO: grossly normal single raise but **fails repeated / successive raises**)

**Heel on double-leg heel rise** — normal / flexible: heel **inverts**, arch **reconstitutes** (stage II) · rigid: heel **stays valgus** (stage III)

**Too-many-toes sign** — viewed from behind · **forefoot abduction** · **> 40% TN uncoverage** (stage IIB)

![Too-many-toes sign: forefoot abduction seen from behind](../../Orthobullets/attachments/ob7020-forefoot-abduction.jpg)

**PTT power** — foot **plantarflexed + fully inverted** → can't hold against examiner's eversion force · pain with resisted inversion

**Forefoot varus check** — hold flexible heel **neutral** → fixed varus = **lateral border more plantarflexed than medial** · flexible = MT heads perpendicular to long axis of tibia + calcaneus

**Flexible vs rigid** — flexible = passively correctable to plantigrade (**stage II**) · rigid = not correctable (**III, IV**) → **decides joint-sparing vs fusion**

**Equinus (must be evaluated + addressed at surgery)** — **Silfverskiöld** with hindfoot / TN held **neutral**: **increased ankle dorsiflexion with knee flexion = gastrocnemius contracture** · no change = gastroc + soleus (Achilles) · TO: equinus = **< 10° DF with knee extended** (TO)

**✗ Exam traps** — anterior drawer in 20° PF = **ATFL** · **Coleman block** = cavovarus (correction = flexible, forefoot-driven cavovarus) · **piano-key** = Lisfranc · **Thompson** = Achilles rupture · inability to flex hallux = **FHL**

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Finding |
|---|---|
| **Views** | **WB AP + lateral foot**, **ankle mortise** |
| **AP foot** | **↑ TN uncoverage** (TN coverage angle normal **< 7°**) · **↑ AP talo-1st MT angle (Simmon)** — stages II–IV |
| **WB lateral** | **↑ lateral talo-1st MT angle (Meary) > 4° = pes planus** (II–IV) · **↓ calcaneal pitch** (normal **17–32°**) · **↓ medial cuneiform–floor height** · **dorsal navicular subluxation on talus** |
| Lateral (TO) | **Midfoot break at talo-MT angle**, abnormal talocalcaneal angle, **↓ cuneiform height** (stage 2) (TO) |
| Hindfoot | **Subtalar arthritis** — stages **III–IV** |
| **Mortise** | **Talar tilt (valgus)** = **deltoid insufficiency** — **stage IV** |
| **US** | Stage 1 / 2a **tenosynovitis — target sign** · degenerating tendon **hyper- → hypo-echoic** · stage 2b **empty groove sign** = ruptured tendon gap (TO) · ↑ role |
| **MRI** | Tendinosis, tenosynovitis, tearing · **elongated, thinned tendon** (TO) · TN, subtalar, tibiotalar arthritis |

![Talonavicular coverage angle: normal under 7°, flatfoot 33°](../../MCQ/attachments/q5661-illa-talonavicular-coverage.jpg)

**Meary in stems** — 8°, 12°, 30° = pes planus · collapse sometimes reported as **"negative" Meary angle**

**Flatfoot X-ray signs (TO)** — **TN uncoverage = classic sign** · **talonavicular sag** · **naviculocuneiform sag** · forefoot abduction · ↑ Meary · **hindfoot alignment (Saltzman) view** · MRI for PTT · **CT for rigid foot / suspected coalition** (TO)

**Four angles (TO)** — **Hibb's · Meary's · calcaneal pitch · tibiotalar** — assess every flat / cavus foot (TO)

**PTT function tests (TO)** — single + double heel raise · **resisted inversion** · **hopping sign** · too-many-toes = **hindfoot valgus + forefoot abduction** · exam: medial ankle fullness, **subfibular tenderness**, **talar head callosity** (TO)

### Diagnostic criteria

| Finding | Threshold / meaning |
|---|---|
| Pes planus | **Meary (lateral talo-1st MT) > 4°** |
| Calcaneal pitch | Normal **17–32°** → ↓ = loss of arch height |
| **Stage IIB / LCL** | **TN uncoverage > 40%** (Orthobullets, OB, Thordarson consensus) · **> 30%** (OB; Myerson IIa < 30% vs IIb > 30%) · "> 40% or > 30°" (OB) — read the options |
| Gastroc contracture | **DF ↑ with knee flexion** (Silfverskiöld +) |
| Equinus (TO) | **< 10° DF with knee extended** |
| Stage I vs II | **Can vs can't single-leg heel rise** |
| Stage II vs III | **Flexible vs rigid** hindfoot · rigid = stage III **irrespective of arthritis on X-ray** |
| Stage III vs IV | **Deltoid compromise / talar tilt / ankle arthritis** |
| 1st TMT instability | **Plantar gapping medial cuneiform–1st MT base** |

### Differential

**Midfoot-driven flatfoot** — midfoot OA / **chronic Lisfranc**; apex at **naviculocuneiform** = **cuneiform subluxes dorsally, TN alignment maintained** (vs PTTI = navicular subluxes dorsally on talus) → **midfoot fusion + realignment**

**Isolated spring ligament incompetence (no PTT pathology)** — standard flatfoot reconstruction **+ adjunctive spring ligament reconstruction**

**Tarsal coalition** — young, rigid pes planus, recurrent sprains

**Adolescent flexible flatfoot** — ligamentous laxity → **conservative**

### Staging (Johnson & Strom, Myerson modification)

**Johnson and Strom classification** — for **tibialis posterior** (TO) · stage IV added later (Myerson)\
✗ Wrong options: tibialis anterior · peroneus longus · FHL

| Stage | Deformity | Exam | X-ray | Treatment |
|---|---|---|---|---|
| **I** | **Tenosynovitis, no deformity** | **(+) single heel raise** | Normal | **Cast / boot 3–4 mo** → tenosynovectomy |
| **IIA** | **Flexible** hindfoot valgus, **normal forefoot** | **(−) single-leg heel raise**, mild sinus tarsi pain | Arch collapse | **FDL + MDCO** ± TAL / gastroc |
| **IIB** | Flexible + **flexible forefoot abduction** (too many toes, **> 40% TN uncoverage**) | (−) heel raise, mild sinus tarsi pain | Arch collapse | **+ lateral column lengthening** |
| **IIC** | Flexible hindfoot + **rigid forefoot abduction / varus** | (−) heel raise, **moderate** sinus tarsi pain | Arch collapse, **gapping of 1st TMT** | **+ Cotton** or **medial column fusion** |
| **III** | **Rigid hindfoot valgus**, rigid forefoot abduction | (−) heel raise, **severe sinus tarsi pain** | **Subtalar arthritis** | **Triple (hindfoot) arthrodesis** |
| **IV** | III + **deltoid ligament compromise** | + **ankle pain** | **Talar tilt in ankle mortise** | Correctable → **triple + deltoid recon** · rigid + arthritis → **TTC** |

### Johnson & Strom stages (TO)

| Stage | TO description |
|---|---|
| **1** | Tenosynovitis, **no deformity** · tendon pain, normal function, **able to repeat tiptoes** |
| **2** | **Flexible deformity** · tendon rupture, ↓ strength, **unable to repeat tiptoes** |
| **3** | **Rigid flat foot**, valgus heel, **loss of subtalar motion**, forefoot varus, absent heel raise, **anterolateral impingement**, secondary OA |
| **4** | **Ankle joint involvement — tibiotalar degeneration** |

**Stage 1 (TO)** — medial pain, ↓ endurance · erythema, swelling, warmth, tenderness along TP · arch + alignment normal (TO)

**Stage 2 (TO)** — inflammatory signs + **flexible hindfoot valgus** · flattened arch **returns on single-leg raise** · forefoot **abducted + supinated** · yet usually **can't do an unsupported single heel rise** (TO) — Orthobullets: (−) single-leg heel raise — read the options

**Stage 3–4 (TO)** — **subtalar arthropathy**, deformity fixed · stage 4 = **tibiotalar degeneration** · X-rays diagnostic · treatment = **arthrodesis** (TO)

**Stage 2A vs 2B (TO lecture)** — **2A = heel raise present · 2B = heel raise absent** (TO) · Orthobullets / Myerson: 2A vs 2B by **forefoot abduction / TN uncoverage** — read the options

**Stage 2 treatment (TO lecture)** — **2A → tibialis posterior debridement (open or tendoscopic)** · **2B → gastroc recession + MDCO + LCL + FDL → navicular** ± (rare) **cuneiform plantarflexion (Cotton) osteotomy** (TO) · Orthobullets: IIA = FDL + MDCO — read the options

### Four-stage AAFD with surgical treatment (Myerson)

| Stage | Deformity | Surgery |
|---|---|---|
| **I** | No AAFD deformity (may have pre-existing flatfoot) | **Tenosynovectomy**, possible tendon transfer and / or medial slide osteotomy |
| **IIa** | Mild / moderate flexible, **< 30% TN uncoverage** | Tendon transfer + medial slide osteotomy ± **Cotton** |
| **IIb** | Severe flexible, abduction through TN, **> 30% TN uncoverage** | Transfer + medial slide ± **LCL** or hindfoot fusion (subtalar or TN + CC) · Cotton / TMT fusion to lower 1st ray |
| **III** | **Fixed** (triple-joint complex) | **Hindfoot fusion, usually triple** — all three joints |
| **IV** | Foot deformity + **lateral talar tilt** | Correct foot ± **deltoid reconstruction** · severe arthritis → **ankle fusion or TAA** + foot correction |
| IVa / IVb | Flexible / fixed foot | Foot corrected as **IIb** / as **III** |

### Bluman classification (detailed Myerson)

| Stage | Hallmark | Treatment |
|---|---|---|
| **I A / B / C** | Normal anatomy, PTT tenderness (A ± systemic disease · C slight HF valgus) | Immobilisation, NSAIDs, cryotherapy, orthoses, tenosynovectomy |
| **II A1** | Supple HF valgus, **flexible forefoot varus** | Orthoses · MDCO · **TAL / Strayer + FDL** if deformity corrects only with ankle PF |
| **II A2** | Supple HF valgus, **fixed forefoot varus** | MDCO + FDL + **Cotton** |
| **II B** | **Forefoot abduction**, TN uncovering | MDCO + FDL + **LCL** |
| **II C** | **Fixed forefoot varus + medial column instability**, **1st TMT plantar gapping**, 1st ray dorsiflexes with HF correction | MDCO + FDL + **Cotton or medial column fusion** |
| **III A** | Rigid HF valgus, sinus tarsi pain, subtalar space loss, angle of Gissane sclerosis | Custom bracing if not surgical · **triple** |
| **III B** | + forefoot abduction | **Triple ± LCL** |
| **IV A** | **Supple tibiotalar valgus** | Correct HF + **deltoid reconstruction** |
| **IV B** | **Rigid tibiotalar valgus** | **TTC or pantalar fusion** |

### RAM classification (rearfoot · ankle · midfoot)

| Stage | Rearfoot | Ankle | Midfoot |
|---|---|---|---|
| **Ia** | PTT tenosynovitis | Neutral | Neutral |
| **Ib** | PTT tendonitis, no deformity | Mild valgus **< 5°** | Mild flexible supination |
| **IIa** | Flexible planovalgus: **< 40% talar uncoverage, < 30° Meary, incongruency 20–45°** | Valgus + deltoid insufficiency, no arthritis | Supination, no instability |
| **IIb** | Flexible: **> 40%, > 30° Meary, incongruency > 45°** | Valgus + deltoid insufficiency + **tibiotalar arthritis** | Supination + **midfoot instability**, no arthritis |
| **IIIa** | Fixed / arthritic, < 40% · < 30° | Valgus from **lateral plafond bone loss**, deltoid normal | Arthritis **isolated to medial column** (NC or 1st TMT) |
| **IIIb** | Fixed, > 40% · > 30° — **not correctable through triple** | Plafond bone loss **+ deltoid insufficiency** | **Medial + middle column** arthritis |

## 5 Management

```
PTTI — nonoperative first at every stage
├─ I tenosynovitis, heel rise OK → walking cast / boot 3–4 mo
│      └─ fails → tenosynovectomy / PTT debridement
├─ II flexible → UCBL / AFO with medial post
│      └─ fails → FDL transfer + MDCO (+ adjuncts)
├─ III rigid hindfoot ± subtalar arthritis → triple arthrodesis
└─ IV deltoid failure, talar tilt → decide by ankle
       ├─ ankle valgus correctable → triple + deltoid reconstruction
       └─ rigid valgus + tibiotalar arthritis → TTC / pantalar
```

```
Stage II reconstruction — base FDL → navicular + MDCO
├─ Forefoot abduction, TN uncoverage > 40% (IIB) → + lateral column lengthening
├─ Residual forefoot varus, stable medial column → + Cotton osteotomy
├─ 1st TMT plantar gapping / hypermobility / arthritis → + 1st TMT fusion (Lapidus)
├─ DF ↑ with knee flexion (gastroc only) → + gastrocnemius recession
└─ No change with knee flexion (gastroc + soleus) → + TAL
```

```
Rigid flatfoot (stage III–IV)
├─ Unfit / declines surgery → custom AFO (articulated if ankle normal + active)
├─ Hindfoot arthritis, CC joint spared → TN + subtalar arthrodesis (medial)
├─ Hindfoot + CC involved → triple arthrodesis
│      └─ forefoot varus unmasked → derotate through transverse tarsal joints
└─ + ankle arthritis / rigid tilt → TTC (hindfoot nail) or pantalar
```

### Operative criteria

| Procedure | Indication | Contraindication |
|---|---|---|
| **Tenosynovectomy / PTT debridement** | **Stage I after failed immobilisation** | Stage II+ alone (no deformity correction) |
| **FDL transfer → navicular** | **Stage II** (FDL synergistic with PT) | **Subtalar rigidity (< 15° motion)** · **fixed forefoot varus > 10–12°** |
| **Stage II reconstruction** | Failed nonop, flexible | **Hypermobility** · **neuromuscular** · **severe subtalar arthritis** · obesity (relative) · **age > 60–70** (relative) |
| **MDCO** | **Flexible hindfoot valgus** (IIA; all stage II) | Rigid valgus |
| **Lateral column lengthening (Evans)** | **Forefoot abduction / TN uncoverage > 40%** (IIB) | Stage IIA · normal calcaneal pitch or mild valgus (Chi) |
| **Cotton** | **Residual forefoot varus / supination, stable medial column** | Medial column unstable / arthritic |
| **1st TMT (Lapidus) / NC fusion** | **Stage II with 1st TMT hypermobility, instability or arthritis** · NC sag | — |
| **Isolated subtalar arthrodesis** | **No fixed forefoot deformity** | **Fixed forefoot supination / varus** (→ lateral border overload) · hypermobility |
| **Triple / hindfoot arthrodesis** | **Stage III** · **stage II with severe subtalar arthritis** | Ankle valgus / arthritis not addressed |
| **Triple + TAL + deltoid reconstruction** | **Stage IV, passively correctable ankle valgus** | Ankle arthritis |
| **TTC arthrodesis** | **Stage IV: rigid hindfoot, valgus talus, tibiotalar + subtalar arthritis** | — |

### Nonoperative care – orthoses (UCBL, AFO, medial posting)

**Stage I** — **immobilisation in walking cast / boot 3–4 months = first line** → custom-molded in-shoe orthosis after

**Stage I (TO)** — immobilisation, ice, NSAID, rest · **CAM walker boot → less muscle atrophy than plaster** · orthotics eliminate forefoot pronation, rest TP · PT once inflammation settles · recalcitrant → **arthroscopic or open debridement + synovectomy** (TO)

**AFO indications** — **initial treatment for stage II, III + IV** · non-operative candidates (**sedentary / low demand, age > 60–70**, comorbid)

| Orthosis | Key facts |
|---|---|
| **Custom in-shoe orthosis** | Stage I after immobilisation, stage II · **medial heel lift + longitudinal arch support** · **+ medial forefoot post if fixed forefoot varus / supination** |
| **UCBL with medial posting** | Plastic over cast in **maximal manual correction** · **flexible** deformity · first-line orthotic for stage II · not for rigid → uncomfortable, **skin breakdown** |
| **AFO family** (Arizona, molded, articulating) | **Most effective** · **acquired flexible flatfoot deformity** · medial post supports valgus collapse |
| **Short articulated AFO** | **Rigid flatfoot (stage III), active patient, normal stable ankle** → supports deformity, **keeps ankle motion** |
| **Arizona brace** | **Molded leather lace-up gauntlet** (UCBL + laced ankle support) → stabilises tibiotalar, hindfoot + arch · **significantly limits ankle motion** · TO: custom rigid AFO above malleoli accommodates rigid flatfoot (TO) |
| **Non-articulated AFO** | **Rigid planovalgus** (OB) · **stage IV** — deltoid incompetence + talar tilt (Elftman; stage III → articulated AFO) — read the options |
| **Custom-molded AFO** | Advanced rigid AAFD, **not an operative candidate** (fitted in situ) |
| **Rocker-bottom shoe** | **No role in PTTI** (OB — ankle / subtalar arthritis, calcaneal ulcers) · palliative for rigid flatfoot (TO) — read the options |
| PTB brace (TO) | Offloads foot in severe rigid flatfoot (TO) |

**Medial post** — **promotes hindfoot inversion** · elevates medial heel → ↓ lateral hindfoot impingement pressure · fits any shoe\
✗ Wrong options: medial post for eversion · lateral post for inversion · lateral post for forefoot varus / adduction

**Rigid flatfoot nonop (TO)** — palliative only, accommodates deformity · activity modification, NSAIDs, **steroid injection into subtalar / TN joint** · for elderly, low-demand, medically unfit or surgery-averse (TO)

**Best nonop responders** — **elderly patient with a sedentary lifestyle**\
✗ Wrong options: young active · inflammatory systemic disorder · balance / ambulation problems: **Parkinson's**, severe ipsilateral **hip / knee arthritis**

**Outcomes** — AFO + PT: **83% improved at 4 mo, 89% satisfied** (Alvarez) · molded AFO (rigid) / UCBL (flexible): **67%** good–excellent (Chao) · **~90%** satisfaction nonop stage II (Deland) · eccentric exercise group improved most (Kulig)

**✗ Orthotic traps** — **lateral hindfoot posting + 1st ray cutout** = cavovarus (worsens PTTI) · full-length semi-rigid insole + 1st ray depression + lateral wedge = cavovarus · **total contact cast** = insensate / Charcot · **Morton's extension** / rigid forefoot plate limiting MTP DF = hallux rigidus · wide toe box = hallux valgus · rigid sole + rocker = midfoot arthritis · pressure-dissipating insoles + accommodative laced shoes = diabetic neuropathy · AFO = mild equinovarus · **CROW** = neuropathic severe deformity

**Stage II, fixed forefoot supination, first visit** — **medial heel lift, longitudinal arch support + medial forefoot posting**\
✗ Wrong options: Lapidus + LCL + spring repair (1st TMT hypermobility, after failed orthosis) · short boot + lateral heel wedge (stage I) · triple · FDL + MDCO (after failed nonop)

**Stage II, untreated, no abduction** — **physical therapy and orthotics with medial hindfoot posting**\
✗ Wrong options: FDL + calcaneal osteotomy + Cotton + gastroc (only after failed nonop) · triple (rigid)

**Stage II, improved with 6 wk PT** — custom orthotic with **medial post + arch support** → hindfoot inversion

**Rigid stage III, avid walker, normal ankle, declines surgery** — **short articulated AFO**\
✗ Wrong options: short leg cast NWB (early tendon "rest") · CAM boot + PTT strengthening + Achilles stretch (immobilises normal ankle) · UCBL + medial heel wedge (stage I–II flexible) · Arizona (limits ankle motion, affects gait)

### Flexible deformity – FDL transfer, calcaneal osteotomy, lateral column lengthening, Cotton, gastrocnemius recession

**Classic stage II** — **medial displacement calcaneal osteotomy + posterior tibial augmentation with flexor digitorum longus tendon transfer** to navicular\
✗ Wrong options: PTT debridement alone · triple · ankle fusion · Lapidus

**Why MDCO** — corrects hindfoot valgus (**static**) · **shifts Achilles pull medially** · **offloads / protects the transferred FDL** · moves heel WB axis toward tibial axis (TO) · **transfer alone → early failure**\
✗ Wrong options: isolated FDL transfer

**FDL (dynamic)** — **synergistic with PT** → augments a deficient PT · found at **knot of Henry** · inserted into **navicular** near PT insertion

**Knot of Henry** — at ankle FDL anterior to FHL ("Tom, Dick and Harry") · **in the midfoot FHL crosses dorsal (deep) to FDL** → structure immediately deep to FDL at harvest = **flexor hallucis longus**\
✗ Wrong options: Achilles (not in exposure) · FHB (anterolateral to FHL) · adductor hallucis (too distal) · abductor hallucis (never crosses FDL)

**FDL vs FHL** — **FDL is standard** (Orthobullets) · FHL harder to mobilise, no better results · FHL + MDCO: arch not reconstituted, good satisfaction (OB) · **TO answer = FHL transfer** (FDL not offered) — read the options

**Stage II (TO)** — bilateral planovalgus, heel valgus **passively correctable non-WB**, can't single heel rise → **medial displacement calcaneal osteotomy, tibialis posterior tendon debridement and FHL transfer** (TO)\
✗ Wrong options: posterior tibial tenotomy + lengthening · PTT debridement + medial arch support orthotics · subtalar arthrodesis + MDCO + FHL (no arthritis)

**Outcome** — FDL + MDCO: **87% arch reconstitution, 84% normal shoes without orthotics** (Myerson)

**IIA (flexible, no forefoot abduction)** — **medial calcaneus displacement osteotomy + FDL transfer to navicular** alone\
✗ Wrong options: lateral calcaneal displacement (worsens valgus) · peroneus longus → brevis (cavovarus) · **split PTT transfer** (spastic equinovarus)

**IIB (too many toes)** — **+ lateral column lengthening (Evans)**: opening wedge of **anterior calcaneus** or through **CC joint** · **LCL corrects forefoot abduction** · aims: adduct TN joint, plantarflex midfoot, derotate calcaneus out of valgus · may need MDCO too\
✗ Wrong options: hindfoot valgus (MDCO) · hindfoot varus, forefoot adduction, cavus (not PTTI features)

**LCL titration** — overlengthening → correct with 1st TMT fusion or medial cuneiform osteotomy · **overcorrection (> 5–10 mm) → lateral column overload**

**IIB package** — **medial calcaneal displacement osteotomy, lateral column lengthening, FDL tendon transfer and tendoachilles lengthening** (or gastroc recession) ± **Cotton**\
✗ Wrong options: tenosynovectomy + UCBL (stage I) · **Dwyer closing wedge + 1st MT closing wedge + plantar fascia release** (cavovarus) · triple (stage III) · **lateral** calcaneal displacement

**Flexible planovalgus, failed AFO** — **lateral column lengthening, medializing calcaneal osteotomy, FDL transfer to the navicular**\
✗ Wrong options: isolated FDL · 1st ray dorsiflexion osteotomy + PL → PB (cavus) · lateralizing calcaneal osteotomy · triple

**Large talar head uncoverage, painful heel rise that corrects valgus** — **medializing calcaneal osteotomy + lateral column lengthening + flexor digitorum longus transfer to the medial navicular**\
✗ Wrong options: PTT débridement (stage I only) · FDL alone · MCO + FDL without LCL · triple (supple, no arthritis)

**Equinus not correcting with knee flexed, 50% uncoverage, no arthritis** — **stage IIB: transfer of FDL to medial navicular + MCO + lateral column lengthening + tendo-Achilles lengthening (TAL)**\
✗ Wrong options: stage I debridement · IIA (has abduction) · triple / TTC

**Gastroc-only equinus** — DF **−5° knee extended → +10° flexed** → **open gastrocnemius muscle lengthening** (recession / Strayer) · gastroc + soleus both tight → **TAL** (open Achilles lengthening for significant deformity, percutaneous) · recession = less weakness, better cosmesis, less powerful correction\
✗ Wrong options: posterior ankle capsule release (ankle can DF) · PL → PB

**No equinus** — Silfverskiöld **+5° / +5°** → no lengthening needed

**Forefoot varus / supination** — compensatory; **unmasked once hindfoot corrected** intra-op → must be corrected or residual deformity

**Cotton osteotomy** — **plantarflexion (dorsal) opening wedge medial cuneiform osteotomy** = **plantarflexion osteotomy to correct residual forefoot varus** · requires **stable medial column** (navicular colinear with 1st MT)\
✗ Wrong options: medial opening wedge for abduction · for forefoot valgus · for hindfoot valgus

**Cotton corrects** — **forefoot supination / varus**\
✗ Wrong options: forefoot abduction (LCL) · forefoot pronation (cavovarus) · hindfoot equinus (gastroc / Achilles release) · hindfoot valgus (MCO static + FDL dynamic)

**After FDL + MCO + TAL, forefoot still supinated** — **plantarflexion opening wedge medial cuneiform osteotomy**\
✗ Wrong options: dorsiflexion closing wedge (worsens) · in-situ 1st–3rd TMT fusion (Lisfranc) · lateral column closing-wedge shortening · subtalar fusion (subtalar arthritis)

**Cotton vs 1st MT–cuneiform fusion** — Cotton: **predictable union, preserves 1st-ray mobility, easily varied correction**

**Unstable medial column (plantar sag at 1st TMT and / or NC)** — **medial column fusion**: isolated 1st TMT, NC, or both

**1st TMT instability + abduction, flexible hindfoot** — **first tarsal-metatarsal arthrodesis, medializing calcaneal osteotomy, flexor digitorum longus tendon transfer and lateral column lengthening**\
✗ Wrong options: Cotton + MCO + FDL (no 1st TMT instability) · triple + Achilles lengthening (rigid) · TTC + gastroc (stage IV) · 1st TMT + subtalar fusion + PTT debridement ± LCL (IIB with severe subtalar arthritis; subtalar fusion + LCL rarely combined → CC fusion instead; PTT debridement no proven benefit)

**Modified Lapidus** — indication = **plantar gapping between medial cuneiform and first metatarsal base** (1st TMT instability) · = 1st TMT fusion + distal soft tissue (modified McBride) ± medial cuneiform osteotomy · also 1st TMT arthritis, hypermobility, neuromuscular\
✗ Wrong options: flexible hindfoot valgus · Meary 12° · TN uncoverage 50° → LCL · + Silfverskiöld → gastroc recession

**Stage IIB + gastroc tightness, no TMT instability** — **flexor digitorum longus transfer, medial calcaneal slide osteotomy, lateral column lengthening, Cotton osteotomy, gastrocnemius recession**\
✗ Wrong options: PTT synovectomy + FDL (no bony correction) · lateral calcaneal slide (varus feet) · 1st TMT arthrodesis (no instability) · triple

**Contraindication to FDL + osteotomies + LCL + Cotton** — **rigid hindfoot valgus** → arthrodesis\
✗ Wrong options: failed heel raise · forefoot varus · forefoot abduction · pes planus (all expected in stage II)

| Procedure (Chi) | Indication | Contraindication |
|---|---|---|
| **Lateral column lengthening** | TN sag, forefoot abduction, **valgus calcaneus** | **Normal calcaneal pitch or mild valgus** · can overcorrect → forefoot varus |
| **Medial column stabilisation** | NC / cuneiform–1st MT **sag**, forefoot abduction, **neutral calcaneus** | Valgus calcaneus with flat pitch |
| **Combined medial + lateral** | NC / cuneiform–1st MT sag **+ valgus calcaneus** | — |
| **Medial column + MCO** | **Valgus calcaneus with normal pitch** | — |

**MIS vs open calcaneal osteotomy** — **traditional open technique associated with higher wound complications + longer surgical time compared to MIS technique** · MIS: smaller incision, **fewer wound complications**, **↓ nerve injury**, **shorter time**, **same radiographic + patient outcomes** · radiation **↓ with MIS** (Orthobullets) · **no difference** (OB) — read the options

**Exam ↔ procedure** — **flexible forefoot abduction and hindfoot valgus deformities + gastrocnemius contracture** ↔ FDL + MCO + LCL + gastroc lengthening · flexible HF valgus + gastroc contracture ↔ MCO + gastroc lengthening · isolated PTT tenderness ↔ tenosynovectomy after failed immobilisation · rigid forefoot + hindfoot ↔ triple + gastroc · + tibiotalar arthritis ↔ tibiotalar fusion ± triple

**FDL + MCO alone** — female with pain, **inability to perform single leg heel raise + flexible hindfoot valgus deformity**, no abduction = **IIA**\
✗ Wrong options: rigid → triple · + deltoid compromise → triple + deltoid / TTC · retained heel raise → stage I, maximise nonop then debridement · + forefoot abduction → IIB, needs LCL ± spring reconstruction

### Rigid deformity – triple, hindfoot & TTC arthrodesis

**Rigid adult flatfoot causes (TO)** — **stage III / IV PTTD**, post-traumatic deformity, inflammatory arthropathy (TO)

**Surgery indication (TO)** — persistent pain + functional limit despite adequate nonop, fit + willing (TO)

**Stage III gold standard** — **triple arthrodesis (talocalcaneal, talonavicular + calcaneocuboid fusion) with appropriate structural realignments** (TO) (TO)\
✗ Wrong options: LCL (Evans) + Cotton · isolated PTT reconstruction with FDL transfer + spring repair · isolated subtalar fusion without addressing the midtarsal complex

**Triple technique (TO)** — one or two incisions (medial + lateral) · realign valgus, abducted, dorsiflexed hindfoot → **neutral / slight valgus (5°), adducted, plantigrade** · **multiple cannulated screws** · bone graft (resected surfaces / iliac crest) · **NWB 6–8 wk** → boot until union **12–16 wk** (TO) · fusion **98%** at 2 yr (Pell)

**Principles (TO)** — **plantigrade, braceable foot** > perfect angles · **correct all components** (valgus + abduction + arch; subtalar alone leaves TN subluxation) · **equinus → Strayer or percutaneous TAL** concurrently (deforming force into pronation) · **forefoot varus → Cotton** (dorsal opening wedge medial cuneiform, plantarflexes 1st ray) or **lateral border overload** (TO)

**Preferred stage III surgery** — **arthrodesis of calcaneocuboid, talonavicular and subtalar joints**\
✗ Wrong options: FDL + MDCO + TAL (flexible) · pantalar (stage IV) · FDL + LCL through anterior calcaneus · PTT debridement + tenodesis to FDL

**Forefoot derotation in triple** — after subtalar realigned, **forefoot varus unmasked** → **derotation of the forefoot through the transverse tarsal joints** (TN + CC) → plantigrade, no **lateral border foot pain** · alternatives: Cotton, 1st TMT fusion, NC fusion\
✗ Wrong options: derotation through CC alone (can't fix abduction) · dorsiflexion osteotomy medial cuneiform · isolated TN fusion (subtalar degenerate too) · no further step

**Double arthrodesis** — **talonavicular + subtalar** via **single medial incision** when **CC not substantially arthritic** (OB; medial approach: no wound complications) · TO: double = **TN + CC**, spares subtalar when subtalar arthrosis minimal + deformity at TN (TO) — read the options

**TN + subtalar case** — rigid hindfoot + TN not passively correctable, pain on resisted inversion, failed bracing → **talonavicular and subtalar arthrodesis**\
✗ Wrong options: CROW (neuropathic) · MCO + PTT debridement ± FDL ± LCL (joint-sparing fails in rigid: no arthritic pain relief, loss of correction)

**Isolated subtalar fusion** — **stage III** with mainly subtalar symptoms / arthritis (OB) · no fixed forefoot deformity (Orthobullets) · **rarely sufficient** for rigid flatfoot — TN usually degenerate → isolated subtalar coalition or post-traumatic subtalar arthritis (TO) · obese elderly with Chopart arthritis → subtalar alone leaves **TN + CC symptomatic** → triple (OB) — read the options

**Rigid = stage III examples** — 70-year-old, **hindfoot not passively correctable** → **triple arthrodesis** (✗ Wrong options: talocalcaneal arthrodesis · FDL + calcaneal slide ± LCL through cuboid) · obese 75-year-old → **triple** (✗ Wrong options: double calcaneal osteotomy · subtalar alone) · obese 62-year-old, **plantar-medial callus = talar head**, TN dislocation, no hindfoot motion → **triple** (✗ Wrong options: exostectomy (destabilises) · LCL · MCO · TN arthrodesis)

**Heel rise test for rigidity** — **hindfoot valgus persisting with double-leg heel rise** = rigid → **triple** even with only 25% TN uncoverage\
✗ Wrong options: heel inverts to varus on heel rise = flexible IIA / IIB → reconstruction · 14-year-old flexible flatfoot → conservative

**Hindfoot arthrodesis** — **stage III** (usually triple) · **stage II with severe subtalar arthritis**\
✗ Wrong options: walking cast / boot 3–4 mo (stage I) · FDL + calcaneal osteotomy + TAL ± forefoot osteotomy (stage II) · 1st TMT fusion + calcaneal osteotomy + TAL ± LCL (stage II + 1st TMT hypermobility) · TTC (no tibiotalar arthritis / tilt)

**Stage IV** — **passively correctable ankle valgus** (cartilage preserved) → **triple arthrodesis + deltoid ligament reconstruction** (+ TAL) · **rigid ankle valgus + tibiotalar arthritis** → **tibiotalocalcaneal (TTC) arthrodesis** with **retrograde hindfoot nail** · end-stage ankle arthritis → **pantalar (triple + ankle) fusion** — eliminates all hindfoot + ankle motion (TO; OB: "stage IV → pantalar")

**Stage IV, Meary 30°, ankle osteophytes, rigid subtalar + tibiotalar valgus** — **tibiotalocalcaneal arthrodesis**\
✗ Wrong options: AFO (functionally limiting deformity) · MCO + FDL ± deltoid repair (rigid) · triple (ignores ankle)

**TTC caveat** — salvage only; **tibiotalar joint provides most DF / PF**

**Unfit for surgery** — stage IV + **severe symptomatic aortic stenosis** → **custom-molded ankle-foot orthosis (AFO)**\
✗ Wrong options: TTC · triple (stage III) · triple + deltoid (stage IV correctable) · in-shoe orthosis with medial forefoot post (stage I–II with forefoot varus)

**Midfoot (NC) flatfoot** — flexible hindfoot, full strength, collapse at NC joint on X-ray → **navicular-cuneiform arthrodesis**\
✗ Wrong options: lateral calcaneal slide (worsens, cavovarus) · MCO / LCL (stage II PTTI) · TN arthrodesis (part of stage III)

## 6 Complications

| Complication | Cause / fact |
|---|---|
| **Lateral column overload** → **5th MT stress fracture**, lateral column stiffness | **LCL (anterior calcaneal opening wedge) for stage IIb** · overcorrection > 5–10 mm |
| CC arthritis | After LCL — **14%** radiographic, rarely symptomatic (Mosier-LaClair) |
| **Lateral border foot pain** | **Forefoot varus not corrected** after hindfoot realignment / isolated subtalar fusion with fixed forefoot varus |
| Early transfer failure | FDL transfer **without** hindfoot valgus correction |
| **Lateral plantar nerve** | **Retrograde hindfoot (TTC) nail start point** (mid plantar heel, centred on talus + tibia) → **numbness lateral plantar midfoot** → careful dissection to bone for guidewire + nail |
| **FHL impingement** | **Long lateral → medial calcaneal interlocking screw** by **sustentaculum** → ↓ hallux flexion |
| Loss of correction | Joint-sparing surgery in rigid deformity |
| Progression untreated | Flexible → rigid (peritalar arthritis) → deltoid failure → **tibiotalar valgus**, arthritis, near-total loss of ankle ROM |

### Lateral column overload & hindfoot-nail nerve injury

**5th MT stress fracture after correction of** — **stage IIb PTTI** (LCL)\
✗ Wrong options: ligamentous Lisfranc (planovalgus malreduction, PTOA) · moderate hallux valgus (iatrogenic hallux varus, transfer metatarsalgia) · stage I (tenosynovectomy) · stage IIa (normal TN coverage, no LCL)

**Numbness after retrograde hindfoot nail** — **lateral plantar midfoot** (lateral plantar nerve, branching medially from tibial nerve)\
✗ Wrong options: medial plantar midfoot (medial plantar n.) · lateral hindfoot (sural) · medial hindfoot (saphenous) · plantar hindfoot (medial calcaneal n.)

**Long distal interlocking screw by sustentaculum** — **flexor hallucis longus**\
✗ Wrong options: lateral plantar nerve (nail start point, not screw) · tibialis anterior · saphenous vein (superficial) · tibial nerve (anterior to FHL, not by sustentaculum)
