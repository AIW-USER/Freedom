# Cerebral Palsy - Upper Extremity Disorders

*Pediatrics · 18 / 112*

## 1 Basics

**Who** — **hemiplegia** and **quadriplegia**

**Typical posture** — **shoulder IR · elbow flexion · forearm pronation · wrist flexion + ulnar deviation · thumb-in-palm** · finger flexion

**Wrist flexion cause** — weak wrist extensors · spastic wrist flexors · volar capsule contracture → weak grip, hygiene problems

### Hygienic vs functional procedures

| | **Hygienic** | **Functional** |
|---|---|---|
| Patient | ↓ mental + physical function | **Voluntary control**, **IQ ≥50–70**, **good sensibility** (position sense without vision) |
| Examples | Releases, **wrist arthrodesis + PRC** | **Tendon transfers** (FCU → ECRB), PT rerouting |

**Voluntary control** — best predictor of improvement after **hand/wrist tendon transfer**

## 3 Presentation

### Volkmann angle

**Technique** — **fingers extended**, wrist from maximal flexion → extend wrist · angle short of full extension = **Volkmann angle**\
✗ Wrong options: fingers flexed (must stretch extrinsic flexors)

**Meaning** — high Volkmann angle → **extrinsic finger flexor contracture** → correcting wrist alone gives **clenched fist** unless finger flexors also lengthened

![Measuring Volkmann angle](../../MCQ/attachments/q219551-illc-illustration-c.jpg)

| Volkmann angle | Severity / treatment |
|---|---|
| **~15°** | Mild → **FCU or FCR lengthening** |
| **~25°**, correctable wrist | **FCU + FDS/FDP tenotomy + ECU → ECRB transfer** |
| **Cannot reach within 45° of neutral** | Severe → **wrist arthrodesis + PRC** |
| **90° + palmar wounds** (fingers-in-palm) | **PRC + wrist fusion + FDS → FDP** |

**Distractors** — locked IR shoulder + extended elbow = **arthrogryposis** · unstable thumb CMC = **Blauth IIIB hypoplasia** (pollicise) · constricting bands = constriction band syndrome

## 4 Diagnosis & Classification

### House classification (thumb-in-palm)

| Type | Deformity | Treatment |
|---|---|---|
| **I** | **1st MC adduction** contracture | Adductor release ± 1st dorsal interosseous release · **Z-plasty** 1st web |
| **II** | + **MP flexion** contracture | Adductor release |
| **III** | + **unstable / hyperextensible MP** | Adductor release + **MP fusion or capsulodesis** |
| **IV** | + **MP + IP flexion** contractures | Adductor release + **FPB + FPL release/lengthening** |

## 5 Management

### Operative criteria

| Deformity | Procedure | Indication |
|---|---|---|
| **Shoulder IR** | Derotational humeral osteotomy and/or subscapularis + pectoralis lengthening | **>30°** contracture interfering with hand function |
| **Elbow flexion** | **Lacertus fibrosus release**, biceps + brachialis lengthening, brachioradialis origin release | Elbow flexion contracture |
| **Forearm pronation** | **Pronator teres release / rerouting** to anterolateral (makes it a **supinator**) · or FCU → ECRB | Pronation deformity · risk: **supination deformity** (worse than pronation) |
| **Wrist flexion, mild** | **FCU or FCR lengthening** | Good finger extension, little wrist-flexor spasticity |
| **Wrist flexion, functional** | **FCU → ECRB (Green)** · FCU → EDC | Supple wrist, voluntary control, IQ ≥50–70, sensibility · **better long-term than botox/therapy** |
| Wrist flexion, spastic FCU | **ECU → ECRB** | Avoids hyperextension from transferring spastic FCU |
| Wrist flexor weakening | **Flexor-pronator slide** (from medial epicondyle) | Severe fixed wrist + finger flexion (also post-compartment syndrome) |
| **Fixed, non-supple** | **Wrist arthrodesis ± PRC** | No volitional control · hygiene + function |
| Swan neck | Correct wrist flexion first | Intrinsic tightness + extensor overpull |

```
CP wrist flexion deformity
├─ Supple, voluntary control, functioning FCU
│      ├─ Good grasp → FCU to EDC
│      └─ Poor grasp / weak extensors → FCU to ECRB (Green)
├─ Supple but finger-flexor tightness (Volkmann 25°) → FCU + FDS/FDP tenotomy + ECU to ECRB
└─ Rigid, no volitional control, palmar wounds → PRC + wrist arthrodesis (dorsal plate)
```

### Wrist flexion deformity – tendon transfers vs arthrodesis (Volkmann angle, FCU to ECRB, pronator teres rerouting)

**Green transfer (flexor carpi ulnaris → extensor carpi radialis brevis, FCU → ECRB)** — supple wrist, **weak/absent wrist extensors**, resting ulnar deviation · improves **extension + supination** · **most effective for restoring supination** · not if no functioning **FCR** or **rigid wrist**

**Pronator teres rerouting** — converts PT to **supinator** · very functional patient with **no active but full passive supination** + good sensibility → **PT transfer**\
✗ Wrong options: anconeus, brachialis, brachioradialis, supinator

**PT to ECRB** — powers wrist extension when wrist flexors can't be used

**Distractors** — ✗ Wrong options: PT → FCU (↑ pronation + ulnar deviation) · botox (inferior to transfer) · PT/brachioradialis rerouting (less effective than Green for supination)

**Wrist arthrodesis** — best for deformity **not passively correctable** · **with PRC** (↓ soft-tissue tension, provides graft) · dorsal plate · **union >95%**, high satisfaction\
✗ Wrong options: <75% union · higher failure in spastic CP · only after failed Green

## X vs Y

| | **FCU → ECRB (Green)** | **Wrist arthrodesis + PRC** |
|---|---|---|
| Wrist | **Supple** | **Rigid** |
| Control | **Voluntary**, good sensibility | Lacks volitional control |
| Goal | Function — extension + supination | Hygiene, position, fingers out of palm |
| Contraindication | Rigid wrist, no FCR | — |

## How it's asked

**"Exam missed before wrist fusion + PRC?"** → **fingers extended, wrist can't extend to within 45° of neutral (Volkmann)**

**"Functioning flexors, flexible wrist, absent extensors — best result?"** → **FCU to ECRB**

**"No active, full passive supination, good sensibility — transfer?"** → **pronator teres**

**"Best restoration of supination?"** → **FCU to ECRB (Green)**\
✗ Wrong options: PT → FCU · PT/BR rerouting · fusion

**"True of wrist arthrodesis?"** → **best when deformity not passively correctable**

**"Correctable wrist, Volkmann 25°, lasting correction?"** → **FCU + FDS/FDP tenotomy with ECU transfer**\
✗ Wrong options: PT · botox · FCU tenotomy alone · fusion

**"Rigid wrist fused in neutral with dorsal scar — indication?"** → **Volkmann 90° with palmar wounds**\
✗ Wrong options: GMFCS V alone · supple ulnar deviation
