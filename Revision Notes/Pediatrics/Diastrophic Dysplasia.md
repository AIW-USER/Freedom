# Diastrophic Dysplasia

*Pediatrics · 33 / 112*

## 1 Basics

**Epidemiology** — rare · **Finland** (carrier **1 in 70** Finns)

### SLC26A2 sulfate transporter & phenotype

### Genes & lab markers

**Inheritance** — **autosomal recessive** (both parents carriers)

**Gene** — **DTDST = SLC26A2**, **chromosome 5q** → defective **sulfate transporter** → **undersulfation of cartilage proteoglycan** → abnormal cartilage matrix (ear, trachea, ligaments)

**Ossification** — failure of secondary ossification centres (OB)

**No commercial test** — many mutations → clinical + radiographic + family history · prenatal US possible

| Gene (distractors) | Disorder |
|---|---|
| **SLC26A2 / DTDST** | **Diastrophic dysplasia** ✓ |
| FGFR3 | Achondroplasia, hypochondroplasia |
| FGFR2 | Apert (craniosynostosis + complex syndactyly) |
| CBFA-1 / RUNX2 | Cleidocranial dysplasia (osteocalcin) |
| Gs α (GNAS) | Fibrous dysplasia |
| COL1A1/2 | OI (blue sclera, bowing) |
| COL5A1/2 | Ehlers-Danlos (classic) |
| Lysosomal storage | Hunter, Hurler |
| Lipid storage | Gaucher |

## 3 Presentation

**"Twisted dwarf"** — **short-limbed** (rhizomelic) dwarfism, diagnosed at birth

| Feature | Note |
|---|---|
| **Cauliflower ears** | **80%** · cystic swelling of pinnae · responds to early **compressive bandages** |
| **Hitchhiker thumb** | **Short 1st MC + radial subluxation of MCP** (abducted) |
| **Cleft palate** | **60%** (59%) |
| **Cervical kyphosis** | **Severe**, early · often **resolves spontaneously** |
| Thoracolumbar kyphoscoliosis | Progressive |
| Feet | **Rigid clubfeet (equinocavovarus)** · **skewfoot** (TMT adductus + hindfoot valgus) · tarsal valgus 43%, MT adductus 37% |
| Lower limb | **Genu valgum** (± dislocated patellae) · hip + knee contractures · hip dislocation |
| Hand | Symphalangism (stiff fingers) |
| Other | **Tracheomalacia** (can be fatal) · atlantoaxial instability (rare) |

## 4 Diagnosis & Classification

### Key radiology findings

**Views** — AP + lateral **cervical** and **thoracolumbar** spine · standing 3-joint lower-limb films

## 5 Management

**Most** — observation + supportive

### Operative criteria

| Problem | Surgery |
|---|---|
| **Atlantoaxial instability + neuro symptoms** | **Occipitocervical fusion** (quadriplegia risk) |
| Cervical kyphosis **not resolving** | Posterior cervical fusion |
| Progressive TL kyphoscoliosis | ASF / PSF |
| Foot deformity after casting · severe hip/knee contractures | Soft-tissue release |
| Progressive valgus, resistant clubfeet, fixed knee flexion, early hip subluxation | Osteotomies (distal femoral extension, valgus intertrochanteric ± acetabuloplasty) |
| End-stage hip OA | THA |

## How it's asked

**"Newborn hitchhiker thumb, SLC26A2 mutation, carrier parents?"** → **diastrophic dysplasia**\
✗ Wrong options: achondroplasia · OI · hypochondroplasia · EDS

**"Pathoanatomy of hitchhiker thumb + cauliflower ear dwarfism?"** → **sulfate transporter mutation affecting cartilage matrix**\
✗ Wrong options: CBFA-1 · lysosomal · lipid storage · FGFR3

**"Genetic cause of hitchhiker thumb, cauliflower ears, severe clubfeet?"** → **sulfate transport protein**\
✗ Wrong options: FGFR2 · FGFR3 · CBFA-1 · Gs α

**"DTDST defect phenotype?"** → **cauliflower ears + hitchhiker thumb**\
✗ Wrong options: blue sclera · MR + cardiac = Down · craniosynostosis + syndactyly = Apert · rhizomelia + frontal bossing = achondroplasia

**"Spine region most deformed?"** → **cervical kyphosis** (often resolves)

**"Treatment of cauliflower ears?"** → **early compressive bandaging**
