# Marfan Syndrome

*Pediatrics · 63 / 112*

## 1 Basics

**Incidence** — **1 in 10,000** · no ethnic or sex predilection

### Genes & lab markers

**Inheritance** — **autosomal dominant** · **~30% sporadic**

**Gene** — **fibrillin-1 (FBN1)**, chromosome **15q21** · fibrillin = glycoprotein of **elastin-containing microfibrils**

**TGF-β** — misfolded fibrillin **sequesters TGF-β poorly** → ↑ tissue TGF-β (lungs, valves, aorta) → **aortic dilatation**

**Aneurysm mechanism** — **TGF-β + renin-angiotensin system** act synergistically (AngII → wall remodeling + TGF-β via Smad) → **losartan (ARB)** proposed (mixed results vs β-blockers)\
✗ Wrong options: CRP · interferon-γ

**Genetic testing** — FBN1 testing **neither sensitive nor specific** → diagnosis by **Ghent nosology** (clinical + family history; diagnoses/excludes 86%, caution in young children)

### Genetics & pathophysiology (fibrillin, TGF-beta)

| Defective protein | Disease |
|---|---|
| **Fibrillin-1** | **Marfan** |
| Elastin | Supravalvular aortic stenosis, AD cutis laxa |
| **FGFR3** | Achondroplasia |
| Type I collagen (COL1A1/2) | OI, Ehlers-Danlos |
| Type II collagen | SED, achondrogenesis, Stickler |
| **COMP** | Pseudoachondroplasia |
| Neurofibromin (NF1) | Neurofibromatosis |

| Other molecule (distractors) | Role |
|---|---|
| BMP-2 | Osteoblast differentiation, bone growth |
| Osteocalcin | ↑ insulin, glucose uptake |
| Indian hedgehog | Chondrocyte proliferation |

### Clinical features

| Orthopaedic | Non-orthopaedic |
|---|---|
| **Arachnodactyly** | **Aortic root dilatation / dissection** |
| **Scoliosis (50%)** — often first diagnosed | **Mitral valve prolapse** |
| **Protrusio acetabuli (15–25%)** | **SUPERIOR lens dislocation (60%)** (✗ Wrong options: inferior (homocystinuria)) |
| **Dural ectasia (>60%)** · meningocele | **Spontaneous pneumothorax** |
| Ligamentous laxity, recurrent dislocations (patella, shoulder, fingers), ankle sprains | Myopia |
| **Pes planovalgus** | Skin striae, recurrent hernias |
| Pectus excavatum / carinatum | — |

**Dural ectasia** — also in **NF1** · complicates instrumentation

## 3 Presentation

**Dolichostenomelia** — **arm span > height (ratio >1.05)**

**Steinberg thumb sign** — thumb tip extends beyond ulnar border of hand when clasped under fingers

**Walker-Murdoch wrist sign** — thumb + small finger distal phalanges **overlap** around opposite wrist

**Sudden death** — aortic dissection / MVP → **exertion or pregnancy** · cardiovascular causes nearly all early deaths

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — scoliosis series → scoliosis, kyphosis

**MRI spine before surgery** — **dural ectasia** (→ CSF leak risk)

**CT before surgery** — pedicle / bony adequacy for fixation

**Echo + cardiology** — **before ANY surgery** (dissection, anticoagulation for prosthetic valves)

**Protrusio acetabuli** — CE angle **>40°** + medial wall past **ilioischial line** · differential: Marfan, Paget, RA, psoriatic, AS, infection (TB), osteomalacia, fibrous dysplasia, idiopathic

## 5 Management

### Cardiovascular evaluation

**Rule** — orthopaedist often first to suspect → refer **cardiology** (± genetics) · **cardiovascular evaluation before conception** and before surgery\
✗ Wrong options: genetic testing first · spine/brain MRI first

**Medical** — **β-blockers** ↓ aortic dilatation · laxity → observation + orthotics

### Scoliosis management

**Bracing** — early mild curves · **less effective than AIS**, usually refractory\
✗ Wrong options: "often effective if started early"

**Surgery** — **PSF ± ASF** · rapidly progressive curve in immature patient · large curve in mature · **extend construct** (avoid adding-on) · fuse to pelvis for obliquity / poor distal fixation · growing rods if young · **maximise fixation points**, slow distraction/compression · **avoid overcorrection** (cardiovascular complications) · treating kyphosis risks vertebral subluxation

**Early surgery routinely needed for** — **progressive scoliosis**\
✗ Wrong options: kyphosis · ankle instability · protrusio · tibial pseudarthrosis (NF1)

| Complication vs AIS | Marfan |
|---|---|
| **Fixation failure** (most common — thin laminae/pedicles, osteopenia) | **↑** |
| Infection | ↑ |
| **Pseudarthrosis** | ↑ |
| **Dural tear / CSF leak (8%)** | ↑ |
| Decompensation, reoperation | ↑ |
| Blood loss | Same |
| **Neurologic deficit** | **Same** (✗ Wrong options: increased) |
| Length of stay | Same |

### Acetabular protrusio

| Situation | Treatment |
|---|---|
| Asymptomatic, stable | Observation |
| **Progressing or painful**, immature | **Triradiate cartilage closure** (controversial) |
| Mature, young, minimal OA | **Valgus osteotomy** |
| Older, symptomatic OA | **THA** |

## How it's asked

**"Marfan — defective gene encodes?"** → **fibrillin**\
✗ Wrong options: elastin · FGFR3 · collagen I/II

**"Finding most linked to FBN1 mutation?"** → **dural ectasia**\
✗ Wrong options: Sprengel · sacral agenesis · fibular hemimelia · Lisch nodules

**"Misfolded glycoprotein, TGF-β accumulation, dural ectasia — associated?"** → **positive thumb and wrist signs**\
✗ Wrong options: spinal stenosis · odontoid hypoplasia · enlarged calves

**"Fibrillin-1 defect → diagnosis?"** → **Marfan syndrome**\
✗ Wrong options: pseudoachondroplasia (COMP)

**"Two factors synergistic in Marfan aortic aneurysm?"** → **TGF-β and renin-angiotensin system**

**"Elevated TGF-β associated with?"** → **aortic dilatation**\
✗ Wrong options: impaired chondrocyte proliferation

**"All associated with Marfan EXCEPT?"** → **inferior lens dislocation**

**"23-yr, bilateral protrusio, wants to conceive?"** → **cardiovascular evaluation**\
✗ Wrong options: genetic testing · pelvic CT

**"Tall basketball player, pectus, flatfeet — refer for?"** → **cardiovascular evaluation**\
✗ Wrong options: ophthalmology · genetics

**"Marfan scoliosis — all true EXCEPT?"** → **bracing often effective if started early**

**"Vs AIS surgery — all true EXCEPT?"** → **increased neurologic deficits**

**"Routinely needs early surgery in Marfan?"** → **progressive scoliosis**
