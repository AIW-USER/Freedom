# Cleidocranial Dysplasia (Dysostosis)

*Pediatrics · 22 / 112*

## 1 Basics

### Epidemiology

**Incidence** — **~1 in 1,000,000**

### RUNX2 mutation, inheritance & features

**Defect** — **intramembranous ossification** → failure of **midline structures** (clavicles, skull, pubic symphysis, face)

**Hallmark** — **hypoplastic or absent clavicles**

### Genes & lab markers

**Inheritance** — **autosomal dominant** · ~**two-thirds familial**

**Gene** — **RUNX2 = CBFA1 (core-binding factor α1)** · **heterozygous loss of function** · transcription factor for **osteoblast differentiation**

**No commercial test** — many mutations → diagnosis = family history + clinical/radiographic features

| Gene (distractors) | Disorder |
|---|---|
| **RUNX2 / CBFA1** | **Cleidocranial dysplasia** ✓ |
| **SOX9** | **Campomelic dysplasia** |
| cAMP / GNAS → c-fos | **Fibrous dysplasia** |
| BMP-2 | — (not CCD) |
| COL1A1 / COL1A2 | OI |
| DTDST | Diastrophic dysplasia |
| FGFR2 | Apert (complex syndactyly) |
| FGFR3 | Achondroplasia |
| Fibrillin-1 | Marfan |
| Dystrophin | Duchenne (calf pseudohypertrophy) |

## 3 Presentation

**Body** — **proportionate dwarfism** · short stature

**Shoulders** — **hypermobile, droopy** · can **approximate shoulders in front of chest** · narrow chest\
✗ Wrong options: ectodermal dysplasia · MED · glenoid dysplasia

**Skull/face** — **frontal bossing**, large head · **delayed closure of fontanelles + sutures** · **wormian bones** · hypertelorism, midface hypoplasia

**Teeth** — **delayed eruption of permanent teeth** (Orthobullets) · delayed primary teeth (OB) · **supernumerary teeth** → crowding (TO)

**Hands** — **short middle phalanges of 3rd–5th fingers** (Orthobullets) · short terminal phalanges (TO)

**Hips/pelvis** — **coxa vara** (± coxa valga) · **delayed ossification of pubis** (wide symphysis) · lateral notching of capital femoral epiphysis

**Other** — scoliosis, kyphosis, **genu valgum**, pes planus, syringomyelia · **normal intellect**

## 5 Management

**Clavicles** — **observe** · most manifestations need no intervention

### Operative criteria

**Intertrochanteric (reorienting valgus) osteotomy** — **coxa vara with neck-shaft angle <100°**

### Craniosynostosis – trigonocephaly

**Trigonocephaly** — **metopic suture** fusion (triangular "keel" forehead) · metopic is **first suture to close** (3–8 months) (TO)\
✗ Wrong options: unilateral/bilateral coronal · sagittal

| Shape | Suture |
|---|---|
| **Scaphocephaly / dolichocephaly** (boat) | **Sagittal — most common (~50%)** |
| Brachycephaly | Bicoronal ± bilambdoid |
| Frontal plagiocephaly | Unilateral coronal (harlequin eye) |
| Occipital plagiocephaly | Unilateral lambdoid |
| **Trigonocephaly** | **Metopic** |
| Oxycephaly / turricephaly | Sagittal + coronal + lambdoid |
| Cloverleaf | Intrauterine multi-suture (most severe) |

**Craniosynostosis** — M:F **3:1** · 1 in 2000–2500 · coronal ~20%, lambdoid ~5%, metopic ~5% · syndromic ~8–10%: **Apert, Crouzon, Carpenter** · anterior fontanelle closes **18–24 mo**

## X vs Y

| | **Cleidocranial dysplasia** | **SED tarda** | **SCFE / hypothyroid** |
|---|---|---|---|
| Clavicles | **Absent/hypoplastic** | Normal | Normal |
| Hip | **Coxa vara**, unossified pubis | Coxa vara, poorly ossified epiphyses | Slipped epiphysis |
| Ossification defect | **Intramembranous** | Endochondral (COL2A1) | — |

## How it's asked

**"Shoulder approximation in front of chest?"** → **cleidocranial dysplasia** (TO)

**"Heterozygous loss-of-function gene causing CCD?"** → **RUNX2**\
✗ Wrong options: BMP-2 · cAMP · c-fos · SOX-9

**"8-yr, extreme shoulder motion, frontal bossing, abnormal clavicles + coxa vara?"** → **cleidocranial dysplasia**\
✗ Wrong options: SED tarda · hypothyroidism · SCFE · renal osteodystrophy

**"Droopy shoulders, absent clavicles, delayed pubic ossification — inheritance?"** → **autosomal dominant**

**"Mutated core-binding factor A1 — clinical photo?"** → **shoulders touching (CCD)**\
✗ Wrong options: marfanoid · rhizomelia · calf pseudohypertrophy · cavovarus

**"Defective intramembranous ossification — gene?"** → **RUNX2/CBFA1**\
✗ Wrong options: COL1A1 · DTDST · FGFR2 · SOX9

**"Coxa vara in CCD — when operate?"** → **neck-shaft angle <100°**

**"Trigonocephaly results from?"** → **metopic suture fusion** (TO)
