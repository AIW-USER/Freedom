# Cervical Myelopathy

*Spine · 15 / 69*

## 1 Basics

### Aetiology

**Commonest cause** — **degenerative cervical spondylotic myelopathy (CSM)**: osteophytes, disc-osteophyte complex, degenerative spondylolisthesis, **LF hypertrophy**

**Others** — **congenital stenosis** (symptoms when spondylosis adds on) · **OPLL** · tumour · epidural abscess · trauma · kyphosis

**Cord injury mechanism** — direct compression + **ischaemia (anterior spinal artery compression)**

**Tandem stenosis (cervical + lumbar)** — **\~20%** (Orthobullets) · **5–25%** (OB) → myelopathy **takes precedence**

### Epidemiology & canal diameter

**Commonest level of spondylosis (TO)** — **C5-6**, then C6-7 (most subaxial motion)\
✗ Wrong options: C3-4 · C1-2

| Canal (AP) | Value (TO) |
|---|---|
| Normal | \~17 mm (C1 23, C2 20, C3–6 17, C7 15) |
| **Relative stenosis** | **10–13 mm** |
| **Absolute stenosis** | **< 10 mm** (area < 100 mm²) |
| Cord compression | Canal **< 13 mm** (Orthobullets) |
| **Pavlov (Torg) ratio** | **< 0.8** → congenitally narrow canal |

**X-ray degeneration** — **70% by age 70** · MRI false positives: **28%** of > 40 yrs have HNP / foraminal stenosis

### Natural history

**Pattern** — **slow, stepwise deterioration with plateaus** · rarely improves non-op\
✗ Wrong options: stable · rapid continuous decline · improves with steroids/rest

**Worse non-op outcome** — segmental kyphosis, circumferential compression

## 3 Presentation

**Symptoms** — neck pain/stiffness (often absent; **\~15%** of severe cases painless), occipital headache · **diffuse non-dermatomal** bilateral paraesthesia · **hand clumsiness** (buttons, handwriting, dropping things) · **gait instability** (most important clinical predictor; stairs) · urinary retention (**rare, late**)

**Severe CSM** — proximal LL muscles weaker than distal (opposite in lumbar stenosis)

### Clinical diagnosis – UMN signs

| Sign | Fact |
|---|---|
| **Gait ataxia** | **Commonest physical finding (91%)** (OB) |
| **Hoffmann** | Flick middle finger DIP → thumb/index flexion; "most common exam finding" (Orthobullets) · **80%** (OB) / 59% in another series; ↑ with severity |
| Hyperreflexia | LL 81%, UL 67%; **absent if concomitant peripheral neuropathy / root compression / diabetes** |
| **Inverted radial reflex** | Tap distal brachioradialis → finger flexion |
| **Sustained clonus (> 3 beats)** | **Sensitivity \~13%, specificity \~100%** |
| **Babinski** | **Least common** (≤ 1/3) |
| **Finger escape (Wartenberg)** | Small finger abducts/flexes (intrinsic weakness) |
| **Grip-and-release** | Normal **20 in 10 s** |
| **Lhermitte** | Neck **flexion → electric shock** down spine/limbs; specific, insensitive; also MS |
| Romberg / tandem gait | Posterior column dysfunction |
| Proprioception loss | Advanced, **poor prognosis** |
| Pinprick ↓ | Lateral spinothalamic tract |

**UMN vs LMN** — **fasciculations, atrophy, tongue fasciculations, areflexia = LMN** (EXCEPT answers) · weakness = both

**Myelopathy hand** — intrinsic/webspace atrophy, finger escape, **dysdiadochokinesia**, Hoffmann \
✗ Wrong options: **intrinsic plus posture**

**Other tests** — Spurling (radiculopathy) · Jackson (hyperextension) · Lasègue (lumbar SLR)

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Findings |
|---|---|
| **X-ray** (AP, lateral, oblique, flex-ext) | Uncovertebral + facet degeneration, osteophytes, disc narrowing; **Pavlov < 0.8**; **C2-C7 alignment** + **local kyphosis angle**; obliques → foraminal stenosis; flex-ext → instability / compensatory subluxation |
| **MRI** | **Study of choice**; CSF effacement = functional stenosis; **T2 bright = myelomalacia**; **T1 signal change → poorer prognosis**; **compression ratio < 0.4 → poor prognosis** |
| CT | OPLL, osteophytes |
| **CT myelogram** | Pacemaker / hardware artefact (C1-2 or lumbar puncture) |
| NCS | High false negatives; separates peripheral vs central (ALS) |

**Compression ratio** — smallest **AP** cord diameter ÷ largest **transverse** diameter

![Compression ratio of the cord](../../Orthobullets/attachments/ob2031-compression-ratio.jpg)

**Prognostic MRI** — **focal** T2 signal better than **multisegmental** T2 signal · isolated **low T1** = gliosis/cavitation, little improvement · cord shape boomerang → teardrop → **triangular** (worst)

**Non-op success predictor** — **transverse cord area > 70 mm²**\
✗ Wrong options: ↑ CMCT · low T1 signal · canal < 13 mm · younger age

**Differential** — normal ageing, stroke, movement disorders, **B12 deficiency**, **ALS**, **MS**

### Tandem stenosis

**Lumbar claudication + UMN signs (hyperreflexia, clonus, broad gait, clumsy hands)** — **MRI cervical (± thoracic) spine before lumbar surgery** · pacemaker → **CT myelogram of C-spine** · gait problem with 5/5 strength + mild lumbar stenosis → **MRI thoracic + cervical** (brain MRI second-line)\
✗ Wrong options: lumbar decompression ± fusion · ESI · PT · discogram · ABI

### Classifications

| Nurick | |
|---|---|
| 0 | Root symptoms only |
| 1 | Cord signs, **normal gait** |
| 2 | Gait difficulty, **fully employed** |
| 3 | Gait prevents employment, walks unassisted |
| **4** | **Walks with assistance** |
| 5 | Chair / bedbound |

| Ranawat | |
|---|---|
| I | Pain, no deficit |
| II | Subjective weakness, hyperreflexia, dysaesthesia |
| IIIA | Objective weakness + long-tract signs, **ambulatory** |
| IIIB | Same, **non-ambulatory** |

**JOA / mJOA (17 points)** — UL motor, LL motor, sensory, bladder · **severe = mJOA < 12** · excellent outcome ≥ 16

## 5 Management

**Non-op** — mild disease **without functional impairment** or poor surgical candidate (function > exam findings) · NSAIDs, gabapentin, collar in slight flexion, PT · no traction/chiropractic · **cord compression without myelopathy signs → PT**\
✗ Wrong options: surgery

**Surgery** — significant functional impairment / progression; **mild myelopathy by mJOA** also indicated; **operate as soon as medically stable**\
✗ Wrong options: wait for Nurick IV, multisegmental T2 signal, intolerable pain, incontinence

### Goals & outcomes of surgery

**Goal** — **halt stepwise neurologic decline**\
✗ Wrong options: complete recovery · mJOA > 16 · resolve myelomalacia · restore normal lordosis (aim neutral)

**Expected** — **significant mJOA improvement at 1 yr even in severe (mJOA 10) CSM**; gait / sensory improvement variable

### Approach selection

```
Cervical myelopathy surgery
├─ 1–2 levels, anterior pathology → ACDF (± corpectomy)
├─ ≥ 3 levels, lordotic / neutral
│      ├─ No axial neck pain, want motion → LAMINOPLASTY
│      └─ Axial neck pain / instability → LAMINECTOMY + FUSION
└─ Fixed kyphosis > 10–13°
       ├─ ≤ 2 levels → ANTERIOR (ACDF / corpectomy)
       └─ ≥ 3 levels → ANTERIOR + POSTERIOR
```

### Operative criteria – alignment thresholds

| Threshold | Meaning |
|---|---|
| **Fixed kyphosis > 10°** | Anterior procedure (corrects kyphosis); posterior alone not enough |
| **Local kyphosis > 13°** | Contraindication to posterior decompression / **strongest predictor of poor laminoplasty outcome** (✗ Wrong options: multilevel stenosis · osteoporosis · CSF effacement) |
| **Kyphosis > 12° + > 2 levels** | **Combined A/P** (OB) |
| **≥ 3-level corpectomy** | Anterior alone → **> 70% catastrophic failure** → add posterior |

**Bowstringing** — in kyphosis cord drapes over anterior osteophytes; posterior decompression can't let it drift back

### Anterior decompression – ACDF/corpectomy

**ACDF** — **mainstay for 1–2 levels**, anterior pathology (soft disc, disc-osteophyte, focal OPLL), fixed kyphosis > 10° · single-level CSM gold standard (TO) · Smith-Robinson approach · avoid with poor swallowing

**Anterior vs posterior** — anterior: **↓ infection, ↓ blood loss, ↓ post-op pain** · no difference in C5 palsy, C7 radiculopathy, overall complications

**Corpectomy** — retrovertebral disease / kyphosis · 2-level corpectomies vulnerable (prefer **1 corpectomy + adjacent discectomy**) · **graft dislodgement 7–20%** (can be fatal) · **2-level → add posterior fixation**; **3-level → A + P mandatory**

**3-level corpectomy, anterior plate failure** — prevented by **combined anterior + posterior fixation**\
✗ Wrong options: discectomies (can't decompress OPLL) · mesh cage · longer collar/halo · screw mix

### Cervical disc arthroplasty

**Ideal (TO)** — skeletally mature, 20–70 yrs, **1–2 levels C3–C7**, soft disc, minimal spondylosis, preserved facets, disc height ≥ 3 mm, ≥ 6 wks failed non-op · single-level myelopathy without kyphosis → CDA gives best function (OB)

**Contraindications (TO)** — **≥ 3 levels** · **instability (> 3 mm translation / > 11° rotation)** · **facet degeneration** · axial neck pain alone · severe spondylosis (bridging, > 50% height loss, < 2° motion) · osteoporosis / metabolic bone disease · adjacent fusion / prior surgery at level · **morbid obesity (BMI > 40)** · **RA / spondyloarthropathy** · infection, malignancy, steroids, pregnancy · kyphotic deformity \
✗ Wrong options: **2-level disease** (NOT a contraindication)

**Complication** — hardware failure → retropulsion

### Posterior decompression – laminectomy/fusion vs laminoplasty

| | Laminectomy + fusion | Laminoplasty |
|---|---|---|
| Indication | **Multilevel**, kyphosis < 10°, **axial neck pain** (facet) | **Multilevel**, **preserved lordosis**, **congenital stenosis**, **OPLL**, motion desired, pseudarthrosis risk (diabetes, steroids) |
| Contraindication | Fixed kyphosis > 10–13° | **Kyphosis > 13°** (e.g. 15°, 20°); severe axial neck pain (relative) |
| Motion | Lost | **Preserved** (some loss) |
| Wound complications | Higher | **Lower** |
| Cost (2 yr) | **Higher** | Lower |
| Revision | Comparable | Comparable |
| ASD | Higher | Lower |
| C5 palsy | Higher (some series) | Similar / lower |

**Laminoplasty mechanism** — ↑ **AP** canal dimension + cord drifts dorsally · **open door** = unilateral hinge, opening held by bone/anchors/plate · **French door** = bilateral hinges, midline opening · C3–7 · facets not violated · bilateral exposure still needed\
✗ Wrong options: medial-lateral

**Not contraindications to laminoplasty** — OPLL · multilevel stenosis · 30° flex-ext motion · age > 55 · SAC < 8 mm · prior posterior surgery · radiculopathy (add keyhole foraminotomy) · C7 SVA +5 cm · compression ratio 0.3

**Laminoplasty + fusion after ACDF** — preserves **paraspinal muscle attachments / ↓ atrophy**\
✗ Wrong options: infection · neuro · stay benefit

**Laminectomy alone** — rarely; **post-laminectomy kyphosis 11–47%**

**Posterior-alone ideal image** — **multilevel stenosis with preserved lordosis**\
✗ Wrong options: teardrop fracture · kyphotic multilevel → A/P · skip-level lordotic → skip ACDF · anterior abscess

**Central cord syndrome on background CSM + axial neck pain, multilevel** — **posterior decompression + fusion**\
✗ Wrong options: 2-level corpectomy without posterior · lumbar MRI (proximal weaker)

### Combined anterior-posterior

**Indications** — **multilevel stenosis in rigid kyphotic spine** · multilevel corpectomies · **post-laminectomy kyphosis**

**Occipitocervical fusion** — periodontoid pannus (posterior-only resolves pannus; transoral ↑ morbidity > 4 h)

## 6 Complications

### C5 palsy

**Definition** — post-op **deltoid ± biceps** weakness ≥ 1 grade without myelopathy worsening

**Incidence** — **\~4.6%** (Orthobullets) · 5–12% after laminoplasty · 0–30% range

**Timing** — immediate to **weeks** (most within 1 week; up to 20 days); **92% unilateral**; half with C5 pain/sensory change

**Risk factors** — **male** (strongest) · **laminectomy + fusion** (higher in some studies) \
✗ Wrong options: age · myelopathy severity · OPLL · level

**Anterior vs posterior** — **no significant difference** (Orthobullets, OB, TO); laminoplasty lower in some studies

**Mechanism** — **dorsal cord drift tethers C5 root** (C5 at apex of lordosis) vs segmental cord ischaemia/reperfusion · prevention: prophylactic **C4-5 keyhole foraminotomy**, avoid excessive cord shift/lordosis, deltoid/biceps MEP monitoring

**Prognosis** — **good**; observe · \~80% recover by 6–12 months · **prolonged recovery: multilevel paresis, motor grade ≤ 2, sensory involvement + intractable pain**\
✗ Wrong options: revision · extension · steroids

### Anterior approach complications

| Complication | Fact |
|---|---|
| **RLN palsy (hoarseness)** | Commonest nerve injury (\~1%); **prolonged tracheo-oesophageal retraction / ET cuff**; **right = left** in studies; **↑ in revision (up to 9.5%)**; observe → ENT at **6 wks** (Teflon); revision on **same side** as prior palsy · left RLN loops **aortic arch**, right **subclavian** |
| **Dysphagia** | 30–50%; **local retropharyngeal steroid** before closure ↓ it (✗ Wrong options: TXA · incision type) |
| **Airway compromise** | **> 5 h surgery, > 300 mL blood loss, multilevel at/above C3-4 (C2–C4 exposure)** → **keep intubated 24–48 h** |
| **Retropharyngeal haematoma (TO)** | **6–24 h**, tense incision, dyspnoea/dysphagia/dysphonia → **immediate evacuation** |
| Angioedema (TO) | **6–12 h**, face/tongue swelling → IV steroids, antihistamine, adrenaline |
| Pharyngolaryngeal oedema (TO) | **12–72 h**, voice change, worse supine → may need **cricothyrotomy** |
| **Vertebral artery** | **Burr through lateral wall** of body in corpectomy |
| Horner | Lateral retraction on **longus colli** (sympathetic chain) |
| Superior laryngeal nerve | Rare; C4 and above |
| Hypoglossal | Rare; tongue deviation |
| Oesophageal | Rare; trauma, revision, diverticula |

### Posterior approach & general complications

| Complication | Fact |
|---|---|
| **Infection** | **Higher posterior** than anterior |
| **Pseudarthrosis** | **12% single, 30% multilevel** (3-level ACDF + plate fusion \~80%) |
| **Post-laminectomy kyphosis** | Loss of posterior tension band + muscle denervation; ↑ with pre-op kyphosis, **> 30–50% facet resection**, **children (\~100%)** → **A/P revision** |
| **Epidural haematoma** | **1/1000**; new weakness → **emergent MRI + evacuation** |
| Hardware failure | 7–20% after 2-level corpectomy → stabilise posteriorly |

| Epidural haematoma age | T1 | T2 |
|---|---|---|
| **Hyperacute (< 24 h)** | **Hypo** | **Hyper** (STIR bright) |
| Acute (1–3 d) | Iso | Hypo |
| Subacute (3 d–2 wk) | Hyper | Hypo |
| Chronic (> 2 wk) | Hypo | Hypo |

### Root-level localisation

| Disc → root | Motor | Sensory | Reflex |
|---|---|---|---|
| **C4-5 → C5** | **Deltoid** (± biceps) | **Lateral arm** | Biceps |
| **C5-6 → C6** | **Biceps (elbow flexion) + wrist extensors** | **Radial forearm, thumb** | **Supinator (brachioradialis)** |
| **C6-7 → C7** | **Triceps + wrist flexors** | Index, middle (ring) | **Triceps** |
| **C7-T1 → C8** | **Finger flexors (FDP)** | **Little finger, ulnar hand/forearm** | — |
| T1 | Finger abduction | Medial forearm | — |

**Cervical rule** — disc compresses the **exiting lower root** (C5-6 → C6)

**Shoulder abduction relief sign** — radiculopathy (C7 here; elbow flexion weakness = C6)

## X vs Y

| | Myelopathy | Radiculopathy |
|---|---|---|
| Lesion | Cord (UMN) | Root (LMN) |
| Signs | Hoffmann, clonus, broad gait | Dermatomal pain, weak reflex |
| Tests | Lhermitte | Spurling, shoulder abduction relief |

| Early airway problem after ACDF (TO) | Time | Treatment |
|---|---|---|
| Angioedema | 6–12 h | Steroids / antihistamine / adrenaline |
| **Retropharyngeal haematoma** | **6–24 h** | **Immediate evacuation** |
| Pharyngolaryngeal oedema | 12–72 h | Reintubation / cricothyrotomy |
