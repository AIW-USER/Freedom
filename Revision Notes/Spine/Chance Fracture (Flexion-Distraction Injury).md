# Chance Fracture (Flexion-Distraction Injury)

*Spine · 20 / 69*

## 1 Basics

**Definition** — thoracolumbar **flexion-distraction (seat-belt / jack-knife)** injury; described by **GQ Chance 1948** (purely osseous)

**Level** — **T12–L2 / T12–L3** (transitional zone; TO: D12–L2)

**Types** — **bony** (fracture through spinous process → lamina → pedicles → body; heals well) · **ligamentous / discoligamentous** (through disc + ligaments; heals poorly) · mixed

**Neuro deficit** — relatively **low** incidence (TO)

### Associated intra-abdominal injuries (lap belt)

**GI injury \~50%** — **commonest associated injury** (✗ Wrong options: head injury · pulmonary contusion · pelvis · GU) · colon rupture, small bowel / **duodenal** tear (✗ Wrong options: tamponade · bladder rupture · cholecystitis)

**Seat-belt sign** (abdominal ecchymosis) → suspect **flexion-distraction injury** + bowel injury · lap-only belts (old cars, rear seat, children)\
✗ Wrong options: L5 TP fracture (pelvic ring) · burst · pars · HNP

## 2 Mechanism

**Axis of rotation** — **anterior to the spine** (abdominal wall / **abdominal viscera**) — lap belt acts as fulcrum\
✗ Wrong options: ISL · PLL · ALL

**Column failure** — **posterior + middle columns fail in tension (distraction)** · **anterior column**: fails in **compression** (Orthobullets, OB) · "no crushing of the body" (TO) — TO answer: **middle + posterior columns fail in distraction**

**Posterior column failure mode** — **tension**\
✗ Wrong options: torsion · shear · compression

**Pure ligamentous variant (X-ray)** — **splayed spinous processes + ↑ posterior disc height**, no body fracture

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Use |
|---|---|
| X-ray AP + lateral | **Interspinous widening**, horizontal fracture line, empty pedicle sign on AP |
| Flexion-extension | Instability |
| **CT** | Bony extent; retropulsion |
| **MRI** | **Posterior ligamentous complex (PLC)** — ↑ T2 in ISL / PLL = ligamentous injury |

![Lateral X-ray: Chance fracture through posterior elements](../../Orthobullets/attachments/ob2023-lateral-xray-moved.jpg)

### AO thoracolumbar classification (TO)

| Type | Pattern |
|---|---|
| **A0** | Spinous / transverse process fracture |
| A1 | Wedge, one endplate, posterior wall intact |
| A2 | Split, both endplates, posterior wall intact |
| A3 | Incomplete burst — one endplate + posterior wall |
| A4 | Complete burst — both endplates + posterior wall |
| **B1** | **Monosegmental osseous posterior tension band failure = bony Chance** |
| **B2** | **Osseoligamentous posterior tension band** disruption (± bone; ISL T2 signal; heals slower) |
| B3 | **Hyperextension** — anterior tension band failure (ankylosed spines) |
| C | Translation / dislocation (no subtypes; all operative) |

**Neuro modifier** — N0 intact · N1 transient · N2 radicular · N3 incomplete SCI / cauda equina · N4 complete · NX unknown · "+" ongoing compression

**Case modifiers** — **M1** indeterminate tension band injury · **M2** comorbidity (AS, skin, rheumatologic)

**B1 vs B2** — B1: CT line through spinous process, MRI posterior elements may look normal · B2: ISL hyperintense, body comminution favours B2

### Operative criteria (TO – TLICS)

| TLICS component | Points |
|---|---|
| **Distraction** mechanism | **4** |
| PLC injury suspected / confirmed | 2 / 3 |
| Neuro intact | 0 |
| **Total ≥ 5** | **Surgery** (≤ 3 non-op) |

## 5 Management

```
Chance / flexion-distraction injury
├─ Purely bony, PLC intact, neuro intact, kyphosis < 15–20° → HYPEREXTENSION CAST / TLSO (12–16 wks)
│      (serial X-rays for nonunion + kyphosis)
├─ Ligamentous / mixed (PLC torn) → POSTERIOR COMPRESSION INSTRUMENTATION + FUSION
│      (1 level above + 1 below with pedicle screws)
└─ Neuro deficit → DECOMPRESSION + STABILISATION
```

**Non-op union** — > 90% in selected bony injuries (cancellous bone heals)

**Surgical construct** — **compression** construct for Chance · historically 3 above + 2 below · modern pedicle screws **1 above + 1 below** (short segment ± index screws)\
✗ Wrong options: distraction (that's for burst)

**Anterior** — vertebrectomy + strut + instrumentation (decompression)

**Laminectomy** — only for compressive deficit; further destabilises posterior column

**Bowel perforation** — laparotomy first; spine staged or same sitting

**Paediatric soft-tissue Chance (8-yr, L3-4, CT negative for bone)** — **L3-4 posterior instrumented fusion**\
✗ Wrong options: percutaneous screws (bony only) · TLSO · L1-5 fusion + laminectomy · PLIF

**Bony-ligamentous L2 (PLC + PLL signal, through superior endplate), ASIA E (TO)** — **posterior short-segment instrumentation**\
✗ Wrong options: cast (not purely osseous) · surgery justified by seat-belt sign · TLSO because neuro intact

## 6 Complications

| Complication | Note |
|---|---|
| **Pain** | Commonest |
| **Progressive kyphosis** | **Unrecognised PLL/PLC injury** |
| Scoliosis, flat back | Forward-flexed posture, fatigue |
| Post-traumatic syringomyelia | — |
| Nonunion | Ligamentous / non-op |

## X vs Y

| | Chance (flexion-distraction) | Burst |
|---|---|---|
| Mechanism | Flexion + distraction, axis **anterior** | **Axial load** ± flexion, axis middle column |
| Posterior column | **Tension** failure | Usually intact |
| Middle column | Tension | **Compression** (retropulsion) |
| Associated | **Bowel injury 50%** | Calcaneus, other spine |
| Construct | **Compression** | Distraction |

| | Bony Chance (AO B1) | Ligamentous (AO B2) |
|---|---|---|
| Healing | Good | Poor |
| Rx | **Hyperextension brace / cast** | **Posterior fusion** |

## How it's asked

**"Lap-belt bruising + Chance fracture — commonest associated injury?"** → **colonic / GI injury**

**"Seat-belt sign, GCS 8 — suspect?"** → **flexion-distraction injury**

**"Lap belt + small bowel tear — spinal injury?"** → **flexion-distraction**

**"Lap belt, posterior column involved — likely associated injury?"** → **gastrointestinal**

**"Mechanism of Chance fracture?"** → **flexion-distraction** (TO)

**"Columns failing in Chance fracture?"** → **middle + posterior in distraction** (TO)

**"Posterior column failure mode?"** → **tension**

**"Centre of rotation, ligamentous Chance?"** → **abdominal viscera (anterior to spine)**

**"8-yr soft-tissue Chance L3-4, no deficit?"** → **L3-4 posterior instrumented fusion**

**"Bony Chance — AO type?"** → **B1** (TO)

**"L2 bony-ligamentous Chance with PLC signal, ASIA E?"** → **posterior short-segment instrumentation** (TO)
