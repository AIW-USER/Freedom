# Scheuermann's Kyphosis

*Spine · 52 / 69*

## 1 Basics

### Epidemiology

**Incidence** — 0.4–8.3% · **commonest structural kyphosis in adolescents** · 2nd commonest adolescent deformity after idiopathic scoliosis (TO)

**Age / sex** — onset **10–12 yrs** (diagnosed 12–17) · **M:F 2:1 to 7:1**

**Location** — **thoracic** (commonest) · thoracolumbar/lumbar less common

### Genes & pathology

**Inheritance** — **autosomal dominant**

**Theory (most accepted)** — **developmental error in collagen aggregation → abnormal endplate** (defective endochondral ossification) · others: ring apophysis osteonecrosis, disc herniation, relative osteoporosis, biomechanical growth arrest

**Histology (TO)** — abnormal endplate cartilage, irregular mineralisation, **↓ collagen : proteoglycan ratio**

**HLA-B27** — association stated in one OB explanation

### Associations

| Association | Rate |
|---|---|
| **Lumbar hyperlordosis** | Compensatory |
| **Lumbar spondylolysis** | **33%** (Orthobullets) · **50–54%** (TO) — read the options |
| **Scoliosis** | **33%** |
| Dural cysts | — |
| Tight hamstrings, iliopsoas, anterior shoulder | — |
| Pulmonary compromise | Curves **> 100°** |

## 3 Presentation

**Symptoms** — cosmesis, dull thoracic/lumbar pain (worse with activity, better with rest) · neuro deficit **rare**

**Exam** — **rigid kyphosis, sharper angulation on forward bending** · doesn't correct prone/extension · compensatory cervical/lumbar lordosis

**Normal thoracic kyphosis** — **20–45°** (Orthobullets) · **20–50°** T5-T12 (OB) — 38° in a 13-yr = normal · any thoracolumbar kyphosis abnormal

## 4 Diagnosis & Classification

### Diagnostic criteria (Sorensen)

| Criterion |
|---|
| **Anterior wedging > 5° of 3 consecutive vertebrae** (at apex) |
| Irregular endplates / apophyseal lines |
| **Schmorl's nodes** (disc into endplate) |
| **Disc space narrowing** |
| TO: + thoracic kyphosis **> 50°** |

✗ Wrong options: **Traps** — posterior wedging, lumbar hypolordosis, preserved disc height, **marginal syndesmophytes (AS)**

![Anterior wedging over three vertebrae](../../Orthobullets/attachments/ob2061-f1-1-moved.jpg)

### Key radiology findings

| Study | Use |
|---|---|
| AP + lateral standing | Wedging, endplates, Schmorl's, scoliosis · **C7 plumb line** (sagittal balance) |
| **Hyperextension lateral (supine over bolster)** | **Separates postural kyphosis** · Scheuermann's is **inflexible** |
| MRI | Pre-op (controversial) — disc herniation, epidural cyst, cord, stenosis · **any neuro deficit** |
| Lumbar films | Spondylolysis if LBP |

### Types

| | Thoracic (typical, type 1) | Thoracolumbar / lumbar (atypical, type 2) |
|---|---|---|
| Curve | T1/2–T12/L1, **apex T6–T8** | T4/5–L2/3, apex TL junction |
| Frequency | Commonest | Less common |
| Radiograph | Wedging | **Endplate irregularity, Schmorl's, narrow discs — less wedging** |
| Course | **Better prognosis** | **More pain, more progressive** |
| Surgical threshold | 70–75° | **25–30°** (OB) |

## 5 Management

```
Scheuermann's kyphosis
├─ < 60° (TO: < 50°), mild symptoms → OBSERVE + PT (extension, hamstring stretch)
├─ 60–80° with growth left → EXTENSION BRACE (Jewitt / Milwaukee)
└─ > 75°, neuro deficit, cord compression, severe adult pain → POSTERIOR SPINAL FUSION ± PONTE / SPO
```

### Bracing

**Thresholds** — **60–80° with growth remaining** (Orthobullets) · **50–74°** skeletally immature (OB) · **> 50° with ≥ 1 yr growth + 40–50% flexibility** (TO) — read the options

**Brace** — **extension orthosis (Jewitt, high chest pad)** · **Milwaukee** (TO) full time 12–18 months then part time · TLSO if apex **T7–T9 or lower** · Boston for < 70°

**Outcome** — stops progression; best if **< 65°** and **> 15° correction in brace** · compliance poor \
✗ Wrong options: Charleston night brace · electrical stimulation

**TO answer** — 12-yr, 55°, pain, no deficit → **Milwaukee brace**

### Operative criteria

| Indication | Source |
|---|---|
| **Kyphosis > 75°** | Orthobullets, OB |
| **> 70–75° + pain not relieved + unacceptable cosmesis — all** | TO |
| **> 60° + persistent pain** | OB |
| Neuro deficit, cord compression | All |
| Severe pain in adults | Orthobullets |
| Not if painless < 75° | OB |

**Technique** — **posterior-only PSF, dual rods**, pedicle screws ± hooks · **cantilever** or **compression across posterior anchors** · **Ponte (posterior shortening)** for stiff curves: remove spinous processes, flavum, facets · anterior release rarely now · **MEP + SSEP monitoring**\
✗ Wrong options: intracanal hooks at apex

**Osteotomy choice** — **Smith-Petersen** for **long, sweeping kyphosis** (\~10°/level, less in rigid Scheuermann) \
✗ Wrong options: PSO (AS, 30–40°/level) · VCR (sharp angular kyphosis)

**Goal** — final kyphosis **40–50°** · **correct ≤ 50%** of original

### Fusion levels

**Proximal** — whole kyphotic Cobb

**Distal (LIV)** — **sagittal stable vertebra (SSV)**: most proximal body **bisected by / ≥ 50% anterior to the posterior sacral vertical line** · old **first lordotic disc** method → more DJK

**Too long (e.g. L5 when SSV is L3)** — protects against DJK but **excessively stiff** → early disc degeneration

![Posterior sacral vertical line selecting LIV](../../MCQ/attachments/q218926-b-screenshot-2023-05-02-at-11-46-17-am.jpg)

**Outcomes** — 60–90% pain improvement (not correlated with correction) · residual > 75° → worse function

## 6 Complications

| Complication | Fact |
|---|---|
| **Neurologic** | **0.6–0.8%** (> AIS surgery) · cord stretch → ensure posterior shortening · reverse correction on signal change |
| **Distal junctional kyphosis** | **20–30%** · avoid: fuse to **SSV**, **don't overcorrect > 50%** |
| **Proximal junctional kyphosis** | **Overcorrection + negative sagittal balance** (less common) |
| Others | Pseudarthrosis, hardware failure, loss of correction, **SMA syndrome** |

**Junctional kyphosis** — Cobb **> 10°** between fused and unfused segments

**Prognosis** — at least some progression in **80%** · adult pain rarely limits activity (mean 71°) · > 75° → severe thoracic pain

## X vs Y

| | Scheuermann's | Postural kyphosis |
|---|---|---|
| Rigidity | **Rigid** | Corrects on hyperextension |
| Wedging | > 5° × 3 | None |
| Forward bend | **Sharp angulation** | Smooth |

## How it's asked

**"Not true regarding Scheuermann's?"** → **"cannot be corrected by postural control"** (TO key — read carefully; Orthobullets calls it rigid)

**"13-yr, 38° thoracic kyphosis?"** → **normal range**

**"16-yr chronic back pain, wedged vertebrae — expected finding?"** → **Schmorl's nodes**

**"15-yr athlete, mid-back pain — underlying condition?"** → **anterior wedging > 5° across three consecutive vertebrae**

**"12-yr, 55° kyphosis with pain, no deficit?"** → **Milwaukee brace** (TO)

**"Risser 2, kyphosis corrects to 50°?"** → **extension-type spinal orthosis**

**"Surgical indication?"** → **all — > 70° curve, pain + rigidity, unacceptable cosmesis** (TO)

**"Fixed 80° kyphosis, no correction on hyperextension?"** → **Smith-Petersen osteotomies + posterior arthrodesis**

**"Fusion stopped at L5 beyond SSV (L3)?"** → **protects against DJK but excessively stiff**

**"14-yr Risser 4, rigid 90° kyphosis?"** → **posterior spinal fusion + instrumentation**
