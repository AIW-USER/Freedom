# Thoracolumbar Burst Fractures

*Spine · 66 / 69*

## 1 Basics

### Epidemiology & mechanism

**Mechanism** — high-energy **axial load ± flexion** (falls, MCC) · anterior + middle column compression → **retropulsion**

**Level** — **thoracolumbar junction T10–L2** (commonest **L1**, OB key **L2** among L2–S1) · > 50% of thoracic + lumbar fractures (T12–L2) · TL junction = stress riser between rigid ribbed thoracic (T1–10) and mobile lumbar spine · T10–12 floating ribs

| Region (TO) | Feature | Typical injury |
|---|---|---|
| T1–T8 | Rigid (rib cage), kyphotic | Flexion · > half have rib/chest injury |
| **T9–L2** | Rigid → mobile, kyphosis → lordosis | **Most injuries** (T12–L1 commonest) |
| L3–sacrum | Mobile, lordotic | Axial load / burst |

**Bangle analogy (TO)** — ring broken once = stable · **twice = unstable** (Denis: 1 column stable, **≥ 2 columns unstable**)

**SCI epidemiology (TO)** — **80%** RTA + falls from height · young males 20–29 · **5× premature death**

**Neuro** — maximal canal occlusion at impact (recoil after) · **retropulsed fragments resorb**, rarely cause late deterioration · deficit type depends on level vs conus: cord / **conus** / cauda equina

### Associated injuries

| Injury | Fact |
|---|---|
| **Non-contiguous spine fractures** | **20%** → image whole spine |
| **Traumatic durotomy** | **Laminar fracture, split spinous process** (entrapped roots) |
| Thoracic fracture + deficit | 1/3 haemopneumothorax, great-vessel injury, diaphragm rupture |
| Flexion-distraction / dislocation | Bowel rupture, vessels, kidney, liver, spleen, pancreas |
| Long-bone fractures | Hamper rehab |

### Anatomy

**Denis columns** — anterior (ALL, anterior 2/3 body) · **middle (PLL, posterior 1/3 body)** · posterior (pedicles, laminae, facets, flavum, spinous process, PLC)

**Instability** — middle column injury (**widened interpedicular distance**, posterior body height loss) · PLC + anterior/middle column injury

**PLC** — supraspinous, interspinous, flavum, facet capsule · **clearly ruptured**: bony Chance, interspinous widening, progressive kyphosis, facet diastasis · indeterminate: MRI signal only

**Conus** — ends **L1-2**; **L1 fracture → conus medullaris syndrome** (bowel/bladder paralysis ± mixed UMN/LMN LE)

## 3 Presentation

**Vitals** — hypotension + **bradycardia = neurogenic** · + tachycardia = haemorrhage

**Exam** — log roll · palpable gap / **↑ interspinous distance** (posterior injury) · full neuro incl. reflexes · **absent BCR = spinal shock** (up to 72 h) · **hyperactive BCR** = disinhibition, complete cord injury

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| X-ray (whole spine; often trauma CT) | AP: **widened pedicles**, coronal deformity · lateral: retropulsion (underestimated), kyphosis · flexion-extension once stable: **spinous process diastasis = PLC injury** |
| **CT** | **Best for retropulsion (axial)**, comminution · more sensitive than X-ray |
| **MRI** | **PLC (STIR/T2 signal, sagittal)**, conus level, compression, cord oedema/haematoma · **investigation of choice (TO)** · nearly every case unless CT/X-ray already shows instability |
| CT myelogram | MRI contraindicated; durotomy |

**MRI prognosis** — **cord oedema > 2 levels** or **haematoma (low T2 with oedema halo)** → poor motor recovery

![Axial CT retropulsion](../../Orthobullets/attachments/ob2022-axial-ct-of-the-lumbar-spine-with-a-burst-fracture-and-retro.jpg)

**X-ray (TO)** — detects \~**80%** · height vs adjacent levels, **interpedicular widening = burst**, TP + spinous fractures, alignment lines · compression = **one endplate**, burst = **both endplates**

**Radiographic instability (TO)** — **kyphosis > 20°** · **> 50% anterior height loss** · multiple adjacent compression fractures · dislocation / malalignment · posterior ligament injury → CT + MRI

**Burst vs compression on CT (TO)** — compression: **posterior cortex intact** · burst: fracture through **anterior AND posterior cortex** → MRI for retropulsion / epidural haematoma · acute fracture shows trabecular condensation · torn ALL/PLL → blood spills epidural/prevertebral · posterior element fracture → **posterior epidural haematoma** pushing cord forward → urgent decompression · AS: **chalk-stick** 3-column fracture

### Denis burst types

| Type | Pattern |
|---|---|
| A | **Both endplates**, retropulsion |
| **B** | **Superior endplate** — commonest (axial + flexion) |
| C | Inferior endplate |
| D | Burst-rotation (mimics fracture-dislocation) |
| E | Burst-lateral flexion (↑ interpedicular distance vs lateral compression) |

### TLICS

| Category | Points |
|---|---|
| **Morphology** | Compression 1 · **burst 2** · rotation/translation 3 · **distraction 4** |
| **Neurology** | Intact 0 · **root 2** · **incomplete cord/conus 3** · **complete cord/conus 2** · **cauda equina 3** |
| **PLC** | Intact 0 · indeterminate 2 · **disrupted 3** (largest single contribution) |
| **Total** | **< 4 non-op · 4 either · > 4 surgery** |

**TO rules** — max 10 · score each level, highest decides · translation/rotation always with PLC (3 + 3 = 6) · posterior distraction always PLC (4 + 3 = 7) · **incomplete scores more than complete**

**Not in TLICS** — **% canal compromise**

| TLICS (TO wording) | Points |
|---|---|
| Compression / burst / **translation-rotation** / **distraction** | **1 / 2 / 3 / 4** |
| PLC intact / **suspected (MRI signal)** / injured | **0 / 2 / 3** |
| Intact / root or **complete cord** / **incomplete cord or cauda equina** | **0 / 2 / 3** |

**TLICS logic (TO)** — **distraction scores more than dislocation** · **incomplete > complete** (can recover, emergency) · only system with neurology · flexion-distraction + fracture-dislocation → **PLC = 3 without MRI** · e.g. F-D intact = 4+3+0 = **7** · dislocation + complete = 3+3+2 = **8** · **TLICS decides whether, AO type decides how**

![TLICS](../../Orthobullets/attachments/ob2022-tlics-score.jpg)

**Worked scores** — burst + intact PLC + intact neuro = **2 → non-op** · burst + indeterminate PLC + root = **6 → surgery** · burst + incomplete + PLC = **8 → surgery** · burst + translation + PLC + ASIA B = 9

## 5 Management

```
TL burst fracture
├─ Neuro intact + PLC intact (TLICS ≤ 3) → MOBILISE AS TOLERATED ± TLSO
│      (no bed rest or traction)
├─ PLC injury / progressive kyphosis / polytrauma, intact → POSTERIOR INSTRUMENTED STABILISATION
└─ Deficit with compression / TLICS ≥ 5 → DECOMPRESSION + STABILISATION
       ├─ Below conus, PLC injured, fracture-dislocation → POSTERIOR (transpedicular, posterior corpectomy, cage)
       └─ Anterior compression above conus (≤ L2), comminution, kyphosis > 30°, > 4–5 days → ANTERIOR / LATERAL CORPECTOMY ± posterior
```

### Non-operative

**Neuro intact + stable** — **equivalent outcomes** (pain, function, RTW, kyphosis, fragment resorption at 5 yrs; better PROs at 16–22 yrs) with **fewer complications** than surgery · surgery → **↑ complications and disability**

**TLSO** — **no clear advantage**; use for comfort · may begin **early ambulation without brace** if pain controlled · older teaching: TLSO/body cast 3–6 months

**Old thresholds** — kyphosis > 30°, height loss > 50% (controversial; no longer indications alone)

**Non-op regimen (TO)** — burst **< 50% height loss + < 20° kyphosis** (TLICS 0–3) · **no bed rest** · **Taylor brace (TLSO), not LS belt** (even at L1–L2) — brace when upright · settles **6–8 wks** · **standing X-rays every 2–3 wks** → operate if collapse/kyphosis progresses · TLSO 8–12 wks (TO, other lecture) · **LS belt below L3, Taylor above L3** + bed rest 1–2 wks (TO, older lecture) — read the options

### Operative criteria

| Indication | Detail |
|---|---|
| **PLC injury on MRI** | **Indication even in a compression fracture** (TO) (✗ Wrong options: radiculopathy · middle column · kyphosis 15°) |
| **Neuro deficit + compression** | > single root level (TO) · complete and incomplete |
| Progressive deficit / **CES** after bracing | **Anterior decompression + strut → posterior instrumentation** |
| Progressive kyphosis, polytrauma | Stabilise |
| **Laminar fracture + unilateral L5–S4 deficit** | **Laminectomy, free entrapped roots, repair dura**, posterior fusion |

**AO-based surgery (TO)** — unstable burst **A3/A4**, all distraction **B1–B3**, fracture-dislocation **C**

| Injury (TO) | Fixation | Fusion |
|---|---|---|
| **Burst (A2–A4), bony Chance (B1)** | **Short segment**: 1 above + 1 below **+ index screws** (intact pedicles on CT) | **No** (bone heals) |
| **B2, fracture-dislocation (C)** | **Long segment: 2 above + 2 below** | **Yes** |
| **AS hyperextension (B3)** | **3 above + 3 below** | Yes |

**Index screw (TO)** — short segment without fracture-level screw failed (**McLain 1993**, cantilever) · broken index pedicle → 2 above + 2 below · shorter, thinner screws in fractured body · index screw left proud → "lordosing" reduction of kyphosis

**TO burst L4 with deficit** — **posterior decompression + stabilisation**\
✗ Wrong options: laminectomy alone · bed rest · brace

**Near-complete canal compromise, incomplete deficit at L1** — **anterior decompression + stabilisation**

**L1 burst + incomplete cord + PLC (TLICS 8)** — **lateral L1 corpectomy + T12-L2 fusion** (cord at level → avoid posterior retraction)

### Technique

**Posterior** — pedicle screws · historically 3 above / 2 below; modern **1 above / 1 below (short segment)** — not at TL junction · "**fuse short, instrument long**" · percutaneous option · **two above + two below (T11–L3)** for L1 burst with deficit (OB) · no laminectomy alone (destabilises)

**Indirect decompression** — **distraction + lordosis → ligamentotaxis** (PLL + annulus pull fragments) · **less effective after 4–5 days** · **monoaxial screws** give more distraction · equal to anterior + 360° in studies · overdistraction → pseudarthrosis, pain, deformity

**Ligamentotaxis needs intact PLL (TO)** — CT: **cortical surface of retropulsed fragment faces the canal** → works · **rotated fragment (cortex not facing canal) = PLL torn** → direct transpedicular impaction · neuro intact burst: **no decompression even with 60% retropulsion** — canal **remodels within \~1 yr**

**Rod contour (TO)** — thoracic kyphosis · lumbar lordosis · **TL junction straight**

**Lamina fracture (TO)** — traps roots + **dural tear** → expose carefully

**Direct posterior** — transpedicular removal **below conus (L2)** · above conus → cord retraction risk

**Anterior** — corpectomy to contralateral pedicle wall · strut (tricortical iliac, allograft, expandable cage) · lumbar: retroperitoneal (below L1) · **T11–L1: left lateral lumbotomy** (avoid liver) · **above T11: right thoracotomy** (avoid great vessels) · diaphragm level

**Pedicle screw entry (TO)** — **intersection technique** commonest free-hand (lateral facet line × TP bisector) · mammillary point more lateral

**Unkeyed TO item** — 1 above + 1 below with index-level screw = short-segment construct (source gives no key)

## 6 Complications

| Complication | Fact |
|---|---|
| **Pain** | **Commonest** · overdistraction |
| Dural tear / entrapped roots | Laminar fractures · fewer with anterior approach |
| **Progressive kyphosis** | Missed PLC/PLL injury, comminution |
| Flat back | Pain, stooped posture; post-traumatic syrinx |
| SSI | **Up to 10%** |
| Pseudarthrosis | Overdistraction |
| Iatrogenic neuro injury | **1%** — medial screws, cord manipulation |
| Approach | Ileus (transperitoneal), pleural effusion (thoracotomy), loss of correction (posterior) |

### Chance fracture (TO)

**Mechanism** — **flexion-distraction** around an axis **anterior to the spine** (lap belt, "jack-knife") · **middle + posterior columns fail in distraction** · no body crush · bony Chance → hyperextension brace; ligamentous/unstable → surgery
