# Discogenic Back Pain

*Spine · 25 / 69*

## 1 Basics

**Definition** — **axial** low back pain from disc degeneration, **no radicular symptoms**

**Biology** — disc characteristics modified by **bone morphogenetic proteins**

## 3 Presentation

**Pain ↑ with** — **bending, sitting, axial loading** · flexion aggravates, extension relieves

**Exam** — **SLR / nerve tension negative**, neuro normal

**Acute lumbago (3 wks), no red flags** — **PT + NSAIDs**, no imaging · red flags: diabetes / IVDU (infection), cancer, smoking, **night pain**\
✗ Wrong options: X-ray · MRI · discography · steroid taper

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| **X-ray** | **Best initial study** — degeneration, **vacuum phenomenon**; excludes other causes |
| MRI | Degenerated discs **without** significant stenosis / herniation |
| **Provocative discography** | Primary confirmatory test but **accelerates degeneration**: ↑ herniation, ↓ disc height, **reactive endplate changes** (✗ Wrong options: myelogram · TFESI · spinal anaesthesia) |

### Diagnostic criteria – positive discogram

| Criterion |
|---|
| **Concordant pain** on injection |
| **Abnormal disc morphology** on fluoroscopy / post-discography CT |
| **Negative (painless) control level(s)** |

## 5 Management

**First line (majority)** — NSAIDs, PT, **cognitive therapy**, lifestyle change

**Fusion vs cognitive-exercise therapy** — **equivalent ODI improvement** at **1 + 10 yrs**\
✗ Wrong options: fusion superior · therapy superior

**Fusion** — controversial; **poor results when based on positive discography**

### Lumbar total disc replacement (TDR)

**Indication** — **single-level DDD with disease-free facets** (controversial)

| TDR vs fusion / ALIF | Finding |
|---|---|
| Safety + efficacy at 2 yrs | **Comparable / better** |
| Hospital stay | **Shorter** |
| Reoperation | **Lower** |
| Disc height restoration | **Greater** |
| Subsidence | **Less** |
| Adjacent segment disease | **Lower** |

**Contraindications** — pars defect, fracture, **facet arthrosis**, **spondylolisthesis**, posterior element insufficiency, prior laminectomy, scoliosis, instability

**Metal-on-metal TDR** — **↑ serum cobalt + chromium, like MoM THA**; persist; renally excreted\
✗ Wrong options: transient · only cobalt · hepatic neutralisation · negligible

```
Failed lumbar TDR
├─ Asymptomatic subsidence, no extrusion → OBSERVE
├─ Facet pain / micro-instability, implant well placed → POSTERIOR STABILISATION
└─ Poly dislocation / malposition → REVISION ARTHROPLASTY or ARTHRODESIS VIA RETROPERITONEAL APPROACH
       (not far-lateral — iliac crest blocks L5-S1)
```

## X vs Y

| | Discogenic pain | Radiculopathy |
|---|---|---|
| Pain | Axial | Leg > back |
| SLR | Negative | Positive |
| Worse with | Sitting, bending, loading | Sitting/cough (HNP) |

## How it's asked

**"3 weeks of lumbago, no red flags?"** → **PT + NSAIDs**

**"Best initial study for discogenic pain?"** → **radiography**

**"MoM vs poly TDR — labs?"** → **↑ cobalt + chromium like MoM THA**

**"TDR vs fusion for single-level DDD?"** → **comparable safety + efficacy at 2 yrs**

**"Anterior poly dislocation 6 wks after TDR?"** → **revision to arthrodesis via retroperitoneal approach**

**"Fusion vs cognitive/exercise therapy?"** → **equivalent improvement**

**"Procedure accelerating disc degeneration?"** → **provocative discography**
