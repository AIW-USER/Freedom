# Lower Extremity Spine Exam

*Spine · 34 / 69*

## 1 Basics

### Root map

**Overlap** — most muscles have > 1 root (e.g. **ankle dorsiflexion = L4 + L5**)

| Root | Motion | Muscle (nerve) | Sensory | Reflex |
|---|---|---|---|---|
| **L1** | — | — | Iliac crest, groin | **Cremasteric (L1-2)** |
| **L2** | Hip flexion + adduction | Iliopsoas (femoral/plexus), adductors (obturator) | Anterior + inner thigh | Cremasteric |
| **L3** | Knee extension (+ L4) | Quadriceps (femoral) | Anterior/medial thigh, medial knee | — |
| **L4** | **Ankle dorsiflexion** (+ L5) | **Tibialis anterior** (DPN) | Lateral thigh, anterior knee, **medial leg** | **Patellar** |
| **L5** | **Foot inversion**, **toe dorsiflexion**, hip extension, **hip abduction** | Tib posterior (tibial), **EHL/EDL** (DPN), hamstrings, glut max (inferior gluteal), **glut medius (superior gluteal)** | **Lateral leg + dorsum of foot** | — |
| **S1** | **Plantar flexion**, **eversion** | Gastrocsoleus (tibial), peroneals (SPN) | Posterior leg (lateral foot) | **Achilles** |
| S2 | Toe plantar flexion | FHL, FDL (tibial) | Plantar foot | — |
| S3–4 | Bowel + bladder | Bladder | Perianal | — |

## 3 Presentation

### Symptom clues

| Symptom | Think |
|---|---|
| Weight loss, axial pain, **night pain** | Tumour / infection |
| Mechanical pain | Instability, discogenic |
| Radicular pain | HNP |
| Referred pain | PUD, cholecystitis, renal stone, PID, pancreatitis |
| Psychogenic | Secondary gain |

**Inspection** — scars, café-au-lait, lumbar hairy patch

### Grading (ASIA)

| Motor | |
|---|---|
| 0 | Paralysis |
| 1 | Palpable / visible contraction |
| 2 | Full ROM, gravity eliminated |
| 3 | Full ROM against gravity |
| 4 | Against some resistance |
| 5 | Normal resistance |
| NT | Not testable |

**Sensory** — 0 absent · 1 impaired · 2 normal · NT

## 4 Diagnosis & Classification

### Special tests

| Test | Fact |
|---|---|
| **Straight leg raise** | Supine passive elevation **30–70°** (positive by \~40°) → pain **below the knee** = **L4–S1 (L5-S1)** root tension; separate from hamstring tightness |
| **Crossed SLR** | Raising the well leg reproduces pain in the affected leg (more specific) |
| **Femoral nerve stretch** | **Prone, knee flexed + hip extended** → anterior thigh pain = **L2-3, L3-4** protrusion |
| Babinski, ankle clonus | **UMN** lesion |
| **Bulbocavernosus reflex** | Squeeze glans/clitoris or **tug Foley** → anal contraction; tests for **spinal shock** |
| Lhermitte / Hoffmann / Spurling | Cervical tests (✗ Wrong options: lumbar) |

### Clinical findings → lesion

| Finding | Cause |
|---|---|
| Medial knee paraesthesia | **Saphenous** (femoral) irritation — psoas abscess, surfer's compression |
| **Trendelenburg gait** | **L5 root** → gluteus medius (superior gluteal) — **L5/S1 far-lateral HNP** (OB) / **paracentral L4/5 HNP** (Orthobullets) |
| Lateral thigh numbness | **Meralgia paraesthetica (LFCN)** — positioning |
| Foot drop | **Common peroneal palsy** / sciatic compression (lateral knee pressure, hip dislocation) |
| Quadriceps weakness | **Femoral nerve palsy** (hyperflexed Pavlik) / L3-L4 roots |

### HNP → root (Trendelenburg logic)

| Disc | Root | Weak |
|---|---|---|
| L3/4 far lateral | L3 | Hip flexion |
| L3/4 central / L4/5 far lateral | L4 | Knee extension, dorsiflexion |
| **L4/5 paracentral or L5/S1 far lateral** | **L5** | **Hip abduction (Trendelenburg)**, EHL |
| L5/S1 paracentral | S1 | Plantar flexion |

### UMN + LMN together (TO)

**Absent ankle jerks + upgoing plantars** — **B12 deficiency** (subacute combined degeneration), **motor neuron disease**, **Friedreich ataxia** (also conus lesions, cervical myelopathy + lumbar stenosis) \
✗ Wrong options: **multiple sclerosis** (UMN only, never LMN)

### Waddell signs (≥ 3 = significant)

| Sign | Description |
|---|---|
| Tenderness | Superficial (light touch) or deep non-anatomic |
| Simulation | Pain with light **axial skull compression** or **pelvic twist** |
| Distraction | **No pain with distracted SLR** |
| Regional | Non-anatomic motor / sensory findings |
| Overreaction | Any time |

## How it's asked

**"Passive leg elevation 30–70° → pain below knee?"** → **straight leg raise test**

**"Trendelenburg gait from lumbar disc?"** → **L5/S1 far-lateral herniation (L5 root)**

**"NOT a cause of absent ankle jerks + upgoing plantars?"** → **multiple sclerosis** (TO)

**"Bulbocavernosus reflex tests for?"** → **spinal shock**

**"Femoral stretch test positive in?"** → **L2-3 / L3-4 disc**
