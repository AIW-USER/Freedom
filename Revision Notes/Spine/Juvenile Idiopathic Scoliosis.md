# Juvenile Idiopathic Scoliosis

*Spine · 31 / 69*

## 1 Basics

### Epidemiology

**Definition** — idiopathic scoliosis presenting at **4–10 yrs** (3–10 in OB)

**Incidence** — **15%** of idiopathic scoliosis

**Sex / curve** — **females > males** · **right main thoracic** commonest

**Natural history** — **high risk of progression**: **70% need treatment** (half brace, half surgery); spontaneous resolution rare; can be fatal untreated

### Associated neural axis abnormalities

**Prevalence** — **18–25%** (\~20% with curves > 20°)

| Anomaly | Clue |
|---|---|
| **Syringomyelia** | Curve **without rotation**; **asymmetric / absent abdominal (umbilical) reflex** |
| **Arnold-Chiari** | Tonsillar herniation blocking CSF |
| **Tethered cord** | Often silent until adult |
| Dysraphism | Midline skin signs |
| Cord tumour | Astrocytoma, dermoid, epidermoid, teratoma |

**Not associated** — atlantoaxial rotatory instability (EXCEPT answer)

**EOS** — scoliosis < 10 yrs: infantile, juvenile, congenital, neurogenic, syndromic (Marfan, Down)

## 3 Presentation

**History** — when noticed, progression, perinatal history · **no bowel/bladder control by 3–4 yrs** → neuro cause

**Screening** — **7° on scoliometer** (Adams) ≈ 20° Cobb

**Exam** — café-au-lait, LLD (sitting forward bend eliminates), shoulder/waist asymmetry, **cavovarus**, hairy patch, dimples, nevi, rib hump · **abdominal reflexes** (stroke each quadrant → umbilicus moves toward it), clonus, Hoffmann, Babinski, gait

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — upright PA + lateral · **Cobb > 10°** = scoliosis (error 3–5°) · bending films → which curves to fuse

### Diagnostic criteria – MRI (whole spine)

| MRI indicated | Not an indication |
|---|---|
| **Age < 10–11 with curve > 20°** (even neuro-normal; e.g. 25° right thoracic in 7-yr) | Right thoracic curve per se (in older child) |
| **Left thoracic curve** | Thoracic hypokyphosis |
| **Asymmetric / absent abdominal reflexes** | Lenke C lumbar modifier |
| **Male** | No family history |
| **Absence of thoracic apical lordosis** (hypokyphosis lost) — strong predictor | Symmetric abdominal reflexes |
| Abnormal neuro (hyperreflexia, sensory loss) · **rapid progression** | — |
| Absent pedicle, congenital bar | — |

## 5 Management

```
Juvenile idiopathic scoliosis (MRI normal)
├─ < 20° → OBSERVE (frequent X-rays)
├─ 20–50° → BRACE 16–23 h/day (prevent progression)
│      (TO: 25–40° → casting)
└─ > 50°
       ├─ Young, much growth left → GROWING RODS / VEPTR (or A + P fusion)
       └─ Near maturity → POSTERIOR SPINAL FUSION
```

**Bracing** — relative CI = **thoracic hypokyphosis** · goal is prevention, not correction

**45° curve in 7-yr (TO)** — options: growing rods, **stapling**, **casting** · (✗ Wrong options: **posterior instrumented fusion** (crankshaft + ↓ thoracic growth)) · TO thresholds: **25–40° cast**, **> 40° growth-friendly surgery**

**Fusion** — **A + P in young** (prevent crankshaft) · **PSF near maturity** (gold standard thoracic + double major) · ASF for TL / lumbar with normal sagittal profile

### Growing rods

**Lengthening** — every **\~6 months** → **> 2 procedures**\
✗ Wrong options: VBT + PSF = 2 stages · single-stage PSF · A/P 1–2 stages · halo + PSF

**Law of diminishing returns** — each lengthening needs **↑ force** and gains **↓ length** (force doubles by 5th; < 8 mm per lengthening)

| Comparison | Finding |
|---|---|
| **Traditional rods vs VEPTR** | **TGR: ↑ curve correction + truncal height**, fewer complications (VEPTR subcutaneous → ↑ wound problems) |
| Magnetic (MCGR) vs traditional | MCGR → **fewer surgeries** |
| Final fusion after growth-friendly vs primary fusion | **↑ reoperation + complications** |
| Younger age / longer duration | **↑ infection + wound complications** |
| Pulmonary | Growing rods ↑ PFTs + diaphragm motion |

## 6 Complications

**Crankshaft** — posterior fusion alone in young child

## X vs Y

| | Juvenile | Infantile | Adolescent |
|---|---|---|---|
| Age | 4–10 | 0–3 | 10–18 |
| Sex | F > M | M > F | F |
| Curve | Right thoracic | Left thoracic | Right thoracic |
| Neural axis anomaly | **18–25%** | \~22% (> 20°) | Low |
| Natural history | **Progresses (70% treated)** | Mostly resolves | Variable |

## How it's asked

**"MRI rules out all EXCEPT?"** → **atlantoaxial rotatory instability**

**"Screening MRI indications EXCEPT?"** → **right thoracic curve**\
✗ Wrong options: male, age < 11, absent apical lordosis, neuro signs

**"8-yr, left curve, normal neuro — next?"** → **MRI cervical-thoracic-lumbar**

**"Progressive curve + absent abdominal reflex?"** → **spinal cord abnormality → whole-spine MRI**

**"7-yr, MRI recommended because?"** → **25° right thoracic curve**

**"7-yr, 45° JIS — EXCEPT?"** → **posterior instrumented fusion** (TO)

**"Growing rods with repeated lengthenings?"** → **force ↑, length gained ↓**

**"TGR vs VEPTR?"** → **TGR more correction + truncal height**

**"7-yr, 75° + 45° curves — option needing > 2 surgeries?"** → **traditional growing rods**
