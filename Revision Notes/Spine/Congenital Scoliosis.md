# Congenital Scoliosis

*Spine · 22 / 69*

## 1 Basics

### Epidemiology & aetiology

**Definition** — failure of normal vertebral development at **4–6 weeks of gestation** (mesenchymal anlage) — same window as **heart + kidneys**

**Prevalence** — **1–4%**

**Causes** — mostly **sporadic**; maternal **diabetes, alcohol, valproic acid, hyperthermia** · environmental / vascular disruption

### Genes & inheritance

**Familial inheritance** — **not** associated → "deformity NOT familial" = congenital scoliosis (e.g. child with myelomeningocele) · genetics uncertain\
✗ Wrong options: unlike AIS

**Jarcho-Levin (spondylocostal dysostosis)** — most commonly **autosomal recessive**

### Associated anomalies

| System | Rate |
|---|---|
| **Any systemic anomaly** | **Up to 60–61%** |
| **Cardiac** | **10%** (Orthobullets) · **25–26%** (OB) — **VSD** commonest, then ASD, PDA, ToF, TGA |
| **Genitourinary** | **25%** (Orthobullets) · 20% / up to one-third (OB) — unilateral absent kidney, horseshoe, obstructive uropathy, duplicate ureters, hypospadias |
| **Intraspinal (neural axis)** | **20–40%** (Orthobullets) · 37% (OB) · 18% pre-MRI era — diastematomyelia, **tethered cord**, syrinx, **Chiari**, intradural lipoma, dural bands; ↑ with segmentation + mixed defects |
| Orthopaedic | Clubfoot, DDH, limb hypoplasia, **Sprengel**, Klippel-Feil, vertical talus, cavus, **thumb hypoplasia / radial club hand** |

**TO rates** — **renal 20%** (USG ± Doppler) · **cardiac 25%** (2D echo) · **neurological 10–35%** (MRI) · **MRI + renal US + echo mandatory before intervention**

| Syndrome | Features |
|---|---|
| **VACTERL** (38–55%) | Vertebral, anal atresia, cardiac, TE fistula, renal, radial / limb |
| **Goldenhar** (oculo-auriculo-vertebral) | **Hemifacial microsomia + epibulbar dermoids** |
| **Jarcho-Levin** | **Short-trunk dwarfism, multiple vertebral + rib fusions** → **thoracic insufficiency syndrome** |
| **Klippel-Feil** | Short neck, low hairline, cervical fusion |
| **Alagille** | Peripheral pulmonic stenosis, cholestasis, facial dysmorphism |

**Not associated** — Sever's disease (calcaneal apophysitis)

## 4 Diagnosis & Classification

### Classification

| Category | Type | Note |
|---|---|---|
| **Failure of formation** | **Fully segmented hemivertebra** | Disc + growth plate above and below → progresses; **commonest anomaly (38%)** (TO) |
| | Semisegmented | Fused one side |
| | Unsegmented | Fused both sides |
| | **Incarcerated** | Within margins of adjacent vertebrae → little progression |
| | Unincarcerated | Laterally placed |
| | Wedge / butterfly | — |
| **Failure of segmentation** | **Block vertebra** | **Least progression (< 2°/yr)** |
| | **Unilateral unsegmented bar** | Common, likely to progress |
| **Mixed** | **Unilateral bar + contralateral hemivertebra** | **Most rapid progression** |

### Progression risk

| Anomaly (fastest → slowest) | Rate |
|---|---|
| **1 Unilateral bar + contralateral (convex) hemivertebra** | **5–10°/yr** (Orthobullets) · **6–7°/yr**, most > 50° by age 2 (TO) |
| 2 Unilateral unsegmented bar | \~5°/yr; > 50° by 10, > 70° at maturity |
| (Double convex hemivertebra) | 3–4°/yr (TO) |
| 3 Fully segmented hemivertebra | 1–2°/yr |
| 4 Unincarcerated hemivertebra | — |
| 5 Incarcerated hemivertebra | — |
| 6 Unsegmented hemivertebra | — |
| 7 Block vertebra | **< 2°/yr** |

**Commonest congenital defect** — **hemivertebra** (TO)

**Progression order (TO)** — unilateral bar + hemivertebra > unilateral bar (**> 5–10°/yr**) > fully segmented hemi > unincarcerated > incarcerated > unsegmented hemi > block vertebra (< 2°/yr)

**Hemivertebra growth potential (TO)** — **fully segmented (disc above + below) highest** · semi-segmented moderate · incarcerated / non-segmented minimal

**Timing** — fastest in **first 3 years** · **fused ribs** ↑ progression

**Anterior failure of formation (kyphosis)** — **progressive sagittal deformity + paralysis** · anterior failure of segmentation → progressive but **rarely paralysis**

### Key radiology findings & work-up

| Study | Purpose |
|---|---|
| AP + lateral X-ray | Usually diagnostic |
| **3D CT** | Posterior anatomy, surgical planning (judicious radiation) |
| **MRI whole spine** | **All before surgery**; immediately if **hairy patch / neuro signs** (sedation in infants → may defer if no surgery planned) |
| **Renal US (or MRI)** | **All patients** — "renal US indicated in?" → **congenital scoliosis** |
| **Echocardiogram** | Cardiac evaluation |

**New congenital scoliosis in infant** — **echo + renal US (+ spinal MRI)** first (✗ Wrong options: HLA-B27 · bone scan · skeletal survey · EMG · brace · surgery yet) · MRI already normal → **renal US** next (✗ Wrong options: blood cultures · flex-ext C-spine · platelets)

## 5 Management

**Observation** — non-progressive: incarcerated, non-segmented, some partially segmented hemivertebrae; serial X-rays every 4–6 months; **document progression before surgery**

**Bracing** — **NOT effective** for congenital curves; may control supple compensatory curves · derotational casting may delay growing constructs\
✗ Wrong options: primary treatment

```
Congenital scoliosis
├─ Unilateral bar + contralateral hemivertebra → SURGERY AT ANY AGE
│      (hemivertebra excision + short-segment posterior fusion)
├─ Progressive fully segmented hemivertebra, young → HEMIVERTEBRECTOMY + SHORT FUSION
├─ Unilateral bar, minimal deformity → IN-SITU FUSION
└─ Multiple fused ribs (> 4) / thoracic insufficiency → VEPTR / rib osteotomies / growing rods
```

### Operative criteria & procedures

| Procedure | Indication |
|---|---|
| **Hemivertebra excision + short posterior fusion** | Progressive hemivertebra (esp. **lumbosacral** → oblique takeoff, truncal imbalance); best **< 5–6 yrs, flexible < 40°** (Orthobullets) · ages 3–8 (posterior; younger = poor anchors) · indication = **documented progression** (✗ Wrong options: failed bracing · Cobb > 45° · Risser 4 · maturity) |
| **In-situ arthrodesis (A/P or posterior)** | Unilateral bars with minimal deformity |
| **Posterior fusion ± osteotomy** | Hemivertebra opposite bar not needing vertebrectomy; older patients with progression/deficit/respiratory decline; many pedicle screws ↓ crankshaft |
| **A/P fusion ± vertebrectomy** | Young (**girls < 10, boys < 12**) with progression, deficit, respiratory decline |
| **Convex hemiepiphysiodesis** | Concave growth intact, **< 5 yrs, < 40–50°**; mixed results |
| **Distraction growing rods** | Control deformity during growth, delay fusion; lengthen \~6-monthly |
| **VEPTR / rib osteotomies** | **> 4 fused ribs**, **thoracic insufficiency syndrome** (may stiffen chest) |
| Spinal column shortening resection | Late, severe, rigid deformity; fixed pelvic obliquity |

| Thoracic insufficiency (Campbell) (TO) | Pattern |
|---|---|
| **1** | **Absent ribs** + scoliosis |
| **2** | **Fused ribs** + scoliosis |
| **3A** | **Shortened thorax** (Jarcho-Levin) |
| **3B** | **Transversely narrowed thorax** (Jeune) |

**VEPTR (TO)** — rib–rib, rib–spine, rib–pelvis · lengthen 6-monthly · **high complication rate → not routine** · types 3A/3B worst outcome

**Timing (TO)** — **hemivertebrectomy 3–8 yrs** for progressive deformity with kyphosis · A + P fusion / vertebrectomy in **girls < 10, boys < 12** with progression or deficit · single fully segmented hemi → excision + short fusion · multi-segment → excision + growth rod

**22-month / 14-month with bar + contralateral hemivertebra (\~40°), normal MRI** — **hemivertebrectomy + short-segment posterior instrumented fusion**\
✗ Wrong options: observe · brace · Risser cast · VEPTR · growing rods

**7-yr, hemivertebra curve ↑ 10°** — **hemivertebra excision + limited fusion**

**18-month, lumbar hemivertebra** — echo + renal US first; no long TL fusion (crankshaft, limits growth)

### Congenital kyphosis

**Level (TO)** — **T7–T9** (gibbus) · associations: MPS, SED congenita, Morquio, pseudoachondroplasia

| Type | Prognosis |
|---|---|
| **I – failure of formation (anterior)** | **Worst**; relentless progression → **paraplegia** |
| II – failure of segmentation | Rounded, slower, paraplegia uncommon |

**Treatment (TO)** — **no bracing** · **< 5 yrs + < 50–55° → posterior in-situ fusion** (anterior growth continues → some correction) · **> 5 yrs, > 55°, or neuro deficit → anterior release/decompression + strut + posterior instrumented fusion** (neuromonitoring)

**Supports early in-situ posterior fusion (8-month)** — 50° curve, failure of formation, bar, neuro weakness \
✗ Wrong options: **block vertebra** (EXCEPT — least progression)

## 6 Complications

| Complication | Note |
|---|---|
| **Crankshaft** | Posterior fusion alone in young |
| **Short stature** | Fusion limits trunk growth (younger worse) |
| **Neurologic injury** | Overdistraction / shortening, overcorrection, segmental vessel ligation → SSEP + MEP |
| Soft tissue | Optimise nutrition pre-op |

## X vs Y

| | Congenital | Idiopathic (AIS) |
|---|---|---|
| Cause | Vertebral anomaly (4–6 wks) | Unknown, familial |
| Inheritance | No | Yes |
| Brace | Ineffective | Effective 25–45° |
| Work-up | Echo + renal US + MRI | MRI only if atypical |

| | Anterior failure of formation | Anterior failure of segmentation |
|---|---|---|
| Deformity | Sharp kyphosis | Rounded kyphosis |
| Paralysis | **Often** | Rare |
