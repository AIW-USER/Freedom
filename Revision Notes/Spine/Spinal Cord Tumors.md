# Spinal Cord Tumors

*Spine · 56 / 69*

## 1 Basics

### Epidemiology

**Primary CNS tumours** — mostly intracranial · only **2–4% spinal** (850–1,700/yr US)

**Compartments** — **intradural extramedullary** (60–70%) · **intradural intramedullary** (20–30% adults, **50% children**) · extradural

![Spinal tumour compartments](../../Orthobullets/attachments/ob2072-spinal-tumor.jpg)

## 3 Presentation

| Compartment | Symptoms |
|---|---|
| Intradural extramedullary | Cord compression, **radicular pain**, deep **back pain worst at night**, cauda equina-like |
| Intramedullary | Local/radicular pain, motor (65%), sensory (60%), **sphincter dysfunction (38%) — often first symptom** |

## 4 Diagnosis & Classification

### Intradural extramedullary

| | Schwannoma | Meningioma |
|---|---|---|
| Frequency | **Commonest intradural tumour** (with meningioma) | **25%** of primary spinal tumours |
| Demographics | **40s–50s, M = F** | **Women 80%**, 5th–6th decades |
| Site | **Dorsal nerve root** · cervical 31%, cauda equina 24%, thoracic 22% | **Thoracic** |
| Risk | **NF2** | **NF2**, prior radiation |
| MRI | T1 iso, **T2 hyperintense** | **Dura-based**, T1 iso/hypo, T2 slightly hyper, homogeneous enhancement |
| Histology | **Antoni A (hypercellular) + B (hypocellular)**, **S-100+** | Lobulated, **meningothelial whorls** |
| Treatment | Resection ± RT if malignant | Resection (curative if complete); RT for recurrence |

![Schwannoma from dorsal root](../../Orthobullets/attachments/ob2072-schwannoma.jpg)

### Intramedullary

| | Ependymoma | Astrocytoma |
|---|---|---|
| Frequency | **Commonest intramedullary (adults)** (Orthobullets) | **Commonest in children (80–90%)** · **commonest overall** (TO) |
| Age | Adults | Peak **3rd decade** |
| Site | **Cervical** commonest spinal site (TO) · myxopapillary in **filum terminale** | **Cervicothoracic** junction (children) |
| Types | Myxopapillary 40–50%, cellular 42% (benign) · anaplastic | 30% benign |
| MRI | T2 hyper, heterogeneous · myxopapillary: **scalloping, foraminal enlargement, scoliosis, sacral seeding** · cellular: **polar cysts**, haemorrhage | **Fusiform, irregular margins**, infiltrative |
| Histology | **Rosettes + pseudorosettes** | Hypercellular, mitoses, **eosinophilic granules** |
| Treatment | **Gross total resection** — good prognosis (clean plane) | GTR difficult → **RT** ± chemo |

**TO** — paediatric ependymoma intracranial (**4th ventricle**); adult spinal

![Ependymoma polar cyst](../../Orthobullets/attachments/ob2072-polar-cyst.jpg)

### Extradural & metastatic

**Metastasis** — extramedullary = advancing disease · **drop metastases** via CSF · intramedullary rare (< 1%) from **lung > breast**, cervical + conus · **intramedullary mets → life expectancy < 3 months** · RT/chemo

**GBM drop metastasis (TO)** — **intradural extramedullary** · 1–2% of GBM · CSF spread (debulking ↑ seeding) · lag \~8.5 months · steroids for rapid cord compression

**Lymphoma** — image whole neuraxis · T2 ill-defined hyperintense, marked homogeneous enhancement, little cord enlargement · **cervical** · **methotrexate**

## 5 Management

### Metastatic cord compression

**Frameworks** — **SINS** (instability) + **NOMS** (neurologic, oncologic/radiosensitivity, mechanical, systemic) · **Tokuhashi 9–11 → 6–12 months**

**Renal cell metastasis with anterior compression, myelopathy** — **pre-op embolisation → corpectomy + instrumented fusion → post-op RT**\
✗ Wrong options: posterior decompression alone · surgery without embolisation · pre-op RT

**Unkeyed TO item** — structure spared and cut last during intramedullary tumour removal (denticulate ligament / midline myelotomy / functional root / DRG) — answer not provided by source

### Brain tumour facts (TO)

| Fact | Answer |
|---|---|
| Commonest brain tumour | **Metastases** (> 50%) |
| Commonest primary (adult CNS) | **GBM** |
| Commonest primary non-glial | **Meningioma** |
| Commonest paediatric CNS tumour | **Astrocytoma** (\~50%), then medulloblastoma |
| Commonest paediatric brain malignancy / vermian tumour | **Medulloblastoma** |
| **Brainstem glioma** presentation | **Cranial neuropathies first** (then weakness/ataxia; headache, vomiting late) · 77% < 20 yrs |
| **Petroclival meningioma** | Feeders from **ICA dural branches (meningohypophyseal trunk)** · PVA particles not more complications · liquid agents (NBCA, Onyx) infrequent |
| **Arachnoid cyst** | Commonest **Sylvian fissure** (middle fossa) · M:F 4:1, left · EMA+, CEA− · middle fossa cysts bleed (bridging veins) · suprasellar → hydrocephalus, precocious puberty, **bobble-head doll** · incidental adult → 1 repeat scan at 6–8 months |

## How it's asked

**"Renal cell met with cord compression, 6–12 months expected?"** → **embolisation, corpectomy + fusion, post-op RT**

**"Commonest site for spinal ependymoma?"** → **cervical** (TO)

**"Commonest intramedullary tumour?"** → **astrocytoma** (TO — overall; ependymoma in adults)

**"GBM drop metastases?"** → **intradural extramedullary** (TO)

**"Petroclival meningioma — true?"** → **feeders from internal carotid artery** (TO)

**"Brainstem glioma first presents with?"** → **cranial neuropathies** (TO)

**"Commonest arachnoid cyst location?"** → **Sylvian fissure** (TO)
