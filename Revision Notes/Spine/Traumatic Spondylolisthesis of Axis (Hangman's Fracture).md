# Traumatic Spondylolisthesis of Axis (Hangman's Fracture)

*Spine · 68 / 69*

## 1 Basics

**Definition** — **bilateral C2 pars (or pedicle) fractures** → traumatic spondylolisthesis of C2 on C3

**Mechanism** — **primary hyperextension** (pars fracture) + **secondary flexion** (tears PLL + disc → anterolisthesis) · MVA/falls: hyperextension-compression · judicial hanging: hyperextension-**distraction** (cord transection)\
✗ Wrong options: primary hyperflexion (TO)

**Associations** — **30% other C-spine fracture** · vertebral artery injury (MRA if suspected)

## 3 Presentation

**Neck pain** — usually **neurologically intact** (fragments separate → canal widens) · deficit mainly **type III**

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| **CT** | **Study of choice** for pattern |
| Flexion-extension X-ray | Subluxation |
| MRA | Vertebral artery injury |

### Levine-Edwards

| Type | Mechanism | Features | Treatment |
|---|---|---|---|
| **I** | Axial compression + hyperextension | **< 3 mm** displacement, no angulation, **C2-3 disc intact**, stable | **Rigid collar 4–6 wks** |
| **II** | Hyperextension + axial load → rebound flexion | **> 3 mm**, significant angulation, **vertical** fracture line, disc + PLL torn | **< 5 mm: traction + extension → halo 6–12 wks** · **> 5 mm: surgery** or prolonged traction · usually auto-fuse C2 on C3 |
| **IIA** | **Flexion-distraction** | **No displacement**, significant **angulation**, **horizontal/oblique** line | **No traction** (worsens) → **gentle axial compression + hyperextension → compression halo** 6–12 wks |
| **III** | Flexion-distraction → hyperextension | Type I + **bilateral C2-3 facet dislocation** | **Open reduction + fusion (posterior)** |

![Levine-Edwards types](../../Orthobullets/attachments/ob2017-screen-shot-2017-06-23-at-1-17-34-pm.jpg)

**Halo duration** — 6–12 wks (Orthobullets) · 8–12 wks · "2 months" (TO)

## 5 Management

```
Hangman's fracture
├─ Type I → RIGID COLLAR 4–6 wks
├─ Type II
│      ├─ 3–5 mm → TRACTION + EXTENSION → HALO
│      └─ > 5 mm, severe angulation → SURGERY
├─ Type IIA → NO TRACTION · hyperextension + compression → HALO
└─ Type III → OPEN REDUCTION of facets + C2-3 FUSION
```

**Surgical options** — **anterior C2-3 interbody fusion** (disc injury) · **posterior C1-3 fusion** · **bilateral C2 pars screw osteosynthesis** · anterior facet fixation for failed posterior fusion

## X vs Y

| | Type II | Type IIA |
|---|---|---|
| Displacement | > 3 mm | **None** |
| Angulation | Significant | **Severe** |
| Fracture line | Vertical | Horizontal |
| Reduction | **Traction** + extension | **No traction** — compression + extension |

## How it's asked

**"Polytrauma, undisplaced C2 pars fractures, intact disc?"** → **type I — rigid collar**

**"Hangman's — EXCEPT?"** → **"primary hyperflexion mechanism"** (TO)

**"CT shows bilateral C2 pars fracture — called?"** → **Hangman's fracture** (TO, unkeyed — options Jefferson, Hangman's, odontoid II, flexion teardrop)
