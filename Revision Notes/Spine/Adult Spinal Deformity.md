# Adult Spinal Deformity

*Spine · 4 / 69*

## 1 Basics

### Epidemiology & types

**Demographics** — mean age **60**; M = F

**Coronal imbalance** — lateral deviation of vertical line **> 10°**

**Sagittal imbalance** — radiographic **> 5 cm** (C7 plumb vs posterosuperior S1)

**Degenerative pathoanatomy** — **asymmetric degeneration** of discs ± facets

**Loss of sagittal balance** — osteoporosis · pre-existing scoliosis · iatrogenic instability · DDD

| | Idiopathic (residual) | Degenerative (de novo) |
|---|---|---|
| Origin | Untreated AIS | Degeneration, iatrogenic, paralysis |
| Curve pattern | **Classic** patterns | Lacks classic pattern |
| Segments | **More** | Fewer |
| Location | **Thoracic** | **Lumbar** |
| Magnitude | Larger | Smaller |

### Natural history & progression

**Progression by curve** — thoracic > lumbar > thoracolumbar > double major · right thoracic **1°/yr** · right lumbar **0.5°/yr** · TL **0.25°/yr**

**By magnitude** — **< 30° rarely progress** · **> 50° commonly progress**

**Other risks** — **intercrestal line below L4-5** · pre-existing rotation

**Symptoms progress to** — side of curve **convexity**

## 3 Presentation

**Low back pain** — **commonest (40–90%)**; spondylosis, instability, discogenic; more severe/recurrent than general population

**Neurogenic claudication** — stenosis on **concave side**; no relief with sitting / flexion (unlike classic claudication)

**Radicular pain** — foraminal + lateral recess stenosis, worse in **concavity** (rotation + translation)

**Exam** — thoracic prominence on forward bend, compensatory posture, weakness

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Use |
|---|---|
| **36-inch standing AP + lateral + R/L bending** | Cobb, coronal (C7PL vs CSVL) + sagittal balance, flexibility |
| **CT** | Bony deformity, facet arthrosis |
| **CT myelogram** | **Best for stenosis + bony anatomy** when rotation makes MRI hard |
| **MRI** | When leg pain present: stenosis, facet hypertrophy, foraminal encroachment |
| **DEXA** | Bone density for planning |

### Sagittal balance – SVA, PI-LL mismatch, pelvic parameters

**Sagittal vertical axis (SVA)** — horizontal distance **C7 plumb line → posterosuperior corner of S1**; neutral = through it · positive = anterior · negative = posterior

**Strongest predictor of symptoms / HRQOL / PROMs / poor surgical result** — **sagittal balance (C7 SVA)**\
✗ Wrong options: coronal imbalance · Cobb · levels · apex level · residual scoliosis > 25° · L5-S1 disc left out · truncal shift · PI

**Radiographic parameter correlating with pain + disability (VAS, ODI)** — **thoracolumbar kyphosis** (✗ Wrong options: SS · TK · PT · PI) · TL/lumbar curves also correlate (✗ Wrong options: thoracic scoliosis · thoracic hypokyphosis · lumbar hyperlordosis · disc degeneration)

**Pelvic incidence** — **only permanent anatomic parameter**; **PI = PT + SS**; not posture dependent (TO); stabilises after adolescence; determines lordosis needed

**Compensation for positive SVA** — **pelvic retroversion (↑ PT, ↓ SS)** · thoracic hypokyphosis · cervical hyperlordosis · knee flexion → SVA may look normal (< 5 cm) → look for regional imbalance

**T1 pelvic angle (T1PA)** — angle T1 centre → femoral head → S1 endplate centre = **T1 spinal inclination + PT**; accounts for **spinal inclination + pelvic retroversion**; no calibration needed; usable intra-op · goal **< 14°** · **> 20° ≈ ODI 40** (severe) · ↑ T1PA = ↑ ODI

### Diagnostic criteria – surgical alignment targets

| Target | Value |
|---|---|
| **SVA** | **< 5 cm** (best reliable improvement correcting to **+3 cm**) |
| **PI − LL** | **LL = PI ± 9°** (PI − LL < 10°) (✗ Wrong options: within 15° · LL = PI + 25° · LL = TK + 15°) |
| **Pelvic tilt** | **< 20°** (OB) · < 25° (alternate goal) |
| **T1PA** | **< 14°** |
| **TK + LL + PI** | **≤ 45°** — most predictive of maintaining correction |
| **GAP score** | **< 3** → fewer mechanical failures / revisions |

**Normal lumbar lordosis** — 40–60° (\~70% from L4-S1; apex L3-4 / L4)

## 5 Management

**Non-op** — coronal curves **< 30°** rarely progress · NSAIDs · **TCAs for sleep** · PT core strengthening · injections / root blocks (diagnostic + therapeutic) · bracing (comfort)

### Operative criteria

| Indication for instrumented fusion |
|---|
| Curve **> 50°** |
| **Sagittal imbalance** |
| Curve progression |
| Intractable back / radicular pain failing non-op |
| Cardiopulmonary decline: thoracic **> 60° → PFTs ↓**; **> 90° → mortality ↑** |
| Cosmesis (controversial) |

```
ASD surgical approach
├─ Thoracic / double structural > 50° → POSTERIOR-ONLY FUSION
└─ Isolated TL / lumbar, > 70°, rigid, L5-S1 interbody → ANTERIOR RELEASE + POSTERIOR
```

**Goals** — restore **spinal balance** · relieve pain · solid fusion

**Worse outcomes** — **baseline depression** · **obesity** · ≥ 4 comorbidities · insufficient sagittal correction · pseudarthrosis\
✗ Wrong options: ethnicity · pre-op ODI · pre-op SVA if corrected

### Fusion level selection

**Proximal** — extend to a **neutral + horizontal vertebra above main curve**

| Distal level | Indication / outcome |
|---|---|
| **L5** | Only if **no L5-S1 pathology**; lowest future L5-S1 degeneration with **normal C7 plumb + normal sacral inclination** |
| **S1** | **Any L5-S1 pathology**: spondylolisthesis, spondylolysis, facet arthrosis, prior laminectomy · ✓ **better correction + maintenance of sagittal balance** · (✗ Wrong options: ↑ pseudarthrosis, OR time, reoperation, **sacral insufficiency fracture**, altered gait)|
| **Ilium (sacropelvic)** | Sacrum in fusion of **> 3 levels**; iliac screws/bolts → **↑ fusion success** at L5-S1 + **↓ sacral fractures** in osteopenic; prominent hardware |

**Maximise fusion rate** — **ilium + sacrum** both in distal fixation\
✗ Wrong options: ilium alone · sacrum alone · coronal balance

**Pubic ramus fractures** — occur with sacral **and** iliac fixation

### Osteotomies – correction per level

| Osteotomy | Correction | Indication / prerequisite |
|---|---|---|
| **Smith-Petersen (SPO) / Ponte** | **\~10° per level** (Orthobullets) · posterior column osteotomy **3–5°** (OB) | Mild–moderate imbalance; needs **mobile disc + disc height**, **no anterior fusion**; more in lumbar |
| **Pedicle subtraction (PSO)** | **30–35° lumbar**, 25° thoracic (Orthobullets) · **25–35°** (OB) | **SVA > 12 cm** (Orthobullets) · **> 10 cm** (TO); **anterior fusion present** (correction through body) |
| **Vertebral column resection (VCR)** | **Up to / > 45°** (avg 62° coronal, 45° sagittal) | **Rigid sharp angular** kyphosis (tumour, fracture, infection), rigid scoliosis, congenital kyphosis, hemivertebra |
| TLIF | \~8° | — |
| TLIF + ALL release + hyperlordotic cage | 10–15° (22° with PCOs) | — |

![Osteotomy types for sagittal correction](../../Orthobullets/attachments/ob2041-osteotomies.jpg)

**3 SPO ≈ 1 PSO** — PSO more blood loss · neuromonitoring preferred

**PSO level** — **L3 / L4** (apex of lordosis L3-4; 70% of LL from L4-S1)\
✗ Wrong options: L1 → non-anatomic · SPOs above apex · thoracic SPOs ↓ TK

**Flat back after prior lateral interbody / L3-S1 fusion** — **L3 PSO + extension to pelvis**\
✗ Wrong options: SPOs through fused discs · T12 PSO · VCR

### Bone health optimisation

**Osteoporosis (T < −2.5) or ≥ 2 vertebral compression fractures (= osteoporosis without DEXA)** — **teriparatide** before surgery (≥ **6 months** → ↓ pseudarthrosis + reoperation)\
✗ Wrong options: continue/start alendronate (impairs fusion) · vit D/Ca alone · denosumab switch · repeat DEXA

**Osteopenia (T −1.7)** — no anabolic referral needed

**Cement (PMMA) augmentation of end vertebrae** — ↑ **fusion rate** + ↓ **junctional failure** + ↑ pullout strength, no extra complications · osteoporotic spine: **≥ 3 fixation points above + below**\
✗ Wrong options: fewer levels fused

**Active smoker** — **smoking cessation clinic + nicotine testing**, postpone elective fusion\
✗ Wrong options: schedule now

**Smoking** — ↑ pseudarthrosis, infection, implant loosening, fracture risk; **cessation programmes improve outcomes** (EXCEPT answer: "cessation doesn't help" is FALSE)

### Perioperative considerations

**Neuromonitoring (SSEP ↓ 60% at correction)** — **stop instrumenting + raise MAP ≥ 85 mmHg**, recheck, then reverse correction\
✗ Wrong options: wake-up test first · MAP 60 · steroids first · inhalational only (reduce inhalational agents)

**Neuro deficit on monitoring after correction** — remove instrumentation, consider wake-up test

**Jehovah's Witness** — **closed-circuit cell saver**\
✗ Wrong options: whole blood, PRBC, plasma, platelets

**Open thoracotomy for anterior release (adult)** — **pulmonary function ↓ and often stays ↓ long term**

**Pedicle anatomy** — cortical:cancellous ratio **thoracic pedicles > lumbar pedicles > vertebral bodies > sacrum** (implant failure likeliest in sacrum) · lumbosacral pedicle **diameter + medial angulation ↑ caudally** (L3 more medial than L1; S1 > L1) · **L5 root on sacral ala** (at risk with S-I screws) · S1 screw start **inferior + lateral** to L5 inferior articular process tip

**Posterior instrumentation system (TO)** — **Cotrel-Dubousset** (rods + hooks/screws, posterior)\
✗ Wrong options: Dwyer · Zielke (anterior) · Boston brace

## 6 Complications

| Complication | Rate / fact |
|---|---|
| **Overall** | **\~13.5%**; ↑ with osteotomies, revisions, A/P |
| **Major** | **\~10% (10–20%)**; irreversible; **VTE** → worst outcomes |
| **Strongest predictor of major complication** | **Age > 60** (✗ Wrong options: smoking · BMI > 30 · PSO · comorbidities) |
| **Pseudarthrosis** | **5–25%**; posterior-only 15%; **L5-S1 + TL junction**; **commonest reason for revision within 3 yrs** |
| **Implant failure / rod fracture** | **Commonest cause of reoperation**; rod breakage L4-S1 from **large PI-LL mismatch** (✗ Wrong options: titanium rods · coronal balance) |
| **Proximal junctional failure** | 2nd commonest revision; within 6–9 months |
| Dural tear | 2.9% |
| Infection | Deep 1.5%, superficial 0.9%; **smoking** strongest SSI factor (✗ Wrong options: drains · drain output · prolonged abx) |
| Neuro deficit | Acute \~1%, delayed 0.5% · **after PSO 18%** (Orthobullets) · 11%, 2.8% permanent (OB) · \~20% |
| PSO pseudarthrosis | **29% at 5 yrs**, at TL junction above osteotomy |
| Epidural haematoma / PE / DVT | \~0.2% each · death 0.3% |

**Pseudarthrosis risks** — **age > 55** · kyphosis > 20° · **positive SVA > 5 cm** · hip OA · smoking · **thoracoabdominal approach** · incomplete lumbopelvic fixation · osteoporosis · TL Cobb > 20°\
✗ Wrong options: posterior midline · Cobb 60°

**Post-PSO quadriceps weakness** — screw malposition (30% of deficits → CT), large PI-LL correction, prone positioning (femoral nerve), stroke · **least likely = apical derotation** (coronal manoeuvre)

**Post-op neuro decline + fluid collection at 3 months** — **I&D, retain hardware**\
✗ Wrong options: observation · antibiotics only · remove hardware

|---|---|---|---|
| Columns | Posterior | 3-column wedge (hinge anterior) | All 3 removed |
| Correction | \~10°/level | 25–35° | > 45° |
| Needs mobile disc | **Yes** | No | No |
| Prior anterior fusion | No | Yes | Yes |
| Commonest complication | — | **Pseudarthrosis** | High blood loss, instability |

| | Fusion to L5 | Fusion to S1 + ilium |
|---|---|---|
| L5-S1 healthy | ✓ | — |
