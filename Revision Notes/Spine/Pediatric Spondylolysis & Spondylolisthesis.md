# Pediatric Spondylolysis & Spondylolisthesis

*Spine · 47 / 69*

## 1 Basics

### Epidemiology

**Prevalence** — **4–6%** of population (defects **not present at birth**) · **6–7% of adolescent athletes** · up to **47% of adolescent LBP** · up to **47% in gymnasts, weightlifters, football linemen, divers**

**Ethnicity** — ↑ **Native Americans** · possible **autosomal dominant** inheritance

**Level** — **L5 pars (85–95%)**, L5 on S1 · then L4, L3 (TO)

**Laterality (TO)** — **80% bilateral**, 20% unilateral · unilateral defect stresses the contralateral pars

**Risk factors** — **repetitive hyperextension** (+ rotation) · ↑ **pelvic incidence**, sacral slope, sacral table index · ↓ sacral table angle

### Continuum

| Stage | Definition |
|---|---|
| **Pars stress reaction** | Sclerosis, no complete break |
| **Spondylolysis** | Complete pars fracture |
| **Isthmic spondylolisthesis** | Forward slip through the pars defect |
| **Spondyloptosis** | **100%** translation |

**Morita stages (TO)** — early (hairline) → progressive (wider, fragments) → **terminal (sclerotic, pseudarthrosis)** · healing predictors: **unilateral**, earlier stage, **level other than L5**

### Progression

**Lysis → listhesis** — **\~15%** (all bilateral defects) · most pars defects **never need surgery**

| Progression risk ↑ |
|---|
| **Higher grade at presentation (> Meyerding 2, > 50%)** |
| **Dysplastic (Wiltse I)** slips |
| **Slip angle > 45–50°** — best predictor of progression (OB), instability, pseudarthrosis, pain |
| Young age at presentation |

**Severity of current slip** — correlates most with **pelvic incidence** (PI = PT + SS; constant, \~57° adult; high PI → ↑ lumbosacral shear)\
✗ Wrong options: SS · PT · slip grade

## 3 Presentation

**Classic** — active adolescent, **activity-related LBP**, relieved by rest · many asymptomatic · **grade ≠ symptoms**

**Leg** — **hamstring tightness (commonest)**, buttock pain, L5 radicular pain

**Commonest exam finding** — **pain with lumbar extension**, especially **single-leg-stance extension**\
✗ Wrong options: pain on flexion · SLR · lost Achilles reflex

**High-grade / dysplastic** — **heart-shaped buttocks**, flat lumbar lordosis, palpable **step-off**, ↑ **popliteal angle**

**Gait (Phalen-Dickson)** — **short stride, hips + knees flexed (crouched)**

**Listhetic crisis** — severe pain worse with extension, neuro deficit, hamstring spasm · CES rare

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Fact |
|---|---|
| **AP + lateral X-ray** | **Best initial**; lateral shows **80%** of defects · obliques add 15% (OB) but **no extra diagnostic value + more radiation** (Orthobullets, OB) · TO: AP, lateral + **bilateral obliques** |
| Oblique | **Scotty dog collar** (neck = pars, nose = TP, eye = pedicle, ear = SAP, front leg = IAP) |
| **SPECT** | **Most sensitive** after normal X-rays (OB) · "gold standard" (TO) · now rarely used (radiation) |
| **MRI** | **As sensitive + specific as SPECT, no radiation** → **next test** after negative X-rays · STIR oedema = acute · neuro deficit, stenosis |
| **CT (thin cut)** | **Best to delineate the defect** · age + healing |
| Bone scan | Most sensitive screen (lesion may be cold) |
| Flexion-extension | Instability (**> 3 mm** translation abnormal, TO) |

### Wiltse-Newman

| Type | Description |
|---|---|
| **I Dysplastic** | Congenital lumbosacral facets/sacrum, **pars intact** · **more neuro symptoms, more progression** |
| **II-A Isthmic** | **Pars fatigue (stress) fracture** — lytic |
| **II-B Isthmic** | **Pars elongation** (healed microfractures) |
| **II-C Isthmic** | **Acute pars fracture** |
| III | Degenerative (commonest overall) |
| IV | Traumatic |
| V | Neoplastic / pathologic |
| VI | Iatrogenic (TO) |

**Marchetti-Bartolozzi** — developmental (Wiltse I + II) vs acquired (traumatic, post-surgical, pathologic, degenerative)

### Meyerding

| Grade | Slip |
|---|---|
| I | < 25% |
| II | 25–50% |
| III | 50–75% |
| IV | 75–100% |
| V | **Spondyloptosis** (> 100%) |

**Low grade** I–II · **high grade** III–V

**Slip angle** — lumbosacral kyphosis

## 5 Management

```
Spondylolysis / spondylolisthesis
├─ Asymptomatic (any grade) → OBSERVE, NO ACTIVITY RESTRICTION
├─ Symptomatic lysis / low grade → ACTIVITY MODIFICATION + PT 6 MONTHS
│      └─ Acute stress reaction or failed PT → BRACE (TLSO / LSO) 6–12 WKS
└─ Failed non-op
       ├─ L1–L4 defect, multiple defects → PARS REPAIR
       ├─ L5 lysis / low grade (I–II) → L5-S1 POSTEROLATERAL FUSION
       └─ High grade (III–V) → L4-S1 POSTEROLATERAL FUSION ± reduction
```

### Non-operative

**PT** — 6 months: **hamstring stretching, pelvic tilts, abdominal strengthening** · most improve

**Bracing** — **acute pars stress reaction** (brace > activity restriction alone; prevents defect formation) · failed PT · chronic L5 lysis failing 3 months PT (no STIR signal) → **rigid LSO 6–12 wks** · **antilordotic (hypolordotic) brace**\
✗ Wrong options: hyperextension brace

**TO stepwise protocol** — avoid hyperextension → **non-rigid corset** → after 2–4 wks PT (core) → still painful at 4 wks → **TLSO / Boston antilordotic brace** · healing 3–6 months · return to play from **8 wks** if pain-free

**TO answers** — SPECT-proven bilateral stress fracture → **activity modification + rest** first · **2-month-old bilateral pars defect → antilordotic brace**

**Sport** — stopping sport ≥ 3 months improves outcome · return controversial

### Operative criteria

| Procedure | Indication |
|---|---|
| **Direct pars repair** | **L1–L4 isthmic defect** failing non-op, **multiple defects** · preserves motion · screw, tension wiring, screw + hook · not with **disc degeneration** (MRI first), facet arthropathy, listhesis |
| **L5-S1 posterolateral fusion** ± ALIF | **L5 spondylolysis** failing non-op · **low grade (I–II)** failing non-op, progressive, deficit or **dysplastic** · in situ, ± instrumentation, TLSO |
| **L4-S1 posterolateral fusion** ± reduction | **High grade (III–V)** · L5-S1 alone fails for > 50% slip |
| Gaines L5 vertebrectomy | **Spondyloptosis** (grade V) |
| No | Isolated ASF, pars repair with listhesis |

**TO surgical indications** — pain > **6–12 months** of conservative care, neuro deficit, worsening symptomatic listhesis, **grade ≥ III**, progression > 1 grade, instability > 3 mm · fusion avoided in pro athletes (adjacent segment disease: **36%** reoperation at 10 yrs after posterior lumbar fusion)

**TO acute grade 3 in a gymnast, no deficit** — **observation** initially (then elective fusion) — controversial

**Return to sport after fusion** — non-contact 3–6 months, contact 6–12 months · ALIF may help · 90% success

### Reduction

**Pros** — restores sagittal alignment, ↓ lumbosacral kyphosis · TO: partial slip-angle reduction favoured for high grade

**Cons** — complications **8–30%** · **L5 root commonest injury** (**weak EHL / great-toe extension**, hip abduction, dorsal foot numbness) · sexual dysfunction · catastrophic deficit → neuromonitoring

**360° fusion + decompression** — more in-hospital complications

## 6 Complications

**List** — **L5 root injury (commonest neuro)**, pseudarthrosis, slip progression, hardware failure

## X vs Y

| | Dysplastic (I) | Isthmic (II) |
|---|---|---|
| Pars | Intact (elongated) | Defect |
| Neuro | **More** (intact arch traps cauda) | Less |
| Progression | **Higher** | Lower |

## How it's asked

**"Most sensitive test when AP + lateral normal?"** → **SPECT**

**"13-yr, 6 months back pain, SPECT + CT?"** → **spondylolysis**

**"Lineman with insidious LBP — exam?"** → **pain with lumbar extension in single-leg stance**

**"Commonest exam finding in chronic spondylolysis?"** → **pain with lumbar extension**

**"14-yr, extension pain, negative X-rays — next?"** → **MRI**

**"15-yr lineman, extension pain — true?"** → **best initial studies are AP + lateral alone**

**"Gymnast, MRI finding fitting rest + PT?"** → **pars fracture (Figure A)**

**"Gymnast, SPECT bilateral pars stress fracture — next?"** → **activity modification + rest** (TO)

**"2-month-old bilateral pars defect?"** → **antilordotic brace** (TO)

**"13-yr gymnast, acute pain, SPECT hot L5 pars?"** → **molded lumbosacral orthosis**

**"Asymptomatic low-grade isthmic slip in soccer player?"** → **observe, no activity restriction**

**"Chronic L5 lysis, failed 3 months PT, no STIR signal?"** → **LSO brace**

**"7-yr gymnast with L5 pars defect — true?"** → **likely never needs surgery**

**"Spondylolysis, extension pain, hamstring tightness — initial?"** → **activity modification ± brace + PT**

**"Grade I isthmic slip in 13-yr gymnast?"** → **short activity modification + structured PT**

**"Parameter correlating with severity?"** → **pelvic incidence**

**"Lines measuring the angle best correlating with severity?"** → **pelvic incidence lines (C + D)**

**"Grade III — predicts progression?"** → **slip angle**

**"Factor associated with progression?"** → **> Meyerding 2 at presentation**

**"Gymnast acute grade 3 L5-S1, no deficit?"** → **observation** (TO)

**"12-yr, 80% slip, failed non-op?"** → **posterior instrumented fusion L4-S1**

**"Reduction of high-grade L5-S1 slip — complication?"** → **weak great-toe extension (L5)**

**"14-yr, grade 4, crouched gait — surgery?"** → **posterior fusion L4–S1 ± instrumentation**

**"Gait pattern in spondylolisthesis?"** → **short stride, hips + knees flexed**

**"Same lesion at L3 — surgical difference?"** → **pars interarticularis repair indicated**
