# Cerebral Palsy - Spinal Disorders

*Spine · 10 / 69*

## 1 Basics

### Epidemiology

**Scoliosis in CP** — overall **20%**; ↑ with severity · **spastic quadriplegia** highest (esp. non-sitters) · **bedridden → \~100%** · rare in ambulators

**Spondylolisthesis** — **4–21%** in **spastic diplegia** → check lateral film

### Pathophysiology

**Cause** — muscle weakness + truncal imbalance (little evidence) · **pelvic obliquity** drives deformity

| CP scoliosis vs idiopathic | |
|---|---|
| Progression | **More likely**; **1–2° per month** from age 8–10 |
| Onset | Earlier |
| Shape | **Long, stiff C-shaped**; left curves common |
| Sagittal | Greater kyphosis / lordosis |
| Pelvis | **Pelvic obliquity** |
| Maturity | Delayed |
| Bracing | **Less effective** |
| Fusion | Longer, often **to pelvis** |
| Host | Medically fragile → multidisciplinary |

## 4 Diagnosis & Classification

### Weinstein classification

| Group | Curve | Pelvic obliquity |
|---|---|---|
| **I** | **Double** thoracic + lumbar | Minimal |
| **II** | Large **lumbar / thoracolumbar** | **Marked** |

### Key radiology findings

**X-rays** — same technique over time; erect films when possible · AP + lateral (rib deformity, wedging, rotation, spondylolisthesis) · **bending films**: push-pull / fulcrum if uncooperative

**MRI** — **not routine** pre-op; only for **rapid progression** or **neuro change**

**Exam** — **hamstring contracture → ↓ lumbar lordosis** · **hip contracture → ↑ lordosis** · curve flexibility, balance, pelvic obliquity

## 5 Management

**Non-op** — **non-progressive curves < 50°** or age **< 10** (delay surgery) · custom seat (sitting only) · **TLSO improves sitting balance**, doesn't change natural history (may slow progression only if immature) · **Botox** short-term (2–3 months)

### Operative criteria

| Procedure | Indication |
|---|---|
| **PSF ± pelvis** | **Group I, 50–90°**, ambulators, progressive / interfering with sitting; **age > 10**; adequate hip ROM; stable nutrition |
| **PSF ± ASF ± pelvis** | **Group I > 90°**, **non-ambulators**, **Group II**; immature (**crankshaft**); anterior release for **> 100–120°** rigid curves (don't bend < 60°) |
| Growing rods | Young child |
| Pre-op traction | Severe rigid curves |

**Surgery threshold (OB)** — progressive **> 40–50°** interfering with sitting in **> 10 yrs**

### Fusion levels

**Proximal** — **T1 or T2** (avoid proximal junctional kyphosis)

**Distal** — L4/L5 for long curves · **pelvis if obliquity > 15°** (else loss of correction + pseudarthrosis)

```
CP scoliosis needing fusion
├─ Pelvic obliquity > 15° / non-sitter → POSTERIOR T2 → PELVIS
│      (do not fuse to L4 — late loss of correction)
└─ Immature or > 100–120° rigid → ADD ANTERIOR RELEASE (same day)
```

### Fixation techniques

| Technique | Note |
|---|---|
| **Luque rod + sublaminar wires** | Classic |
| **Unit rod + sublaminar wires** | Pelvic limb may penetrate pelvis |
| **Pedicle screws** | Better correction, may avoid anterior surgery |
| **Galveston** | Rod bent from **S1 lamina → PSIS → between iliac tables** just above **sciatic notch** |
| Others | Bilateral sacral screws, iliosacral screws, spinopelvic transiliac, **Dunn-McCarthy** (S-rod over sacral ala) |

**A/P same day** — ↓ complications vs staged (nutrition, blood loss, stay) · post-op brace usually unnecessary

### Pre-operative assessment

| Domain | Action |
|---|---|
| **Nutrition** | Weight < 5th centile → ↑ infection, intubation, stay; **albumin > 3.5 g/dL**; consider **G-tube** |
| Respiratory | History, exam, CXR (formal PFTs hard) |
| GI | Treat **GERD** (aspiration) |
| Seizures | Control; **valproic acid → check bleeding time** |

**Goal** — painless solid fusion, balanced spine, **level pelvis**; family goals + risk-benefit

## 6 Complications

| Complication | Fact |
|---|---|
| **Pulmonary** | **Insufficiency = commonest**; aspiration, pneumonia |
| Implant failure | Often asymptomatic |
| **Wound infection** | **3–5%**, > idiopathic; local debridement usually enough |
| GI | GERD, malnutrition |
| Neuro | Seizures |
| **Death** | **0–7%** |

**Natural history** — larger curves progress more; pelvic obliquity; decubitus (conflicting)

## X vs Y

| | Weinstein I | Weinstein II |
|---|---|---|
| Curve | Double | Large lumbar/TL |
| Obliquity | Minimal | Marked |
| Fusion | PSF (50–90°, ambulator) | PSF ± ASF to pelvis |

## How it's asked

**"GMFCS V, 75° C-curve with pelvic obliquity, mature?"** → **posterior fusion T2 to pelvis**\
✗ Wrong options: brace · anterior-only · A/P · T2–L4

**"When add anterior release in CP?"** → **> 100–120° rigid curves** or **immature (crankshaft)**

**"Extend fusion to pelvis when?"** → **pelvic obliquity > 15°**

**"Commonest post-op complication?"** → **pulmonary insufficiency**

**"Pre-op lab for patient on valproate?"** → **bleeding time**
