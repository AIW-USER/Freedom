# Cervical Radiculopathy

*Spine · 16 / 69*

## 1 Basics

### Epidemiology

**Incidence** — **107.3 / 100,000 men**, 63.5 / 100,000 women per year · peak **50–54 yrs**

**Risk factors** — white race, **smoking**, prior lumbar radiculopathy

**Degeneration prevalence** — X-ray changes in **70% by 70** · MRI: HNP/foraminal stenosis in **28%** of asymptomatic > 40 · **≥ 1 degenerated disc in \~57% (50–60%)** of asymptomatic > 40 (Boden) · up to 19% asymptomatic root compression → **treat only if clinical findings match MRI**

### Aetiology

| Cause | Note |
|---|---|
| **Cervical spondylosis** | Disc-osteophyte, height loss, **uncovertebral + facet spurs** |
| **Soft disc** | **Posterolateral = commonest** (between uncinate and lateral PLL) → mostly **motor** · intraforaminal → **radicular pain** · midline → **myelopathy** |
| **Double crush** | Root + distal entrapment (↓ axoplasmic flow) |
| Rare | Tumour, root avulsion, synovial / meningeal cyst, dural AVF, tortuous vertebral artery |

**Chemical mediators** — **IL-1, IL-6, substance P, neuropeptide Y, CGRP, bradykinin, TNF-α, prostaglandins**

### Anatomy

**Pedicle-root mismatch** — cervical root exits **above** its pedicle (C6 above C6 pedicle) · lumbar root exits **below** (L5 under L5) · extra **C8** root makes the switch

**Disc → root** — cervical disc compresses the **lower (exiting) root**: **C6-7 → C7**

**Horizontal cervical root** — **central/paracentral and foraminal discs hit the SAME root** (vs lumbar: paracentral → traversing, foraminal → exiting) · far-lateral discs not typically described in C-spine

**Compression sources** — facet hypertrophy (posterior) · **uncovertebral osteophyte (anterior)** · disc height loss (↓ foraminal volume) · ventrolateral root course → ventral compression

**Disc** — annulus **type I collagen** (thicker ventrally) · nucleus **type II collagen + GAGs**; water **90% (< 30 yrs) → 70%** (8th decade)

## 3 Presentation

**Symptoms** — occipital headache, **trapezial / interscapular pain**, neck pain, unilateral arm pain (often non-dermatomal), dermatomal paraesthesia, weakness (overhead = C7, grip = C8)

### Root-level localisation

| Root (disc) | Motor | Reflex | Sensory |
|---|---|---|---|
| **C4** (C3-4) | **Scapular winging** | — | Base of neck; Tinel at levator scapulae |
| **C5** (C4-5) | **Deltoid + biceps** (shoulder abduction, ER, elbow flexion) | **Biceps** | **Superior shoulder, lateral arm** |
| **C6** (C5-6) | **Brachioradialis (elbow flexion in mid-pronation) + wrist extension (ECRL)**, biceps | **Brachioradialis (supinator)** | **Thumb, (index), dorsoradial forearm** |
| **C7** (C6-7) | **Triceps, wrist flexion**, finger extension, pronation | **Triceps** | **Middle finger** (index/ring), dorsal forearm, posterior arm |
| **C8** (C7-T1) | **Finger flexion — DIP of middle + index (FDP)**, grip, **thumb extension** | — | **Ring + little finger**, ulnar hand/forearm |
| **T1** (T1-2) | **Hand intrinsics** (finger abduction) | — | **Axilla / medial arm**, ipsilateral **Horner** |

**Commonest root** — **C7** (several studies)

**Commonest level (TO)** — **C6-7** (then C5-6) → **C7 root** · rule: disc level → **root below** affected

| Type (TO) | Age | Cause | Feature |
|---|---|---|---|
| **Acute** | Young | **Soft disc** | Sudden neck + arm pain, no prior neck pain |
| **Subacute** | Middle-aged | Spondylosis + hard disc | **Neck pain precedes arm pain** |
| **Chronic** | Older | Degenerative | Intermittent, long-standing |

**Clinical clues (TO)** — **"restless arm"** · upper cervical root → occipital + scapular pain · **exaggerated reflexes → think myelopathy**

**C8 vs ulnar neuropathy** — C8 weakens **index/middle FDP** (AIN-innervated) — ulnar entrapment does not

**C6 vs tennis elbow vs PIN** — C6: thumb paraesthesia + relief with shoulder abduction · lateral epicondylitis: pain with resisted wrist/long-finger extension · PIN: painless wrist extension weakness **with radial deviation**

**Facet fracture localisation** — **C6 superior facet fracture → C5-6 instability → C6 root** (radial forearm + thumb numbness)

### Provocative tests

| Test | Fact |
|---|---|
| **Shoulder abduction relief (SAR)** | Hand on head relieves pain (↓ root tension) — **virtually pathognomonic**, best separates cervical vs shoulder/peripheral causes; analogue of SLR |
| **Spurling** | **Extension + rotation + lateral bend to affected side + axial load** → ipsilateral arm pain; **specific, not sensitive** (✗ Wrong options: contralateral rotation) |
| Upper limb tension, Valsalva, neck distraction | Supportive |
| Axial compression (TO) | Downward pressure on head → reproduces pain |
| Cervical distraction (TO) | Upward traction → **relief** |
| Hoffmann, inverted radial reflex, clonus, Babinski | **Myelopathy** (✗ Wrong options: radiculopathy) |

**Tension tests (TO)** — **increase**: Spurling, axial compression · **relieve**: cervical distraction, **shoulder abduction (Davidson)**

**Peripheral mimics** — Froment (ulnar), **"OK" sign** failure (AIN), Guyon (no dorsal wrist sensory change), cubital tunnel (worse with elbow **flexion**), diabetic neuropathy (glove-stocking)

**Differential** — carpal / cubital tunnel, **Parsonage-Turner**, thoracic outlet, myelopathy, brachial plexus injury, rotator cuff (history must match MRI)

| Mimic (TO) | Root | Distinguishing feature |
|---|---|---|
| **Rotator cuff / shoulder** | C5 | Abduction weak but **elbow flexion intact**, joint tenderness |
| **Brachial plexitis** (Parsonage-Turner) | C5–6 | **Pain precedes weakness** by days–weeks · **MRI normal**, NCS confirms |
| **Thoracic outlet** | C8–T1 | Worse with **neck rotation to opposite side** · hyperabduction aggravates |

## 4 Diagnosis & Classification

### Key radiology findings

| Study | Use |
|---|---|
| X-ray AP, lateral, **oblique** | **Oblique = best for foraminal stenosis** from osteophytes; flex-ext for instability |
| **MRI (T2 axial)** | Red flags (fever, weight loss, night pain), **> 6 weeks** of failed care, motor weakness; loss of perineural fat |
| CT | Bony anatomy, **OPLL**, instrumentation planning; **post-op pseudarthrosis study of choice** |
| CT myelogram | Pacemaker, hardware artefact |
| Discography | Rarely; oesophageal puncture, discitis |

### Genes & lab markers – electrodiagnostics

| EMG / NCS finding | Fact |
|---|---|
| **Fibrillations + positive sharp waves** | In affected root muscles (✓) — appear **\~3 weeks**; **paraspinals first** |
| **SNAPs normal** | Lesion **proximal to DRG** |
| CMAP | ↓ in proportion to atrophy |
| F-wave | ↓ / absent in severe cases (✗ Wrong options: ↑) |
| H-reflex | S1 only (✗ Wrong options: cervical) |
| Prolonged distal latency | Peripheral compression (✗ Wrong options: radiculopathy) |
| Sensitivity | **40–70%** — not a screening test; not needed with concordant exam + MRI |

**Selective nerve root block** — localises level in multilevel disease

## 5 Management

### Natural history & non-op care

**Natural history** — favourable: **75% (75–90%) improve non-op**\
✗ Wrong options: stepwise decline = myelopathy · needs PT/surgery to resolve

**80% resolve in 3–6 weeks** non-op (TO)

**Non-op regimen (TO)** — rest **3–7 days**, soft collar, large pillow (**flexion relieves tension**) · NSAIDs, pregabalin, short steroid taper (deflazacort) · neck exercises after 2 weeks · **avoid traction in acute soft disc** (if used → **in flexion**) · epidural / SNRB when inflammation dominates

**Medications** — **NSAIDs** = most appropriate for chronic radicular pain (TO) · brief **oral steroids** · gabapentin · **nortriptyline** if depressed (↓ narcotic need)\
✗ Wrong options: narcotics · muscle relaxants (habituation, depression) · anticonvulsants

**Other** — short immobilisation **< 1–2 weeks** (avoid prolonged → atrophy) · isometrics, heat, traction (not in myelopathy)

**Selective nerve root steroid injection** — long-term relief **40–70% (50–70%)**; steroid + LA = LA alone long term; ↑ risks vs lumbar (dural puncture, meningitis, abscess, root injury)

**Axial neck pain only (no root/cord signs, solid old fusion)** — **education + PT**\
✗ Wrong options: hardware removal · revision · PSF · ESI

**Return to play** — after symptom resolution + **repeat MRI without cord compression**; **oral methylprednisolone** speeds return; **no ↑ catastrophic SCI risk** after C4-5 HNP · single-level ACDF not a contraindication · collegiate C5 radiculopathy → **NSAIDs + PT, RTP after resolution + repeat imaging**\
✗ Wrong options: immediate RTP on steroids · EMG · surgery

### Operative criteria

| Indication |
|---|
| Disabling pain after **3 months** of non-op care |
| **Progressive / significant neurologic deficit** |
| Static deficit with significant radicular pain |

**Failed non-op duration** — **3 months** (Orthobullets) · **> 6 weeks** (TO) — read the options

| Procedure (TO) | Use |
|---|---|
| **ACDF** | **Gold standard**; fusion prevents segmental kyphosis |
| Anterior discectomy without fusion | Limited role → **collapse + kyphosis** |
| **Posterior foraminotomy / laminotomy** | Soft paracentral / foraminal disc · motion preserving |

### Surgical options

| Procedure | Indication / outcome |
|---|---|
| **ACDF** | **Gold standard**; ventral compression; e.g. 6 months C7 radiculopathy + ventral cord compression (✗ Wrong options: posterior foraminotomy (cord risk) · anterior foraminotomy (vertebral artery) · corpectomy · laminoplasty) |
| **Posterior foraminotomy** | **Foraminal soft disc / osteophyte, single level**, prior anterior surgery; **> 91% success**, \~3% complications, = ACDF outcomes, faster return to work, lower cost · not for central disc, myelopathy, instability, OPLL, kyphosis |
| Anterior foraminotomy | Unilateral root, avoid fusion (smokers, diabetics); uncovertebral resection; **vertebral artery + sympathetic chain risk**; not widely accepted |
| **CDA** | Single level, minimal facet arthrosis; **= ACDF** (arm pain, NDI, SF-36, neuro; **PROMs equivalent at 2–5 yrs**); ASD + reoperation + dysphagia similar; less neck pain; **heterotopic bone 60%** (no motion effect) |

**Best posterior foraminotomy candidate** — **young, foraminal soft disc at C6-7, C7 radiculopathy**\
✗ Wrong options: myelopathy · SCI · midline disc-osteophyte · MS

### ACDF technique

**Approach** — Smith-Robinson · **transverse incision 1–2 levels**, longitudinal for multilevel / short thick neck

**Landmarks** — mandible **C1-2** · hyoid **C3-4** · thyroid cartilage **C4-6** · **cricoid C5-6**

**Side** — left-sided **lower RLN risk** theoretically; **C7-T1 left → thoracic duct** risk · **deflate ET cuff after retractor placement** (RLN compressed against tube)

**ACDF steps (TO)** — supine, roll under scapula · transverse incision · plane **between SCM (lateral) and strap muscles (medial)** · trachea + oesophagus medial, **carotid sheath lateral** · excise PLL to clear fragment · **left-sided approach for singers/teachers**

**ACDF complications (TO)** — **dysphagia** (oesophageal retraction oedema) · hoarseness (RLN, esp. right) · **oesophageal perforation (rare, fatal)** · persistent radiculopathy (inadequate decompression)

**Plates** — ↑ fusion in **multilevel** (↓ graft complications, reoperation, earlier return to work); **single-level: no difference** · dynamic (controlled settling) vs static (fixed angle) · old Caspar bicortical → neuro risk · screw length > 80% AP → ↓ pseudarthrosis

**Graft** — **ICBG autograft gold standard** (donor pain) · allograft ↑ pseudarthrosis (**41% vs 27%**) + subsidence (**28% vs 16%**) (Orthobullets) · **no difference single level** (OB) — read the options

**Post-op** — walk day 0, soft collar briefly (hard collar if no plate), ROM at 6 wks, full activity 3 months

## 6 Complications

### Pseudarthrosis

**Rates** — single level **5–10%** (Orthobullets complications) · 20% (Orthobullets outcomes) · **2.6–4.8%** (OB) · multilevel **30% / > 50%** · doesn't always correlate with outcome

**Risk factors** — **smoking + diabetes** (strongest, modifiable) · multilevel · revision (✗ Wrong options: graft type · plate · level · alignment single level) · **smoking cessation ≥ 4 weeks pre-op** = greatest fusion impact (✗ Wrong options: plate · autograft · collar)

**Treatment** — asymptomatic → observe · symptomatic → **posterior cervical fusion** (↑ fusion, ↓ revision; but ↑ blood loss, stay, complications) or anterior revision if radiculopathy (EXCEPT: posterior does NOT ↓ fusion rate)

### ACDF complications

| Complication | Fact |
|---|---|
| **RLN palsy** | **Commonest nerve injury** (1–11%; 2.7%); vagus branch; **left hooks aortic arch, right hooks subclavian** (shorter, crosses lateral → medial higher, can be aberrant) → right **theoretically** riskier (TO: left approach preferred) · **no proven clinical difference** (Orthobullets, OB); posterior cricoarytenoid paralysis; observe → ENT at 6 wks (Teflon) |
| **Revision after RLN palsy** | **Same side** as prior approach; **pre-op laryngoscopy** for revision / prior thyroidectomy (bilateral palsy → stridor) · not contralateral approach |
| **Superior laryngeal nerve** | Runs with **superior thyroid artery** (upper C-spine); cricothyroid → pitch / voice fatigue |
| **Hypoglossal** | Upper C-spine (C2-3); **tongue deviates toward injured side** |
| **Horner** | Sympathetic chain on **lateral longus colli at C6**; retractors not under longus colli → ptosis, miosis, anhidrosis, enophthalmos |
| **Vertebral artery** | **Lateral discectomy / uncovertebral** bleeding; aberrant medial course (C6) |
| **Dysphagia** | ↑ at C3-4; **zero-profile cages** ↓ prominence; local steroid helps |
| **Oesophageal perforation** | Early: sharp instruments → repair now · late: plate loosening → NG + TPN |
| **Airway** | **> 5 h surgery**, exposure **above C4**, **> 4 levels / ≥ 4 bodies** (✗ Wrong options: smoking · lung disease · myelopathy · drains) |
| **CSF leak (TO)** | \~1% (↑ OPLL 12.5%, revision, corpectomy, men); intra-op → watertight repair; post-op → bed rest → **lumbar subarachnoid drain** → open repair |
| **Adjacent-level ossification** | **Plate < 5 mm from supra-adjacent disc** (✗ Wrong options: needle · stripping · longus colli); **start screws near inferior endplate** of top vertebra ↓ it |
| ASD | \~3%/yr, 30% at 10 yrs |

## X vs Y

| | Cervical | Lumbar |
|---|---|---|
| Root vs pedicle | Exits **above** | Exits **below** |
| Root course | Horizontal | Vertical |
| Paracentral disc | **Same root as foraminal** | Traversing root |
| Example | C5-6 → C6 | L4-5 paracentral → L5, foraminal → L4 |

| | Radiculopathy | Myelopathy |
|---|---|---|
| Natural history | **75% improve** | Stepwise decline |
| Signs | Dermatomal, SAR, Spurling | Hoffmann, clonus, gait |
| First line | Non-op | Surgery if impaired |
