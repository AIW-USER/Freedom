# Eosinophilic Granuloma

*Pathology · 16 / 66*

## 1 Basics

### Epidemiology

**Age** — **80% <20 yr** · commonly <10 · **M:F 2:1**

**Site** — skull, ribs, clavicle, scapula, mandible, pelvis · **spine (thoracic commonest)** · **diaphysis** of long bones

**Nature** — **self-limiting**, benign histiocytic lesion (Langerhans cell histiocytosis, LCH) · reticuloendothelial system

### LCH spectrum

| Form | Age | Features | Prognosis |
|---|---|---|---|
| **Eosinophilic granuloma** | Children/adolescents | **Single**, self-limited bone lesion | Excellent · spine lesions resolve spontaneously |
| **Hand-Schüller-Christian** | **>3 yr** | Chronic disseminated · **triad: multiple lytic skull lesions + diabetes insipidus + exophthalmos** · visceral (lung, liver, spleen, skin, nodes) → abdominal pain | Depends on chemo response · worse with more extraskeletal disease |
| **Letterer-Siwe** | **<3 yr** | Fulminant · skin rash from birth, multiple lesions | **Fatal** in early childhood |

### Genes & lab markers

**Genetics** — no clear inheritance or locus

**CD1a +** Langerhans cells · **Birbeck granules** on EM

## 3 Presentation

**Bone** — pain + swelling · **limp** (pelvis / lower limb)

**Spine** — local or diffuse back/neck pain · progressive **kyphosis** · radiculopathy if aggressive

**HSC** — **thirst / polydipsia** (DI) · **exophthalmos** · weight loss, skin lesions, abdominal pain

## 4 Diagnosis & Classification

### Key radiology findings

**"Great mimicker"** — DD osteomyelitis, leukaemia, lymphoma, fibrous dysplasia, **Ewing**

**Diaphysis** — **well-defined intramedullary lytic "punched-out"** lesion · cortex thinned/expanded/destroyed · **periosteal reaction** possible

**Metaphysis** — up to, **not through, the physis** · less central

**Spine** — **vertebra plana** (flattened vertebral body) · ↑ kyphosis

![Vertebra plana](../../Orthobullets/attachments/ob8041-case-b-vertebra-plan-xray-parsons-moved.png)

**Skull** — **multiple punched-out lytic lesions**

**MRI** — adjacent soft-tissue mass · **Bone scan** — ↑ uptake · **Whole-body PET/CT** — staging if multifocal · skeletal survey finds extra lesions

### Vertebra plana — differential (TO)

| Cause | Vertebra plana? |
|---|---|
| **Eosinophilic granuloma / LCH** | ✓ **Commonest** |
| Ewing sarcoma | Yes |
| Lymphoma / leukaemia | Yes |
| Gaucher disease | Yes |
| ABC | Yes |
| Infection (spondylitis) | Yes |
| Metastasis (neuroblastoma) | ✓ occasionally |
| **Lyme disease** | No |

### Histology

**Langerhans cells** — mononuclear **histiocyte-like** cells, **oval nuclei** with **prominent nuclear groove ("coffee-bean")**, eosinophilic cytoplasm

**Stain** — **CD1a +**

**EM** — **Birbeck granules** — **tennis-racquet** shaped cytoplasmic organelles, diagnostic\
✗ Wrong options: Langerhans cell itself · plasma cell · Kupffer cell

![Birbeck granules on electron microscopy](../../Orthobullets/attachments/ob8041-birbeck-body-parsons-moved.jpg)

**Background** — **eosinophils** (bilobed nuclei), mixed inflammatory cells, giant cells

**No nuclear atypia, no atypical mitoses** — separates from Ewing, lymphoma, metastatic neuroblastoma

### Differential

| | Destructive lesion, young | Multiple lesions, young | Observation alone |
|---|---|---|---|
| **EG** | ✓ | — (HSC ✓) | ✓ (self-limited) |
| Osteomyelitis · OS · Ewing · desmoplastic fibroma | ✓ | — | — |
| Lymphoma · leukaemia | ✓ | ✓ | — |
| FD · Ollier/Maffucci · MHE · NOF/Jaffe-Campanacci | — | ✓ | ✓ |
| Haemangioendothelioma | — | ✓ | — |

## 5 Management

```
Eosinophilic granuloma
├─ Isolated, stable → OBSERVATION ± protected weight bearing, repeat X-ray 6 wk
│      └─ Symptomatic → CORTICOSTEROID INJECTION (± after curettage)
├─ Spine, no neuro deficit → BRACE / COLLAR + OBSERVE
│      ├─ Instability / neuro compromise → LOW-DOSE RT (600–800 cGy)
│      └─ Progressive deformity despite brace (~10%) → SURGICAL CORRECTION
├─ Impending fracture / articular surface at risk → CURETTAGE + GRAFT
└─ Disseminated HSC → CHEMOTHERAPY
```

### Treatment — observation

**Observation** — self-limited · heals spontaneously or after biopsy · femoral diaphysis: **crutches + repeat X-ray in 6 wk**\
✗ Wrong options: wide excision · chemo · RT alone · curettage first

**Cervical spine EG, no neuro deficit** — **cervical collar + observation**\
✗ Wrong options: antibiotics · chemo/RT · resection

**Bracing** — prevents kyphosis · corrects deformity **90%** · vertebrae regain ~**50%** height

**Low-dose RT 600–800 cGy** — spinal instability / neurology · lesions not amenable to injection/surgery

**Chemotherapy** — **only diffuse/disseminated HSC**

**Surgical decompression** — rare cord compression

## X vs Y

| | **EG / LCH** | **Ewing** | **Osteomyelitis** |
|---|---|---|---|
| Cells | Langerhans cells, coffee-bean nuclei, eosinophils | Small round blue cells, t(11;22) | Neutrophils |
| Marker | **CD1a**, Birbeck | CD99 | Culture |
| Atypia | None | Malignant | None |
| Treatment | Observe | Chemo + local control | Antibiotics ± debridement |

## How it's asked

**"5-yr-old, skin lesions, limp, weight loss, lytic femoral lesion with histiocytes?"** → **eosinophilic granuloma**\
✗ Wrong options: neuroblastoma · Ewing · ALL · fifth disease

**"2-yr-old, thirst, exophthalmos, lytic skull lesions?"** → **LCH (Hand-Schüller-Christian)**\
✗ Wrong options: abuse · NF · metastatic neuroblastoma · adamantinoma

**"6-yr-old, limp, skull + pelvic lesions, thirst, abdominal pain?"** → **Hand-Schüller-Christian**\
✗ Wrong options: McCune-Albright · Maffucci · Ollier

**"10-month-old, multiple skeletal lesions + rash since birth, CD1a +?"** → **LCH**\
✗ Wrong options: osteomyelitis · Ewing · lymphoma · neuroblastoma

**"Vertebra plana — EM structure (tennis racquet)?"** → **Birbeck granule**

**"7-yr-old, femoral diaphyseal EG?"** → **crutches + repeat X-ray in 6 weeks**

**"7-yr-old, cervical EG, no neuro deficit?"** → **cervical collar + observation**

**"Causes of vertebra plana — all EXCEPT?"** → **Lyme disease** (✓ EG, Ewing, lymphoma) **(TO)**
