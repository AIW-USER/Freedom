# Soft Tissue Sarcoma

*Pathology · 59 / 66*

## 1 Basics

### Epidemiology

**Incidence** — **12,000/yr** in US · 4,700 deaths/yr · **M > F** · **85% >15 yr**

**Site** — **60% extremities** · **44% thigh**

**Origin** — mesoderm (connective tissue, muscle, fat, nerve, vessels) · grow **centripetally with a pseudocapsule**, compress neighbours

**Types** — **>50** histologic types (~100 — OB) · same presentation, imaging, differential and treatment · commonest: **UPS/MFH, liposarcoma, leiomyosarcoma, synovial sarcoma**

**Commonest by group (TO)** — adults: **MFH > liposarcoma** · young adults: **synovial** · children: **rhabdomyosarcoma** · hand/UL: **epithelioid** · foot: **synovial**

### Genes & lab markers

| Translocation / association | Sarcoma |
|---|---|
| **t(X;18), SYT-SSX** | **Synovial sarcoma** |
| **t(2;13)** | **Alveolar rhabdomyosarcoma** |
| **t(12;16)(q13;p11)** | **Myxoid liposarcoma** |
| **NF1** | **MPNST** |
| **Stewart-Treves / chronic lymphoedema** | **Angiosarcoma** |
| **S-100 + HMB45** | **Clear-cell sarcoma** (melanoma of soft parts) |

### Sarcomas with lymph node spread

**"RACES"** — **R**habdomyosarcoma · **A**ngiosarcoma · **C**lear-cell sarcoma · **E**pithelioid sarcoma · **S**ynovial sarcoma → consider **sentinel node biopsy**

**Overall** — only **5%** of STS go to nodes \
✗ Wrong options: liposarcoma · desmoid · GCT · Ewing · OS · chondrosarcoma · MFH · MPNST

**Leiomyosarcoma** — can spread via lymphatics but mainly **haematogenous** → lungs

## 3 Presentation

**Slow-growing, painless mass** · trauma draws attention · **rapid growth → higher grade**

**Red flags** — **>5 cm**, **deep to fascia**, **immobile**, rapid growth, pain in a previously painless mass, recurrent swelling

**Mimics** — lipoma, **haematoma** (no trauma, no ecchymosis → suspect sarcoma; mean **7-month delay** when misdiagnosed), desmoid, nerve sheath tumours, abscess, biceps tear

**"Sarcoma until proven otherwise"** — large (>5 cm), deep, heterogeneous mass

## 4 Diagnosis & Classification

### Workup of soft tissue mass (MRI, biopsy)

```
Soft-tissue mass
├─ X-rays (2 planes) → bone involvement, mineralization (synovial sarcoma)
├─ Contrast MRI → diagnostic & benign & symptomatic → EXCISE WITHOUT BIOPSY
│      (lipoma, ganglion, schwannoma, intramuscular myxoma)
└─ MRI indeterminate / sarcoma-like → CORE NEEDLE or OPEN BIOPSY → STAGING CT
```

**MRI (mandatory)** — **T1 low** (iso to muscle), **T2 high**, gadolinium: **peripheral enhancement + non-enhancing necrotic centre** · ~**90%** accurate benign vs malignant (ill-defined, large, heterogeneous)

![Deep adductor sarcoma on MRI](../../Orthobullets/attachments/ob8049-adductor-sarcoma.jpg)

**CT chest** — staging (lungs) · **myxoid liposarcoma → CT chest/abdomen/pelvis (± bone scan)**

**PET** — evolving · useful for node-spreading sarcomas · ↓ uptake predicts response

**Next step order** — X-ray → **MRI** (✗ Wrong options: biopsy before MRI · FNA · excisional biopsy) → **biopsy** (✗ Wrong options: RT · chemo · resection · observation before tissue diagnosis) → staging

### Biopsy

**Core needle** — modality of choice · correct in **68–93%** (Orthobullets) · **84%** (Skrzynski) · cheaper ($1106 vs $7234)

**Open biopsy** — gold standard · after **non-diagnostic core** (e.g. "only blood" in a presumed haematoma)

**Excisional biopsy** — only small (**<3 cm**) clearly benign lesions

**Who** — at the treating centre, by the definitive surgeon · **2–12× more complications** otherwise

**Technique** — **longitudinal** incision · avoid NV structures/compartments · meticulous haemostasis · **drain distal + in line** with incision · expert pathologist\
✗ Wrong options: transverse

### Histology distractors

| Lesion | Histology |
|---|---|
| **Leiomyosarcoma** | Spindle cells, smooth muscle |
| Myxoma | Paucicellular myxoid stroma, bland spindle cells, macrophages |
| Haematoma | Cystic cavity, necrotic debris, fibrin, clot |
| Neurofibroma (dermal) | Discoid proliferations of peripheral nerves |
| Fibroma | Poorly marginated hypocellular collagen |
| **Fibrosarcoma** | **Herringbone** spindle cells **(TO)** |
| **MFH / UPS** | **Storiform** pleomorphic |
| **Clear-cell sarcoma** | Nests of **clear cells** in fibrocollagenous septa, giant cells |

### AJCC 8th staging (extremity / trunk)

| Stage | Size | Nodes | Mets | Grade |
|---|---|---|---|---|
| **IA** | <5 cm | None | None | Low |
| **IB** | >5 cm | None | None | Low |
| **II** | <5 cm | None | None | Intermediate/high |
| **IIIA** | **5–10 cm** | None | None | Intermediate/high |
| **IIIB** | **>10 cm** | None | None | Intermediate/high |
| **IVA** | Any | **Any N+** | None | Any |
| **IVB** | Any | Any | **M+** | Any |

**8th edition changes** — **separates appendicular/truncal from other sites** (head/neck, visceral, retroperitoneum) — widely accepted · **depth removed** (not independent) · new T3 (10–15 cm) + T4 (>15 cm) · **node = stage IV** (controversial, equated with lung mets) \
✗ Wrong options: margins · histologic subtype · hospital type

**Vanderbilt staging** — includes depth · **Enneking** — no size, not for marrow/RES tumours, limited for spine

## 5 Management

```
Soft tissue sarcoma (localized)
├─ Most → WIDE RESECTION + RT (pre- or post-op)
├─ Abutting critical structure → PLANNED CLOSE / MICRO-POSITIVE MARGIN + RT
│      (remove adventitia / perineurium / periosteum)
├─ Encasing critical structure → EN BLOC with the structure (bypass graft if possible)
├─ Can't get negative margin / irreversible nerve loss / comorbid → AMPUTATION (often foot)
└─ Resectable lung mets → WEDGE RESECTION / LOBECTOMY
```

### Surgical margins & resection

**Most important treatment factor** (subcutaneous sarcoma DFS) — **size of operative margin**\
✗ Wrong options: chemo dose · RT · RFA

**High grade** — at least **wide** · not intralesional or marginal · dorsum of foot → **wide resection + fasciocutaneous flap**\
✗ Wrong options: STSG over tendons

**Abutting SFA + sciatic nerve, tumour within 1 mm, ink negative** — **equivalent to wide resection removing the structures** (with RT)

**Periosteal resection >10 cm** → fracture risk → **prophylactic nailing**

**Large midfoot synovial sarcoma** — **transtibial amputation** (best local control, fastest return)

**Resection technique** — elliptical incision **incorporating biopsy + drain sites** · tourniquet **without exsanguination** · frozen section margins

**Lung mets** — first-line **surgical resection** if complete resection possible (wedge/lobectomy) · curative in up to **25%** \
✗ Wrong options: RT · chemo first

**Chemotherapy** — **controversial** (no survival benefit in RCTs for most) · consider high grade · **standard for rhabdomyosarcoma + Ewing** · synovial sarcoma more chemo-sensitive

### Radiation therapy

**Effect** — **↓ local recurrence regardless of margin status** · **no overall survival benefit** (Yang) · transient strength/ROM loss · does not hamper limb salvage

**Dose** — **50 Gy pre-op**, **66 Gy post-op** (Orthobullets, OB7588) · **60 Gy** typical adjuvant (OB1117), range 45–65 Gy · palliative bone mets **~30 Gy** · HO prophylaxis **~6 Gy**

| | **Pre-op** | **Post-op** |
|---|---|---|
| Wound complications | **↑** — 20–30% (Orthobullets) · 30% (O'Sullivan) · **35% vs 17%** (OB7588) | ↓ |
| Dose · volume | **Lower, smaller** | Higher, larger |
| Fibrosis, oedema, stiffness, fracture, lymphoedema | ↓ | **↑** · ↑ radiation-induced sarcoma |
| Function | Trend better | — |
| Local recurrence · survival | **No difference** | No difference |

**RT not used** — chondrosarcoma, osteosarcoma (as adjuvant) · **WD liposarcoma / ALT → excision alone** (recurrence 2%)

### Unplanned excision — tumour bed re-excision

**Commonest mistake** in STS treatment · **74% residual disease**

```
Unplanned ("whoops") excision
├─ First → MRI limb + CT chest/abdomen/pelvis (no RT or surgery before imaging)
├─ Positive margins → TUMOUR BED RE-EXCISION (wide, ≥3 cm along scar) ± RT
└─ Negative margins → OBSERVATION vs ADJUVANT RT
```

**Deep, positive margins (e.g. sartorius)** — **wide tumour bed excision + RT**\
✗ Wrong options: RT alone · amputation · chemo

**High-grade superficial forearm** — **wide resection of tumour bed + coverage**\
✗ Wrong options: marginal to spare NV

**After wide re-excision vs planned** — **↑ plastic reconstruction** · less blood loss · same function · **5-yr LR-free >90%** · no extra chemo

### Specific subtypes (clear cell, alveolar soft part)

**Clear-cell sarcoma** — **malignant melanoma of soft parts** · adolescents/young adults · foot/ankle, bound to tendons · **S-100, HMB45** · **lymph node** mets · chemo + RT resistant → **wide excision / amputation**

**Alveolar soft part sarcoma** — **<1%** of STS · very vascular · lung, bone, **CNS** mets at presentation · LR 11–50% · **wide resection** + metastasectomy

**Fibrosarcoma (TO)** — diagnosis of exclusion · **herringbone** spindle cells · 5–10 cm slow painless deep lower-limb mass, **30–50 yr**

### Synovial sarcoma — histology & prognosis (TO)

**Not synovial in origin** — arises near bursae, tendon sheaths, capsules from multipotent stem cell rests → **biphasic = epithelial + mesenchymal (spindle)** · **lacks synovial differentiation**

**Subtypes** — **biphasic** (epithelial + spindle) · **monophasic** (spindle only) · poorly differentiated

**Genetics** — **t(X;18)(p11;q11)**, SS18 (SYT) on 18 + SSX1/2/4 on X → **SYT-SSX** · in **>90%** / **95%** · **SYT-SSX1 → biphasic** · markers (poorly differentiated): **CD56, CD99, HMW keratin** · BCL-2 under study

**Epidemiology** — **7%** (6–8%) of STS · commonest **foot** STS · commonest **non-RMS paediatric** STS · median **35 yr**, 15–40 · slight **M** · **knee** commonest

**Imaging** — X-ray: heterogeneous well-defined septate cystic mass, **calcification in 1/3** (CT best) · MRI: cystic, sharp, multiloculated → **misread as benign** · PET for mets/recurrence

**Grade** — **all high grade** · FNCLCC grading used

**Treatment** — wide excision (**>4 cm** margin) + RT (all >5 cm: EBRT, brachytherapy, IMRT) ± (neo)adjuvant chemo · amputation for fungating mass, difficult fracture, infection · metastatic → **doxorubicin + ifosfamide**

| Advanced-disease drug | Mechanism |
|---|---|
| **Pazopanib** | **Only approved targeted drug for STS** · TKI vs VEGFR, PDGFR, KIT |
| Trabectedin | Blocks DNA binding of the fusion oncoprotein |
| Tazemetostat | **EZH2 inhibitor** (INI1/SMARCB1-negative) |
| NY-ESO-1 T cells | Antigen in **80%** |
| Isolated limb perfusion | **TNF-α + melphalan**/doxorubicin, hyperthermic · limb preservation **72–96%** |

| Poor prognosis (TO) | Yes / No |
|---|---|
| **Age >50** (younger better) | ✓ |
| **Size ≥5 cm** | ✓ |
| Deep | ✓ |
| **Axial site** (distal extremity best) | ✓ |
| Higher stage · FNCLCC grade II–III · mitoses | ✓ |
| **Monophasic** histology | ✓ |
| CXCR4, IGF-1R nuclear expression | ✓ |
| Inadequate margins | ✓ |
| **Biphasic histology** | **No (favourable)** |

**Metastasis** — most important factor · in **~50%** · lung **80%**, nodes **up to 20%**, bone 9.9%, liver 4.5% · **5-yr OS ~60%** (61–73%)

## 6 Complications

**Metastasis** — **lungs commonest (40–60%)** · then **lymph nodes** (OB6341) · or bone/soft tissue (OB7545) · liver, brain rare

**Local recurrence** — **<10%** with surgery + RT · commonest site for low-grade recurrence = **local** · most within **5 yr**, but follow indefinitely

**Radiation** — pre-op wound problems · post-op fibrosis, fracture, secondary sarcoma

### Prognosis

**Most important factor** — **tumour stage** (Orthobullets) · **metastatic disease at presentation** (OB6333, bone sarcoma) · **histological grade** (TO one-liner)

**Poor** — high grade · mets · **>5 cm** · **deep to fascia** · delayed diagnosis · **unplanned excision**

| Stage | 5-yr survival |
|---|---|
| Low grade | **90%** |
| II–III | **50–75%** |
| IV | **15%** · median 12–18 months |
