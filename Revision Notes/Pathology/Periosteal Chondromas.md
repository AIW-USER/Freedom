# Periosteal Chondromas

*Pathology · 52 / 66*

## 1 Basics

**Nature** — rare, **benign chondrogenic surface** tumour (under periosteum)

**Age** — **10–20 yr**

**Site** — **proximal humerus (59%)** · distal femur, proximal femur · **hand** (metacarpals, phalanges)

## 3 Presentation

**Pain** — many painful from **irritation of overlying tendons** · night pain possible · palpable, mildly tender mass

## 4 Diagnosis & Classification

### Key radiology findings

**X-ray** — **well-demarcated, shallow cortical defect** · **saucerization** of underlying cortex · punctate mineralization in **1/3** · cortically based, eroding cortex\
✗ Wrong options: medullary epicentre (enchondroma)

![Saucerized cortical defect, proximal tibia](../../Orthobullets/attachments/ob8019-case-f-prox-tibia-xray-parsons-moved.png)

**X-ray is the key** — histology can look like **chondrosarcoma**

### Histology

**Like enchondroma, but more cellular** with more malignant-looking cells · **bland hyaline cartilage** · small **chondroid cells in lacunae**

![Bland hyaline cartilage](../../Orthobullets/attachments/ob8019-histology-a-moved.png)

### Differential

| | Surface lesion | Similar chondroid histology | Marginal excision |
|---|---|---|---|
| **Periosteal chondroma** | ✓ | ✓ | ✓ |
| **Osteochondroma / MHE** | ✓ | ✓ | — |
| **Parosteal OS** · **periosteal OS** | ✓ | — | — |
| **Enchondroma / Ollier / Maffucci** | — | ✓ | — |
| **Chondrosarcoma** | — | ✓ | — |
| Neurilemmoma · nodular fasciitis (soft tissue) | — | — | ✓ |
| Epidermal inclusion cyst · **glomus tumour** | — | — | ✓ |

| Lesion | Key distinction |
|---|---|
| **Enchondroma** | Same histology, **central medullary** epicentre |
| **Surface chondrosarcoma** | Malignant histology |
| **CMF** | Fibrous + myxoid elements |
| **Chondroblastoma** | Polyhedral cells, **chicken-wire** calcification |
| **Periosteal OS / CS** | Similar location — malignant |

## 5 Management

```
Periosteal chondroma
├─ Mild symptoms → OBSERVATION
└─ Severe / progressive pain, function impaired → MARGINAL EXCISION INCLUDING UNDERLYING CORTEX
       └─ Large defect → BONE GRAFT
```

**Recurs if cartilage left behind** \
✗ Wrong options: wide excision · RT · chemo

## How it's asked

**"19-yr-old shoulder night pain, surface cartilage lesion on CT + biopsy — treatment?"** → **marginal excision including underlying cortex**\
✗ Wrong options: wide excision · chemo · RT 60 Gy

**"10-yr-old wrist, cortical saucer-shaped defect, benign cartilage?"** → **periosteal chondroma**\
✗ Wrong options: enchondroma (medullary) · surface CS · CMF · chondroblastoma
