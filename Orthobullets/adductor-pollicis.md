## Summary


**Adductor Pollicis**

|  |  |  |
|---|---|---|
| **Origin** | **Oblique head:** bases of 2nd and 3rd metacarpals, capitate, and adjacent carpals;<br>**Transverse head:** anterior surface of the body of 3rd metacarpal | ![[ob10044-adductor-pollicis.jpg]] |
| **Insertion** | Medial side of base of proximal phalanx of thumb |  |
| **Action** | Draws 1st metacarpal laterally to oppose thumb toward center of palm and rotates it medially |  |
| **Innervation** | **Deep branch of ulnar nerve (C8, T1)** |  |
| **Arterial supply** | Deep palmar arterial arch |  |
