## Summary


**Brachialis**

|  |  |  |
|---|---|---|
| **Origin** | Distal half of anterior surface of humerus | ![[ob10018-brachialis.jpg]] |
| **Insertion** | Coronoid process and tuberosity of ulna |  |
| **Action** | Major flexor of forearm -- flexes forearm in all positions |  |
| **Innervation** | Medial half: **Musculocutaneous nerve (C5,C6)**<br>Lateral half: **Radial nerve** |  |
| **Arterial Supply** | Muscular branches of brachial artery, recurrent radial artery |  |
