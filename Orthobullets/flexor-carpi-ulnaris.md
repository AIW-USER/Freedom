## Summary


**Flexor Carpi Ulnaris**

|  |  |  |
|---|---|---|
| **Origin** | **Humeral head:** medial epicondyle of humerus;<br>**Ulnar head:** olecranon and posterior border of ulna | ![[ob10025-flexor-carpi-ulnaris.jpg]] |
| **Insertion** | Pisiform bone, hook of hamate bone, and 5th metacarpal bone |  |
| **Action** | Flexes and adducts hand (at wrist) |  |
| **Innervation** | **Ulnar nerve (C7, C8)** |  |
| **Arterial supply** | Ulnar artery |  |
