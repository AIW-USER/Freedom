## Summary


**Piriformis**

|  |  |  |
|---|---|---|
| **Origin** | Anterior surface of sacrum and gluteal surface of ilium at the margin of the greater sciatic notch | ![[ob10073-obturator-internus.jpg]] |
| **Insertion** | Superior border of greater trochanter |  |
| **Action** | External rotator of the hip joint; also helps abduct the hip if it is flexed |  |
| **Innervation** | **Piriformis nerve (L5, S1, S2)** |  |
| **Arterial supply** | Superior and inferior gluteal and internal pudendal arteries |  |
