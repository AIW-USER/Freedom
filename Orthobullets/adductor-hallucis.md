## Summary


**Adductor hallucis**

|  |  |  |
|---|---|---|
| **Origin** | Oblique: second to fourth metatarsal | ![[ob10098-ll3-moved.jpg]] |
| **Insertion** | Proximal phalanx of great toe (lateral side) |  |
| **Action** | Adduct great toe |  |
| **Innervation** | **Lateral plantar nerve** |  |
| **Arterial supply** | Lateral plantar artery |  |
