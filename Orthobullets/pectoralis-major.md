## Summary


**Pectoralis Major**

|  |  |  |
|---|---|---|
| **Origin** | **Clavicular head**<br>&nbsp;&nbsp;– anterior surface of medial half of clavicle<br>**Sternocostal head**<br>&nbsp;&nbsp;– anterior surface of sternum, superior six costal cartilages, and aponeurosis of external oblique muscle | ![[ob10008-pectoralis-major.jpg]] |
| **Insertion** | Lateral lip of intertubercular groove of humerus |  |
| **Action** | Adducts and medially rotates humerus<br>Draws scapula anteriorly and inferiorly<br>Acting alone: clavicular head flexes humerus and sternocostal head extends it |  |
| **Innervation** | **Lateral and medial pectoral nerves (C5-T1)** |  |
| **Arterial Supply** | Pectoral branch of the thoracoacromial trunk |  |
