## Summary


**Flexor Digitorum Superficialis**

|  |  |  |
|---|---|---|
| **Origin** | **Humeroulnar head:** medial epicondyle of humerus, ulnar collateral ligament, and coronoid process of ulna.<br>**Radial head:** superior half of anterior border of radius | ![[ob10024-flexor-digitorum-superficialis.jpg]] |
| **Insertion** | Bodies of middle phalanges of fingers |  |
| **Action** | Flexes middle phalanges at PIP joints of digits 2-5. Also flexes proximal phalanges at MCP joint. |  |
| **Innervation** | **Median nerve (C7, C8, T1)** |  |
| **Arterial supply** | Ulnar artery |  |
