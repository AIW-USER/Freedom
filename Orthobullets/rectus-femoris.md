## Summary


**Rectus femoris**

|  |  |  |
|---|---|---|
| **Origin** | Straight head from anterior inferior iliac spine; reflected head from groove just above acetabulum | ![[ob10057-rectus-femoris.jpg]]<br>![[ob10057-rectus-cross-function.jpg]] |
| **Insertion** | Base of patella to form the more central portion of the quadriceps femoris tendon |  |
| **Action** | Extends the knee, accessory flexor of hip |  |
| **Innervation** | **Muscular branches of femoral nerve (L2, L3, L4)** |  |
| **Arterial Supply** | Lateral circumflex femoral artery |  |
