## Summary


**Abductor Pollicis Longus**

|  |  |  |
|---|---|---|
| **Origin** | Posterior surfaces of ulna, radius and interosseous membrane | ![[ob10036-abductor-pollicis-longus.jpg]] |
| **Insertion** | Base of 1st metacarpal |  |
| **Action** | Abducts thumb and extends it at carpometacarpal joint |  |
| **Innervation** | **Posterior interosseous nerve (C7, C8)** |  |
| **Arterial Supply** | Posterior interosseous artery |  |
