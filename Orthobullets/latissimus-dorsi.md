## ANATOMY


**Latissimus Dorsi**

|  |  |  |
|---|---|---|
| **Origin** | Spinous processes of inferior 6 thoracic vertebrae, thoracolumbar fascia, iliac crest, and inferior 3 or 4 ribs | ![[ob10010-latissimus-dorsi.jpg]] |
| **Insertion** | Floor of intertubercular groove of humerus |  |
| **Action** | Extends, adducts, and medially rotates humerus; raises body toward arms during climbing |  |
| **Innervation** | **Thoracodorsal nerve (C6, C7, C8)** |  |
| **Arterial supply** | Thoracodorsal artery |  |
