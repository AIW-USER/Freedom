## Summary


**Extensor hallucis longus**

|  |  |  |
|---|---|---|
| **Origin** | Anterior surface of the fibula and the adjacent interosseous membrane | ![[ob10081-extensor-hallucis-longus.jpg]] |
| **Insertion** | Base and dorsal center of distal phalanx of great toe |  |
| **Action** | Extends great toe and dorsiflexes ankle |  |
| **Innervation** | **Deep peroneal nerve (L4, L5, S1)** |  |
| **Arterial supply** | Anterior tibial artery |  |
