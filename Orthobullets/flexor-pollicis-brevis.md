## Summary


**Flexor Pollicis Brevis**

|  |  |  |
|---|---|---|
| **Origin** | **Superficial head:** Flexor retinaculum and tubercles of scaphoid and trapezium<br>**Deep head:** Trapezoid and Capitate (more medial than superficial head) | ![[ob10043-fhb.jpg]] |
| **Insertion** | Lateral side of base of proximal phalanx of thumb |  |
| **Action** | Flexes thumb | ![[ob10043-flexor-pollicis-brevis.jpg]] |
| **Innervation** | Superficial head: **recurrent branch of the median nerve (C8, T1)**<br>Deep head: |  |
| **Arterial Supply** | Superficial palmar branch of the radial artery |  |
