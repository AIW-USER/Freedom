## Summary


**Scalene**

|  |  |  |
|---|---|---|
| **Origin** | Transverse process of C2 to C7 | ![[ob10006-scalene-muscles.jpg]] |
| **Insertion** | Anterior and medial scalene insert on first rib. Posterior scalene inserts on second rib. |  |
| **Action** | Anterior and medial scalene elevate first rib and flexes neck to same side. Posterior scalene elevates second riband flexes neck to same side. |  |
| **Innervation** | **Anterior branches of the cervical spinal nerves (C3-C8)** | ![[ob10006-scalene-and-brachial-plexus.jpg]] |
| **Arterial Supply** | Ascending cervical artery (branch of the thyrocervical trunk) | ![[ob10006-scalene-and-brachial-plexus-2.jpg]] |
