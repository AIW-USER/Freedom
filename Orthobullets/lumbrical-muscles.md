## Summary


**Lumbricals (4 muscles)**

|  |  |  |
|---|---|---|
| **Origin** | FDP tendon | ![[ob10051-lumbricals-moved.jpg]] |
| **Insertion** | Radial lateral band of the extensor expansion (tendon) |  |
| **Action** | Extends PIP and DIP joint. |  |
| **Innervation** | 1st & 2nd lumbricals: **median nerve**.<br>3rd & 4th lumbricals: **ulnar nerve** |  |
| **Arterial supply** | Palmar metacarpal arteries |  |
