## Summary


**Tibialis anterior**

|  |  |  |
|---|---|---|
| **Origin** | Lateral condyle of tibia, proximal 1/2 - 2/3 or lateral surface of tibial shaft, interosseous membrane, and the deep surface of the fascia cruris | ![[ob10079-tibialis-anterior.jpg]] |
| **Insertion** | Medial and plantar surfaces of 1st cuneiform and base of first metatarsal |  |
| **Action** | 1. Dorsiflexes ankle and inverts the hindfoot<br>2. Dorsiflexes foot in preparation for heel strike (late swing phase)<br>3. Eccentrically contracts after heel strike |  |
| **Innervation** | **Deep peroneal nerve (L4, L5)** |  |
| **Arterial Supply** | Anterior tibial artery |  |
