## Summary


**Levator Scapulae**

|  |  |  |
|---|---|---|
| **Origin** | Posterior tubercles of transverse processes of C1 - C4 vertebrae | ![[ob10003-levator-scapulae.jpg]] |
| **Insertion** | Superior part of medial border of scapula |  |
| **Action** | Elevates scapula and tilts its glenoid cavity inferiorly by rotating scapula |  |
| **Innervation** | **Dorsal scapular nerve (C5)** |  |
| **Arterial Supply** | Dorsal scapular artery |  |
