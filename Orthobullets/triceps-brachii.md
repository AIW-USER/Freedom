## Summary


**Triceps Brachii**

|  |  |  |
|---|---|---|
| **Origin** | **Long head:** infraglenoid tubercle of scapula;<br>**Lateral head:** posterior surface of humerus, superior to radial groove;<br>**Medial head:** posterior surface of humerus, inferior to radial groove | ![[ob10020-triceps-brachii.jpg]] |
| **Insertion** | Proximal end of olecranon process of ulna and fascia of forearm |  |
| **Action** | Chief extensor of forearm; long head steadies head of abducted humerus |  |
| **Innervation** | **Radial nerve (C6, C7, C8)** |  |
| **Arterial supply** | Branches of deep brachial artery |  |
