## Summary


**Extensor Indicis Proprius**

|  |  |  |
|---|---|---|
| **Origin** | Posterior surface of ulna and interosseous membrane | ![[ob10040-extensor-indicis.jpg]] |
| **Insertion** | Extensor expansion of 2nd digit |  |
| **Action** | Extends 2nd digit and helps to extend the hand |  |
| **Innervation** | **Posterior interosseous nerve (C7, C8)** |  |
| **Arterial supply** | Posterior interosseous artery |  |
