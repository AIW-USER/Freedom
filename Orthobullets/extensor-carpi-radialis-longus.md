## Summary


**Extensor Carpi Radialis Longus**

|  |  |  |
|---|---|---|
| **Origin** | Lateral supracondylar ridge of humerus | ![[ob10030-extensor-carpi-radialis-longus.jpg]] |
| **Insertion** | Base of 2nd metacarpal | ![[ob10030-extensor-compartments-moved.jpg]] |
| **Action** | Wrist extension and wrist abduction (radial deviation) |  |
| **Innervation** | **Radial nerve (C6,C7)** |  |
| **Arterial Supply** | Radial artery |  |
