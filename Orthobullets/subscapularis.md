## Summary


**Subscapularis**

|  |  |  |
|---|---|---|
| **Origin** | Subscapular fossa of scapula | ![[ob10016-subscapularis.jpg]] |
| **Insertion** | Lesser tuberosity of humerus |  |
| **Action** | Medially rotates arm and adducts it; helps to hold humeral head in glenoid cavity of scapula |  |
| **Innervation** | **Upper and lower subscapular nerves (C5, C6, C7)** |  |
| **Arterial Supply** | Subscapular artery |  |
