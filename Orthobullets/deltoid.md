## Summary


**Deltoid**

|  |  |  |
|---|---|---|
| **Origin** | Lateral third of clavicle, acromion, and spine of scapula | ![[ob10012-deltoid.jpg]] |
| **Insertion** | Deltoid tuberosity of humerus |  |
| **Action** | **Anterior part:** flexes and medially rotates arm;<br>**Middle part:** abducts arm;<br>**Posterior part:** extends and laterally rotates arm |  |
| **Innervation** | **Axillary nerve (C5, C6)** |  |
| **Arterial Supply** | Deltoid branch of thoracoacromial artery |  |
