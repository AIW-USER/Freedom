## Summary


**Vastus intermedius**

|  |  |  |
|---|---|---|
| **Origin** | Superior 2/3 of anterior and lateral surfaces of femur; also from lateral intermuscular septum of thigh | ![[ob10059-vastus-intermedius.jpg]] |
| **Insertion** | Lateral border of patella; also forms the deep portion of the quadriceps tendon |  |
| **Action** | Extends the knee |  |
| **Innervation** | **Muscular branches of femoral nerve (L2, L3, L4)** |  |
| **Arterial supply** | Lateral circumflex femoral artery |  |
