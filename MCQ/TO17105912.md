Chapter: Arthroplasty MCQs — Ligament Balancing in TKR

## Question

Genu recurvatum correction during TKR would involve all the steps except

## Options

1. Minimum resection of distal femur
2. Moving the joint line distally
3. Use of 1 size bigger femoral component
4. Use of a constraint implant

## Correct option

**3. Use of 1 size bigger femoral component**

## Answer explanation

Recurvatum correction:

For recurvatum correction one has to increase the flexion gap and use the thicker tibial polyethylene component.

Moving the joint line distally and/or using a smaller femoral component with anterior referencing is a preferable technique. Although possibly counterintuitive, using a smaller femoral component referenced from the anterior aspect of the femur requires removal of more posterior femoral condylar bone, which will increase the flexion gap. This will allow the height of the tibial polyethylene component to be used to fill the gap and create a joint space that is stable in extension and flexion.

So steps in recurvatum correction are-

- Minimum resection of distal femur
- Choose small femoral component
- Choose right level of constraintMoving the joint line distally

Answer: 3
