## Question

Downsizing femoral component would be helpful for which of the following scenario (FNB 2022)

## Options

1. Tight extension and normal flexion
2. Tight flexion and normal extension
3. Tight both in flexion and extension
4. Normal extension but loose flexion gap

## Correct option

**2. Tight flexion and normal extension**

## Answer explanation

Ans 2: B

The scenario in the question is the stage where bone cuts have been taken by surgeon using a particular referencing system (he’s comfortable with) and surgeon has moved on to balancing the cuts he has taken. So a particular size femur would have been selected by the surgeon.
Now if u downsize from here what happens next is what’s been asked in question (that’s why reference system used has not been given by examiner).
Downsizing at this stage would be actually done here keeping anterior cut same to avoid notching, hence this would end up removing more bone from posterior condyles (as smaller component has less AP diameter).
Now it’s obvious that removing more bone from posterior condyles would widen flexion gap. So tight flexion gap and normal extension gap (choice B) would be most beneficial scenario.

Choice A: A tight extension gap (normal flexion gap) would require more of distal femur to be resected.

Choice C: If both gaps are tight, remove bone from upper tibia as its part of both flexion and extension gaps.

Choice D: Here increase size of femoral component to increase AP diameter that would more profoundly decrease the flexion gap.
