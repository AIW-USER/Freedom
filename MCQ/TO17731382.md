## Question

Which muscle is being tested by the examiner in the figure? ( Regional orthopedics- shoulder- clinical examination)

![[TO17731382-1.png]]

## Options

1. Supraspinatus
2. Infraspinatus
3. Teres minor
4. Subscapularis

## Correct option

**4. Subscapularis**

## Answer explanation

This is lift-off test for subscapularis

Lift-off test (Gerber): Patient’s arm is internally rotated with the dorsum of the hand touching the back. If the patient is able to lift his hand off the back, subscapularis function can be presumed to be normal.

Answer : D
