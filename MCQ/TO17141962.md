## Question

True about Radioscapholunate ligament are all except:

## Options

1. It is also called as Ligament of Testut and Kuentz
2. Primary function is it provides mechanical strength to the wrist
3. Functions as a neurovascular conduit
4. It is an extrinsic carpal ligament

## Correct option

**2. Primary function is it provides mechanical strength to the wrist**

## Answer explanation

The radioscapholunate ligament (RSL) or ligament of Testut and Kuentz is a quite lax fibrous structure. According to Berger, ‘RSL Ligament’ is not a real ligament in the biomechanical or historical sense of the term. It can be considered as a mesocapsule. It contains terminal branches of the anterior interosseous nerve and rami from the radial arcade.

Functions - only functions as a neurovascular conduit, does not add mechanical strength

Answer : b
