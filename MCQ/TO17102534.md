## Question

Loosening of a cemented prosthesis begins at

## Options

1. At prosthesis cement interface
2. Cement bone interface
3. Any of the site can be involved
4. Cement bone interface at distal stem

## Correct option

**3. Any of the site can be involved**

## Answer explanation

In cemented acetabular component loosening starts at cement bone interface so answer is C. studies have found that failure occur at the prosthesis-cement interface of well-fixed femoral components before the development of fibrous tissue interfaces between cement and bone, suggesting that the inception of loosening of cemented femoral components is mechanical.

In Cemented THR, what studies have shown

- Cemented Acetabular components fail at Bone-Cement interface

- Cemented Femoral components fail at Cement-Prosthesis interface (as gaps are evident at cement prosthesis interface prior to development of fibrous tissue interfaces between bone cement interface).

Now in this question it’s not specified as to which component is being spoken so that’s why the answer chosen is C (any site can be involved).

Answer : C
