## Question

True about post arthroplasty X rays given below is

![[TO17105562-1.png]]

## Options

1. A is CR, B is PS
2. A is CR, B is CR
3. A is PS, B is PS
4. A is PS, B is CR

## Correct option

**1. A is CR, B is PS**

## Answer explanation

In X ray of PS total knee arthroplasty there is box or outline of the cam (black arrow in X ray B) to accommodate tibial insert post. This box is not seen in the X ray of CR total knee arthroplasty.

![[TO17105562-2.png]]

Answer : a
