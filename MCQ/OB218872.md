## Question

An orthopedic intern is submitting a research proposal for a prospective study. The attending surgeon recommends that a power analysis be performed for the study. Which of the following most accurately calculates the power for a given research study?

## Options

1. 1 - type I error
2. 1 - type II error
3. 1 / type I error
4. 1 / type II error
5. 1 - (type I error / (type I error - type II error))

## Correct option

**2. 1 - type II error**

## Answer explanation

A power analysis is calculated as: Power = 1 - (probability of a type-II, or beta error).

A power analysis is an estimate of the probability a study will be able to detect a true effect of the intervention. It helps to determine the sample size that should be performed prior to the initiation of the study. It is calculated as: Power = 1 - (probability of a type-II, or beta error). A type II, or beta, error is defined as a false negative difference that can occur by detecting no difference when there is a difference or accepting a null hypothesis when it is false and should be rejected.

*Staffa et al. provided a strategy for pediatric surgeons to use when planning a study to determine the sample sizes required for detecting a clinically meaningful effect, which is important for interpreting and validating their results.* **They reported** that understanding sample size considerations and statistical power in the surgical research community will improve the quality of published articles. **They concluded** that appropriate sample sizes are useful for detecting a clinically meaningful effect with sufficient statistical power.

*Kocher et al. reviewed clinical statistical primer for orthopedic surgeons.* **They reported** concepts that orthopedic surgeons should understand including how to perform a power analysis. **They concluded** that appropriately done statistics impact clinical practice and decision-making.
