## Question

. Predominate collagen type in human meniscus (FNB Pattern Paper 2017)

## Options

1. Type I
2. Type II
3. Type II in red-red zone and type I in rest of the meniscus
4. Type I in red-red zone and type II in rest of the meniscus

## Correct option

**1. Type I**

## Answer explanation

Collagen types in human meniscus: 75% of dry weight of extracellular matrix of meniscus is made up of collagen type I. Collagen II, III, V, and VI are also present in variable amounts. Abundance of type I collagen in meniscus distinguishes the fibrocartilage of menisci from articular (hyaline) cartilage where type II collagen predominates.

Bone- type I collagen

Meniscus (fibrocartilage)- type I collagen

Tendons- type I collagen

Articular cartilage (hyaline cartilage)- type II collagen

Answer: 1
