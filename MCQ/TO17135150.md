## Question

The Lenke classification for adolescent idiopathic scoliosis includes all except?

## Options

1. Type 1-6 Primary curve
2. Lumbar modifier (A, B, C)
3. Sagittal modifier (-, N, +)
4. Thoracic modifier (A, B, C)

## Correct option

**4. Thoracic modifier (A, B, C)**

## Answer explanation

The Lenke classification for adolescent idiopathic scoliosis has gained popularity and consists of three steps

- Label primary curve at Type 1-6
- Assign lumbar modifier (A, B, C)
- Assign sagittal modifier (-, N, +)

Answer: 4
