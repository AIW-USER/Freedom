Chapter: Regional Orthopedics MCQs — Charcot’s Arthropathy

## Question

Which of the following is not true about Charcot neuroarthropathy?

## Options

1. Type 1 involves all or portions of the midfoot including metatarsocuneiform and naviculocuneiform joints.
2. Type 2 represents those in which main changes are in hindfoot
3. Type 3A represents predominantly forefoot changes
4. Type 3B are those that develop pathological fractures of calcaneal tubercle with secondary deformity and distal collapse.

## Correct option

**3. Type 3A represents predominantly forefoot changes**

## Answer explanation

Ans: c

Type 3A primarily represents ankle involvement with significant deformity and disability.

Brodsky classification of diabetic charcot neuropathy:

Type 1
Involves tarsometatarsal and naviculocuneiform joints

Collapse leads to fixed rocker-bottom foot with valgus angulation

Type 2

Involves subtalar, talonavicular or calcaneocuboid joints

Unstable, requires long periods of immobilization (up to 2 years)

Type 3A

Involves tibiotalar joint

Late varus or valgus deformity produces ulceration and osteomyelitis of malleoli

Type 3B

Follows fracture of calcaneal tuberosity

Late deformity results in distal foot changes or proximal migration of the tuberosity

Type 4

Involves a combination of areas

Type 5
Occurs solely within forefoot

Type 3A primarily represents ankle involvement with significant deformity and disability.
