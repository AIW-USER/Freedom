## Question

You performed a hybrid THR where the femoral stem was fixed with cement. On post op X ray, you wanted to assess how well you have done the cementing so you used Barrack Harris grading system. You observed an incomplete cement mantle with radiolucencies that comprised > 50% of bone-cement interface. Your correct scoring as per the system would be (NEW)

## Options

1. A
2. B
3. C
4. D

## Correct option

**3. C**

## Answer explanation

Ans: C

Barrack and Harris system is used to grade how well you have performed femoral component cementing in THR. A simplified version of the system is presented below: -

Grade A: Complete filling of medullary canal giving a perfect "white-out" of cement-bone interface

Grade B: Slight radiolucency that comprise < 50% of cement-bone interface are there on X ray.

Grade C: The radiolucencies > 50% of bone-cement interface and there is incomplete cement mantle.

Grade D: Gross radiolucencies are there on X ray and/or failure of cement to surround tip of stem which can be seen abutting the bone directly.
