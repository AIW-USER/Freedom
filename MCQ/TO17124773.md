## Question

The abrupt appearance of which of the following collagens heralds the onset of ossification in the physis: (general orthopedics- anatomy, basic science and pathology)

## Options

1. Type I
2. Type X
3. Type II
4. Type VI

## Correct option

**2. Type X**

## Answer explanation

Explanation: The terminal hypertrophic chondrocytes the hypertrophic zone produces Type X collagen. The appearance of Type X collagen heralds’ ossification. Remember that Type II collagen is the most abundant collagen in the hypertrophic zone.

Answer: 2
