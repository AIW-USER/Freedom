## Question

Which muscle is being tested by the examiner in the figure? ( FNB Pattern Paper 2015)

![[TO17140081-1.png]]

## Options

1. Supraspinatus
2. Infraspinatus
3. Teres minor
4. Subscapularis

## Correct option

**4. Subscapularis**

## Answer explanation

ANSWER-D

This is lift-off test for subscapularis

Lift-off test (Gerber): Patient’s arm is internally rotated with the dorsum of the hand touching the back. If the patient is able to lift his hand off the back, subscapularis function can be presumed to be normal.
