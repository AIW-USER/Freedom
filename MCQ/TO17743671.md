## Question

Dorr’s classification is for (arthroplasty- hip arthroplasty- implants and prosthetic design)

## Options

1. Femoral stem component
2. Acetabular shell component
3. Proximal femur
4. Acetabular cavity

## Correct option

**3. Proximal femur**

## Answer explanation

DORR classification classifies proximal femur in type A,B and C types. It recommends type of femoral stem to be used in THR (see table) but it doesn't classify femoral stem.

Type
Ratio (inner canal diameter 10 cm distal to mid portion of lesser trochanter divided by inner canal diameter at mid portion of lesser trochanter)
Characteristics
Femoral component

Type A
<.5
 Cortices seen on both AP and lateral X rays
Uncemented

Type B
0.5 to 0.75
Thinning of posterior cortex on lateral X ray
Uncemented

Type C
>0.75
Thinning of cortices on both views
Cemented

Answer: 3
