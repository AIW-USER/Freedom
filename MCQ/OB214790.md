## Question

A 68-year-old patient returns to your office for persistent anterior knee pain 14 months following cruciate-substituting total knee arthroplasty. Her pain is during flexion whereas standing does not bother her. Previous comprehensive workup for infection, loosening, and metal allergy have been negative. Figure A is a pre-operative radiograph of her knee, while Figure B is a current radiograph. Which of the following techniques most likely led to the findings shown in Figure B?

*Figure A*

![[q214790-b-tka-patellar-tilt-jpg.jpg]]

## Options

1. Excessive external rotation of the femoral implant
2. Over lateralization of the femoral implant
3. Using a gap balancing approach to set femoral rotation
4. Matching the transepicondylar axis for femoral rotation
5. Using the posterior-condyles as a reference to set femoral rotation

## Correct option

**5. Using the posterior-condyles as a reference to set femoral rotation**

## Answer explanation

This patient has lateral patellar tilt and maltracking following a total knee arthroplasty with pre-operative genu valgum. In this setting of a hypoplastic lateral femoral condyle, using the posterior condyles as a reference could internally rotate your femoral component leading to patellar maltracking.

Axial patellar alignment is an important consideration when performing total knee arthroplasty. Many subtle techniques can have a great impact on the patella's ability to track properly. This is particularly challenging in the setting of pre-operative valgus deformity. The disproportionate wear on the lateral femoral condyle in flexion, termed hypoplastic, alters both the coronal alignment of the lower extremity (increasing Q angle) and the rotational profile of the femur (externally rotates the femur). Using standard posterior-condylar referencing instruments can lead to femoral component internal rotation unless the deformity is recognized and accounted for by adding external rotation or augments. The use of the transepicondylar axis or the anteroposterior/Whiteside's line can aid in verifying the true femoral rotation when setting component rotation.

Whiteside and Arima first detailed using the anteroposterior axis of the femur to guide proper femoral rotation. They described a series of valgus-aligned knees undergoing arthroplasty where they either referenced the posterior-condylar axis or a line from the deepest point of the trochlear groove to the center of the intercondylar notch. They showed significantly fewer instances of post-operative patellar maltracking and re-operation by using the anteroposterior axis.

*Middleton and Palmer reviewed the accuracy of the anteroposterior axis as a rotational reference.* The average angle between the transepicondylar axis and the anteroposterior axis was 91 degrees, +/- 4 degrees. This shows that while this is often a reliable reference, it should not be used in isolation and other axes should be used to establish correct femoral rotation.

Incorrect Answers:
Answer 1- Adding more external rotation to the femoral component will help restore the Q angle.
Answer 2- This will cause a relative internal rotation to the tibia and lessen the Q angle.
Answers 3- Gap balancing has not been shown to be associated with patellar maltracking.
Answer 4- Using the epicondylar axis as a reference is more reliable than posterior condylar axis so this is not the best answer.
