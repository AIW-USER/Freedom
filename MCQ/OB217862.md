## Question

You are designing a study with a group of residents, and they ask when an ANOVA test would be useful for statistical comparison. Which of the following comparisons best illustrates the most appropriate implementation of this test?

## Options

1. Return to play functional scores after ACL reconstruction in groups with hamstring, quadriceps and bone-tendon-bone grafts
2. Incidence of male and female soccer players with ACL tears at your high school
3. Fastball velocity between top five major league pitchers
4. Rotator cuff healing rates based on smoking history
5. DASH outcome scores between distal radius fractures treated operatively vs. non-operatively

## Correct option

**3. Fastball velocity between top five major league pitchers**

## Answer explanation

An analysis of variance (ANOVA) is a statistical test that can be used for comparing the means of 3 or more parametric, continuous data sets, as referenced by the example of fastball velocity for five different major league pitchers. This data set would be considered parametric given the relative normality of major league fastball velocity.

Statistical tests are an important part of research studies and understanding the usage of these tests helps both the author and the reader come to the most appropriate conclusions. In using these tests, it is important to understand the difference between parametric and non-parametric data. Parametric data is classified as continuous data that is normally distributed. Non-parametric data, however, refers to continuous data that is skewed or categorical. Continuous data sets involve numerical values (ex. means), while categorical data references different groups of information (male/female or smoker/non-smoker). Therefore, these groups must all be compared differently. Two sets of continuous data can be compared using a Student's t-test, while 3 or more sets of continuous data are compared using an ANOVA test. Categorical data, however, involves two sets of grouped data being compared using a chi-squared analysis or fisher's exact test when the sample size is low. When comparing 3 or more sets of non-parametric data, a Kruskal-Wallis test may also be useful and is the non-parametric equivalent of an ANOVA test for parametric data.

*Kuhn et al. reviewed statistical tests for categorical/discrete data sets.* **They note** that categorical data falls into specific categories (i.e gender = male or female) and that the frequency with which the observation occurs in each category can be evaluated with a chi-square test. They go on to discuss ways in which the chi-squared test can be misused as well as reasons why using Fisher's exact test for categorical data comparisons may be more appropriate.

*Greenfield et al. reviewed statistical tests for continuous data sets,* **noting** their purpose is to evaluate if the difference between the means/proportions of groups is statistically significant. They discuss different variations of t-tests including independent and paired, as well as the ANOVA, which is used in situations where 3 or more groups are being compared. They go on to summarize clinical situations in which both tests would be appropriate to use.

Incorrect Answers:
Answer 1: When considering the comparison between the 3 types of grafts, one must consider that the data is finite (meaning there is a range which the scores must lie within). Therefore, the data set is not technically continuous and a Chi-squared test would be most appropriate. If the 3 groups were continuous and non-parametric (skewed data), the Kruskal-Wallis test would be most appropriate because non-parametric tests use the median score values to account for these skewed values and provide more statistically appropriate results.
Answer 2: The incidence of male and female soccer players with ACL tears is a comparison between two categorical data sets which can be compared using a chi-squared analysis.
Answer 4: Rotator cuff healing rates based on smoking history (yes/no), is another example of categorical data, which can be compared using a chi-squared test.
Answer 5: DASH outcome scores between distal radius fractures treated operatively vs. non-operatively are another example of comparing two sets of continuous data and a Student's t-test would be used.
