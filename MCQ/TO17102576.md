## Question

How can one avoid distal femur osteolysis after THR?

## Options

1. By using long stem
2. By using proximally circumferentially coated stem
3. By using collared stem
4. By using fully cemented stem

## Correct option

**2. By using proximally circumferentially coated stem**

## Answer explanation

Answer: 2
