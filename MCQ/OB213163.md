## Question

Figure A is a plain radiograph of a 65-year-old female that presents to clinic for evaluation of activity related right knee pain. She has previously been diagnosed with osteoporosis. She states that she has trialed physical therapy and NSAIDs for her knee pain. She also asks if you could review her medications that she is taking for osteoporosis. You perform an intra-articular steroid injection of the right knee and adjust her medications for osteoporosis. When billing for the care provided, what would be the difference between the billing codes for Evaluation and Management (E&M), the procedure, and modifier 25?

![[q213163-a-screen-shot-2021-11-26-at-2-56-11-pm.jpg]]
*Figure A*

## Options

1. Without the injection, this would be billed for an E&M service with modifier 25
2. Without evaluation/adjustment of her osteoporosis medication, the service would be billed as a E&M service only
3. If all the services were provided above, then billing would have included a procedure code and an E&M code appended with modifier 25
4. If all the services were provided above, then billing would have included a procedure code and an E&M code without modifier 25
5. If all the services were provided, then billing would have included an E&M code and a procedure code with modifier 25

## Correct option

**3. If all the services were provided above, then billing would have included a procedure code and an E&M code appended with modifier 25**

## Answer explanation

If all the services were provided, then the provider would bill for the injection as a procedure code, as well as an E&M with modifier 25 for evaluating/managing her osteoporosis.

E&M coding is the use of Current Procedural Terminology (CPT®) codes from the range 99202-99499 to represent services provided by a physician or other qualified healthcare professional. As the name E&M indicates, these medical codes apply to visits and services that involve evaluating and managing patient health. Modifier 25 is appended to claims for an E&M service provided to indicate that a significant, separately identifiable E&M service was performed by the same physician on the day a minor procedure was performed. Note that a procedural code and an E&M code are two different billing codes. CPT codes for procedures do include services necessary for the performance of the procedure, including assessing the site and condition of the problem area, explaining the procedure, and obtaining consent. This is why an E&M code is not necessary when treating a patient with a minor procedure (for example, performing an intra-articular injection). When significant and separately identifiable E&M services are performed above and beyond those necessary for the procedure, these E&M services need to be protected with the appended -25 modifier. Unless protected by a -25 modifier, carriers will not reimburse for an E&M service in addition to the procedure.

*Savarise et al.* *2016 review the appropriate application of modifier 25.* *They discuss the difference between procedure codes and E&M services, and the role of modifier 25 in the setting of performing a procedure.*

Hammon 2005 provides a review of the appropriate documentation needed to support appropriate billing with modifier 25. They note the use of this particular modifier is under increased scrutiny because in one recent year Medicare paid approximately 1.7 billion dollars for Evaluation and Management (E/M) services billed with modifier 25. They conclude that it is important that physicians be knowledgeable in determining when it is appropriate to bill using this modifier.

Incorrect Answers:
Answer 1: Modifier 25 is only applied to the E&M code in the setting of procedure performed on the same day, as described above. If the provider had only evaluated and managed this patient’s osteoporosis, this would simply be coded for the appropriate E&M service (which differs based on the place and/or type of service, such as observation or inpatient hospital care; the service’s content, such as a comprehensive history, a comprehensive examination, and medical decision making (MDM) of moderate complexity; the nature of the presenting problem or problems usually associated with a given level, such as moderate severity; and the time usually associated with the service).
Answer 2: If only the injection was performed, only a procedure code would be billed.
Answer 4: Unless protected by a -25 modifier, carriers will not reimburse for an E&M service in addition to the procedure.
Answer 5: Modifier 25 is appended to an E&M code, not a procedure code.
