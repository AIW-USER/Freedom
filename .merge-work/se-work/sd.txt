@@AFTER **Who** — athletes, **baseball pitchers** · sequela of prior shoulder injury disrupting **scapular stabiliser activation**
**Incidence (TO)** — in **61–100%** of athletes with shoulder injury (throwers: baseball, cricket, volleyball, javelin, tennis) · often a **symptom, not a diagnosis** → treat underlying cause (TO)

| Normal scapula at rest (TO) | Value |
|---|---|
| Internal rotation | **30–45°** |
| Upward rotation | 5–10° (20° in another TO lecture) |
| Anterior tilt | 10–15° |
| Vertebral border | **2–3 cm** from spine |
| Scapular plane | 30–45° anterior to frontal plane |

**During elevation (TO)** — upward rotation **~60°** (with 120° humeral) · **posterior tilt 20°** · ER 15–20° · rhythm **2:1**

| Muscle (TO) | Scapular action |
|---|---|
| **Serratus anterior** | Upward rotation + **posterior tilt** |
| **Lower trapezius** | Depression + upward rotation |
| Upper trapezius | Elevation + upward rotation |
| Rhomboids, levator scapulae | Downward rotation + retraction |
| **Pectoralis minor** | **Anterior tilt** + IR |

**Scapular roles (TO)** — stable base · kinetic-chain link · **shock absorber in deceleration** · glenoid orientation · elevation via upward rotation + posterior tilt
@@END
@@AFTER **Causes (multifactorial)** — neurologic injury · thoracic **kyphosis** · **periscapular muscle fatigue** · **poor throwing mechanics** · pain (shoulder, neck)
**Mechanisms (TO)** — weak **serratus / lower trapezius** + tight **pec minor / levator** · GH instability · kyphosis · kinetic-chain disruption · posterior capsule tightness (anterior tilt) · nerve: **long thoracic → serratus (winging)**, **spinal accessory → trapezius**

**Associated lesions (TO)** — internal impingement · SLAP · GIRD · subacromial impingement
@@END
@@AFTER **Diagnosis** — **clinical**
| Kibler type (TO) | Pattern | Muscle | Pathology |
|---|---|---|---|
| **I** | **Inferomedial border** prominence ("wing") | Weak lower trap / serratus | **Labral tear**, impingement |
| **II** | **Medial border** prominence | Weak rhomboids | **GH instability** |
| **III** | **Superior translation, shrug** | Overactive upper trap, weak lower trap | **Rotator cuff** |
| **IV** | Normal symmetric | — | Normal |

| Test (TO) | Positive |
|---|---|
| **Scapular assistance (SAT)** | ↓ pain / ↑ ROM with manual upward rotation + posterior tilt |
| **Scapular retraction (SRT)** | ↑ supraspinatus strength with manual retraction · **most sensitive for dynamic dyskinesis** (TO) |
| **Lateral scapular slide** | **>1.5 cm** side difference |
| Wall push-up | Medial border prominence (serratus weakness) |
@@END
@@AFTER **SICK / GIRD initial regimen** — **stretch posterior capsule** (IR deficit) **+ pectoralis minor** (coracoid tenderness)
| Rehab (TO) | Technique |
|---|---|
| Stretch **pec minor** | Doorway / corner |
| Stretch levator | Contralateral flexion + rotation |
| Stretch posterior capsule | Cross-body adduction |
| Strengthen **serratus** | **Push-up plus**, dynamic hugs |
| Strengthen **lower trapezius** | **Prone Y raises**, wall slides |
| Rhomboids | Prone retraction, rows |
| Kinetic chain | **Closed chain first** → open-chain overhead; "proximal stability for distal mobility" |

**Return to play (TO)** — full pain-free ROM, no winging · strength **≥90%** of other side · no kinetic-chain deficit · **negative SAT/SRT**
@@END
