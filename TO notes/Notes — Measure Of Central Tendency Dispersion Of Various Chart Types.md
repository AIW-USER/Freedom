Overview / Key Concepts
Measures of central tendency describe the central value of a dataset, while measures of
dispersion explain how widely data is spread around that central value. Both are
essential for correct interpretation of clinical and research data.
This lecture covers: - Mean, median, and mode - Measures of dispersion including
range, IQR, variance, and standard deviation - Appropriate graphical representation of
different data types - Common exam-oriented pitfalls and decision rules

Central Tendency
Central tendency reflects the tendency of data to cluster around a central value.
Common measures: - Mean - Median - Mode

Arithmetic Mean
Definition
Arithmetic mean is the sum of all observations divided by the total number of
observations.
Mean = Σ observations / n

### Key Features
- Most commonly used measure
- Best suited when data is continuous and symmetrically distributed
- Uses all observations
Merits
- Unique value for every dataset
- Easy to calculate and understand
- Suitable for further mathematical analysis
- Least affected by sampling fluctuations
Demerits
- Highly affected by extreme values (outliers)
- Cannot be calculated for qualitative data
- Cannot be calculated for open-ended class intervals
Faculty Quote “If your data has outliers, mean will mislead you. Never use it
blindly.”

Median
Definition
Median is the middle observation when data is arranged in ascending or descending
order.

Calculation
- Odd number of observations: (n + 1) / 2 th term
- Even number of observations: Average of (n / 2) th and (n / 2 + 1) th terms
Merits
- Not affected by extreme values
- Can be calculated for open-ended intervals
- Suitable for ordinal data
- Positional average
Demerits
- Not based on all observations
- Cannot be exactly calculated for even number of observations

Mode
Definition
Mode is the most frequently occurring value in a dataset.

Applications
- Categorical data
- Identifying most common category or choice
Merits
- Easy to understand
- Can be used for nominal data
- Can be calculated for open-ended intervals
Demerits
- May be more than one (bimodal or multimodal)
- May not exist
- Not based on all observations

Dispersion
Dispersion measures the extent of variability or spread in a dataset.
Location alone is incomplete. Location plus dispersion gives a true picture of data
distribution.

Absolute Measures of Dispersion
Range
- Difference between maximum and minimum values
Range = Maximum – Minimum
Limitation - Ignores distribution of values between extremes

Quartiles
- Divide data into four equal parts
- Each segment contains 25 percent of data
- Q1: 25 percent below
- Q2: Median
- Q3: 75 percent below

Interquartile Range (IQR)
### IQR = Q3 – Q1
- Represents spread of central 50 percent of data
- Preferred measure when data has outliers
Quartile Deviation
Quartile Deviation = IQR / 2

### Variance and Standard Deviation
- Measure average variation around the mean
- Variance = Σ(xi – ̄x)² / n
- Standard deviation = Square root of variance

<!-- page 4 -->

Key Point
Standard deviation is preferred over variance because it retains the original unit of
measurement.

Charts and Graphs
Charts simplify complex data for interpretation.
Objectives: - Distribution - Composition - Comparison - Relationship between variables

Common Graph Types and Uses
### Pie Chart
- Represents parts of a whole
- Best for percentages
Limitations - Poor for comparison - Difficult to interpret similar-sized segments

### Bar Diagram
- Used for categorical data
- Height represents frequency
Types: - Vertical bar diagram - Horizontal bar diagram (useful for many or long
categories) - Clustered bar diagram (multiple variables)

### Line Chart
- Represents trends over time
- Used for continuous data
- Can compare two variables over time

Histogram
- Used for continuous numerical data
- Bars are adjacent
- Width represents class interval
- Height represents frequency

<!-- page 5 -->

Difference Between Bar Diagram and Histogram
Bar Diagram: - Used for categorical data - Gaps between bars allowed - Bars can be
reordered
Histogram: - Used for continuous data - No gaps between bars - Bars cannot be
reordered

### Box and Whisker Plot
- Used in exploratory data analysis
- Shows five-number summary:
  - Minimum
  - Q1
  - Median
  - Q3
  - Maximum
- Identifies outliers
- Does not represent mean

### Scatter Plot
- Studies relationship between two continuous variables
- Pattern indicates correlation

### Common Mistakes Highlighted
- Using mean in presence of outliers
- Using pie charts for comparison
- Confusing bar diagrams with histograms
- Reporting mean without standard deviation

### Exam Pearls
- Mean is affected by outliers, median is not
- Median is a positional average
- Mode is preferred for nominal data
- Report mean with standard deviation
- Use median with IQR when outliers are present
- Histogram is used for continuous data
- Line chart represents trends over time
- Scatter plot studies relationship between two continuous variables
